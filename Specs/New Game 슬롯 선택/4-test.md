# New Game 슬롯 선택 검증 결과

## 1. 테스트 시나리오

- 시나리오 실행 명령: `python -I Scripts/ScenarioTest/run.py <시나리오> --map /Game/Maps/LV_FrontEnd`
- 시나리오는 작업용 임시 파일이라 저장소에 두지 않았습니다.
  - 슬롯 선택: 시작 전 Slot 5에 읽을 수 없는 파일을 둠
  - 슬롯 가득: Slot 1~5는 저장, Slot 6은 읽을 수 없는 파일
- 저장 파일은 시나리오가 디스크의 `SlotN.sav`를 직접 읽어 확인했습니다.
  - 마지막 스테이지: 레벨 이름(`LV_`)이 들어 있는지
  - 정상 저장 파일: 파일 앞 표식이 있는지
- 테스트 전 `Saved/SaveGames`는 비어 있었고, 끝난 뒤 다시 비웠습니다.

## 2. 결과

- 빌드: `Build.bat AgEditor Win64 Development` 성공, 포맷 검사 265개 파일 실패 0
- 판정: 두 시나리오 모두 통과 (16개 항목)

| 완료 조건 | 확인한 것 | 결과 |
| - | - | - |
| 시나리오 1 | 저장이 없을 때 타이틀에 New Game만 보임(Continue 숨김). New Game 화면은 줄 6개가 모두 버튼이고 Delete 없음. 처음 선택은 Slot 1. Slot 3(빈 슬롯) 실행 → Slot 3 파일이 생기고 스테이지 선택 화면 | 통과 |
| 시나리오 2 | 스테이지 선택 Back → New Game 화면, Slot 3 선택. Back → 타이틀, New Game 선택 | 통과 |
| 시나리오 3 | 던전에 다녀와 마지막 스테이지가 생긴 Slot 3 실행 → 확인 창, No 선택. No → 창 닫힘, Slot 3 선택, 파일에 마지막 스테이지 그대로 | 통과 |
| 시나리오 4 | 다시 실행 후 Yes → 파일에서 마지막 스테이지가 사라진 새 게임, 스테이지 선택 화면 | 통과 |
| 시나리오 5 | 읽을 수 없는 Slot 5 실행 → 확인 창 → Yes → 정상 저장 파일이 되고 Load Game 화면에 저장된 슬롯으로 보임 | 통과 |
| 시나리오 6 | 슬롯 6개가 모두 차 있어도 타이틀에 New Game이 보이고, New Game 화면의 처음 선택은 Slot 1 | 통과 |

- 화면 캡처(슬롯 가득): 줄 6개가 화면 가운데에 놓이고, 읽을 수 없는 줄은 'Slot 6 Corrupted' 버튼으로 보임.
- 로그: 창 로그에 게임 오류(`LogAg: Error`) 없음.
- 첫 실행에서는 시나리오 쪽 실수 두 가지로 5개 항목이 실패했습니다. 기록을 보고 시나리오만 고쳤고, 통과 기준은 바꾸지 않았습니다.
  - 파일 앞 표식을 반대 바이트 순서로 비교함
  - 타이틀 버튼을 포커스 없이 눌러, 엔진이 그전 포커스(Continue)를 되돌림

## 3. 회귀 확인

- Load Game 화면: 저장된 슬롯 줄만 버튼이고 Delete 버튼이 보임. Delete → Yes로 그 슬롯이 지워짐. Back → 타이틀. 모두 통과.
- 확인하지 않은 것: Load Game 화면의 줄 정렬을 화면으로 다시 찍어 보지는 않았습니다. Delete 칸은 너비 192px에 안쪽 왼쪽 여백 24px를 두는 구조로 바뀌었고, 버튼 크기와 간격은 이전과 같습니다.
