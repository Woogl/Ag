# New Game 슬롯 선택 Spec

## 1. 개요 및 목적

- 지금은 New Game을 실행하면 빈 슬롯 중 번호가 가장 작은 슬롯에 바로 새 게임을 만듭니다. 이 단계를 바꿔 새 게임을 저장할 슬롯을 플레이어가 고르게 합니다.
- 이미 저장된 슬롯도 골라 덮어쓸 수 있게 해서, 슬롯 6개가 모두 차 있어도 New Game을 시작할 수 있게 합니다.

## 2. 플레이 규칙 및 수치

### 타이틀 화면 (덮어쓰기: [UI 시스템](<../../Docs/Design/System/UI 시스템.md>) '타이틀 화면', [게임 플로우](<../../Docs/Design/System/게임 플로우.md>) 'Front End')

- New Game 버튼은 항상 표시합니다. 빈 슬롯이 없을 때 New Game 버튼을 숨기던 규칙은 없앱니다. Continue와 Load Game 버튼을 숨기는 규칙은 그대로입니다.
- New Game을 실행하면 New Game 화면을 엽니다.

### New Game 화면 (신규)

LV_FrontEnd에서 타이틀 화면의 New Game 버튼으로 여는 화면입니다.

- 배치와 표시는 Load Game 화면과 같습니다. 다른 점은 아래뿐입니다.
  - 제목은 'New Game'입니다.
  - Delete 버튼이 없습니다.
  - 빈 슬롯의 줄과 읽을 수 없는 저장의 줄도 버튼이어서, 여섯 줄을 모두 선택하고 실행할 수 있습니다. 빈 슬롯의 줄에는 슬롯 이름과 'Empty'를, 읽을 수 없는 저장의 줄에는 슬롯 이름과 'Corrupted'를 적습니다.
- 처음 선택된 것은 빈 슬롯 중 번호가 가장 작은 슬롯의 줄입니다. 빈 슬롯이 없으면 Slot 1의 줄입니다.
- 스테이지 선택 화면에서 Back으로 돌아오면 그 화면을 열 때 실행한 슬롯 줄이 선택됩니다.
- Back 버튼을 실행하거나 Esc를 누르면 화면을 닫고 타이틀 화면으로 돌아갑니다.

| 조작 | 실행 결과 |
| - | - |
| 빈 슬롯의 줄 실행 | 그 슬롯에 새 게임을 만들어 저장하고 스테이지 선택 화면을 엽니다. |
| 저장된 슬롯이나 읽을 수 없는 저장의 줄 실행 | 덮어쓰기 확인 창을 엽니다. 창에서 Yes를 실행하면 그 슬롯의 저장을 지우고 새 게임을 만들어 저장한 뒤 스테이지 선택 화면을 엽니다. 덮어쓴 저장은 되돌릴 수 없습니다. |
| Back | 화면을 닫고 타이틀 화면으로 돌아갑니다. |

- 새 게임의 내용은 지금과 같습니다. ([게임 플로우](<../../Docs/Design/System/게임 플로우.md>) 'Front End'의 새 게임)
- New Game 화면에서 연 스테이지 선택 화면의 Back은 New Game 화면으로 돌아갑니다. 만든 슬롯은 내려놓고, 저장은 남습니다.

### 덮어쓰기 확인 창 (신규)

New Game 화면에서 저장된 슬롯이나 읽을 수 없는 저장의 줄을 실행하면 여는 창입니다.

- 배치와 표시, 조작은 삭제 확인 창과 같고, 문구만 '이 저장 데이터를 덮어쓰시겠습니까?'입니다.
- 처음 선택된 버튼은 No입니다.
- No를 실행하거나 Esc를 누르면 창을 닫고, 덮어쓰려던 슬롯의 줄이 선택됩니다.

### 저장 (덮어쓰기: [게임 플로우](<../../Docs/Design/System/게임 플로우.md>) '저장하는 순간')

- 'New Game으로 슬롯을 만듦'은 'New Game 화면에서 고른 슬롯에 새 게임을 만듦'으로 바꿉니다. 덮어쓸 때도 같습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시나리오 1: 슬롯이 모두 비어 있을 때 New Game → New Game 화면이 열리고 Slot 1의 줄이 선택되어 있다. Slot 3의 줄을 실행하면 Slot 3에 새 게임이 저장되고 스테이지 선택 화면이 열린다.
- [ ] 시나리오 2: 스테이지 선택 화면의 Back → New Game 화면으로 돌아오고 Slot 3의 줄이 선택되어 있으며, Slot 3의 줄은 저장된 슬롯으로 표시된다. 다시 Back → 타이틀 화면으로 돌아오고 New Game 버튼이 선택되어 있다.
- [ ] 시나리오 3: 저장된 슬롯의 줄 실행 → 덮어쓰기 확인 창이 열리고 No가 선택되어 있다. No → 창이 닫히고 그 줄이 선택되며 저장은 그대로다.
- [ ] 시나리오 4: 같은 줄에서 Yes → 그 슬롯이 새 게임(시작 보유 수, 던전 진행과 마지막 스테이지 없음, 플레이 시간 0)으로 바뀌고 스테이지 선택 화면이 열린다.
- [ ] 시나리오 5: 읽을 수 없는 저장의 줄도 덮어쓰기 확인 창을 거쳐 새 게임으로 덮어쓸 수 있다.
- [ ] 시나리오 6: 슬롯 6개가 모두 저장되어 있어도 타이틀 화면에 New Game 버튼이 보이고, New Game 화면에서는 Slot 1의 줄이 선택되어 있다.
