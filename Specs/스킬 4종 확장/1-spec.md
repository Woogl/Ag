# 스킬 4종 확장 작업 명세 (Spec)

## 1. 개요 및 목적

- [마일스톤 3](<../../Docs/Milestone/마일스톤 3.md>)의 '스킬 확장과 콤보'에 따라 스킬을 4개로 늘립니다. 이 명세는 숫자 키 1~4로 서로 다른 스킬 4개를 쓰고, 전투 HUD에서 네 스킬의 상태를 보는 기본 구성까지 다룹니다. 스킬마다의 고유 동작은 다루지 않습니다.
- 지금 E 키로 쓰는 스킬(올려베기로 띄우기)은 마일스톤 3의 표대로 스킬 2가 됩니다. 스킬 1·3·4는 스킬 2와 같은 동작입니다.

## 2. 플레이 규칙 및 수치

### 키 배치

| 조작 | 키 |
| - | - |
| 스킬 1, 2, 3, 4 | 1, 2, 3, 4 |

- 숫자 키는 키보드 위쪽 줄의 숫자 키입니다.
- E 키에는 조작이 없습니다.
- [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)의 '키 배치' 표에서 '스킬 | E' 행을 위 행으로 바꿉니다. 전투 HUD의 '조작 안내'와 조작 안내 팝업은 이 표를 따르므로 스킬을 한 줄('1, 2, 3, 4 | 스킬 1, 2, 3, 4')로 표시합니다.

### 스킬 구성

| 스킬 | 키 | ID | 동작 |
| - | - | - | - |
| 스킬 1 | 1 | Skill1 | 스킬 2와 같습니다. |
| 스킬 2 | 2 | Skill2 | 지금 스킬과 같습니다. MP 소모 40, 쿨다운 3초, 몸을 회전하며 아래에서 위로 크게 올려베어 적을 공중에 띄웁니다. HP 배율 1.2, PP 배율 2.5, 피격 반응 넉업. 후딜 시작과 모션도 지금 스킬과 같습니다. |
| 스킬 3 | 3 | Skill3 | 스킬 2와 같습니다. |
| 스킬 4 | 4 | Skill4 | 스킬 2와 같습니다. |

- MP 소모와 쿨다운은 스킬마다 따로 적용합니다. 한 스킬이 쿨다운 중이어도 다른 스킬은 MP가 충분하면 쓸 수 있습니다.
- 기획서에서 '스킬'로 적은 규칙은 스킬 1~4에 모두 적용합니다. [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)의 상태별 허용 입력·선입력·모션 캔슬, [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>)의 공격 방향·공격 중 위치·회전 보정·적중에 의한 충전 횟수·UP 충전(스킬 적중 +15)·MP 충전 없음·SP 소모 없음이 여기에 들어갑니다.
- 그래서 스킬의 후딜에 다른 스킬 키를 누르면 그 스킬로 모션 캔슬하고, 후딜 전에 누르면 선입력으로 기억합니다. 같은 스킬 키는 쿨다운 중이라 실행하지 않습니다.
- 스킬 1~4의 HUD 아이콘은 모두 지금 스킬 아이콘입니다.

### 전투 HUD 스킬·궁극기 슬롯

[UI 시스템](<../../Docs/Design/System/UI 시스템.md>) '전투 HUD'의 '스킬·궁극기 슬롯'을 아래로 바꿉니다.

| 슬롯 | 위치 | 슬롯 안 정보 |
| - | - | - |
| 스킬 1 ~ 4 | 화면 오른쪽 아래에 십자로 놓습니다. 스킬 1 왼쪽, 스킬 2 위, 스킬 3 오른쪽, 스킬 4 아래입니다. | 그 스킬의 아이콘, MP 코스트, 쿨다운 표시(쿨다운 중) |
| 궁극기 | 스킬 십자의 오른쪽 위 | 궁극기 아이콘. 슬롯 테두리에 UP 게이지를 표시합니다. |

- 슬롯은 모두 지름 80px의 원형이며, 반투명한 어두운 바탕에 얇고 옅은 흰 테두리를 둡니다. 아이콘은 슬롯 가운데에 54 × 54px로 표시합니다.
- 십자 가운데에서 각 스킬 슬롯의 중심까지는 75px입니다. 십자 가운데에는 아무것도 표시하지 않습니다. 궁극기 슬롯까지 합친 전체 크기는 약 250 × 250px입니다.
- 키 표시: 각 스킬 슬롯의 십자 가운데 쪽 테두리에 걸치도록 십자 가운데에서 30px 떨어진 곳에 그 슬롯의 키 이름(1~4)을 표시합니다. 글자는 Small이며 지름 28px의 반투명한 어두운 원 위에 둡니다. 키 이름은 UI 스타일의 '입력 키 표시'를 따릅니다.
- MP 코스트는 슬롯 중심에서 오른쪽으로 29px, 아래로 29px인 곳에 글자 Small로 표시합니다. 슬롯 테두리에 걸치므로 글자에 어두운 외곽선을 둘러 배경 위에서도 읽히게 합니다.
- 궁극기 슬롯은 십자 가운데에서 오른쪽으로 96px, 위로 96px인 곳에 중심을 둡니다. 위 슬롯(스킬 2)·오른쪽 슬롯(스킬 3)과 약 18px 떨어집니다.
- 궁극기 슬롯의 오른쪽 끝과 아래 슬롯(스킬 4)의 아래쪽 끝을 화면 여백(48px)에 맞춥니다.
- UP 게이지는 궁극기 슬롯의 원형 테두리가 UP 비율만큼 위쪽 가운데부터 시계 방향으로 채워지는 표시입니다. UP가 가득 차면 테두리 전체가 채워집니다.
- 쿨다운 표시, MP·UP 부족 시 흐리게 표시하는 규칙은 지금과 같고, 스킬 슬롯마다 따로 표시합니다. 원형 표시는 원형 슬롯 안쪽을 덮습니다.
- 스킬 슬롯과 궁극기 슬롯은 조작 안내와 겹치지 않습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] MP가 충분할 때 1·2·3·4 키를 각각 누르면 그 키의 스킬이 발동합니다. 네 스킬 모두 올려베기로 적을 띄우고 MP를 40씩 소모합니다.
- [ ] E 키를 눌러도 아무 행동도 하지 않습니다.
- [ ] 스킬 1을 쓴 직후 쿨다운 3초 동안 1 키는 발동하지 않고, MP가 충분하면 2·3·4 키는 바로 발동합니다.
- [ ] 스킬의 후딜에 다른 스킬 키를 누르면 그 스킬로 모션 캔슬합니다. 후딜 전에 누른 다른 스킬 키는 0.3초 안에 후딜이 시작되면 그때 실행합니다.
- [ ] MP가 40 미만이면 어느 스킬 키도 발동하지 않고, 네 스킬 슬롯이 모두 흐리게 표시됩니다.
- [ ] 각 스킬의 첫 적중마다 UP가 15 늘고, MP는 늘지 않습니다.
- [ ] 전투 HUD 오른쪽 아래에 원형 스킬 슬롯 4개가 십자(1 왼쪽, 2 위, 3 오른쪽, 4 아래)로 놓이고, 각 슬롯 안쪽에 키 숫자, 슬롯 안에 아이콘과 MP 코스트 40이 보입니다.
- [ ] 스킬을 쓰면 그 스킬 슬롯에만 쿨다운 원형 표시와 숫자가 나타나고, 다른 슬롯에는 나타나지 않습니다. 두 스킬을 연달아 쓰면 두 슬롯이 각자의 남은 시간을 표시합니다.
- [ ] 궁극기 슬롯이 스킬 십자의 오른쪽 위에 원형으로 보이고, UP가 오르면 원형 테두리가 위쪽 가운데부터 시계 방향으로 채워집니다.
- [ ] 스킬·궁극기 슬롯이 화면 여백 안에 있고 조작 안내와 겹치지 않습니다.
- [ ] 전투 HUD의 조작 안내와 타이틀의 조작 안내 팝업에 '1, 2, 3, 4 | 스킬 1, 2, 3, 4' 한 줄이 'E | 스킬' 대신 표시됩니다.
- [ ] 궁극기 컷신과 스테이지 결과 중에는 지금처럼 슬롯을 모두 숨깁니다.
