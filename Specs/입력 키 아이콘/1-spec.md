# 입력 키 아이콘 Spec

## 1. 개요 및 목적

- 화면에 키를 글자로 적던 곳을 키 아이콘으로 바꿉니다. 키보드 키는 키캡 그림, 마우스 입력은 누르는 부분을 표시한 마우스 그림으로 보여 줘, 글자를 읽지 않아도 어떤 키인지 알아보게 합니다.
- 아이콘은 현재 키 배치를 따릅니다. 키 배치가 바뀌면 아이콘도 함께 바뀝니다.

## 2. 플레이 규칙 및 수치

### UI 스타일 '입력 키 표시' (덮어쓰기)

- 키보드·마우스 기준으로 표시합니다. 지원하는 조작 장치는 [게임 개요](<../../Docs/Design/게임 개요.md>)를 따릅니다.
- 키는 키 아이콘으로 표시합니다. 키보드 키는 키 이름을 적은 키캡, 마우스 입력은 마우스 그림으로, 좌클릭·우클릭은 누르는 버튼을, 휠 클릭은 휠을 강조하고, 마우스 이동은 마우스 둘레에 네 방향 화살표를 둡니다.
- 아이콘의 크기는 아이콘을 담는 정사각형 칸의 한 변으로 적습니다. 키캡과 마우스 그림은 칸 안에 여백을 두고 그려집니다.
- 아이콘의 에셋과 모양은 [아트 표현 사양](<../../Docs/Art/아트 표현 사양.md>)의 '입력 키 아이콘'을 따릅니다.

### 전투 HUD (덮어쓰기)

| 요소 | 변경 전 | 변경 후 |
| - | - | - |
| 스킬 1 ~ 4 키 표시 | 지름 28px 반투명 어두운 원 위에 키 이름(1~4)을 글자 Small로 | 그 슬롯의 키 아이콘 36px. 위치(십자 가운데에서 30px, 슬롯 테두리에 걸침)는 그대로 |
| 회복병 키 | 지름 28px 원 위에 키 이름(R) | 키 아이콘 36px. 위치(칸 중심에서 오른쪽으로 45px)는 그대로 |
| 회복병 횟수 | 키 표시 오른쪽 | 그대로 키 아이콘 오른쪽 |

### 상호작용 안내 (덮어쓰기)

| 항목 | 변경 후 |
| - | - |
| 키 표시 | 상호작용 키의 키 아이콘 48px. 바탕 원과 테두리는 두지 않습니다. |
| 행동 이름 | 키 아이콘 오른쪽에 8px 띄우고 세로 가운데를 맞춥니다. (그 밖은 그대로) |
| 위치 | 키 아이콘의 왼쪽 끝을 안내 지점에서 오른쪽으로 22px 띄웁니다. (그 밖은 그대로) |

### 조작 안내 팝업 (덮어쓰기)

- 각 줄은 왼쪽에 키 아이콘, 오른쪽에 조작 이름을 표시합니다. 조작 이름은 모든 줄에서 같은 위치에서 시작합니다.
- 키 아이콘은 36px입니다. 한 줄에 키가 여럿이면(이동의 W·A·S·D, 스킬의 1·2·3·4) 키 배치 표의 순서대로 4px 간격으로 나란히 놓습니다.
- 조작 이름은 글자 Medium입니다. 아이콘 줄의 세로 가운데에 맞춥니다.
- 줄 사이는 6px입니다. 배경 안쪽 여백 24px, 키 아이콘 열과 조작 이름 사이 48px은 그대로입니다.
- 일시정지 줄의 Esc도 키 아이콘으로 표시합니다.

### 바뀌지 않는 것

- 키 배치, 아이콘을 표시하는 화면과 그 표시 조건, 궁극기 슬롯(키를 표시하지 않음)은 그대로입니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 스테이지의 전투 HUD에서 스킬 1~4 슬롯에 1·2·3·4 키캡, 회복병 칸에 R 키캡이 36px로 보이고, 회복병 횟수가 그 오른쪽에 보입니다.
- [ ] 상호작용 대상(처형 가능한 적) 앞에서 F 키캡 48px과 행동 이름이 안내 지점 오른쪽에 보입니다.
- [ ] 타이틀에서 Controls를 열면 12줄 모두 키 배치 표의 키가 아이콘으로 보입니다. 이동은 W·A·S·D 네 개, 스킬은 1·2·3·4 네 개, 시야는 마우스 이동, 기본 공격·가드·락온은 좌클릭·우클릭·휠 클릭, 일시정지는 Esc입니다.
- [ ] 밝은 배경과 어두운 배경 모두에서 키캡의 키 이름을 읽을 수 있습니다.
- [ ] 팝업을 닫았다가 다시 열어도, 팝업을 닫고 Play로 스테이지에 들어가도 아이콘과 조작이 정상입니다.
