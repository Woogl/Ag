# 쿨다운 충전 작업 명세 (Spec)

## 1. 개요 및 목적

- 행동에 충전 횟수를 둡니다. 충전이 남아 있으면 쿨다운이 흐르는 중에도 그 행동을 다시 쓸 수 있고, 쿨다운이 지날 때마다 최대 횟수까지 한 번씩 다시 채워집니다.
- 짧은 간격으로 몇 번 이어 쓰는 신규 스킬에 씁니다. 이번 작업에서는 규칙과 데이터 값만 더하고, 지금 있는 행동의 값은 바꾸지 않습니다.

## 2. 플레이 규칙 및 수치

[전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '쿨다운'을 아래 규칙으로 바꿉니다.

- 행동마다 최대 충전 횟수를 둘 수 있습니다. 적혀 있지 않으면 1회이며, 이때는 지금 규칙과 같습니다.
- 행동을 시작하면 충전을 1회 씁니다. 충전이 남아 있으면 쿨다운이 흐르는 중에도 그 행동을 사용할 수 있습니다.
- 충전이 최대보다 적은 동안 쿨다운이 흐르고, 끝날 때마다 충전이 1회 늘어납니다. 그래도 최대보다 적으면 바로 다음 쿨다운을 셉니다. 쿨다운은 한 번에 하나만 흐릅니다.
- 충전이 최대일 때 행동을 시작하면 그 순간부터 쿨다운을 셉니다. 쿨다운이 흐르는 중에 행동을 시작해도 흐르던 쿨다운은 처음부터 다시 세지 않습니다.
- 충전이 남지 않은 동안을 쿨다운 중이라 하며, 그 행동을 사용할 수 없습니다. 이때 남은 쿨다운은 다음 충전까지의 시간입니다.
- 처음 전투에 들어갈 때는 모든 행동의 충전이 최대입니다.
- 쿨다운과 최대 충전 횟수는 각 캐릭터 기획서를 따르며, 쿨다운이 적혀 있지 않은 행동은 쿨다운이 없습니다.

예: 최대 충전 3회, 쿨다운 3초인 행동을 0초·1초·2초에 쓰면

| 시각 | 일 | 남은 충전 |
| - | - | - |
| 0초 | 사용. 쿨다운 시작 | 2 |
| 1초 | 사용. 흐르던 쿨다운은 이어짐 | 1 |
| 2초 | 사용. 쿨다운 중(다음 충전까지 1초) | 0 |
| 3초 | 충전. 다음 쿨다운 시작 | 1 |
| 6초 | 충전. 다음 쿨다운 시작 | 2 |
| 9초 | 충전 | 3 |

- 쿨다운의 시간 기준은 지금처럼 [시간 규칙](<../../Docs/Design/System/시간 규칙.md>)을 따릅니다.
- HUD는 바꾸지 않습니다. 스킬 슬롯의 쿨다운 표시([UI 시스템](<../../Docs/Design/System/UI 시스템.md>) '스킬·궁극기 슬롯')는 쿨다운 중, 곧 충전이 남지 않은 동안에만 나타나고 다음 충전까지의 시간을 보여 줍니다.

## 3. 완료 조건 (Acceptance Criteria)

확인용으로 린의 스킬에 최대 충전 3회와 쿨다운 5초를 임시로 적고, 확인 뒤 되돌립니다. 스킬 모션이 약 1.2초라, 쿨다운 3초로는 세 번 쓰는 동안 첫 충전이 돌아와 충전이 없어 막히는 때를 따로 볼 수 없기 때문입니다.

- [ ] 시나리오 1: 스킬 키를 계속 누르면 세 번 이어 실행되고, 세 번째 스킬이 끝난 뒤 첫 충전 전까지는 실행되지 않는다.
- [ ] 시나리오 2: 첫 사용부터 5초·10초·15초에 충전이 1회씩 늘어난다. 10초 뒤에는 두 번 연달아 쓸 수 있고, 그 뒤에는 15초에 다시 쓸 수 있다(10초 뒤에 쓴 두 번 때문에 늦춰지지 않는다).
- [ ] 시나리오 3: 충전이 남아 있는 동안 스킬 슬롯에 쿨다운 표시가 없고, 0회가 되면 다음 충전까지 남은 시간이 표시된다.
- [ ] 시나리오 4: 최대 충전 횟수를 적지 않은 행동은 지금과 같다. 린의 스킬(되돌린 값)은 3초 동안 다시 쓸 수 없고, 보스 패턴의 쿨다운도 그대로다.
