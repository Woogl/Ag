# 일시정지 메뉴 탭 Spec

## 1. 개요 및 목적

- 스테이지에서 Esc로 여는 일시정지 메뉴를 위쪽의 탭으로 화면을 바꾸는 메뉴로 바꿉니다.
- 탭은 Inventory와 System 두 개입니다. Inventory 탭은 린이 가진 아이템을 보여 주고, System 탭은 지금 일시정지 메뉴의 버튼을 그대로 담습니다.
- 메뉴를 여는 조건과 게임을 멈추는 규칙은 바꾸지 않습니다.

## 2. 플레이 규칙 및 수치

### 2.1 열기와 닫기

- 여는 조건과 메뉴가 열려 있는 동안 게임이 멈추는 규칙은 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 '일시정지' 그대로입니다.
- 메뉴를 열 때마다 System 탭을 표시합니다.
- 어느 탭에서든 Esc를 누르면 메뉴를 닫고 게임을 이어 갑니다. System 탭의 Resume 버튼을 실행해도 같습니다.

### 2.2 화면 구성

[UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '일시정지 메뉴'를 아래로 바꿉니다.

- 뒤의 게임 화면은 어둡게 표시합니다. 페이드 없이 바로 표시하고, 표시하는 즉시 입력을 받습니다.
- 메뉴가 열려 있는 동안 전투 HUD의 플레이어 상태, 스킬·궁극기 슬롯, 보스 상태를 숨기고, 메뉴를 닫으면 다시 표시합니다. 탭 바가 화면 위쪽 가운데의 보스 상태와 겹치기 때문입니다. 락온 마커, 상호작용 안내, 적 네임플레이트는 메뉴를 열기 직전의 표시를 그대로 둡니다.
- 메뉴가 떠 있는 동안 마우스 커서를 표시하고, 플레이어 입력은 UI만 받습니다.
- 화면 위쪽 가운데에 탭 바를 둡니다. 탭 바의 위쪽은 화면 여백에 맞춥니다.
  - 탭 이름을 왼쪽부터 Inventory, System 순서로 가로로 놓습니다. 글자는 Large이고, 탭 이름 사이는 64px입니다.
  - 고른 탭의 이름은 흰색 굵은 글자이고, 이름 아래 8px에 이름 너비만큼 두께 4px의 흰 밑줄을 긋습니다.
  - 고르지 않은 탭의 이름은 흐린 회색 글자이고 밑줄이 없습니다. 마우스를 올리면 글자가 밝아집니다.
  - 탭 바 왼쪽 끝에 Q, 오른쪽 끝에 E 키 아이콘을 탭 이름과 32px 띄워 놓습니다. 키 아이콘은 36px이며 UI 스타일의 '입력 키 표시'를 따릅니다.
- 탭 바 아래에 고른 탭의 내용을 표시합니다. 탭을 바꾸면 내용이 페이드 없이 바로 바뀝니다.

### 2.3 탭 바꾸기

- Q를 누르면 왼쪽 탭으로, E를 누르면 오른쪽 탭으로 바꿉니다. 첫 탭에서 Q를 누르면 마지막 탭으로, 마지막 탭에서 E를 누르면 첫 탭으로 바꿉니다.
- 고르지 않은 탭의 이름을 좌클릭해도 그 탭으로 바꿉니다.
- 탭 이름에 마우스를 올릴 때와 탭을 바꿀 때 UI 스타일 '버튼'의 효과음을 재생합니다.
- 탭을 바꾸면 그 탭에서 처음 선택된 것을 선택합니다.

### 2.4 Inventory 탭

왼쪽에 아이템 칸을 격자로 늘어놓은 그리드를, 오른쪽에 고른 아이템의 상세 패널을 둡니다. 그리드와 상세 패널은 48px 띄워 한 묶음으로 화면 가운데에 놓고, 둘의 위쪽은 탭 바 아래 72px에 맞춥니다.

**그리드**

- 칸은 128 × 160px이고, 칸 사이는 가로세로 모두 16px입니다. 그리드는 한 줄에 7칸, 4줄이 보이는 크기입니다.
- 보유 수가 1 이상인 아이템을 칸 하나에 하나씩, 왼쪽 위 칸부터 오른쪽으로 채우고 줄이 차면 다음 줄로 넘어갑니다. 순서는 소비 아이템, 재화 아이템 순서이고, 같은 카테고리 안에서는 [아이템 시스템](<../../Docs/Design/System/아이템 시스템.md>)의 '아이템 목록' 순서입니다.
- 칸의 바탕은 반투명한 어두운 색입니다. 칸 위쪽 가운데, 칸 위에서 12px에 아이템 아이콘을 96px로 놓고, 칸 아래쪽 32px은 바탕보다 밝은 띠로 두어 가운데에 보유 수를 숫자만 Medium으로 표시합니다. (예: 3)
- 고른 칸은 굵은 흰 테두리와 밝은 바탕으로, 마우스를 올린 칸은 옅은 테두리로 구분합니다.
- 칸이 4줄을 넘으면 그리드 안에서 세로로 스크롤합니다. 마우스 휠로 스크롤하고, 방향키로 보이지 않는 칸을 고르면 그 칸이 보이도록 스크롤합니다.
- 보유한 아이템이 없으면 그리드를 빈 채로 두고 상세 패널은 표시하지 않습니다.

**칸 고르기**

- Inventory 탭을 표시할 때마다 첫 칸이 골라져 있습니다. 다른 탭에 갔다가 돌아와도 같습니다.
- 칸을 좌클릭하거나 방향키로 옮기면 그 칸을 고릅니다. 마우스를 올리기만 해서는 고르지 않습니다.
- 칸에 마우스를 올릴 때와 좌클릭으로 칸을 고를 때 UI 스타일 '버튼'의 효과음을 재생합니다.
- 이 탭에서 아이템을 쓰거나 버리는 조작은 없습니다. 고른 칸을 다시 좌클릭하거나 Enter를 눌러도 아무 일도 하지 않습니다.

**상세 패널**

고른 아이템을 너비 560px의 패널에 보여 줍니다. 패널의 바탕은 반투명한 어두운 색입니다.

- 패널 위쪽의 높이 72px 띠는 바탕보다 밝은 색이고, 왼쪽에서 24px 안쪽에 아이템 이름을 Large 굵은 글자로 표시합니다. 이름은 '아이템 목록'의 '아이템' 열입니다. (예: 회복병)
- 이름 띠 아래 높이 224px 칸의 오른쪽에 아이템 아이콘을 192px로 놓습니다. 왼쪽에는 위에서부터 카테고리 이름('소비 아이템' 또는 '재화 아이템', Medium, 흐린 회색), '보유'(Small, 흐린 회색), '보유 수 / 최대 보유 수'(Large)를 표시합니다. (예: 3 / 3)
- 그 아래에 아이템 설명을 Medium으로 표시합니다. 안쪽 여백은 24px이고, 패널 너비를 넘는 글은 다음 줄로 넘깁니다. 패널의 높이는 설명이 끝나는 곳까지입니다.
- 이름과 설명은 [아이템 시스템](<../../Docs/Design/System/아이템 시스템.md>)의 '이름과 설명'을 따릅니다.

### 2.5 System 탭

- 화면 가운데에 Resume, Restart, Return to Title, Quit 버튼을 위에서부터 세로로 배치합니다. (글자 Large) 제목은 표시하지 않습니다.
- 처음 선택된 버튼은 Resume입니다.
- 버튼의 실행 결과는 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 '일시정지'를 따릅니다.

### 2.6 UI 조작

[UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 조작' 표에 두 줄을 더합니다.

| 동작 | 키 |
| - | - |
| 일시정지 메뉴의 탭 바꾸기 | Q·E, 또는 탭 이름 좌클릭 |
| Inventory 탭의 칸 고르기 | 좌클릭, 또는 방향키(↑·↓·←·→) |

- Q·E는 일시정지 메뉴가 입력을 받을 때만 탭을 바꿉니다. 전투 HUD에서 Q는 지금처럼 궁극기입니다.
- 방향키는 지금 탭의 내용 안에서만 선택을 옮기고, 탭 바로는 옮기지 않습니다.
- Inventory 탭의 방향키는 그 방향의 바로 옆 칸이나 위아래 칸으로 옮깁니다. 줄의 끝에서 ←·→는 다음 줄이나 이전 줄로 넘어가지 않고 멈춥니다.

### 2.7 리소스

- 아이템 아이콘: 회복병은 전투 HUD의 회복병 아이콘과 같은 그림입니다. ([아트 표현 사양](<../../Docs/Art/아트 표현 사양.md>)의 '회복병 HUD 아이콘')
- E 키 아이콘을 다른 입력 키 아이콘과 같은 방식으로 더합니다. ([아트 표현 사양](<../../Docs/Art/아트 표현 사양.md>)의 '입력 키 아이콘')

### 2.8 기존 문서와의 관계

| 문서 | 반영 |
| - | - |
| UI 시스템 | '일시정지 메뉴'를 2.1~2.5로 바꾸고 그림을 이 Spec의 두 그림으로 바꿈. '상황별 표시 규칙'에 일시정지 메뉴 행을 더하고 표 아래의 일시정지 문장을 2.2의 HUD 숨김에 맞춤. 'UI 조작' 표와 Esc 설명에 2.6 반영 |
| 게임 플로우 | '일시정지'의 'Resume 버튼'을 'System 탭의 Resume 버튼'으로 |
| 아트 표현 사양 | '회복병 HUD 아이콘'이 Inventory 탭에도 쓰임, '입력 키 아이콘'에 E 키 추가 |

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 스테이지에서 Esc를 누르면 게임이 멈추고 일시정지 메뉴가 System 탭으로 열리며 Resume이 선택되어 있다. 탭 바에 Q·Inventory·System·E가 보이고 System에 밑줄이 있다.
- [ ] 메뉴가 열려 있는 동안 플레이어 상태, 슬롯, 보스 상태가 보이지 않고, 닫으면 다시 보인다. 보스전 중 HP 감소 잔상과 스킬 쿨다운은 닫은 뒤 멈춘 자리에서 이어진다.
- [ ] 스테이지 시작 직후 메뉴를 열고 Q로 바꾼 Inventory 탭의 그리드 첫 칸에 회복병 아이콘과 '3'이 보이고 그 칸이 골라져 있다. 상세 패널에 '회복병', '소비 아이템', '보유', '3 / 3', 설명 '마시면 HP를 회복합니다.'와 큰 아이콘이 보인다.
- [ ] 회복병을 한 번 마시고 열면 칸에 '2', 상세 패널에 '2 / 3'이 보인다. 모두 마시고 열면 그리드가 비어 있고 상세 패널은 없다.
- [ ] 칸에 마우스를 올리면 옅은 테두리만 생기고 상세 패널은 바뀌지 않는다. 좌클릭하면 그 칸이 골라진다. (테스트 창 사본 데이터에만 시험용 아이템을 넣어 두 칸 이상에서 확인)
- [ ] 칸 사이를 방향키로 옮길 수 있고, 줄 끝에서 ←·→를 누르면 멈춘다.
- [ ] System 탭에서 Q를 누르면 Inventory 탭으로 바뀌고 첫 칸이 골라진다. Inventory 탭에서 E를 누르면 System 탭으로 바뀌고 Resume이 선택된다. System 탭에서 E를 누르면 Inventory 탭으로, Inventory 탭에서 Q를 누르면 System 탭으로 넘어간다.
- [ ] 탭 이름을 좌클릭하면 그 탭으로 바뀐다. 탭 이름에 마우스를 올릴 때와 탭을 바꿀 때 버튼 효과음이 난다.
- [ ] 두 탭 모두에서 Esc를 누르면 메뉴가 닫히고 게임이 멈춘 자리에서 이어진다. 다시 열면 System 탭이다.
- [ ] System 탭의 Resume, Restart, Return to Title, Quit가 지금 일시정지 메뉴와 같은 결과를 낸다.
- [ ] System 탭에서 방향키는 버튼 사이로만 선택을 옮긴다.
- [ ] 메뉴를 닫은 전투 중에 Q를 누르면 궁극기가 지금처럼 발동한다.
