# 락온 대상 전환 작업 명세 (Spec)

## 1. 개요 및 목적

- 다수전에서 다른 적을 노리려면 락온을 풀고 화면 중앙에 그 적을 맞춘 뒤 다시 락온해야 합니다. 락온을 유지한 채 대상만 바꿀 수 있게 합니다.
- 락온 중에 마우스를 좌우로 튕기면 그쪽에 있는 적으로 바꿉니다. 락온 카메라는 마우스 이동을 시야 입력으로 쓰지 않으므로 다른 조작과 겹치지 않고, 공격·가드 중에도 손가락을 옮기지 않고 바꿀 수 있습니다.
- 락온 대상이 죽으면 락온을 풀지 않고, 락온 키를 다시 누른 것처럼 다음 대상을 고릅니다. 다수전 게임은 이 동작을 기본으로 하거나 옵션으로 둡니다(엘든 링의 자동 락온 옵션, 고스트 오브 요테이의 처치 시 전환). 이 게임에는 설정 화면이 없으므로 이 동작으로 정합니다.

## 2. 플레이 규칙 및 수치

### 대상 전환

| 항목 | 값 |
| - | - |
| 입력 | 락온 중 마우스를 좌우로 튕기기 |
| 튕김 판정 | 최근 실제 시간 0.1초 동안 마우스를 가로로 움직인 양이, 자유 시점이었다면 카메라가 30° 돌아갈 만큼을 넘는 순간 |
| 다음 전환 | 바꾼 뒤 최근 실제 시간 0.1초 동안 바꾼 쪽으로 움직인 양이 자유 시점 기준 5° 아래가 된 뒤(마우스가 거의 멈추거나 반대쪽으로 움직임) |

- 튕긴 쪽(오른쪽 또는 왼쪽)에서 대상을 고릅니다. 마우스의 세로 이동은 보지 않습니다.
- 후보는 '락온'의 락온 대상 조건(락온 타겟팅 범위 안, 화면 안, 생존한 적)을 만족하는 적 가운데 지금 대상을 뺀 적입니다.
- 오른쪽으로 튕기면 화면에서 지금 대상보다 오른쪽에 있는 후보 가운데, 지금 대상과 화면 가로 거리가 가장 가까운 적으로 바꿉니다. 왼쪽도 같습니다.
- 튕긴 쪽에 후보가 없으면 바꾸지 않습니다. 반대쪽 끝의 적으로 넘어가지 않습니다.
- 한 번 튕기면 한 번만 바꿉니다. 바꾼 뒤에는 '다음 전환'이 될 때까지 다시 바꾸지 않으므로, 튕기는 도중 속도가 출렁여도 두 칸을 넘어가지 않습니다. 빠르게 두 칸을 옮기려면 사이에 잠깐 멈춥니다.
- 락온 키와 같이 '상태별 허용 입력' 표의 제한을 받지 않으며, 행동·피격 반응 중에도 바꿉니다.
- 처형 카메라와 궁극기 컷신 동안에는 바꾸지 않습니다. 그동안의 마우스 이동은 지금처럼 무시합니다.
- 바꾸면 카메라는 '락온 카메라'의 '회전'처럼 새 대상 쪽으로 부드럽게 돌아갑니다. 락온 마커와 적 네임플레이트, 공격 방향, 처형 대상의 락온 대상 우선은 새 대상을 따릅니다.

### 대상이 죽었을 때

- 락온 대상이 사망하면 그 순간 락온 키를 다시 누른 것처럼 '락온'의 락온 대상 조건으로 대상을 다시 고릅니다.
- 고를 적이 없으면 락온을 해제합니다.
- 처형 카메라나 궁극기 컷신 중에는 그 연출의 화면이 아니라 게임 카메라의 화면을 기준으로 고릅니다. 처형으로 대상을 처치했을 때 처형 카메라에 다른 적이 보이지 않아도, 락온 카메라 화면에 있던 적으로 옮깁니다. 락온 키를 누른 경우도 같습니다.
- 대상의 캡슐이 플레이어 캡슐 중심에서 반경 30m 밖으로 벗어나면 지금처럼 해제합니다.

### 기존 기획과의 관계

| 문서 | 바뀌는 내용 |
| - | - |
| [카메라와 타겟팅](<../../Docs/Design/System/카메라와 타겟팅.md>) '락온' | 이 명세의 '대상 전환'과 '대상이 죽었을 때'를 더합니다. 락온 해제 조건의 '대상 사망'은 '대상이 사망했는데 다시 고를 적이 없음'으로 바꿉니다. 락온 대상을 고르는 '화면'이 처형 카메라·궁극기 컷신 중에도 게임 카메라의 화면이라는 문장을 더합니다. |
| 카메라와 타겟팅 '카메라 모드' | 락온 카메라의 시야 입력 '무시'에 '마우스 가로 이동은 대상 전환에 씀'을 더합니다. |
| 카메라와 타겟팅 '락온 카메라' '회전' | "락온을 걸 때도"를 "락온을 걸거나 대상을 바꿀 때도"로 바꿉니다. |
| [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>) '공통 입력 처리' | "락온 키는 이 표의 제한을 받지 않으며"에 락온 대상 전환(카메라와 타겟팅의 '락온' 참고)을 함께 적습니다. '키 배치' 표에는 줄을 더하지 않으므로, 이 표를 보여 주는 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '조작 안내'와 조작 안내 팝업은 지금과 같습니다. |
| [ABP와 로코모션](<../../Docs/Art/ABP와 로코모션.md>) '대상 바라보기' | 대상이 바뀌는 경우의 목록에 '락온 대상 전환'을 더합니다. 머리가 새 대상 쪽으로 부드럽게 옮겨 가는 규칙은 그대로입니다. |

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시뮬레이션 룸에서 샌드백을 왼쪽·가운데·오른쪽에 두고 가운데를 락온한 뒤 마우스를 오른쪽으로 튕기면 오른쪽 샌드백으로 바뀌고, 카메라와 락온 마커가 그쪽으로 옮겨 갑니다. 왼쪽으로 튕기면 가운데로 돌아옵니다.
- [ ] 오른쪽 끝의 대상에서 다시 오른쪽으로 튕기면 바뀌지 않습니다.
- [ ] 크게 한 번 튕기면 한 칸만 옮겨 가고, 두 칸을 건너뛰지 않습니다. 튕기는 도중 잠깐 느려졌다가 다시 빨라져도 한 칸입니다.
- [ ] 오른쪽으로 튕긴 뒤 멈추지 않고 바로 왼쪽으로 튕기면 오른쪽으로 바뀌었다가 다시 왼쪽으로 바뀝니다.
- [ ] 마우스를 천천히 가로로 움직이거나 세로로만 움직이면 바뀌지 않습니다.
- [ ] 락온 타겟팅 범위(20m) 밖이나 화면 밖에 있는 적으로는 바뀌지 않습니다.
- [ ] 기본 공격, 가드, 회피, 움찔 중에도 바뀝니다. 기본 공격 중에 바꾸면 다음 타부터 새 대상을 향합니다.
- [ ] 처형 카메라와 궁극기 컷신 중에는 마우스를 튕겨도 바뀌지 않습니다.
- [ ] 락온한 적을 처치하면 화면 중앙에 가장 가까운 다른 적으로 락온이 옮겨 가고, 카메라가 그쪽으로 부드럽게 돌아갑니다.
- [ ] 처형으로 락온한 적을 처치하면, 처형 카메라에 보이지 않던 적이라도 락온 카메라 화면 안에 있던 적으로 옮겨 가고, 처형 카메라가 끝나면 그 적을 향한 락온 카메라로 돌아옵니다.
- [ ] 락온한 적을 처치했을 때 남은 적이 없거나 모두 20m 밖·화면 밖이면 락온이 해제됩니다.
- [ ] 락온한 적이 30m 밖으로 벗어나면 다른 적이 있어도 해제됩니다.
- [ ] 보스 스테이지에서 보스만 상대할 때 락온과 해제가 지금과 같습니다.
