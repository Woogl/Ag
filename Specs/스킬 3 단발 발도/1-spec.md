# 린 스킬 3 단발 발도 Spec

## 1. 개요 및 목적

린의 3번 스킬을 짧은 공격 기회에 큰 HP 대미지를 한 번에 넣는 발도기로 설계합니다. 린은 0.7초 동안 발도 자세를 잡고, 검을 빠르게 한 번 휘두릅니다. 베는 순간 서로 다른 궤적의 검기 세 줄이 동시에 나타납니다.

| 스킬 | 전투에서 맡는 역할 |
| - | - |
| 1 | 위치를 바꿔 적에게 접근합니다. |
| 2 | 적의 동작을 끊고 공중 콤보를 시작합니다. |
| 3 | 발도 준비를 마친 뒤 한 타에 HP 대미지를 집중합니다. |
| 4 | 소용돌이를 설치해 시간차로 여러 타를 넣습니다. 전타 적중 시 네 스킬 중 총 HP 대미지가 가장 큽니다. |

이 Spec은 [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#스킬-3-skill3>)의 장풍 3연발을 단발 발도로 교체하는 변경안입니다.

## 2. 플레이 규칙 및 수치

### 2.1. 발동, 모션, 연출

| 단계 | 동작과 판정 |
| - | - |
| 선딜 | 발동 시점부터 0.7초 동안 그 자리에서 발도 자세를 잡습니다. 이 구간에는 공격 판정이 없습니다. |
| 발도 | 선딜이 끝나면 검을 빠르게 한 번 휘두릅니다. 칼이 전방을 가르는 순간 타격 판정 1회와 검기 세 줄을 동시에 냅니다. |
| 후딜 | 베기 판정이 끝나는 즉시 회복 동작으로 들어갑니다. 후딜에서의 선입력과 모션 캔슬은 [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)의 스킬 공통 규칙을 따릅니다. |

- `3` 키로 발동합니다. 발도 직전까지 공통 공격 방향 규칙에 따라 회전만 보정합니다. 락온이나 적 선택 없이도 정면으로 발동할 수 있습니다. 발도 동작은 제자리에서 마칩니다. [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#공격-방향>)
- 선딜에 피격으로 행동이 중단되면 타격과 검기 연출이 발생하기 전에 스킬이 끝납니다. 스킬 자체의 무적과 슈퍼아머는 없습니다. 발동에 사용한 MP와 쿨다운은 그대로 적용합니다.
- 검기 세 줄은 한 번의 베기를 서로 다른 각도에서 강조하는 VFX입니다. 적중 여부와 관계없이 같은 순간에 나타나고 베기 주변에서 짧게 사라집니다. 세 줄이 겹친 대상에게도 타격은 한 번만 적용합니다.
- 모션 참고는 《Fate/stay night》 5차 어새신의 츠바메가에시와 《엘든 링》 말레니아의 물새난격 마지막 타입니다. 츠바메가에시에서는 세 검기가 한꺼번에 교차하는 구도를, 물새난격에서는 마지막 베기가 순식간에 터지는 속도감을 가져옵니다. 린의 동작은 발도 자세에서 한 번 베고 마무리합니다.

### 2.2. 대미지와 피격

| 항목 | 규칙 |
| - | - |
| 공격 판정 | 린의 전방 근접 범위에 한 번 발생합니다. 범위 안에 있는 대상마다 최대 1타를 적용합니다. |
| HP 배율 | **1.80**. [스킬 4](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#스킬-4-skill4>) 전타 합계 HP 배율 2.0의 90%를 한 타에 적용합니다. |
| PP 배율 | 0. HP 대미지에 집중합니다. |
| 피격 반응 | 없음. 보스는 살아 있는 경우 진행 중인 이동과 공격을 이어갑니다. 넉업 중인 적도 저글로 다시 띄우지 않습니다. |
| 자원 충전 | 발동당 최초 적중에서 UP +5. MP는 충전하지 않습니다. [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#up-충전>) |

- 가드, 패리, 무적, 보너스 대미지, 반올림은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 공통 규칙을 따릅니다. 90%는 보너스와 반올림을 적용하기 전 기본 HP 배율의 비교 기준입니다.
- 일반 적중의 타격감은 발도 VFX와 공통 히트스톱으로 표현합니다. [시간 규칙](<../../Docs/Design/System/시간 규칙.md#히트스톱>)

### 2.3. 초기 밸런스 제안

| 항목 | 초안 |
| - | - |
| MP 소모 | 30 |
| 쿨다운 | 발동 시점부터 6초. 최대 충전 1회 |
| 공격 범위 | 발도 방향 기준 전방 120°, 반경 3m |

## 3. 완료 조건

- [ ] `3` 키로 발동하면 0.7초간 발도 자세를 잡고, 이후 검을 빠르게 한 번 휘두르는 순간 검기 세 줄과 타격 판정이 함께 나온다. 빗나가도 검기 세 줄은 나온다.
- [ ] 한 대상에 검기 세 줄이 겹쳐도 HP 배율 1.80이 한 번만 적용된다. 전방 범위 안의 여러 대상은 각각 한 번 맞으며, 베기 순간 범위 밖에 있던 대상은 잔상에 닿아도 맞지 않는다.
- [ ] 일반 적중 시 대상의 PP가 줄지 않는다. 보스가 이동 중이거나 공격 중일 때 맞고 살아남으면 공통 히트스톱이 끝난 뒤 하던 동작을 이어간다. 공중의 적도 추가로 떠오르지 않는다.
- [ ] 선딜에 린의 행동이 피격으로 끊기면 베기와 검기 없이 종료된다. 발도할 때까지 동작을 마치면 타격 직후 공통 후딜 규칙으로 후속 행동을 이을 수 있다.
- [ ] 한 번 발동한 뒤 쿨다운 중에는 재발동할 수 없고, 여러 대상을 맞혀도 UP는 한 번만 충전된다.
