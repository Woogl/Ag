# 커스터 공격 가독성과 연타 개선 Spec

## 1. 개요 및 목적

커스터의 공격 예고로 공격이 온다는 것은 알 수 있지만, 빠른 모션과 읽기 어려운 찌르기 때문에 실제 동작보다 피격 경험으로 외운 리듬에 의존해 패리하게 된다는 피드백을 반영합니다. 공격 동작을 보고 대응할 여유를 확보하고, 단타 위주의 근접 패턴을 2~3타로 확장하는 것이 목표입니다.

이 문서는 기획 논의를 위한 Spec입니다. 아래의 확정 사항과 미정 사항을 구분하며, 구현·에셋 편집·데이터 변경은 진행하지 않습니다. 미정인 모션과 수치를 확정한 뒤 기술 설계로 넘깁니다.

### 확정 범위

| 패턴 | 현재 | 변경 목표 |
| - | - | - |
| JumpCleave — 뛰어 내려찍기 | 도약 내려찍기 1타 | 도약 내려찍기를 포함한 3타 패턴 |
| Sweep — 휩쓸기 | 휩쓸기 1타 | 휩쓸기 2타 패턴 |
| DashThrust — 돌진 찌르기 | 돌진 찌르기 1타 | 1타 유지 |

- 공격 속도를 낮추고 모션을 읽기 쉽게 한다는 개선 방향을 반영합니다. 패턴별 감속 범위와 수치는 미정입니다.
- DashThrust는 타수 유지만 확정했습니다. 돌진 찌르기 모션을 베기로 교체할지는 확정하지 않았습니다.
- GroundSlam의 연타 전환과 DoubleStrike의 찌르기 대체 모션은 이번에 확정한 변경 범위에 포함하지 않습니다.

### 기존 기획서와의 관계

- 현재 동작의 기준은 [보스 캐릭터 - 커스터](<../../Docs/Design/Content/보스 캐릭터 - 커스터.md>)입니다.
- 이 Spec은 해당 문서의 '모션 템포', 'Sweep', 'JumpCleave'에 대한 변경안을 정의합니다. 기획서 정본은 구현·검증과 결과 확인을 마친 뒤 동기화합니다.
- 별도 변경을 명시하지 않은 페이즈, 발동 가능 거리, 선택 가중치, 쿨다운과 공통 규칙은 기존 기획을 따릅니다.
- 공격 예고는 [적 시스템](<../../Docs/Design/System/적 시스템.md#공격-예고>), 공격 판정·피격·가드·패리는 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)을 따릅니다.

## 2. 플레이 규칙 및 수치

### 2.1. 공격 모션의 가독성과 속도

- 패턴의 시작뿐 아니라 연타의 각 타에서도 준비 동작과 공격으로 전환되는 순간을 볼 수 있어야 합니다.
- 첫 타까지의 준비 시간, 실제로 무기를 휘두르는 속도, 타 사이의 간격을 나누어 조정합니다. 준비 자세를 오래 유지하는 것만으로 속도 개선을 충족한 것으로 보지 않습니다.
- 후속 타는 앞 타가 끝난 자세에서 다음 공격을 준비하는 동작이 보여야 합니다. 후속 타의 준비 동작을 생략해 외운 박자로만 대응하게 만들지 않습니다.
- 공격 판정은 눈에 보이는 무기의 이동과 맞춥니다. 속도나 모션을 바꿨을 때 판정과 예고가 이전 시점에 남아 있지 않아야 합니다.
- 감속 배율, 준비 시간, 타 사이 간격, 마지막 타의 회수 시간은 미정입니다. 전체 모션에 동일한 감속 배율을 적용하는 것으로 확정하지 않습니다.

### 2.2. Sweep — 휩쓸기 2타

**확정 규칙**

- 하나의 패턴 안에서 두 번 공격하는 2타로 변경합니다.
- 두 타 모두 휩쓸기 계열의 동작을 사용해 공격 궤적을 읽을 수 있게 합니다.
- 가드 가능 패턴이라는 기존 성격을 유지하며, 각 타는 기존 공격 예고 규칙을 따릅니다.
- 패턴의 반격 기회는 2타까지 대응한 뒤에 둡니다. 1타 뒤의 연결 동작과 2타 뒤의 종료 동작이 구별되어야 합니다.

**모션 구성안 — 세부 구성 미확정**

| 타 | 구성안 |
| - | - |
| 1 | 앞으로 달려들며 크게 휩쓸기 |
| 2 | 무기를 반대 방향으로 되베기 |

현재 모션에는 첫 휩쓸기 뒤 반대로 한 번 더 휘두르는 동작이 있지만 그 동작에는 공격 판정이 없습니다. 이 동작을 2타로 활용하는 안을 우선 검토합니다. 두 번째 동작의 정면 도달 범위와 준비 시간이 충분한지 확인한 뒤 모션을 확정합니다. 판정만 추가하는 것으로 완료하지 않습니다.

각 타의 대미지, 피격 반응, 시간과 이동·회전 구간은 미정입니다.

### 2.3. JumpCleave — 뛰어 내려찍기 3타

**확정 규칙**

- 하나의 패턴 안에서 세 번 공격하는 3타로 변경합니다.
- 첫 타는 기존 패턴의 성격인 도약 내려찍기로 구성합니다.
- 가드 가능 패턴이라는 기존 성격을 유지하며, 각 타는 기존 공격 예고 규칙을 따릅니다.
- 패턴의 반격 기회는 3타까지 대응한 뒤에 둡니다. 중간 타의 연결 동작과 마지막 타의 종료 동작이 구별되어야 합니다.

**모션 구성안 — 세부 구성 미확정**

| 타 | 구성안 |
| - | - |
| 1 | 도약해 할버드를 내려찍기 |
| 2 | 낮아진 무기를 크게 올려치기 |
| 3 | 크게 휩쓸며 마무리 |

후속 타는 찌르기 대신 무기의 궤적이 드러나는 동작을 후보로 삼습니다. 위 조합은 모션 간 자세 연결과 실제 공격 범위를 확인하기 위한 제안이며, 개별 모션 채택을 확정한 것은 아닙니다.

첫 도약으로 접근한 뒤 후속 타가 어떤 거리까지 닿는지, 각 타에서 얼마나 이동하고 언제 방향을 확정하는지는 미정입니다. 기존 단타의 추적 동작을 후속 타 모두에 그대로 적용하지 않습니다.

각 타의 대미지, 피격 반응과 시간은 미정입니다.

### 2.4. DashThrust — 돌진 찌르기 1타 유지

- 돌진은 단타 패턴으로 유지하며, 돌진 뒤 추가 공격을 연결하지 않습니다.
- 기존 돌진의 이동·유도·정지·판정 규칙을 유지합니다.
- 찌르기 대체 여부가 결정되기 전까지 기존 모션을 변경 대상으로 확정하지 않습니다.
- 공격 모션 감속과 돌진 이동 속도 변경은 별개입니다. 이번 타수 합의만으로 돌진 이동 속도를 변경하지 않습니다.

### 2.5. 연타에 따른 피해와 반격 기회

- 기존 단타의 대미지를 각 타에 그대로 복제하는 것으로 확정하지 않습니다. 각 타의 대미지와 패턴 전체 피해량을 함께 정합니다.
- 기존 Sweep의 넉업과 JumpCleave의 넉다운을 중간 타에 유지할지는 미정입니다. 첫 타에 맞은 뒤 후속 타에 대응할 수 있는지와 연속 피격 결과를 함께 확인해 정합니다.
- 마지막 타까지 방어하거나 피한 뒤 반격할 수 있어야 합니다. 연타 길이가 늘어난 만큼 보스가 공격하는 시간과 플레이어가 반격하는 시간을 함께 확인합니다.
- 타수가 증가하면서 패리 기회도 증가하므로, 연속 패리 시 보스의 그로기 도달이 지나치게 빨라지는지 확인합니다. 공통 패리·PP 규칙의 변경은 이번 확정 범위에 포함하지 않습니다.

### 2.6. 구현 전에 결정할 항목

| 항목 | 결정할 내용 |
| - | - |
| 감속 범위와 수치 | 패턴별 준비·휘두르기·회수 속도, 타 사이 간격, 기존 연타 패턴의 감속 포함 여부 |
| Sweep 모션 | 현재 되베기 동작을 2타로 사용할 수 있는지, 두 타의 최종 모션 구성 |
| JumpCleave 모션 | 올려치기와 휩쓸기를 포함한 3타 구성의 최종 모션 선택 |
| 공격 중 이동·회전 | 후속 타의 이동량, 추적 여부, 방향 확정 시점 |
| 대미지·피격 반응 | 타별 피해량과 반응, 중간 타 피격 뒤 후속 타 대응 가능 여부 |
| 반격 시간 | 마지막 타의 회수 시간, 기존 패턴 후딜레이 유지 여부 |
| 찌르기 교체 범위 | DoubleStrike의 2타와 DashThrust 모션 교체를 이번 작업에 포함할지 |

## 3. 완료 조건 (Acceptance Criteria)

아래는 구현 이후의 검증 기준이며, 이 문서 작성만으로 완료 처리하지 않습니다.

- [ ] 구현 전 미정 항목을 확정하여 본문의 규칙·수치와 모션 구성에 반영했습니다.
- [ ] Sweep은 하나의 패턴에서 구별되는 두 번의 공격 동작과 판정을 수행합니다.
- [ ] JumpCleave는 도약 내려찍기를 시작으로 구별되는 세 번의 공격 동작과 판정을 수행합니다.
- [ ] DashThrust는 기존과 같이 1타이며, 돌진 뒤 후속 공격이 추가되지 않았습니다.
- [ ] Sweep과 JumpCleave의 각 타는 가드 가능하며, 각 판정에 맞춰 기존 규칙대로 예고합니다.
- [ ] 실제 전투 시점에서 첫 타와 후속 타의 준비 동작·공격 전환·무기 궤적을 볼 수 있고, 기획자가 모션을 보고 대응할 여유가 개선되었음을 확인했습니다.
- [ ] 모션과 속도 변경 후에도 보이는 무기의 궤적과 판정 시점이 일치합니다.
- [ ] 중간 타를 가드·패리·회피한 경우 후속 타에 대응할 수 있으며, 중간 타 피격 시의 결과도 확정한 피격 규칙과 일치합니다.
- [ ] 마지막 타의 종료를 동작으로 구별할 수 있고, 전체 패턴에 대응한 뒤 반격 기회가 있습니다.
- [ ] 1·2페이즈에서 변경 패턴의 선택 조건이 유지되며, 연타 증가에 따른 총 피해량과 그로기 빈도를 확인했습니다.
- [ ] 변경 범위 밖 패턴과 공통 전투 규칙이 유지됩니다.
