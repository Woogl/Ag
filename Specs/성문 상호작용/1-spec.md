# 성문 상호작용 작업 명세

## 1. 개요 및 목적

미니던전 요새 돌파의 성문 앞 구간과 보스 아레나 사이를 성문이 막는다. 플레이어는 성문에 다가가 직접 열고 보스 커스터에게 간다. 성문의 위치는 [스테이지 - 미니던전 요새 돌파](<../../Docs/Design/Level/스테이지 - 미니던전 요새 돌파.md>)의 '성문'을 따른다.

- **M3**에서 성문의 닫힘·열림, 상호작용 입력(F), 안내 표시, 열리는 동작을 구현한다. 이 던전에서 플레이어가 상호작용하는 장치는 성문 하나뿐이다.
- 성문은 조건 없이 언제든 열 수 있다. 기획서 '성문'의 여는 조건(성문 앞 적 5명 처치)은 이 명세로 덮어쓴다.
- 상호작용 거리 1m와 열리는 시간 2초는 플레이테스트 초기 제안값이다.

## 2. 플레이 규칙 및 수치

### 성문의 상태

| 항목 | 규칙 |
| - | - |
| 위치와 크기 | 성문 단(높이 6m) 위, 성문 앞 구간 입구 맞은편 벽의 가운데. 폭 약 5m. 레벨에서는 현재 문틀(`FB_Gate_GatePillarS`, `GatePillarN`, `GateLintel`) 사이의 빈 자리에 둔다. |
| 처음 상태 | 닫혀 있다. 닫힌 성문은 플레이어와 적의 이동, 시선, 탄환을 모두 막는다. |
| 여는 조건 | 없다. 성문 앞에 적이 남아 있어도 열 수 있다. |
| 열리는 중 | F를 누르면 성문이 약 2초 동안 위로 올라간다. 다 올라가기 전까지는 이동과 탄환을 계속 막는다. |
| 열린 뒤 | 끝까지 올라간 성문은 이동, 시선, 탄환을 막지 않고, 다시 닫히지 않는다. |
| 재도전 | [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 Restart나 타이틀을 통한 새 도전에서는 닫힌 상태로 다시 시작한다. |

### 여는 입력

| 항목 | 규칙 |
| - | - |
| 입력 키 | F. 처형과 같은 키를 쓴다. [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)의 키 배치에서 F 항목에 상호작용을 추가한다. |
| 입력할 수 있는 때 | 린이 닫힌 성문에서 1m 안에 있을 때. 1m 밖이면 F는 기존 처형 입력으로만 처리한다. |
| 처형과 겹칠 때 | 처형이 우선이다. 성문에서 1m 안에 있어도 처형할 수 있는 적이 있으면 F는 처형으로 처리하고 성문은 열지 않는다. 레벨에서는 성문 가까이에 적을 두지 않아 겹치는 일이 없게 한다. |
| 한 번만 실행 | 성문이 열리기 시작한 뒤의 F 입력은 성문에 쓰지 않는다. 길게 눌러도 한 번만 처리한다. |
| 린의 동작 | 여는 동작(모션)은 없다. F를 누른 뒤에도 린은 평소처럼 움직이고 행동할 수 있다. |

### 플레이어에게 보이는 정보

- 린이 닫힌 성문에서 1m 안에 들어오면 화면 가운데 아래에 'F 성문 열기' 안내를 고정해서 띄운다. 1m 밖으로 나가거나 성문이 열리기 시작하면 바로 지운다.
- 안내의 글꼴과 색은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 스타일'을 따른다.
- 조작 안내 팝업의 F 항목에 상호작용을 추가한다.

## 3. 완료 조건

### M3 · 성문

- [ ] 레벨을 시작하면 성문이 닫혀 있다. 린이 성문을 지나갈 수 없고, 성문 너머의 커스터가 보이지 않는다. 성문 앞 사수가 성문 쪽으로 쏜 탄환은 성문에 막힌다.
- [ ] 성문 앞 적이 모두 살아 있는 상태에서 성문에서 1m 안에 들어온다. 'F 성문 열기'가 뜨고, 1m 밖으로 나가면 사라진다.
- [ ] 안내가 뜬 상태에서 F를 누른다. 안내가 바로 사라지고, 성문이 약 2초 동안 올라간다. 올라가는 도중에는 지나갈 수 없고, 다 올라간 뒤에는 지나가서 통로 너머의 커스터가 보인다.
- [ ] F를 길게 누르거나 여러 번 눌러도 성문은 한 번만 열린다. 열린 성문은 보스 아레나에 들어가도 다시 닫히지 않는다.
- [ ] 성문에서 1m 밖에서는 F가 기존처럼 처형으로만 동작한다.
- [ ] 성문에서 1m 안에 있고 처형할 수 있는 적이 가까이 있을 때 F를 누른다. 처형이 실행되고 성문은 닫힌 채로 남는다. 처형이 끝난 뒤 다시 F를 누르면 성문이 열린다.
- [ ] 성문을 연 뒤 Restart로 다시 시작하면 성문이 닫힌 상태로 돌아온다.
- [ ] 키 배치표와 조작 안내 팝업의 F 항목에 상호작용이 있다.
