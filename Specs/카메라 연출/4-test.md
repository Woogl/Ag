# 카메라 연출 검증 결과

## 1. 테스트 시나리오

- 시나리오 실행 명령: `python -I Scripts/ScenarioTest/run.py <시나리오.py>` (시나리오 파일은 테스트마다 쓰는 임시 파일이라 저장소에 두지 않습니다.)
- 모든 시나리오는 보스 AI를 멈추고 패턴을 직접 실행했습니다. 카메라 값은 플레이어 카메라 매니저의 최종 시점(시야각, 회전, 위치)과 컨트롤 방향을 프레임마다 기록해 판정했습니다.

| 시나리오 | 확인 내용 | 완료 조건 |
| - | - | - |
| 패리 | QuintupleStrike를 예고마다 가드해 패리, 이어서 패리 연출을 0.12초 간격으로 3번 재생 | 1, 2 |
| 극한 회피 | 보스가 화면 안 가운데에서 벗어난 상태에서 DoubleStrike를 극한 회피 | 3 |
| 처형 | 보스를 그로기로 만든 뒤 처형 | 4(회피 반격 제외), 5 |
| 보스 처치 | 카메라를 120° 돌린 채 `AgKillBoss` | 7 |
| 궁극기 처치 | 보스 HP 1에서 궁극기 마무리로 처치 | 7 |
| 포효 | 보스 3m와 30m에서 PhaseTransition | 9 |
| 회귀 | GroundSlam 착지, 보스 처치 연출 재생 직후 궁극기 | 10, 12 |
| 일시정지 | 보스 처치 연출 재생 중 `pause` 두 번 | 11 |

## 2. 결과

- 빌드: `AgEditor Win64 Development` 성공(경고·오류 없음). 에디터를 다시 켠 뒤 로그에 `LogAg` 오류가 없습니다. 지운 셰이크 큐 3개의 태그 경고는 큐를 지우면서 사라졌습니다.
- 판정: 시나리오의 기능 확인 항목이 모두 기대값과 맞았습니다.

| 시나리오 | 측정값 |

- 측정 프레임 간격(약 0.017초) 때문에 슬로우모션 길이가 0.02 ~ 0.04초 짧게 잡힙니다.
- 수정 요청(기울기 제거, 처형 카메라 완화) 뒤 패리와 처형을 다시 실행해 위 값을 얻었습니다(`slot*_20261026-2321*.json`). 화면 밖 공격 연출은 그 뒤 수정 요청으로 삭제해 결과에서 뺐습니다.
- 다시 실행한 것: 시나리오 쪽 문제로 네 번 다시 실행했습니다. 패리는 가드 타이밍 탓에 처음에 패리가 1번만 났습니다. 극한 회피는 그때 있던 화면 밖 공격 회전이 먼저 카메라를 돌려 놓았습니다. 처형은 시야각을 중앙값으로 쟀는데, 모션이 1.8초라 조이는 구간이 대부분이었습니다. 회귀는 궁극기 시간 정지가 컷신 뒤 베기 단계까지 이어지는 것을 판정에 넣지 않았습니다. 극한 회피의 '회피 순간 보스 방향' 항목은 카메라가 플레이어 뒤에서 공전하는 탓에 실패로 남았지만, 컨트롤 방향의 회전량으로 회전을 확인했습니다.
- 보스 처치와 궁극기 처치는 줌인 변경과 슬로우모션 재발동 규칙 변경 뒤 다시 실행했습니다(`slot*_20261026-2355*.json`).
- 로그: `Saved/ScenarioTest/slot*_20261026-2302*.json` ~ `slot*_20261026-2355*.json`

## 3. 회귀 확인

- 확인한 기존 기능과 결과: 패리의 보통 셰이크(`CS_Medium`), 처형의 작음·큼 셰이크, GroundSlam 착지 셰이크(노티파이 교체), 궁극기 컷신·베기·마무리와 그 뒤 게임 카메라, 슬로우모션(극한 회피 0.5초), 기본 공격 콤보·그로기·처형 흐름이 그대로 동작했습니다.

## 4. 테스트 창으로 확인하지 못한 것

테스트 창은 사람의 입력을 받지 않으므로, 아래는 PIE에서 사람이 확인해야 합니다.

- 연출 중 마우스로 시점을 돌릴 수 있는지, 극한 회피의 회전 중 마우스를 움직이면 회전이 멈추는지, 처형 카메라 중 마우스 입력이 무시되는지 (완료 조건 1, 3, 5)
- 락온 중 극한 회피에서 카메라가 돌지 않는지 (완료 조건 3)
- 패리의 타격감과 연속 패리에서 어지럽지 않은지, 처형 카메라의 시네마틱 구도(수평 망원, 줌인, 들어가기 0.8초, 마지막 일격 0.2초 뒤 돌아오기)는 플레이로 판단합니다.
- 벽이 붙은 자리에서 처형하면 왼쪽 구도로 바뀌는지 (완료 조건 6)
- 플레이어가 먼저 사망한 뒤 보스가 사망하면 보스 처치 연출이 없는지 (완료 조건 8)
- 데이터를 바꿨을 때 빌드 없이 반영되는지 (완료 조건 13, 14)
- 회귀: 락온 카메라의 회전과 해제 (락온 중에는 상대 쪽 회전을 하지 않고, 락온을 걸면 진행 중인 회전이 끝남)
