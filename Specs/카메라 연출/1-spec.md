# 카메라 연출 작업 명세 (Spec)

## 1. 개요 및 목적

- 패리, 극한 회피, 회피 반격, 처형, 보스 처치의 순간을 카메라로 강조해 타격감과 '잘했다'는 피드백을 줍니다.
- 보스의 페이즈 전환 포효에 카메라 연출을 넣어 전투의 흐름이 바뀌었음을 알립니다.
- 기획자는 어느 상황이나 모션 시점에 어떤 연출을 쓸지, 그리고 연출의 수치를 코드 수정 없이 데이터로 조정할 수 있어야 합니다. ([마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)의 '카메라 연출 개선')
- 궁극기 컷신은 지금 방식을 그대로 유지합니다.

용어는 [용어집](<../../Docs/용어집.md>)을 따릅니다.

## 2. 플레이 규칙 및 수치

### 2.1 카메라 연출

카메라 연출은 지금 쓰는 카메라(자유 시점, 락온 카메라, '2.4'의 처형 카메라)에 아래 변화를 잠깐 더했다가 되돌립니다. 연출 중에도 시야 입력은 그대로 받습니다.

| 항목 | 내용 |
| - | - |
| 시야각 변화 | 시야각에 더하는 값입니다. 음수면 화면이 좁아져 다가간 것처럼, 양수면 넓어져 물러난 것처럼 보입니다. |
| 시간 | 들어가기 동안 0에서 변화량까지 부드럽게 커지고, 유지 동안 그대로 있다가, 돌아오기 동안 0으로 부드럽게 줄어듭니다. |
| 셰이크 | 연출을 시작할 때 [카메라와 타겟팅](<../../Docs/Design/System/카메라와 타겟팅.md>)의 '셰이크 단계' 가운데 하나를 재생합니다. 셰이크가 없는 연출도 있습니다. |
| 상대 쪽 회전 | 연출을 일으킨 상대가 화면에 들어오도록 카메라를 가로로 돌립니다. ('2.3 상대 쪽 회전' 참고) |

### 2.2 공통 규칙

- 카메라 연출, 상대 쪽 회전, 처형 카메라로 바뀌고 돌아오는 시간은 셰이크와 같이 게임 시간으로 흐릅니다. 슬로우모션 중에는 느려지고, 히트스톱으로는 멈추지 않으며, 일시정지 메뉴가 열려 있는 동안에는 멈춥니다.
- 여러 연출이 겹치면 시야각 변화를 모두 더합니다.
- 같은 연출의 시야각 변화는 서로 더하지 않습니다. 재생 중에 다시 일어나면 그 연출을 다시 재생합니다. 셰이크는 지금처럼 겹쳐서 재생합니다.
- 연출은 일어난 위치에서 멀수록 약해지고, 일정 거리 밖에서는 재생하지 않습니다. 기준 거리는 셰이크와 같습니다. 적의 모션 시점에 붙인 연출은 그 적의 위치에서, 그 밖의 연출은 플레이어 위치에서 일어나므로 늘 제 세기로 재생합니다.
- 궁극기 컷신이 시작되면 진행 중인 카메라 연출과 상대 쪽 회전은 모두 끝납니다.

### 2.3 상대 쪽 회전

| 항목 | 규칙 |
| - | - |
| 상대 | 극한 회피의 공격한 적입니다. |
| 하지 않는 경우 | 락온 중이거나 처형 카메라 중이면 돌지 않습니다. |
| 방향 | 가로로만 돌고, 위아래 각도는 그대로 둡니다. |
| 목표 | 카메라가 보는 방향과 상대의 캡슐 중심 쪽 방향 사이의 가로 각도가 연출마다 정한 각도 이하가 될 때까지 돕니다. 시작할 때 이미 그 각도 안이면 돌지 않습니다. |
| 속도 | 락온 카메라의 '회전'처럼 부드럽게 가속했다가 감속합니다. 따라잡는 시간은 약 0.2초이고, 회전 속도는 초당 최대 360°입니다. |
| 끝 | 목표 각도에 닿거나, 시야 입력이 들어오거나, 락온을 걸면 끝납니다. 시야 입력이 들어오면 그 순간부터 입력을 따릅니다. |

- 상대 쪽 회전은 한 번에 하나만 합니다. 새 회전이 시작되면 진행 중인 회전은 끝납니다. 같은 순간에 여러 회전이 시작되면 플레이어와 가장 가까운 상대 쪽으로 돕니다.

### 2.4 처형 카메라

처형하는 동안 플레이어와 처형 대상을 영화의 한 장면처럼 비추는 카메라입니다. 락온 중에도 처형을 시작하면 처형 카메라로 바뀝니다.

| 항목 | 값 |
| - | - |
| 구도 | 플레이어의 오른쪽 뒤 옆에서 봅니다. 플레이어가 대상을 바라보는 방향에서 오른쪽으로 약 135° 방향, 바라보는 지점에서 수평으로 약 4.8m 떨어진 같은 높이에서 바라보는 지점을 수평으로 봅니다. 플레이어는 화면 왼쪽 앞에, 대상은 화면 오른쪽 안쪽에 보입니다. |
| 바라보는 지점 | 플레이어의 캡슐 중심과, 처형을 시작할 때 대상의 캡슐 중심 사이 가운데에서 위로 약 0.3m. 대상이 걷어차여 밀려나도 따라가지 않습니다. |
| 시야각과 줌인 | 망원 화면인 50°에서 시작해, 처형을 시작한 뒤 1.8초 동안 40°까지 천천히 좁혀 다가가듯 보입니다. 처음에 빠르게 좁히다가 끝에서 느려집니다. |
| 방향 고정 | 구도의 방향은 처형을 시작할 때 플레이어에서 대상 쪽으로 향하는 방향으로 정하고, 처형이 끝날 때까지 바꾸지 않습니다. 위치는 바라보는 지점을 따라 움직입니다. |
| 들어가기 | 처형을 시작하면 0.8초에 걸쳐 게임 카메라에서 처형 카메라로 부드럽게 옮겨 갑니다. |
| 돌아오기 | 마지막 일격이 들어가고 0.2초 뒤(처형을 시작하고 약 1.53초)부터 0.8초에 걸쳐 게임 카메라로 부드럽게 돌아옵니다. 그 전에 처형이 끝나거나 끊기면 그때부터 돌아옵니다. 자유 시점이면 처형 직전의 방향으로, 락온 중이면 락온 카메라의 방향으로 돌아옵니다. |
| 시야 입력 | 들어가기부터 돌아오기가 끝날 때까지 무시합니다. |

- 처형을 시작할 때 오른쪽 구도의 카메라 위치가 바라보는 지점에서 지형에 가려지면, 왼쪽에서 좌우를 뒤집은 구도로 봅니다. 양쪽 모두 가려지면 오른쪽 구도에 '카메라 충돌'을 적용합니다.
- 처형 카메라 중에도 '2.1'의 시야각 변화와 셰이크를 더합니다.

- 가드 브레이크는 '가드로 막음' 대신 적용합니다.
- 회피 반격 적중은 적중할 때마다 재생하며, '2.2'의 같은 연출 규칙에 따라 여러 적을 맞혀도 조임이 더해지지 않습니다. 셰이크는 '플레이어의 공격 적중'의 셰이크를 함께 재생합니다.
- 궁극기 마무리 셰이크는 적중 여부와 관계없이 한 번 재생합니다. 여러 적에게 동시에 적중해도 한 번만 재생합니다.

### 2.6 보스 처치

- 보스의 HP가 0 이하가 되어 사망하는 순간 '보스 처치' 연출과 슬로우모션이 발동합니다. 처형, 궁극기 마무리, 반사된 검기 등 처치한 공격과 관계없이 발동합니다.
- 스테이지 결과가 이미 정해진 뒤의 사망([게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 Boss Stage)에는 발동하지 않습니다.

| 발동 | 속도 | 지속 시간 |
| - | - | - |
| 보스 처치 | 0.3배 | 실제 시간 1.0초 |

- 슬로우모션이 겹칠 때의 규칙은 아래와 같이 바꿉니다. 같은 순간에 여러 슬로우모션이 발동해도(예: 궁극기 마무리로 보스를 처치함) 처리 순서와 관계없이 결과가 같습니다. 그 밖의 중첩은 [시간 규칙](<../../Docs/Design/System/시간 규칙.md>)의 '중첩과 전환'을 따릅니다.

| 시간 규칙의 문장 | 바꾼 문장 |
| - | - |
| '중첩과 전환': 슬로우모션 중에 다시 발동하면 새로 발동한 슬로우모션의 속도와 지속 시간으로 처음부터 다시 셉니다. 배율을 곱하거나 남은 시간에 더하지 않습니다. | 슬로우모션 중에 다시 발동하면, 진행 중인 것과 새로 발동한 것 가운데 더 느린 속도와, 진행 중인 것의 남은 시간과 새 지속 시간 가운데 더 긴 시간으로 이어 갑니다. 같은 순간에 여러 번 발동해도 같습니다. 배율을 곱하거나 남은 시간에 더하지 않습니다. |
| '시간 연출의 영향': 극한 회피 포스트프로세스는 성공 시점의 극한 회피 슬로우모션 지속 시간을 전체 재생 길이로 사용합니다. 이후 슬로우모션의 재발동이나 종료로 그 길이를 바꾸지 않습니다. | 극한 회피 포스트프로세스는 성공 시점에 위 규칙을 적용한 슬로우모션 지속 시간(더 긴 슬로우모션이 진행 중이었다면 그 남은 시간)을 전체 재생 길이로 사용합니다. 이후 슬로우모션의 재발동이나 종료로 그 길이를 바꾸지 않습니다. |

- 지금 값(모두 0.3배, 극한 회피 0.5초·궁극기 마무리 0.8초·보스 처치 1초)으로는 더 긴 슬로우모션 도중에 극한 회피가 일어날 때만 결과가 달라지며, 슬로우모션이 0.5초로 줄지 않고 남은 시간만큼 이어집니다.

### 2.7 데이터로 조정하는 항목

기획자는 아래 항목을 코드 수정과 빌드 없이 데이터에서 바꾸며, 바꾼 값은 다음에 재생하는 연출부터 반영됩니다.

| 대상 | 조정 항목 |
| - | - |
| 연출 | 이름(ID)을 붙여 정의합니다. 시야각 변화, 들어가기·유지·돌아오기 시간 |
| 상황 연결 | '2.5' 표의 각 상황에 재생할 연출과 셰이크(여러 개, 없음 포함), 상대 쪽 회전 여부와 목표 각도 |
| 모션 시점 연결 | 플레이어와 적의 모션에서 원하는 시점에 연출과 셰이크를 붙이고, 멀수록 약해지는 기준 거리를 정합니다. 보스 페이즈 전환 포효의 기합 순간이 이 방법을 씁니다. |
| 처형 카메라 | 구도의 방향 각도, 바라보는 지점과의 수평 거리, 카메라 높이, 바라보는 지점의 높이, 시작·끝 시야각과 줌인 시간, 들어가기·돌아오기 시간, 돌아오기를 시작하는 시각 |
| 시간 연출 | '2.6'의 슬로우모션 속도와 지속 시간 |

- 상황 목록은 '2.5' 표의 상황입니다. 표에 없는 상황을 더하려면 코드를 고쳐야 하며, 모션에 맞춘 연출은 모션 시점 연결로 붙입니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시나리오 1: 패리에 성공하면 화면이 0.05초 만에 살짝 조여 들었다가 히트스톱이 끝날 무렵부터 약 0.25초에 걸쳐 돌아오고, 보통 셰이크가 함께 재생됩니다. 연출 중에도 마우스로 시점을 돌릴 수 있습니다.
- [ ] 시나리오 2: QuintupleStrike를 연속으로 패리해도 화면이 점점 더 조여 들지 않고, 패리할 때마다 같은 세기로 다시 재생됩니다.
- [ ] 시나리오 3: 락온하지 않은 상태에서 극한 회피에 성공하면 슬로우모션 동안 화면이 조여 들고, 공격한 적이 화면 가운데에 오도록 카메라가 가로로 돕니다. 도는 중에 마우스를 움직이면 회전이 멈춥니다. 락온 중에는 돌지 않고 조여 들기만 합니다.
- [ ] 시나리오 4: 회피 반격이 적중하면 화면이 짧게 조여 듭니다. 여러 적에게 적중해도 조임이 더해지지 않습니다.
- [ ] 시나리오 5: 처형을 시작하면 0.8초에 걸쳐 오른쪽 뒤 옆에서 수평으로 보는 망원 구도로 부드럽게 옮겨 가, 플레이어는 화면 왼쪽 앞에, 대상은 오른쪽 안쪽에 보입니다. 처형 동안 시야각이 50°에서 40°로 천천히 좁혀집니다. 처형 중에는 마우스 입력이 무시되고, 찌르기와 마지막 일격에 셰이크와 함께 화면이 살짝 더 조여 들며, 걷어찬 대상을 카메라가 따라가지 않습니다. 마지막 일격이 들어가고 0.2초 뒤부터 0.8초에 걸쳐 처형 직전의 시점(락온 중이면 락온 카메라)으로 돌아옵니다.
- [ ] 시나리오 6: 오른쪽에 벽이 붙은 자리에서 처형하면 왼쪽에서 좌우를 뒤집은 구도로 봅니다.
- [ ] 시나리오 7: 보스를 처치하면 실제 시간 1초 동안 0.3배 슬로우모션과 함께 화면이 천천히 조여 들고(시야각 -12°), 카메라는 돌지 않습니다. 처형의 마지막 일격으로 처치하면 두 연출의 조임이 더해집니다. 궁극기 마무리로 처치해도 슬로우모션은 처리 순서와 관계없이 0.3배, 1초입니다. 보스 처치 슬로우모션 도중에 극한 회피를 해도 슬로우모션이 0.5초로 줄지 않습니다.
- [ ] 시나리오 8: 플레이어가 먼저 사망해 스테이지 결과가 정해진 뒤 보스가 사망하면 보스 처치 연출과 슬로우모션이 발동하지 않습니다.
- [ ] 시나리오 9: 보스가 페이즈 전환 포효에서 기합을 터뜨리는 순간 보통 셰이크와 함께 화면이 살짝 넓어졌다가 돌아옵니다. 보스에게서 멀수록 약하고, 셰이크가 느껴지지 않는 거리에서는 재생하지 않습니다.
- [ ] 시나리오 10: 패리 연출 도중 궁극기를 쓰면 컷신 시작과 함께 연출이 끝나고, 컷신이 끝난 뒤 연출 없는 게임 카메라로 돌아옵니다.
- [ ] 시나리오 11: 극한 회피 연출 도중 일시정지 메뉴를 열면 연출이 멈추고, 메뉴를 닫으면 남은 부분부터 이어집니다.
- [ ] 시나리오 12: 기존 셰이크 상황(공격 적중, 피격, 가드, 가드 브레이크, 처형, 궁극기 마무리, GroundSlam 착지)은 지금과 같은 단계로 재생됩니다.
- [ ] 시나리오 13: 데이터에서 패리 성공 연출의 시야각 변화를 바꾸면 빌드 없이 다음 패리부터 바뀐 값으로 재생됩니다. 새 연출을 정의해 가드 브레이크에 연결하면 가드 브레이크 때 재생되고, 처형 카메라의 구도 값을 바꾸면 다음 처형에 반영됩니다.
- [ ] 시나리오 14: 데이터에서 보스의 한 공격 모션의 원하는 시점에 연출을 붙이면 그 시점에 재생되고, 보스에게서 멀수록 약하게 재생됩니다.
