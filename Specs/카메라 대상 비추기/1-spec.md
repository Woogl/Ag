# 카메라 대상 비추기 Spec

## 1. 개요 및 목적

- 정해진 상황에서 카메라를 정해진 대상 쪽으로 당겨 그 대상을 화면 한가운데 크게 비추고, 끝나면 대상 쪽을 본 게임 카메라로 돌아옵니다. 플레이어와 대상을 함께 보여 주는 락온 카메라와 달리 대상에만 집중하게 합니다.
- 첫 사용처는 보스 페이즈 전환 포효입니다. 플레이어가 어디를 보고 있었든 포효하는 보스를 화면에 담아 페이즈가 바뀌는 순간을 놓치지 않게 하고, 새 페이즈를 보스를 본 채로 시작하게 합니다.
- 포효를 시작할 때 시야각을 좁혀 보스를 크게 보여 강조합니다. 이미 보스를 보고 있거나 락온 중이어서 카메라가 돌 필요가 없을 때도 이 줌인으로 페이즈 전환이 눈에 띕니다.

## 2. 플레이 규칙 및 수치

### 2.1 대상 비추기

[카메라와 타겟팅](<../../Docs/Design/System/카메라와 타겟팅.md>)의 '카메라 연출'에 '대상 비추기' 절을 새로 둡니다.

| 항목 | 규칙 |
| - | - |
| 대상 | 상황마다 정합니다. (2.2 참고) |
| 구도 | 대상의 락온 지점(가슴 높이)을 화면 한가운데 둡니다. 게임 카메라에서 락온 지점을 잇는 선을 따라 카메라를 락온 지점에서 4m 거리까지 당기며, 이미 그보다 가까우면 당기지 않습니다. 플레이어는 화면 아래로 빠집니다. 락온 중에도 이 구도로 바뀝니다. |
| 들어가기 / 돌아오기 | 상황마다 정한 구간이 시작되면 0.5초 동안 부드럽게 이 구도로 옮겨 가고, 구간이 끝나면 0.6초 동안 부드럽게 게임 카메라로 돌아옵니다. |
| 게임 카메라의 방향 | 비추는 동안 락온 중이 아니면 게임 카메라가 '락온 카메라'의 '구도'와 '회전'처럼 대상 쪽으로 돕니다(따라잡는 시간 약 0.2초, 초당 최대 360°). 그래서 돌아온 뒤에는 대상을 본 채로 자유 시점을 이어 가며, 원래 보던 방향으로 돌아가지 않습니다. 락온 중이면 락온 카메라가 그대로 돌며, 락온 대상과 락온 마커는 바뀌지 않습니다. |
| 시야 입력 | 구간이 끝날 때까지 무시하고, 돌아오는 동안부터 받습니다. |
| 하지 않는 경우 | 처형 카메라 중이면 비추지 않습니다. 적의 모션 시점에 일어나므로 '공통 규칙'의 일정 거리 밖에서도 비추지 않습니다. |

- 비추는 도중 락온을 걸면 게임 카메라의 방향은 락온 카메라가 맡고, 당긴 구도는 구간이 끝날 때까지 이어집니다. 락온을 풀면 다시 대상 쪽으로 돕니다.
- 처형 카메라로 바뀌면 돌아오기를 시작하고, 궁극기 컷신이 시작되면 바로 끝납니다.
- 대상이 사라지면 바로 게임 카메라로 돌아옵니다.
- 비추기는 한 번에 하나만 합니다. 새 비추기가 시작되면 진행 중인 비추기는 끝납니다. 같은 순간에 여러 비추기가 시작되면 플레이어와 가장 가까운 대상을 비춥니다.
- 비추는 동안에는 '상대 쪽 회전'을 하지 않으며, 비추기가 시작되면 진행 중인 상대 쪽 회전은 끝납니다.
- 같은 상황의 시야각 변화와 셰이크는 비추는 동안에도 그대로 더합니다.

### 2.2 상황별 대상 비추기

| 상황 | 대상 | 구간 |
| - | - | - |
| 보스 페이즈 전환 포효 | 보스 | 포효 모션의 처음부터 끝까지 (2초) |

- 포효를 시작하자마자 옮겨 가므로, 보스가 등 뒤에 있어도 0.58초의 기합보다 먼저 보스를 거의 가운데에 잡습니다.
- 포효가 끝나면 0.6초 동안 게임 카메라로 돌아오며, 그 뒤 보스의 패턴 후딜레이가 이어집니다.

### 2.3 포효 시작 줌인

[카메라와 타겟팅](<../../Docs/Design/System/카메라와 타겟팅.md>)의 '상황별 연출' 표에 아래 행을 '보스 페이즈 전환 포효' 행 앞에 더합니다. 열은 그 표와 같습니다.

| 상황 | 셰이크 | 시야각 변화 | 시간 | 상대 쪽 회전 목표 | 의도 |
| - | - | - | - | - | - |
| 보스 페이즈 전환 포효 시작 | | -12° | 0.5 / 0.08 / 0.6 | | 포효를 시작하면 보스 쪽으로 돌아가는 동안 화면을 좁혀 보스를 크게 비추어 강조합니다. 0.58초의 기합부터 풀리며 '보스 페이즈 전환 포효'의 넓어지는 화면으로 이어집니다. 보스 위치에서 일어납니다. |

- 두 연출의 시야각 변화는 '공통 규칙'에 따라 더해지므로, 기합 무렵부터 약 0.6초 동안 시야각이 줌인한 78°에서 넓힌 100°까지 넓어집니다.

### 2.4 기존 기획서와의 관계

4단계에서 아래처럼 반영합니다.

- [카메라와 타겟팅](<../../Docs/Design/System/카메라와 타겟팅.md>)
  - '카메라 연출': 표에 '대상 비추기' 행을 더하고, 첫 문단의 "연출 중에도 시야 입력은 그대로 받습니다"에 대상 비추기는 예외임을 적습니다.
  - '공통 규칙': 게임 시간으로 흐르는 항목과 궁극기 컷신이 시작되면 끝나는 항목에 대상 비추기를 더합니다.
  - '상대 쪽 회전': '하지 않는 경우'에 대상 비추기 중을 더합니다.
  - 2.1과 2.2를 '대상 비추기' 절로 옮깁니다.
  - '상황별 연출': 2.3의 '보스 페이즈 전환 포효 시작' 행을 더합니다.
- [보스 캐릭터 - 커스터](<../../Docs/Design/Content/보스 캐릭터 - 커스터.md>)의 '페이즈 전환': 포효하는 동안 카메라가 보스를 비춘다는 문장과 '대상 비추기' 참조를 더합니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 보스를 등지고 자유 시점으로 서 있을 때 보스 HP가 50% 이하가 되면, 포효 시작부터 0.5초 동안 카메라가 보스 쪽으로 당겨져 보스의 락온 지점이 화면 한가운데, 4m 거리에 옵니다.
- [ ] 비추는 동안 마우스를 움직여도 화면이 돌지 않고, 포효가 끝나면 0.6초 동안 보스를 본 게임 카메라로 돌아오며 그때부터 마우스 입력을 따릅니다.
- [ ] 비추는 동안 이동 입력의 방향이 게임 카메라 기준과 같습니다.
- [ ] 보스 4m 안에서 기합에 밀려 넉다운되어도 보스를 계속 가운데에 비춥니다.
- [ ] 보스에 락온한 채로 페이즈 전환이 일어나도 같은 구도로 당겨지고, 락온이 유지됩니다.
- [ ] 비추는 도중 락온 키를 누르면 락온이 걸리고, 당긴 구도는 포효가 끝날 때까지 이어집니다.
- [ ] 포효를 시작하면 0.5초 동안 시야각이 12° 좁아지고, 기합 뒤 넓어지는 화면으로 이어집니다. 보스에 락온한 채로 전환해도 같습니다.
- [ ] 기합의 시야각 변화(+10°)와 셰이크(보통)가 비추기와 함께 재생됩니다.
- [ ] 회귀: 극한 회피의 상대 쪽 회전, 처형 카메라의 들어가기와 돌아오기, 락온 대상 전환이 전과 같이 동작합니다.
