# GroundSlam 충격파 작업 명세 (Spec)

상태: 기획 명세. 구현 전입니다.

## 1. 개요 및 목적

보스 GroundSlam의 착지 판정을 '착지 순간 반경 50m 안의 땅에 있는 대상을 한 번에 맞힘'에서 '착지 지점에서 지면 높이로 퍼져나가는 충격파'로 바꿉니다. 퍼져 오는 충격파를 보고 닿는 순간에 맞춰 뛰어넘거나 회피로 피하는 대응을 만들고, 충격파가 닿지 않는 거리까지 벗어나는 것도 대응이 되게 합니다.

도약, 궤적, 착지 목표, 최대 도약 거리, 가드 불가 예고, 쿨다운과 패턴 선택은 바꾸지 않습니다.

## 2. 플레이 규칙 및 수치

### 2.1 판정

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 착지하며 창끝을 바닥에 꽂아 충격파 발생 | 2.0 | 넉업 | 불가 |

- GroundSlam의 공격 판정은 충격파 하나입니다. 착지 순간 보스 주변을 따로 맞히는 판정은 없습니다.
- 충격파는 착지하는 순간 생깁니다.

### 2.2 충격파

| 항목 | 규칙 |
| - | - |
| 중심 | 착지한 순간 보스의 캡슐 중심의 수평 위치 |
| 높이 | 착지한 보스의 발이 닿은 지면 높이에서 위로 0.1m까지 |
| 퍼지는 모양 | 중심에서 모든 수평 방향으로 같은 속도로 넓어지는 고리 |
| 속도 | 초당 15m |
| 최대 반경 | 15m. 반경이 15m에 도달하면 소멸합니다. |
| 판정 | 넓어지는 고리의 가장자리가 지나가는 동안 그 높이 범위에 캡슐이 닿는 대상. 가장자리가 이미 지나간 안쪽은 판정하지 않습니다. |
| 판정 횟수 | 충격파 하나는 같은 대상을 한 번만 판정합니다. |
| 벽 | 벽(보이지 않는 벽 포함)과 지형에 가로막히지 않으며, 벽 너머의 대상도 반경 안이면 맞습니다. |
| 피격 방향 | 충격파 중심에서 대상의 캡슐 중심을 향하는 수평 방향 |

- 점프 등으로 발이 지면에서 0.1m 넘게 떠 있는 동안 가장자리가 지나가면 맞지 않습니다.
- 충격파는 보스의 상태 변화(사망, 그로기, 페이즈 전환 등)와 관계없이 최대 반경까지 퍼집니다.
- 충격파의 현재 가장자리는 지면에서 밝게 빛나는 띠와 그 위로 옅어지는 낮은 벽으로 보입니다. 가장자리가 지나간 안쪽은 옅은 잔광만 남겨, 맞지 않는 곳임을 구분할 수 있게 합니다. 색은 가드 불가 예고와 같은 붉은 계열입니다.

### 2.3 설계 의도

가드 불가 공격입니다. 도약할 때 가드 불가 예고로 가드 불가임을 알리고, 퍼져 오는 충격파가 닿는 순간에 맞춰 점프로 뛰어넘거나 회피 무적으로 피하게 합니다. 착지 지점에서 15m 밖으로 벗어나도 피할 수 있습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 보스가 착지하는 순간 착지 지점에서 충격파가 생기고, 초당 15m로 넓어져 반경 15m에서 사라진다.
- [ ] 땅에 서 있는 플레이어는 충격파 가장자리가 닿는 순간 HP 배율 2.0, 넉업으로 맞고, 가드 중이어도 막히지 않는다.
- [ ] 가장자리가 지나가는 순간 점프로 0.1m 넘게 떠 있으면 맞지 않는다.
- [ ] 가장자리가 닿는 순간 회피 무적이면 맞지 않고, 극한 회피 구간이면 극한 회피가 발동한다.
- [ ] 착지 지점에서 15m보다 멀리 있는 플레이어는 맞지 않는다.
- [ ] 가장자리가 지나간 뒤 충격파 안쪽으로 들어온 플레이어는 맞지 않는다.
- [ ] 벽 너머에 있어도 반경 안이면 맞는다.
- [ ] 충격파 하나는 플레이어를 한 번만 맞힌다.
- [ ] 충격파가 적중해도 보스는 멈추지 않는다.
- [ ] 궁극기 시간 정지 동안 충격파가 그 자리에서 멈추고, 마무리 순간 이어서 퍼진다.
- [ ] 충격파가 퍼지는 동안 보스가 그로기나 사망이 되어도 충격파는 최대 반경까지 퍼진다.
