# 전투 통계 작업 명세 (Spec)

## 1. 개요 및 목적

- 플레이어가 치른 전투마다 통계를 기록해 파일로 남기고, 시뮬레이션 룸의 전투 결과 UI에도 보여 줍니다.
- 외부 플레이테스트와 밸런싱에서 어느 전투에 몇 번 도전했고, 얼마나 걸렸고, 얼마나 막고 피하고 맞았는지 확인하는 데 씁니다.

## 2. 플레이 규칙 및 수치

### 2.1 기록하는 전투

- 플레이어와 전투 중인 적이 하나도 없다가 생기는 순간 전투 기록을 시작합니다. 보스, 일반 적, 샌드백 모두 셉니다. 적이 전투에 들어가는 규칙은 [적 시스템](<../../Docs/Design/System/적 시스템.md>)을 따릅니다.
- 아래 표의 순간 중 먼저 온 때에 기록을 끝내고 저장합니다.

| 결과 | 기록을 끝내는 순간 |
| - | - |
| 처치 | 스테이지 결과가 Stage Clear로 정해진 순간. 전투 중인 다른 적이 남아 있어도 끝냅니다. |
| 처치 | 전투 중인 적이 하나도 남지 않은 순간, 이 전투에서 상대한 적이 모두 사망했으면 처치입니다. |
| 사망 | 전투 중인 적이 하나도 남지 않은 순간, 플레이어가 사망해 있으면 사망입니다. 플레이어가 사망하면 적은 모두 대기에 들어가 전투에서 빠집니다. |
| 이탈 | 전투 중인 적이 하나도 남지 않은 순간, 위의 두 경우가 아니면 이탈입니다. (시야에서 놓친 적이 비전투로 돌아가 전투가 끝난 경우) |

- 스테이지 결과가 정해진 뒤에는 새 전투 기록을 시작하지 않습니다.
- 기록 중에 Restart, Return to Title, Quit로 레벨을 떠나거나 게임이 꺼지면 그 전투는 저장하지 않습니다.

### 2.2 기록 항목

| 항목 | 기록 내용 |
| - | - |
| 레벨 | 전투한 레벨의 이름 (예: LV_SimulationRoom) |
| 끝난 시각 | 기록을 끝낸 날짜와 시각. 게임을 실행한 컴퓨터의 시각을 따릅니다. |
| 도전 횟수 | 아래 '2.3 도전 횟수' |
| 결과 | 처치, 사망, 이탈 ('2.1 기록하는 전투') |
| 상대한 적 | 기록하는 동안 한 번이라도 플레이어와 전투에 들어간 적마다 종류와 배치 좌표를 적습니다. 처음 전투에 들어간 순서이며, 같은 적이 비전투로 돌아갔다가 다시 들어와도 한 번만 적습니다. |
| 전투 시간 | 기록을 시작한 순간부터 끝낸 순간까지의 실제 시간을 초 단위로 밀리초(소수점 아래 세 자리)까지 적습니다. (예: 48.312) 일시정지 메뉴가 열려 있던 동안은 세지 않습니다. 슬로우모션과 궁극기 시간 정지 동안은 셉니다. |
| 패리 성공 | 패리가 성공한 횟수. 투사체 패리도 셉니다. |
| 회피 성공 | 극한 회피가 발동한 횟수. 회피 한 번에 최대 한 번입니다. ([플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>)의 '극한 회피') |
| 피격 횟수 | 플레이어가 공격에 맞아 피격으로 처리된 횟수. 한 공격이 여러 번 맞히면 맞힌 만큼 셉니다. 가드로 막은 공격(가드 브레이크 포함), 패리, 극한 회피, 무적으로 받지 않은 공격, 낙하 대미지는 세지 않습니다. 플레이어를 쓰러뜨린 공격도 셉니다. |

- 적의 종류는 캐릭터 데이터의 ID입니다. (예: Boss, Cutter, Gunner, Sandbag, AttackSandbag)
- 배치 좌표는 그 적이 레벨에 처음 놓인 자리의 레벨 좌표로, 언리얼 에디터의 위치 값과 같은 단위(cm)의 정수입니다. 시뮬레이션 룸에서는 배치 자리에 놓인 위치입니다.
- 패리 성공, 회피 성공, 피격 횟수는 기록하는 동안 일어난 것만 셉니다.

### 2.3 도전 횟수

- 스테이지 선택 화면에서 스테이지에 들어오면 1입니다. 시뮬레이션 룸은 적 선택 화면의 Start로 배치해 시작할 때 1입니다.
- 같은 스테이지를 Restart로 다시 시작할 때마다 1을 더합니다. 전투 결과 UI와 일시정지 메뉴의 Restart를 모두 셉니다.
- Return to Title로 타이틀에 돌아가거나 게임을 끄면, 다음에 스테이지에 들어올 때 다시 1부터 셉니다.
- 같은 도전에서 끝난 전투 기록에는 모두 같은 도전 횟수를 적습니다.

### 2.4 저장

- 게임을 실행한 뒤 처음으로 전투 기록을 끝낼 때 저장 경로의 `CombatStats` 폴더에 파일 하나를 만듭니다. 파일 이름은 게임을 실행한 날짜와 시각입니다. (예: `2026-11-23_14-00-12.json`)
- 그 뒤로 전투 기록을 끝낼 때마다 같은 파일에 끝난 순서대로 덧붙여 바로 저장합니다. 게임이 비정상 종료되어도 그전에 끝난 기록은 파일에 남습니다.
- 게임을 다시 실행하면 새 파일을 만듭니다. 이전 파일은 지우지 않습니다.
- 저장 경로는 엔진의 Saved 폴더입니다. 에디터에서는 프로젝트의 `Saved`, Development 패키지는 패키지 폴더의 `Ag/Saved`, Shipping 패키지는 `%LOCALAPPDATA%/Ag/Saved`입니다.
- 파일은 사람이 읽을 수 있는 JSON 텍스트입니다. 결과는 처치 `Victory`, 사망 `Death`, 이탈 `Disengage`로 적습니다. 아래 예의 값은 형식을 보이기 위한 것입니다.

```json
{
	"Records": [
		{
			"Level": "LV_SimulationRoom",
			"EndedAt": "2026-11-23 14:05:33",
			"Attempt": 2,
			"Result": "Victory",
			"Duration": 48.312,
			"Enemies": [
				{ "Id": "Boss", "Location": { "X": 800, "Y": -274, "Z": 98 } },
				{ "Id": "Cutter", "Location": { "X": 655, "Y": 459, "Z": 98 } },
				{ "Id": "Cutter", "Location": { "X": 800, "Y": 274, "Z": 98 } }
			],
			"ParryCount": 3,
			"PerfectDodgeCount": 1,
			"HitCount": 5
		}
	]
}
```

### 2.5 시뮬레이션 룸 전투 결과 UI

LV_SimulationRoom의 Stage Clear UI와 Game Over UI에 그 결과로 끝난 전투 기록을 보여 줍니다. 다른 스테이지의 전투 결과 UI에는 보여 주지 않습니다. 그 밖의 표시와 조작은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'Stage Clear UI / Game Over UI'를 따릅니다.

- 제목과 버튼 사이 가운데에 통계 표를 놓습니다. 한 줄에 항목 이름과 값을 하나씩, 위에서부터 아래 순서로 표시합니다. 글자는 Medium입니다.

| 항목 이름 | 값 |
| - | - |
| 도전 횟수 | 숫자 (예: 2) |
| 전투 시간 | '분:초.밀리초', 초는 두 자리, 밀리초는 세 자리 (예: 0:48.312, 12:05.040) |
| 상대한 적 | 적의 이름을 처음 전투에 들어간 순서로 쉼표로 이어 적습니다. 같은 이름이 둘 이상이면 처음 나온 자리에 '× 수'를 붙여 한 번만 적습니다. (예: 커스터, 절단자 × 2). 이름은 각 캐릭터 문서를 따릅니다. |
| 패리 성공 | 숫자 |
| 회피 성공 | 숫자 |
| 피격 횟수 | 숫자 |

- 배치 좌표와 결과, 끝난 시각은 표시하지 않습니다. 파일에만 남깁니다.
- 통계 표는 전투 결과 UI와 함께 서서히 나타납니다.
- 스테이지 결과가 정해질 때 기록 중인 전투가 없었으면 통계 표를 표시하지 않습니다.

### 2.6 기존 기획서와의 관계

- 신규 규칙입니다. 검증 뒤 '2.1'~'2.4'는 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)에 '전투 통계' 절로, '2.5'는 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'Stage Clear UI / Game Over UI'에 반영합니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시뮬레이션 룸에서 배치한 적을 모두 처치하면 `Victory` 기록이 하나 저장되고, 상대한 적의 ID와 배치 좌표가 배치 자리와 같습니다. Stage Clear UI에 같은 값의 통계 표가 나타납니다.
- [ ] 플레이어가 사망하면 `Death` 기록이 저장되고, 쓰러뜨린 공격까지 피격 횟수에 들어갑니다. Game Over UI에 통계 표가 나타납니다.
- [ ] 사망 뒤 Restart로 다시 싸우면 다음 기록의 도전 횟수가 2이고, 일시정지 메뉴의 Restart로 다시 시작해도 1을 더합니다. 타이틀로 나갔다 다시 들어오면 1입니다.
- [ ] 던전에서 보스를 처치하면 남은 적이 있어도 그 순간 `Victory` 기록이 저장됩니다. 다른 스테이지의 전투 결과 UI에는 통계 표가 없습니다.
- [ ] 적이 플레이어를 놓쳐 비전투로 돌아가 전투가 끝나면 `Disengage` 기록이 저장됩니다.
- [ ] 패리, 극한 회피, 피격이 일어난 만큼 셉니다. 가드로 막은 공격과 낙하 대미지는 피격 횟수에 들어가지 않습니다.
- [ ] 전투 중 일시정지 메뉴를 열어 둔 시간은 전투 시간에 들어가지 않습니다.
- [ ] 전투 도중 Restart나 Return to Title로 나가면 그 전투는 저장되지 않습니다.
- [ ] 한 번 실행하는 동안의 기록은 한 파일에 쌓이고, 게임을 다시 실행하면 새 파일이 생깁니다.
