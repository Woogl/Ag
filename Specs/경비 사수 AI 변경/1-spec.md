# 경비 사수 AI 변경 작업 명세 (Spec)

상태: 기획 확정 전. 구현·플레이 검증 전입니다.

## 1. 개요 및 목적

경비 사수가 플레이어를 더 멀리서 발견하고 더 멀리서 쏘게 합니다. 가까이 붙은 플레이어와는 거리를 벌리고, 곧게 달리기만 하는 플레이어는 맞힙니다. 탄환은 대미지를 주면 사라져 다음 대상을 뚫고 가지 않습니다.

- 예측 조준은 적이 쏘는 모든 투사체(경비 사수의 탄환, 보스 SwordWave의 검기)에 적용합니다.
- 패턴 후딜레이 동안의 움직임과 낭떠러지 규칙은 모든 적에게 같은 규칙을 씁니다. 적마다 다른 값만 각 적 문서에서 정합니다. 특정 적에게만 적용하는 예외 규칙은 두지 않습니다.

### 바뀌지 않는 것

- 사격 패턴은 지금처럼 조준·발사·반동·재장전을 한 모션으로 이어 재생하는 패턴 하나입니다. 재장전이 끝나야 패턴 후딜레이로 넘어갑니다. 구간 길이, 쿨다운 6초, 패턴 후딜레이 2.0~4.0초 무작위는 그대로입니다.
- 움찔이 끝나면 바로 다음 패턴을 고르고, 후보가 없으면 다가가는 [적 시스템](<../../Docs/Design/System/적 시스템.md>)의 공통 전환은 그대로입니다.

## 2. 플레이 규칙 및 수치

### 2.1 경비 사수의 시야와 사거리

| 항목 | 현재 | 변경 |
| - | - | - |
| 시야 거리 | 20m | 30m |
| 정면 각도 | 120° (좌우 60°씩) | 180° (좌우 90°씩) |
| 기본 사격 발동 가능 거리 | 캡슐 중심 사이 수평 거리 0~20m | 0~30m |
| 탄환 최대 이동 거리 | 발사점부터 30m | 발사점부터 100m |

- 시야 판정 방식(고저차를 포함한 캡슐 중심 사이 거리, 지형 가림)은 그대로입니다.

### 2.2 패턴 후딜레이 동안의 움직임 (모든 적)

패턴 후딜레이 동안 적은 플레이어를 바라보며 아래 표처럼 움직입니다. 대기 시간은 지금처럼 각 적 문서의 '패턴 후딜레이'를 따릅니다.

| 조건 | 움직임 |
| - | - |
| 플레이어가 '물러나는 거리' 안에 있음 (캡슐 중심 사이 수평 거리 미만) | 플레이어를 바라본 채 플레이어 반대쪽으로 MOV 속도로 걷습니다. |
| 그 밖 | 각 적의 '후딜레이 이동'에 따라 좌우로 걷거나 제자리에 서 있습니다. |

- 후딜레이 동안 거리를 계속 확인하고, 거리가 바뀌면 움직임도 바꿉니다.
- 뒤가 벽이면 더 물러나지 못합니다. 벽에 비스듬히 닿으면 벽을 따라 미끄러질 수 있습니다. 낭떠러지에서는 2.5를 따릅니다.
- MOV가 0인 적은 지금처럼 그 자리에 서 있습니다.
- 전투 진입 직후, 넉업·넉다운 뒤, 그로기·처형 피격 뒤, 조준 취소 뒤처럼 패턴 후딜레이를 거치는 모든 경우에 같은 규칙을 씁니다.

| 적 | 후딜레이 이동 | 물러나는 거리 |
| - | - | - |
| 커스터 | 좌우 걷기 | 없음 |
| 절단자 | 좌우 걷기 | 없음 |
| 경비 사수 | 제자리 | 8m |
| 샌드백·공격 샌드백 | 좌우 걷기 (MOV 0이라 서 있음) | 없음 |

경비 사수는 이렇게 움직입니다.

- 8m 이상이면 사격한 뒤 2~4초 동안 제자리에서 플레이어를 바라보며 기다리고, 다시 사격합니다.
- 8m 안이면 사격한 뒤 2~4초 동안 뒤로 걷습니다. MOV 2m/s라 최대 약 8m 물러납니다.

### 2.3 투사체 예측 조준 (모든 적)

적이 쏘는 투사체는 발사하는 순간에 방향을 정합니다. 대상의 지금 위치가 아니라, 대상이 지금 수평 속도로 계속 움직인다고 볼 때 투사체가 대상에 닿을 위치(예측 지점)를 향해 쏩니다.

- 예측 지점 = 발사 순간 대상의 캡슐 중심 + 대상의 수평 이동 속도 × 비행 시간입니다.
  - 비행 시간은 발사 위치에서 예측 지점까지 투사체가 날아가는 시간입니다.
- 위아래 움직임은 예측하지 않습니다. 앞서 겨누는 거리에 상한은 없습니다.
- 발사한 뒤에 방향을 바꾸거나 멈추면 빗나갑니다. 서 있는 대상에게는 지금처럼 캡슐 중심을 겨눕니다.
- 쏘는 적의 몸은 지금처럼 대상의 현재 위치를 바라봅니다. 그래서 옆으로 움직이는 대상을 쏠 때는 몸 방향과 투사체 방향이 벌어집니다. 옆으로 달리는 플레이어라면 탄환은 약 17°, 검기는 약 24°입니다.
- 패리로 반사한 투사체는 예측하지 않고, 지금처럼 쏜 적의 현재 위치를 향합니다.
- 보스의 GroundSlam 충격파는 겨누는 공격이 아니라서 해당하지 않습니다.

| 투사체 | 몸 방향 | 날아가는 방향 |
| - | - | - |
| 경비 사수의 탄환 | 조준 시작부터 발사 순간까지 플레이어를 바라봅니다. 발사부터 반동이 끝날 때까지는 돌지 않습니다. | 발사 순간 총구에서 예측 지점으로 직진 |
| SwordWave의 검기 (1~3타) | 지금처럼 각 타에서 플레이어를 바라보다가 정해진 시점에 회전을 멈춥니다. | 발사 순간 보스의 캡슐 중심 높이에서 예측 지점 쪽으로 수평 직진 |

- 예: 경비 사수에게서 15m 떨어진 플레이어가 옆으로 초당 6m로 달리면, 사수는 약 4.7m 앞(약 17°)으로 쏩니다.
- 경비 사수의 조준과 취소:
  - 조준하는 동안 발사 순간까지 세 가지를 계속 확인합니다. 플레이어가 시야 안에 있는지, 총구에서 플레이어의 캡슐 중심까지 벽·지형이 가리지 않는지, 사수의 몸에서 총구까지 벽·지형이 가리지 않는지입니다. 하나라도 어긋나면 지금처럼 조준·예고·발사를 취소합니다.
  - 발사 0.35초 전의 조준점 고정은 없어집니다. 예측 지점이 벽 뒤에 있어도 취소하지 않고 쏘며, 탄환은 벽에 닿아 사라집니다.

### 2.4 경비 사수의 탄환이 사라지는 조건

| 닿았을 때의 결과 | 탄환 |
| - | - |
| 적중, 가드, 가드 브레이크 | 그 자리에서 사라집니다. 뒤에 있는 다른 대상은 맞지 않습니다. |
| 패리 | 지금처럼 반사합니다. 반사된 탄환도 처음으로 적중하거나 가드된 대상에서 사라집니다. |
| 극한 회피, 무적 | 피격 처리가 없으므로 그대로 지나갑니다. |

- 보스의 검기는 지금처럼 대상을 뚫고 지나갑니다.

### 2.5 낭떠러지 (모든 적)

- 적은 걷기, 공격 중 이동, 넉다운으로 낭떠러지를 넘어가지 않고 가장자리에서 멈춥니다. 가장자리를 따라 옆으로 미끄러질 수 있습니다.
  - 낭떠러지는 계단처럼 걸어서 내려설 수 있는 단차보다 높은 곳입니다.
- 넉업처럼 공중에 띄워진 적은 그대로 떨어질 수 있습니다.
- 플레이어는 지금과 같습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 1. 시야: 경비 사수가 정면 180° 안 30m 이내의 플레이어를 보면 전투에 들어갑니다. 30m 밖이나 등 뒤의 플레이어는 발견하지 못합니다.
- [ ] 2. 사거리: 수평 25m에 있는 플레이어에게 다가가지 않고 사격합니다. 30m 밖이면 다가갑니다.
- [ ] 3. 탄환 거리: 빗나간 탄환이 30m를 넘어 날아가고, 100m에서 사라집니다.
- [ ] 4. 후딜레이 움직임
  - 8m 이상이면 경비 사수가 제자리에 서 있고, 8m 안이면 플레이어를 바라본 채 뒤로 걷습니다.
  - 후딜레이 중 거리가 바뀌면 움직임도 바뀝니다.
  - 등 뒤가 벽이면 더 물러나지 못하고, 낭떠러지면 가장자리에서 멈춥니다.
  - 절단자와 커스터는 지금처럼 좌우로 걷습니다.
- [ ] 5. 예측 조준 (경비 사수)
  - 옆으로 곧게 달리는 플레이어에게 탄환이 맞습니다.
  - 발사 직후 반대로 달리거나 멈추면 빗나갑니다.
  - 서 있는 플레이어에게는 지금처럼 맞습니다.
  - 발사 순간까지 몸이 플레이어를 바라봅니다.
- [ ] 6. 예측 조준 (SwordWave): 옆으로 곧게 달리는 플레이어에게 검기가 맞고, 검기는 수평으로 날아갑니다.
- [ ] 7. 탄환 소멸
  - 플레이어에게 적중하거나 가드된 탄환은 그 자리에서 사라져, 같은 줄 뒤의 샌드백이 맞지 않습니다.
  - 패리로 반사된 탄환은 사수에게 맞은 뒤 사라집니다.
  - 극한 회피하면 탄환이 지나갑니다.
- [ ] 8. 낭떠러지: 경비 사수가 뒤로 걷다가, 절단자가 다가가거나 공격하며 움직이다가, 넉다운으로 밀려나다가 낭떠러지 가장자리에서 멈춥니다. 넉업으로 띄운 적은 떨어질 수 있습니다.
- [ ] 9. 회귀: 조준 취소(시야 상실·총구 가림·몸에서 총구까지 가림), 반사 탄환의 대미지와 PP 감소, 검기 관통과 반사, 절단자·커스터의 패턴과 후딜레이가 지금과 같습니다.
