# 세이브&로드 Spec

## 1. 개요 및 목적

- 게임을 끄고 다시 켜도, 던전에서 사망해도 진행이 이어지게 합니다.
- 방식은 엘든링을 따릅니다. 수동 저장 없이 자동으로 저장하고, 타이틀 화면에서 Continue, Load Game, New Game으로 저장 슬롯을 고르며, 사망하면 버튼을 누르지 않아도 마지막으로 휴식한 체크포인트에서 다시 시작합니다.
- 엘든링과 달리 저장 슬롯은 6개이고, 플레이어의 위치와 적의 상태는 저장하지 않습니다. 이어 하는 자리는 언제나 마지막으로 휴식한 체크포인트이며, 슬롯을 불러오면 스테이지 선택 화면으로 들어갑니다.

## 2. 플레이 규칙 및 수치

### 2.1 저장 슬롯

저장 슬롯은 6개이고, 슬롯 하나가 게임 하나의 진행입니다. 슬롯끼리는 서로 영향을 주지 않습니다.

| 저장하는 것 | 내용 |
| - | - |
| 보유 아이템 | 아이템마다의 보유 수 |
| 던전 진행 | 던전마다 마지막으로 휴식한 체크포인트와 연 성문 |
| 마지막 스테이지 | 스테이지 선택 화면의 Start로 마지막에 들어간 스테이지 |
| 플레이 시간 | 이 슬롯으로 플레이한 시간의 합 |
| 저장한 시각 | 마지막으로 저장한 날짜와 시각. 게임을 실행한 컴퓨터의 시각을 따릅니다. |

- 플레이 시간은 슬롯을 만들거나 불러온 순간부터 타이틀 화면으로 돌아가거나 게임을 끌 때까지의 실제 시간입니다. 스테이지 선택 화면과 일시정지 메뉴가 떠 있는 동안도 셉니다.
- Settings의 내용은 슬롯에 저장하지 않으며, 슬롯을 바꾸거나 지워도 그대로입니다.

### 2.2 저장하는 순간

수동 저장은 없습니다. 아래 순간마다 지금 슬롯에 바로 저장합니다.

| 순간 | 저장으로 남는 것 |
| - | - |
| 아이템의 보유 수가 바뀜 | 바뀐 보유 수 |
| 체크포인트에서 휴식 | 그 던전의 마지막으로 휴식한 체크포인트 |
| 성문을 엶 | 그 던전의 연 성문 |
| 스테이지 선택 화면에서 Start | 마지막 스테이지 |
| 던전의 결과가 Stage Clear로 정해짐 | 그 던전의 던전 진행을 지움 |
| Return to Title, Quit, 스테이지 선택 화면의 Back | 플레이 시간 |

- 저장할 때마다 플레이 시간과 저장한 시각도 함께 저장합니다.
- 저장하는 동안 화면에 따로 표시하는 것은 없습니다.

### 2.3 타이틀 화면

Play 버튼을 없애고, Continue, New Game, Load Game, Settings, Quit 버튼을 위에서부터 세로로 배치합니다.

| 버튼 | 실행 결과 |
| - | - |
| Continue | 저장한 시각이 가장 늦은 슬롯을 불러와 스테이지 선택 화면을 엽니다. |
| New Game | 빈 슬롯 중 번호가 가장 작은 슬롯에 새 게임을 만들어 저장하고 스테이지 선택 화면을 엽니다. |
| Load Game | Load Game 화면을 엽니다. |

- 저장된 슬롯이 하나도 없으면 Continue와 Load Game 버튼을, 빈 슬롯이 없으면 New Game 버튼을 표시하지 않습니다. 남은 버튼은 빈자리 없이 위에서부터 채워 놓습니다.
- 처음 선택된 버튼은 표시된 버튼 중 맨 위의 버튼입니다.
- 새 게임은 아이템마다 시작 보유 수를 가지고, 던전 진행과 마지막 스테이지가 없으며, 플레이 시간은 0입니다.

![타이틀 화면](<타이틀 화면.svg>)

### 2.4 Load Game 화면

타이틀 화면의 Load Game 버튼으로 여는 화면입니다.

- UI 스타일의 '메뉴 화면'을 따르며, 제목은 'Load Game'입니다. 페이드 없이 바로 표시하고, 표시하는 즉시 입력을 받습니다.
- 슬롯 줄 6개를 슬롯 번호순으로 위에서부터 세로로 놓고, 마지막 줄 아래 가운데에 Back 버튼을 놓습니다.
- 슬롯 줄은 너비 720px, 높이 96px이고, 줄 사이는 24px입니다. 저장된 슬롯의 줄은 버튼입니다.
- 저장된 슬롯의 줄 오른쪽 24px에 너비 168px, 높이 96px의 Delete 버튼을 둡니다. 슬롯 줄과 Delete 버튼을 한 묶음으로 보고 화면 가운데에 놓으며, 빈 슬롯의 줄도 같은 자리에 맞춥니다.
- 빈 슬롯의 줄은 슬롯 이름과 'Empty'만 흐리게 적은 줄입니다. 버튼이 아니어서 실행하거나 선택할 수 없고, Delete 버튼이 없습니다.
- 처음 선택된 것은 저장한 시각이 가장 늦은 슬롯의 줄입니다.

| 슬롯 줄에 표시하는 것 | 자리 | 내용 |
| - | - | - |
| 슬롯 이름 | 왼쪽 | 'Slot 1' ~ 'Slot 6' (글자 Large) |
| 마지막 스테이지 | 슬롯 이름 오른쪽 | 스테이지 선택 화면의 표시 이름 (글자 Medium). 마지막 스테이지가 없으면 표시하지 않습니다. |
| 플레이 시간 | 오른쪽 위 | '시:분:초', 분과 초는 두 자리 (예: 1:05:32) (글자 Medium) |
| 저장한 시각 | 오른쪽 아래 | '연-월-일 시:분' (예: 2026-11-27 21:04) (글자 Medium) |

| 조작 | 실행 결과 |
| - | - |
| 저장된 슬롯의 줄 실행 | 그 슬롯을 불러와 스테이지 선택 화면을 엽니다. |
| Delete | 삭제 확인 창을 엽니다. |
| Back, 또는 Esc | 화면을 닫고 타이틀 화면으로 돌아갑니다. 타이틀 화면에서는 Load Game 버튼이 선택됩니다. Load Game 버튼이 표시되지 않으면 맨 위의 버튼이 선택됩니다. |

![Load Game 화면](<Load Game 화면.svg>)

**삭제 확인 창**

- Load Game 화면 위에 화면 전체를 어둡게 덮고, 화면 가운데에 창을 표시합니다. 창이 떠 있는 동안 뒤의 화면은 입력을 받지 않습니다.
- 창에는 문구 '이 저장 데이터를 삭제하시겠습니까?'(글자 Medium)와 그 아래 Yes, No 버튼을 가로로 놓습니다. 문구에는 지울 슬롯의 이름을 함께 적습니다. (예: Slot 2)
- 처음 선택된 버튼은 No입니다.

| 조작 | 실행 결과 |
| - | - |
| Yes | 그 슬롯의 저장을 지우고 창을 닫습니다. 지운 저장은 되돌릴 수 없습니다. 그 슬롯의 줄은 빈 슬롯의 줄로 바뀌고, 남은 저장된 슬롯 중 저장한 시각이 가장 늦은 줄이 선택됩니다. 저장된 슬롯이 남아 있지 않으면 Back 버튼이 선택됩니다. |
| No, 또는 Esc | 창을 닫습니다. 지우려던 슬롯의 줄이 선택됩니다. |

![삭제 확인 창](<삭제 확인 창.svg>)

### 2.5 스테이지 선택 화면

- 화면을 열 때 지금 슬롯의 마지막 스테이지가 골라져 있습니다. 마지막 스테이지가 없거나 목록에 없으면 목록의 첫 스테이지가 골라져 있습니다.
- Back은 스테이지 선택 화면을 연 화면(타이틀 화면, 또는 Load Game 화면)으로 돌아갑니다. 돌아간 화면에서는 스테이지 선택 화면을 열 때 실행한 버튼이나 슬롯 줄이 선택되고, 그 버튼이 표시되지 않으면 맨 위의 버튼이 선택됩니다.

### 2.6 던전을 시작하는 자리

던전 레벨을 열 때마다 아래 자리에서 시작합니다. 스테이지 선택 화면의 Start로 들어올 때와 '2.7'의 다시 시작이 모두 같습니다.

| 그 던전의 던전 진행 | 시작하는 자리 |
| - | - |
| 휴식한 체크포인트가 있음 | 마지막으로 휴식한 체크포인트의 정면 1.5m 바닥에서 체크포인트를 바라보고 섭니다. |
| 휴식한 체크포인트가 없음 | 던전의 시작 지점 |

- 레벨을 여는 흐름과 로딩 화면은 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Dungeon'과 같고, 플레이어와 적은 레벨을 처음 열었을 때의 상태입니다.
- 연 성문은 처음부터 열려 있습니다. 여는 움직임은 재생하지 않습니다.
- 체크포인트는 정면 1.5m 자리가 비어 있고 바닥이 있게 놓습니다.

모든 스테이지에 공통으로, 레벨을 열 때마다 휴식으로 채우는 아이템(회복병)을 최대 보유 수까지 채웁니다. 나머지 아이템의 보유 수는 슬롯에 저장된 그대로입니다.

### 2.7 체크포인트에서 다시 시작

던전에서 플레이어가 사망하면 Game Over UI 대신 아래 순서로 다시 시작합니다.

1. 스테이지 결과 연출을 재생합니다. ([전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '스테이지 결과 연출')
2. 연출이 끝나면 0.5초 동안 화면을 서서히 어둡게 하면서 GAME OVER 제목 문구를 서서히 표시합니다. 문구의 모양과 자리는 Game Over UI의 제목과 같고, 버튼은 없습니다.
3. 표시가 끝나고 1.5초 뒤에 지금 던전 레벨을 다시 열어 '2.6'의 자리에서 시작합니다.

- GAME OVER 문구가 떠 있는 동안에는 입력을 받지 않고 Esc를 무시합니다.
- 1.5초의 시간 기준은 전투 결과 UI의 페이드와 같습니다.

- 던전의 일시정지 메뉴에는 Restart 버튼이 없습니다. System 탭에 Resume, Return to Title, Quit 버튼을 위에서부터 빈자리 없이 놓습니다.
- 던전의 Stage Clear UI의 Restart는 던전 진행이 지워졌으므로 던전의 시작 지점에서 시작합니다.
- 시뮬레이션 룸의 Game Over UI와 일시정지 메뉴의 Restart 버튼은 바뀌지 않습니다.

### 2.8 예외 처리

- 읽을 수 없는 저장은 Load Game 화면에 슬롯 이름과 'Corrupted'만 적은 줄로 표시합니다. 이 줄은 버튼이 아니어서 실행하거나 선택할 수 없고, 오른쪽의 Delete 버튼으로 지울 수만 있습니다. Continue가 고르는 슬롯에서 빼며, 빈 슬롯으로도 저장된 슬롯으로도 세지 않습니다. 다만 읽을 수 없는 저장만 있어도 타이틀 화면의 Load Game 버튼은 표시합니다.
- 저장에 있는데 지금 게임에 없는 것은 버립니다. 없는 아이템의 보유 수는 버리고, 최대 보유 수를 넘는 보유 수는 최대 보유 수로 줄입니다. 휴식한 체크포인트가 레벨에 없으면 던전의 시작 지점에서 시작하고, 연 성문이 레벨에 없으면 무시합니다.
- 에디터에서 타이틀 화면을 거치지 않고 스테이지 레벨을 바로 플레이하면 슬롯 없이 진행합니다. 아이템은 시작 보유 수로 시작하고 아무것도 저장하지 않으며, 그 밖의 규칙('2.6', '2.7')은 그 플레이 안에서 같습니다.

### 2.9 저장 파일

- 저장 경로의 `SaveGames` 폴더에 슬롯마다 파일 하나(`Slot1.sav` ~ `Slot6.sav`)를 둡니다. 저장 경로는 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 '전투 통계'의 '저장'과 같습니다.

### 2.10 기존 기획서와의 관계

| 문서 | 바뀌는 곳 |
| - | - |
| [게임 플로우](<../../Docs/Design/System/게임 플로우.md>) | 저장 절을 새로 둡니다('2.1', '2.2', '2.8', '2.9'). 'Front End'의 Play를 Continue, New Game, Load Game으로 바꾸고('2.3'), '스테이지 선택'의 Back과 처음 골라진 스테이지('2.5'), '스테이지 공통'의 다시 시작 문장, '일시정지'의 버튼 문장과 'Dungeon'의 시작 지점·Restart('2.6', '2.7'), 'Game Over'(던전은 '2.7', Game Over UI는 시뮬레이션 룸만), 플로우 차트를 고칩니다. |
| [아이템 시스템](<../../Docs/Design/System/아이템 시스템.md>) | '공통'의 시작: 스테이지에 들어갈 때마다 시작 보유 수로 돌아가는 규칙을 없애고, 새 게임의 시작 보유 수('2.3')와 레벨을 열 때 채우는 규칙('2.6')으로 바꿉니다. |
| [UI 시스템](<../../Docs/Design/System/UI 시스템.md>) | '타이틀 화면'('2.3'), '스테이지 선택 화면'('2.5'), '일시정지 메뉴'의 System 탭('2.7'), 'Stage Clear UI / Game Over UI'('2.7'), 'UI 조작'을 고치고, Load Game 화면과 삭제 확인 창('2.4')을 새로 둡니다. '메뉴 화면' 양식을 쓰는 화면에 Load Game 화면을 더합니다. |
| [전투 시스템](<../../Docs/Design/System/전투 시스템.md>) | '스테이지 결과 연출'의 연출이 끝난 뒤 문장 |
| [용어집](<../../Docs/용어집.md>) | 저장 슬롯(Save Slot), 던전 진행을 더합니다. |

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 저장이 없는 상태로 게임을 켜면 타이틀 화면에 New Game, Settings, Quit 버튼만 위에서부터 빈자리 없이 나오고, New Game이 선택되어 있다.
- [ ] New Game을 실행하면 Slot 1에 저장이 생기고 스테이지 선택 화면이 열린다. 타이틀로 돌아오면 버튼이 Continue, New Game, Load Game, Settings, Quit 순서로 나온다.
- [ ] 슬롯 6개가 모두 차면 타이틀 화면에 New Game 버튼이 나오지 않는다.
- [ ] 던전에서 체크포인트에 휴식하고 게임을 끈 뒤 다시 켜 Continue → Start로 들어가면, 그 체크포인트 정면에서 체크포인트를 바라보고 시작하고 스테이지 선택 화면에는 그 던전이 골라져 있다.
- [ ] 성문을 열고 게임을 끈 뒤 다시 들어가면 성문이 처음부터 열려 있다.
- [ ] 휴식한 적 없는 던전에서 사망하면 GAME OVER 문구 뒤에 버튼 없이 던전의 시작 지점에서 다시 시작한다.
- [ ] 체크포인트에서 휴식한 뒤 사망하면 그 체크포인트에서 다시 시작하고, 적은 모두 처음 상태이며 회복병은 최대 보유 수다.
- [ ] 던전에서 일시정지 메뉴를 열면 System 탭에 Resume, Return to Title, Quit 버튼만 위에서부터 빈자리 없이 나온다. 시뮬레이션 룸에서는 Restart를 포함한 네 버튼이 나온다.
- [ ] GAME OVER 문구가 떠 있는 동안 Esc와 조작 입력이 듣지 않는다.
- [ ] 던전을 클리어한 뒤 Stage Clear UI의 Restart로, 또는 타이틀을 거쳐 다시 들어가면 던전의 시작 지점에서 시작하고 성문이 닫혀 있다.
- [ ] 시뮬레이션 룸에서 사망하면 지금처럼 Game Over UI가 뜨고 Restart가 같은 구성으로 다시 시작한다.
- [ ] 치트로 아이템 보유 수를 바꾸고 게임을 껐다 켜면 바뀐 보유 수가 남아 있다. 회복병을 쓰고 타이틀로 나갔다가 스테이지에 들어가면 회복병이 최대 보유 수다.
- [ ] Load Game 화면에 슬롯 줄 6개가 번호순으로 나온다. 저장된 슬롯의 줄에는 마지막 스테이지, 플레이 시간, 저장한 시각이 표시되고, 빈 슬롯의 줄은 'Empty'로 흐리게 나오며 선택되지 않는다. 저장된 슬롯의 줄을 실행하면 그 슬롯의 진행으로 스테이지 선택 화면이 열린다.
- [ ] 두 슬롯의 진행(휴식한 체크포인트, 보유 수)이 서로 섞이지 않는다.
- [ ] Delete → No(또는 Esc)는 저장을 그대로 두고, Yes는 그 슬롯의 줄을 빈 슬롯의 줄로 바꾼다. 게임을 껐다 켜도 지운 슬롯은 비어 있다. 마지막 슬롯까지 지우고 Back으로 나가면 타이틀 화면에 New Game, Settings, Quit만 나온다.
- [ ] 저장 파일을 망가뜨리면 그 슬롯이 'Corrupted' 줄로 표시되고, 선택되지 않으며 Delete로 지울 수 있다.
- [ ] Settings에서 바꾼 언어와 화면 설정은 슬롯을 바꾸거나 지워도 그대로다.
- [ ] 에디터에서 던전 레벨을 바로 플레이하면 저장 파일이 생기거나 바뀌지 않고, 휴식한 뒤 사망하면 그 체크포인트에서 다시 시작한다.
