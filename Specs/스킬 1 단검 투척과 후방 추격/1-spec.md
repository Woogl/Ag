# 스킬 1 단검 투척과 후방 추격 Spec

## 1. 개요 및 목적

린의 1번 스킬을 단검의 실제 명중으로 접근 기회를 얻는 기술로 바꿉니다. 나나야 시키의 ‘극사 나나야’를 동작의 참고로 삼아, 단검을 던지고 맞힌 적의 등 뒤로 이동해 한 번 벱니다. 15m 사거리와 직선 궤적으로 접근을 제한하고, 빗나가면 투척 동작만 마친 뒤 후딜로 넘어갑니다.

이 Spec은 [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#스킬-1-skill1>)의 ‘스킬 1’ 변경안입니다. 피해 배율과 자원의 비교 기준은 [현재 어빌리티 데이터](<../../DesignData/Abilities.json>)의 `Skill1`입니다. 아래 투척 속도, 피해 배분, 조준·후방 이동·무적·예외 판정은 검토용 초안입니다.

## 2. 플레이 규칙 및 수치

### 2.1. 발동과 단검 투척

| 항목 | 값 |
| - | - |
| 입력 | `1` 키 |
| MP 소모 | 20 |
| 쿨다운 | 6초 |
| 최대 사거리 | 단검이 손을 떠난 지점부터 실제 비행 거리 15m |
| 비행 속도 | 초당 40m. 최대 사거리까지 약 0.375초 |
| 궤적 | 투척 순간에 정한 방향으로 직진. 유도와 낙하 없음 |

- 스킬 발동 시 MP를 차감하고 쿨다운을 시작합니다. 대상을 잡지 못한 상태에서도 투척할 수 있으며, 빗나가거나 도중에 끊겨도 MP와 쿨다운을 돌려주지 않습니다.
- 투척할 때 락온 중이면 락온 대상의 현재 몸통을 향합니다. 락온 중이 아니면 15m 이내의 지형에 가려지지 않은 가장 가까운 적의 현재 몸통을 향하고, 조준할 적이 없으면 린의 정면으로 수평하게 던집니다. 락온 대상까지의 거리는 조준 방향에만 영향을 주며, 단검의 사거리는 항상 15m입니다. 투척 준비와 비행 중에는 적에게 다가가는 위치 보정을 적용하지 않습니다.
- 단검은 벽이나 비행 경로에서 처음 만난 판정 가능한 적에 닿으면 멈춥니다. 락온 대상 앞을 다른 적이 막고 있으면 앞의 적을 판정합니다. 단검은 적을 관통하지 않으며, 경로가 비어 있으면 15m에서 소멸합니다. 샌드백도 적으로 판정합니다.
- 단검을 놓으면 충돌하거나 최대 사거리에 닿을 때까지 결과를 기다립니다. 단검이 빗나가거나 지형에 막히면 투척 후딜만 재생합니다. 후방 이동과 후속 베기는 단검에 일반 피격 판정을 받은 살아 있는 적이 있을 때만 한 번 자동으로 시도합니다. 적중으로 베기까지 이어지면 베기 판정이 끝날 때 후딜을 시작합니다. 후딜 중 선입력과 모션 캔슬은 [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)의 스킬 공통 규칙을 따릅니다.

### 2.2. 후방 이동과 베기

- 순간이동 직전에 단검에 맞은 적의 현재 위치와 바라보는 방향을 확인합니다. 두 캐릭터의 중심 사이 수평 거리가 3m인 정후방 바닥에 나타나 그 적을 바라보며 한 번 벱니다. 정후방이 막혀 있으면 같은 거리의 등 뒤 좌우 45° 안에서 정후방과 가장 가까운 안전한 자리를 사용합니다. 안전한 자리는 적 아래 바닥과 거의 같은 높이에 서 있을 수 있고, 지형이나 다른 캐릭터와 겹치지 않으며, 도착 지점과 적 사이를 지형이 가로막지 않는 곳입니다. 적이 공중에 있으면 적 아래 바닥 높이를 기준으로 삼습니다.
- 후방에 안전한 자리가 없거나 단검으로 적을 처치하면 단검 타격으로 끝납니다. 가드·패리·무적이 단검을 막으면 공통 피격 결과만 적용합니다. 단검을 던진 뒤 린이 피격으로 행동이 중단되거나 사망하면 날아가는 단검은 유지하되 후속 동작은 취소합니다.
- 스킬 자체의 무적은 순간이동으로 사라져 나타나는 구간에만 적용합니다. 투척 준비, 비행 대기, 베기 및 후딜에는 스킬 무적이 없습니다.
- 후속 베기는 단검에 맞은 적 한 명에게만 판정합니다. 베기 판정이 닿는 시점에 대미지와 백어택을 판정합니다. 대상이 이동해 베기를 벗어나거나 돌아서면 베기가 빗나가거나 백어택이 성립하지 않을 수 있습니다.

### 2.3. 대미지와 자원 충전

| 타격 | HP 배율 | PP 배율 | 피격 반응 |
| - | - | - | - |
| 단검 1타 | 0.30 | 0.30 | 별도 피격 모션 없음 |
| 후속 베기 1타 | 1.20 | 1.20 | 움찔. 공중의 적은 공통 저글 규칙 적용 |
| 두 타의 기본 배율 합계 | **1.50** | **1.50** | |

- 두 타 모두 가드할 수 있습니다. [전투 시스템](<../../Docs/Design/System/전투 시스템.md#대미지>)에 따라 타격마다 대미지와 보너스를 계산하고 반올림합니다. 기존 1번 스킬과 같은 값은 두 타의 기본 배율 합계이며, 백어택·그로기 등의 성립 시점과 타격별 반올림에 따라 실제 HP·PP 감소량은 달라질 수 있습니다.
- 일반 피격을 일으킨 단검 적중으로 UP를 15 충전합니다. 후속 베기에서 UP를 추가로 충전하지 않으며, 두 타 모두 MP를 충전하지 않습니다. [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#up-충전>)

## 3. 완료 조건

- [ ] 사거리 안의 적에게 단검을 맞히면 그 적의 정후방으로 이동해 한 번 벤다. 적이 처음부터 등을 보이는 경우에도 적의 등 방향을 기준으로 도착한다.
- [ ] 적이 없는 곳에 쓰거나 적이 궤적에서 벗어나면 투척 후딜만 재생한다. MP 20이 줄고 발동 시점부터 6초 동안 재사용할 수 없다.
- [ ] 비행 경로에서 15m 이내에 처음 닿는 적은 맞고, 첫 접촉 지점이 15m를 넘는 적은 락온 중에도 맞지 않는다. 벽에 먼저 닿으면 벽 뒤의 적에게 도달하지 않는다.
- [ ] 락온 대상 앞의 다른 적에게 단검이 먼저 맞으면 그 적이 후방 이동과 베기의 대상이 된다. 한 번의 투척으로 후방 이동은 최대 한 번 발생한다.
- [ ] 정후방이 막히면 등 뒤 90° 안의 안전한 자리로 이동한다. 안전한 자리가 없거나 단검이 대상의 가드·패리·무적에 막히거나 대상을 처치하면 이동과 후속 베기가 발생하지 않는다.
- [ ] 두 타가 일반 피격으로 들어가면 기본 HP·PP 배율은 각각 0.30과 1.20으로 합계 1.50이며, 단검 적중에서 UP 15가 한 번만 충전된다. 베기 전에 대상이 린 쪽을 돌아보면 베기에 백어택 보너스가 붙지 않는다.
- [ ] 투척 후 비행 중 린이 피격으로 행동이 끊기면 단검은 계속 날아가지만 명중해도 린이 순간이동하거나 베지 않는다.
