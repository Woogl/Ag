# 적 네임플레이트 작업 명세 (Spec)

## 1. 개요 및 목적

일반 적과 보스의 상태 표시는 스텔라 블레이드의 화면 배치·외형·표시 방식을 기준으로 합니다. PP는 사용자 지정에 따라 HP와 같은 노란색 격자로 표시하며, 일반 적·샌드백은 1줄, 보스는 2줄로 구성합니다. 자원은 AG의 HP·PP를 유지하며, 실드를 추가하지 않습니다.

- 일반 적은 머리 위에 작게 표시하고, 보스는 화면 위쪽 가운데에 고정합니다.
- 일반 적과 보스의 HP는 흰색 작은 사각형이 모인 격자, PP는 노란색 작은 사각형이 모인 격자로 표현합니다. PP는 일반 적·샌드백 1줄, 보스 2줄입니다.
- 일반 적과 샌드백의 표시를 추가하고, 기존 보스 상태 표시를 변경합니다.
- 이번 작업은 기획 초안입니다. 아래에서 **관찰**은 참고 화면에서 확인한 사실, **확정 방향**은 사용자가 선택한 범위, **제안**은 AG에 적용하기 위해 작성한 규칙입니다. 제안 수치와 동적 표시 조건은 원작에서 측정한 값이 아닙니다.

용어는 [용어집](<../../Docs/용어집.md>), 현재 개발 범위는 [마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)를 따릅니다. 일반 적·샌드백 외에 보스 표시 변경은 이번 요청에 포함합니다.

### 2.2 구성과 배치 — 제안

기준 해상도와 해상도별 배율은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '화면 기준'을 따릅니다. 아래 크기는 1920 × 1080 기준의 초안 값이며 원작 실측값이 아닙니다.

| 항목 | 일반 적·샌드백 | 보스 |
| - | - | - |
| 이름 | 없음 | HP 위 가운데, 글자 Small. 이름 양옆에 2 × 2 사각형 장식 |
| HP 격자 | 가로 20칸 × 세로 2칸, 사각형 4px, 간격 2px. 전체 118 × 10px | 가로 94칸 × 세로 3칸, 사각형 5px, 간격 2px. 전체 656 × 19px |
| PP 줄 | HP 아래 6px, HP 왼쪽에 정렬 | HP 아래 6px, HP 왼쪽에 정렬 |
| PP 격자 | 가로 20칸 × 세로 1칸, 사각형 4px, 간격 2px. 전체 118 × 4px | 가로 94칸 × 세로 2칸, 사각형 5px, 간격 2px. 전체 656 × 12px |
| 위치 기준 | 현재 자세의 머리 위에 PP 줄의 아래쪽이 오도록 배치. 머리와의 화면상 여백 16px | 이름 영역 위쪽을 화면 상단 32px에 두고, HP 격자의 위쪽은 60px. 가로 가운데 정렬 |
| 거리 변화 | 화면상 크기를 유지하며 적 위치만 따라감 | 카메라·보스 위치와 관계없이 고정 |
| 머리 위 중복 표시 | 해당 없음 | 표시하지 않음 |

- 보스의 32px 상단 여백은 원작과 비슷한 상단 배치를 위한 제안이며, 기존 공통 여백 48px에 대한 이 요소의 예외입니다.
- 보스 이름 Small은 기존 Large에서 변경하는 제안입니다. 한 줄 가운데 정렬을 유지하며, 실제 콘텐츠 이름으로 잘림 여부를 확인합니다.
- 일반 적 표시의 위치는 점프·넉업·넉다운에도 적을 따라갑니다. 락온 마커는 기존 락온 지점에 따로 표시합니다.
- PP가 없는 대상 또는 그로기 면역 대상은 PP 줄을 숨기고 HP만 표시합니다. 샌드백은 샌드백 기획에서 정한 자원·면역 상태를 따릅니다.

### 2.3 HP 표시 — 제안

- 채움 비율은 현재 HP / 최대 HP입니다. 0 아래는 빈 상태, 최대값 위는 가득 찬 상태로 표시합니다.
- 세로의 여러 격자 줄은 하나의 HP를 나타냅니다. 모든 줄의 같은 가로 위치가 함께 줄어들며, 줄마다 별도 체력을 갖지 않습니다.
- 왼쪽부터 현재 HP 비율만큼 흰색으로 채웁니다. 감소할 때 오른쪽 끝부터 줄고, 빈 영역에는 어두운 격자가 남습니다. 마지막 열은 남은 비율만큼 부분적으로 채웁니다.
- HP 격자 수는 최대 HP와 무관하게 유형별 고정입니다. 사각형 한 개가 HP 1이나 공격 1회를 뜻하지 않습니다.
- 감소 잔상의 대기·감소 시간과 연속 피격 시 갱신은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '플레이어 상태'에 정의된 HP 감소 잔상을 재사용합니다. 격자 사이 틈을 채우지 않고 격자 안에만 잔상을 표시합니다. 이는 원작 시간 재현을 확인하기 전의 제안입니다.
- 회복은 현재 수치를 바로 반영합니다. 회복으로 현재 HP보다 낮아진 감소 잔상은 제거합니다.
- 사망으로 숨겨지거나 표시 조건을 잃으면 잔상도 함께 숨깁니다. 다시 표시될 때 지난 피격 연출을 재생하지 않고 최신 수치로 시작합니다.
- 페이즈 경계선, 레벨, 속성, 상태이상 아이콘은 표시하지 않습니다.

### 2.4 PP 표시

**PP는 HP와 같은 노란색 사각형 격자로 표시하며, 일반 적·샌드백은 1줄, 보스는 2줄입니다. 형태·색·유형별 줄 수는 확정 방향이며, 세부 치수와 아래 상태별 표시는 제안입니다.**

- 일반 적·샌드백과 보스 모두 HP와 가로 너비·칸 크기·간격·가로 칸 수를 맞춥니다. 세로 줄 수와 치수는 2.2를 따릅니다.
- 보스의 두 줄은 하나의 PP를 나타냅니다. 두 줄의 같은 가로 위치를 함께 채우고 비우며, 한 줄이 먼저 소진된 뒤 다른 줄이 줄어드는 방식은 사용하지 않습니다.
- 현재 PP / 최대 PP의 비율만큼 왼쪽부터 노란색으로 채우고, 감소할 때 오른쪽 끝부터 비웁니다. 빈 영역에는 어두운 격자가 남고, 마지막 열은 남은 비율만큼 부분적으로 채웁니다.
- PP 100%·50%·45%는 각 줄에서 전체 너비의 100%·50%·45%를 채웁니다. 0 아래는 빈 상태, 최대값 위는 가득 찬 상태로 표시합니다. 최대 PP가 0이면 PP 줄을 표시하지 않습니다.
- 공격·패리·리젠·페이즈 전환으로 변하는 PP를 그대로 표시합니다. 사각형 한 개가 PP 1이나 패리 1회를 뜻하지 않습니다.
- PP 감소 잔상은 두지 않고 현재 채움량을 즉시 반영합니다. 기존 보스 PP 바의 감소 잔상 규칙은 이 제안으로 대체합니다.
- 그로기 진입 시 PP 격자를 모두 비웁니다. 그로기 동안 빈 상태를 유지하며, 기존 AG의 'PP 바를 다시 채워 그로기 남은 시간 표시'는 제거하는 안입니다. 그로기 남은 시간을 위한 별도 요소도 추가하지 않습니다.
- 공중 그로기와 처형 피격 중에도 PP 격자는 빈 상태를 유지합니다. 처형 가능 여부는 기존 처형 안내로 전달합니다.
- 그로기 종료 또는 처형 피격 종료·중단 후에는 실제 PP로 표시합니다. PP 회복·면역·사망 판정은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)을 따릅니다.

### 2.5 일반 적·샌드백 표시 조건 — 제안

다음은 원작 동작 대조 전의 검토안입니다.

1. 살아 있고, 머리 위 표시 기준점이 화면 안에 있으며, 카메라에서 대상의 몸 중심으로 향하는 시야가 벽·지형에 막히지 않아야 합니다. 다른 캐릭터가 잠깐 앞을 지나가는 것은 숨김 조건으로 삼지 않습니다.
2. 위 조건에서 **플레이어와 전투 중**, **현재 락온 대상**, **최근 3초 안에 HP 또는 PP 감소** 가운데 하나를 만족하면 표시합니다. 샌드백도 같은 조건을 사용하되 전투 상태 진입을 요구하지 않습니다.
3. 별도 거리 제한은 두지 않습니다. 화면·가림·전투 등의 조건으로 표시 여부를 정합니다. 원작 표시 거리는 확인 후 조정할 항목입니다.
4. 조건을 만족하는 적은 락온 대상 외에도 함께 표시합니다. 여러 적의 HP·PP를 합치거나 다른 적의 정보로 교체하지 않습니다.
5. 비전투로 돌아가도 락온 또는 최근 감소 조건이 남아 있으면 계속 표시합니다. 모든 표시 조건을 잃으면 숨깁니다.
6. 사망·제거·화면 밖·벽 뒤에서는 즉시 숨깁니다. 화면 가장자리로 옮겨 붙이거나 화살표로 대체하지 않습니다.
7. 표시가 겹치면 락온 대상이 가장 앞에, 나머지는 카메라와 가까운 대상이 앞에 보입니다. 위치를 임의로 흩뜨리지 않습니다.
8. 표시·숨김에는 초안에서 페이드를 넣지 않습니다. 최근 감소 3초는 게임 시간으로 세며 일시정지 중에는 멈춥니다.

### 2.6 보스 표시 조건 — 제안

- 보스가 플레이어와 전투에 들어가면 이름·HP·PP를 함께 표시합니다. 락온 여부와 무관합니다.
- 전투 중 보스가 화면 밖으로 나가거나 벽 뒤로 가도 고정 상태 표시를 유지합니다.
- 보스와 일반 적이 함께 있어도 일반 적의 머리 위 표시를 유지합니다. 락온을 일반 적에게 옮겨도 상단 상태 표시의 대상은 보스입니다.
- 페이즈 전환 때 표시를 유지하며, HP·PP는 실제 값만 반영합니다. 바를 임의로 초기화하거나 페이즈 구간을 미리 알리지 않습니다.
- 보스 사망·제거·전투 종료 시 숨깁니다. 같은 프레임에 사망과 PP 소진이 발생하면 사망에 따른 숨김을 우선합니다.
- 새 레벨·다시 시작·새 보스 전투에서는 이전 보스의 이름·수치·감소 잔상을 남기지 않습니다.

### 2.7 공통 상황과 표시 우선순위 — 제안

| 상황 | 일반 적·샌드백 | 보스 |
| - | - | - |
| 일반 전투·페이즈 전환 | 각 표시 조건 적용 | 전투 중 표시 |
| 처형 | 대상이 살아 있고 표시 조건을 만족하면 HP·빈 PP 표시 | HP·빈 PP 표시 |
| 궁극기 컷신 | 숨김 | 숨김 |
| 일시정지 | 메뉴 직전의 표시와 감소 잔상을 멈춘 상태로 유지 | 동일 |
| 플레이어 사망·스테이지 결과 연출·전투 결과 UI | 숨김 | 숨김 |
| 레벨 전환·다시 시작 | 기존 대상의 표시 제거 | 동일 |

- 컷신 등으로 숨겼다가 돌아오면 최신 상태로 다시 판단하며, 숨겨진 동안의 피해 연출을 몰아서 재생하지 않습니다.
- 일반 적·샌드백 표시는 캐릭터를 따라가는 다른 표시와 같이 HUD·Menu·Modal보다 아래에 놓습니다. 보스 상태는 HUD에 놓습니다.
- 처형 안내와 락온 마커의 조건은 기존 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)을 따릅니다. 머리 위 표시가 처형 안내와 겹치면 처형 안내를 네임플레이트 위에 12px 간격으로 놓습니다.
- 일시정지 외 시간 연출에 따른 감소 잔상과 최근 감소 후 표시 유지 시간의 진행은 [시간 규칙](<../../Docs/Design/System/시간 규칙.md>)을 따릅니다.

### 2.8 원작 대조가 필요한 항목

원작을 따르는 항목은 아래를 같은 HUD 설정의 플레이 영상이나 직접 플레이로 확인해야 합니다. 확인되지 않은 항목을 원작 규칙으로 간주하지 않습니다. PP의 노란색 격자와 유형별 줄 수는 사용자 지정이므로 원작 동일성 대조에서 제외합니다.

| 항목 | 확인할 장면 | 초안의 처리 |
| - | - | - |
| 일반 적 표시 진입·해제 | 비전투 접근 → 락온 → 락온 해제 → 피격 → 전투 이탈 | 2.5의 조건을 제안으로 작성 |
| 표시 거리·가림·화면 경계 | 거리 변화, 벽 뒤 이동, 큰 적을 근거리에서 락온 | 별도 거리 제한 없음, 가림·화면 밖 숨김 제안 |
| 다수 적 표시와 겹침 | 둘 이상과 전투하며 락온 전환 | 조건을 만족하는 적을 함께 표시하는 안 |
| 피해 잔상·표시 페이드 | 단타, 연타, 회복, 처치 장면 | 기존 AG HP 잔상 재사용, PP 잔상·페이드 없음 제안 |
| 정확한 크기·색·서체·장식 | HUD 설정을 고정한 원본 해상도 화면 | 2.2는 초안 수치. 첨부 그림은 비교용 |
| PP 및 그로기 표현 | 밸런스 소진 → 처형 가능 → 회복 | PP의 노란색 격자와 일반 적·샌드백 1줄·보스 2줄 구성은 확정 방향. AG 수치 매핑과 기존 그로기 타이머 제거는 별도 제안 |

## 3. 완료 조건 (Acceptance Criteria)

아래는 초안 규칙을 채택했을 때의 확인 조건이며 아직 구현·검증하지 않았습니다. 원작 동일성 확인은 2.8의 대조를 추가로 요구합니다.

- [ ] 일반 적은 이름 없이 머리 위에, 보스는 이름과 함께 화면 상단 가운데에 표시된다. 보스 머리 위에는 중복 표시가 없다.
- [ ] 실드 줄이 없고, HP 아래에 같은 너비·칸 크기·간격의 노란색 PP 격자가 왼쪽 정렬로 표시된다. 일반 적·샌드백은 1줄, 보스는 2줄이다.
- [ ] HP 격자는 하나의 체력 비율을 나타내며, 부분 HP·연타·회복·사망 시 채움과 잔상이 실제 값에 맞는다.
- [ ] PP 100%·50%·45%·0%에서 각 줄이 전체 너비의 100%·50%·45%·0%를 채운다. 보스의 두 줄은 함께 변하고, 패리·일반 공격·리젠 시 실제 감소·회복량을 보존한다.
- [ ] 그로기·처형 피격 중 PP는 빈 상태로 유지되며, 기존 그로기 타이머 표현이 남지 않는다. 처형 중단·종료와 공중 그로기 종료 시 실제 PP로 돌아간다.
- [ ] 그로기 면역 또는 최대 PP가 0인 대상은 PP 없이 HP만 표시된다.
- [ ] 일반 적의 락온·전투·최근 피격·가림·화면 밖·사망을 조합해도 정해진 표시 조건과 우선순위를 따른다.
- [ ] 보스와 일반 적을 함께 상대하며 락온을 바꾸어도 각 표시 대상이 섞이지 않는다.
- [ ] 샌드백은 락온하거나 피해를 주면 표시되고, 샌드백의 실제 자원·면역 상태에 맞게 구성된다.
- [ ] 궁극기 컷신·일시정지·결과 화면·다시 시작 이후 오래된 이름·수치·잔상이 남지 않는다.
- [ ] 해상도와 카메라 거리가 달라져도 화면상 크기 비율과 고정·추적 배치 규칙을 유지한다.
