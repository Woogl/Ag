# 적 네임플레이트 작업 명세 (Spec)

## 1. 개요 및 목적

[UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 공통 스타일을 적용하여 일반 적과 샌드백 머리 위에 HP·PP를 표시합니다. 전투 중 각 대상의 체력, 그로기까지 남은 PP와 그로기 진행 상태를 구분할 수 있어야 합니다.

- 일반 적·샌드백은 이름 없이 머리 위에 HP 바와 PP 바를 표시합니다.
- 보스 상태는 UI 시스템의 '보스 상태'를 그대로 따르며, 머리 위에 중복 표시하지 않습니다.
- 공통 스타일·색상·시간 규칙은 기준 문서를 참조하고, 일반 적·샌드백에 필요한 크기·배치·표시 조건은 이 Spec에서 정의합니다.
- 이 문서는 구현 전 기획 명세입니다. 일반 적·샌드백의 치수와 표시 조건은 이 Spec의 적용안이며, UI 시스템에 이미 구현된 규칙이라는 뜻은 아닙니다. 구현·검증 전까지 Docs 정본은 유지합니다.

용어는 [용어집](<../../Docs/용어집.md>), 개발 범위는 [마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)를 따릅니다.

### 기존 기획과의 관계

| 문서 | 관계 |
| - | - |
| [UI 시스템](<../../Docs/Design/System/UI 시스템.md>) | 화면 기준, 게이지 바 스타일, 감소 잔상, 보스 상태, 레이어와 상황별 표시의 기준입니다. 일반 적·샌드백 네임플레이트와 처형 안내 배치를 추가합니다. |
| [전투 시스템](<../../Docs/Design/System/전투 시스템.md>) | HP·PP 계산, PP 리젠, 그로기, 처형 피격, 사망 판정을 따릅니다. 표시를 위해 전투 수치를 변경하지 않습니다. |
| [적 시스템](<../../Docs/Design/System/적 시스템.md>), [보스 시스템](<../../Docs/Design/System/보스 시스템.md>) | 전투 진입·이탈과 보스 전투 유지 규칙을 따릅니다. |
| [샌드백 Spec](<../샌드백/1-spec.md>) | 샌드백 2종의 자원, HP 즉시 회복, 그로기·처형 규칙을 따릅니다. |
| [근거리 일반 적 Spec](<../근거리 일반 적/1-spec.md>) | 일반 적의 자원과 상태를 표시하며, 락온·처형 안내와 함께 사용합니다. |
| [시뮬레이션 룸 Spec](<../시뮬레이션 룸/1-spec.md>) | 보스와 일반 적·샌드백을 함께 배치해도 각 대상의 표시를 구분합니다. |

## 2. 플레이 규칙 및 수치

### 2.1 공통 스타일과 적용 범위

| 항목 | 적용 기준 |
| - | - |
| 기준 해상도·배율·화면 여백 | UI 시스템의 '화면 기준' |
| 바 형태·배경·채움 방향·자원별 색상 | UI 시스템의 '게이지 바' |
| HP·PP 감소 잔상의 모양 | UI 시스템의 '게이지 바' |
| HP·PP 감소 잔상의 대기·감소 시간과 연속 피격 처리 | UI 시스템의 '플레이어 상태'에 정의된 HP 감소 잔상 |
| 그로기·처형 피격 중 PP 표현 | UI 시스템의 '보스 상태'에 정의된 PP 표시를 일반 적·샌드백에도 적용 |
| 보스 이름·바 크기·배치·표시 조건 | UI 시스템의 '보스 상태'와 '상황별 표시 규칙' |

위 기준의 정의는 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)을 참조합니다. 일반 적·샌드백에는 HP와 PP만 표시하며, 현재값·최대값·백분율, 이름, 레벨, 속성, 상태이상 아이콘은 표시하지 않습니다.

### 2.2 일반 적·샌드백 구성과 배치

아래 px 값은 UI 시스템의 기준 해상도에서의 크기입니다. 두 종류의 샌드백에 같은 구성을 사용합니다.

| 항목 | 규칙 |
| - | - |
| HP 바 | 118 × 10px |
| PP 바 | 118 × 4px. HP 바 아래 6px 간격으로 왼쪽 정렬 |
| 위치 기준 | 현재 자세의 머리 위에 표시 묶음의 아래쪽을 두며, 머리와의 화면상 여백은 16px. 가로 가운데 정렬 |
| 거리 변화 | 카메라 거리와 관계없이 화면상 크기를 유지하며 대상 위치를 따라감 |
| 자세 변화 | 점프·넉업·넉다운 중에도 현재 자세의 머리 위치를 따라감 |
| PP 표시 제외 | PP를 사용하지 않거나 그로기 면역으로 설정된 대상은 HP만 표시. 최대 PP가 0인 대상도 PP를 표시하지 않음 |

- PP 바가 없으면 PP 영역과 바 사이 간격을 없애고, HP 바 아래쪽을 머리 위 위치 기준에 맞춥니다.
- 락온 마커는 기존 락온 지점을 따릅니다. 네임플레이트 위치로 옮기지 않습니다.
- 그로기·처형 피격 중 PP 감소를 받지 않는 것은 PP 표시 제외 조건이 아닙니다. 해당 상태의 표현은 2.4를 따릅니다.

### 2.3 HP 표시

- 현재 HP / 최대 HP의 비율을 표시합니다. 표시 비율은 0~100%로 제한하며 실제 전투 수치는 변경하지 않습니다.
- HP 감소 시 2.1의 공통 감소 잔상을 적용합니다.
- 회복은 현재 HP를 즉시 반영합니다. 감소 잔상이 회복된 HP보다 낮으면 그 잔상을 제거합니다.
- 사망·제거되면 HP 바와 잔상을 함께 숨깁니다. 사망 여부는 전투 판정을 따릅니다.
- 샌드백의 HP가 0 이하가 되어 즉시 최대 HP로 회복하면 회복된 값을 표시합니다. 해당 타격을 최근 HP 감소로 취급하며, 사망에 따른 숨김을 적용하지 않습니다.

### 2.4 PP·그로기·처형 피격 표시

- 평상시에는 현재 PP / 최대 PP의 비율을 표시합니다. 표시 비율은 0~100%로 제한합니다.
- 공격·패리로 PP가 감소하면 2.1의 공통 감소 잔상을 적용합니다. 리젠과 상태 종료에 따른 회복은 실제 PP를 즉시 반영하며, 회복된 PP보다 낮은 잔상은 제거합니다.
- 그로기 진입부터는 실제 PP 비율 대신 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '보스 상태'에 정의된 그로기 시간 표시를 적용합니다. 공중 그로기에도 같은 규칙을 적용합니다.
- 처형 피격으로 전환되면 같은 문서의 처형 중 PP 바·감소 잔상 정지 규칙을 적용합니다. 종료·중단 후에는 실제 PP 표시로 돌아갑니다.
- 그로기·처형 피격 종료 시점과 PP 회복·사망 판정은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '그로기'를 따릅니다. UI 연출이 실제 PP를 회복시키거나 그로기를 연장하지 않습니다.
- PP 소진과 사망이 동시에 발생하면 사망에 따른 숨김을 우선합니다. 샌드백의 HP 즉시 회복은 사망으로 취급하지 않습니다.

### 2.5 일반 적·샌드백 표시 조건

1. 대상이 살아 있고, 머리 위 표시 기준점이 화면 안에 있으며, 카메라에서 대상의 몸 중심으로 향하는 시야가 벽·지형에 막히지 않아야 합니다. 다른 캐릭터가 앞을 지나가는 것은 숨김 조건으로 삼지 않습니다.
2. 위 조건을 만족하면서 **플레이어와 전투 중**, **현재 락온 대상**, **최근 3초 안에 HP 또는 PP 감소** 가운데 하나를 만족하면 표시합니다.
3. 샌드백은 전투 상태 진입을 요구하지 않으며, 락온 또는 최근 HP·PP 감소 조건으로 표시합니다. 공격 샌드백도 같습니다. 피해를 준 대상의 진영과 관계없이 HP·PP 감소를 판정합니다.
4. 최근 감소 시간은 마지막 HP·PP 감소 시점부터 다시 셉니다. 회복만 발생한 경우에는 갱신하지 않습니다. 그로기·처형 피격 상태 자체는 별도 표시 유지 조건이 아니며, 위 조건을 모두 잃으면 숨깁니다.
5. 별도 거리 제한은 두지 않습니다. 조건을 만족하는 모든 대상에 개별 표시하며, 락온 대상만 표시하거나 여러 대상의 수치를 합치지 않습니다.
6. 비전투로 돌아가도 락온 또는 최근 감소 조건이 남아 있으면 유지합니다. 사망·제거·화면 밖·벽 뒤에서는 즉시 숨깁니다. 화면 가장자리에 붙이거나 화살표로 대체하지 않습니다.
7. 표시가 겹치면 락온 대상이 가장 앞에, 나머지는 카메라와 가까운 대상이 앞에 보입니다. 위치를 임의로 흩뜨리지 않습니다.
8. 표시·숨김에는 페이드를 넣지 않습니다. 최근 감소 시간은 [시간 규칙](<../../Docs/Design/System/시간 규칙.md>)의 게임 시간으로 세며, 일시정지 중에는 멈춥니다.

### 2.6 보스 상태와 함께 표시

- 보스 상태의 이름·HP·PP와 표시 시점은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)을 따릅니다. 보스 머리 위에는 네임플레이트를 추가하지 않습니다.
- 보스와 일반 적·샌드백이 함께 있어도 보스 상태와 각 머리 위 표시를 함께 유지합니다. 각 표시는 자신의 표시 조건을 적용합니다.
- 락온을 일반 적·샌드백으로 옮겨도 화면 상단 보스 상태의 대상은 바뀌지 않습니다.
- 보스가 화면 밖이나 벽 뒤로 이동해도 전투 중인 보스 상태는 유지합니다. 2.5의 화면·가림 조건은 머리 위 네임플레이트에만 적용합니다.

### 2.7 상황별 표시와 다른 UI의 관계

일반 적·샌드백의 상황별 표시는 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '상황별 표시 규칙'에 맞춰 다음과 같이 적용합니다.

| 상황 | 일반 적·샌드백 네임플레이트 |
| - | - |
| 일반 전투·페이즈 전환 | 2.5의 표시 조건 적용 |
| 그로기·처형 피격 | 2.5의 표시 조건 적용. PP 표현은 2.4를 따름 |
| 궁극기 컷신 | 숨김 |
| 일시정지 메뉴 | 메뉴 직전 표시와 감소 잔상·타이머를 멈춘 상태로 유지하고, 닫으면 이어감 |
| 플레이어 사망·스테이지 결과 연출·전투 결과 UI | 숨김 |
| 레벨 전환·다시 시작 | 이전 대상의 표시와 잔상·표시 유지 시간 제거 |

- 사망·제거와 위 표의 숨김 상황이 일반 표시 조건보다 우선합니다.
- 숨겼다가 다시 표시할 때는 최신 HP·PP와 현재 상태로 시작합니다. 숨겨진 동안의 피해 잔상을 몰아서 재생하지 않습니다. 그로기 시간 표시는 현재 진행도, 처형 피격 중 PP 표시는 처형 전환 시 고정한 상태를 사용합니다. 일시정지는 표의 유지·재개 규칙을 따릅니다.
- 일반 적·샌드백 네임플레이트는 캐릭터를 따라가는 락온 마커·처형 안내와 같이 HUD·Menu·Modal보다 아래에 표시합니다. 보스 상태는 기존 HUD를 사용합니다.
- 일반 적·샌드백의 락온 마커와 처형 안내는 각 콘텐츠 Spec의 적용 대상 규칙과 UI 시스템의 표현 규칙을 따릅니다. 네임플레이트가 숨겨졌다는 이유만으로 처형 안내의 발동 조건을 바꾸지 않습니다.
- 머리 위 처형 안내가 네임플레이트와 겹치면 처형 안내의 아래쪽을 네임플레이트 위쪽에서 12px 띄웁니다.
- 감소 잔상과 그로기 진행은 [시간 규칙](<../../Docs/Design/System/시간 규칙.md>)의 해당 항목을 따릅니다.

## 3. 완료 조건 (Acceptance Criteria)

아래는 구현 후 확인할 조건이며, 현재 검증 결과를 뜻하지 않습니다.

- [ ] 일반 적·샌드백은 이름·수치 없이 머리 위에 표시되고, HP·PP 바의 형태·색상·배경·채움 방향이 UI 시스템의 공통 스타일과 일치한다.
- [ ] 바 크기·간격·머리 위 여백이 2.2와 일치하고, 해상도 변경 시 공통 배율을 따르며 카메라 거리 변화로 화면상 크기가 달라지지 않는다.
- [ ] 점프·넉업·넉다운 중에도 대상의 머리 위치를 따라가며 락온 마커의 기준점을 바꾸지 않는다.
- [ ] HP·PP가 감소하면 공통 감소 잔상이 적용되고, 연속 피격·회복 이후 현재 수치와 잔상이 맞는다.
- [ ] 평상시 HP·PP 비율이 부분값을 정확히 반영하며, 최대 PP가 0이거나 그로기 면역으로 설정된 대상은 PP 영역과 간격 없이 HP만 표시한다.
- [ ] 그로기 중에는 UI 시스템의 PP 시간 표시가 적용되고, 공중에서도 진행된다. 처형 피격으로 전환되면 바와 잔상이 정지하며 종료·중단 후 실제 PP로 돌아간다.
- [ ] 샌드백의 HP가 0 이하가 되어 회복하는 타격에도 네임플레이트는 사망한 것처럼 사라지지 않고, 최신 HP와 최근 감소 조건을 반영한다.
- [ ] 비전투 접근만으로는 표시되지 않고, 전투·락온·최근 감소 조건 중 하나가 있으면 표시된다. 샌드백은 전투 상태 없이도 락온하거나 피해를 받으면 표시된다.
- [ ] 마지막 감소 후 유지 시간의 경계에서 표시 여부가 맞고, 회복만으로 시간이 갱신되지 않는다. 다른 표시 조건이 없으면 그로기·처형 피격 중에도 유지 시간이 끝나면 숨겨진다.
- [ ] 화면 밖·벽 뒤·사망·제거 시 즉시 숨겨지고, 다른 캐릭터가 앞을 지나가는 것만으로는 숨겨지지 않는다. 같은 타격의 사망과 PP 소진에서는 사망 숨김이 우선한다.
- [ ] 여러 대상이 함께 표시될 때 락온 대상과 거리의 겹침 우선순위를 지키며, 보스와 일반 적 사이의 락온 전환으로 표시 대상이 섞이지 않는다.
- [ ] 보스 상태의 이름·크기·배치·감소 잔상·그로기·처형 표현은 UI 시스템과 일치하며, 머리 위에 중복 표시되지 않는다.
- [ ] 처형 안내는 기존 조건으로 표시되고, 네임플레이트와 겹칠 때 지정한 간격을 유지한다.
- [ ] 궁극기 컷신·일시정지·결과 화면·레벨 전환·다시 시작 시 2.7을 따르고, 다시 표시될 때 오래된 수치·피해 잔상이 재생되지 않는다.
- [ ] 슬로우모션·궁극기 시간 정지·히트스톱에서 감소 잔상·그로기·최근 감소 시간이 각 시간 기준에 맞게 진행된다.
