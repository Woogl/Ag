# 적 네임플레이트 명세 변경 기록

## 2026-11-01 — 처형 안내를 락온 지점 오른쪽으로

프로그래머 요청으로 처형 안내를 머리 위에서 락온 지점 오른쪽으로 옮겼습니다(2.7). 네임플레이트와 겹칠 때의 12px 규칙은 없앴고, 락온 마커 오른쪽 가장자리에서 12px 띄우는 위치로 대신했습니다. 보스에도 같이 적용됩니다.

## 2026-11-01 — UI 시스템 기준으로 재정리

사용자 요청에 따라 [작업 명세](<1-spec.md>)의 기준을 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)으로 변경했습니다. 이 문서는 요청된 변경 이력이며 구현 기준은 작업 명세와 그 참조 문서입니다.

- 스텔라 블레이드 화면 관찰, 외부 참고 이미지, 원작 대조 항목과 격자 표시 규칙을 제거했습니다.
- HP·PP의 외형과 색상, 감소 잔상, 그로기·처형 피격 중 PP 표현을 UI 시스템의 공통 규칙에 맞췄습니다.
- 보스 외형·크기·이름·상단 여백을 바꾸는 제안을 제거하고 기존 보스 상태 규칙을 참조하도록 했습니다.
- 일반 적·샌드백의 바 전체 크기, 바 사이 간격, 머리 위 여백과 전투·락온·최근 감소 표시 조건은 기존 초안 값을 유지했습니다. 격자 칸 수·칸 크기·줄 수는 사용하지 않습니다.
- 샌드백의 HP 즉시 회복, 그로기·처형 중 표시 조건, 숨김 후 복귀와 UI 겹침 규칙을 명확히 하고 완료 조건을 갱신했습니다.
- `네임플레이트 구성.png`와 `네임플레이트 구성.svg`를 삭제했습니다. 작업 명세의 두 파일 링크와 첨부 그림 설명도 제거했습니다. 이 기록의 파일명은 삭제 이력이며 참고 이미지 지정이 아닙니다.
- Docs 정본, 게임 코드·데이터·에셋은 변경하지 않았습니다. 구현·게임 실행 검증은 수행하지 않았습니다.
