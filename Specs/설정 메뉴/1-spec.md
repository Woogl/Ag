# 설정 메뉴 Spec

## 1. 개요 및 목적

- 조작 안내와 게임 설정을 Settings 내용 하나에 분류별로 모읍니다. 분류는 Controls, Display, Language입니다.
- 타이틀에서는 Settings 화면으로, 스테이지에서는 일시정지 메뉴의 Settings 탭으로 같은 내용을 엽니다.
- Display에서 창 모드와 해상도를 바꿀 수 있게 합니다.
- 일시정지 메뉴의 System 탭(Resume, Restart, Return to Title, Quit)은 바꾸지 않습니다.
- 스테이지 선택 화면과 적 선택 화면도 Settings 화면·일시정지 메뉴와 같은 메뉴 화면 양식으로 맞춥니다. 타이틀 화면과 전투 결과 UI의 모양은 바꾸지 않습니다.

## 2. 플레이 규칙 및 수치

### 2.1 메뉴 화면 공통 양식

[UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 스타일'에 메뉴 화면의 공통 양식을 둡니다. 스테이지 선택 화면, Settings 화면, 적 선택 화면, 일시정지 메뉴가 따릅니다.

- 화면 전체를 불투명한 검은 배경으로 덮어, 뒤의 레벨과 게임 화면은 보이지 않습니다.
- 화면 위쪽 가운데에 제목을 표시합니다. 제목의 위쪽은 화면 여백에 맞춥니다. 제목은 Large 흰색 굵은 글자이고, 제목 아래 8px에 제목 너비만큼 두께 4px의 흰 밑줄을 긋습니다. 일시정지 메뉴는 이 자리에 탭 바를 두며, 고른 탭의 이름이 제목과 같은 모양입니다.
- 화면의 내용은 화면 가운데에 놓고, 위쪽을 제목 아래 72px에 맞춥니다.

![Settings 화면 - Display](<Settings 화면 - Display.svg>)

### 2.2 타이틀 화면

- 제목 아래 버튼은 위에서부터 Play, Settings, Quit입니다. Controls 버튼과 조작 안내 팝업, Settings 팝업은 없앱니다.
- Settings 버튼을 실행하면 레벨 전환 없이 Settings 화면을 엽니다.
- 배경은 지금처럼 뒤의 LV_FrontEnd 레벨이 보입니다.

### 2.3 Settings 화면

LV_FrontEnd에서 타이틀 화면의 Settings 버튼으로 여는 메뉴 화면입니다. 스테이지 선택 화면과 같이 타이틀 화면 대신 표시합니다.

- '2.1 메뉴 화면 공통 양식'을 따릅니다. 제목은 'Settings'이고, 내용은 Settings 내용('2.6 Settings 내용')입니다. 그래서 일시정지 메뉴의 Settings 탭과 같은 자리에 같은 모양으로 보입니다.
- Settings 내용 아래 32px 가운데에 Back 버튼을 Large로 표시합니다.
- 페이드 없이 바로 표시하고, 표시하는 즉시 입력을 받습니다. 마우스 커서를 표시합니다.
- 화면을 열 때마다 Controls 분류가 선택됩니다.
- Back 버튼을 실행하거나 Esc를 누르면 화면을 닫고 타이틀 화면으로 돌아갑니다. 타이틀 화면에서는 Settings 버튼이 선택됩니다.

### 2.4 일시정지 메뉴의 Settings 탭

- 탭은 왼쪽부터 Inventory, System, Settings입니다. 메뉴를 열 때마다 System 탭을 표시하고, 탭을 바꾸는 조작과 끝에서 반대쪽 끝으로 넘어가는 규칙은 지금 탭 바와 같습니다.
- Settings 탭은 Settings 내용을 '2.1 메뉴 화면 공통 양식'의 내용 자리에 놓습니다.
- Settings 탭을 표시할 때마다 Controls 분류가 선택됩니다. 다른 탭에 갔다가 돌아와도 같습니다.

![일시정지 메뉴 - Settings 탭](<일시정지 메뉴 - Settings 탭.svg>)

### 2.5 스테이지 선택 화면과 적 선택 화면

두 화면은 '2.1 메뉴 화면 공통 양식'을 따릅니다. 아래에 적지 않은 배치와 조작은 지금 규칙 그대로입니다.

| 화면 | 제목 | 바뀌는 것 |
| - | - | - |
| 스테이지 선택 화면 | Stage Select | 제목 글자와 모양, 불투명한 검은 배경(지금은 뒤의 LV_FrontEnd 레벨이 보임), 스테이지 드롭다운의 위쪽을 제목 아래 72px에 맞춤 |
| 적 선택 화면 | Enemy Select | 제목 글자와 모양, 불투명한 검은 배경(지금은 뒤의 게임 화면을 어둡게 표시), 적 카드 줄의 위쪽을 제목 아래 72px에 맞춤 |

- 두 화면의 제목은 지금 대문자('STAGE SELECT', 'ENEMY SELECT')인데, 탭 이름과 같이 단어의 첫 글자만 대문자로 적습니다.
- 적 선택 화면이 떠 있는 동안 게임이 멈추는 규칙과 카드의 모델 표시는 그대로입니다.

### 2.6 Settings 내용

Settings 화면과 Settings 탭이 같은 내용을 씁니다. 왼쪽에 분류 목록을, 그 오른쪽 48px에 고른 분류의 내용을 놓습니다.

**분류 목록**

- 분류 이름을 위에서부터 Controls, Display, Language 순서로 세로로 놓습니다. 글자는 Large이고, 분류 이름 사이는 24px입니다.
- 고른 분류의 이름은 흰색 굵은 글자이고, 이름 왼쪽 16px에 이름 높이만큼 두께 4px의 흰 세로 막대를 긋습니다. 고르지 않은 분류의 이름은 흐린 회색 글자이고 막대가 없으며, 마우스를 올리면 글자가 밝아집니다.
- 분류 이름을 좌클릭하거나, 분류 목록에서 ↑·↓로 선택을 옮기면 그 분류를 고릅니다. 마우스를 올리기만 해서는 고르지 않습니다.
- 분류를 고르면 내용이 페이드 없이 바로 바뀝니다.
- 분류 이름에 마우스를 올릴 때와 좌클릭으로 분류를 고를 때 UI 스타일 '버튼'의 효과음을 재생합니다.
- 분류 목록에서 →를 누르면 고른 분류 내용의 첫 드롭다운으로 선택을 옮기고, 내용에서 ←를 누르면 고른 분류의 이름으로 돌아옵니다. Controls에는 고를 것이 없어 →로 옮기지 않습니다.

**내용 칸**

- 분류를 바꿔도 내용 칸의 크기는 바뀌지 않습니다. 크기는 세 분류 가운데 가장 큰 내용에 맞추고, 내용은 칸의 왼쪽 위에 붙입니다.
- Display와 Language의 줄은 왼쪽에 항목 이름, 오른쪽에 드롭다운을 둡니다. 글자는 둘 다 Large이고, 이름은 드롭다운과 세로 가운데를 맞춥니다. 드롭다운은 그 분류의 모든 줄에서 같은 위치, 가장 긴 항목 이름의 오른쪽 48px에서 시작합니다. 줄 사이는 16px입니다.
- 드롭다운의 모양과 목록을 여닫는 조작은 스테이지 선택 화면의 스테이지 드롭다운과 같습니다.

### 2.7 Controls

- 지금 조작 안내 팝업의 조작 안내(줄 구성과 순서, 키 아이콘, 조작 이름, 줄 사이, 반투명한 어두운 배경과 그 안쪽 여백)를 그대로 표시합니다.
- 읽기 전용입니다.

### 2.8 Display

| 줄 | 항목 이름 | 목록 |
| - | - | - |
| 1 | Window Mode | Fullscreen, Windowed |
| 2 | Resolution | 지금 창 모드에서 고를 수 있는 해상도를 큰 것부터 '가로 × 세로'로 적습니다. (예: 1920 × 1080) |

- Fullscreen은 모니터를 고른 해상도로 바꿔 화면 전체를 씁니다. Windowed는 고른 해상도 크기의 창입니다.
- 고를 수 있는 해상도는 아래 표의 해상도 가운데, Fullscreen은 모니터가 지원하는 것, Windowed는 모니터보다 가로와 세로가 모두 작은 것입니다.
  - Fullscreen 목록에는 표에 없더라도 모니터 해상도를 늘 넣습니다.
  - Windowed에서 고를 수 있는 해상도가 하나도 없으면 모니터 해상도 하나입니다.

| 화면 비율 | 해상도 |
| - | - |
| 16:9 | 1280 × 720, 1366 × 768, 1600 × 900, 1920 × 1080, 2560 × 1440, 3840 × 2160 |
| 16:10 | 1280 × 800, 1440 × 900, 1680 × 1050, 1920 × 1200, 2560 × 1600 |
| 21:9 | 2560 × 1080, 3440 × 1440 |

- 창 모드를 바꿀 때 지금 해상도가 새 창 모드의 목록에 없으면 그 목록의 가장 큰 해상도로 바꿉니다.
- 목록의 항목을 실행하면 바로 적용하고 저장합니다. 저장한 창 모드와 해상도는 다음 실행에도 그대로입니다.
- 창 모드나 해상도를 고른 적이 없으면 Fullscreen, 모니터 해상도로 시작합니다.
- 드롭다운은 닫혀 있을 때 지금 창 모드와 지금 해상도를 표시합니다.

### 2.9 Language

- 'Language' 줄 하나입니다. 언어 목록, 닫혀 있을 때의 표시, 항목을 실행했을 때 바꾸고 저장하는 규칙은 지금 Settings 팝업의 언어 드롭다운과 같습니다.
- 일시정지 메뉴에서 바꿔도 바로 적용되어, 그 뒤에 보이는 문구는 모두 그 언어로 표시합니다.

### 2.10 UI 조작

[UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 조작' 표에서 '조작 안내 팝업 닫기'와 'Settings 팝업 닫기' 줄을 지우고 두 줄을 더합니다.

| 동작 | 키 |
| - | - |
| Settings 화면 닫기 | Back 버튼 실행, 또는 Esc |
| Settings의 분류 고르기 | 분류 이름 좌클릭, 또는 분류 목록에서 ↑·↓ |

- Esc 설명의 '스테이지 선택 화면에서는 Back 버튼과 같습니다'에 Settings 화면을 더합니다.

### 2.11 기존 기획서와의 관계

검증 뒤 아래를 고칩니다.

- [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)
  - 'UI 스타일'에 '메뉴 화면' 절(이 Spec의 2.1)을 더함.
  - '타이틀 화면'의 버튼 목록. '조작 안내 팝업'과 'Settings 팝업' 절을 지우고 'Settings 화면' 절을 더함(조작 안내 규칙은 Settings의 Controls로 옮김).
  - '일시정지 메뉴'의 탭 목록, 배경·탭 바 위치를 '메뉴 화면'으로 가리킴, 'Settings 탭' 절 추가.
  - '스테이지 선택 화면'과 '적 선택 화면'의 제목·배경·위치를 '메뉴 화면'으로 가리킴.
  - 'UI 레이어': Settings 화면은 Menu 레이어. Modal 레이어에 남는 화면이 없어 레이어 구성에서 Modal을 뺌. '표시'의 괄호 안 화면 목록.
  - '메뉴 UI' 첫 문장의 화면 목록, 'UI 조작' 표와 Esc 설명.
- [게임 플로우](<../../Docs/Design/System/게임 플로우.md>) 'Front End': Controls 버튼 문장을 Settings 버튼으로 바꿈.
- [게임 개요](<../../Docs/Design/게임 개요.md>) '지원 언어'의 '언어 바꾸기': 타이틀의 Settings 화면과 일시정지 메뉴의 Settings 탭.
- 첨부 그림: 'FrontEnd 화면 구성'의 버튼, 'UI 레이어 구성'의 Modal 레이어, '조작 안내 팝업' 삭제, 이 Spec의 그림 네 장 추가.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 타이틀 화면의 버튼이 위에서부터 Play, Settings, Quit이고, Controls 버튼이 없다.
- [ ] 타이틀에서 Settings를 실행하면 타이틀 화면 대신 Settings 화면이 Controls 분류를 고른 상태로 열린다. Back 또는 Esc로 닫으면 타이틀 화면의 Settings 버튼이 선택되어 있다.
- [ ] 일시정지 메뉴의 탭이 Inventory, System, Settings이고, 열 때마다 System 탭이 보인다. Q·E로 세 탭을 오가고, 끝에서 반대쪽 끝으로 넘어간다.
- [ ] Settings 탭을 표시할 때마다 Controls 분류가 골라져 있다.
- [ ] 분류 이름 좌클릭과 분류 목록의 ↑·↓로 분류가 바뀌고, 마우스를 올리기만 해서는 바뀌지 않는다. 분류를 바꿔도 내용 칸의 크기와 Back 버튼의 위치가 그대로다.
- [ ] Controls에 지금 조작 안내와 같은 줄이 같은 순서로, 키 아이콘과 함께 보인다. 타이틀의 Settings 화면에서도 같다.
- [ ] Window Mode 목록이 Fullscreen, Windowed 둘이고, 고르면 바로 그 창 모드가 된다.
- [ ] Fullscreen과 Windowed의 Resolution 목록이 '2.8 Display'의 표와 규칙대로이고(표에 없는 크기가 없음, Fullscreen에는 모니터 해상도가 있음), 고르면 바로 그 해상도가 되며, UI는 'UI 스타일'의 '화면 기준'대로 크기를 맞춘다.
- [ ] 창 모드를 바꿨을 때 지금 해상도가 새 목록에 없으면 그 목록의 가장 큰 해상도가 된다.
- [ ] 창 모드와 해상도를 바꾸고 게임을 다시 실행하면 바꾼 값으로 시작한다. 처음 실행하면 Fullscreen, 모니터 해상도로 시작한다.
- [ ] Settings 화면과 Settings 탭 어디서 언어를 바꿔도 바로 적용되고, 다음 실행에도 그 언어로 시작한다.
- [ ] 드롭다운 목록이 열려 있을 때 Esc는 목록만 닫는다. 목록이 닫혀 있으면 Settings 화면에서는 화면을, Settings 탭에서는 일시정지 메뉴를 닫는다.
- [ ] 스테이지 선택 화면, Settings 화면, 적 선택 화면이 불투명한 검은 배경 위에 같은 자리, 같은 모양의 제목('Stage Select', 'Settings', 'Enemy Select')을 보이고, 내용의 위쪽이 일시정지 메뉴의 탭 내용과 같은 높이다. 타이틀 화면은 뒤의 레벨이 보이고, 전투 결과 UI는 지금 그대로다.
