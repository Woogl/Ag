# 스테이지 선택 작업 명세 (Spec)

## 1. 개요 및 목적

- 타이틀 화면에서 보스전, 미니던전 3종, 시뮬레이션 룸 가운데 하나를 골라 들어갈 수 있도록 게임 흐름을 바꿉니다. ([마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)의 '스테이지 선택')
- 지금은 타이틀의 Start 버튼이 LV_BossStage로만 이어집니다. Start 버튼 뒤에 스테이지 선택 화면을 두어, 스테이지가 늘어나도 타이틀 화면은 바꾸지 않습니다.
- 이번 마일스톤은 전투 검증과 밸런싱·디버깅이 목적이므로 모든 스테이지를 처음부터 고를 수 있습니다.
- 이 Spec은 타이틀에서 각 스테이지로 들어가는 흐름과 미니던전의 공통 흐름(시작, 결과, 일시정지)을 정합니다. 미니던전 각각의 구성은 미니던전별 레벨디자인 기획서를, 시뮬레이션 룸에 들어온 뒤의 규칙은 시뮬레이션 룸 Spec을 따릅니다.

용어는 [용어집](<../../Docs/용어집.md>)을 따릅니다.

## 2. 플레이 규칙 및 수치

### 2.1 스테이지 목록

| 순서 | 버튼 이름 | 레벨 | 들어간 뒤의 규칙 |
| - | - | - | - |
| 1 | Boss Stage | LV_BossStage | [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Boss Stage' |
| 2 | Duel Corridor | LV_DuelCorridor | '2.4 미니던전 공통 흐름' |
| 3 | Fortress Breach | LV_FortressBreach | '2.4 미니던전 공통 흐름' |
| 4 | Temp Dungeon 3 | LV_TempDungeon03 | '2.4 미니던전 공통 흐름' |
| 5 | Simulation Room | LV_SimulationRoom | 시뮬레이션 룸 Spec |

- 미니던전의 구성은 [결투 회랑](<../../Docs/Design/Level/스테이지 - 미니던전 결투 회랑.md>), [요새 돌파](<../../Docs/Design/Level/스테이지 - 미니던전 요새 돌파.md>) 기획서를 따릅니다.
- 세 번째 미니던전의 버튼 이름과 레벨 이름은 임시입니다. 레벨디자인 기획서에서 던전 이름이 정해지면 바꿉니다.
- 잠금이나 해금 조건은 없습니다. 게임을 처음 실행했을 때부터 모든 스테이지를 고를 수 있습니다.

### 2.2 타이틀 화면의 변경

- 타이틀 화면의 배치와 버튼(Start, Controls, Quit)은 그대로 둡니다. ([UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '타이틀 화면')
- Start 버튼을 실행하면 레벨 전환 없이 스테이지 선택 화면을 엽니다. LV_BossStage로 바로 이동하지 않습니다.
- Controls, Quit 버튼은 지금과 같습니다.

### 2.3 스테이지 선택 화면

LV_FrontEnd에서 Start 버튼으로 여는 화면입니다. Menu 레이어에 표시합니다. ([UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 레이어')

**화면 구성**

- 화면 위쪽 가운데에 제목 'STAGE SELECT'를 Large로 표시합니다.
- 제목 아래 가운데에 '2.1 스테이지 목록'의 버튼 5개를 순서대로 위에서부터 세로로 놓고, 그 아래에 Back 버튼을 놓습니다. (글자 Large)
- 타이틀 화면과 같은 Menu 레이어이므로, 이 화면이 열려 있는 동안 타이틀 화면은 숨깁니다. ('UI 레이어'의 '표시')
- 페이드 없이 바로 표시하고, 표시하는 즉시 버튼 입력을 받습니다.
- 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Boss Stage입니다.

**버튼**

| 버튼 | 실행 결과 |
| - | - |
| 스테이지 버튼 (Boss Stage ~ Simulation Room) | 해당 스테이지의 레벨로 이동합니다. 레벨이 아직 게임에 없으면 버튼을 흐리게 표시하고, 선택은 되지만 실행해도 아무 일도 하지 않습니다. |
| Back | 스테이지 선택 화면을 닫고 타이틀 화면으로 돌아갑니다. 타이틀 화면에서는 Start 버튼이 선택됩니다. |

- Esc를 누르면 Back 버튼과 같습니다.
- 그 밖의 조작은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 조작'을 따릅니다.
- 스테이지에서 Return to Title로 돌아오면 타이틀 화면이 열리며, 스테이지 선택 화면은 닫힌 상태입니다.

### 2.4 미니던전 공통 흐름

LV_DuelCorridor, LV_FortressBreach, LV_TempDungeon03에 공통으로 적용하는 흐름입니다.

**시작**

- 레벨이 열리면 플레이어는 던전의 시작 지점에서 바로 조작할 수 있습니다. 시작 지점과 적 배치는 미니던전별 레벨디자인 기획서를 따릅니다.
- 마우스 커서와 입력은 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Boss Stage'와 같습니다.
- 전투 HUD는 보스전과 같습니다. 일반 적의 체력 표시는 네임플레이트 Spec을 따릅니다.

**결과**

- 던전 최종 목적지의 보스(모든 미니던전에서 커스터)가 사망하면 Stage Clear, 플레이어의 HP가 0 이하가 되면 Game Over입니다. 스테이지 결과 연출과 전투 결과 UI는 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Stage Clear', 'Game Over'와 같습니다.
- 일반 적이 남아 있어도 보스가 사망하면 Stage Clear입니다.
- 결과는 먼저 처리된 사망으로 정해지며, 결과가 정해진 뒤의 사망은 'Boss Stage'와 같이 처리합니다.

**일시정지와 레벨 이동**

- 일시정지는 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 '일시정지'를 따릅니다.

| 버튼 | 실행 결과 |
| - | - |
| Restart (일시정지 메뉴, 전투 결과 UI) | 지금 있는 던전 레벨을 처음부터 다시 로드하고, 플레이어와 모든 적의 상태를 초기화합니다. |
| Return to Title, Quit | 'Stage Clear'의 같은 버튼과 같습니다. |

### 2.5 기존 스테이지의 변경

- LV_BossStage에 들어간 뒤의 규칙은 바뀌지 않습니다. Restart는 지금처럼 LV_BossStage를 다시 시작하고, Return to Title은 타이틀 화면으로 돌아갑니다.
- LV_SimulationRoom은 스테이지 선택 화면의 Simulation Room 버튼으로 들어갑니다. 들어온 뒤의 규칙은 시뮬레이션 룸 Spec을 따릅니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시나리오 1: 게임을 실행하면 타이틀 화면이 지금과 같은 배치로 열리고, Start를 실행하면 레벨 전환 없이 스테이지 선택 화면이 열립니다. 제목 'STAGE SELECT' 아래에 Boss Stage, Duel Corridor, Fortress Breach, Temp Dungeon 3, Simulation Room, Back이 위에서부터 놓이고 Boss Stage가 선택되어 있습니다.
- [ ] 시나리오 2: 스테이지 선택 화면에서 Back을 실행하거나 Esc를 누르면 타이틀 화면으로 돌아가고 Start가 선택되어 있습니다.
- [ ] 시나리오 3: Boss Stage를 실행하면 LV_BossStage로 이동해 지금과 같이 보스전이 시작됩니다.
- [ ] 시나리오 4: Duel Corridor, Fortress Breach, Temp Dungeon 3을 각각 실행하면 해당 던전 레벨로 이동하고, 시작 지점에서 바로 조작할 수 있으며 마우스 커서가 숨겨집니다.
- [ ] 시나리오 5: 던전에서 일반 적이 남아 있는 상태로 보스를 처치하면 스테이지 결과 연출 뒤 Stage Clear UI가 뜨고, Restart를 실행하면 같은 던전이 처음부터 다시 시작됩니다.
- [ ] 시나리오 6: 던전에서 플레이어가 사망하면 Game Over UI가 뜨고, Return to Title을 실행하면 타이틀 화면으로 돌아오며 스테이지 선택 화면은 닫혀 있습니다.
- [ ] 시나리오 7: 던전에서 Esc를 누르면 보스전과 같은 일시정지 메뉴가 열리고, Restart는 지금 던전을 다시 시작합니다.
- [ ] 시나리오 8: Simulation Room을 실행하면 LV_SimulationRoom으로 이동하고, 이후 동작은 시뮬레이션 룸 Spec의 완료 조건을 따릅니다.
- [ ] 시나리오 9: 스테이지 선택 화면에서 마우스와 ↑·↓ 키로 버튼을 고르고 좌클릭·Enter로 실행할 수 있으며, 맨 위·맨 아래에서 더 넘어가는 방향을 누르면 선택이 멈춥니다.
- [ ] 시나리오 10: 레벨이 아직 없는 스테이지의 버튼은 흐리게 표시되고, 선택은 되지만 실행해도 화면이 바뀌지 않습니다. 그 레벨을 만들면 버튼이 보통 상태로 표시되고 해당 레벨로 이동합니다.
