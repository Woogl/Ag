# 적 AI 이동 규칙 정리 작업 명세 (Spec)

상태: 기획 확정 전. 구현·플레이 검증 전입니다.

## 1. 개요 및 목적

적이 공격하지 않는 동안의 움직임을 지금은 상황마다 따로 정합니다. 패턴 후딜레이 동안은 좌우로 걷거나 서 있고, 고를 패턴이 없으면 다가갑니다. 이것을 적마다 정한 적정 거리를 지키는 규칙 하나로 정리하고, 패턴 후딜레이를 모든 패턴에 함께 걸리는 쿨다운으로 바꿉니다. 모든 적이 같은 규칙을 쓰고, 적마다 다른 것은 각 적 문서의 값뿐입니다.

적정 거리는 다수전도 고려합니다. 기다리는 근거리 적이 플레이어 바로 앞에 몰리지 않고 둘러싸게 합니다.

이 정리로 지금 규칙의 빈틈 두 가지를 없앱니다.
- 거리와 시야가 맞아도 쿨다운만 남아 있으면 고를 패턴이 없어 플레이어에게 걸어옵니다. 경비 사수가 움찔·조준 취소·넉다운 뒤 물러나지 않고 다가오는 원인입니다.
- 패턴 후딜레이 도중 움찔시키면 남은 후딜레이가 사라져, 움찔이 끝나자마자 공격합니다.

### 바뀌지 않는 것

- 패턴을 고르는 조건(발동 가능 거리, 페이즈, 패턴마다 정한 시야 조건, 쿨다운)과 가중치
- 각 적의 패턴 후딜레이 길이, 좌우 걷기·제자리 선택. 경비 사수의 8m는 적정 거리의 가까운 쪽으로 옮겨 값이 그대로입니다.
- 움찔만 끝났을 때는 후딜레이를 새로 걸지 않는 것
- 상태 전환 표(사망, 플레이어 사망, 그로기, 처형, 페이즈 전환)
- 비전투와 정찰, 낭떠러지
- 커스터 Backstep의 발동 조건과 '끝나면 대기 없이 바로 다음 패턴'

| [샌드백](<../../Docs/Design/Content/샌드백.md>) | 두 샌드백에 적정 거리를 더합니다. MOV가 0이라 움직임은 바뀌지 않습니다. |

## 2. 플레이 규칙 및 수치

전투 중인 적의 상태는 셋입니다. 패턴 실행, 피격 반응 등(피격 반응·그로기·처형 피격·페이즈 전환), 그리고 그 밖입니다. 그 밖의 상태에서 적은 2.1로 공격을 고르고, 고르지 못하는 동안 2.2로 움직입니다.

### 2.1 공격

아래를 모두 만족하는 패턴이 있으면, 그중 가중치에 따라 하나를 골라 실행합니다.

- 적과 플레이어의 캡슐 중심 사이 수평 거리가 발동 가능 거리 안입니다.
- 지금 쓸 수 있습니다(현재 페이즈, 패턴마다 정한 시야 조건).
- 그 패턴의 쿨다운이 끝났습니다.
- 패턴 후딜레이가 끝났습니다.

패턴 후딜레이가 끝나는 순간과 피격 반응 등이 끝나는 순간에 바로 확인합니다. 고르지 못하면 그 뒤로 0.5초마다 다시 확인합니다.

반응형 패턴(가중치 없이 반응 확률로만 나오는 패턴, 예: 커스터 Backstep)은 2.1과 2.2에서 빼고, 2.3의 조건으로만 씁니다.

### 2.2 공격하지 않는 동안의 움직임

2.1에서 패턴을 고르지 못한 동안, 적은 목표 거리 안으로 움직입니다. 거리는 모두 캡슐 중심 사이 수평 거리입니다.

| 상황 | 기준 | 목표 거리 |
| - | - | - |
| 공격할 차례 | 패턴 후딜레이가 끝났고, 현재 페이즈에서 쿨다운이 끝난 패턴이 있음 | 쿨다운이 끝난 패턴들의 발동 가능 거리 |
| 기다리는 중 | 그 밖. 패턴 후딜레이 중이거나, 쿨다운이 끝난 패턴이 없음 | 각 적 문서의 적정 거리 |

| 목표 거리와 비교 | 움직임 |
| - | - |
| 목표 거리보다 멂 | 플레이어에게 걸어서 다가감 |
| 목표 거리보다 가까움 | 플레이어를 바라본 채 반대쪽으로 걸음 |
| 목표 거리 안 | 기다리는 중이면 플레이어를 바라보며, 적마다 정한 대로 좌우로 걷거나 제자리에 섬. 공격할 차례이면 거리는 맞는데 다른 사용 조건(시야 등)이 안 맞아 고르지 못한 것이므로, 플레이어에게 걸어서 다가감 |

- 공격할 차례에 쿨다운이 끝난 패턴이 여럿이면, 하나라도 발동 가능 거리 안이면 '목표 거리 안'입니다. 모두 밖이면, 가장 적게 움직여 닿는 패턴의 거리 쪽으로 움직입니다.
- 예:
  - 경비 사수는 쏠 차례에 30m 밖이면 다가가고, 30m 안인데 안 보이면 찾아 다가갑니다.
  - 절단자는 기다리는 동안 2~4m를 지키다가, 공격할 차례가 되면 패턴이 닿는 거리(최대 2.3m)까지 다가갑니다.
  - 커스터가 플레이어 2m 앞에 있고 쿨다운이 끝난 패턴이 DashThrust(3~50m)뿐이면, 3m까지 물러난 뒤 돌진합니다. 지금 데이터에서는 쿨다운 0인 DoubleStrike(0~3m)가 늘 닿아 이 장면은 나오지 않습니다.
- 적정 거리를 사거리보다 넓게 잡아도, 공격할 차례가 되면 사거리 안으로 움직이므로 공격하지 못하고 서 있는 일은 없습니다.
- 패턴을 더하거나 발동 가능 거리를 바꿔도, 기다리는 동안의 움직임은 바뀌지 않습니다.
- 다가갈지는 2.1과 함께 0.5초마다 다시 정합니다. 다가가지 않는 동안 물러나기·좌우 걷기·제자리 사이는 거리가 바뀌는 대로 바로 바꿉니다.
- 걷는 속도는 MOV이고, MOV가 0인 적은 어느 줄이든 그 자리에 서 있습니다.
- 뒤가 벽이면 더 물러나지 못하며, 비스듬히 닿으면 벽을 따라 미끄러질 수 있습니다. 낭떠러지는 '낭떠러지'를 따릅니다.

### 2.3 패턴 후딜레이

패턴 후딜레이는 모든 패턴에 함께 걸리는 쿨다운입니다. 걸려 있는 동안에는 어떤 패턴도 시작하지 않으며(2.1), 움직임은 2.2를 따릅니다.

| 거는 때 | 비고 |
| - | - |
| 전투에 들어갈 때 | |
| 공격 패턴을 끝까지 마쳤을 때 | 피격 반응으로 끊기면 그 반응의 규칙을 따릅니다(움찔이면 걸지 않음). 회피 패턴이 끝난 뒤의 처리는 각 적 문서의 패턴 항목을 따릅니다. |
| 넉업·넉다운·그로기·처형 피격·페이즈 전환이 끝날 때 | 움찔 도중 이것으로 바뀌었을 때도 같습니다. |
| 조준을 취소할 때 | 조준이 있는 패턴만 |

- 길이는 걸 때마다 각 적 문서의 범위에서 무작위로 새로 정합니다. 이미 걸려 있을 때 다시 걸면 새로 정한 길이로 처음부터 셉니다. 둘을 더하지 않습니다.
- 움찔만 끝났을 때는 걸지 않습니다. 이미 걸려 있던 후딜레이는 움찔 중에도 흐르며, 움찔이 끝나도 남은 만큼 그대로 남습니다.
- 쿨다운처럼 게임 시간으로 흐릅니다([시간 규칙](<../../Docs/Design/System/시간 규칙.md>)).
- 반응형 패턴의 발동 조건 '패턴 후딜레이 중'은 후딜레이가 걸려 있고, 패턴 실행이나 피격 반응 등의 중이 아닌 때입니다. 커스터 Backstep은 끝까지 마치면 남은 후딜레이를 없애고 바로 2.1을 확인합니다. 피격 반응으로 끊기면 그 반응의 규칙을 따릅니다(움찔이면 남은 후딜레이가 그대로 남음). 이것은 지금의 "대기 없이 즉시 다음 패턴"과 같습니다.

### 2.4 비전투 복귀 시점

- 시야 상실에 따른 비전투 복귀(5초)는 패턴 실행이나 피격 반응 등의 중이 아닐 때 적용합니다. 지금의 "패턴 후딜레이 또는 다가가기 중"과 같은 범위입니다.

### 2.5 적마다 정하는 값

후딜레이 길이는 지금 값 그대로입니다. '알맞음'의 움직임은 지금 값 그대로이고, 샌드백 두 종만 실제 동작에 맞춰 제자리로 적습니다(MOV 0이라 동작은 같음). 적정 거리는 모든 적이 가지며 새로 정합니다.

| 적 | 후딜레이 길이 | 적정 거리 | '알맞음'의 움직임 | 적정 거리를 정한 근거 |
| - | - | - | - | - |
| 커스터 | 0.5~1.2초 | 0~10m | 좌우 걷기 | 근거리 패턴과 JumpCleave(0~10m)가 닿는 거리. 그보다 멀면 후딜레이 중에 걸어서 다가갑니다. |
| 절단자 | 0.6~1.0초 | 2~4m | 좌우 걷기 | 다수전에서 기다리는 절단자가 플레이어 바로 앞(공격 간격 1.2m)에 몰리지 않고 둘러싸도록 띄웁니다. 공격할 차례가 되면 패턴이 닿는 거리(0~2.3m)까지 다가갑니다. |
| 경비 사수 | 2.0~4.0초 | 8~30m | 제자리 | 가까운 쪽은 지금의 뒤로 걷는 거리, 먼 쪽은 사거리. 지금 동작과 같습니다. |
| 샌드백 | 없음(패턴 없음) | 0~1.5m | 제자리 | 공격 샌드백과 같게 둡니다. MOV 0이라 늘 서 있습니다. |
| 공격 샌드백 | 1초 | 0~1.5m | 제자리 | 내려찍기(0~1.5m)가 닿는 거리. MOV 0이라 늘 서 있습니다. |

### 2.6 달라지는 체감

- **경비 사수:** 맞은 뒤, 조준 취소 뒤, 넉다운 뒤에 쿨다운이 남아 있어도 다가오지 않습니다. 8m 안이면 물러나고, 그 밖이면 서서 기다립니다. 쿨다운이 끝나 쏠 차례인데 30m 밖이거나 안 보이면 다가갑니다.
- **절단자:**
  - 공격한 뒤 후딜레이(0.6~1.0초) 동안 2m까지 물러나고, 차례가 되면 다시 붙어 공격합니다.
  - 여러 마리가 있을 때, 기다리는 절단자는 2~4m에서 좌우로 걸으며 둘러쌉니다.
  - 후딜레이 중 플레이어가 4m 밖으로 빠지면 걸어서 따라옵니다.
  - 후딜레이 도중 맞으면, 남은 후딜레이가 지나야 공격합니다.
  - 모든 패턴이 쿨다운이면, 파고들지 않고 2~4m를 지키며 기다립니다.
- **커스터:**
  - 후딜레이 중 플레이어가 10m 밖이면, 좌우로 걷지 않고 걸어서 다가옵니다. 지금은 아레나 안에서 늘 좌우로 걷습니다.
  - 후딜레이 도중 맞으면, 남은 후딜레이가 지나야 공격합니다.
  - 모든 패턴이 쿨다운이면, 10m 안을 지키며 좌우로 걷습니다.
  - 쿨다운이 끝난 패턴이 근거리 패턴뿐인데 플레이어가 멀면, 그 패턴이 닿을 때까지 걸어서 다가옵니다.
- 패턴 실행 중 움찔하면, 움찔이 끝나자마자 공격할 수 있는 것은 지금과 같습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 1. 경비 사수: 4m에서 1초마다 움찔시켜도 다가오지 않습니다. 움찔 사이와 그 뒤로 8m까지 물러나고, 8m 밖에서는 서 있습니다.
- [ ] 2. 경비 사수: 조준 취소(시야 상실) 뒤 쿨다운이 남은 동안은 다가가지 않고 8~30m를 지킵니다. 쿨다운이 끝났는데 안 보이면 다가갑니다.
- [ ] 3. 절단자: 공격한 뒤 후딜레이 동안 2m 밖으로 물러나고, 후딜레이가 끝나면 다가와 공격합니다. 후딜레이 중 플레이어가 5m에 있으면 다가오되, 후딜레이가 끝나기 전에는 공격하지 않습니다.
- [ ] 4. 절단자: 모든 패턴이 쿨다운이면 2~4m 안에서 좌우로 걷고, 그보다 가까이 파고들지 않습니다.
- [ ] 5. 후딜레이 도중 움찔(절단자·커스터): 움찔이 끝나도 남은 후딜레이가 지날 때까지 공격하지 않습니다.
- [ ] 6. 패턴 도중 움찔(절단자): 움찔이 끝나고 조건이 맞으면 후딜레이 없이 공격합니다.
- [ ] 7. 넉다운이 끝나면 후딜레이가 걸려, 그 길이가 지나야 공격합니다.
- [ ] 8. 커스터 적정 거리: 후딜레이 중 플레이어가 15m에 있으면 다가오고, 5m에 있으면 좌우로 걷습니다.
- [ ] 9. 커스터 Backstep: 후딜레이 중 플레이어가 기본 공격을 시작하면 발동할 수 있고, 끝나면 바로 다음 패턴을 고릅니다.
- [ ] 10. 회귀: 시야 상실 5초 뒤 비전투 복귀, 경비 사수 첫 사격(발견 후 3.2~5.2초), 커스터·절단자·경비 사수·공격 샌드백의 패턴이 지금과 같습니다.
