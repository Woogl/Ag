# 에셋 로딩 범위 Spec

## 1. 개요 및 목적

지금은 게임을 켤 때 `Abilities.json`, `SpawnActors.json`, `Camera.json`이 가리키는 에셋(모든 캐릭터의 몽타주, 궁극기 컷신, 생성 액터 블루프린트, 카메라 셰이크)을 모두 읽고 게임이 끝날 때까지 메모리에 둡니다. 타이틀 화면에서도, 보스가 없는 스테이지에서도 보스의 몽타주와 검기가 메모리에 있습니다.

이 작업 뒤에는 지금 월드에 있는 캐릭터가 쓰는 것만 메모리에 둡니다. 플레이 규칙과 수치는 바뀌지 않으며, `DesignData` JSON의 형식도 그대로입니다.

## 2. 규칙

### 2.1 메모리에 두는 동안

| 에셋 | 메모리에 두는 동안 |
| - | - |
| 어빌리티의 몽타주(`Montage.Asset`), 사망 이어 재생 몽타주(`DeathMontage`) | 그 어빌리티를 가진 캐릭터가 월드에 있는 동안 |
| 어빌리티 Task가 직접 가리키는 에셋(궁극기 컷신) | 위와 같음 |
| 어빌리티가 생성하는 액터의 블루프린트(`SpawnActors.json`의 `Class`) | 그 액터를 생성하는 어빌리티를 가진 캐릭터가 월드에 있는 동안 |
| `Camera.json`의 카메라 셰이크 | 플레이어 캐릭터가 월드에 있는 동안 |

- 여러 캐릭터가 함께 쓰는 에셋(`Flinch`의 몽타주 등)은 그 에셋을 쓰는 캐릭터가 하나라도 있는 동안 둡니다.
- 캐릭터가 월드에서 사라지면 그 캐릭터만 쓰던 에셋은 엔진의 다음 가비지 컬렉션 때 메모리에서 내려갑니다. 레벨을 바꾸거나 다시 시작할 때도 같습니다.
- 타이틀 화면에는 캐릭터가 없으므로 위 에셋을 하나도 두지 않습니다.

### 2.2 읽는 시점

- 캐릭터가 월드에 들어올 때, 어빌리티를 부여하기 전에 그 캐릭터가 쓰는 에셋을 모두 읽고 나서 진행합니다. 그래서 어떤 행동도 첫 발동부터 모션·컷신·생성 액터가 바로 나옵니다.
- 레벨에 배치된 캐릭터와 레벨 시작 때 생기는 캐릭터(시뮬레이션 룸의 적)는 레벨을 여는 동안 읽습니다. 플레이 중에 처음 등장하는 종류의 캐릭터(테스트용 소환)는 생기는 프레임에 읽으므로 그 프레임이 길어질 수 있습니다.

### 2.3 바꾸지 않는 것

- 데이터 오류는 지금과 같은 때에 알립니다. 게임을 켤 때와 쿡에서 모든 어빌리티, 생성 액터 정의, 카메라 설정을 읽어 검사하고, 에디터에서 JSON을 저장하면 다시 검사합니다.
- 행동·아이템 아이콘은 지금처럼 그리는 위젯이 비동기로 읽습니다.
- 게임플레이 큐는 지금처럼 엔진이 처음 쓸 때 읽습니다.
- 에디터에서 JSON을 저장하면 다시 읽는 동작은 그대로입니다. 생성 액터 정의의 반영 시점은 어빌리티 정의와 같아져, 다음 발동부터 새 값을 씁니다. 카메라 설정의 반영 시점은 그대로입니다.

## 3. 완료 조건 (Acceptance Criteria)

- [x] 타이틀 화면: 테스트 창에서 가비지 컬렉션 뒤 `obj list`에 몽타주(`/Game/Animations/AM_*`), 생성 액터 블루프린트(`/Game/Projectiles`), 궁극기 컷신, 카메라 셰이크 클래스가 없습니다.
- [x] 시뮬레이션 룸에 샌드백만 둔 경우: 보스·절단자·경비 사수만 쓰는 몽타주와 생성 액터가 메모리에 없고, 플레이어와 샌드백이 쓰는 것은 있습니다.
- [x] 보스 스테이지에서 보스를 처치하고 Stage Clear까지 진행할 수 있습니다(회귀 시나리오 `stage_boss_clear`).
- [x] 플레이어의 모든 행동이 첫 발동부터 몽타주를 재생하고, 스킬 1~4의 생성 액터·궁극기 컷신·처형·회복병이 기존 회귀 시나리오대로 동작합니다.
- [x] 보스의 패턴(생성 액터를 쓰는 SwordWave, GroundSlam, 페이즈 전환 포함)과 적의 사망 이어 재생 몽타주가 기존과 같이 동작합니다.
- [x] 카메라 반응(패리, 피격 등)의 셰이크와 락온·처형 카메라가 기존과 같이 동작합니다.
- [x] 없는 몽타주 경로나 몽타주가 아닌 에셋을 적은 `Abilities.json`으로 게임을 켜면, 그 캐릭터가 월드에 없어도 켤 때 오류가 보입니다.
- [ ] 에디터에서 PIE 중에 `Abilities.json`·`SpawnActors.json`을 저장하면 다음 발동부터 새 값과 새 몽타주를 씁니다.
- [x] 쿡이 JSON이 가리키는 에셋을 모두 포함하고, 잘못된 경로나 다른 종류의 에셋을 가리키면 쿡이 실패합니다.
