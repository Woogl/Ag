# 투사체 비행 시간 고정 작업 명세

## 1. 개요 및 목적

경비 사수의 탄환을 패리하기 쉽게 만든다. 지금은 탄속이 고정이라, 사수와의 거리에 따라 예고(노랑 반짝임)부터 탄환이 닿기까지의 시간이 크게 달라진다. 초당 30m 기준으로 8m에서는 약 0.27초, 30m에서는 약 1.0초다. 가까우면 신호를 보고 반응할 수 없고, 멀면 너무 일찍 눌러 패리 구간(0.3초)을 놓친다.

이 작업은 일부 투사체를 **발사부터 목표에 닿기까지의 시간이 거리와 관계없이 같도록** 날아가게 한다. 플레이어는 '신호가 켜지면 약 0.45초 뒤에 닿는다'는 리듬 하나만 익히면 어느 거리에서든 신호를 보고 패리할 수 있다.

- **M3**에서 구현한다. 비행 시간과 속도 한도는 플레이테스트 초기 제안값이다.
- 적용 대상은 경비 사수의 탄환(`PistolBullet`)뿐이다. 검기·초승달 검기·충격파 같은 다른 투사체는 지금처럼 고정 탄속으로 날아간다.
- 탄환이 날아가는 모습이 거리마다 달라 보이는 점은 의도한 결과다. 가까운 사수의 탄은 느리고 먼 사수의 탄은 빠르다.

### 왜 0.45초인가

패리 구간은 가드를 새로 시작한 순간부터 0.3초다. 신호를 보고 가드를 누르기까지는 보통 0.25~0.3초가 걸린다고 가정한다. 이때 탄환이 신호 후 0.45초에 닿으면, 신호를 본 즉시 누른 플레이어의 패리 구간(신호 후 약 0.3~0.6초)에 도착이 들어온다. 더 빠르게 반응하는 플레이어는 조금 기다렸다 누르면 된다.

## 2. 플레이 규칙 및 수치

### 비행 시간 고정 투사체의 속도 정하기

| 항목 | 규칙 |
| - | - |
| 적용 조건 | 투사체 데이터에 비행 시간이 지정된 투사체만 적용한다. 지정하지 않은 투사체는 지금의 '속도 고정' 규칙을 그대로 따른다. |
| 비행 시간 | 경비 사수의 탄환은 0.45초다. 게임 시간 기준이며, 탄환의 이동과 같은 시간 기준을 쓴다. |
| 속도 계산 | 발사하는 순간 총구에서 예측 지점까지의 거리를 비행 시간으로 나눈 값을 그 탄환의 속도로 정한다. 거리는 고저차를 포함한 3차원 거리다. |
| 예측 지점 | 대상의 캡슐 중심 + 수평 이동 속도 × 비행 시간이다. 위아래 움직임을 예측하지 않고 서 있는 대상은 캡슐 중심을 겨누는 규칙은 [적 시스템](<../../Docs/Design/System/적 시스템.md>)의 '투사체 조준'과 같다. |
| 속도 한도 | 계산한 속도가 최소 15m/s보다 느리면 15m/s로, 최대 60m/s보다 빠르면 60m/s로 정한다. |
| 한도에 걸린 경우 | 한도로 정한 속도로 날아가며 비행 시간은 0.45초와 달라진다. 이때 예측 지점은 그 속도로 계산하는 지금의 '투사체 조준' 규칙을 따른다. 대상이 한도 속도의 탄환보다 빨라 해가 없으면 지금 거리로 센다. |
| 비행 중 | 속도는 발사 때 한 번 정하며 날아가는 동안 바꾸지 않는다. 대상이 움직이거나 멈춰도 속도와 방향은 그대로다. |

- 속도 한도 때문에(최소 15m/s × 0.45초) 사수와의 거리가 약 6.75m보다 가까우면 탄환이 0.45초보다 빨리 닿고, 약 27m보다 멀면 0.45초보다 늦게 닿는다. 사수의 적정 거리(8~30m) 안에서는 약 27m까지 모두 0.45초이고, 30m에서는 0.5초다.
- 사수가 쏘는 시점, 조준·반동·재장전 길이, 예고가 켜지는 시점(발사 순간)은 바꾸지 않는다.

### 패리하거나 반사할 때

- 패리하면 [린의 투사체 반사](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#투사체-반사>) 규칙을 지금과 같이 적용한다. 반사된 탄환은 날아오던 속도를 그대로 유지하므로, 속도를 다시 계산하지 않는다.
- 반사된 탄환은 발사자의 현재 위치로 방향을 바꾸고, 이동 거리를 다시 센다. 반사탄이 발사자에게 닿는 시간은 반사 지점의 거리와 유지한 속도로 정해진다.
- 가드로 막거나 회피하는 규칙, 벽에 닿으면 사라지는 규칙, 적중 판정은 바꾸지 않는다.

### 기존 기획서와의 관계

완료 후 아래를 덮어쓴다.

- [적 시스템](<../../Docs/Design/System/적 시스템.md>)의 '투사체 조준'과 '공격 예고'에 비행 시간 고정 투사체의 속도 규칙을 추가한다. '실제 도착 시점은 비행 거리와 속도에 따라 달라집니다'는 문장은 투사체 종류에 따라 다르다고 고친다.
- [일반 적 - 경비 사수](<../../Docs/Design/Content/일반 적 - 경비 사수.md>)의 '탄환' 표에서 '이동: 초당 30m로 직진'을 비행 시간 0.45초와 속도 한도로 바꾼다. 같은 절의 '정상 속도로 10m를 비행하는 데 약 0.33초' 문장도 고친다.

## 3. 완료 조건

### M3 · 비행 시간 고정

- [ ] 경비 사수 하나와 서 있는 플레이어를 8m, 14m, 20m, 27m 거리에 두고 사격하게 한다. 발사 순간부터 플레이어에게 닿을 때까지 걸린 시간이 모든 거리에서 약 0.45초(±0.05초)다. 이때 탄속은 8m에서 약 17.8m/s, 14m에서 약 31m/s, 20m에서 약 44m/s, 27m에서 60m/s다.
- [ ] 같은 조건에서 3m 거리일 때 탄속은 15m/s이고 약 0.2초에 닿는다. 40m 거리에서는 탄속이 60m/s이고 약 0.67초에 닿는다. 한도 때문에 0.45초가 되지 않는 경우다.
- [ ] 플레이어가 옆으로 달리는 중에 쏜 탄환은 수평 이동 속도 × 0.45초만큼 앞을 겨누며, 그대로 달리면 맞는다. 발사 뒤 멈추거나 방향을 바꾸면 빗나간다.
- [ ] 높이 3m의 성벽 위 사수가 바닥의 플레이어를 쏜다. 속도는 고저차를 포함한 거리로 정해져, 같은 수평 거리의 평지 사수와 도착 시간이 같다.
- [ ] 예고(노랑 반짝임)가 켜진 직후 가드를 눌러 신호를 보고 반응하는 방식으로 패리해 본다. 14m와 20m에서 모두 패리가 성공하고, 반사탄이 날아가 사수를 맞힌다.
- [ ] 패리해서 반사한 탄환의 속도가 날아오던 속도와 같고 바뀌지 않는다.
- [ ] 비행 시간을 지정하지 않은 투사체(검기, 초승달 검기, 충격파)는 속도와 도착 시간이 이전과 같다.
- [ ] 비행 시간과 속도 한도를 바꿔도 코드를 고치지 않고 데이터 수정만으로 반영된다.
