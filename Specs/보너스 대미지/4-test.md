# 보너스 대미지 검증 결과

## 1. 테스트 시나리오

- 시나리오 실행 명령: `python -I Scripts/ScenarioTest/run.py <scratchpad>/bonus_damage.py` (보스 스테이지, 적 AI 정지)
- 대상은 보스(DEF 100)입니다. 린의 ATK가 100이라 DEF 비율이 0.5이고, 1타(HP·PP 배율 1)의 기본 HP 감소량은 50입니다.
- 넉업은 `Event.Hit.KnockUp` 이벤트, 그로기는 A6을 빼고 `AgGroggy`로 만들었습니다. A6은 PP를 1로 낮춘 뒤 실제 타격으로 그로기를 일으켰습니다.
- 판정 프레임의 보스 태그(`State.Groggy`·`State.Airborne`)와 보스 정면에서 플레이어까지의 각도(135° 이상이면 등 쪽)를 함께 확인했습니다.

## 2. 결과

- 빌드: `AgEditor Win64 Development` 성공 (JSON 이름을 `...BonusDamage`로 바꾼 뒤 다시 빌드)
- 판정: 12항목 모두 통과, 창 로그에 `LogAg: Error` 없음

| 조건 | 결과 | 기대 |
| - | - | - |
| A1 정면 지상 1타 | HP 50, PP 50, 0° | 50 |
| A3 등 뒤 지상 1타 | HP 55, PP 50, 180° | 55, PP 그대로 |
| A4 넉업 중 정면 1타 | HP 55, PP 50, 공중 | 55, PP 그대로 |
| A6 그로기를 시작시킨 1타 | HP 50, 그 타격으로 그로기 시작 | 50 |
| A2 그로기 정면 1타 | HP 75 | 75 |
| A5 그로기 + 등 뒤 + 넉업 중 1타 | HP 85, 공중, 180° | 85 |
| A6 그로기 정면 스킬(띄움, HP 배율 1.2) | HP 90, 그 뒤 보스가 떠오름 | 90 (에어리얼 없음) |
| A8 처형(그로기 대상, 배율 1.5·4.5) | HP 75, 225 (처형 상태) | 75, 225 |
| A9 보스 DoubleStrike가 플레이어 등을 침 | 플레이어 HP 133, 187 (`AM_Flinch:Back`) | 133, 187 (보너스 없음) |
| A10 창에 읽힌 규칙 값 | 0.5, 0.1, 0.1 | `CombatRules.json` 값 |

- A7(PP 감소량 그대로)은 A3·A4의 PP 50으로 확인했습니다.
- A10은 `DesignData` JSON을 고치지 않고, 창에 읽힌 값이 JSON 값과 같고 측정한 감소량이 그 값으로 계산된 것으로 확인했습니다. 값을 바꿔 다시 읽는 확인은 하지 않았습니다.
