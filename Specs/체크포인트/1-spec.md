# 체크포인트 Spec

## 1. 개요 및 목적

던전 안에 체크포인트를 놓아 전투 구간을 나눕니다. 플레이어는 체크포인트에서 휴식해 HP와 회복병을 채웁니다.

휴식하면 체크포인트를 지나기 전에 처치한 적도 모두 되살아납니다. 회복을 얻는 대신 구간을 다시 정리해야 하는 대가를 둡니다. 휴식은 닿기만으로 일어나지 않고 F 상호작용으로만 일어나므로, 지나가다 스치는 것만으로 적이 되살아나지는 않습니다.

## 2. 플레이 규칙 및 수치

### 2.1 체크포인트

체크포인트는 상호작용 장치입니다. 장치에 공통으로 적용하는 범위, 대상 선택, 입력 규칙은 [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)의 '상호작용'을 따릅니다.

- 안내에 적는 행동은 '휴식'입니다.
- 안내 지점은 체크포인트 중심의 바닥에서 1.2m 높이입니다. 상호작용 범위는 안내 지점을 중심으로 한 반지름 2m의 구입니다.
- 체크포인트는 항상 쓸 수 있는 상태입니다.
- 같은 체크포인트에서 몇 번이든 휴식할 수 있습니다.
- 체크포인트는 전투 공간에 두지 않습니다. 놓는 자리는 던전별 레벨디자인 기획서에서 정합니다.
- 체크포인트의 외형은 휴식 전후로 바뀌지 않으며, 휴식할 때 따로 재생하는 연출은 없습니다. 장치 상호작용이므로 린의 모션도 없습니다.

### 2.2 휴식

F를 누르면 휴식하며, 아래 일이 한 번에 일어납니다.

1. 린의 상태를 아래와 같이 바꿉니다.

| 항목 | 휴식할 때 |
| - | - |
| HP | MaxHP까지 채웁니다. |
| 회복병 | 최대 보유 수(3)까지 채웁니다. |
| 쿨다운 | 모든 행동의 남은 쿨다운을 없앱니다. |
| MP | 그대로 둡니다. |
| UP (궁극기 게이지) | 그대로 둡니다. |

2. 레벨의 적을 2.3에 따라 처음 상태로 되돌립니다.

### 2.3 적을 처음 상태로 되돌리기

휴식할 때 레벨에 처음 배치된 모든 적을 처음 상태로 되돌립니다.

- 처치한 적은 되살아납니다.
- 살아 있던 적도 다쳤거나 자리를 옮겼는지와 관계없이 되돌립니다.
- 처음 상태는 레벨을 처음 열었을 때와 같습니다. HP는 MaxHP, PP와 그로기는 처음 값, 페이즈는 첫 페이즈, 남은 쿨다운은 없으며, 처음 배치된 자리에서 처음 배치된 방향을 보고 비전투 상태입니다.
- 보스는 처치하면 되살아나지 않습니다. 보스가 사망하면 Stage Clear이므로([게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Dungeon') 실제로 보스는 언제나 살아 있는 채로 되돌립니다.

### 2.4 되돌리지 않는 것

휴식해도 아래는 그대로 둡니다.

- 열어 둔 성문 같은 장치의 상태
- 열어 본 보물상자와 그 보물상자에서 얻은 아이템. 연 보물상자는 다시 닫히지 않고 아이템도 다시 나오지 않습니다. (이번 작업에는 보물상자가 없으므로 규칙으로만 둡니다.)

### 2.5 문구

| 쓰는 곳 | 문구 |
| - | - |
| 상호작용 안내의 행동 | 휴식 |

### 2.6 레벨을 열 때의 로딩 화면

미니던전 레벨을 열면 레벨에 배치된 적이 모두 등장할 때까지 로딩 화면을 보여 줍니다. Restart로 다시 시작할 때도 같습니다.

- 로딩 화면은 화면 전체를 검은색으로 덮습니다. 문구와 진행 표시는 없습니다.
- 로딩 화면이 떠 있는 동안에는 조작과 Esc를 받지 않습니다.
- 적이 모두 등장하면 로딩 화면을 닫고, 그때부터 조작할 수 있습니다.
- 시뮬레이션 룸은 바뀌지 않습니다.

### 2.7 기존 기획서와의 관계

- [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>): '상호작용'의 장치 예시에 체크포인트를 더하고, 장치를 정의한 문서로 체크포인트 규칙을 가리킵니다.
- [게임 플로우](<../../Docs/Design/System/게임 플로우.md>): 'Dungeon'의 "레벨이 열리면 … 바로 조작할 수 있습니다"를 2.6에 맞춰 고칩니다.
- [UI 시스템](<../../Docs/Design/System/UI 시스템.md>): 바뀌지 않습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 체크포인트 범위에 들어가면 '휴식' 안내가 뜨고, 닿기만 해서는 회복도 적 부활도 일어나지 않는다.
- [ ] F를 누르면 HP와 회복병이 최대로 차고, 쿨다운이 초기화되며, MP와 UP는 그대로다.
- [ ] 휴식하면 처치한 일반 적이 되살아나고, 살아 있던 적도 처음 자리·방향·HP·비전투 상태로 돌아간다.
- [ ] 휴식해도 열어 둔 성문은 열린 채로 남는다.
- [ ] 미니던전 레벨을 열거나 Restart 하면 로딩 화면이 뜨고, 닫힌 뒤에는 배치된 적이 모두 있으며 조작할 수 있다.

## 4. 플레이해 보고 조정할 값

- 상호작용 범위(반지름 2m)와 안내 지점 높이(1.2m)

## 5. 프로그래머 확인 요청

기획에서는 규칙만 정했고, 아래는 구현 방식에 따라 결과가 달라지거나 새 구조가 필요해 보이는 부분입니다. 2-plan에서 방식을 정해 주세요.

- **레벨을 다시 불러오지 않는 되돌리기:** 지금 Restart는 레벨을 처음부터 다시 불러와 모든 상태를 초기화합니다. 휴식은 적과 린만 되돌리고 열어 둔 성문은 남겨야 합니다(2.4).
- **적 전체를 처음 상태로 되돌리기:** 처치되어 없어진 적까지 처음 배치된 종류·자리·방향으로 다시 세워야 합니다(2.3). 적 그룹, 정찰 지점 같은 배치 정보도 처음과 같아야 합니다.
- **쿨다운 일괄 초기화:** 모든 행동의 남은 쿨다운을 없애는 처리가 필요합니다(2.2).
- **체크포인트 에셋:** 외형은 기획에서 따로 정하지 않았으니 임시 메시로 충분합니다.
