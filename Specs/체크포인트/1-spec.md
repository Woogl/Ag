# 체크포인트 Spec

## 1. 개요 및 목적

던전 안에 체크포인트를 놓아 전투 구간을 나눕니다. 플레이어는 체크포인트에서 휴식해 HP와 회복병을 채우고, 휴식한 뒤 사망하면 던전 처음이 아니라 마지막으로 휴식한 체크포인트에서 다시 시작할 수 있습니다.

휴식하면 체크포인트를 지나기 전에 처치한 적도 모두 되살아납니다. 회복과 다시 시작 지점을 얻는 대신 구간을 다시 정리해야 하는 대가를 둡니다. 휴식은 닿기만으로 일어나지 않고 F 상호작용으로만 일어나므로, 지나가다 스치는 것만으로 적이 되살아나지는 않습니다.

## 2. 플레이 규칙 및 수치

### 2.1 체크포인트

체크포인트는 상호작용 장치입니다. 장치에 공통으로 적용하는 범위, 대상 선택, 입력 규칙은 [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)의 '상호작용'을 따릅니다.

- 안내에 적는 행동은 '휴식'입니다.
- 상호작용 범위는 체크포인트 중심에서 반지름 2m, 바닥에서 2.5m 높이까지의 원기둥입니다. 안내 지점은 체크포인트 중심의 바닥에서 1.2m 높이입니다.
- 체크포인트는 항상 쓸 수 있는 상태입니다.
- 같은 체크포인트에서 몇 번이든 휴식할 수 있습니다.
- 체크포인트는 전투 공간에 두지 않습니다. 놓는 자리는 던전별 레벨디자인 기획서에서 정합니다.
- 다시 시작할 때 린이 서는 위치와 바라보는 방향은, 언리얼 에디터에서 체크포인트를 놓은 위치와 체크포인트의 방향(에디터의 화살표가 가리키는 방향)입니다.
- 체크포인트의 외형은 휴식 전후로 바뀌지 않으며, 휴식할 때 따로 재생하는 연출은 없습니다. 장치 상호작용이므로 린의 모션도 없습니다.

### 2.2 휴식

F를 누르면 휴식하며, 아래 일이 한 번에 일어납니다.

1. 이 체크포인트를 다시 시작 지점으로 기록합니다. 다시 시작 지점은 마지막으로 휴식한 체크포인트 하나뿐입니다. 닿기만 하고 휴식하지 않은 체크포인트는 다시 시작 지점이 되지 않습니다.
2. 린의 상태를 아래와 같이 바꿉니다.

| 항목 | 휴식할 때 |
| - | - |
| HP | MaxHP까지 채웁니다. |
| 회복병 | 최대 보유 수(3)까지 채웁니다. |
| 쿨다운 | 모든 행동의 남은 쿨다운을 없앱니다. |
| MP | 그대로 둡니다. |
| UP (궁극기 게이지) | 그대로 둡니다. |

3. 레벨의 적을 2.3에 따라 처음 상태로 되돌립니다.
4. 화면에 "체크포인트에서 휴식하셨습니다"를 출력합니다.

### 2.3 적을 처음 상태로 되돌리기

휴식할 때와 체크포인트에서 다시 시작할 때, 레벨에 처음 배치된 모든 적을 처음 상태로 되돌립니다.

- 처치한 적은 되살아납니다.
- 살아 있던 적도 다쳤거나 자리를 옮겼는지와 관계없이 되돌립니다.
- 처음 상태는 레벨을 처음 열었을 때와 같습니다. HP는 MaxHP, PP와 그로기는 처음 값, 페이즈는 첫 페이즈, 남은 쿨다운은 없으며, 처음 배치된 자리에서 처음 배치된 방향을 보고 비전투 상태입니다.
- 보스는 처치하면 되살아나지 않습니다. 보스가 사망하면 Stage Clear이므로([게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Dungeon') 실제로 보스는 언제나 살아 있는 채로 되돌립니다.

### 2.4 되돌리지 않는 것

휴식하거나 체크포인트에서 다시 시작해도 아래는 그대로 둡니다.

- 열어 둔 성문 같은 장치의 상태
- 열어 본 보물상자와 그 보물상자에서 얻은 아이템. 연 보물상자는 다시 닫히지 않고 아이템도 다시 나오지 않습니다. (이번 작업에는 보물상자가 없으므로 규칙으로만 둡니다.)

### 2.5 사망과 다시 시작

플레이어가 사망하면 지금처럼 스테이지 결과 연출이 재생되고 Game Over UI 창이 뜹니다.

Game Over UI 창과 일시정지 메뉴의 System 탭에 'Restart from Checkpoint' 버튼을 더합니다.

| 버튼 | 실행 결과 |
| - | - |
| Restart | 지금처럼 던전 레벨을 처음부터 다시 시작합니다. 휴식 기록도 지웁니다. |
| Restart from Checkpoint | 마지막으로 휴식한 체크포인트에서 다시 시작합니다. 휴식한 체크포인트가 없으면 버튼을 표시하지 않습니다. |

- Game Over UI 창의 버튼은 위에서부터 Restart from Checkpoint, Restart, Return to Title, Quit 순서입니다. Restart from Checkpoint 버튼이 있으면 처음 선택된 버튼은 이 버튼이고, 없으면 지금처럼 Restart입니다.
- 일시정지 메뉴 System 탭의 버튼은 위에서부터 Resume, Restart from Checkpoint, Restart, Return to Title, Quit 순서입니다. 처음 선택된 버튼은 지금처럼 Resume입니다.

체크포인트에서 다시 시작하면 아래와 같이 됩니다.

- 린은 체크포인트의 위치에서 체크포인트의 방향을 보고 서며, 바로 조작할 수 있습니다.
- 린의 상태는 아래와 같습니다. MP만 휴식과 다릅니다.

| 항목 | 다시 시작할 때 |
| - | - |
| HP | MaxHP까지 채웁니다. |
| 회복병 | 최대 보유 수(3)까지 채웁니다. |
| 쿨다운 | 모든 행동의 남은 쿨다운을 없앱니다. |
| MP | 0으로 되돌립니다. |
| UP (궁극기 게이지) | 그대로 둡니다. |

- 적은 2.3에 따라 처음 상태로 되돌리고, 2.4의 것은 그대로 둡니다.
- 다시 시작해도 휴식 기록은 그대로입니다.

휴식 기록은 지금 있는 던전 레벨 안에서만 유지합니다. Restart, Return to Title, Quit로 레벨을 떠나면 지워집니다.

### 2.6 문구

| 쓰는 곳 | 문구 |
| - | - |
| 상호작용 안내의 행동 | 휴식 |
| 휴식했을 때 | 체크포인트에서 휴식하셨습니다 |
| 버튼 | Restart from Checkpoint |

휴식 문구는 화면 가운데에서 위쪽(화면 높이의 위에서 약 1/4 지점)에 글자 Medium으로 표시합니다. 2초 동안 표시한 뒤 0.5초 동안 서서히 사라집니다. 문구가 떠 있는 동안 새 문구가 나오면 앞의 문구를 바로 지우고 새 문구를 처음부터 표시합니다.

### 2.7 기존 기획서와의 관계

- [게임 플로우](<../../Docs/Design/System/게임 플로우.md>): 'Dungeon'의 버튼 표와 'Game Over'에 Restart from Checkpoint와 2.5의 다시 시작을 더합니다. 'Stage Clear'와 시뮬레이션 룸은 바뀌지 않습니다.
- [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>): '상호작용'의 장치 예시에 체크포인트를 더하고, 장치를 정의한 문서로 체크포인트 규칙을 가리킵니다.
- [UI 시스템](<../../Docs/Design/System/UI 시스템.md>): 일시정지 메뉴와 Game Over UI 창에 버튼을 더하고, 휴식 문구를 표시하는 방식을 더합니다.
- 전투 통계: 바뀌지 않습니다. 사망하면 적이 모두 전투에서 빠져 그 전투는 '사망'으로 기록이 끝나므로, 다시 시작한 뒤의 전투는 새 기록입니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 체크포인트 범위에 들어가면 '휴식' 안내가 뜨고, 닿기만 해서는 회복도 적 부활도 일어나지 않는다.
- [ ] F를 누르면 HP와 회복병이 최대로 차고, 쿨다운이 초기화되며, MP와 UP는 그대로이고, "체크포인트에서 휴식하셨습니다"가 뜬다.
- [ ] 휴식하면 처치한 일반 적이 되살아나고, 살아 있던 적도 처음 자리·방향·HP·비전투 상태로 돌아간다.
- [ ] 휴식해도 열어 둔 성문은 열린 채로 남는다.
- [ ] 휴식하지 않고 사망하면 Game Over UI 창에 Restart from Checkpoint 버튼이 없고, Restart는 던전 처음부터 시작한다.
- [ ] 휴식한 뒤 사망해 Restart from Checkpoint를 누르면, 마지막으로 휴식한 체크포인트의 위치·방향에서 시작하고, HP·회복병·쿨다운은 채워지고 MP는 0, UP는 그대로이며, 적은 처음 상태로 돌아간다.
- [ ] 체크포인트 A에서 휴식하고 B에 닿기만 한 뒤 사망하면 A에서 다시 시작한다.
- [ ] 휴식한 뒤 Restart를 누르면 던전 처음부터 시작하고, 이후 사망하면 Restart from Checkpoint 버튼이 없다.
- [ ] 휴식한 뒤 일시정지 메뉴의 Restart from Checkpoint로도 같은 다시 시작이 된다.

## 4. 플레이해 보고 조정할 값

- 상호작용 범위(반지름 2m, 높이 2.5m)와 안내 지점 높이(1.2m)
- 문구의 위치, 표시 시간(2초), 사라지는 시간(0.5초)

## 5. 프로그래머 확인 요청

기획에서는 규칙만 정했고, 아래는 구현 방식에 따라 결과가 달라지거나 새 구조가 필요해 보이는 부분입니다. 2-plan에서 방식을 정해 주세요.

- **레벨을 다시 불러오지 않는 되돌리기:** 지금 Restart는 레벨을 처음부터 다시 불러와 모든 상태를 초기화합니다. 휴식과 체크포인트에서 다시 시작하기는 적과 린만 되돌리고 열어 둔 성문과 휴식 기록은 남겨야 합니다(2.4, 2.5). 레벨을 다시 불러온다면 이 상태들을 넘겨받는 방법이 필요합니다.
- **적 전체를 처음 상태로 되돌리기:** 처치되어 없어진 적까지 처음 배치된 종류·자리·방향으로 다시 세워야 합니다(2.3). 적 그룹, 정찰 지점 같은 배치 정보도 처음과 같아야 합니다.
- **쿨다운 일괄 초기화:** 모든 행동의 남은 쿨다운을 없애는 처리가 필요합니다(2.2).
- **새 UI 요소:** 화면 알림 문구는 지금 UI 시스템에 없는 요소입니다(2.6). 일시정지 메뉴와 Game Over UI 창의 버튼은 휴식 기록에 따라 보이거나 숨겨야 합니다(2.5).
- **체크포인트 에셋:** 다시 시작 위치·방향을 에디터에서 놓은 체크포인트의 위치와 화살표 방향으로 쓰므로, 배치할 때 방향이 보여야 합니다(2.1). 외형은 기획에서 따로 정하지 않았으니 임시 메시로 충분합니다.
