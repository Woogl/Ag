# 적 선택 모델 표시 검증 결과

## 1. 테스트 시나리오

- 시나리오 실행 명령: `python -I Scripts/ScenarioTest/run.py --map /Game/Maps/LV_SimulationRoom <시나리오.py>` (일회성 시나리오라 저장소에 두지 않음)
- 시나리오 내용: 적 선택 화면이 열린 채 시작 → 빈 카드 촬영(`shot showui`) → 자리 1 ~ 5에 커스터, 절단자, 경비 사수, 샌드백, 공격 샌드백을 고름(콤보 박스 선택 + 사람의 선택과 같은 알림으로 화면 갱신까지) → 카드 촬영, 렌더 타깃 저장 → 1초 뒤 렌더 타깃 다시 저장 → 자리 2를 Empty로 → 다시 촬영 → 적 선택 화면을 숨기고 UI 없이 아레나 촬영

## 2. 결과

- 빌드: AgEditor Development 성공 (메시 범위 맞춤으로 고친 뒤 다시 빌드, 성공)
- 판정: 통과 (`Saved/ScenarioTest/slot1_20261103-195836.json`), 창 로그에 `LogAg: Error` 없음

| 완료 조건 | 결과 | 근거 |
| - | - | - |
| 1. 카드 5장, 모두 '+'와 Empty, Start 흐림 | 통과 | 빈 카드 촬영. 자리 5개 확인 |
| 2. 고른 적의 모델(무기 포함)과 이름, 전신이 높이를 거의 채움 | 통과 | 카드 촬영과 렌더 타깃 5장. 커스터·공격 샌드백의 할버드, 절단자의 칼, 경비 사수의 총이 보임. 머리 위와 발 아래 여백이 비슷함 |
| 3. 화면이 떠 있는 동안 대기 모션 | 통과 | 게임 멈춤 상태에서 1초 간격 렌더 타깃 5장이 모두 바뀜 |
| 4. 같은 적 여러 자리, 한 자리 Empty | 통과 | 자리 2만 '+'와 Empty로 바뀌고 다른 카드 그대로, 표시 액터 수 유지(5) |
| 5. 아레나에 모델·그림자 없음 | 통과 | UI 없이 찍은 아레나에 표시용 캐릭터와 그림자가 없음 |
| 6. 보스 제한, Start 흐림, 방향키, Esc | 일부 | Start 흐림만 확인. 목록 채우기·잠금 코드는 바뀌지 않았고, 테스트 창은 키 입력을 받지 않아 방향키·Esc·열린 목록 모양은 사람이 확인 |
| 7. Start 뒤 전투, 결과, Return to Title | 확인 안 함 | 배치·결과 코드는 바뀌지 않음. 표시용 캐릭터는 레벨을 다시 로드할 때 함께 사라짐 |

- 테스트 중 고친 것: 캡슐 높이로 맞추면 메시를 1.2배로 키운 보스의 머리가 잘려, 메시 범위로 맞추게 바꿈. 여유 배율 `BP_EnemyPreview` 1.2.
