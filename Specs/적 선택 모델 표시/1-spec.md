# 적 선택 모델 표시 작업 명세 (Spec)

## 1. 개요 및 목적

- 시뮬레이션 룸의 적 선택 화면에서 배치 자리마다 고른 적의 모델을 카드로 보여 줍니다. 이름만 보고 고르던 적을 모습으로 확인하고 고르게 합니다.
- [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '적 선택 화면'에서 드롭다운의 닫힌 모양과 배치를 아래 내용으로 바꿉니다. 화면을 여는 때, 버튼의 실행 결과, 배치 규칙은 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Simulation Room' 그대로입니다.

## 2. 플레이 규칙 및 수치

### 2.1 적 선택 화면 (UI 시스템 '적 선택 화면'의 바뀌는 줄)

- 제목 아래 가운데에 배치 자리 1 ~ 5의 적 카드를 왼쪽부터 자리 번호 순서로 가로로 나란히 놓습니다. 카드는 300 × 450px, 카드 사이 간격은 24px입니다. 이 순서는 플레이어 시작 지점에서 본 배치 자리의 왼쪽부터 오른쪽 순서와 같습니다.
- 카드 아래 가운데에 Start, Return to Title 버튼을 가로로 놓습니다. 버튼의 글자는 Large입니다.
- 처음 선택된 것은 배치 자리 1의 카드입니다.
- 제목, 뒤의 게임 화면, 일시정지, 마우스 커서와 입력, Start 흐림은 지금 규칙 그대로입니다.

### 2.2 적 카드

적 카드는 그 자리의 적 드롭다운이 닫혀 있을 때의 모양입니다. 카드를 실행하면 지금처럼 목록을 엽니다. 목록의 항목, 순서, 보스 제한, 같은 적을 여러 자리에 고르는 규칙과 UI 조작은 지금 규칙 그대로입니다.

- 카드의 바탕은 검은색입니다. 카드 아래쪽 60px은 이름 칸이고, 그 위가 모델 칸입니다.
- 고른 적이 있으면 모델 칸에 그 적의 모델을, 이름 칸 가운데에 그 적의 이름을 Large로 표시합니다.
- 고른 적이 없으면 모델 칸 가운데에 '+'를 전용 글자 Size 96으로, 이름 칸 가운데에 'Empty'를 Large로 표시합니다. 화면을 열 때는 모든 카드가 이 모양입니다.
- 자리의 적을 바꾸면 그 카드의 모델과 이름이 바로 바뀝니다.

**모델**

- 모델은 게임에서와 같은 모습으로, 들고 있는 무기도 함께 보입니다.
- 모델은 카메라를 정면으로 바라보고 서 있으며, 머리부터 발끝까지 전신이 모델 칸 안에 들어옵니다. 적마다 키가 달라도 전신이 모델 칸의 높이를 거의 채우도록 크기를 맞춥니다.
- 모델은 그 적이 서 있을 때의 대기 모션을 반복합니다. 화면이 떠 있어 게임이 멈춰 있는 동안에도 움직입니다.
- 모델은 레벨의 조명과 관계없이 늘 같은 밝기로, 앞쪽에서 비추는 빛을 받아 형태와 무기가 또렷이 보입니다. 모델 뒤는 카드 바탕 그대로 검은색입니다.
- 카드에 보이는 모델은 아레나와 뒤의 게임 화면에 나타나지 않고, 전투에 끼어들지 않습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시나리오 1: 스테이지 선택 화면에서 Simulation Room에 들어오면 적 선택 화면에 카드 5장이 가로로 나란히 있고, 모두 '+'와 Empty를 표시하며, 배치 자리 1의 카드가 선택되어 있다.
- [ ] 시나리오 2: 카드를 실행해 목록에서 적을 고르면 그 카드에 그 적의 모델(무기 포함)과 이름이 나온다. 보스, 일반 적 2종, 샌드백 2종 모두 전신이 모델 칸에 잘리지 않고 들어오며 높이를 거의 채운다.
- [ ] 시나리오 3: 화면이 떠 있는 동안 모델이 대기 모션으로 움직인다.
- [ ] 시나리오 4: 같은 적을 여러 자리에 고르면 그 카드들 모두에 모델이 나온다. 한 자리를 Empty로 바꾸면 그 카드만 '+'와 Empty로 돌아가고 다른 카드의 모델은 그대로 있다.
- [ ] 시나리오 5: 뒤의 게임 화면(아레나)에 카드의 모델이나 그 그림자가 보이지 않는다.
- [ ] 시나리오 6: 보스 제한, 모든 자리가 Empty일 때 Start 흐림, 방향키 이동, Esc로 목록 닫기가 지금처럼 동작한다.
- [ ] 시나리오 7: Start 뒤에는 고른 적만 배치되고 전투, Stage Clear, Game Over가 지금과 같다. Return to Title도 지금과 같다.
