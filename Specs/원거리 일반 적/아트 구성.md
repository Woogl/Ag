# 원거리 일반 적 — 경비 사수 아트 구성

상태: 보유 애니메이션 기반의 초안입니다. 에셋 파일과 기존 GIF 목록을 확인했으며, 실제 적에 조합·적용한 결과는 아닙니다. 플레이 규칙과 시간은 [작업 명세](<1-spec.md>)를 따릅니다.

## 외형

- 인간 크기의 마네킹과 권총 1자루를 기본으로 합니다. 권총 메시 자체는 아직 선정하지 않았습니다.
- 가벼운 장비의 사수라는 인상을 목표로 하며, 첫 구현에 전용 캐릭터 모델 제작을 요구하지 않습니다.
- 조준할 때 손·권총이 플레이어를 향하고, 재장전할 때는 총을 내리고 탄창을 다루는 동작이 읽혀야 합니다.

## 보유 모션과 사용안

권총 모션 위치는 `Content/Characters/Mannequins/Anims/Pistol`입니다. 해당 폴더에는 시퀀스 27개, 사격 몽타주 1개, 에임 오프셋 1개가 있습니다. 주요 권총 시퀀스는 프로젝트의 `SK_Mannequin`을 참조합니다.

원본 길이는 [기본 시퀀스 GIF 목록](<../../Docs/Art/GIF/Base/README.md>)의 값입니다. 실제 패턴 구간 길이를 뜻하지 않습니다.

| 용도 | 보유 에셋 | 원본 길이 | 사용안 |
| - | - | - | - |
| 조준 자세 | `MF_Pistol_Idle_ADS` | 9.033초 | 반복 자세를 바탕으로 조준 전조 구성 |
| 발사 반동 | `MM_Pistol_Fire` | 0.667초 | 조준 자세 위에 반동을 더함. 단독 전신 사격 모션으로 사용하지 않음 |
| 재장전 | `MM_Pistol_Reload` | 2.000초 | 매 사격 뒤 빈틈을 보여 주는 후딜 동작 |
| 접근·정찰·복귀·좌우 걷기 | `MF_Pistol_Walk_*` | 방향별 상이 | 공통 적 이동 규칙에 맞춰 필요한 이동 방향 사용 |
| 상하 조준 | `AO_Pistol` 및 `Aim` 폴더의 자세 | 자세별 상이 | 고저차 대응 후보. 실제 보정 범위와 총구 정렬 확인 필요 |
| 무기 준비 | `MM_Pistol_Equip` | 1.400초 | 보유 확인만 함. 기본 사격마다 반복하는 전조로 채택하지 않음 |

- `MM_Pistol_Fire`에는 메시 공간 회전 애디티브 설정이 있습니다. 최종 조준 자세 위에 적용한 모습을 확인해야 합니다.
- `MM_Pistol_Fire_Montage`는 원본 참고용입니다. 존재만으로 AG의 사격 패턴·발사 시점·예고가 구성되어 있다고 보지 않습니다.
- 피격·넉업·넉다운은 [아트 표현 사양](<../../Docs/Art/아트 표현 사양.md>)의 공통 모션을 사용합니다. 그로기·처형 피격은 기존 인간형 적 표현을 재사용하는 방향으로, 권총을 든 손과 린의 동작이 충돌하지 않는지 확인합니다.
- 기다림과 조준이 구분되도록 대기 시 총을 낮추고, 조준 전조에서 총을 겨누는 연결이 필요합니다. 별도의 총 내린 대기 모션은 아직 선정하지 않았습니다.

## 효과와 사운드

- 발사 예고는 공통 패리 예고를 사용합니다. 전조와 탄환 도착의 시간차는 작업 명세를 따릅니다.
- 탄환은 작은 실제 총알처럼 알아보기 어렵게 만들지 않고, 발광하는 탄체와 짧은 궤적으로 이동을 읽을 수 있게 합니다. 판정 크기를 효과 크기에 맞춰 임의로 키우지 않습니다.
- 사격음과 재장전 소리를 구분하여 공격이 끝났다는 것을 전달합니다. 사용할 사운드·권총 메시·탄환 효과는 선정 전입니다.
