# 원거리 일반 적 — 경비 사수 작업 명세 (Spec)

상태: 구현 중. 플레이 검증 전입니다.

## 1. 개요 및 목적

[마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)의 미니던전에 사용할 인간 크기의 권총 원거리 일반 적 1종을 추가합니다. 멀리서 존재감을 주되 공격을 자주 끊지 않고, 사격을 피하며 접근한 플레이어가 쉽게 제압할 수 있게 합니다.

핵심 흐름은 '조준을 확인한다 → 한 발을 피하거나 막는다 → 긴 빈틈에 접근해 처치한다'입니다. 단발 사격만 사용하며, 연사·강공격·가드 불가 공격·근접 공격·회피 공격은 없습니다. 매 발사 뒤 재장전하는 동작을 보여 주고 충분히 기다립니다.

### 작업 범위

- 일반 적 1종의 스탯, 시야, 이동, 기본 사격, 피격, 그로기, 처형 피격, 사망을 정의합니다.
- 기존 권총 애니메이션을 사용합니다. 모션과 리소스 확인 범위는 [아트 구성](<아트 구성.md>)을 따릅니다.
- 탄창 수·잔탄·빈 총 발사·탄약 보급은 관리하지 않습니다. 재장전은 단발 사격 패턴의 후딜 동작입니다.
- 여러 사수의 공격 순번을 배분하는 기능은 포함하지 않습니다. 개체마다 대기 시간을 따로 뽑습니다.
- 던전의 배치 위치·개체 수·승리 조건은 레벨디자인과 게임 흐름 기획에서 정합니다.

## 2. 플레이 규칙 및 수치

### 2.1 개요와 스탯

| 항목 | 값 |
| - | - |
| 이름 | 경비 사수 — 가칭 |
| 분류·무기 | 인간형 원거리 일반 적, 권총 1자루 |
| 크기 | 무기를 제외한 직립 신장 기준 플레이어와 같은 크기 |
| 강인도 | 소형 |
| 페이즈 | 1개. HP에 따른 패턴 변경 없음 |
| HP / MaxHP | 300 / 300 |
| SP / MaxSP, MP / MaxMP, UP / MaxUP | 각각 0 / 0. 사용하지 않음 |
| PP / MaxPP | 200 / 200 |
| ATK | 90 |
| DEF | 0 |
| MOV | 200cm/s. 접근·정찰·복귀·좌우 걷기에 사용 |
| HP 회복 | 자동 회복 없음 |
| PP 리젠 | 초당 15. 회복 시작 시점은 전투 시스템을 따름 |
| Yaw 회전 속도 | 초당 360° |

- 접근 후 기본 공격으로 쉽게 제압하는 것을 목표로 합니다. 현재 린의 기본 공격 1~3타가 모두 정상 적중하면, 별도 대미지 보정이 없을 때 각 100 대미지로 처치할 수 있는 체력입니다.
- 슈퍼아머·자체 무적·가드·회피 행동이 없습니다.

### 2.2 시야와 이동

| 항목 | 값 |
| - | - |
| 시야 거리 | 20m |
| 정면 각도 | 120° — 좌우 60°씩 |

- 발견·피격에 의한 전투 진입, 지형 가림, 시야 상실에 의한 비전투 복귀는 적 시스템을 따릅니다.
- 전투 중 이동은 적 시스템을 따릅니다. 사격 후보가 없으면 플레이어에게 걸어서 다가가며 다시 선택하고, 패턴 후딜레이 동안에는 플레이어를 바라보며 좌우로 걷습니다.
- 플레이어가 바로 앞까지 접근해도 도망가지 않습니다. 사격 조건이 맞으면 동일한 기본 사격만 사용하며, 근접 전용 공격이나 빠른 발사는 없습니다.
- 비전투 복귀 시에는 공통 규칙대로 정찰 지점 또는 최초 배치 위치로 돌아갑니다.
- 사격의 방향 확정 후부터 반동 종료까지, 피격 반응·그로기·처형 중에는 일반 목표 방향 회전을 하지 않습니다. 재장전과 일반 대기 중에는 다시 플레이어를 바라볼 수 있습니다.

### 2.3 기본 사격과 공격 간격

| ID | 설명 | 발동 가능 거리 | 가중치 | 가드 가능 | 쿨다운 |
| - | - | - | - | - | - |
| PistolShot | 조준 후 탄환 1발, 반동, 재장전 | 캡슐 중심 간 수평 거리 0~20m | 1 | 가능 | 패턴 시작부터 게임 시간 6초 |

실제 조준점까지의 거리가 20m를 넘으면 고저차와 관계없이 사격하지 않습니다. 쿨다운이 끝나도 아래의 대기와 사격 조건을 모두 만족해야 합니다.

| 구간 | 길이 | 동작과 판정 |
| - | - | - |
| 조준 | 1.2초 | 제자리에서 권총을 겨눔. 마지막 0.35초 전에 조준점 확정 |
| 발사·반동 | 0.8초 | 구간 시작에 탄환 1발 발사. 추가 타격 없음 |
| 재장전 | 2.0초 | 공격하지 않고 재장전. 움직이지 않음 |
| 패턴 후딜레이 | 2.0~4.0초 중 무작위 | 공통 규칙에 따라 플레이어를 바라보며 좌우로 걸음. 끝난 뒤 다음 사격 조건 확인 |

- 조준·반동·재장전은 모션 진행 기준입니다. 패턴 후딜레이는 게임 시간 기준이며, 시간 연출의 영향은 시간 규칙을 따릅니다.
- 중단이나 시간 연출 없이 사격 조건이 계속 맞으면 **발사부터 다음 발사까지 6~8초**입니다. 패턴 4초와 후딜레이 2~4초를 합한 값이며, 쿨다운 6초를 여기에 다시 더하지 않습니다.
- 전투 진입 시에도 먼저 패턴 후딜레이를 거칩니다. 따라서 조건이 계속 맞는 첫 발은 발견 후 3.2~5.2초에 나옵니다. 기습 즉발 사격은 없습니다.
- 대기는 매번 개체별로 독립적으로 뽑습니다. 대기 중 매 순간 다시 뽑지 않습니다.
- 쿨다운이나 사격 조건 때문에 더 기다린 경우에는 조건을 만족했을 때 조준부터 시작합니다. 지나간 발사 기회를 모아 연속으로 쏘지 않습니다.
- 패턴 후딜레이를 마친 뒤에도 사격 자격이 없으면 공통 패턴 선택 규칙에 따라 다가가며 다시 선택합니다. 피격·그로기 등 다른 상태의 해제 조건도 충족해야 다음 조준을 시작합니다.

### 2.4 사격 조건과 불합리한 피격 억제

- 조준 시작 시 플레이어가 살아 있고, 사격 거리 안이며, 적이 플레이어를 볼 수 있어야 합니다. 총구에서 조준점까지 벽·지형이 가리지 않아야 합니다.
- 조준 도중부터 발사 직전까지 위 거리·시야 조건을 유지해야 합니다. 한 조건이라도 깨지면 조준과 예고를 취소하고 패턴 후딜레이로 들어갑니다. 사격 조건을 다시 만족해도 기존 조준 시간을 이어 쓰지 않습니다.
- 발사 전 마지막 0.35초에는 플레이어의 당시 캡슐 중심을 조준점으로 고정합니다. 이후 좌우·상하 이동을 따라가지 않고, 이동 속도를 예상해 앞쪽을 겨누지도 않습니다.
- 방향 확정 뒤에는 총구에서 고정 조준점까지의 장애물도 발사 직전에 확인합니다. 벽·지형에 막혔으면 발사를 취소합니다.
- 발사 순간에는 총구에서 고정 조준점으로 향하는 직선으로 탄환을 내보냅니다. 총구 앞에 벽이 있으면 벽 너머에서 탄환이 생기지 않아야 합니다.
- 여러 사수의 사격이 우연히 겹칠 수는 있습니다. 동시 사격 제한 기능으로 해소하지 않으며, 완료 조건에서 2명 혼합 배치의 압박을 별도로 검토합니다.

### 2.5 탄환과 대응

| 항목 | 값 |
| - | - |
| 발사 수 | 패턴당 1발 |
| HP 배율 | 1.0 |
| 피격 반응 | 움찔. 넉업·넉다운 없음 |
| 가드·패리 | 모두 가능 |
| 이동 | 초당 20m로 직진. 중력·유도·폭발 없음 |
| 판정 크기 | 반지름 5cm, 길이 30cm의 캡슐. 진행 방향으로 눕힘 |
| 최대 이동 거리 | 발사점부터 30m |
| 소멸 | 벽·지형 충돌 또는 최대 이동 거리 도달 |

- 이동하는 투사체이며 발사와 동시에 원거리 대상에게 대미지를 주지 않습니다. 속도 기준으로 10m 비행에는 0.5초가 걸립니다.
- 캐릭터는 관통하되 같은 대상은 한 번만 판정합니다. 진영·무적·극한 회피의 처리는 전투 시스템을 따릅니다. 같은 진영을 피해 입히거나 공격 대상으로 고르지 않습니다.
- 플레이어는 PP를 사용하지 않으므로 일반 탄환의 PP 배율은 0입니다. 패리 반사 후의 PP 처리는 린의 투사체 반사 규칙을 따릅니다.
- 패리하면 린의 기존 투사체 반사 규칙을 적용합니다. 발사자의 현재 위치로 방향을 바꾸고 직진하며, 반사 시 최대 이동 거리를 다시 셉니다. 반사 전용 대미지 배율은 추가하지 않습니다.
- 현재 린의 DEF 기준 일반 적중은 60 HP, 가드는 30 HP와 15 SP 소모입니다. 이 값은 위 공격 수치와 공통 공식의 검산값이며 별도 고정 대미지가 아닙니다.
- 패리 예고는 적 시스템의 공통 길이·색·효과음을 사용하며, **발사 시점**을 알립니다. 탄환 도착 시점과 같다고 안내하지 않습니다. 비행 중 탄환의 빛과 궤적을 보고 실제 도착에 맞춰 패리·회피할 수 있어야 합니다.

### 2.6 피격·중단·그로기·사망

- 소형 강인도를 적용하여 일반 움찔 공격에도 조준·반동·재장전이 중단됩니다. 발사 전에 중단되면 탄환이 나오지 않습니다.
- 피격 후 행동 전환은 적 시스템을 따릅니다. 움찔만 끝나면 추가 패턴 후딜레이 없이 다음 패턴을 선택하며, 넉업·넉다운이 끝나면 공통 패턴 후딜레이를 거칩니다. 선택한 사격의 조준 구간은 그대로 적용합니다.
- 중단해도 이미 시작한 쿨다운은 초기화하거나 없애지 않습니다. 남은 쿨다운과 사격 조건에 따라 다음 패턴을 선택합니다. 탄약 수가 없으므로 재장전 중단으로 다음 패턴이 막히지 않습니다.
- 이미 발사된 탄환은 사수의 피격·그로기·처형·사망으로 제거하지 않습니다. 플레이어 사망 시 적의 행동 중단은 공통 규칙을 따릅니다.
- 그로기 지속 시간·피격·PP 회복·처형 조건은 공통 규칙을 따릅니다. 그로기 또는 처형 피격 종료 후 살아 있고 행동할 수 있으면 패턴 후딜레이를 거칩니다. 여러 종료 조건이 겹쳐도 대기를 중복해서 더하지 않습니다.
- 처형 피격과 처형 사망 동작은 린의 처형에 맞춰 재생합니다. 일반 적도 기존 조건에 맞게 처형 안내가 표시되어야 합니다.
- 사망은 전투 시스템을 따릅니다. 일반 사망에는 보스 처치 슬로우모션을 사용하지 않습니다. 사망 후 락온·충돌·네임플레이트 처리는 해당 공통 규칙을 따릅니다.

### 2.7 검토할 제작 항목

- 조준 대기에서 1.2초 전조를 읽을 수 있는 연결과, 원본 사격 반동을 0.8초 구간에 맞추는 방법을 모션 조합으로 확인해야 합니다. 조정 결과가 위 플레이 타이밍을 바꾸면 구현 전에 이 초안을 수정합니다.
- 권총 메시, 총구 위치, 발사·재장전 사운드, 탄환의 빛과 궤적은 선정 전입니다. 무기 선정·적용은 별도 후속 작업입니다.
- 원거리·고저차 조준에서 손과 총구가 실제 발사 방향을 표현하는지 확인해야 합니다. 에임 보정 에셋의 존재만으로 적용 완료로 보지 않습니다.
- 아래 숫자는 체감 검증 전 기준안입니다. 특히 2명 이상의 사수가 끼어 있는 전투에서는 공격 간격과 배치의 조합을 함께 검토합니다.

## 3. 완료 조건 (Acceptance Criteria)

아래는 구현 후 확인할 시나리오이며, 현재 통과 결과가 아닙니다. 실행은 AI 워크플로우의 테스트 작업 수칙을 따릅니다.

- [ ] 공격 패턴은 PistolShot 하나이며 패턴당 한 발만 나간다. 근접·가드 불가·연사 공격이 없다.
- [ ] 시간 연출·피격 없이 사격 조건을 유지한 단일 사수를 30초 관찰했을 때, 첫 발은 발견 후 3.2~5.2초에 나가고 이후 발사 간격은 6~8초다. 프레임 단위 오차를 제외하고 6초보다 빠른 반복 사격이 없다.
- [ ] 조준 1.2초, 반동 0.8초, 재장전 2초와 대기가 구분된다. 재장전·대기 중 추가 발사는 없다.
- [ ] 조준 마지막 0.35초에 옆으로 이동하면 조준점이 따라오지 않는다. 고저차에서도 같은 규칙이 적용된다.
- [ ] 벽·지형으로 플레이어가 가려지면 조준을 시작하지 않는다. 조준 중 엄폐 뒤로 숨으면 취소되고, 사격 조건을 다시 만족해도 전조를 처음부터 보인다. 카메라 방향은 사격 조건에 영향을 주지 않는다.
- [ ] 탄환이 벽·엄폐물과 총구 앞 장애물을 통과하여 피해를 주지 않는다.
- [ ] 탄환은 보이는 속도로 직진한다. 10m 비행 시간은 정상 속도에서 약 0.5초이며 유도·즉시 적중·폭발이 없다.
- [ ] 기본 사격은 가드·패리·극한 회피로 대응할 수 있다. 패리한 탄환의 반사·대미지·PP·소멸은 공통 규칙과 일치한다.
- [ ] 현재 린의 기본 스탯으로 일반 적중 시 HP 60, 가드 시 HP 30·SP 15가 감소한다. 별도 보정이 없는 사수는 린의 기본 공격 1~3타가 정상 적중하면 사망한다.
- [ ] 플레이어가 접근해도 사수는 도망가거나 빠른 공격으로 전환하지 않는다. 조준 중 기본 공격에 맞으면 발사하지 못한다.
- [ ] 조준·재장전·대기 중 각각 피격시킨 뒤, 움찔 종료 시에는 추가 대기 없이 패턴을 선택하고 넉업·넉다운 종료 시에는 공통 패턴 후딜레이를 적용한다. 남은 쿨다운은 유지하며 취소된 발사를 몰아서 처리하지 않는다.
- [ ] 사격 후보가 없으면 플레이어에게 걸어서 다가가며 다시 선택하고, 패턴 후딜레이 동안에는 좌우로 걷는다. 공통 시야 상실 조건을 만족하면 정찰 지점 또는 배치 위치로 복귀한다.
- [ ] 그로기·처형·사망·락온·네임플레이트·클리어 연계가 공통 규칙과 맞는다. 사망 직전 이미 발사한 탄환도 정해진 소멸 조건까지 남는다.
- [ ] 슬로우모션·궁극기 시간 정지·일시정지에 대해 사수·탄환·대기가 시간 규칙을 따른다. 재개 직후 예정하지 않은 추가 발사가 없다.
- [ ] 근거리 적 1명과 사수 2명을 배치해 엄폐 후 접근할 수 있으며, 전조 없는 사격이나 도주 추격전이 없다. 기획자가 플레이로 공격 빈도가 부담스럽지 않은지 확인한다. 각 사수의 간격 충족만으로 체감 검증을 통과 처리하지 않는다.
