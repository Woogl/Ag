# 스킬 4 작업 명세 (Spec)

## 1. 개요 및 목적

- [마일스톤 3](<../../Docs/Milestone/마일스톤 3.md>)의 '스킬 확장과 콤보'에 따라 스킬 4(광역기)를 만듭니다. 근처의 여러 적에게 한 번에 큰 대미지를 주는 기술입니다.
- 지금 스킬 4는 스킬 2와 같은 동작입니다. 이 명세는 스킬 4의 동작만 바꾸며, 스킬 1·2·3과 스킬 공통 규칙(키, 상태별 허용 입력, 선입력, 모션 캔슬, 자원 충전, HUD 슬롯)은 바꾸지 않습니다.
- 뛰어올라 내려찍는 큰 동작 끝에 주위의 적을 한꺼번에 쓰러뜨려, 여러 적에게 둘러싸였을 때 숨 돌릴 틈을 만들고 콤보를 크게 마무리합니다.

## 2. 플레이 규칙 및 수치

### 스킬 4 (Skill4)

| 항목 | 값 |
| - | - |
| MP 소모 | 60 |
| 쿨다운 | 8초 |
| 동작 | 낮게 한 번 휩쓴 뒤 앞으로 뛰어올라 칼로 바닥을 내려찍고, 무릎을 꿇은 자세로 착지합니다. 내려찍는 순간 주위의 적을 한꺼번에 칩니다. |
| 범위 | 내려찍는 순간 플레이어 캡슐 중심에서 반경 4m 안에 캡슐이 닿는 적 |
| HP 배율 | 2.5 |
| PP 배율 | 2.5 |
| 피격 반응 | 넉다운 |
| 후딜 시작 | 내려찍은 뒤 무릎을 꿇은 자세에 들어선 직후 |

- 내려찍기는 1타입니다. 범위 안의 적마다 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '피격 처리 순서'를 따르며, 범위 밖의 적은 맞지 않습니다. 앞·옆·뒤를 가리지 않습니다.
- 뛰어오르기 전 낮게 휩쓰는 동작에는 공격 판정이 없습니다.
- 방향은 '공통 규칙'의 '공격 방향'을 따르고, 내려찍기 직전에 방향을 확정합니다. 뛰어드는 거리는 '공격 중 위치·회전 보정'의 위치 보정을 따라 대상 앞에 착지하도록 맞춥니다. 대상이 없으면 모션대로 정면으로 약 3m 뛰어듭니다.
- 무적 구간은 없습니다. 내려찍기 전에 맞아 움찔하면 스킬이 끊기며, 소모한 MP와 쿨다운은 돌려받지 않습니다.
- 넉다운의 강인도 처리는 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '강인도'를 따릅니다. 그래서 보스(중형)는 그로기 중에만 쓰러지고, 그로기가 아니면 움찔합니다.
- 피격 VFX, 히트스톱, 카메라 셰이크(넉다운 적중: 보통), 대미지 숫자, 보너스 대미지, UP 충전(스킬 적중 +15, 여러 적을 맞혀도 한 번), MP 충전 없음은 다른 공격과 같은 공통 규칙을 따릅니다.

### 내려찍기 VFX

내려찍는 순간 스킬 4 전용 VFX를 재생합니다. 칼로 내려찍은 힘이 바닥을 타고 주위로 퍼져 나가 둘레의 적을 휩쓰는 느낌을 주고, 어디까지 맞는지 보여 줍니다. 적중 여부와 관계없이 재생합니다.

| 요소 | 표현 |
| - | - |
| 섬광 | 칼이 바닥에 닿는 자리에서 짧고 밝은 섬광이 터집니다. |
| 충격파 | 플레이어 발밑에서 바닥을 따라 납작한 충격파가 빠르게 퍼집니다. 바깥 가장자리가 가장 밝고 안쪽은 지나가며 흐려집니다. 가장자리는 판정 반경(4m)에서 멈추며 사라지므로, 충격파가 덮은 곳 안에 있거나 몸이 걸친 적이 맞습니다. |
| 참격 선 | 가늘고 날카로운 빛줄기 여러 개가 충격파와 함께 바닥 위를 바깥으로 뻗어 나가, 칼로 벤 기세가 사방으로 퍼지는 모습을 보여 줍니다. 판정 반경을 넘지 않습니다. |
| 흙먼지와 파편 | 충격파가 지나는 바닥에서 흙먼지와 작은 파편이 낮게 튀어 오릅니다. |

- 색은 푸르스름한 흰빛입니다. 적의 공격 예고(빨간색·금색)와 보스 GroundSlam 충격파(주황색)와 헷갈리지 않게 합니다.
- 충격파는 약 0.15초 안에 판정 반경까지 퍼지고, 전체는 0.6초 안에 사라져 다음 행동을 가리지 않습니다.
- 판정 반경을 바꾸면 충격파와 참격 선이 퍼지는 거리도 같이 바뀝니다.
- 나이아가라 시스템과 머티리얼을 직접 새로 만듭니다. 쓰는 에셋은 [아트 표현 사양](<../../Docs/Art/아트 표현 사양.md>)에 적습니다.

### 모션

모션: [Attack12](<../../Docs/Art/GIF/ACS2ComboSkill/Attack12.gif>) (ACS2 Combo Skill)

1배속 원본은 3.17초입니다. 0.3 ~ 0.45초에 낮게 휩쓸고, 0.45 ~ 0.85초에 뛰어올라, 약 1.03초에 칼이 바닥에 닿습니다. 1.1 ~ 2.4초에 무릎을 꿇은 채 머물다가 2.9초까지 일어섭니다. 착지까지 앞으로 약 3.0m 나아가고 일어서며 0.35m 물러납니다.

- 뛰어오르기 전의 준비는 읽히되 늘어지지 않게, 내려찍기는 빠르고 무겁게 보이게 합니다. 무릎을 꿇은 자세는 마무리의 무게가 느껴질 만큼만 두고 일어섭니다. 재생 템포는 [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>) '공통 규칙'대로 AI가 초기값을 정하고 플레이 확인 후 조정합니다.
- 휩쓸기와 내려찍기에 무기 궤적을 표시합니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] MP가 60 이상일 때 4 키를 누르면 낮게 휩쓴 뒤 뛰어올라 내려찍고 무릎을 꿇고 착지합니다. MP가 60 줄고 스킬 4 슬롯에 8초 쿨다운이 표시됩니다.
- [ ] 스킬 4 슬롯의 MP 코스트가 60으로 보입니다. MP가 40 이상 60 미만이면 4 키는 발동하지 않고 스킬 4 슬롯만 흐리게 표시되며, 1·2·3 키는 발동합니다.
- [ ] 쿨다운 8초 동안 4 키는 발동하지 않고, 8초가 지나면 다시 발동합니다.
- [ ] 플레이어 둘레(앞·옆·뒤) 4m 안에 있는 적 여럿이 내려찍는 순간 함께 HP·PP가 줄고, 각자 플레이어 반대쪽으로 넉다운됩니다. 4m 밖(캡슐이 닿지 않는 거리)의 적은 맞지 않습니다.
- [ ] HP 감소량이 같은 적에게 맞힌 기본 공격 1타(HP 배율 1.0)의 2.5배이고, PP 감소량도 2.5배입니다(보너스 대미지가 없는 상황).
- [ ] 휩쓰는 동작에 칼이 닿은 적은 맞지 않습니다.
- [ ] 보스는 그로기가 아니면 움찔하고, 그로기 중이면 넉다운됩니다.
- [ ] 락온 대상이나 범위 안의 가장 가까운 적을 향해 뛰어들어 그 적 앞에 착지합니다. 적이 없으면 정면으로 약 3m 뛰어듭니다.
- [ ] 적중하면 UP가 15 늘고(여러 적을 맞혀도 한 번), MP는 늘지 않습니다.
- [ ] 내려찍는 순간 섬광이 터지고, 발밑에서 푸르스름한 흰빛의 충격파와 참격 선이 바닥을 따라 4m까지 퍼진 뒤 0.6초 안에 사라집니다. 아무도 맞지 않아도 재생합니다.
- [ ] 충격파가 멈춘 가장자리에 몸이 걸친 적은 맞고, 그보다 바깥의 적은 맞지 않습니다.
- [ ] 무릎을 꿇은 뒤(후딜)에는 기본 공격·가드·회피·점프·다른 스킬·궁극기로 모션 캔슬할 수 있고, 내려찍기 전에는 할 수 없습니다. 후딜 전에 누른 입력은 0.3초 안에 후딜이 시작되면 그때 실행합니다.
- [ ] 뛰어오르는 동안 적의 공격에 맞아 움찔하면 스킬이 끊기고 내려찍기 판정이 나오지 않습니다.
