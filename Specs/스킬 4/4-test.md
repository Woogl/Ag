# 스킬 4 검증 결과

## 1. 테스트 시나리오

- 샌드백: `python -I Scripts/ScenarioTest/run.py skill4.py --map "/Game/Maps/LV_SimulationRoom?Enemies=Sandbag,Sandbag,Sandbag,Sandbag,Sandbag"`
  - 샌드백 A 앞 1m, L 왼쪽 3m, R 오른쪽 3m, B 뒤 3m, F 앞 왼쪽 5.5m(범위 밖). 모두 플레이어를 봄.
  - 1타(기준 대미지) → 스킬 4 → HUD 읽기 → MP 40에서 스킬 2 → 쿨다운 중 스킬 4 → A를 앞 4m로 옮겨 스킬 4(다가가기) → 뛰어오르는 중 움찔.
- 보스: `python -I Scripts/ScenarioTest/run.py skill4_boss.py` (보스 스테이지). 보스 앞 2m에서 스킬 4, 그로기(`AgGroggy`) 뒤 다시 스킬 4.
- 시나리오 파일은 임시 파일이라 저장소에 두지 않았습니다.

## 2. 결과

- 빌드: 스킬 1·3 세션과 합친 작업 트리 전체 AgEditor 빌드 성공(스킬 1 세션이 실행). 그 전에 HEAD + 스킬 4 변경만으로 임시 폴더 빌드도 성공.
- 판정: 샌드백 18개 항목, 보스 3개 항목 모두 통과. 스킬 3 세션이 `Skill4`의 `AbilityTags`(`Ability.Action.Skill.4`)와 HitReward 줄을 나눈 뒤 다시 실행해도 통과.

| 완료 조건 | 결과 |
| - | - |
| 4 키로 발동, MP 60 소모, 쿨다운 8초 표시 | MP 100→40, 슬롯 쿨다운 표시 보임 |
| 슬롯 비용 60, MP 40이면 스킬 4만 흐림·스킬 2는 발동 | 비용 "60", 스킬 4 칸 불투명도 0.5, 스킬 2 칸 1.0, 스킬 2 발동(MP 40→0) |
| 쿨다운 동안 발동 안 함, 지나면 발동 | 쿨다운 중 MP 100 그대로, 8.4초 뒤 발동 |
| 둘레 4m 안 여럿 동시 적중·넉다운, 밖은 안 맞음 | A·L·R·B가 같은 프레임(3.50초)에 HP·PP 감소와 넉다운, F(5.5m) 그대로 |
| HP·PP 배율 2.5 | 1타 100, 스킬 4 250 (2.50배), PP 250 |
| 휩쓸기에는 판정 없음 | 판정 전 A의 HP 변화 없음, 적중 한 번 |
| 보스: 평소 움찔, 그로기 중 넉다운 | 평소 `AM_Flinch:Body`(대미지 125), 그로기 중 `AM_KnockDown`(대미지 188, 그로기 보너스 포함) |
| 대상 앞에 착지 | 앞 4m의 A를 향해 뛰어들어 내려찍는 순간 간격 100cm(최소 간격) |
| UP 15 한 번, MP 충전 없음 | UP 0→15, 1타 뒤 MP는 이미 100이라 영향 없음 |
| 내려찍는 순간 VFX | `NS_Skill4Slam`이 발밑(5.6cm)에서 재생 중 |
| 후딜 캔슬 시점 | `State.Busy` 끝 = 판정 + 0.14초 + 히트스톱 0.12초(측정 3.74, 계산 3.76) |
| 뛰어오르는 중 움찔하면 끊김 | `AM_Player_Skill4`→`AM_Flinch:Body`, 이후 A의 HP 변화 없음 |

- 처음 실행에서 4개 항목이 실패했고, 기록을 보고 시나리오 쪽 오류로 확인해 고쳤습니다.
  - 후딜 시각: 기준에 히트스톱(몽타주가 멈춤) 0.12초를 넣지 않았습니다. 측정값은 판정 시각 + 0.14 + 0.12와 일치합니다.
  - 착지 간격: 넉다운으로 밀려난 뒤(12.5초)를 쟀습니다. 내려찍는 순간의 간격으로 재니 100cm입니다.
  - 움찔: 이벤트 태그를 잘못 넣었습니다(`Event.Hit.Stagger.Body`가 맞음).
  - VFX: 판정과 같은 프레임에 찾아 늦췄습니다.
- 로그: 창 로그에 `LogAg: Error` 없음. 기록은 `Saved/ScenarioTest/slot1_20261107-142109.json`, `slot2_20261107-142223.json`.
