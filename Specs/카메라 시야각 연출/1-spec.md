# 카메라 시야각 연출 작업 명세 (Spec)

## 1. 개요 및 목적

- 달리기 중에 시야각을 부드럽게 넓혀 속도감을 줍니다.
- 카메라 연출의 시야각 변화를 카메라 셰이크가 아닌 별도 구조로 옮깁니다. 이미 정한 연출의 규칙과 수치는 패리 셰이크 말고는 바꾸지 않습니다.
- 패리 성공의 셰이크를 전용 단계 대신 '보통'으로 바꿉니다.

## 2. 플레이 규칙 및 수치

### 달리기 시야각

| 항목 | 내용 |
| - | - |
| 시야각 변화 | +6° (넓어져 물러난 것처럼 보입니다) |
| 적용 조건 | 달리기 중이고 이동 입력이 있는 동안에만 적용합니다. Shift를 누른 채 이동 입력을 멈춰 제자리에 서 있으면 적용하지 않습니다. |
| 들어가기 | 적용 조건을 만족하면 0.6초 동안 0에서 변화량까지 부드럽게 커집니다. |
| 돌아오기 | 적용 조건을 벗어나면 0.5초 동안 0으로 부드럽게 줄어듭니다. 들어가는 도중에 벗어나면 그때의 크기에서 줄어듭니다. |
| 적용 카메라 | 자유 시점과 락온 카메라에 더합니다. |

- 시간과 겹침은 '카메라 연출'의 '공통 규칙'을 따릅니다. 게임 시간으로 흐르고, 다른 연출의 시야각 변화와 더해지며, 궁극기 컷신이 시작되면 끝납니다.

### 기존 기획서와의 관계

- [카메라와 타겟팅](<../../Docs/Design/System/카메라와 타겟팅.md>)에 '달리기 시야각'을 새로 추가합니다.
- '상황별 연출'에서 패리 성공의 셰이크를 '패리'에서 '보통'으로 바꿉니다. '카메라 셰이크'의 '셰이크 단계'에서 '패리' 단계를 지워 작음, 보통, 큼 세 단계만 남깁니다.
- 그 밖의 '카메라 연출' 규칙과 '상황별 연출' 수치는 그대로입니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 자유 시점에서 달리기를 시작하면 시야각이 0.6초 동안 부드럽게 넓어지고, 달리기를 멈추면 0.5초 동안 돌아옵니다.
- [ ] 락온 중에 달려도 같은 변화가 락온 카메라에 더해집니다.
- [ ] Shift를 떼거나 다른 행동을 시작해 달리기가 끝나면, 그 순간부터 시야각이 돌아옵니다.
- [ ] Shift를 누른 채 이동 입력을 멈추면 시야각이 돌아오고, 이동 입력을 다시 넣으면 다시 넓어집니다.
- [ ] 달리는 중에 궁극기를 쓰면 컷신으로 바뀔 때 넓힌 시야각이 남지 않습니다.
- [ ] 패리 성공에서 가드 밀림과 같은 '보통' 셰이크가 재생됩니다.
- [ ] 패리, 극한 회피, 회피 반격, 처형, 보스 처치, 보스 페이즈 전환 포효의 시야각 변화와 패리 말고 나머지 셰이크가 바꾸기 전과 같게 보입니다.
