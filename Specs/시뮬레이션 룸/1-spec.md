# 시뮬레이션 룸 작업 명세 (Spec)

## 1. 개요 및 목적

- 플레이어가 고른 적과 싸우는 전투 연습장 레벨 LV_SimulationRoom을 만듭니다. ([마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)의 '시뮬레이션 룸')
- 전투 밸런싱과 디버깅에 씁니다. 고른 구성으로 같은 상황을 반복할 수 있어야 합니다.
- 타이틀 화면에서 LV_SimulationRoom으로 들어오는 버튼과 흐름은 스테이지 선택 Spec을 따릅니다. 이 Spec은 레벨에 들어온 뒤의 규칙만 정합니다.

용어는 [용어집](<../../Docs/용어집.md>)을 따릅니다.

## 2. 플레이 규칙 및 수치

### 2.1 레벨 구성

| 항목 | 내용 |
| - | - |
| 레벨 | LV_SimulationRoom |
| 환경과 아레나 | [스테이지 - 보스 전장](<../../Docs/Design/Level/스테이지 - 보스 전장.md>)의 '개요' 환경과 '보스 아레나' 조건을 그대로 따릅니다. |
| 레벨에 배치하는 적 | 없음. 적은 '2.3 배치'에 따라 놓습니다. |
| 제한 시간, 체크포인트, 회복 수단 | 없음 |

| 기호 | 요소 | 위치와 설정 |
| - | - | - |
| C | 아레나 중심 | 플레이어 시작 지점이자 적 배치 자리를 정하는 기준점입니다. |
| P | 플레이어 시작 지점 | C. 입구 반대편(아레나 안쪽)을 바라봅니다. |
| 1 ~ 5 | 적 배치 자리 | '2.3 배치' 참고 |

### 2.2 적 선택 화면

싸울 적을 고르는 화면입니다. Menu 레이어에 표시합니다. ([UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 레이어')

**여는 때**

- 타이틀 화면에서 LV_SimulationRoom에 들어오면 바로 한 번 엽니다. 이때 아레나에는 플레이어만 있습니다.
- 그 밖에는 열지 않습니다. 구성을 바꾸려면 타이틀로 돌아가 다시 들어옵니다.

**화면 구성**

- 화면 위쪽 가운데에 제목 'ENEMY SELECT'를 Large로 표시합니다.
- 왼쪽 열은 후보 목록, 오른쪽 열은 선택 목록, 두 열 아래 가운데에 Start, Return to Title 버튼을 가로로 놓습니다. 버튼과 목록 글자는 Large입니다.
- 뒤의 게임 화면은 어둡게 표시하며, 화면이 떠 있는 동안 게임은 멈춥니다. 일시정지 메뉴와 같이 페이드 없이 바로 표시합니다.
- 마우스 커서를 표시하고, 플레이어 입력은 UI만 받습니다.
- 처음 선택된 버튼은 후보 목록의 첫 번째 항목입니다.

**후보 목록**

- 게임에 있는 보스, 일반 적, 샌드백을 모두 한 줄에 하나씩 표시합니다. 순서는 보스, 일반 적, 샌드백입니다.
- 각 줄에는 이름을 표시합니다. 이름은 각 캐릭터 문서를 따릅니다. (예: 커스터)
- 항목을 실행하면 선택 목록의 맨 끝에 그 적을 하나 더합니다. 같은 적을 여러 번 고를 수 있습니다.
- 선택 목록이 5개로 가득 찼으면 모든 항목을, 선택 목록에 보스가 있으면 보스 항목을 흐리게 표시하고 실행해도 아무 일도 하지 않습니다. 보스는 한 번에 한 명만 고릅니다. (전투 HUD의 보스 상태가 하나뿐입니다.)

**선택 목록**

- 고른 순서대로 '번호. 이름' 형식으로 표시합니다. 번호는 '2.3 배치'의 배치 자리 번호입니다.
- 항목을 실행하면 그 항목을 목록에서 빼고, 뒤의 항목을 한 칸씩 앞으로 당깁니다.
- 화면을 열 때는 비어 있습니다.

**버튼**

| 버튼 | 실행 결과 |
| - | - |
| Start | LV_SimulationRoom을 다시 시작하고, 선택 목록의 적을 배치합니다. 선택 목록이 비어 있으면 흐리게 표시하고 실행되지 않습니다. |
| Return to Title | [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Stage Clear'의 같은 버튼과 같습니다. |

- Esc는 아무 일도 하지 않습니다.
- 방향키(↑·↓·←·→)는 그 방향에서 가장 가까운 버튼으로 선택을 옮깁니다. 그 밖의 조작은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 'UI 조작'을 따릅니다.

### 2.3 배치

- 다시 시작은 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Boss Stage'의 다시 시작과 같이 레벨을 처음부터 다시 로드하며, 플레이어와 적의 모든 상태를 초기화합니다. 플레이어는 시작 지점(P)에서 시작합니다.
- 선택 목록의 n번째 적을 배치 자리 n에 놓습니다. 배치 자리는 아레나 중심(C)에서 캡슐 중심까지 수평 거리 8m이고, 플레이어 시작 방향을 0°로 한 각도는 아래와 같습니다.

| 배치 자리 | 1 | 2 | 3 | 4 | 5 |
| - | - | - | - | - | - |
| 각도 | 0° | 오른쪽 25° | 왼쪽 25° | 오른쪽 50° | 왼쪽 50° |

- 적은 플레이어를 바라보고 놓입니다.
- 보스와 일반 적은 놓이자마자 시야와 관계없이 전투에 들어갑니다. 그 뒤의 행동은 [적 시스템](<../../Docs/Design/System/적 시스템.md>)과 [보스 시스템](<../../Docs/Design/System/보스 시스템.md>)을 따릅니다. 샌드백의 행동은 샌드백 Spec을 따릅니다.
- 고른 적을 배치한 뒤 마우스 커서와 입력은 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Boss Stage'와 같습니다. 전투 HUD는 보스전과 같고, 일반 적과 샌드백의 체력 표시는 네임플레이트 Spec을 따릅니다.

### 2.4 결과

- 배치한 적이 모두 사망하면 Stage Clear, 플레이어의 HP가 0 이하가 되면 Game Over입니다. 스테이지 결과 연출과 전투 결과 UI는 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 'Stage Clear', 'Game Over'와 같습니다.
- 샌드백(중립 진영)은 Stage Clear 조건에서 뺍니다. 보스나 일반 적을 하나도 배치하지 않았으면 Stage Clear가 없습니다.
- 결과는 먼저 처리된 사망으로 정해집니다. 마지막 적과 플레이어의 사망이 겹칠 때도 같으며, 결과가 정해진 뒤의 사망은 'Boss Stage'와 같이 처리합니다.

### 2.5 일시정지 메뉴와 레벨 이동

- 일시정지는 [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 '일시정지'를 따릅니다.
- 일시정지 메뉴의 버튼과 배치는 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 '일시정지 메뉴'와 같습니다.

| 버튼 | 실행 결과 |
| - | - |
| Restart (일시정지 메뉴, 전투 결과 UI) | 지금 배치된 구성 그대로 LV_SimulationRoom을 다시 시작합니다. 적 선택 화면은 열지 않습니다. |
| Return to Title, Quit | 'Stage Clear'의 같은 버튼과 같습니다. |

- 고른 구성은 Return to Title로 타이틀로 돌아가거나 게임을 종료하면 비웁니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시나리오 1: 타이틀에서 LV_SimulationRoom에 들어오면 빈 아레나의 시작 지점에 플레이어가 서 있고, 적 선택 화면이 열려 있으며 선택 목록이 비어 있고 Start가 흐립니다.
- [ ] 시나리오 2: 후보 항목을 실행하면 선택 목록 끝에 더해지고, 같은 일반 적을 여러 번 고를 수 있습니다. 선택 목록 항목을 실행하면 빠지고 뒤 항목이 당겨집니다.
- [ ] 시나리오 3: 보스를 고르면 보스 항목이 흐려지고, 5개를 고르면 모든 후보가 흐려지며 더 더해지지 않습니다.
- [ ] 시나리오 4: 보스 1명과 일반 적 2명으로 Start하면 레벨이 다시 시작되어 1·2·3번 자리(중심에서 8m, 0°·오른쪽 25°·왼쪽 25°)에 고른 순서대로 플레이어를 바라보며 놓이고, 곧바로 전투에 들어가 패턴 후딜레이 뒤 공격을 시작합니다. 보스 상태 HUD가 표시됩니다.
- [ ] 시나리오 5: 배치한 적을 모두 처치하면 스테이지 결과 연출 뒤 Stage Clear UI가 뜨고, Restart를 실행하면 같은 구성이 같은 자리에 다시 놓입니다. 적 선택 화면은 열리지 않습니다.
- [ ] 시나리오 6: 플레이어가 사망하면 Game Over UI가 뜨고, Restart는 시나리오 5와 같습니다.
- [ ] 시나리오 7: 적 선택 화면에서 Esc는 아무 일도 하지 않고, Return to Title을 실행하면 타이틀로 돌아갑니다. 전투 중 일시정지 메뉴는 보스전과 같은 버튼만 보입니다.
- [ ] 시나리오 8: 샌드백만 배치하면 Stage Clear가 뜨지 않고, 적과 함께 배치하면 샌드백이 남아 있어도 적을 모두 처치했을 때 Stage Clear가 뜹니다.
- [ ] 시나리오 9: 배치 뒤 Return to Title로 나갔다가 다시 들어오면 적 선택 화면이 다시 열리고 선택 목록이 비어 있습니다.
