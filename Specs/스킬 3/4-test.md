# 스킬 3 장풍 검증 결과

## 1. 테스트 시나리오

- 시나리오 파일은 작업용 임시 파일이라 저장소에 두지 않았습니다. 통과 기준은 실행 전에 1-spec 완료 조건으로 정했습니다.
- A. 연속 발동·충전·관통·HUD: `python -I Scripts/ScenarioTest/run.py skill3_chain.py --map "/Game/Maps/LV_SimulationRoom?Enemies=,Sandbag,Sandbag,Sandbag"`
  - 샌드백 셋을 정면 5·8·11m 한 줄에 둡니다. MP 0에서 3 키를 누르고, MP를 채운 뒤 3 키를 2.1초 연타하고, 6초에 한 번 더 누른 뒤 14초까지 충전 회복을 봅니다.
- B. 공중 콤보·다시 시작·조준: `python -I Scripts/ScenarioTest/run.py skill3_combo.py --map "/Game/Maps/LV_SimulationRoom?Enemies=,Sandbag,Sandbag"`
  - 스킬 2로 띄운 샌드백에 3 키(선입력)를 누르고, 후딜에 기본 공격으로 캔슬한 뒤 3 키를 누릅니다. 이어서 오른쪽 12m의 샌드백에 락온해 쏘고, 샌드백을 30m 밖으로 치운 뒤 쏩니다.
- C. 기울기 화면 확인: 3연발마다 장풍이 3.5m 날아간 프레임을 테스트 창에서 `shot`으로 찍었습니다.

- HUD 버그 1건을 찾아 고쳤습니다. 처음에는 어빌리티를 부여받을 때 충전 숫자가 그려지지 않아, 첫 발동 전까지 숫자가 숨어 있었습니다. 어빌리티 부여·데이터 다시 읽기 알림에서 쿨다운 표시도 다시 그리게 고친 뒤 다시 확인했습니다.
- 쿨다운 효과가 끝나는 한 프레임(약 0.017초)에는 덮개가 충전 숫자 '0'보다 먼저 사라집니다. 그 프레임에는 남은 시간이 이미 0이지만 효과가 아직 지워지지 않았기 때문입니다. 충전이 없는 스킬에서도 덮개가 발동 가능 한 프레임 전에 사라지던 같은 현상이고, 눈에 보이지 않아 고치지 않았습니다.
- B에서 3.3초 장풍은 일어나는 중인 샌드백에 맞지 않았습니다. 넉업 착지(`Land` 0.1~0.7초)의 무적 때문이며 기존 규칙대로입니다.
- 따로 확인하지 않은 것: 움직이는 적을 앞서 겨누는 것, 벽·사거리 20m에서 소멸하는 것은 기존 투사체 코드 그대로라 이번에 따로 재지 않았습니다.
- 로그: 테스트 창의 게임 오류(`LogAg: Error`)는 없었습니다. 데이터를 넣는 도중 `Abilities.json`만 먼저 저장된 순간에 에디터가 '없는 생성 액터 ID' 오류로 다시 읽기를 거부했고, `SpawnActors.json`까지 저장한 뒤에는 오류 없이 읽었습니다.
- 기록: `Saved/ScenarioTest/slot1_20261107-152055.json`(A), `slot1_20261107-142616.json`(B)
