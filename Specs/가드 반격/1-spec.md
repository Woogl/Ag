# 가드 반격 작업 명세 (Spec)

## 1. 개요 및 목적

- 가드로 공격을 막거나 패리한 직후 기본 공격 키로 반격하는 '가드 반격'을 추가합니다. 규칙은 회피 반격과 같게 하되, 기회가 생기는 조건과 사라지는 조건만 가드에 맞춥니다.
- 회피 반격의 배율과 타겟팅 범위를 가드 반격과 같은 값으로 바꿉니다.

## 2. 플레이 규칙 및 수치

### 2.1 가드 반격 기회

| 항목 | 규칙 |
| - | - |
| 발생 시점 | 적의 공격(투사체 포함)을 가드로 막거나 패리한 순간. 가드 반응(없음, 가드 움찔, 가드 밀림)과 상관없이 생기며, 가드 브레이크는 해당하지 않습니다. |
| 유효 시간 | 발생 시점부터 0.5초. 기회가 남아 있는 동안 다시 막거나 패리하면 그 순간부터 0.5초를 새로 셉니다. |
| 사용 입력 | 기본 공격 키. 입력 처리는 '기본 공격 키의 처리 순서'를 따릅니다. |

다음 중 하나가 일어나면 기회가 사라집니다.

- 유효 시간이 끝남
- 가드 반격을 사용함
- 다른 액션(회피, 점프, 스킬, 궁극기, 처형)을 함
- 가드를 새로 시작함. 가드 키를 새로 누른 경우와 가드 키를 누르고 있어 가드가 저절로 시작된 경우를 포함합니다. 막거나 패리한 뒤 가드 키를 누른 채 가드를 이어 가는 경우(가드 움찔 중, 패리 모션의 후딜이 시작되거나 가드 밀림이 끝나 가드 자세로 돌아감)는 해당하지 않습니다.
- 넉업, 넉다운에 맞거나 가드 브레이크가 발생함

### 2.2 가드 반격 (GuardCounter)

| HP 배율 | PP 배율 | 피격 반응 | 타겟팅 범위 | 후딜 시작 |
| - | - | - | - | - |
| 1.5 | 1.5 | 움찔 | 8m | 판정 구간 끝 0.08초 뒤 |

모션: [ARPG_Samurai_Anim_UE_Attack_Combo4](<../../Docs/Art/GIF/Samurai/ARPG_Samurai_Anim_UE_Attack_Combo4.gif>)

- 칼을 크게 휘둘러 내려찍습니다. 1타입니다.
- 방향, 다가가는 거리, 회전은 회피 반격과 같습니다. 시작부터 판정 시작까지 회전과 접근을 보정하고 판정 시작에 방향을 확정하며, 회전은 공통 회전 속도 제한을 적용하지 않고 추적 구간이 끝날 때까지 선택한 대상 방향으로 완료합니다.
- 시작부터 판정 구간이 끝날 때까지 무적입니다.
- 적중하면 MP를 8 충전하고 UP는 충전하지 않습니다.
- 적중하면 회피 반격 적중과 같은 카메라 연출을 재생합니다.
- 상태별 허용 입력, 선입력, 모션 캔슬은 회피 반격과 같습니다.

참고: 모션은 1.7m 나아가며, 베는 시점은 0.43 ~ 0.48초, 닿는 거리는 제자리 1.7m / 이동 포함 3.4m입니다([Samurai 애니메이션 조사](<../../Docs/Art/Samurai 애니메이션 조사.md>)의 '공격'). 가드·패리 자세에서 이어 시작하므로 첫 자세로 블렌드합니다.

### 2.3 회피 반격 수치 변경

| 항목 | 현재 | 변경 |
| - | - | - |
| HP 배율 | 2.5 | 1.5 |
| PP 배율 | 5.0 | 1.5 |
| 타겟팅 범위 | 8.5m | 8m |
| 회피 반격 기회의 유효 시간 | 1초 | 0.5초 |

그 밖의 회피 반격 규칙은 바꾸지 않습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [x] 가드 키를 누른 채 움찔 공격을 막고(가드 움찔) 0.5초 안에 기본 공격 키를 누르면 가드 반격이 나가고, 0.5초가 지난 뒤 누르면 기본 공격 1타가 나간다.
- [x] 가드 키를 누른 채 패리하거나 가드 밀림을 당해 가드 자세로 돌아온 뒤, 막은 순간부터 0.5초 안에 기본 공격 키를 누르면 가드 반격이 나간다.
- [x] 패리 모션 중에 기본 공격 키를 누르면 후딜이 시작될 때 가드 반격이 나간다.
- [x] 패리 후 가드 키를 떼었다가 다시 눌러 가드를 시작하면 기회가 사라진다.
- [x] 가드 브레이크로는 기회가 생기지 않고, 기회가 남아 있을 때 가드 브레이크·넉업·넉다운이 일어나거나 회피·점프·스킬·궁극기·처형을 하면 기회가 사라진다.
- [x] 가드 반격은 8m 안의 적에게 순식간에 다가가 한 번 적중하고, 시작부터 판정 끝까지 피해를 받지 않으며, 적중 시 MP 8 충전과 카메라 연출이 나온다.
- [x] 회피 반격의 HP·PP 배율이 1.5이고 타겟팅 범위가 8m이다.
