# 샌드백 작업 명세 (Spec)

## 1. 개요 및 목적

- 전투 밸런싱과 디버깅에 쓰는 샌드백 2종을 만듭니다. ([마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)의 '샌드백')
- 샌드백은 사망하지 않아 대미지를 계속 넣을 수 있고, 피격 반응·그로기·처형을 공통 규칙대로 받아 콤보와 처형을 시험할 수 있습니다. 공격 샌드백은 제자리에서 같은 공격을 되풀이해 패리·가드·회피를 연습하게 합니다.
- 샌드백은 시뮬레이션 룸 Spec의 적 선택 화면에서 골라 배치합니다. 이 Spec은 배치된 뒤의 규칙만 정합니다.
- 머리 위 체력바는 네임플레이트 Spec을 따릅니다.

용어는 [용어집](<../../Docs/용어집.md>)을 따릅니다.

## 2. 플레이 규칙 및 수치

### 2.1 종류

| 이름 | 행동 | 무기 |
| - | - | - |
| 샌드백 | 놓인 자리에서 놓인 방향을 보고 서 있기만 합니다. | 없음 |
| 공격 샌드백 | 놓인 자리에서 플레이어를 바라보며, 플레이어가 가까이 오면 공격합니다. ('2.5 공격 샌드백의 공격') | 할버드 |

- 시뮬레이션 룸 적 선택 화면의 후보 목록에는 샌드백, 공격 샌드백 순서로 표시합니다.

### 2.2 개요

| 항목 | 내용 |
| - | - |
| 진영 | 중립. 적중 규칙은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '공격 판정 세부 규칙'을, 적이 노리지 않는 규칙은 [적 시스템](<../../Docs/Design/System/적 시스템.md>)의 '공격 대상과 시야'를 따릅니다. |
| 강인도 | 소형. 공통 규칙은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md#강인도>)을 따릅니다. |
| 크기 | 플레이어와 같음 |
| 외형 | 보스·일반 적과 한눈에 구분되어야 합니다. 쓰는 에셋은 '2.8 기존 Docs 기획서와의 관계'의 아트 표현 사양 반영 내용을 따릅니다. |

### 2.3 스탯

두 샌드백의 스탯은 같습니다.

| 스탯 | 값 | 비고 |
| - | - | - |
| HP / MaxHP | 10000 / 10000 | '2.6 HP' 참고 |
| SP / MaxSP | 0 / 0 | 사용하지 않음 |
| MP / MaxMP | 0 / 0 | 사용하지 않음 |
| UP / MaxUP | 0 / 0 | 사용하지 않음 |
| PP / MaxPP | 1000 / 1000 | |
| ATK | 100 | 공격 샌드백의 공격에만 씁니다. |
| DEF | 0 | HP·PP 감소량이 공격자의 ATK × 배율 그대로 나옵니다. |
| MOV | 0 | 걷지 않습니다. |

| 항목 | 값 |
| - | - |
| PP 리젠 | 초당 100 회복. 리젠 대기 시간은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)을 따릅니다. |

### 2.4 위치와 회전

- 샌드백은 스스로 이동하지 않습니다. 피격 반응으로 밀려나면 밀려난 자리에 그대로 서 있으며, 놓인 자리로 돌아가지 않습니다.
- 샌드백은 스스로 돌지 않습니다. 넉업·넉다운 등 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '피격 반응'에 따라 돌아선 방향을 그대로 유지합니다.
- 공격 샌드백의 목표 방향은 플레이어이며, [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '목표 방향 회전'에 따라 플레이어를 정면으로 바라봅니다. 회전 속도와 제자리 회전 모션은 [보스 캐릭터 - 커스터](<../../Docs/Design/Content/보스 캐릭터 - 커스터.md>)의 '회전'과 같습니다. 공격, 피격 반응(움찔·넉업·넉다운), 그로기, 처형 피격 중에는 이 회전을 하지 않습니다.

### 2.5 공격 샌드백의 공격

| 순서 | 동작 | HP 배율 | 피격 반응 | 가드 가능 | 예고 |
| - | - | - | - | - | - |
| 1 | 낮은 자세에서 앞으로 찌르기 | 1.0 | 움찔 | 가능 | 패리 예고 |
| 2 | 머리 위로 들어 올렸다가 정면 바닥까지 내려찍기 | 1.4 | 넉다운 | 불가 | 가드 불가 예고 |

- 공격은 각각 1타입니다. 찌르기로 시작하며, 공격을 시작할 때마다 찌르기와 내려찍기를 번갈아 씁니다. 피격 반응이나 그로기로 중단된 공격도 시작한 것으로 셉니다.
- 공격 예고는 [적 시스템](<../../Docs/Design/System/적 시스템.md>)의 '공격 예고'와 같습니다.
- 공격 조건: 샌드백과 플레이어의 캡슐 중심 사이 수평 거리가 3m 이하이고, 공격 대기 시간이 끝났고, 공격·피격 반응·그로기·처형 피격 중이 아닐 때 공격을 시작합니다. 플레이어가 3m보다 멀면 플레이어를 바라보며 서 있습니다.
- 공격 대기 시간: 배치된 순간, 그리고 공격·움찔·넉업·넉다운·그로기·처형 피격이 끝난 순간부터 2초입니다. 이 동안에는 공격하지 않습니다.
- 공격 대상은 플레이어뿐입니다. 공격 판정에 들어온 적에게도 맞습니다. ([전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '공격 판정 세부 규칙')
- 놓인 자리에서 공격하며, 공격 모션에 들어 있는 이동도 하지 않습니다.
- 각 공격은 준비 동작 동안 플레이어를 향해 돌고, 판정 직전에 방향을 확정해(회전 정지) 이후 플레이어의 이동을 따라가지 않습니다. 타겟팅 범위는 샌드백 캡슐 중심에서 반경 3m 안에 플레이어의 캡슐이 닿는 범위이며, 그 밖의 보정은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '공격 중 위치·회전 보정'을 따릅니다.
- 공격이 닿은 극한 회피 구간은 극한 회피를 발동합니다. 패리·가드·가드 브레이크·극한 회피와 그 보상은 [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>)을 따릅니다. 패리로 줄어든 샌드백의 PP가 0 이하가 되면 그로기에 빠집니다.
- 플레이어가 사망하면 진행 중인 공격을 즉시 중단하고 그 자리에서 대기 모션을 유지하며, 더 공격하지 않습니다.

모션: 찌르기 [ARPG_Halberd_Anim_UE_Attack_Combo1](<../../Docs/Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo1.gif>), 내려찍기 [ARPG_Halberd_Anim_UE_Attack_Combo2](<../../Docs/Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo2.gif>)

- 내려찍기는 커스터의 DoubleStrike 2타와 같은 모션을 혼자 시작합니다. 판정 구간과 패리 구간은 모션을 따릅니다.

### 2.6 HP

- 샌드백은 사망하지 않습니다. HP 감소로 HP가 0 이하가 되면 사망 처리 없이 즉시 MaxHP로 회복합니다. 회복은 그 타격의 피격 반응과 그로기 판정을 바꾸지 않습니다.
- 처형 피격 중에 HP가 0 이하가 되어도 위와 같이 회복하며, 처형 사망 모션을 재생하지 않고 처형 피격 모션을 끝까지 재생합니다. 처형 피격이 끝난 뒤의 PP 회복은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '그로기'를 따릅니다.
- 그 밖에 HP는 자동으로 회복하지 않습니다.
- 사망하지 않으므로 시뮬레이션 룸의 Stage Clear 조건과 관계가 없습니다.

### 2.7 피격과 그로기

- 피격 반응, 저글, 그로기, 처형은 [전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 공통 규칙을 그대로 따릅니다.
- 피격·그로기·처형 피격 모션은 [보스 캐릭터 - 커스터](<../../Docs/Design/Content/보스 캐릭터 - 커스터.md>)의 '피격과 그로기'와 같습니다.
- 플레이어에게는 아래 항목에서 샌드백을 적과 같게 다룹니다.

| 항목 | 내용 |
| - | - |
| 락온 | 락온 대상 후보에 들어갑니다. ([카메라와 타겟팅](<../../Docs/Design/System/카메라와 타겟팅.md>)의 '락온') |
| 공격 방향 | 공격 방향을 정하는 '적'에 들어갑니다. ([플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>)의 '공격 방향') |
| MP·UP 충전 | 샌드백에게 공격이 적중하면 적과 같이 충전합니다. |
| 처형 | 그로기 상태의 샌드백도 처형할 수 있고, 처형 안내를 표시합니다. ([플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>)의 '처형') |
| 대미지 숫자 | 플레이어의 공격이 샌드백에게 적중하면 보스와 같은 규칙으로 HP 감소량을 표시합니다. ([전투 시스템](<../../Docs/Design/System/전투 시스템.md>)의 '대미지 숫자') |

- 적의 공격에 맞은 샌드백도 HP·PP가 줄고 피격 반응을 받지만, 대미지 숫자는 표시하지 않습니다.

## 3. 완료 조건 (Acceptance Criteria)

- [ ] 시나리오 1: 시뮬레이션 룸에서 샌드백을 배치하면 놓인 자리에서 놓인 방향을 보고 서 있으며, 플레이어가 주위를 돌아도 돌지 않고 공격하지 않습니다.
- [ ] 시나리오 2: 샌드백에 락온할 수 있고, 락온 없이도 기본 공격이 가장 가까운 샌드백을 향해 보정됩니다. 적중할 때마다 대미지 숫자가 ATK × HP 배율 그대로(DEF 0) 표시되고 MP·UP가 충전됩니다.
- [ ] 시나리오 3: 샌드백의 HP를 0 이하로 만들면 쓰러지지 않고 HP가 즉시 MaxHP로 돌아오며, 그 타격의 피격 반응은 그대로 재생됩니다.
- [ ] 시나리오 4: 움찔·넉업·넉다운·저글이 소형 규칙대로 적용되고, 넉다운으로 밀려난 샌드백은 그 자리에 서 있습니다.
- [ ] 시나리오 5: PP를 0으로 만들면 5초간 그로기에 빠지고 처형 안내가 뜨며, 처형할 수 있습니다. 처형 중 HP가 0 이하가 되어도 처형 피격 모션이 끝까지 재생되고 HP가 MaxHP로 돌아옵니다. 처형이 끝나면 PP가 MaxPP로 회복합니다.
- [ ] 시나리오 6: 공격 샌드백은 플레이어를 바라보며 돌고, 플레이어가 3m 안에 있으면 배치 2초 뒤 찌르기(패리 예고, 움찔)를, 그 공격이 끝나고 2초 뒤 내려찍기(가드 불가 예고, 넉다운)를 번갈아 씁니다. 공격 중 앞으로 움직이지 않습니다. 플레이어가 3m 밖에 있으면 공격하지 않습니다.
- [ ] 시나리오 7: 공격 샌드백의 찌르기를 패리·가드할 수 있고, 내려찍기는 가드해도 일반 피격으로 맞으며, 두 공격 모두 극한 회피를 발동합니다. 패리를 되풀이해 PP를 0으로 만들면 그로기에 빠집니다.
- [ ] 시나리오 8: 공격 샌드백을 공격해 공격을 끊으면 그 공격도 한 번으로 셉니다. 찌르기를 끊었으면 2초 뒤 다음 공격은 내려찍기입니다.
- [ ] 시나리오 9: 일반 적과 함께 배치하면 적은 샌드백을 노리지 않고, 공격 샌드백의 공격 판정에 들어온 적과 적의 공격 판정에 들어온 샌드백은 맞습니다. 이때 대미지 숫자는 뜨지 않습니다.
- [ ] 시나리오 10: 플레이어가 사망하면 공격 샌드백은 공격을 멈추고 대기합니다.
