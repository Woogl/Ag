# 정찰 경로 검증 결과

## 1. 테스트 시나리오

- 동작: 테스트 창, LV_BossStage(게임 중 내비게이션이 있는 맵). 시나리오는 작업 폴더 밖 임시 파일이며 저장소에 두지 않았습니다.
  - 실행: `python -I Scripts/ScenarioTest/run.py <patrol_runtime.py> --hold 3`
  - 준비: 보스 AI는 멈춘 채로 두고, 엔진 `summon`으로 정찰 경로 2개와 절단자 4, 샌드백 1을 만든 뒤 경로를 넣고 AI를 다시 시작합니다. 절단자의 시야는 꺼서 플레이어를 보고 전투에 들어가지 않게 합니다.
  - 공유 경로: A → B → E(아레나 밖 60m, 갈 수 없음) → C → D. 절단자 c1(A 근처)·c2(C 근처)와 샌드백 s1(MOV 0)이 씁니다.
  - 모두 실패 경로: 아레나 밖 두 점. 절단자 c3(처음 방향 90°)가 씁니다. 절단자 c4는 경로가 없습니다.
  - 통과 기준(실행 전에 정함): c1·c2가 가장 가까운 점부터 A→B→C→D 순서로 돌고 E를 방문하지 않음, c3·c4·s1이 처음 자리에서 50cm 안, c3가 처음 방향 ±15°, 로그에 E 경고가 남고 c3는 점마다 한 번(2번)만 경고.
- 에디터: 열린 LV_BossStage에 에디터 파이썬으로 경로·적을 임시로 놓고 확인한 뒤 지웠습니다(맵 저장 안 함). 뷰포트 표시는 MCP `CaptureViewport`로 위에서 찍었습니다.

## 2. 결과

- 빌드: 임시 복사본(HEAD + 이 작업 파일만) `AgEditor` Development 성공(경고 없음). 작업 트리 `Build.bat` 성공. 바닥 고르기 수정과 번호 글꼴 수정은 처음에 라이브 코딩으로 확인한 뒤 에디터를 닫고 `Build.bat`으로 다시 빌드했습니다. 다시 켠 에디터에서 높이 0·−400으로 넣은 점이 아레나 바닥(Z 200.25)에 붙는 것을 확인했습니다.
- 판정(동작): 통과.
  - c1 `ABCDABC`, c2 `CDABCDA`: 가장 가까운 점부터 순서대로, E 방문 없음
  - c3·c4·s1 이동 최대 0cm, c3 처음 방향 0°
  - 로그 `LogAg: Warning: ... cannot walk to patrol point ...` 5줄: c3는 1번·2번 점 한 번씩, E(3번)는 c1이 두 번, c2가 한 번 지날 때마다. `LogAg: Error` 없음
- 판정(에디터): 통과.
  - 배치: 공중(Z 692)에 놓은 경로의 기본 점 2개가 아레나 바닥(Z 200.25)에 붙고, 점 종류는 직선, 닫힌 고리.
  - `set_point_locations`: 높이 5000·−400·0으로 넣은 점 4개가 모두 Z 200.25. 처음 구현은 높이 0·−400을 아레나 바닥 아래 구조물 SM_Cube30 윗면(Z −200, 내비게이션 없음)에 붙였습니다. 내비게이션이 있는 바닥을 먼저 고르게 고친 뒤 다시 확인했습니다.
  - 바닥 없는 점(아레나 밖 500m)은 그대로 두고, 경고 `Patrol point 2 has no floor below it.`와 갈 수 없는 구간 경고 2개.
  - 적: MOV 0 샌드백에 경로를 넣으면 `MOV is 0, so this enemy does not walk its patrol route.` 정상 경로를 쓰는 절단자는 경고 없음. 처음 구현에서 갈 수 없는 점에 붙었을 때는 `Cannot walk from the start position to patrol point 2 of AgPatrolRoute.`가 남았습니다.
  - 편집 중 경고(경로 설정·경로 지정 직후)와 `MAP CHECK`가 같은 경고를 맵 검사 로그에 남깁니다(액터 링크 포함).
  - 표시: 적을 선택하면 경로 고리, 마지막 → 첫 점 구간, 처음 자리 → 가장 가까운 점 구간이 초록 선으로, 점 번호 1~4가 보입니다. 시야 부채꼴(청록)과 구분됩니다. 바닥 없는 점으로 가는 구간은 붉은 직선입니다. 처음 번호 글꼴이 작아 1.6배로 키우고 점 오른쪽 위로 옮겼습니다.
- 로그: `Saved/ScenarioTest/slot1_20261105-010548.json`, `Saved/ScenarioTest/slot1.log`, `Saved/Logs/Ag.log`의 `MapCheck: Warning` 줄

## 3. 회귀 확인

- 경로 없는 절단자와 MOV 0 샌드백은 처음 자리에서 움직이지 않습니다(위 c4·s1).
- 확인하지 못한 것:
  - 뷰포트에서 점을 Alt 드래그로 추가하거나 끌어 놓을 때의 스냅. 엔진이 끌기를 마치면 `PostEditMove(true)` → `OnConstruction`을 부르는 것은 엔진 코드로 확인했고, `OnConstruction` 스냅은 배치로 확인했습니다.
  - 길 정보가 없는 구간의 흐린 회색 선. 확인한 맵에는 에디터 내비게이션이 있었습니다.
  - 전투 후 비전투로 돌아올 때의 정찰 재개. 정찰 태스크 진입은 AI 다시 시작으로 확인했고, 비전투 복귀 전환은 바꾸지 않았습니다.
- 작업 밖에서 찾은 것: LV_DuelCorridor에는 게임 중 내비게이션 데이터가 없어 경로 계산이 모두 실패합니다(정찰과 다가가기 모두 해당). 지금 그 맵에 걷는 적은 없습니다.
