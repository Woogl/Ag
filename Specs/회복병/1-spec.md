# 회복병 사용 작업 명세

## 1. 개요 및 목적

린은 던전에 들어갈 때 여러 번 마실 수 있는 회복병 하나를 챙긴다. 남은 전투를 고려해 회복병을 아껴 쓸지 판단하고, 전투 중에는 적의 공격이 끝난 틈을 골라 마신다.

- **M3**에서 회복병 사용, 잔여 횟수, HUD를 구현한다. 사용 키·회복량·동작 시간은 플레이테스트 초기 제안값이다.

## 2. 플레이 규칙 및 수치

### 회복병을 마실 때

| 항목 | 규칙 |
| - | - |
| 소지 및 충전량 | 던전과 보스 전장에서 기본 소지한다. 새 도전은 3/3회로 시작한다. 같은 도전에서 던전 구역을 지나 보스방으로 들어갈 때는 잔여 횟수를 이어 간다. 시뮬레이션 룸도 3/3회로 시작하고, Restart하면 3/3회로 돌아간다. |
| 사용 입력 | 지상에서 가만히 서 있거나 걷거나 달리는 중에 R을 한 번 누르면 마시기 시작한다. 사용하려면 잔여 횟수가 1회 이상이어야 한다. 조건 밖에서 누른 R은 버리고, 길게 눌러도 한 번만 시도한다. |
| 마시는 중 이동 | 평소 속도로 걷는다. 달리는 중에 R을 누르면 달리기가 끝나고 평소 속도로 걸으며 마신다. 이동을 시작하거나 멈추고 방향을 바꿔도 마시는 동작은 이어진다. 다 마신 뒤 다시 달리려면 [린의 달리기 규칙](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#달리기-sprint>)대로 Shift를 새로 눌러 회피부터 시작한다. |
| 회복량 | 1회에 최대 HP의 40%를 즉시 회복하고 최대 HP에서 멈춘다. 린의 최대 HP가 1,000이면 최대 400을 회복한다. 부족한 HP가 400보다 적거나 HP가 가득 차 있어도 1회를 쓴다. |
| 사용 동작 | 총 1.2초. 병을 들어 한 모금 삼키는 0.8초 시점에 HP 회복과 횟수 1회 차감을 함께 적용한다. 남은 0.4초 동안 병을 내린다. 두 시점은 [시간 규칙](<../../Docs/Design/System/시간 규칙.md>)의 모션 진행을 따른다. |
| 행동 제한 | 이동은 계속 조작할 수 있다. 공격·처형·가드·회피·점프·스킬·궁극기는 병을 내린 뒤에 실행할 수 있다. 기존 전투 입력의 선입력, 시야·락온·일시정지는 [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>)을 따른다. 회복병에는 무적·슈퍼아머가 없다. |
| 중단 | 삼키기 전에 행동을 끊는 피격 반응이나 사망이 발생하면 회복과 차감 없이 끝난다. 삼킨 뒤 끊기면 이미 적용한 회복과 차감은 유지한다. 피격 대미지는 평소처럼 받는다. |

### 플레이어에게 보이는 정보

- 전투 HUD의 화면 왼쪽 아래, 플레이어 상태 바로 위에 회복병 아이콘, R, 잔여/최대 횟수를 표시한다. 마지막 한 모금을 마시면 즉시 0/3으로 바꾸고 아이콘을 흐리게 한다. 타이틀과 전투 HUD의 조작 안내에 ‘R 회복병 사용’을 추가한다. 표시는 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>)의 전투 HUD 표시 규칙을 따른다.
- 삼키는 순간 몸에서 회복을 알리는 효과를 한 번 재생한다. 삼키기 전에 끊기면 재생하지 않는다.

### 아트 에셋 · 회복병 사용 모션 (M3)

- **모션**은 린의 서 있는 자세(Samurai `Idle2`)에 왼팔과 머리 움직임을 더한 전용 모션 `A_Potion_Drink`다. 왼손으로 병을 들어 약 0.38초에 입에 대고, 고개를 젖히며 0.8초에 한 모금을 삼키고, 1.2초에 병을 내리는 동작이 끝난다. 카타나는 오른손에 낮게 둔다.
- **이동 중 표현**은 하체에 기존 대기·걷기 자세를 쓰고, 상체에는 척추부터 팔과 머리까지 마시는 자세를 섞는다. 골반과 발은 이동 모션을 따라가고 병과 입은 함께 움직여야 한다. 현재 그래프에서 제자리 회전에 사용하는 본별 블렌딩을 참고한다. [ABP와 로코모션](<../../Docs/Art/ABP와 로코모션.md>)
- **병**은 엔진 `Cylinder`를 줄인 스탠드인이며, 마시는 동안에만 왼손에 보인다.
- **아이콘**은 병 모양의 `T_Potion`이다. 광택이나 찰랑이는 수면 표현 없이 단순하게 그린다.
- **회복 효과**는 몸을 감싸고 위로 흩어지는 따뜻한 붉은빛의 나이아가라다. 이동 중에도 몸을 따라간다.
- **확인 범위**는 정지·걷기 상태에서 전투 카메라로 삼키는 순간 병 입구가 입에 닿는지 본다.

## 3. 완료 조건

### M3 · 회복병

- [ ] 최대 HP 1,000, 현재 HP 350, 잔여 2회에서 R을 누른다. 삼키기 직전까지 350·2회를 유지하고, 삼키는 순간 750·1회가 된다.
- [ ] 걷는 중 R을 누른다. 이동 속도와 발걸음이 이어지고 상체로 병을 마신다. 도중에 방향을 바꾸거나 멈춰도 원래 0.8초 시점에 한 번만 회복한다.
- [ ] 달리는 중 R을 누른다. 달리기가 바로 끝나 평소 속도로 걸으며 마시고, Shift를 계속 누르고 있어도 다 마신 뒤 다시 달리지 않는다.
- [ ] 삼키는 순간 회복 효과가 한 번 재생된다. 삼키기 전에 끊기면 재생되지 않는다.
- [ ] HP 900에서 마지막 1회를 쓰면 HP 1,000·0/3이 된다. 빈 병으로 R을 눌러도 동작이 시작되지 않는다. HP가 가득 찬 상태에서 R을 누르면 마시는 동작을 하고, HP는 그대로이며 1회를 소비한다.
- [ ] 삼키기 직전과 직후에 각각 움찔을 일으키는 공격을 받는다. 전자는 피격 대미지만 받고 횟수를 보존한다. 후자는 회복된 HP에서 대미지를 받고 소비한 횟수를 유지한다.
- [ ] 공중이나 공격 중 누른 R은 착지나 공격 종료 후에도 자동 실행되지 않는다. R을 누른 채 사용 동작이 끝나도 두 번째 횟수가 소비되지 않는다.
- [ ] 던전 구역에서 보스방으로 이어지는 같은 도전에서는 1/3이 그대로 이어진다. [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 Restart나 타이틀을 통한 새 도전은 HUD에 3/3으로 표시된다.
- [ ] 화면 왼쪽 아래에 회복병 아이콘, R, 잔여/최대 횟수가 표시되고, 마지막 1회를 쓰면 0/3과 흐린 아이콘으로 갱신된다.
