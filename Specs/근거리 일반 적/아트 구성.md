# 근거리 일반 적 — 아트 구성

[절단자 Spec](<1-spec.md>)의 리소스 선정 자료입니다. 기존 에셋을 선정한 문서이며 에셋 적용·수정은 수행하지 않았습니다. 구현·검증을 마친 뒤 확정된 아트 구성은 `Docs/Art`에 반영합니다.

## 외형과 무기

| 항목 | 선정 |
| - | - |
| 캐릭터 | 기존 마네킹 Manny (`SKM_Manny_Simple`) |
| 무기 | 기존 Samurai 팩의 카타나 (`katana`) 1자루 |
| 체격 | [Spec](<1-spec.md>)의 '개요'를 따릅니다. |
| 방패·추가 무기 | 사용하지 않습니다. |
| 신규 제작 | 몬스터 모델, 칼날 팔, 전용 무기를 제작하지 않습니다. |

현재 프로젝트의 마네킹과 ARPG 팩은 같은 스켈레톤을 사용합니다. 원본 구성은 [에셋 조사 개요](<../../Docs/Art/에셋 조사 개요.md>), 검의 부착 정보는 [Samurai 애니메이션 조사](<../../Docs/Art/Samurai 애니메이션 조사.md>)를 참고합니다. 검의 위치·각도와 두 손의 접촉은 적용할 체격에서 확인해야 합니다.

## 레퍼런스

스텔라 블레이드의 크리켓 슬래셔를 인간형 근접 일반 적의 전투 구성 참고로 사용합니다.

- [Gamer Guides 도감](https://www.gamerguides.com/stellar-blade/database/naytiba/naytiba-warrior/cricket-slasher): 두 팔과 중앙의 추가 팔을 무기로 사용하는 형태, 초반 에이도스 7 등장 정보.
- [Neoseeker Silent Street 공략](https://www.neoseeker.com/stellar-blade/walkthrough/Scavenger_Adam_-_Silent_Street): 단발 공격, 짧은 연속 공격, 가드 불가 공격 구성.

이 자료는 전투 구성의 참고입니다. AG의 외형은 위 마네킹과 검으로 표현하며 원작의 신장·프레임·스탯을 재현하는 작업이 아닙니다.

## 공격 모션 선정

아래 Samurai 모션의 전체 이름은 `ARPG_Samurai_Anim_UE_` 뒤에 표의 이름을 붙인 것입니다. 원본 길이는 [Samurai 조사](<../../Docs/Art/Samurai 애니메이션 조사.md>)의 기록이며 적 전용 재생 시간이나 공격 판정 시간이 아닙니다.

| 패턴 | 모션 | 원본 길이 | 선정 이유 |
| - | - | - | - |
| SingleSlash | `Attack_Combo3` | 약 0.87초 | 몸을 비틀었다가 크게 가로로 베어 단발 공격의 궤적이 명확합니다. |
| DoubleSlash 1타 | `Attack_Combo1` | 약 0.82초 | 검을 들어 내려베는 기본 공격입니다. |
| DoubleSlash 2타 | `Attack_Combo2` | 약 0.97초 | 첫 타 뒤 사선 내려베기로 이어져 짧은 연속 공격을 구성합니다. |
| HeavyCleave | `Attack_Combo4` | 약 1.15초 | 검을 머리 위로 크게 들어 내려찍으므로 강한 공격의 전조를 보여 주기 좋습니다. |

### SingleSlash

![단발 베기 원본](<../../Docs/Art/GIF/Samurai/ARPG_Samurai_Anim_UE_Attack_Combo3.gif>)

콤보 도중의 자세에서 시작합니다. 단독 공격으로 사용하려면 대기에서 검을 뒤로 당기는 준비 자세로 자연스럽게 들어가야 합니다.

### DoubleSlash

![2연 베기 첫 타 원본](<../../Docs/Art/GIF/Samurai/ARPG_Samurai_Anim_UE_Attack_Combo1.gif>)

![2연 베기 두 번째 타 원본](<../../Docs/Art/GIF/Samurai/ARPG_Samurai_Anim_UE_Attack_Combo2.gif>)

두 GIF는 개별 시퀀스이며 완성된 2연 베기 미리보기가 아닙니다. 첫 타의 전체 복귀를 재생한 뒤 다음 타를 시작하지 않고, 후속타 준비 자세로 이어지는 지점을 확인합니다. 기존 조사 문서의 연결 시점은 원본 기준 참고값이며 적 전용 템포를 확정한 값이 아닙니다.

### HeavyCleave

![내려찍기 원본](<../../Docs/Art/GIF/Samurai/ARPG_Samurai_Anim_UE_Attack_Combo4.gif>)

콤보 도중의 자세에서 시작하므로 대기에서의 진입을 확인합니다. 검을 머리 위로 올리는 준비 동작을 늘리되 내려치는 동작의 힘은 유지하는 방향으로 조정합니다.

## 대기·이동·피격 모션

| 용도 | 선정 또는 확인 기준 |
| - | - |
| 기본 대기 | Samurai `Idle1` |
| 그로기 반복 | Samurai `Stun` |
| 처형 피격 | Warrior `ARPG_Warrior_Anim_UE_Executed` |
| 처형 사망 | Warrior `ARPG_Warrior_Anim_UE_Executed_Death` |
| 걷기·좌우 이동·제자리 회전 | 기존 인간형 이동 구성을 재사용하는 방향. 검을 든 대기 자세와 자연스럽게 이어지는 최종 모션을 적용 전 확인합니다. |
| 넉업·넉다운·기상 | 기존 공통 인간형 피격 구성을 재사용하는 방향. 공격 종료·그로기·처형과 이어지는 자세를 적용 전 확인합니다. |
| 일반 피격 흔들림 | 기존 강인도 중형의 부위 흔들림 표현을 따릅니다. 기본 공격에 전신 움찔을 넣어 행동을 중단하지 않습니다. |
| 일반 사망 | Spec에서 참조한 공통 사망 규칙을 따릅니다. 별도 사망 공격 모션을 추가하지 않습니다. |

![그로기 원본](<../../Docs/Art/GIF/Samurai/ARPG_Samurai_Anim_UE_Stun.gif>)

처형 피격·사망은 현재 린의 처형과 맞춰 사용하는 Warrior 구성을 재사용합니다. 선정은 완료했지만 절단자의 체격에서 시작 간격, 찌르기와 발차기의 접촉, 사망 동작 전환은 확인하지 않았습니다. [Warrior 조사](<../../Docs/Art/Warrior 애니메이션 조사.md>)와 [Samurai 조사의 Warrior 팩 처형](<../../Docs/Art/Samurai 애니메이션 조사.md#warrior-팩의-처형>)을 참고합니다.

## 예고와 타격 표현

- 공격 예고의 색·구간·효과음 규칙은 [적 시스템](<../../Docs/Design/System/적 시스템.md>)을 따릅니다.
- 예고와 무기 궤적은 팔 대신 장착한 검에서 보여 줍니다.
- 무기 궤적, 피격·패리 VFX, 효과음은 [아트 표현 사양](<../../Docs/Art/아트 표현 사양.md>)의 기존 리소스를 사용합니다.
- 가드 불가 내려찍기는 머리 위 준비 자세와 붉은 예고를 함께 보여 줍니다. 원작의 노란 예고색을 사용하지 않습니다.

## 미리보기와 적용 확인의 구분

- 이번 선정은 기존 조사 문서와 GIF의 주요 프레임 비교에 근거합니다. 에디터에서 모션을 조합하거나 게임에서 판정을 검증하지 않았습니다.
- GIF는 원본 1배속이며 시작·끝 정지 시간이 포함됩니다. 촬영 캐릭터는 Quinn이므로 선정한 Manny에서의 최종 모습과는 다릅니다. 촬영 조건은 [GIF 안내](<../../Docs/Art/GIF/README.md>)를 따릅니다.
- 원본 이동량을 그대로 쓰면 근접 일반 적에게 과한 전진이 생길 수 있습니다. Spec의 모션 조정 항목에 따라 발 미끄러짐·사거리·추적 종료를 함께 확인합니다.
- 타이밍·공격 거리·이동량의 정본은 Spec이며 이 문서에는 조정값을 중복 정의하지 않습니다.
