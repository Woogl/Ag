# 근거리 일반 적 — 절단자 작업 명세 (Spec)

상태: 기획 기준안. 마네킹·검과 사용할 공격 모션을 선정했으며, 모션에 맞춘 최종 타이밍·이동량·실제 사거리는 미확정입니다. 구현·플레이 검증은 수행하지 않았습니다.

## 1. 개요 및 목적

[마일스톤 2](<../../Docs/Milestone/마일스톤 2.md>)의 미니던전에 사용할 인간 크기의 근거리 일반 적 1종을 추가합니다. 플레이어가 준비 자세로 단발 공격·연속 공격·가드 불가 공격을 구분하고, 패리와 회피로 대응한 뒤 반격하는 기본 공방을 제공합니다.

강인도는 중형으로 정합니다. 기본 공격의 움찔에는 적의 공격이 계속되고, 스킬의 넉업으로는 공격을 중단할 수 있습니다. 일반 공격과 스킬로 PP를 깎아 그로기·처형으로 연결할 수 있어야 합니다.

### 작업 범위

- 일반 적 1종의 스탯, 시야, 이동, 공격 패턴, 피격, 그로기, 처형 피격, 사망을 정의합니다.
- 외형은 기존 마네킹과 검을 사용합니다. 별도의 몬스터 모델이나 칼날 팔을 제작하지 않습니다. 리소스와 모션 선정은 [아트 구성](<아트 구성.md>)을 따릅니다.
- 기존 커스터와 린의 전투 규칙·수치는 변경하지 않습니다.
- 네임플레이트는 [적 네임플레이트 Spec](<../적 네임플레이트/1-spec.md>)과 연계합니다. 표시 규칙을 이 문서에서 중복 정의하지 않습니다.
- 던전별 배치 위치·개체 수·승리 조건은 해당 레벨디자인과 게임 흐름 기획에서 정합니다.
- 여러 적은 각자 공통 AI 규칙에 따라 행동합니다. 공격 순번을 배분하거나 동시 공격 수를 제한하는 기능은 포함하지 않습니다.
- 이번 산출물은 문서입니다. 기술 설계·구현·에셋 적용·실행 검증은 수행 범위에 포함하지 않습니다.

## 2. 플레이 규칙 및 수치

### 개요

| 항목 | 내용 |

| 레퍼런스 | 스텔라 블레이드의 크리켓 슬래셔. 인간형 근접 적의 단발·짧은 연속 공격 구성을 참고합니다. |

발견, 지형 가림, 피격에 의한 전투 진입, 시야 상실에 의한 복귀는 적 시스템을 따릅니다.

### 패턴 공통 규칙

#### 모션 템포

- 준비 자세에서 검과 상체를 크게 움직여 패턴과 공격 시점을 읽을 수 있게 합니다.
- 단발 베기는 몸을 옆으로 비트는 자세, 2연 베기는 검을 세워 들어 내리는 자세, 내려찍기는 검을 머리 위로 크게 넘기는 자세로 구분합니다.
- 준비 구간을 충분히 보여 주되 베는 순간의 속도는 유지하는 방향으로 조정합니다.
- 선딜·판정·후딜은 모션 진행을 따릅니다. 원본 GIF의 전체 길이와 실제 패턴 길이는 다르며, 타이밍 목표는 '모션 조정 시 확정할 항목'을 따릅니다.
- 패턴 자체의 후딜이 끝난 뒤 별도의 패턴 후딜레이를 적용합니다.
- 공격 판정 구간은 실제로 검이 베는 구간과 일치해야 하며, 준비·회수 동작에는 판정을 두지 않습니다.

#### 회전

회전 속도는 초당 360°입니다.

- 전투 중 일반 이동·대기 시 플레이어를 바라봅니다. 비전투의 이동·복귀 방향은 적 시스템을 따릅니다.
- 공격의 각 타는 준비 동작 중에만 플레이어를 향해 회전합니다. 방향을 확정한 이후 다음 추적 구간 전까지 플레이어의 이동을 따라가지 않습니다.
- 2연 베기는 첫 타와 두 번째 타의 추적 구간을 구분합니다. 첫 타 판정이 끝난 뒤 두 번째 타 준비 동작에서만 다시 방향을 보정합니다.
- 피격으로 행동이 중단된 동안, 그로기, 처형 피격 중에는 일반 목표 방향 회전을 하지 않습니다.
- 회전 정지 시점의 수치 목표는 '모션 조정 시 확정할 항목'을 따릅니다.

#### 이동

- 발동 가능한 패턴이 없으면 플레이어에게 MOV 속도로 다가갑니다.
- 공격 중 위치·회전 보정은 전투 시스템을 따릅니다. 타겟팅 범위는 반경 12m 안에 플레이어의 캡슐이 닿는 범위로 합니다.
- 대상과의 최소 간격은 캡슐 중심 사이 수평 거리 1.2m를 기준으로 합니다.
- 위치 보정은 각 타의 추적 구간 안에서만 수행합니다. 보정 목표는 구간 시작 시 한 번 정하고 대상의 이동을 따라 갱신하지 않습니다.
- 추적 구간이 끝난 뒤 다음 타의 추적 구간 전까지 추가 접근하지 않습니다.
- 이동 중 벽과 캐릭터의 충돌을 유지하며 통과하지 않습니다.
- 원본 모션의 전체 전진량을 그대로 적용하지 않습니다. 최종 전진량·추적 구간·발동 거리의 조합은 '모션 조정 시 확정할 항목'에 따라 확인합니다.

#### 패턴 후딜레이

- 대기 시간은 매번 0.6~1.0초 중 무작위로 정합니다.
- 대기 중에는 플레이어를 바라보며 좌우로 걷습니다.
- 전투 진입, 공격 종료, 피격 반응 종료 등에 후딜레이를 적용하는 조건은 적 시스템을 따릅니다.

| 페이즈 | HP 구간 | 특징 |
| - | - | - |
| 1페이즈 | 0% 초과~100% | 패턴 3종 사용 |

HP 감소에 따른 페이즈 전환이나 패턴 변화는 없습니다.

### 패턴 목록

| ID | 설명 | 페이즈 | 발동 가능 거리 기준안 | 가중치 | 가드 가능 | 쿨다운 |
| - | - | - | - | - | - | - |
| SingleSlash | 한 번 가로 베기 | 1 | 0~2.0m | 6 | 가능 | 없음 |
| DoubleSlash | 내려베기 후 사선 내려베기 | 1 | 0~2.0m | 3 | 두 타 모두 가능 | 4초 |
| HeavyCleave | 크게 준비한 뒤 내려찍기 | 1 | 0~2.3m | 1 | 불가 | 8초 |

- ID는 이 명세에서 패턴을 구분하기 위한 이름입니다.
- 발동 가능 거리는 캡슐 중심 사이 수평 거리이며 양 끝값을 포함합니다. 실제 도달 범위 확인 전의 기준안입니다.
- 거리·쿨다운 조건을 만족한 후보 중 가중치로 선택합니다. 후보에 따라 확률이 달라지며 가중치 자체는 고정 확률이 아닙니다.
- 쿨다운은 패턴 시작 시부터 계산하며 중단되어도 초기화하지 않습니다.
- 공격 대상인 플레이어는 그로기 면역이므로 이 적의 공격 PP 배율은 0입니다.
- 공격 판정은 실제 검의 궤적에 맞춥니다. 발동 가능 거리 자체를 공격 범위로 사용하지 않습니다.

### 패턴 상세

모션과 GIF는 [아트 구성](<아트 구성.md>)을 따릅니다. 원본 GIF에는 적 전용 속도·이동량·판정·상대 캐릭터가 반영되지 않았습니다.

#### SingleSlash — 단발 베기

몸을 비틀고 검을 뒤로 당겼다가 정면을 가로지르며 한 번 벱니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 몸통을 돌리며 가로 베기 | 1.0 | 움찔 | 가능 |

- 선정 모션: Samurai `Attack_Combo3`.
- 패턴 전조 동작: 몸통을 옆으로 비틀고 검을 뒤로 당기는 준비 자세를 보여 줍니다. 원본이 콤보 중간 자세에서 시작하므로 대기 자세에서 준비 자세로 들어가는 연결을 확인해야 합니다.
- 공격 예고: 적 시스템의 패리 예고를 적용합니다.
- 빗나가도 정해진 회수 동작과 후딜을 수행합니다.
- 설계 의도: 단발 공격을 패리하거나 피한 뒤 검을 회수하는 틈에 반격하게 합니다.

#### DoubleSlash — 2연 베기

검을 들어 내려벤 뒤, 검을 다시 들어 사선으로 내려벱니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 검을 세워 들어 내려베기 | 0.8 | 움찔 | 가능 |
| 2 | 검을 다시 들어 사선 내려베기 | 0.8 | 움찔 | 가능 |

- 선정 모션: Samurai `Attack_Combo1` → `Attack_Combo2`.
- 패턴 전조 동작: 검을 위로 세워 들며 첫 번째 내려베기를 준비합니다. 첫 타 뒤에는 대기 자세로 복귀하지 않고 두 번째 준비 동작으로 이어갑니다.
- 공격 예고: 각 타에 패리 예고를 적용합니다.
- 첫 타가 빗나가거나 패리되어도 두 번째 타를 수행합니다. 사망·그로기·행동을 중단시키는 피격 반응이나 플레이어 사망에 따른 전환은 공통 규칙대로 우선 적용합니다.
- 설계 의도: 첫 타를 막은 직후 공격하기보다 후속타까지 확인하게 합니다. 마지막 타 뒤의 후딜이 반격 기회입니다.

#### HeavyCleave — 내려찍기

검을 머리 위로 크게 넘겨 준비한 뒤 정면 아래로 내려찍습니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 머리 위에서 정면 아래로 내려찍기 | 1.5 | 넉다운 | 불가 |

- 선정 모션: Samurai `Attack_Combo4`.
- 패턴 전조 동작: 두 팔과 검을 머리 위로 크게 들어 올리는 동작을 충분히 보여 줍니다. 대기 자세에서 원본의 시작 자세로 들어가는 연결을 확인해야 합니다.
- 공격 예고: 적 시스템의 붉은 가드 불가 예고를 적용합니다.
- 판정은 검이 내려오는 전방 궤적에만 발생하며 별도의 충격파는 없습니다.
- 내려찍은 뒤 검을 낮게 둔 회복 동작을 보여 줍니다.
- 설계 의도: 회피 후 긴 후딜에 반격하게 합니다. 스킬의 넉업으로 준비 동작을 중단할 수도 있습니다.

### 피격과 그로기

#### 피격

- 강인도 중형의 공통 피격 규칙을 적용합니다.
- 움찔 공격에는 맞은 부위가 흔들리며 진행 중인 행동을 유지합니다.
- 넉업·넉다운이 적용되면 진행 중인 패턴을 중단합니다. 중단된 패턴의 남은 타격은 발생하지 않습니다.
- 슈퍼아머와 자체 무적 구간은 없습니다.
- 피격 반응이 끝난 뒤의 행동 전환은 적 시스템을 따릅니다.

#### 그로기

- PP 소진 시 공통 그로기 규칙을 적용합니다.
- 진행 중인 공격을 중단하고 상체와 검을 아래로 늘어뜨린 무방비 자세를 보여 줍니다.
- HP 감소, 피격 반응, 지속 시간, 종료 시 PP 회복은 전투 시스템을 따릅니다.
- 그로기가 끝나 행동 가능 상태가 되면 패턴 후딜레이를 거쳐 다음 패턴을 선택합니다.

#### 처형 피격

- 지상에서 그로기 상태이고 린의 처형 조건을 만족하면 처형 대상이 됩니다. 일반 적도 공통 조건에 맞게 처형 안내를 표시해야 합니다.
- 처형 시작 시 상태 전환과 PP 처리는 전투 시스템을 따릅니다.
- 린의 찌르기와 마지막 일격에 맞춰 처형 피격 동작을 재생합니다.
- 처형 피격 종료 시 살아 있으면 패턴 후딜레이를 거쳐 다음 패턴을 선택합니다.
- 처형 피격·사망 동작의 템포는 린의 처형 동작과 일치해야 합니다. 체격과 검의 조합에 맞는 두 캐릭터의 간격도 확인합니다.

### 연출

#### 페이즈 전환

페이즈 전환 연출은 없습니다.

#### 사망

- HP가 0 이하가 되면 전투 시스템의 사망 처리를 적용합니다.
- 처형으로 사망하면 처형 사망 동작으로 이어지며, 이후 처리는 공통 규칙을 따릅니다.
- 사망한 개체는 공격하거나 다른 캐릭터의 이동을 막지 않습니다.
- 일반 적의 처치에는 보스 처치 슬로우모션이나 Stage Clear를 적용하지 않습니다.
- 락온 해제는 카메라와 타겟팅의 공통 규칙을 따르며, 네임플레이트의 사망 시 처리는 해당 Spec을 따릅니다.

## 3. 완료 조건 (Acceptance Criteria)

아래 항목은 후속 구현의 통과 조건입니다. 현재는 실행하거나 통과 처리하지 않았습니다.

### 외형과 공격 식별

- [ ] 기존 마네킹과 검을 사용하며, 직립 신장이 플레이어의 약 1.05배로 보인다.
- [ ] 단발 베기·2연 베기·내려찍기가 준비 자세로 구분된다.
- [ ] 대기에서 단발 베기·내려찍기로 진입할 때 자세가 갑자기 바뀌지 않는다.
- [ ] 2연 베기의 연결이 자연스럽고, 첫 타 이후에도 두 번째 공격을 준비한다는 것을 식별할 수 있다.
- [ ] 패리 예고와 가드 불가 예고가 공통 규칙에 맞게 출력된다.
- [ ] 실제 베기 궤적과 공격 판정이 일치하고 준비·회수 동작에는 피해가 발생하지 않는다.
- [ ] 모션 조정 표의 타이밍·이동량·실제 사거리를 확인하고 Spec의 확정값으로 반영했다.

### AI와 패턴

- [ ] 시야·지형 가림·피격 조건에 따라 전투에 진입한다.
- [ ] 거리·쿨다운·가중치 조건에 맞게 패턴을 선택하고 후보가 없으면 접근한다.
- [ ] 각 타의 추적 구간 종료 후 플레이어를 따라 회전하거나 추가 접근하지 않는다.
- [ ] 발동 거리 상한에서 움직이지 않는 정면 대상에게 공격이 닿으며, 방향 확정 후 궤적 밖으로 벗어난 대상에게는 닿지 않는다.
- [ ] 각 공격 판정은 같은 대상에게 한 번만 적중한다.
- [ ] 2연 베기는 첫 타가 빗나가거나 패리되어도 이어지고, 행동 중단 조건 발생 시 남은 타격이 취소된다.
- [ ] HP 감소에 따른 페이즈 전환이 발생하지 않는다.
- [ ] 시야 상실 후 공통 조건을 만족하면 복귀하며 HP·PP와 쿨다운을 초기화하지 않는다.
- [ ] 플레이어 사망 시 공격을 중단하고 공통 비전투 대기 상태로 전환한다.

### 전투 수치와 상태

아래는 현재 린의 스탯과 본문의 적 스탯을 대미지 공식에 대입한 기대값입니다. 실제 실행 결과가 아닙니다. 각 시나리오는 별도로 시작하며 절단자의 HP·PP는 최대, PP 리젠은 발생하지 않는 연속 적중 조건입니다. 린의 기본 공격은 1타부터 순서대로 사용합니다. 스킬 시나리오는 MP가 충분한 상태에서 시작합니다.

| 확인 시나리오 | 통과 기준 |
| - | - |
| 린 기본 공격 1~4타 적중 | 절단자 HP 200, PP 소진으로 그로기 |
| 린 기본 공격 5타 전체 적중 | 절단자 HP 80 |
| 위 상태에서 다음 기본 공격 1타 적중 | 절단자 사망 |
| 린 스킬 1회와 기본 공격 1·2타 적중 | 절단자 HP 280, PP 소진으로 그로기 |
| 단발 베기가 방어하지 않는 린에게 적중 | 린 HP 80 감소 |
| 2연 베기가 방어하지 않는 린에게 모두 적중 | 린 HP 총 128 감소 |
| 내려찍기가 방어하지 않는 린에게 적중 | 린 HP 120 감소 |

- [ ] 단발·2연 베기에 가드와 패리가 작동하며, 내려찍기는 가드·패리로 막을 수 없다.
- [ ] 움찔 피격에는 행동을 유지하고 넉업·넉다운에는 행동이 중단된다.
- [ ] 그로기·처형·사망의 상태 전환과 PP 회복이 공통 규칙에 맞는다.
- [ ] 처형 가능한 일반 적에게 안내가 표시되고, 처형의 위치·피격·사망 동작이 맞물린다.
- [ ] 일반 적도 락온할 수 있으며 사망 시 락온이 해제된다.
- [ ] 네임플레이트는 별도 Spec에 따라 연동되며 보스 전용 상태 표시를 사용하지 않는다.
- [ ] 일반 적 사망으로 보스 처치 연출이나 던전 클리어가 발생하지 않는다.

### 플레이 검증

- [ ] 평지에서 패턴을 숙지한 플레이어가 온전한 HP·PP의 적 1마리와 전투한다. 린은 문서 기본 스탯에 HP·SP 최대, MP·UP 0으로 시작하고, 기본 공격·패리·가드·회피·스킬·처형을 사용할 수 있다. 궁극기는 사용하지 않는다. 전투 진입부터 적 HP가 0이 될 때까지 실제 시간을 측정한다.
- [ ] 위 조건으로 5회 교전하고 중앙값이 목표 전투 시간 안에 드는지 확인한다. 목표를 벗어나면 원인과 조정안을 기록하며 통과로 처리하지 않는다.
- [ ] 기본 공격을 계속하는 중에도 적의 전조에 대응할 수 있고, 스킬로 공격을 끊는 선택이 유효하다.
- [ ] 접근 거리를 다르게 둔 2마리와 교전할 때 한 적을 상대하는 중 다른 적의 전조를 확인하고 대응할 수 있다. 배치 거리와 결과를 검증 기록에 남긴다.
