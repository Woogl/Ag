# 아이템 시스템 Spec

## 1. 개요 및 목적

- 린이 가지는 아이템을 소비 아이템과 재화 아이템으로 나누고, 아이템을 가지고 쓰는 규칙을 정합니다.
- 회복병을 소비 아이템으로 옮깁니다. 회복병의 키, 마시는 동작, 회복량, 최대 3개, HUD 칸은 지금과 같습니다.
- 아이템 목록에는 회복병 하나만 둡니다. 재화 아이템은 카테고리 규칙만 만듭니다.

## 2. 플레이 규칙 및 수치

### 2.1 공통

| 항목 | 규칙 |
| - | - |
| 카테고리 | 아이템마다 소비 아이템, 재화 아이템 중 하나입니다. |
| 보유 수 | 린은 아이템마다 0개부터 그 아이템의 최대 보유 수까지 가집니다. |
| 얻기 | 보유 수는 최대 보유 수까지만 늘고, 넘는 만큼은 버려집니다. |
| 쓰기 | 쓰거나 내는 수가 보유 수보다 많으면 쓰지 않고, 보유 수도 그대로입니다. |
| 시작 | 스테이지에 들어갈 때마다 '아이템 목록'의 시작 보유 수로 시작합니다. Restart나 타이틀을 거쳐 다시 들어와도 같습니다. 한 스테이지 안에서는 던전 구역을 지나 보스방으로 들어가도 보유 수가 이어집니다. |

### 2.2 소비 아이템

- 소비 아이템은 그 아이템을 쓰는 행동으로 씁니다. 행동이 아이템을 쓰는 순간에 보유 수가 1 줄고, 그 전에 행동이 끊기면 줄지 않습니다.
- 그 아이템이 0개이면 그 행동을 시작할 수 없습니다.

### 2.3 재화 아이템

- 재화 아이템은 보유 수가 곧 가진 양입니다.

### 2.4 아이템 목록

| 아이템 | ID | 카테고리 | 최대 보유 수 | 시작 보유 수 | 쓰는 행동 |
| - | - | - | - | - | - |
| 회복병 | `Potion` | 소비 아이템 | 3 | 3 | [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md#회복병-potion>)의 '회복병'. 0.8초에 삼키는 순간 1개를 씁니다. |

### 2.5 기존 기획서와의 관계

- 위 규칙은 새 기획서 `Docs/Design/System/아이템 시스템.md`에 둡니다.
- [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>): '스탯' 표의 Potion / MaxPotion 행을 뺍니다. '회복병' 표의 '횟수' 행은 아이템 시스템의 '시작'을 따르고, 잔여 횟수와 1회 차감은 회복병 보유 수와 회복병 1개 쓰기로 바꿉니다.
- [UI 시스템](<../../Docs/Design/System/UI 시스템.md>) '플레이어 상태': 회복병 칸은 회복병이 0개이면 흐리게 표시하고, 회복병 횟수는 '보유 수/최대 보유 수'로 표시합니다.
- [용어집](<../../Docs/용어집.md>): 회복병의 뜻을 소비 아이템으로 바꾸고, 아이템 카테고리 용어를 더합니다.

## 3. 완료 조건 (Acceptance Criteria)

재화 아이템 항목은 시험하는 동안에만 데이터에 더하는 시험용 재화 아이템과 치트 명령으로 확인합니다.

- [ ] 스테이지에 들어가면 회복병 칸이 3/3이고, 마실 때마다 0.8초에 하나씩 줄어듭니다. 0/3이면 칸이 흐려지고 R을 눌러도 마시지 않습니다.
- [ ] 0.8초 전에 피격으로 끊기면 회복병이 줄지 않습니다. 이동하며 마시기, 달리다 마시면 걷기 같은 회복병의 나머지 규칙도 그대로입니다.
- [ ] 회복병을 마신 뒤 Restart, 타이틀을 거쳐 다시 들어오기, 다른 스테이지 들어가기 모두 3/3으로 시작합니다.
- [ ] 회복병이 3개일 때 더 얻어도 3개이고, 1개일 때 3개를 얻으면 3개가 됩니다.
- [ ] 재화를 얻으면 최대 보유 수까지 늘고, 가진 양보다 많이 내려 하면 아무것도 바뀌지 않으며, 가진 양 이하를 내면 그만큼 줄어듭니다.
- [ ] 재화를 얻고 회복병을 마신 뒤 Restart하면 재화와 회복병이 시작 보유 수로 돌아옵니다.
