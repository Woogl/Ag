# 상호작용 Spec

## 1. 개요 및 목적

F 키로 가까운 대상에 하는 행동을 모두 **상호작용**으로 묶습니다. 처형도 상호작용의 한 종류입니다.

- F로 하는 행동은 종류와 관계없이 같은 순서로 대상을 하나 고르고, 같은 모양의 안내를 그 대상 위에 띄우고, 같은 입력 규칙을 따릅니다. 플레이어는 "안내가 떠 있는 대상에 F를 누르면 안내에 적힌 행동이 일어난다"는 한 가지만 익히면 됩니다.
- M3에서 상호작용할 수 있는 대상은 그로기 상태의 적(처형)과 [스테이지 - 미니던전 요새 돌파](<../../Docs/Design/Level/스테이지 - 미니던전 요새 돌파.md>)의 성문(성문 열기) 두 가지입니다.
- 처형의 발동 조건, 대상 선택, 모션, 대미지는 바꾸지 않습니다. 바뀌는 것은 안내의 모양과, F 입력을 '처형'이 아니라 '상호작용'으로 부르는 것입니다.
- 이 Spec은 `Specs/성문 상호작용/1-spec.md`를 합쳐 대신합니다. 성문의 상태, 열리는 동작, 거리, 시간은 그 Spec의 값을 그대로 옮겼습니다. 안내의 위치(화면 가운데 아래 고정 → 성문 위)와 처형과 겹칠 때의 처리만 아래 공통 규칙으로 바꿨습니다.
- 성문의 상호작용 거리 1m, 열리는 시간 2초, 안내 지점의 높이 2m는 플레이테스트 초기 제안값입니다.

## 2. 플레이 규칙 및 수치

### 2.1 상호작용 후보

아래 조건을 만족하는 대상이 상호작용 후보입니다.

| 종류 | 안내에 적는 행동 | 후보가 되는 조건 |
| - | - | - |
| 적 | 처형 | [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>) '처형'의 발동 조건 1·2번(그로기 상태, 처형 범위 안)을 만족하고 처형 피격 중이 아닌 살아 있는 적 |
| 성문 | 성문 열기 | 닫혀 있고 아직 열리기 시작하지 않은 성문. 린의 캡슐 중심이 성문의 상호작용 범위 안에 있어야 합니다. |

- 성문 같은 장치는 장치마다 상호작용 범위를 가집니다. 범위는 장치 둘레에 정한 공간이며, 린의 캡슐 중심이 그 안에 있으면 범위 안입니다.

### 2.2 상호작용 대상

후보 가운데 하나만 상호작용 대상이 됩니다. 아래 순서로 고릅니다.

1. 처형할 수 있는 적이 있으면 그 적입니다. 여럿이면 [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>) '처형'의 대상 선택(락온 대상 우선, 그다음 가장 가까운 적)을 따릅니다.
2. 처형할 수 있는 적이 없으면, 범위 안에 있는 장치 가운데 린의 캡슐 중심에서 안내 지점까지의 거리가 가장 가까운 장치입니다.

- 상호작용 대상은 매 순간 다시 고릅니다. 린이나 대상이 움직여 조건이 바뀌면 바로 바뀝니다.
- 처형이 장치보다 우선하므로, 성문의 범위 안에 있어도 처형할 수 있는 적이 있으면 그 적이 상호작용 대상입니다.

### 2.3 입력

| 항목 | 규칙 |
| - | - |
| 입력 키 | F |
| 실행 | F를 누르면 그 순간의 상호작용 대상에 안내에 적힌 행동을 합니다. 상호작용 대상이 없으면 아무 일도 일어나지 않습니다. |
| 한 번만 실행 | 한 번 누르면 한 번만 실행합니다. 누르고 있어도 반복하지 않습니다. |
| 입력할 수 있는 상태 | [플레이어 시스템](<../../Docs/Design/System/플레이어 시스템.md>) '상태별 허용 입력'에서 지금까지 처형 입력을 허용하던 상태와 같습니다. 표의 '처형'을 '상호작용'으로 바꿉니다. 상호작용의 종류에 따라 달라지지 않습니다. |
| 선입력 | 기억하지 않습니다. 입력할 수 없는 상태에서 누른 F는 버립니다. |

- 적에게 하는 상호작용(처형)은 린의 액션입니다. 실행한 뒤의 진행은 [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>)의 '처형'을 따릅니다.
- 장치에 하는 상호작용(성문 열기)에는 린의 모션이 없습니다. F를 누른 뒤에도 린은 하던 대로 움직이고 행동할 수 있습니다.

### 2.4 상호작용 안내

상호작용 대상이 있는 동안 그 대상 위에 안내를 하나 표시합니다. [UI 시스템](<../../Docs/Design/System/UI 시스템.md>) '전투 HUD'의 '처형 안내'를 대신합니다.

| 항목 | 규칙 |
| - | - |
| 구성 | 왼쪽부터 키 표시, 행동 이름 순서입니다. (예: 키 표시 F, 행동 이름 '처형') |
| 키 표시 | 지름 36px의 원입니다. 스킬 슬롯과 같은 반투명한 어두운 바탕에 얇고 옅은 흰 테두리를 두고, 가운데에 키 이름(F)을 굵은 글자 Medium으로 적습니다. 키 이름은 UI 스타일의 '입력 키 표시'를 따릅니다. |
| 행동 이름 | 키 표시 오른쪽에 8px 띄우고 세로 가운데를 맞춰 글자 Large로 적습니다. 밝은 배경 위에서도 읽히도록 글자에 어두운 외곽선을 두릅니다. |
| 위치 | 대상의 안내 지점 오른쪽에 둡니다. 키 표시의 왼쪽 끝을 안내 지점에서 오른쪽으로 22px 띄우고, 세로 가운데를 안내 지점에 맞춥니다. 대상이 움직이면 따라가고, 카메라 거리와 관계없이 화면상 크기를 유지합니다. |
| 안내 지점 | 적은 락온 지점입니다. 안내가 락온 마커의 오른쪽 가장자리에서 12px 떨어진 자리에 놓이며, 락온 마커가 표시되지 않을 때도 같은 자리입니다. 장치는 장치마다 정한 지점입니다. |

- 안내는 상호작용 대상 하나에만 표시합니다. 대상이 바뀌면 즉시 새 대상으로 옮기고, 대상이 없어지면 즉시 숨깁니다.
- 기본 공격이나 회피 중이라 잠시 F를 입력할 수 없을 때도 숨기지 않습니다.
- 안내 지점이 화면 밖에 있으면 안내는 보이지 않습니다. 화면 가장자리에 붙이지 않으며, 이때도 F는 동작합니다.
- 숨기는 상황은 [UI 시스템](<../../Docs/Design/System/UI 시스템.md>) '상황별 표시 규칙'의 처형 안내와 같습니다. (궁극기 컷신, 스테이지 결과 연출, 전투 결과 UI)
- 레이어에 넣지 않고 모든 레이어보다 아래에 표시합니다.

### 2.5 성문

위치는 [스테이지 - 미니던전 요새 돌파](<../../Docs/Design/Level/스테이지 - 미니던전 요새 돌파.md>)의 '성문'을 따릅니다. 이 던전에서 플레이어가 상호작용하는 장치는 성문 하나뿐입니다.

| 항목 | 규칙 |
| - | - |
| 위치와 크기 | 성문 단(높이 6m) 위, 성문 앞 구간 입구 맞은편 벽의 가운데. 폭 약 5m. 레벨에서는 현재 문틀(`FB_Gate_GatePillarS`, `GatePillarN`, `GateLintel`) 사이의 빈 자리에 둡니다. |
| 처음 상태 | 닫혀 있습니다. 닫힌 성문은 플레이어와 적의 이동, 시선, 탄환을 모두 막습니다. |
| 여는 조건 | 없습니다. 성문 앞에 적이 남아 있어도 열 수 있습니다. 기획서 '성문'의 여는 조건(성문 앞 적 5명 처치)은 이 Spec으로 덮어씁니다. |
| 상호작용 범위 | 성문의 폭 전체에서, 성문 면으로부터 앞뒤 1m까지입니다. |
| 안내 지점 | 성문 폭의 가운데, 바닥에서 2m 높이입니다. |
| 열리는 중 | 상호작용하면 성문이 약 2초 동안 위로 올라갑니다. 다 올라가기 전까지는 이동, 시선, 탄환을 계속 막습니다. 열리기 시작한 성문은 상호작용 후보에서 빠지므로 안내가 바로 사라지고, 다시 F를 눌러도 성문에는 아무 일도 일어나지 않습니다. |
| 열린 뒤 | 끝까지 올라간 성문은 이동, 시선, 탄환을 막지 않고, 다시 닫히지 않습니다. |
| 재도전 | [게임 플로우](<../../Docs/Design/System/게임 플로우.md>)의 Restart나 타이틀을 통한 새 도전에서는 닫힌 상태로 다시 시작합니다. |

- 레벨에서는 성문 가까이에 적을 두지 않아 처형과 성문 열기가 겹치는 일이 드물게 합니다.

## 3. 완료 조건 (Acceptance Criteria)

### 공통

- [ ] 키 배치표와 조작 안내 팝업의 F 줄이 '상호작용'이다.
- [ ] 상호작용 대상이 없는 곳에서 F를 누르면 아무 일도 일어나지 않는다.
- [ ] 안내는 언제나 하나만 보이고, 키 표시(원 안의 F)와 행동 이름으로 이루어져 있다. 처형과 성문 열기의 안내가 행동 이름만 다르고 모양이 같다.
- [ ] 궁극기 컷신과 스테이지 결과 연출 중에는 안내가 보이지 않는다.

### 처형

- [ ] 적을 그로기에 빠뜨리고 3m 안으로 다가가면 그 적의 락온 지점 오른쪽에 'F 처형' 안내가 뜬다. 3m 밖으로 나가거나 그로기가 끝나면 사라진다.
- [ ] 안내가 뜬 상태에서 F를 누르면 지금까지와 같이 처형이 실행된다. 처형 모션, 대미지, 처형 카메라가 달라지지 않는다.
- [ ] 그로기인 적이 둘 이상 범위 안에 있으면 안내는 락온 대상(없으면 가장 가까운 적) 하나에만 뜨고, F를 누르면 안내가 뜬 적을 처형한다.
- [ ] 기본 공격 도중(후딜 전)에 그로기인 적이 범위 안에 있으면 안내는 떠 있고, F를 눌러도 처형하지 않는다. 후딜부터는 F로 처형한다.

### 성문

- [ ] 레벨을 시작하면 성문이 닫혀 있다. 린이 성문을 지나갈 수 없고, 성문 너머의 커스터가 보이지 않는다. 성문 앞 사수가 성문 쪽으로 쏜 탄환은 성문에 막힌다.
- [ ] 성문 앞 적이 모두 살아 있는 상태에서 성문에서 1m 안에 들어온다. 성문 가운데 위에 'F 성문 열기' 안내가 뜨고, 1m 밖으로 나가면 사라진다.
- [ ] 안내가 뜬 상태에서 F를 누른다. 안내가 바로 사라지고, 성문이 약 2초 동안 올라간다. 올라가는 도중에는 지나갈 수 없고, 다 올라간 뒤에는 지나가서 통로 너머의 커스터가 보인다.
- [ ] F를 길게 누르거나 여러 번 눌러도 성문은 한 번만 열린다. 열린 성문은 보스 아레나에 들어가도 다시 닫히지 않는다.
- [ ] F를 누른 직후에도 린이 멈추지 않고 이동, 공격, 회피를 할 수 있다.
- [ ] 성문에서 1m 밖에서는 F가 처형으로만 동작한다.
- [ ] 성문에서 1m 안에 있고 처형할 수 있는 적이 가까이 있으면 안내는 그 적에 '처형'으로 뜬다. F를 누르면 처형이 실행되고 성문은 닫힌 채로 남는다. 처형이 끝난 뒤 안내가 성문으로 옮겨 가고, 다시 F를 누르면 성문이 열린다.
- [ ] 성문을 연 뒤 Restart로 다시 시작하면 성문이 닫힌 상태로 돌아온다.
