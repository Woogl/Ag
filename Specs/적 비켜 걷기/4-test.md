# 적 비켜 걷기 검증 결과

## 1. 테스트 시나리오

- 시나리오 실행 명령: `python -I Scripts/ScenarioTest/run.py <시나리오> --map "<맵>"`
- 공유 에디터를 다른 작업이 쓰고 있어, HEAD에 이번 C++ 변경만 얹은 임시 복사본(`Content` 연결)에서 빌드하고 그 복사본의 `run.py`로 실행했습니다. 비교 기준(변경 전)은 저장소의 빌드(변경 전 DLL)로 같은 시나리오를 실행했습니다.
- 적이 공격하지 않고 '기다리는 중'으로만 움직이도록, 플레이어에게 처형 상태 태그를 붙여 패턴 시작을 막았습니다.
- 통과 기준은 실행 전에 정했습니다. 캡슐 간격 = 캡슐 중심 수평 거리 − 두 캡슐 반지름. "닿지 않음" = 간격 1cm 이상.

| 시나리오 | 맵 | 확인하는 완료 조건 | 통과 기준 |
| - | - | - | - |
| 다가가며 돌아감 | 시뮬레이션 룸, 절단자 2 | 다가가는 적이 서 있는 적을 돌아감 | 앞 10m의 적이 8초 안에 4m 안에 들고, 6.5m에 서 있는 적과 닿지 않음 |
| 넷이 기다리며 돎 | 시뮬레이션 룸, 절단자 4 | 마주 걷는 두 적이 비켜 지나감, 넷이 기다리는 동안 부딪히지 않음 | 3m 둘레에 35°씩 붙여 둔 넷이 15초 동안 서로 닿지 않고, 떨어지지 않음 |
| 좌우 걷기 속력과 벽 앞 멈춤 | 시뮬레이션 룸, 절단자 1 | 벽 앞 멈춤(회귀), 걸음이 끊기지 않음 | 좌우 걷기 중 프레임 95% 이상이 MOV의 85% 이상. 벽 쪽 내비메시 끝으로 30° 비스듬히 물러나 3초 안에 끝 앞(−30 ~ +10cm)에 서고 옆으로 10cm 넘게 벗어나지 않음 |
| 정찰하며 돌아감 | 시뮬레이션 룸, 절단자 2 | 정찰하는 적이 서 있는 적을 돌아감 | 정찰 지점 사이 가운데에 서 있는 적을 8초 안에 지나가고 닿지 않음 |
| 보루 가장자리 | 요새 돌파 | 비켜 걷다가 낭떠러지를 넘지 않음 | 보루 끝 사수가 가장자리로 물러나고 옆의 절단자가 좌우 걷기를 하는 10초 동안 둘 다 떨어지지 않고, 사수는 가장자리를 10cm 넘지 않음 |

## 2. 결과

- 빌드: 임시 복사본 `AgEditor Win64 Development` 성공. `Scripts/FormatCpp.ps1` 검사 통과(바꾼 C++ 3개).
- 판정: 새 빌드에서 다섯 시나리오 모두 통과했습니다.

| 시나리오 | 새 빌드 | 변경 전 빌드 |
| - | - | - |
| 다가가며 돌아감 | 통과. 2.97초에 4m 안, 서 있는 적과 최소 간격 34.9cm | 실패. 서 있는 적에 막혀 7.2m에서 멈춤(간격 0.1cm) |
| 넷이 기다리며 돎 | 통과. 최소 간격 2.4cm, 간격 5cm 아래인 프레임 705개 중 5개, 평균 속력 232~248cm/s | 실패. 706프레임 중 185프레임 맞닿음, 평균 속력 214~220cm/s |
| 좌우 걷기 속력과 벽 앞 멈춤 | 통과. 좌우 걷기 속력 250cm/s 유지, 0.29초에 끝 앞 6.5cm에 섬, 옆으로 8.9cm | 통과. 끝 앞 0.1cm에 섬, 옆으로 1.0cm |
| 정찰하며 돌아감 | 통과. 3.86초에 서 있는 적을 지나감, 최소 간격 27.7cm, 비켜 가는 동안 179cm/s | 실패. 서 있는 적에 막혀 지나가지 못함 |
| 보루 가장자리 | 통과. 사수와 절단자 모두 떨어지지 않음, 사수는 가장자리 안쪽 8.6cm에 섬 | (실행하지 않음) |

- 첫 실행에서 벽 앞 멈춤이 실패했습니다. 30° 비스듬히 물러난 적이 벽을 따라 56cm 미끄러진 뒤 적정 거리에 닿아 좌우 걷기로 넘어갔습니다. 레이캐스트가 닿는 점이 걸을 때마다 옆으로 조금씩 밀려났기 때문입니다. 닿는 점이 10cm 안이면 서도록 고친 뒤 위 결과가 나왔습니다(`2-plan.md` 반영).
- 정찰 지점 도착: 새 빌드에서 250cm/s로 걷다가 한 프레임에 서고 다음 지점으로 돌아섰습니다(군중 도착 감속 꺼짐). 변경 전 빌드는 같은 시나리오에서 서 있는 적에 막혀 도착하지 못해, 도착 모습은 비교하지 못했습니다.
- 로그: 임시 복사본 창에서만 `LogAg: Error: Combat stats: could not write ...`가 나왔습니다. 복사본의 `Saved/CombatStats` 폴더가 없어서였고, 폴더를 만든 뒤로는 나오지 않았습니다.

## 3. 회귀 확인

- 확인한 기존 기능과 결과: 적 AI를 쓰는 회귀 시나리오를 새 빌드에서 실행했고 모두 통과했습니다.
  - `enemy_turn_order` (동시 공격 수: 가까운 순서, 재공격 대기)
  - `enemy_group_kill` (적 그룹: 못 본 그룹원 한 타, 요새 돌파)
  - `groggy` (그로기·비전투·페이즈 전환, 보스 AI)
  - `combat_stats` (전투 통계, 공격 샌드백)
- 공유 에디터: 이번 변경을 넣어 다시 빌드하고 에디터를 켰습니다. 새 로그에 `LogAg` 오류가 없습니다.
- 확인하지 못한 것: 사람이 플레이해 보는 확인.
