# 색상 신호 방어와 순간이동 Spec

## 1. 개요 및 목적

적이 공격 전에 파란색 또는 보라색 신호를 보내면 린은 신호에 맞는 방어를 시도할 수 있습니다. 정해진 방어에 성공하면 공격한 적 근처로 순간이동하고 그 적을 3초간 기절시킵니다. 가능하면 등 뒤를 잡아 백어택과 후속 콤보를 노릴 수 있게 합니다.

## 2. 플레이 규칙 및 수치

### 2.1. 공격 신호와 대응

| 신호 | 추가 보상이 발동하는 조건 | 추가 보상 |
| - | - | - |
| 파란색 | 해당 타격에 패리 성공 | 공격자 근처로 순간이동, 공격자 3초 기절 |
| 보라색 | 해당 타격에 극한 회피 성공 | 공격자 근처로 순간이동, 공격자 3초 기절 |

- 파란색과 보라색은 지정된 공격에만 씁니다. 지정된 타격의 기존 예고 색을 파란색 또는 보라색으로 바꾸고, 예고 위치와 시점은 [적 시스템](<../../Docs/Design/System/적 시스템.md#공격-예고>)의 가드 가능 여부별 규칙을 따릅니다. 연타에서는 새 색이 붙은 타격에만 추가 보상이 걸리며, 그 외 타격은 기존 금색·붉은색 예고를 사용합니다.
- 파란색 타격은 가드할 수 있고 보라색 타격은 가드·패리할 수 없습니다. 가드, 일반 회피, 파란색 타격에 대한 극한 회피로는 추가 보상이 발생하지 않습니다. 이때 방어 또는 피격 결과는 기존 규칙을 따릅니다.
- 발동 시점은 해당 타격의 패리 또는 극한 회피가 성공한 순간입니다. 성공 판정과 기존 보상은 [플레이어 캐릭터 - 린](<../../Docs/Design/Content/플레이어 캐릭터 - 린.md>)의 '패리'와 '극한 회피'를 따릅니다. 투사체는 발사 예고가 나온 시점과 관계없이 린이 비행 중인 투사체에 대응한 순간 판정하며, 순간이동과 기절의 대상은 그 투사체를 발사한 적입니다.
- 방어 성공 1회당 그 성공을 일으킨 적 한 명에게만 추가 보상이 발동합니다. 다른 적을 락온 중이어도 그 적에게 보상을 옮기지 않습니다. 여러 공격이 동시에 닿으면 기존 방어 성공을 발생시킨 타격을 기준으로 판단합니다.

### 2.2. 순간이동 위치와 예외

1. 방어 성공을 일으킨 적의 현재 위치와 바라보는 방향을 기준으로 합니다. 적의 둘레 전체에서 안전한 자리를 찾고 정후방과의 각도 차가 가장 작은 자리를 고릅니다. 후방이 막혔다면 측면, 전방 대각선, 정면에서도 도착할 수 있습니다.
2. 후보는 공격자 중심에서 수평으로 1~3m 떨어진 자리입니다. 정후방과의 각도 차가 같으면 공격자와의 간격이 2m에 가까운 자리, 그다음 린의 출발점에 가까운 자리를 고릅니다. 걸어서 설 수 있는 지상에 착지하고 적을 바라봅니다. 대상이 공중에 있으면 바로 아래의 걸을 수 있는 바닥을 기준으로 후보를 찾습니다. 대상 아래 바닥과 높이 차가 0.5m를 초과하는 후보는 제외합니다.
3. 도착점은 출발점과 같은 전투 구역에 있어야 합니다. 방어에 성공한 순간 린의 발 위치에서 도착점까지 직선거리 10m 이내, 높이 차 1m 이내여야 합니다. 원거리 투사체와 공중 공격에도 같은 기준을 적용합니다.
4. 벽 내부, 낭떠러지 밖, 공격자나 다른 캐릭터와 겹치는 자리, 닫힌 문이나 전투 구역 경계 너머, 지형이 가로막아 출발점에서 도착점 또는 도착점에서 공격자에게 바로 닿을 수 없는 자리는 제외합니다. 순간이동 경로에 캐릭터가 있는 경우에는 목적지에서의 겹침만 확인합니다.
5. 안전한 자리가 없거나 공격자가 이미 사망했거나 사라졌으면 순간이동과 3초 기절을 함께 생략합니다. 이때 기존 패리·극한 회피의 모션, 자원 충전, 반격 기회, 패리 대미지 또는 투사체 반사 등 해당하는 기본 성공 처리를 그대로 적용합니다. 보상을 다른 적으로 넘기거나 나중에 다시 시도하지 않습니다.

### 2.3. 기절과 후속 행동

- 순간이동에 성공한 순간 공격자에게 [기절 상태](<../기절 상태/1-spec.md>)를 적용합니다. 공격자가 이미 그로기 중이거나 같은 패리에서 그로기에 들어가면 순간이동만 적용합니다. 처형 피격 또는 보스 페이즈 전환 중인 공격자에게는 순간이동과 기절을 생략합니다.
- 린은 도착 후 기존 패리·극한 회피의 입력 허용 시점과 반격 기회를 따릅니다. 순간이동에 성공한 극한 회피는 회피 모션의 수평 이동을 도착점에 더하지 않습니다. 자동 후속 공격이나 추가 무적은 없습니다.
- 순간이동에 성공하면 이미 락온 중인 경우 공격자로 락온을 바꿉니다. 자유 시점에서는 락온을 자동으로 켜지 않습니다.

> 검토 기준안으로 도착 간격 1~3m(기준 2m), 공격자 쪽 바닥 높이 허용차 0.5m, 린의 이동 높이 허용차 1m를 사용합니다.

## 3. 완료 조건

- [ ] 파란색 타격을 패리하고 보라색 타격을 극한 회피하면 각각 성공 순간에 린이 공격자의 정후방에 나타납니다. 공격자는 진행 중인 패턴을 멈추고 게임 시간 기준 3초 후 새 행동을 고를 수 있습니다.
- [ ] 파란색 타격을 가드하거나 회피했을 때, 보라색 타격을 일반 회피했을 때, 기존 금색·붉은색 예고 공격을 각각 패리·극한 회피했을 때 추가 보상이 나오지 않습니다. 보라색 타격은 가드·패리로 막을 수 없습니다.
- [ ] 연타 중 신호가 없는 타격을 방어하면 기존 보상만 적용됩니다. 신호가 붙은 타격에 대응해 이동과 기절이 발동하면 공격자의 아직 나오지 않은 후속 타격이 취소됩니다.
- [ ] 정후방이 벽·절벽·다른 적으로 막힌 경우 가장 뒤쪽의 안전한 후보로 이동합니다. 후방과 측면이 모두 막혀 있고 정면만 안전하면 정면으로 이동합니다. 모든 후보가 막혀 있으면 이동과 기절이 모두 생략됩니다.
- [ ] 같은 전투 구역에서는 투사체나 공중 공격에 대응해도 안전한 지상 도착점이 있으면 이동합니다. 도착점이 10m 경계에 있으면 이동할 수 있고, 10m 또는 허용 높이 차를 초과하거나 닫힌 문 너머에만 후보가 있으면 기존 방어 보상만 받습니다.
- [ ] 투사체에 대응했을 때 원래 발사자가 대상이 됩니다. 발사자가 사망하거나 사라졌으면 기존 방어 판정으로 끝납니다. 다른 적을 락온 중이면 이동 성공 시 공격자로 바뀌고, 이동이 생략되면 이 기능에 의한 락온 변경이 없습니다.
- [ ] 기절 중에 적이 그로기에 들어가거나 사망하거나 페이즈를 전환하면 남은 기절 시간이 나중에 이어지지 않습니다. 순간이동 자체로 린이 자동 공격하거나 추가 무적을 얻지 않습니다.
