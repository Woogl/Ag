# ABP와 로코모션

> 출처: 언리얼 에디터에서 ABP 기본값, 애님 그래프, 블렌드 스페이스, 시퀀스 설정을 읽고 루트 본을 평가 (읽기 전용)

플레이어와 적(보스·절단자·경비 사수), 샌드백이 몽타주 밖에서 재생하는 모션(대기, 이동, 가드 이동, 제자리 회전, 공중)과 그 위에 겹치는 반응(가드 움찔, 피격 흔들림), 대상 바라보기, 경비 사수의 상하 조준의 에셋 구성과 선택 근거를 정리합니다. 값을 고치는 위치는 [데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)를 따릅니다. 행동 몽타주에 쓰는 모션은 [Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>) '행동별 모션'과 [Halberd 애니메이션 조사](<Halberd 애니메이션 조사.md>) '보스 모션'을 따릅니다.

## 요약

- 모든 캐릭터가 공통 애님 그래프 `ABP_Character` 하나를 쓰고, 자식 `ABP_Player`·`ABP_Boss`·`ABP_Cutter`·`ABP_Gunner`·`ABP_Sandbag`은 모션 에셋만 바꿉니다. 그래프의 상태 머신은 점프·낙하·착지를 고르는 `Main States` 하나뿐이고, 행동은 모두 몽타주입니다.
- 플레이어 이동은 템플릿 맨손 로코모션이고 서 있는 자세만 Samurai `Idle2`입니다. 가드 이동은 Samurai 팩, 보스 이동은 Halberd 팩입니다. 제자리 회전은 플레이어가 Samurai 팩(가드 중에도 Samurai 팩), 보스가 45°는 Warrior 팩, 90°는 Halberd 팩입니다.
- 몽타주 밖의 모션은 루트 모션을 쓰지 않습니다. 이동 속도와 캐릭터의 회전은 캐릭터 무브먼트가 정하고, 블렌드 스페이스는 그 속도에 맞는 모션을 섞습니다. 서 있는 동안에는 루트 뼈를 캐릭터와 반대로 돌려 몸(발)을 제자리에 두고, 제자리 회전 모션의 루트 회전량만큼 몸을 돌립니다.
- 움찔은 행동 몽타주이며, 강인도·슈퍼아머로 버틴 일반 피격은 모션을 바꾸지 않고 물리 피격 흔들림만 적용합니다. 가드 움찔은 덧입힘 모션입니다. 선택한 움찔 모션은 [아트 표현 사양](<아트 표현 사양.md#피격-모션>)을 따릅니다.

## 애님 그래프

포즈는 아래 순서로 쌓이고, 뒤의 층이 앞의 층을 덮거나 그 위에 더해집니다. 층마다 넣는 에셋은 자식 ABP의 기본값입니다.

| 순서 | 층 | 플레이어 (`ABP_Player`) | 보스 (`ABP_Boss`) |
| - | - | - | - |
| 1 | 이동 블렌드 스페이스 | `BS_PlayerMove` | `BS_BossMove` |
| 2 | 가드 전환: 가드 중이면 가드 이동 블렌드 스페이스 | `BS_PlayerGuardMove` | 없음 |
| 3 | 제자리 회전: 회전 모션의 하체만 섞음 | Samurai `Turn_*`, 가드 중 Samurai `Guard_Turn*` | Warrior `Turn_45*`, Halberd `Turn_90*` |
| 4 | 몸 방향: 루트 뼈를 몸과 캐릭터의 각도 차이만큼 돌림 (`Rotate Root Bone`) | 같음 | 같음 |
| 5 | 상체 비틀기: `spine_02`·`spine_04`·`head`를 목표 쪽으로 돌림 (`Transform (Modify) Bone`) | 같음 | 같음 |
| 6 | 대상 바라보기: `neck_01`·`head`를 쳐다볼 대상의 머리 쪽으로 돌림 (`Look At`) | 같음 | 같음 |
| 7 | 그로기 전환: 그로기 중이면 그로기 반복 모션 | 없음 | Samurai `Stun` |
| 8 | 상태 머신 `Main States`: 7번 층까지의 자세, 도약, 공중 반복, 착지 중 하나('공중') | 템플릿 `MM_Jump`, `MM_Fall_Loop`, `MM_Land` | Halberd `Airborne`(공중 반복만) |
| 9 | `UpperBody` 슬롯: 앞 층까지의 자세에 상체 몽타주의 상체만 섞음 (`Layered blend per bone`) | `AM_Player_Potion` | 없음 |
| 10 | `DefaultSlot`: 행동 몽타주 | 행동별 몽타주 | 패턴·피격 몽타주 |
| 11 | 상하 조준: 목표 높이를 향한 상하 덧입힘 (`Aim Offset`) | 없음 | 없음 |
| 12 | `AdditiveSlot`: 덧입힘 몽타주 | `AM_GuardFlinch` | 없음 |
| 13 | `CinematicSlot`: 레벨 시퀀스의 자세 | 궁극기 컷신 `LS_UltimateCutscene` | 없음 |

- 일반 적은 보스와 같은 층 구성이고 넣는 에셋만 다릅니다. 절단자(`ABP_Cutter`)는 이동 `BS_CutterMove`, 제자리 회전 Samurai `Turn_*`, 그로기 Samurai `Stun`, 공중 템플릿 `MM_Fall_Loop`입니다. 경비 사수(`ABP_Gunner`)는 이동 `BS_GunnerMove`, 제자리 회전 Warrior `Turn_45*`·Halberd `Turn_90*`, 그로기 Samurai `Stun`, 공중 템플릿 `MM_Fall_Loop`, 상하 조준 `AO_Pistol`입니다.
- 상하 조준 층은 경비 사수만 씁니다. 행동 슬롯 뒤에 있어 사격 몽타주의 자세 위에 더해지며, 섞는 구간은 [일반 적 아트 구성](<일반 적 아트 구성.md#경비-사수-사격-모션>)을 따릅니다. 다른 캐릭터는 에셋이 비어 있고 섞지 않습니다.
- 두 샌드백(`ABP_Sandbag`)은 이동만 템플릿 `BS_Idle_Walk_Run`이고 나머지는 경비 사수와 같습니다. 공격 샌드백도 할버드를 든 채 이 맨손 대기 자세로 섭니다.
- 보스와 일반 적은 가드 이동 블렌드 스페이스가 비어 있어 가드 전환이 늘 일반 이동입니다.
- 회전 모션 목록은 자식 ABP의 기본값이고(공통 `ABP_Character`의 목록은 비어 있음), 가드 중 목록은 `ABP_Player`에만 있습니다.
- 4 ~ 6번 층은 그로기 전환·`Main States`와 행동 슬롯 앞에 있어, 그 자세나 몽타주가 섞여 들어오면 덮입니다.
- `DefaultSlot`, `AdditiveSlot`, `CinematicSlot`은 스켈레톤 `SK_Mannequin`에서 슬롯 그룹이 서로 다릅니다(`DefaultGroup`, `AdditiveGroup`, `CinematicGroup`). 몽타주는 같은 그룹의 몽타주만 멈추므로, 가드 움찔이나 컷신 자세가 재생 중인 행동 몽타주를 끊지 않습니다.
- `UpperBody`는 `DefaultSlot`과 같은 `DefaultGroup`이라, 행동·피격 몽타주가 시작되면 상체 몽타주가 멈춥니다. `Main States`까지의 자세를 캐시(`BeforeUpperBody`)해 블렌드의 바탕과 슬롯의 입력에 함께 씁니다. 블렌드의 가지 필터는 `spine_01`(깊이 0)이고 메시 공간 회전 블렌드를 켜서, 척추부터 팔과 머리까지만 몽타주를 따르고 골반과 다리는 이동 모션을 따릅니다. `DefaultSlot`보다 앞에 있어 끊길 때는 들어오는 행동 몽타주가 덮습니다. 상체 몽타주의 시퀀스는 루트 모션을 끕니다. 상체 슬롯만 쓰는 몽타주는 재생 중에도 캐릭터가 돕니다.
- 가드 시작·해제의 블렌드 시간, 제자리 회전의 최대 각도·재생 배율·블렌드 시간, 상체 비틀기의 최대 각도와 따라가는 시간, 대상 바라보기의 한도·뒤쪽 각도·따라잡는 시간은 [데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)의 해당 항목에 있습니다.
- 캐릭터 메시는 화면 밖에서도 포즈와 본을 갱신합니다(`Always Tick Pose and Refresh Bones`). 공격 판정이 메시의 피직스 바디를 쓰고 무기가 손을 따라가기 때문입니다.

## 이동 블렌드 스페이스

블렌드 스페이스의 가로축은 캐릭터 정면 기준 이동 방향(`Direction`, −180° ~ 180°, 45° 간격), 세로축은 이동 속도(`Speed`, cm/s)입니다. 방향마다 대기 모션을 속도 0에 두고, ±180°에는 같은 뒤로 이동 모션을 둡니다.

| 블렌드 스페이스 | 속도 축 | 속도 0 | 걷기 샘플 | 뛰기 샘플 | 쓰는 곳 |
| - | - | - | - | - | - |
| `BS_PlayerMove` | 0 ~ 600 | Samurai `Idle2` | `MF_Unarmed_Walk_*` 8방향, 300 | `MF_Unarmed_Jog_*` 8방향, 600 | 플레이어 기본 이동과 달리기 |
| `BS_PlayerGuardMove` | 0 ~ 300 | Samurai `Guard` | Samurai `Guard_Walk_*_IPC` 8방향, 252 | 없음 | 플레이어 가드 중 이동 |
| `BS_BossMove` | 0 ~ 300 | Halberd `Idle1` | Halberd `Walk_*_IPC` 8방향, 253 | 없음 | 보스 이동 |
| `BS_CutterMove` | 0 ~ 300 | Samurai `Idle1` | Samurai `Walk_*_IPC` 8방향, 253 | 없음 | 절단자 이동. `BS_BossMove`를 복제해 같은 이름의 Samurai 모션으로 바꿈 |
| `BS_GunnerMove` | 0 ~ 600 | 템플릿 `MM_Idle` | `MF_Unarmed_Walk_*` 8방향, 300 | `MF_Unarmed_Jog_*` 8방향, 600 | 경비 사수 이동. 맨손 모션이라 대기·이동 중에는 총을 내린 자세 |
| `BS_Idle_Walk_Run` (템플릿) | 0 ~ 600 | 템플릿 `MM_Idle` | `MF_Unarmed_Walk_*` 8방향, 300 | `MF_Unarmed_Jog_*` 8방향, 600 | 샌드백의 대기. 템플릿 원본 그대로이며 MOV가 0이라 걷지 않음 |

- 샘플 속도는 각 모션의 실제 이동 속도입니다. 템플릿 모션은 루트 이동으로 쟀고(걷기 8방향 모두 3.0m/s, 뛰기 6.0m/s), 팩의 제자리 모션은 같은 이름의 `_Rootmotion` 버전 속도입니다([Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>) '이동·기타', [Halberd 애니메이션 조사](<Halberd 애니메이션 조사.md>) '그 밖의 모션').
- 샘플 속도는 메시 배율 1 기준입니다. `UAgAnimInstance`가 이동 속도를 메시 배율로 나눠 넘기므로, 배율이 다른 캐릭터(보스 1.2배)도 샘플 속도를 고치지 않아도 걸음이 바닥과 맞습니다.
- 재생 속도를 이동 속도에 맞춰 늘리는 설정(`Axis to Scale Animation`)은 쓰지 않습니다. 게임의 이동 속도([플레이어 캐릭터 - 린](<../Design/Content/플레이어 캐릭터 - 린.md>) '이동', [보스 캐릭터 - 커스터](<../Design/Content/보스 캐릭터 - 커스터.md>)의 MOV)가 두 샘플 사이면 이웃한 두 샘플을 섞어 재생합니다. 그래서 플레이어 기본 이동과 달리기는 걷기와 뛰기를 섞은 모습이고, 달리기에 따로 쓰는 모션은 없습니다.
- 루트 모션은 몽타주에서만 쓰므로, 팩은 제자리(`_IPC`) 버전을, 템플릿은 루트 모션을 켠 원본(재생할 때 제자리)을 씁니다.
- `BS_PlayerMove`는 템플릿 `BS_Idle_Walk_Run`(`/Game/Characters/Mannequins/Anims/Unarmed`)을 복제해 속도 0의 샘플만 Samurai `Idle2`로 바꾼 것입니다. 템플릿 원본은 고치지 않습니다.
- 템플릿 샘플 구성을 쓰는 `BS_PlayerMove`·`BS_GunnerMove`·`BS_Idle_Walk_Run`은 템플릿에서 물려받아 샘플 가중치를 보간합니다(초당 5). 가드·보스·절단자 블렌드 스페이스는 보간하지 않습니다.
- 플레이어 기본 이동은 맨손 모션이라 이동 중에는 카타나가 손을 따라 흔들립니다. 서 있을 때는 칼을 내린 Samurai `Idle2`이고, 가드 이동은 칼을 쥔 Samurai 팩 모션입니다.

## 제자리 회전

서 있는 동안 몸의 방향과 목표 방향의 차이가 벌어지면 회전 모션으로 발을 옮겨 돌아섭니다(규칙은 [전투 시스템](<../Design/System/전투 시스템.md>) '목표 방향 회전'). 모션을 고르고 진행하는 것과 몸·상체의 각도 계산은 `UAgAnimInstance`가 맡습니다.

| 자세 | 모션 | 길이(초) | 루트 회전 | 처음·끝 자세 | 서 있는 자세와 다리 차이 |
| - | - | - | - | - | - |
| 일반 (플레이어) | Samurai `Turn_45L` / `Turn_45R` | 0.40 | −45° / +45° | Samurai `Idle1` | 15.7cm (`Idle2`) |
| 일반 (플레이어) | Samurai `Turn_90L` / `Turn_90R` | 0.65 | −90° / +90° | Samurai `Idle1` | 15.7cm (`Idle2`) |
| 가드 중 (플레이어) | Samurai `Guard_Turn45L` / `Guard_Turn45R` | 0.40 | −45° / +45° | Samurai `Guard` | 0.0cm |
| 가드 중 (플레이어) | Samurai `Guard_Turn90L` / `Guard_Turn90R` | 0.65 | −90° / +90° | Samurai `Guard` | 0.0cm |
| 보스 | Warrior `Turn_45L` / `Turn_45R` | 0.40 | −45° / +45° | Warrior `Idle1` | 5.2cm (Halberd `Idle1`) |
| 보스 | Halberd `Turn_90L` / `Turn_90R` | 0.65 | −90° / +90° | Halberd `Idle1` | 0.0cm |
| 절단자 | Samurai `Turn_45L` / `Turn_45R`, `Turn_90L` / `Turn_90R` | 0.40, 0.65 | ±45°, ±90° | Samurai `Idle1` | 0.0cm |
| 경비 사수·샌드백 | Warrior `Turn_45L` / `Turn_45R` | 0.40 | −45° / +45° | Warrior `Idle1` | 13.5cm (`MM_Idle`) |
| 경비 사수·샌드백 | Halberd `Turn_90L` / `Turn_90R` | 0.65 | −90° / +90° | Halberd `Idle1` | 9.0cm (`MM_Idle`) |

- 다리 차이는 다리 뼈 9개(`pelvis`와 좌우 `thigh`·`calf`·`foot`·`ball`)의 루트 기준 위치 차이를 평균한 값입니다.
- 하체만 섞으므로 상체와 무기는 각 캐릭터의 서 있는 자세를 유지합니다. `Layered blend per bone`의 가지 필터는 `pelvis`(깊이 0), `spine_01`(깊이 -1, 제외) 순서이고 메시 공간 회전 블렌드를 켭니다. 제외 필터가 뒤에 있어야 상체가 유지됩니다.
- 플레이어 일반 자세의 서 있는 자세는 칼끝을 아래로 내린 Samurai `Idle2`입니다. 네 팩의 제자리 회전 모션은 모두 각 팩의 `Idle1` 자세에서 시작하고 끝나 `Idle2`와 맞는 것이 없으므로(가장 가까운 것은 Dual Wield `Turn_90` 12.4cm), 회전 전후에 다리 자세가 바뀌는 것을 받아들였습니다. 회전 모션과 맞는 Samurai `Idle1`(0.0cm)은 양손을 앞에 모아 칼끝을 위로 겨눈 자세라 쓰지 않습니다.
- 보스의 45° 회전은 Halberd 팩에 없어 Warrior 모션을 씁니다.
- 경비 사수와 샌드백의 맨손 대기 `MM_Idle`에 맞는 맨손 회전 모션이 없어, 다리 차이가 가장 작은 보스의 회전 모션을 함께 씁니다(Samurai는 26.4cm).
- 회전 시퀀스는 Force Root Lock을 켜고 RefPose에 고정합니다. 첫 프레임에 고정하면 루트가 옆을 보고 시작하는 모션에서 몸 방향이 어긋납니다. 루트를 고정해도 루트 회전은 시퀀스에 남아 있어, 코드가 그 회전량을 읽어 몸을 돌립니다. 회전량은 늘리거나 줄이지 않습니다.
- 몸 방향 층(`Rotate Root Bone`)이 루트 뼈를 몸과 캐릭터의 각도 차이만큼 돌려, 캐릭터가 돌아도 발이 제자리에 남습니다.
- 상체 비틀기 층은 `spine_02`·`spine_04`·`head`의 `Transform (Modify) Bone` 세 개입니다. 회전을 컴포넌트 공간에 더하고 비율은 0.35·0.35·0.3이라, 가슴(팔과 무기)은 비틀기의 70%, 머리는 100%를 돕니다.
- 모션을 바꾸거나 더할 때의 조건입니다.
  - 루트 본에 회전이 들어 있어야 합니다. 이름의 각도가 아니라 루트의 누적 회전량을 쓰며, 이름과 달리 루트가 돌지 않는 모션도 있습니다(Dual Wield `Sprint_Turn180`, [Dual Wield 애니메이션 조사](<Dual Wield 애니메이션 조사.md>)).
  - 처음과 끝 자세가 그 목록이 쓰이는 서 있는 자세(일반은 이동 블렌드 스페이스의 속도 0, 가드는 `Guard`)와 같아야 회전 전후에 다리가 튀지 않습니다.
  - 목록에서 가장 작은 회전량이 발을 옮기기 시작하는 각도입니다. 더 작은 각도의 모션을 넣으면 더 자주 발을 옮기고, 그보다 작은 차이는 발을 붙인 채 상체와 머리의 비틀기가 맡습니다.

## 대상 바라보기

모든 캐릭터는 대기·이동 중에 고개를 돌려 상대를 쳐다봅니다. 누가 누구를 노리는지 머리 방향으로 읽을 수 있고, 적이 플레이어를 알아챈 순간이 보입니다. 판정에 쓰지 않는 연출이며, 공격 방향·회피 방향·등 쪽 판정·적의 시야는 [전투 시스템](<../Design/System/전투 시스템.md>) '목표 방향 회전'의 캐릭터 정면을 씁니다.

### 쳐다보는 대상

모든 캐릭터(플레이어, 보스, 일반 적, 샌드백)가 같은 규칙으로 대상을 정합니다.

| 순서 | 조건 | 대상 |
| - | - | - |
| 1 | 락온 대상이 있음 | 락온 대상 |
| 2 | 그 밖의 경우 | 자기 캡슐 중심에서 반경 20m(락온 타겟팅 범위와 같음) 안에 캡슐이 닿는, 비전투가 아닌 상대 가운데 캡슐 중심 사이 거리가 가장 가까운 상대. 없으면 쳐다보지 않습니다. |

- 비전투(정찰·복귀·대기) 중인 적은 쳐다보지 않습니다. 적은 전투에 들어가면 플레이어를 락온 대상으로 잡으므로, 전투 중인 적은 플레이어를 쳐다봅니다. 플레이어는 락온하지 않았으면 순서 2로 가장 가까운 전투 중인 적을 쳐다봅니다.
- 상대는 공격할 수 있는 다른 팀의 캐릭터이며, 샌드백도 들어갑니다.
- 대상이 바뀌면(락온 시작·해제·대상 전환, 가장 가까운 적이 바뀜, 적의 전투 진입·비전투 복귀, 대상 사망) 머리가 새 대상 쪽으로, 또는 정면으로 부드럽게 옮겨 갑니다.

### 쳐다보는 때

- 서 있을 때, 이동(걷기·달리기·가드 이동) 중, 제자리 회전 중에만 쳐다봅니다. 가드 중 막을 때의 흔들림(가드 움찔)에도 이어서 쳐다봅니다.
- 행동(공격, 회피, 점프, 패리, 처형, 스킬, 궁극기, 적의 패턴과 페이즈 전환), 피격 반응(가드 밀림 포함), 그로기, 공중 자세, 사망 중에는 모션의 머리 방향 그대로 둡니다. 공격 모션은 머리가 무기를 따라 움직이도록 만들어져 있어, 대상을 쳐다보게 하면 어색합니다.
- 그 모션이 섞여 들어오는 동안 머리가 모션 쪽으로 돌아가고, 모션이 끝나 섞여 나가기 시작하면 다시 쳐다봅니다. 상체 비틀기가 풀리고 돌아오는 때와 같습니다.

### 쳐다보는 모습

- 머리가 대상의 머리를 향해, 좌우뿐 아니라 높이 차이만큼 고개를 들거나 숙입니다.
- 목과 머리가 함께 돌며, 합쳐서 그때 자세의 머리 방향에서 어느 쪽으로든 약 75°까지만 돕니다. 대상이 그보다 바깥에 있으면 한도까지만 돌린 채 대상 쪽을 봅니다.
- 대상이 몸의 방향에서 좌우 110°보다 뒤쪽이면 쳐다보지 않고 머리를 정면으로 되돌립니다.
- 머리는 대상을 약 0.5초 동안 따라잡으며 부드럽게 돕니다. 쳐다보기 시작·해제와 대상 변경도 같은 속도입니다. 쳐다보지 않는 모션이 이보다 짧으면(움찔 등) 다 돌아가기 전에 다시 대상 쪽으로 돌아옵니다.

### 애님 그래프 구성

대상과 쳐다볼 지점, 쳐다보는 비율은 `UAgAnimInstance`가 정하고, 애님 그래프의 엔진 `Look At` 노드 두 개가 그 지점으로 뼈를 돌립니다.

| 노드 | 뼈 | 앞 축(뼈 로컬) | 한도 | 비율 |
| - | - | - | - | - |
| 1 | `neck_01` | (0.238, 0.971, 0) | 50° | 쳐다보는 비율 × 0.5 |
| 2 | `head` | +Y | 50° | 쳐다보는 비율 |

- 목이 남은 각도의 절반을 돌고 머리가 나머지를 돌아, 머리는 대상을 정확히 봅니다. 머리 한 뼈만 크게 돌리면 목이 꺾여 보입니다. 두 노드의 한도가 각각 50°라 합쳐 약 75°까지 돕니다. 한도는 좌우·위아래를 가리지 않는 원뿔입니다.
- 앞 축은 `SK_Mannequin` 기준 자세에서 잰 얼굴 앞 방향입니다. `neck_01`의 +Y는 기준 자세에서 약 14° 아래를 향해, 그대로 쓰면 목이 들려 보이므로 얼굴 앞(+Y)을 목 뼈 로컬로 옮긴 축을 씁니다. 다른 스켈레톤을 쓰는 캐릭터를 더하면 다시 잽니다.
- 노드의 보간(`Interpolation Time`)은 0입니다. 따라잡는 것은 `UAgAnimInstance`가 쳐다볼 지점을 부드럽게 옮겨서 합니다. 노드 보간은 목표가 멈췄다 움직일 때만 다시 시작해 계속 움직이는 대상에 맞지 않습니다.
- 순서 2의 상대는 대상 프리셋 `LookAt`(적대·생존·비전투 아님·거리순)으로 찾습니다.
- 상체 비틀기 바로 뒤, 그로기 전환·`Main States`와 행동 슬롯 앞에 있어, 그 자세나 몽타주가 섞여 들어오면 덮입니다. 쳐다보는 동안에는 상체 비틀기의 머리 몫을 덮고, 쳐다볼 대상이 없을 때는 상체 비틀기가 그대로 보입니다.

## 공중

엔진 템플릿 ABP처럼 상태 머신 `Main States`가 `Locomotion`(7번 층까지의 자세), `Jump`, `Fall Loop`, `Land` 중 하나를 고릅니다.

| 캐릭터 | 모션 | 메모 |
| - | - | - |
| 플레이어 | 도약 템플릿 `MM_Jump`, 공중 반복 템플릿 `MM_Fall_Loop`, 착지 템플릿 `MM_Land` | 기본 이동과 같은 템플릿 맨손 모션입니다. |
| 보스 | Halberd `Airborne` (반복) | 도약·착지 모션이 없어 몽타주 없이 떨어지는 동안만 보입니다([Halberd 애니메이션 조사](<Halberd 애니메이션 조사.md>) '보스 모션'). |
| 절단자·경비 사수·샌드백 | 공중 반복 템플릿 `MM_Fall_Loop` | 플레이어와 같은 모션이며, 도약·착지 모션이 없어 몽타주 없이 떨어지는 동안만 보입니다. |

| 전환 | 조건 |
| - | - |
| `Locomotion` → `Jump` | 떨어지는 중이고 위로 1m/s 넘게 움직이며 도약 모션이 있을 때 |
| `Locomotion` → `Fall Loop` | 떨어지는 중일 때 (위 전환이 먼저) |
| `Jump` → `Fall Loop` | 도약 모션이 끝나기 크로스페이드 시간 전 |
| `Jump`·`Fall Loop` → `Land` | 땅에 닿았고 착지 모션이 있을 때 |
| `Fall Loop` → `Locomotion` | 땅에 닿았을 때 (위 전환이 먼저) |
| `Land` → `Locomotion` | 착지 모션이 끝나기 크로스페이드 시간 전, 또는 움직이기 시작하거나 다시 떠오르거나 `DefaultSlot` 몽타주가 재생 중일 때 |

- 크로스페이드는 모두 엔진 기본값입니다.
- 착지 모션은 제자리 모션이라 움직이면 미끄러져 보이므로, 움직이기 시작하면 끝냅니다.
- 몽타주가 착지까지 맡을 때는 뒤에서 도는 착지 모션이 그 몽타주가 끝날 때 드러나지 않도록 바로 `Locomotion`으로 돌아갑니다.
- `DefaultSlot`은 몽타주가 덮는 동안에도 앞 층을 갱신합니다(`Always Update Source Pose`). 갱신을 멈추면 `Main States`도 멈춰, 몽타주가 끝날 때 공중에 있던 때의 자세가 비칩니다.
- `Jump`와 `Land`는 들어갈 때마다 모션을 처음부터 재생합니다(`Always Reset on Entry`). 끄면 크로스페이드로 아직 남아 있는 상태에 다시 들어갈 때 끝난 위치에서 이어 재생해 바로 다음 상태로 넘어갑니다.

- 모두 제자리 모션이라 높이와 체공 시간은 캐릭터 무브먼트가 만듭니다([데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>) 'JSON 외부 데이터 위치'의 '점프 및 공중 이동').
- 점프 공격, 넉업, GroundSlam처럼 공중에서 하는 행동은 각자의 몽타주가 공중 반복 모션을 덮습니다.

막았을 때 가드 자세 위에 덧입혀 재생하는 반응입니다([전투 시스템](<../Design/System/전투 시스템.md>)의 가드 반응).

| 에셋 | 내용 |
| - | - |
| `A_GuardFlinch_Additive` | Samurai `Guard_Hit1`(0.57초, 루트 이동 없음, 가드 자세로 돌아옴)로 만든 덧입힘 시퀀스입니다. `Additive Anim Type` = Local Space, `Base Pose Type` = 자기 애니메이션의 프레임(0프레임)이라 첫 자세와의 차이만 더합니다. 루트 모션은 끕니다. |
| `AM_GuardFlinch` | `A_GuardFlinch_Additive` 하나를 `AdditiveSlot`에 둔 몽타주입니다. |

- 덧입힘이므로 가드 이동이나 가드 중 제자리 회전 위에도 그대로 겹칩니다.
- 기준 자세가 첫 프레임이라, 원본은 처음 자세로 돌아와 끝나는 모션이어야 덧입힘이 0으로 끝납니다. 뒤로 0.5m 밀리는 `Guard_Hit2`·`3`은 루트 이동이 필요해 덧입힘이 아니라 가드 밀림 몽타주로 씁니다.
- 덧입힘 모션은 루트 모션을 끕니다. 루트 모션이 있는 몽타주는 재생하는 동안 이동 입력과 다른 몽타주의 루트 모션을 대신합니다.

## 피격 흔들림

맞거나 막을 때의 흔들림은 모션 에셋이 아니라 `UAgHitPhysicsComponent`가 메시의 피직스 바디를 잠깐 물리로 움직여 애니메이션 위에 섞는 것입니다. 강인도·슈퍼아머로 버틴 일반 피격은 이것만으로 보이며, 행동을 중단시키는 피격 모션과 가드 움찔·가드 밀림에도 함께 나옵니다. 보이게 움직이는 바디는 `spine_02`부터 머리까지의 몸통이고, 가드로 막았을 때만 양팔도 보이게 움직입니다. 피직스 에셋의 머리 관절이 몸통 관절보다 넓고 물러서, 목(`neck_01`)부터 머리는 몸통보다 낮은 비율로 섞습니다. 미는 방향은 무기 공격이면 날이 움직인 방향, 그 밖에는 피격 방향입니다.

- 두 캐릭터의 메시(`SKM_Quinn_Simple`, `SKM_Manny_Simple`)는 피직스 에셋 `PA_Mannequin`을 같이 씁니다. 흔들리는 몸통(`spine_02`부터 머리)과 팔(`clavicle_l`·`clavicle_r` 아래)은 이 에셋의 바디이므로, 바디나 컨스트레인트를 바꾸면 두 캐릭터의 흔들림이 함께 바뀝니다.
- 미는 세기(`PushSpeed`)와 섞는 최대 비율(`MaxBlendWeight`)은 캐릭터 BP의 `HitPhysics` 컴포넌트 값입니다([데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)).

## 갱신 방법

에디터를 켠 상태에서 ABP 기본값과 블렌드 스페이스 샘플은 에디터 파이썬(`get_editor_property`)으로, 애님 그래프 노드는 Unreal MCP의 `BlueprintTools`(`find_nodes`, `get_node_infos`)로 읽습니다. 모션의 길이·루트 이동·루트 회전은 [Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>) '측정 방법'처럼 루트 본을 평가해 잽니다. 에셋이 바뀌면 이 문서를 고칩니다.
