# ABP와 로코모션

> 출처: 언리얼 에디터에서 ABP 기본값, 애님 그래프, 블렌드 스페이스, 시퀀스 설정을 읽고 루트 본을 평가 (읽기 전용)

플레이어와 보스가 몽타주 밖에서 재생하는 모션(대기, 이동, 가드 이동, 제자리 회전, 공중)과 그 위에 겹치는 반응(가드 움찔, 피격 흔들림)의 에셋 구성과 선택 근거를 정리합니다. 값을 고치는 위치는 [데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)를 따릅니다. 행동 몽타주에 쓰는 모션은 [Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>) '행동별 모션'과 [Halberd 애니메이션 조사](<Halberd 애니메이션 조사.md>) '보스 모션'을 따릅니다.

## 요약

- 두 캐릭터가 공통 애님 그래프 `ABP_Character` 하나를 쓰고, 자식 `ABP_Player`·`ABP_Boss`는 모션 에셋만 바꿉니다. 그래프에 상태 머신은 없고 행동은 모두 몽타주입니다.
- 플레이어 이동은 템플릿 맨손 로코모션이고 서 있는 자세만 Samurai `Idle2`입니다. 가드 이동은 Samurai 팩, 보스 이동은 Halberd 팩입니다. 제자리 회전은 플레이어가 Samurai 팩(가드 중에도 Samurai 팩), 보스가 45°는 Warrior 팩, 90°는 Halberd 팩입니다.
- 몽타주 밖의 모션은 루트 모션을 쓰지 않습니다. 이동 속도와 캐릭터의 회전은 캐릭터 무브먼트가 정하고, 블렌드 스페이스는 그 속도에 맞는 모션을 섞습니다. 서 있는 동안에는 루트 뼈를 캐릭터와 반대로 돌려 몸(발)을 제자리에 두고, 제자리 회전 모션의 루트 회전량만큼 몸을 돌립니다.
- 움찔은 행동 몽타주이며, 강인도·슈퍼아머로 버틴 일반 피격은 모션을 바꾸지 않고 물리 피격 흔들림만 적용합니다. 가드 움찔은 덧입힘 모션입니다. 선택한 움찔 모션은 [아트 표현 사양](<아트 표현 사양.md#피격-모션>)을 따릅니다.

## 애님 그래프

포즈는 아래 순서로 쌓이고, 뒤의 층이 앞의 층을 덮거나 그 위에 더해집니다. 층마다 넣는 에셋은 자식 ABP의 기본값입니다.

| 순서 | 층 | 플레이어 (`ABP_Player`) | 보스 (`ABP_Boss`) |
| - | - | - | - |
| 1 | 이동 블렌드 스페이스 | `BS_PlayerMove` | `BS_BossMove` |
| 2 | 가드 전환: 가드 중이면 가드 이동 블렌드 스페이스 | `BS_PlayerGuardMove` | 없음 |
| 3 | 제자리 회전: 회전 모션의 하체만 섞음 | Samurai `Turn_*`, 가드 중 Samurai `Guard_Turn*` | Warrior `Turn_45*`, Halberd `Turn_90*` |
| 4 | 몸 방향: 루트 뼈를 몸과 캐릭터의 각도 차이만큼 돌림 (`Rotate Root Bone`) | 같음 | 같음 |
| 5 | 상체 비틀기: `spine_02`·`spine_04`·`head`를 목표 쪽으로 돌림 (`Transform (Modify) Bone`) | 같음 | 같음 |
| 6 | 그로기 전환: 그로기 중이면 그로기 반복 모션 | 없음 | Samurai `Stun` |
| 7 | 공중 전환: 떨어지는 중이면 공중 반복 모션 | 템플릿 `MM_Fall_Loop` | Halberd `Airborne` |
| 8 | `DefaultSlot`: 행동 몽타주 | 행동별 몽타주 | 패턴·피격 몽타주 |
| 9 | `AdditiveSlot`: 덧입힘 몽타주 | `AM_GuardFlinch` | 없음 |
| 10 | `CinematicSlot`: 레벨 시퀀스의 자세 | 궁극기 컷신 `LS_UltimateCutscene` | 없음 |

- 보스는 가드 이동 블렌드 스페이스가 비어 있어 가드 전환이 늘 일반 이동입니다.
- 회전 모션 목록은 자식 ABP의 기본값이고(공통 `ABP_Character`의 목록은 비어 있음), 가드 중 목록은 `ABP_Player`에만 있습니다.
- 4·5번 층은 그로기·공중 전환과 행동 슬롯 앞에 있어, 그 자세나 몽타주가 섞여 들어오면 덮입니다.
- 세 슬롯은 스켈레톤 `SK_Mannequin`에서 슬롯 그룹이 서로 다릅니다(`DefaultGroup`, `AdditiveGroup`, `CinematicGroup`). 몽타주는 같은 그룹의 몽타주만 멈추므로, 가드 움찔이나 컷신 자세가 재생 중인 행동 몽타주를 끊지 않습니다.
- 가드 시작·해제의 블렌드 시간, 제자리 회전의 최대 각도·재생 배율·블렌드 시간, 상체 비틀기의 최대 각도와 따라가는 시간은 [데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)의 해당 항목에 있습니다.
- 캐릭터 메시는 화면 밖에서도 포즈와 본을 갱신합니다(`Always Tick Pose and Refresh Bones`). 공격 판정이 메시의 피직스 바디를 쓰고 무기가 손을 따라가기 때문입니다.

## 이동 블렌드 스페이스

세 블렌드 스페이스의 가로축은 캐릭터 정면 기준 이동 방향(`Direction`, −180° ~ 180°, 45° 간격), 세로축은 이동 속도(`Speed`, cm/s)입니다. 방향마다 대기 모션을 속도 0에 두고, ±180°에는 같은 뒤로 이동 모션을 둡니다.

| 블렌드 스페이스 | 속도 축 | 속도 0 | 걷기 샘플 | 뛰기 샘플 | 쓰는 곳 |
| - | - | - | - | - | - |
| `BS_PlayerMove` | 0 ~ 600 | Samurai `Idle2` | `MF_Unarmed_Walk_*` 8방향, 300 | `MF_Unarmed_Jog_*` 8방향, 600 | 플레이어 기본 이동과 달리기 |
| `BS_PlayerGuardMove` | 0 ~ 300 | Samurai `Guard` | Samurai `Guard_Walk_*_IPC` 8방향, 252 | 없음 | 플레이어 가드 중 이동 |
| `BS_BossMove` | 0 ~ 300 | Halberd `Idle1` | Halberd `Walk_*_IPC` 8방향, 253 | 없음 | 보스 이동 |

- 샘플 속도는 각 모션의 실제 이동 속도입니다. 템플릿 모션은 루트 이동으로 쟀고(걷기 8방향 모두 3.0m/s, 뛰기 6.0m/s), 팩의 제자리 모션은 같은 이름의 `_Rootmotion` 버전 속도입니다([Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>) '이동·기타', [Halberd 애니메이션 조사](<Halberd 애니메이션 조사.md>) '그 밖의 모션').
- 재생 속도를 이동 속도에 맞춰 늘리는 설정(`Axis to Scale Animation`)은 쓰지 않습니다. 게임의 이동 속도([플레이어 캐릭터 - 린](<../Design/Content/플레이어 캐릭터 - 린.md>) '이동', [보스 캐릭터 - 커스터](<../Design/Content/보스 캐릭터 - 커스터.md>)의 MOV)가 두 샘플 사이면 이웃한 두 샘플을 섞어 재생합니다. 그래서 플레이어 기본 이동과 달리기는 걷기와 뛰기를 섞은 모습이고, 달리기에 따로 쓰는 모션은 없습니다.
- 루트 모션은 몽타주에서만 쓰므로, 팩은 제자리(`_IPC`) 버전을, 템플릿은 루트 모션을 켠 원본(재생할 때 제자리)을 씁니다.
- `BS_PlayerMove`는 템플릿 `BS_Idle_Walk_Run`(`/Game/Characters/Mannequins/Anims/Unarmed`)을 복제해 속도 0의 샘플만 Samurai `Idle2`로 바꾼 것입니다. 템플릿 원본은 고치지 않습니다.
- `BS_PlayerMove`만 템플릿에서 물려받아 샘플 가중치를 보간합니다. 나머지 두 블렌드 스페이스는 보간하지 않습니다.
- 플레이어 기본 이동은 맨손 모션이라 이동 중에는 카타나가 손을 따라 흔들립니다. 서 있을 때는 칼을 내린 Samurai `Idle2`이고, 가드 이동은 칼을 쥔 Samurai 팩 모션입니다.

## 제자리 회전

서 있는 동안 몸의 방향과 목표 방향의 차이가 벌어지면 회전 모션으로 발을 옮겨 돌아섭니다(규칙은 [전투 시스템](<../Design/System/전투 시스템.md>) '목표 방향 회전'). 모션을 고르고 진행하는 것과 몸·상체의 각도 계산은 `UAgAnimInstance`가 맡습니다.

| 자세 | 모션 | 길이(초) | 루트 회전 | 처음·끝 자세 | 서 있는 자세와 다리 차이 |
| - | - | - | - | - | - |
| 일반 (플레이어) | Samurai `Turn_45L` / `Turn_45R` | 0.40 | −45° / +45° | Samurai `Idle1` | 15.7cm (`Idle2`) |
| 일반 (플레이어) | Samurai `Turn_90L` / `Turn_90R` | 0.65 | −90° / +90° | Samurai `Idle1` | 15.7cm (`Idle2`) |
| 가드 중 (플레이어) | Samurai `Guard_Turn45L` / `Guard_Turn45R` | 0.40 | −45° / +45° | Samurai `Guard` | 0.0cm |
| 가드 중 (플레이어) | Samurai `Guard_Turn90L` / `Guard_Turn90R` | 0.65 | −90° / +90° | Samurai `Guard` | 0.0cm |
| 보스 | Warrior `Turn_45L` / `Turn_45R` | 0.40 | −45° / +45° | Warrior `Idle1` | 5.2cm (Halberd `Idle1`) |
| 보스 | Halberd `Turn_90L` / `Turn_90R` | 0.65 | −90° / +90° | Halberd `Idle1` | 0.0cm |

- 다리 차이는 다리 뼈 9개(`pelvis`와 좌우 `thigh`·`calf`·`foot`·`ball`)의 루트 기준 위치 차이를 평균한 값입니다.
- 하체만 섞으므로 상체와 무기는 각 캐릭터의 서 있는 자세를 유지합니다. `Layered blend per bone`의 가지 필터는 `pelvis`(깊이 0), `spine_01`(깊이 -1, 제외) 순서이고 메시 공간 회전 블렌드를 켭니다. 제외 필터가 뒤에 있어야 상체가 유지됩니다.
- 플레이어 일반 자세의 서 있는 자세는 칼끝을 아래로 내린 Samurai `Idle2`입니다. 네 팩의 제자리 회전 모션은 모두 각 팩의 `Idle1` 자세에서 시작하고 끝나 `Idle2`와 맞는 것이 없으므로(가장 가까운 것은 Dual Wield `Turn_90` 12.4cm), 회전 전후에 다리 자세가 바뀌는 것을 받아들였습니다. 회전 모션과 맞는 Samurai `Idle1`(0.0cm)은 양손을 앞에 모아 칼끝을 위로 겨눈 자세라 쓰지 않습니다.
- 보스의 45° 회전은 Halberd 팩에 없어 Warrior 모션을 씁니다.
- 회전 시퀀스는 Force Root Lock을 켜고 RefPose에 고정합니다. 첫 프레임에 고정하면 루트가 옆을 보고 시작하는 모션에서 몸 방향이 어긋납니다. 루트를 고정해도 루트 회전은 시퀀스에 남아 있어, 코드가 그 회전량을 읽어 몸을 돌립니다. 회전량은 늘리거나 줄이지 않습니다.
- 몸 방향 층(`Rotate Root Bone`)이 루트 뼈를 몸과 캐릭터의 각도 차이만큼 돌려, 캐릭터가 돌아도 발이 제자리에 남습니다.
- 상체 비틀기 층은 `spine_02`·`spine_04`·`head`의 `Transform (Modify) Bone` 세 개입니다. 회전을 컴포넌트 공간에 더하고 비율은 0.35·0.35·0.3이라, 가슴(팔과 무기)은 비틀기의 70%, 머리는 100%를 돕니다.
- 모션을 바꾸거나 더할 때의 조건입니다.
  - 루트 본에 회전이 들어 있어야 합니다. 이름의 각도가 아니라 루트의 누적 회전량을 쓰며, 이름과 달리 루트가 돌지 않는 모션도 있습니다(Dual Wield `Sprint_Turn180`, [Dual Wield 애니메이션 조사](<Dual Wield 애니메이션 조사.md>)).
  - 처음과 끝 자세가 그 목록이 쓰이는 서 있는 자세(일반은 이동 블렌드 스페이스의 속도 0, 가드는 `Guard`)와 같아야 회전 전후에 다리가 튀지 않습니다.
  - 목록에서 가장 작은 회전량이 발을 옮기기 시작하는 각도입니다. 더 작은 각도의 모션을 넣으면 더 자주 발을 옮기고, 그보다 작은 차이는 발을 붙인 채 상체와 머리의 비틀기가 맡습니다.

## 공중

| 캐릭터 | 모션 | 메모 |
| - | - | - |
| 플레이어 | 점프 몽타주 `AM_Player_Jump` (섹션 Start = 템플릿 `MM_Jump`, Land = `MM_Land`), 공중 반복 템플릿 `MM_Fall_Loop` | 기본 이동과 같은 템플릿 맨손 모션입니다. |
| 보스 | Halberd `Airborne` (반복) | 몽타주 없이 떨어지는 동안만 보입니다([Halberd 애니메이션 조사](<Halberd 애니메이션 조사.md>) '보스 모션'). |

- 모두 제자리 모션이라 높이와 체공 시간은 캐릭터 무브먼트가 만듭니다([데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>) 'JSON 외부 데이터 위치'의 '점프 및 공중 이동').
- 점프 공격, 넉업, GroundSlam처럼 공중에서 하는 행동은 각자의 몽타주가 공중 반복 모션을 덮습니다.

## 가드 움찔

막았을 때 가드 자세 위에 덧입혀 재생하는 반응입니다([전투 시스템](<../Design/System/전투 시스템.md>)의 가드 반응).

| 에셋 | 내용 |
| - | - |
| `A_GuardFlinch_Additive` | Samurai `Guard_Hit1`(0.57초, 루트 이동 없음, 가드 자세로 돌아옴)로 만든 덧입힘 시퀀스입니다. `Additive Anim Type` = Local Space, `Base Pose Type` = 자기 애니메이션의 프레임(0프레임)이라 첫 자세와의 차이만 더합니다. 루트 모션은 끕니다. |
| `AM_GuardFlinch` | `A_GuardFlinch_Additive` 하나를 `AdditiveSlot`에 둔 몽타주입니다. |

- 덧입힘이므로 가드 이동이나 가드 중 제자리 회전 위에도 그대로 겹칩니다.
- 기준 자세가 첫 프레임이라, 원본은 처음 자세로 돌아와 끝나는 모션이어야 덧입힘이 0으로 끝납니다. 뒤로 0.5m 밀리는 `Guard_Hit2`·`3`은 루트 이동이 필요해 덧입힘이 아니라 가드 밀림 몽타주로 씁니다.
- 덧입힘 모션은 루트 모션을 끕니다. 루트 모션이 있는 몽타주는 재생하는 동안 이동 입력과 다른 몽타주의 루트 모션을 대신합니다.

## 피격 흔들림

맞거나 막을 때의 흔들림은 모션 에셋이 아니라 `UAgHitPhysicsComponent`가 메시의 피직스 바디를 잠깐 물리로 움직여 애니메이션 위에 섞는 것입니다. 강인도·슈퍼아머로 버틴 일반 피격은 이것만으로 보이며, 행동을 중단시키는 피격 모션과 가드 움찔·가드 밀림에도 함께 나옵니다. 보이게 움직이는 바디는 `spine_02`부터 머리까지의 몸통이고, 가드로 막았을 때만 양팔도 보이게 움직입니다. 미는 방향은 무기 공격이면 날이 움직인 방향, 그 밖에는 피격 방향입니다.

- 두 캐릭터의 메시(`SKM_Quinn_Simple`, `SKM_Manny_Simple`)는 피직스 에셋 `PA_Mannequin`을 같이 씁니다. 흔들리는 몸통(`spine_02`부터 머리)과 팔(`clavicle_l`·`clavicle_r` 아래)은 이 에셋의 바디이므로, 바디나 컨스트레인트를 바꾸면 두 캐릭터의 흔들림이 함께 바뀝니다.
- 미는 세기(`PushSpeed`)와 섞는 최대 비율(`MaxBlendWeight`)은 캐릭터 BP의 `HitPhysics` 컴포넌트 값입니다([데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)).

## 갱신 방법

에디터를 켠 상태에서 ABP 기본값과 블렌드 스페이스 샘플은 에디터 파이썬(`get_editor_property`)으로, 애님 그래프 노드는 Unreal MCP의 `BlueprintTools`(`find_nodes`, `get_node_infos`)로 읽습니다. 모션의 길이·루트 이동·루트 회전은 [Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>) '측정 방법'처럼 루트 본을 평가해 잽니다. 에셋이 바뀌면 이 문서를 고칩니다.
