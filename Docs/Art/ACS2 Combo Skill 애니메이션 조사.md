# ACS2 Combo Skill 애니메이션 조사

> 출처: UE 5.8 에디터 파이썬 포즈 평가와 원본 팩 몽타주 · 범위: `/Game/Fab/ACS2ComboSkill/Anim_Seq_UE5` · 애니메이션 시퀀스 30개

ACS2 Combo Skill 팩의 애니메이션 시퀀스를 분류하고 길이, 프레임 수, 루트 이동, 재생 설정, 대기 자세와의 차이, 이어 붙일 시점을 조사했습니다. 각 모션의 GIF는 표에서 열 수 있습니다. 캐릭터 행동과 판정 구간을 결정하는 기획 문서는 별도로 작성합니다.

## 에셋과 재생 설정

- 팩 원본은 UE4 마네킹용이라, 프로젝트의 `SK_Mannequin`(대상 메시 `SKM_Manny_Simple`)으로 리타깃한 사본만 남겼습니다. 사본은 원본보다 루트 이동이 약 1% 짧고, 골반 높이는 원본과 2.4cm 안쪽으로 같습니다.
- 팩의 몽타주는 팩 블루프린트의 노티파이(공격 판정·콤보 입력)가 붙어 있어 가져오지 않았습니다. 쓸 때는 프로젝트 몽타주를 새로 만듭니다.
- 루트 모션 설정('설정' 열)은 원본 그대로이고, 넉업([아트 표현 사양](<아트 표현 사양.md>)의 '넉업·저글')에 쓰는 `Air_Hit`·`Air_DownLoop`만 루트 뼈를 고정했습니다. `Die11_Root`는 루트 모션이 꺼져 있지만 루트 본이 움직입니다.
- 모든 시퀀스에서 루트 본의 높이는 변하지 않습니다. 띄워짐과 공중 자세의 높이는 골반으로만 표현되므로, 실제로 띄우는 높이는 모션 밖에서 줍니다.
- 샘플링은 대기·이동 30fps, 사망 60fps, 나머지 120fps입니다.
- 팩에는 무기 에셋이 없습니다. 대기·이동 자세는 오른손을 몸 앞에 둔 넓은 자세입니다. GIF는 플레이어 모션으로 쓰므로 Quinn에 게임의 카타나를 들려 보여 줍니다.

## 이어 붙이기

이어 재생하던 두 시퀀스에서, 앞 시퀀스의 어느 시점 자세가 뒤 시퀀스의 첫 자세와 가장 가까운지 잰 값입니다.

| 이어지는 순서 | 끊기 좋은 시점(초) | 그 시점 차이(cm) | 끝까지 재생한 뒤 차이(cm) |
| - | -: | -: | -: |
| `Combo01_1` → `Combo01_2` | 0.50 | 10 | 58 |
| `Combo01_2` → `Combo01_3` | 0.43 | 4 | 34 |
| `Combo01_3` → `Combo01_4` | 0.67 | 1 | 43 |
| `Combo01_4` → `Attack12` | 2.97 | 0 | 0 |
| `Attack14_Buff` → `Attack03_5_Root` | 0.60 | 53 | 62 |
| `Step_Slide_F` → `Attack09` | 0.67 | 0 | 0 |
| `Attack09` → `Attack12` | 2.77 | 0 | 0 |
| `DefenseR_Root` → `Parry01_Root` | 0.20 | 45 | 47 |
| `Parry01_Root` → `Combo01_4` | 0.50 | 66 | 69 |
| `Air_Hit` → `Air_DownLoop` | 0.73 | 1 | 1 |
| `Air_DownLoop` 반복 | 1.67 | 0 | 0 |
| `Air_DownLoop` → `Falldown_B_Start` | 0.30 | 95 | 96 |
| `Falldown_B_Start` → `Falldown_B_End` | 0.73 | 0 | 0 |

- 평타 1~4타는 각각 0.43~0.67초 지점에서 다음 타의 첫 자세와 10cm 안쪽으로 맞습니다. 원래 구성은 이보다 이른 0.19~0.45초부터 다음 타 입력을 받아 블렌드로 이었습니다.
- `Combo01_4` → `Attack12`, `Step_Slide_F` → `Attack09`, `Attack09` → `Attack12`, `Falldown_B_Start` → `Falldown_B_End`는 앞 시퀀스의 끝 자세가 뒤 시퀀스의 첫 자세와 같습니다. `Air_DownLoop`는 끝과 처음이 같아 그대로 반복됩니다.
- `Attack03_5_Root`는 웅크린 자세에서 시작해, 원래 앞에 오던 `Attack14_Buff`의 어느 시점과도 53cm 넘게 차이가 납니다. `Air_DownLoop`에서 `Falldown_B_Start`로도 95cm 차이라, 원래 구성은 블렌드로 이었습니다.

## 측정 방법

- 길이, 프레임, 전진, 오른쪽, 설정은 [에셋 조사 개요](<에셋 조사 개요.md>)의 '시퀀스 측정 기준'을 따릅니다. 높이와 루트 높이 범위는 모든 시퀀스가 0이라 열을 두지 않았습니다.
- 대기와 차이는 시퀀스의 첫·마지막 자세를 `Idle`의 첫 자세와 비교한 값입니다. 루트 본 기준으로 골반, `spine_05`, 머리, 양손, 양발 7개 본 위치의 평균 거리(cm)입니다.
- 이어 붙이기는 앞 시퀀스를 30fps로 평가해 같은 7개 본의 평균 거리가 가장 작은 시점입니다. 끝 자세가 그 최솟값과 0.5cm 안쪽이면 끝 시각을 적었습니다.
- 'ACS2에서의 쓰임'의 시각은 리타깃 전 원본 팩 몽타주의 노티파이 위치입니다.
