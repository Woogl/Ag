## 캡처 조건

- 전체 길이를 1배속·20fps로 캡처하고 마지막 포즈를 포함합니다. 반복 재생 시 처음 0.3초, 끝 0.5초를 더 멈춥니다. 짧은 에임 자세나 기준 자세는 정지 이미지처럼 보일 수 있습니다.
- 기존에 촬영한 1,043개는 640×574픽셀로 보관합니다. 앞으로 촬영하는 GIF의 기본 크기는 정보 띠 포함 480×431픽셀(영상 480×401, 정보 띠 30)입니다. 영상은 960×802로 렌더링한 뒤 축소합니다. 상단에 에셋 이름과 시퀀스 시각을 표시합니다.
- 카메라는 캐릭터의 오른쪽 앞 위에서 골반을 따라갑니다. 새 촬영은 몸동작을 보기 쉽게 이전 구도보다 캐릭터를 30% 확대하며, 칼끝이 잠깐 잘리는 것은 허용합니다. 위치 이동량은 배경이 아닌 조사 표의 루트 변위를 참고합니다.
- Samurai는 Quinn과 게임의 카타나, Halberd는 Manny와 게임의 할버드를 사용합니다. `_no_weapon` 변형은 무기를 숨깁니다. Warrior는 오른손 검·왼손 방패, Dual Wield는 오른손 검·왼손 도끼를 원본 무기 본의 손 기준 변환으로 붙입니다. 기본·프로젝트 추가 시퀀스는 Manny의 몸 동작을 무기 없이 표시하며, GIF 상단에 이를 명시합니다.
- 무기는 각 손에 고정해서 보여 줍니다. 장착·해제 시퀀스의 칼집 이동이나 무기 부착 전환을 재현하는 연출은 포함하지 않습니다.
- 애디티브 시퀀스는 단일 시퀀스 미리보기입니다. 실제 게임에서 다른 포즈 위에 겹친 최종 결과와는 다릅니다.
- 캐릭터 크기·공격 판정·몽타주 배속·연출 효과·상대 캐릭터는 반영하지 않습니다. 기존 기획서의 조합 GIF는 `Docs/Design/Attachments`에 있습니다.
