## 캡처 조건

- 전체 길이를 1배속·20fps로 캡처하고 마지막 포즈를 포함합니다. 반복 재생 시 처음 0.3초, 끝 0.5초를 더 멈춥니다. 짧은 에임 자세나 기준 자세는 정지 이미지처럼 보일 수 있습니다.
- 크기는 정보 띠 포함 480×457픽셀(영상 480×401, 정보 띠 56)입니다. 480은 640보다 촬영 시간과 파일 크기가 약 1/3 줄고 몸통과 칼 윤곽은 그대로 보이며, 작은 표면 디테일만 작아집니다. 상단에 에셋 이름과 시퀀스 시각을 20px 글씨로 표시하고, 띠 너비를 넘는 긴 이름만 들어갈 때까지 글씨를 줄입니다.
- 현재 저장소의 모든 GIF는 480×457픽셀(정보 띠 56, 글씨 20px) 규격으로 통일되어 있습니다.
- 카메라는 캐릭터의 오른쪽 앞 위에서 골반을 따라갑니다. 몸동작을 보기 쉽게 캐릭터를 크게 잡으며(배율은 촬영 도구의 `settings.py`), 칼끝이 잠깐 잘리는 것은 허용합니다. 위치 이동량은 배경이 아닌 조사 표의 루트 변위를 참고합니다.
- Samurai, Dodge and Evade는 Quinn과 게임의 카타나, Halberd는 Manny와 게임의 할버드를 사용합니다. `_no_weapon` 변형은 무기를 숨깁니다. Warrior는 오른손 검·왼손 방패, Dual Wield는 오른손 검·왼손 도끼를 원본 무기 본의 손 기준 변환으로 붙입니다. 기본·프로젝트 추가 시퀀스는 Manny의 몸 동작을 무기 없이 표시하며, GIF 상단에 이를 명시합니다.
- 무기는 각 손에 고정해서 보여 줍니다. 장착·해제 시퀀스의 칼집 이동이나 무기 부착 전환을 재현하는 연출은 포함하지 않습니다.
- 애디티브 시퀀스는 단일 시퀀스 미리보기입니다. 실제 게임에서 다른 포즈 위에 겹친 최종 결과와는 다릅니다.
- 캐릭터 크기·공격 판정·몽타주 배속·연출 효과·상대 캐릭터는 반영하지 않습니다. 기획서의 조합 GIF는 `Docs/Art/Attachments`에 있습니다.
