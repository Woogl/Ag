# 에셋 조사 개요

> 갱신일 2026-10-22 · 출처: 언리얼 에디터 에셋 레지스트리 (Unreal MCP)

프로젝트에 있는 아트 리소스의 구성과 Fab ARPG 팩 조사 문서를 안내합니다. 프로젝트에서 만든 에셋은 [에셋 목록](<../Program/에셋 목록.md>)을 따르고, 템플릿 에셋의 세부 값은 에디터에서 확인합니다.

## 현재 상태

- 템플릿 에셋은 UE 5.8 Third Person 템플릿과 그 변형(Combat, Platforming) 샘플에서 온 것입니다.
- Fab의 ARPG 애니메이션 팩 4종(Warrior, Samurai, Dual Wield, Halberd)은 `/Game/Fab/ARPG_Pack`에 있습니다. 팩 공통 사항은 'ARPG 팩 공통', 팩별 내용은 '문서' 표의 팩별 조사 문서를 따릅니다.
- 캐릭터는 마네킹(`SKM_Manny_Simple`, `SKM_Quinn_Simple`) 두 종이며, 애니메이션은 모두 스켈레톤 `SK_Mannequin`을 공유합니다.
- 환경 에셋은 `LevelPrototyping`의 프로토타입용 메시·그리드 머티리얼이 전부입니다.
- 애니메이션 시퀀스의 개별 미리보기는 [GIF 목록](<GIF/README.md>)에서 팩별로 찾습니다.

## ARPG 팩 공통

| 항목 | 내용 |
|---|---|
| 구성 | `ARPG_Warrior` 273, `ARPG_Samurai` 339, `ARPG_Dual_Wield` 164, `ARPG_Halberd` 169 (애니메이션 시퀀스 수, 합계 945) |
| 스켈레톤 | 모두 프로젝트의 `SK_Mannequin`입니다. 리타깃 없이 마네킹에서 바로 재생됩니다. |
| 무기 | 각 팩의 `Demo/Weapon`. 할버드 `Halberd_weapon`(스켈레탈 메시, 길이 약 2.55m)과 스태틱 메시 6개(워리어 `Sword`·`Shield`, 사무라이 `katana`·`scabbard`, 듀얼 윌드 `Axe`·`Sword`), 머티리얼 7개 |
| 루트 모션 | 팩 원본은 모든 시퀀스에서 `bEnableRootMotion`이 꺼져 있지만, 공격·회피·피격 모션은 루트 본에 이동이 들어 있습니다. 이동 모션은 제자리(`_IPC`)와 루트 모션(`_Rootmotion`) 두 벌입니다. |
| 노티파이·커브 | 없습니다. |
| 연결 | 콤보 모션은 정해진 시점에서 끊으면 다음 모션의 첫 자세와 맞도록 만들어져 있습니다. ([Halberd 애니메이션 조사](<Halberd 애니메이션 조사.md>)의 '연결 시점', [Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>)의 '연결' 참고) |

## 갱신 방법

에디터를 켠 상태에서 Unreal MCP의 `AssetTools`(`find_assets`, `get_asset_tags`, `get_dependencies`)로 다시 조회하면 됩니다. 에셋이 바뀌면 해당 문서를 고치고 머리의 갱신일을 바꿉니다.

## 시퀀스 측정 기준

Warrior·Dual Wield 조사 문서의 측정 기준입니다. 다른 문서는 각 문서의 측정 방법을 따릅니다.

- 길이는 시퀀스 전체를 원래 속도(1배속)로 재생했을 때의 초입니다. 프레임은 엔진의 `AnimationLibrary.get_num_frames` 값입니다.
- 전진·오른쪽·높이는 첫 포즈에서 마지막 포즈까지 루트 본의 변위입니다. 컴포넌트 공간 +Y를 전진, −X를 오른쪽, +Z를 높이로 환산한 미터 값입니다. 이동 경로의 총길이나 공격 사거리가 아닙니다.
- 루트 높이 범위는 20fps와 마지막 시점에서 평가한 루트 높이의 최댓값−최솟값입니다. 실제 게임의 점프 높이가 아닙니다.
- 설정은 `RM` = 루트 모션 활성, `고정` = Force Root Lock, `—` = 둘 다 꺼짐입니다. 설정을 바꾸지 않고 읽었습니다.
- GIF는 모션 선택을 위한 미리보기입니다. 타격 판정·무적·취소 구간과 게임 이동은 포함하지 않습니다. GIF의 캡처 조건과 무기 표시 범위는 [GIF 목록](<GIF/README.md>)을 따릅니다.
