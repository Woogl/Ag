# 일반 적 아트 구성

근거리 일반 적 절단자와 원거리 일반 적 경비 사수에 적용된 리소스입니다. 플레이 규칙·스탯·공격 타이밍은 [절단자](<../Design/Content/일반 적 - 절단자.md>)와 [경비 사수](<../Design/Content/일반 적 - 경비 사수.md>) 기획서가 정본입니다. 공통 효과와 피격 모션은 [아트 표현 사양](<아트 표현 사양.md>), 몽타주 밖 모션은 [ABP와 로코모션](<ABP와 로코모션.md>)을 따릅니다.

## 외형과 무기

| 대상 | 캐릭터 | 무기 | 구성 |
| - | - | - | - |
| 절단자 | Manny `SKM_Manny_Simple` | Samurai 팩 `katana` | `BP_Cutter`, `ABP_Cutter`. 검에 `Weapon` 태그, 자식 `WeaponCollision`으로 판정 |
| 경비 사수 | Manny `SKM_Manny_Simple` | 엔진 기본 `Cube`를 줄인 권총 대용 | `BP_Gunner`, `ABP_Gunner`. 오른손 `hand_r`에 부착하고 `Weapon` 태그로 예고 표시 |

두 캐릭터는 플레이어와 같은 직립 신장으로 사용합니다. 전용 몬스터 모델이나 전용 무기 모델은 사용하지 않습니다. 절단자는 스텔라 블레이드의 크리켓 슬래셔를 단발·짧은 연속 공격 구성의 참고로 삼으며, 외형은 마네킹과 검으로 표현합니다.

## 절단자 공격 모션

Samurai 모션 이름의 공통 접두사는 `ARPG_Samurai_Anim_UE_`입니다. 원본 모션과 GIF는 [Samurai 애니메이션 조사](<Samurai 애니메이션 조사.md>)에서 확인합니다.

| 패턴 | 몽타주 | 원본 모션 |
| - | - | - |
| 단발 베기 | `AM_Cutter_SingleSlash` | `Attack_Combo3` |
| 2연 베기 | `AM_Cutter_DoubleSlash` | `Attack_Combo1` → `Attack_Combo2` |
| 내려찍기 | `AM_Cutter_HeavyCleave` | `Attack_Combo4` |

- 몸을 비튼 자세, 검을 세운 자세, 검을 머리 위로 넘긴 자세를 느리게 보여 주어 준비 시간을 만들고, 실제로 베는 구간은 원본 속도를 유지합니다.
- 대기에서 콤보 중간 자세로 시작하는 모션의 연결은 몽타주 블렌드 인으로 잇습니다.
- 2연 베기는 첫 모션의 복귀를 끝까지 재생하지 않고 두 번째 준비 동작으로 블렌드합니다. 연결 시점과 판정·추적 구간은 `Abilities.json`의 해당 타임라인을 따릅니다.
- 무기 궤적과 예고는 검에 표시합니다. 내려찍기는 머리 위 준비 자세와 붉은 가드 불가 예고를 함께 사용합니다.

## 경비 사수 사격 모션

| 구간 | 몽타주 | 시퀀스 |
| - | - | - |
| 조준 | `AM_Gunner_PistolShot`의 `Aim` | `MF_Pistol_Idle_ADS` |
| 발사·반동 | 같은 몽타주의 `Fire` | `A_Pistol_Fire` |
| 재장전 | 같은 몽타주의 `Reload` | `MM_Pistol_Reload` |

- `A_Pistol_Fire`는 원본 `MM_Pistol_Fire`를 복제해 사격 몽타주에서 사용하는 시퀀스입니다. 원본 참고 GIF와 실제 조합 결과를 구분합니다.
- 총을 내린 대기 자세에서 조준 자세로 몽타주 블렌드 인으로 연결합니다. 구간 사이 블렌드는 타임라인의 Transition으로 관리합니다.
- 상하 조준용 `AO_Pistol`은 적용하지 않습니다. 탄환은 높이를 포함한 조준점을 향하지만 팔의 사격 자세는 수평입니다.
- 원본 미리보기: [조준](<GIF/Base/Characters/Mannequins/Anims/Pistol/MF_Pistol_Idle_ADS.gif>), [반동](<GIF/Base/Characters/Mannequins/Anims/Pistol/MM_Pistol_Fire.gif>), [재장전](<GIF/Base/Characters/Mannequins/Anims/Pistol/MM_Pistol_Reload.gif>). 촬영 조건은 [GIF 안내](<GIF/README.md>)를 따릅니다.

## 공용 반응과 처형

- 움찔·공중 움찔·넉업·넉다운은 `AM_Flinch`, `AM_FlinchAir`, `AM_KnockUp`, `AM_KnockDown`을 공유합니다. 피격 표현의 선택은 아트 표현 사양을 따릅니다.
- 그로기는 `AM_Boss_Groggy`의 Samurai `Collide_To_Stun` → `Stun` → `Stun_To_Idle1`을 공유하고, 유지 자세는 자식 ABP의 Samurai `Stun`입니다.
- 처형 피격·처형 사망은 Warrior 모션을 쓰는 `AM_Boss_Executed`·`AM_Boss_ExecutedDeath`를 공유합니다. 린의 처형과 동기화하는 재생 배율은 [데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md#json-외부-데이터-위치>)의 '처형 템포'에서 관리합니다.

## 탄체·효과·사운드

- `BP_PistolBullet`은 엔진 기본 `Sphere` 메시와 검기와 공유하는 `MI_SwordWave` 재질로 보이는 탄체를 만듭니다. 판정은 별도의 `HitCapsule`이며, 표현 크기와 판정 크기를 구분합니다.
- 별도 탄환 궤적 효과, 사격음·재장전 전용 사운드는 적용하지 않습니다. 권총 대용 상자와 공용 재질의 탄체가 현재 표현입니다.
- 패리 예고·가드 불가 예고, 피격·패리 VFX와 효과음은 공통 리소스를 사용합니다. 발동 조건은 [적 시스템](<../Design/System/적 시스템.md>)을 따릅니다.
