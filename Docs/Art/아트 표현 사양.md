# 아트 표현 사양

캐릭터의 외형과 사용 리소스, 전투 VFX·화면 효과·효과음, HUD 아이콘, 글꼴과 버튼 효과음의 표현을 정의합니다. 제작 범위는 [마일스톤1 계획](<../마일스톤1 계획.md>)의 '아트 리소스'를 따릅니다.

효과가 전달할 의도와 발동 조건, 판정 시점은 [전투 시스템](<../Design/System/전투 시스템.md>), [캐릭터 - 린](<../Design/Content/캐릭터 - 린.md>), [보스 - 커스터](<../Design/Content/보스 - 커스터.md>)를 따릅니다. 카메라 연출은 [카메라와 타겟팅](<../Design/System/카메라와 타겟팅.md>), UI의 배치와 표시는 [UI 시스템](<../Design/System/UI 시스템.md>)의 '전투 HUD', [UI 시스템](<../Design/System/UI 시스템.md>)의 '메뉴 UI', [UI 시스템](<../Design/System/UI 시스템.md>)의 'UI 스타일'을 따릅니다.

기존 리소스의 조사와 선택 근거는 [에셋 조사 개요](<에셋 조사 개요.md>)와 [VFX·사운드 리소스 조사](<VFX·사운드 리소스 조사.md>), 실제 설정 위치와 에셋 경로는 [데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)와 에디터 `/Content` 브라우저에서 찾습니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 효과와 UI 리소스

| 용도 | 쓰는 에셋 | 표현 |
| - | - | - |
| 가드 불가 예고 | 직접 제작한 `NS_Telegraph` | 젠레스 존 제로의 공격 전 섬광처럼, 무기에서 교차하는 가는 가로·세로 빛줄기입니다. 세로 줄기는 화면 위아래 끝까지 이어지고, 가로 줄기는 화면 너비에 조금 못 미치는 길이로 끝으로 갈수록 가늘어집니다. 예고가 켜진 동안 젠레스 존 제로와 같은 순서로 바뀝니다. 켜질 때 교차점까지 굵게 번쩍이고, 굵은 빛이 교차점에서 바깥으로 물러나며 가늘어집니다. 이어서 가로 줄기의 바깥 끝이 줄어들며 흐려지고, 세로 줄기가 가로 줄기보다 먼저 흐려집니다. 교차점은 끝나기 바로 직전에야 비고, 사라질수록 주황빛이 짙어집니다. 빨간색입니다. 위치와 시작·종료 시점은 [적 시스템](<../Design/System/적 시스템.md>)의 '공격 예고'를 따르고, 예고가 끝나면 남은 빛도 바로 사라집니다. |

| 무기 궤적 | 직접 제작한 `NS_WeaponTrail`(템플릿 `NS_Jump_Trail`의 리본을 바꾼 것)과 `M_WeaponTrail` | 날이 지나간 면을 따라 짧게 남는 리본입니다. 날의 범위는 무기 메시마다 둔 날 시작·끝 소켓을 따릅니다. 갓 오브 워와 스텔라 블레이드의 베기 궤적처럼, 리본 안의 뒤 화면을 쭈글쭈글하게 일그러뜨립니다. 일그러짐은 궤적을 따라 길게 이어진 물결무늬여서, 색이나 빛 없이도 뒤 화면의 경계가 물결마다 꺾여 보입니다. 물결은 궤적을 따라 흐르며, 손잡이 쪽 가장자리로 갈수록 약해집니다. 칼끝 쪽 가장자리에만 흰빛을 은은하게 줍니다. 새로 생긴 쪽이 가장 강하고 꼬리로 갈수록 사라집니다. 무기 공격 판정(`WeaponHit`) 동안 무기 궤적을 출력하며, 베기 공격뿐만 아니라 돌진 찌르기(`DashThrust`)를 포함한 모든 무기 공격 판정 구간에 적용됩니다. |
| 극한 회피 화면 효과 | 직접 제작한 극한 회피용 후처리 머터리얼(`M_PerfectDodgeScreen`·`MI_PerfectDodgeScreen`) | 스텔라 블레이드의 Perfect Dodge를 참고합니다. 성공 순간 가장자리에 짧은 왜곡과 색 분리, 붉은 기운을 줍니다. 궁극기처럼 화면 전체를 지속해서 흑백으로 만들지 않습니다. 페이드는 아트에서 조정합니다. 의도와 재생 조건, 길이는 [캐릭터 - 린](<../Design/Content/캐릭터 - 린.md>)의 '극한 회피'를 따릅니다. |
| 궁극기 화면 효과 | 직접 제작한 궁극기용 후처리 머터리얼(`M_UltimateScreen`·`MI_UltimateScreen`) | 데빌 메이 크라이의 Judgement Cut End를 참고해 채도를 낮춘 차가운 색감, 어두운 배경과 선명한 명암으로 참격을 강조합니다. 극한 회피 화면 효과와 별도로 제작·조정합니다. 공간을 가르는 참격과 파편은 화면의 색·왜곡을 담당하는 후처리와 구분하는 시각 효과입니다. 재생 구간은 [캐릭터 - 린](<../Design/Content/캐릭터 - 린.md>)의 '궁극기 화면 효과'를 따릅니다. |

## 궁극기 베기 선

궁극기의 베기 단계와 마무리 시점은 [캐릭터 - 린](<../Design/Content/캐릭터 - 린.md>)의 '궁극기'를 따릅니다.

| 항목 | 값 |
| - | - |
| 개수 | 베기 단계 동안 주변을 채울 만큼 여러 개 |
| 나타나는 시점 | 베기 단계 동안 일정한 간격으로 하나씩 |
| 위치 | 플레이어 주변 모든 방향의 조금 떨어진 곳부터 몇 걸음 밖까지, 바닥부터 머리 위 높이까지의 무작위 위치. 각도도 무작위입니다. |
| 사라지는 시점 | 마무리 순간 모두 함께. 사라지는 자리마다 궁극기 마무리 VFX가 하나씩 터집니다. |
