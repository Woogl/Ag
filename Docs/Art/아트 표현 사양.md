# 아트 표현 사양

캐릭터의 외형과 사용 리소스, 전투 VFX·포스트프로세스·효과음, HUD 아이콘, 글꼴과 버튼 효과음의 표현을 정의합니다. 제작 범위는 [마일스톤 1](<../Milestone/마일스톤 1.md>)의 '아트 리소스'를 따릅니다.

효과가 전달할 의도와 발동 조건, 판정 시점은 [전투 시스템](<../Design/System/전투 시스템.md>), [플레이어 캐릭터 - 린](<../Design/Content/플레이어 캐릭터 - 린.md>), [보스 캐릭터 - 커스터](<../Design/Content/보스 캐릭터 - 커스터.md>)를 따릅니다. 카메라 연출은 [카메라와 타겟팅](<../Design/System/카메라와 타겟팅.md>), UI의 배치와 표시는 [UI 시스템](<../Design/System/UI 시스템.md>)의 '전투 HUD', [UI 시스템](<../Design/System/UI 시스템.md>)의 '메뉴 UI', [UI 시스템](<../Design/System/UI 시스템.md>)의 'UI 스타일'을 따릅니다.

기존 리소스의 조사와 선택 근거는 [에셋 조사 개요](<에셋 조사 개요.md>)와 [VFX·사운드 리소스 조사](<VFX·사운드 리소스 조사.md>), 실제 설정 위치와 에셋 경로는 [데이터 로딩과 스키마](<../Architecture/데이터 로딩과 스키마.md>)와 에디터 `/Content` 브라우저에서 찾습니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

### 보스 착지 모션

GroundSlam의 착지는 `A_Boss_GroundSlam_Land`를 씁니다. Halberd `Attack_Airborne_End`에서 발이 내려온 0.15초 이후를 원본 길이에 맞춰 재표본화하고, 접촉 구간의 양손을 함께 내려 창끝을 지면 가까이에 둡니다. 위팔·아래팔 길이와 양손의 잡는 간격은 유지하며, 창을 뽑을 때 손 보정을 부드럽게 해제합니다. 루트 이동과 무기 소켓은 이 보정으로 바꾸지 않습니다. 착지 블렌드는 `Abilities.json`의 GroundSlam 타임라인에서 정합니다.

### 회복병 모션

`A_Potion_Drink`는 팩에 마시는 모션이 없어 직접 만든 1.2초 시퀀스입니다. 린의 서 있는 자세인 Samurai `Idle2`를 바탕으로 왼팔과 머리만 움직입니다. 손가락은 Dual Wield `Idle1`의 왼손 쥔 자세입니다. Samurai `Buff`는 손이 머리 위까지 올라가 병이 입에 닿지 않아 쓰지 않습니다.

| 시각(초) | 동작 |
| - | - |
| 0 ~ 0.38 | 왼손을 몸에서 조금 띄우며 들어 올려 병 입구를 입에 댑니다. |
| 0.38 ~ 0.8 | 고개를 13°까지 젖히고 병을 8°에서 30°까지 기울입니다. 0.8초에 삼킵니다. |
| 0.8 ~ 1.2 | 병을 내리고 고개를 되돌립니다. |

- 병 입구 자리는 머리의 입 자리에서 정하고 왼팔은 두 뼈 IK로 풀어, 고개를 젖혀도 입구가 입에서 떨어지지 않습니다. 팔 길이는 바뀌지 않습니다.
- 카타나는 `Idle2` 자세대로 오른손에 낮게 남습니다.
- `AM_Player_Potion`이 이 시퀀스를 상체 슬롯에서 재생합니다. 이동 중에 섞는 방법은 [ABP와 로코모션](<ABP와 로코모션.md>)을 따릅니다.

## 효과와 UI 리소스

| 용도 | 쓰는 에셋 | 표현 |
| - | - | - |
| 가드 불가 예고 | 직접 제작한 `NS_Telegraph` | 젠레스 존 제로의 공격 전 섬광처럼, 무기에서 교차하는 가는 가로·세로 빛줄기입니다. 세로 줄기는 화면 위아래 끝까지 이어지고, 가로 줄기는 화면 너비에 조금 못 미치는 길이로 끝으로 갈수록 가늘어집니다. 예고가 켜진 동안 젠레스 존 제로와 같은 순서로 바뀝니다. 켜질 때 교차점까지 굵게 번쩍이고, 굵은 빛이 교차점에서 바깥으로 물러나며 가늘어집니다. 이어서 가로 줄기의 바깥 끝이 줄어들며 흐려지고, 세로 줄기가 가로 줄기보다 먼저 흐려집니다. 교차점은 끝나기 바로 직전에야 비고, 사라질수록 주황빛이 짙어집니다. 빨간색입니다. 위치와 시작·종료 시점은 [적 시스템](<../Design/System/적 시스템.md>)의 '공격 예고'를 따르고, 예고가 끝나면 남은 빛도 바로 사라집니다. |

| 무기 궤적 | 직접 제작한 `NS_WeaponTrail`(템플릿 `NS_Jump_Trail`의 리본을 바꾼 것)과 `M_WeaponTrail` | 날이 지나간 면을 따라 짧게 남는 리본입니다. 날의 범위는 무기 메시마다 둔 날 시작·끝 소켓을 따릅니다. 갓 오브 워와 스텔라 블레이드의 베기 궤적처럼, 유리 칼날이 지나간 듯 리본 안의 뒤 화면을 굴절시킵니다. 리본 안쪽은 볼록 렌즈처럼 살짝 확대되어 휘어 보이고, 뒤 화면이 궤적 방향으로 끌려 리본 가장자리에서 뒤 화면의 선이 뚜렷하게 끊깁니다. 끌림은 칼끝 쪽이 가장 세고 손잡이 쪽으로 갈수록 약해지며, 궤적을 따라 길게 이어진 결이 있어 붓으로 쓸어 낸 듯한 줄무늬가 생깁니다. 굴절은 실제 거리만큼 밀어 내므로 멀리 있는 캐릭터의 궤적은 화면에서 그만큼 작게 굴절합니다. 칼끝 쪽 가장자리에는 결을 따라 끊기는 어두운 먹선을 줍니다. 새로 생긴 쪽이 가장 강하고 꼬리로 갈수록 사라집니다. 무기 공격 판정(`WeaponHit`) 동안 무기 궤적을 출력하며, 베기 공격뿐만 아니라 돌진 찌르기(`DashThrust`)를 포함한 모든 무기 공격 판정 구간에 적용됩니다. |
