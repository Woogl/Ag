# 2026.11.01 회의 내용

M2 구현 마감은 11월 8일입니다.

## 구현 수정 사항

모션(회피, 평타 5타, 공중 피격), 카메라 연출, 포스트프로세스, 칼 궤적, 타격 VFX 등 몇 가지 개선했습니다.

강인도 규칙을 좀 더 구체화했습니다. 중형 강인도를 가진 보스는 그로기 중일 때만 넉업됩니다. 자세한 내용은 [전투 시스템의 강인도 규칙](<../Design/System/전투 시스템.md#강인도>)을 참고해주세요.

## Spec 문서

* 일반 적 (근거리, 원거리)
* 네임플레이트
* 스테이지 선택
* 시뮬레이션 룸
* 샌드백

현재 검토한 범위에서는 구현에 문제가 없어 보입니다. 구현 중 문제가 생기면 AI와 논의하며 해결하겠습니다. 구현에는 최대 3일 정도를 예상합니다.

## 레벨디자인

레벨디자인 문서에서 몇 가지 삭제된 요소가 있던데, 다시 넣고 싶은 부분이 있다면 말씀해주세요.

상호작용 시스템 구현할 때 고려하겠습니다.

## 앞으로의 계획

전체 개발 흐름은 [전체 마일스톤](<../Milestone/전체 마일스톤.md>)을 참고해주세요.

마일스톤 3(11월 9일 ~ 11월 22일)는 던전과 보스전을 하나로 묶은 전투 MVP 콘텐츠를 완성하는 것이 목적입니다.

- MVP에서 사용할 던전과 보스룸 결정
- M1의 보스전과 M2의 던전의 조화
- 전투 시스템 확정

던전부터 보스전까지 이어지는 전투 한 판(5분 정도)을 만들고, 완성되면 주변 지인에게 플레이테스트 피드백 받을 예정입니다.

다음 주 회의 이후(11월 9일 이후)에 작성할 것으로 예상하는 Spec 목록을 미리 공유합니다.

1. **회복 아이템**: 에스트병 같은 회복 수단
2. **스킬 확장**: 스킬 1개(E) + 궁극기 1개(Q) → 스킬 4개(1,2,3,4) + 궁극기 1개(Q)
3. **스킬 콤보**: 완성된 스킬 4개가 매끄럽게 콤보로 잘 들어가도록 폴리싱
4. **기본 상호작용**: 레벨디자인에 필요한 문, 엘리베이터, 사다리 등의 개별 규칙은 11월 15일쯤 논의할 것으로 예상합니다.

스킬 확장은 적의 그로기 프리딜 타임에는 스킬 콤보로 극딜 먹이는 방향으로 진행해보려 합니다. (카잔, 인왕, 데메크)

* **스킬1**: 돌진기
* **스킬2**: 띄우기. 현재의 E 스킬
* **스킬3**: 장풍
* **스킬4**: 광역기

M4 쯤 성장 시스템을 구현하면서 2단 점프와 공중 대시를 추가할 예정입니다. 레벨디자인은 그때 점프 높이와 이동 거리 등을 확인하며 조정하면 됩니다.

## 다음 회의 때까지 과제

### 이창영

Spec 구현이 끝나면 말씀드릴 테니, 의도대로 구현되었는지 결과를 확인해주세요.

결과를 확인하고 문제가 없으면 AI에게 기획서 최신화를 요청하면 됩니다. 이것으로 AI 워크플로우 한 차례가 완료됩니다.

### 이민석

그레이박싱 배치 작업 꼼꼼하고 재미있게 부탁드리겠습니다.

창영님께서 적 구현 결과를 최종 확인한 뒤, 민석님께서 던전에 적을 배치해주세요.

### 이우성

M2 Spec 전체의 구현과 검증을 우선 진행합니다.

여유가 있으면 M3에 필요한 기반 작업을 진행합니다. 기반 작업도 구현 전에 필요한 범위를 Spec으로 정리합니다.

* 상호작용 시스템 (F키로 입력)
* 스킬 확장 준비
* 낙뎀 시스템 준비 (렙디 과정 중 필요하면 쓰실 수 있도록 간단하게 준비)
