# 2026.11.07 회의 내용

이제 던전부터 보스전까지 이어지는 **전투 MVP를 완성하는 작업**을 진행하려고 합니다.

M2 구현 마감은 11월 8일입니다. 지난 회의에서 공유한 M3 예정 기간은 **11월 9일 ~ 11월 22일**이며, 개발팀 밖의 사람이 처음 플레이해도 재미를 느낄 수 있는 5분 이상 분량의 전투를 만드는 것이 목표입니다.

전체 개발 방향은 [전체 마일스톤](<../Milestone/전체 마일스톤.md>)을 확인해주세요.

## M2 진행 상황

일반 적과 전투 연습 환경을 구현했고, 던전의 지형과 적 배치를 다듬고 있습니다.

- 근거리 일반 적 **절단자**, 원거리 일반 적 **경비 사수**와 네임플레이트를 구현하고 기획서에 반영했습니다. 일반 적 2종은 사용자 플레이 확인까지 완료했습니다.
- **스테이지 선택, 시뮬레이션 룸, 샌드백**을 구현하고 기획서에 반영했습니다.

## 전투 MVP의 완성 기준

완성본은 **일반 적과의 전투부터 마지막 보스전까지 이어지는, 5분 이상 분량의 던전 1개**입니다. 아래 콘텐츠가 하나의 플레이 가능한 빌드에 들어 있어야 합니다.

| 콘텐츠 | 완성본에 들어갈 내용 |
| - | - |
| 플레이어 전투 | 스킬 4종과 기본 공격을 연계하며, 샌드백을 때리는 것만으로도 타격과 콤보의 재미를 느낄 수 있습니다. |
| 던전 1개 | M2 미니던전에서 선정하거나 구간을 취합한 던전. 입구에서 일반 적 전투 구간을 거쳐 보스방까지 이동할 수 있는 지형과 동선, 적 배치가 갖춰져 있습니다. |
| 일반 적 전투 | 창영님과 민석님이 정한 적의 종류와 공격 패턴이 실제 던전에 적용되어 있습니다. 배치된 적과 공방을 주고받으며 진행할 수 있습니다. |
| 보너스 대미지 | 그로기·백어택·에어리얼 상황에 보너스 대미지가 적용됩니다. 수치는 이후 밸런싱할 수 있습니다. |
| 회복병 | 전투 중 회복병을 사용하고 HUD에서 잔여 횟수를 확인할 수 있습니다. 던전에서 보스방으로 진행할 때 잔여 횟수가 이어집니다. |
| 보스전 | 던전의 마지막에 보스와 싸우며, 보스를 처치하면 해당 던전이 클리어됩니다. |

이 빌드를 M3 마감까지 준비하고, 마감 직후 주변 친구들에게 플레이를 부탁해 전투가 재미있는지 피드백을 받습니다.

## 전투 방향 확정

지난 회의에서는 **공방으로 적을 그로기에 빠뜨리고, 그 틈에 스킬 콤보로 큰 피해를 주는 방향**을 제안했습니다. 이번에는 실제 플레이를 보면서 이 방향을 확정했으면 합니다.

### 스킬 확장과 콤보

스킬 확장과 콤보는 제가 기획부터 Spec 작성, 구현과 폴리싱까지 맡아서 만들겠습니다.

스킬 4개와 궁극기 1개 구성으로 확장합니다. 제가 정한 아래 내용을 바탕으로 구현하겠습니다.

| 스킬 | 역할 | 구현할 내용 |
| - | - | - |
| 스킬 1 | 접근기 | 적의 뒤로 텔레포트해 대미지를 가하는 공격. 회피 용도로도 사용 가능 |
| 스킬 2 | 띄우기 | 현재 E 스킬을 바탕으로 한 공중 연계 |
| 스킬 3 | 장풍 | 최대 3스택까지 재충전 가능한 원거리 투사체 공격 |
| 스킬 4 | 광역기 | 근처의 다수의 적에게 큰 대미지를 입히는 기술 |

각 스킬의 역할에 맞춰 기본 공격과 스킬 간 연계도 함께 구현하겠습니다.

스킬 4종의 모션과 판정, 연계 규칙은 제가 Spec으로 구체화하고 구현하겠습니다.

### 전투 상황별 보너스 대미지

전투 상황에 따른 보너스 대미지도 제가 구현하겠습니다.

| 상황 | 보너스 대미지 |
| - | - |
| 그로기 | +50% |
| 백어택 | +10% |
| 에어리얼 | +10% |

각 수치는 기획 데이터로 제공해 이후 밸런싱할 수 있도록 하겠습니다.

### 회복병

[회복병 Spec](<../../Specs/회복병/1-spec.md>) 초안이 작성되어 있습니다. M3에서는 회복병 사용과 잔여 횟수, HUD를 구현합니다.

### 다수전과 전투 피드백

동시 공격 수 제한이 적용된 상태에서 근거리·원거리 적이 섞인 전투를 확인합니다. 공격 예고가 보이고 대응할 틈이 있는지, 기다리는 적 때문에 전투가 늘어지지는 않는지 봐야 합니다.

카메라, 공격 판정, 적중·패리·피격 효과는 실제 전투를 기준으로 다듬습니다. 플레이어가 성공과 실패의 이유를 알아볼 수 있는지가 기준입니다.

## MVP 던전 선정과 구성

M2에서 만든 미니던전 중 하나를 선정하거나, 플레이 반응이 좋았던 구간을 취합해 MVP 던전을 구성하려고 합니다.

- 첫 전투에서 조작과 적의 공격을 익힐 수 있는지 확인합니다.
- 이후 근거리·원거리 적을 조합해 전투에 변화를 줍니다.
- 길을 헤매거나 전투 없이 이동하는 시간이 길어지지 않도록 동선을 다듬습니다.
- 보스에게 도달했을 때 남는 체력과 회복병 횟수를 보며 전투 난도를 조정합니다.
- 보스 처치, 플레이어 사망, 재도전까지 한 흐름으로 확인합니다.

문·엘리베이터·사다리 같은 상호작용은 **선정한 던전에서 꼭 필요한 것부터** 범위를 정했으면 합니다. 레벨디자인에 필요한 위치와 목적을 먼저 정하고, 신규 구현이 필요하면 Spec으로 요청해주세요.

성장, 장비, 체크포인트, 2단 점프와 공중 대시는 이번 전투 MVP의 필수 범위에 넣지 않는 제안입니다. 현재 이동 능력으로 끝까지 진행할 수 있도록 구성합니다.

## 담당 과제

### 이창영

1. 민석님과 충분히 논의해서 MVP 던전에 필요한 적의 종류와 공격 패턴을 확정하고, 신규 구현이 필요한 부분은 Spec으로 작성해주세요. 실제 던전에 배치한 뒤 함께 플레이하며 전투가 재미있는지 확인해주세요.
2. 회복병 Spec을 M3 범위로 정리하고, 구현 결과를 확인해주세요.
3. 직접 플레이하면서 전투의 세부 규칙과 조작감에 대한 피드백도 부탁드립니다. 예를 들어 달리기의 SP 소모를 없애는 것이 좋을지처럼, 바꾸면 전투가 더 재미있어질 부분을 구체적으로 말씀해주세요.

### 이민석

1. MVP에 사용할 던전 후보와 선정 이유를 제안해주세요. 기존 구간을 취합해도 됩니다.
2. 창영님과 적의 종류·패턴·배치를 논의하며, 선정한 던전을 일반 적 전투부터 보스전까지 5분 이상 분량으로 구성해주세요.
3. 꼭 필요한 상호작용 요소가 있다면 위치와 용도를 정리해주세요.

### 이우성

1. 스킬 확장과 콤보를 전담하겠습니다. 스킬 구성과 연계 규칙 기획, Spec 작성, 기술 설계, 구현까지 진행하겠습니다.
2. 전투 상황별 보너스 대미지를 구현하겠습니다. 그로기·백어택·에어리얼 보너스 수치를 이후 밸런싱할 수 있도록 제공하겠습니다.
3. 회복병과 선정한 던전에 필요한 기능은 확정한 Spec에 따라 기술 설계와 구현을 진행하겠습니다.

## M3 진행 일정

- **첫째 주 (11월 9일 ~ 15일)**: 스킬·콤보·보너스 대미지·회복병을 구현합니다. MVP에 사용할 던전을 선정하고, 적의 종류와 패턴을 결정해 전투 구간을 설계하고 임시 배치합니다.
- **둘째 주 (11월 16일 ~ 22일)**: 필요한 적·패턴을 구현하고, 통합 플레이를 통해 세부 동선과 세부 적 배치를 재미있게 조정해 확정 배치합니다. 난이도 조정과 전투 밸런싱을 진행해 전투 MVP 빌드를 완성합니다.
- **11월 23일**: 주변 친구들에게 플레이를 부탁하고 전투의 재미에 대한 피드백을 받습니다.

외부 플레이테스트는 **2026년 11월 23일, M3 마감 직후**에 진행합니다. 주변 친구들에게 플레이를 부탁하고 전투가 재미있는지 의견을 들어보려고 합니다. 이번 MVP에서는 이 피드백으로 전투 방향을 판단하는 것이 중요합니다.

- 적과 공방을 주고받는 것이 재미있었는지

- 어떤 부분이 재미있거나 아쉬웠는지, 다시 플레이하고 싶은지
