# 1. 마일스톤 1 관련

플레이해보고 괜찮았는지 의견 듣고 싶습니다.

마일스톤 1의 전투는 특정한 방향 없이 제가 임의 구현한 것이므로, 방향 제시해주신다면 고치겠습니다!

- (예시) 스킬을 2개로 늘리자는 의견. (Q스킬, E스킬, R궁극기)
- (예시) 공중 콤보를 비활성화하자는 의견
- (예시) 전투 시스템에서 특정 규칙을 개선하거나, 신규 시스템을 추가하자는 의견

밸런스 느낌이나 데이터는 언제든지 AI에게 얘기해서 바로바로 고쳐주세요.

# 2. AI 워크플로우 관련

우리 프로젝트는 [SDD (Spec-Driven Development)](https://tanujarora.in/blog/2026-04-15-spec-driven-development-in-game-dev-a-complete-guide/)를 적용하고 있습니다.

Spec이란 AI에게 최적화된 개발 요청 사양서입니다. AI가 Spec 문서 및 기획서까지 100% 관리해줄겁니다.

잘 모르겠으면 AI에게 뭐든지 물어보세요.
- (예시) SDD(Spec-Driven Development)에 대해서 알려줘
- (예시) 기획자가 AI 워크플로우를 어떻게 시작하면 되는지 알려줘
- (예시) 지금 우리 게임에 적 시야가 구현되어있는지 알려줘

# 3. 마일스톤 2 관련

마일스톤1은 **보스전**이 주제였습니다.

마일스톤2는 **던전**을 주제로 약 2주간 진행하고자 합니다. 

- 기획 마감: 11월 1일까지
- 구현 마감: 11월 8일까지

## 구현 범위

던전을 주제로 했을 때 저의 제안이며, 수정 가능합니다.

#### 일반 적 추가
- 근거리 일반 적 1종
- 원거리 일반 적 1종
#### 네임플레이트
- 일반 적과 샌드백 머리 위에 출력되는 체력바
#### 미니던전 3종
- 최종 목적지의 보스를 처치하면 클리어되는 전투 컨텐츠 위주의 선형적인 던전입니다.
- 그레이박싱과 적 배치만으로 동선 설계 및 전투를 재밌게 구성합니다.
- 미니던전 중에 제일 재밌는 것 1개를 선정하거나, 반응이 좋았던 부분을 잘 취합하여 프로덕션 예정입니다.
- 별도의 기술 지원이나, 아트 에셋 지원 없습니다. (컷신, 보상, 퀘스트 등은 이번 마일스톤 범위를 벗어나기 때문)
- 신규 구현 필요한 부분은 취합 후 다음 마일스톤에서 정식 기획이 필요합니다.

#### 시뮬레이션 룸
- 샌드백이나 원하는 적들과 싸울 수 있는 전투 연습장입니다.
- 전투 밸런싱이나 디버깅 용도로 사용합니다.
#### 스테이지 선택
- 게임플로우를 수정하여, 타이틀 화면에서 접속할 스테이지를 고를 수 있게 합니다.

# 4. 과제

AI 워크플로우를 사용하여 개발 Spec 문서 또는 기획서를 생성해서 올려주세요.

기획자가 Spec 문서를 빨리 적어주실수록, 추가 개발할 수 있는 여유 시간이 확보됩니다.

SDD 개발에서는 구현이 하루 내에 끝나므로 구현은 개발 병목이 되지 않습니다!

## 이창영
#### 근거리 일반 적 1종, 원거리 일반 적 1종 Spec
- 컨셉이나 패턴 등은 자유롭게 구성하면 됩니다.
- 민석님이 만들 던전에 배치될 예정입니다.
#### 네임플레이트 시스템 Spec
- 일반 적의 머리 위에 붙어서 체력 등의 전투 정보를 출력하는 UI 입니다.
- AI랑 논의해서 세부 규칙 등을 Spec 문서에 남기면 됩니다.

## 이민석
#### 스테이지 선택 Spec
- 마일스톤1에서는 타이틀 화면에서 LV_BossStage만 접속 가능합니다.
- 새로 추가될 미니던전 3종, 시뮬레이션 룸도 접속 가능하게 해달라고 AI에게 요청하세요.
#### 미니던전 레벨디자인 기획서 3종
- 예상되는 던전의 레벨디자인 기획서를 AI와 함께 작성해주세요.
- 기존의 [스테이지 - 보스 전장.md](<../Design/Level/스테이지 - 보스 전장.md>) 수준으로 간단하게 적어도 됩니다.  
- 관련 신규 구현이 필요하지 않으므로, Spec 문서는 불필요할 것 같아요.
- 실제 배치할 때는 플레이해보면서 더 재밌는 배치로 수정하셔도 됩니다.

## 이우성
#### 시뮬레이션 룸 Spec
- 시뮬레이션 룸에 대한 기획서를 작성합니다.
- 전투할 적들 선택과 배치에 대한 규칙 등 Spec을 작성합니다.
#### 샌드백 Spec
- 전투 밸런싱이나 디버깅 용도로 사용할 샌드백에 대한 Spec을 작성합니다.
#### 카메라 연출 개선
- 처형, 패링 등의 상황에서 카메라 연출을 수정할 수 있는 데이터 주도적인 방법을 개발합니다.
