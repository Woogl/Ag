# AI 아트 연구 결과

Tripo, Claude, ChatGPT로 3D 모델링을 여러가지로 테스트해보았습니다.

## AI가 잘할 수 있는 아트 작업

* 컨셉 아트 생성
* 2D 컨셉 아트를 A 포즈 전후좌우 이미지로 변환
* 정적인 사물 3D 모델링 (보물상자, 화물 컨테이너, 텔레비전 등)
* 카툰 스타일 3D 모델링

## AI가 잘 못하는 아트 작업

* 장식, 문자 해석
* 인체 3D 디테일 (머리카락, 귀, 눈썹, 손가락 등)
* 실사 스타일 3D 모델링
* 리깅

## 중간 결론 

AI 아트가 못하는 부분을 우리가 해결해줄 수 없기에, AI 아트가 잘하는 방향으로 아트 스타일을 맞춰야한다.

즉, 카툰풍 + 인간 얼굴이 안나와도 되는 컨셉으로 간다.
