# 문서 인덱스

작업에 필요한 정본을 찾는 진입점입니다. 규칙과 수치, 구현 상세는 연결된 문서에서 확인합니다.

## 읽는 순서

1. [AGENTS.md](<../AGENTS.md>)와 [AI 워크플로우](<AI 워크플로우.md>)의 공통 규칙 및 해당 작업 절을 확인합니다. 같은 대화에서 이미 확인했고 변경되지 않았다면 다시 읽지 않습니다.
2. 아래에서 작업과 주제를 골라 필요한 문서의 관련 절을 읽습니다. 연결된 문서를 전부 읽을 필요는 없습니다.
3. 코드·데이터·에셋의 위치를 모를 때 상세 위치표를 사용합니다. 위치를 이미 알면 해당 원본으로 바로 가되, 수정 전 현재 내용을 확인합니다. 인덱스와 위치표는 현재 구현의 증거를 대신하지 않습니다.
4. 정보가 부족하거나 변경 영향이 다른 주제로 이어질 때만 관련 문서로 탐색을 넓힙니다. 정본 간 충돌은 임의로 해석하지 않고 근거와 함께 보고합니다.

## 문서와 원본의 역할

| 위치 | 역할 |
| - | - |
| `AGENTS.md` | 모든 작업에 적용하는 프로젝트 규칙 |
| `Docs/AI 워크플로우.md` | 작업 진행·승인·동기화·문서 작성 규칙 |
| `Docs/인덱스.md` | 작업과 주제에 따른 문서 탐색 경로 |
| `Docs/용어집.md` | 공통 용어의 뜻 |
| `Docs/Design` | 플레이해서 확인할 수 있는 기획과 마일스톤 범위 |
| `Docs/Drafts` | 확정 전 기획 초안. 현재 구현·검증 기준에 포함하지 않으며, 확정한 내용은 해당 기획서에 반영 |
| `Docs/Program` | 주제별 구현 결정·이유·클래스 구조. 구현 위치표는 기획→구현, 데이터 위치표는 기획→파일·필드, 에셋 목록은 에셋 경로를 안내 |
| `Docs/Plan` | 큰 변경의 검토용 설계안. 완료 후 결정은 구현 문서로 옮기고 설계안은 삭제 |
| `Docs/Art` | 리소스 조사와 선택 근거. 조사 시점의 기록이므로 실제 사용 전 에셋 상태 확인 |
| `Docs/Meeting` | 회의 자료. 확정된 결정은 해당 정본에 반영 |
| `Data`, `Source`, `Content` | 각각 기획 데이터 JSON, C++ 구현, UE 에셋의 실제 원본 |
| `Scripts/*/README.md` | 해당 스크립트의 실행 방법 |
| `.agents/skills` | 반복 작업 절차와 도구 요령. 규칙·결정은 해당 정본을 참조. Claude Code의 `.claude/skills` 연결 방법은 루트 `.gitignore` 주석 참고 |

## 인덱스 유지

- 문서를 추가·이동·삭제하거나 역할을 바꾸면 해당 진입점과 링크를 함께 갱신합니다. 새 주제가 아니면 기존 주제 행에 연결합니다.
- 수치·규칙·클래스 목록·작업 현황을 이 문서에 복제하지 않습니다. 상세 탐색 정보는 기존 위치표에 둡니다.
- 모든 파일의 목록이나 줄 번호를 관리하지 않습니다. 표에 없는 파일은 해당 폴더에서 `rg --files`로 찾고, 긴 문서는 `rg -n`으로 제목·검색어를 찾아 관련 절부터 읽습니다.
