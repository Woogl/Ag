# 전체 마일스톤

출시까지의 마일스톤 순서와 각 마일스톤의 주제, 목표를 정의합니다. 기간, 세부 개발 범위, 담당 과제는 마일스톤별 문서에서 정합니다.

이 문서는 대략적인 구상이며, 진행 중에 변경될 수 있습니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 구성

완성된 게임은 던전과 보스로 이루어진 스테이지를 차례로 진행하며 캐릭터를 성장시키는 구조입니다. 플레이어 캐릭터는 1명입니다.

M3, M6, M9에서 그때까지 만든 기능을 플레이할 수 있는 분량으로 묶어 확인하고, 주변인에게 플레이테스트를 받습니다. 플레이테스트 피드백은 다음 마일스톤에서 반영합니다.

## M4 ~ M6: 버티컬 슬라이스

| 마일스톤 | 주제 | 예상 업무 | 목표 |
| - | - | - | - |
| M4 | 성장 | 스킬트리 <br> 장비 아이템 <br> 체크포인트 | 스테이지를 깨며 캐릭터를 강화하고, 진행 상황을 이어서 플레이할 수 있게 합니다. |
| M5 | AI 아트 워크플로우 | 등장인물과 배경 컨셉아트 <br> 환경 에셋 제작 <br> 캐릭터 에셋 제작 | AI로 만든 에셋을 정한 아트 방향에 맞춰 게임에 넣는 방법을 갖춥니다. |
| M6 | 버티컬 슬라이스 | 신규 스테이지 1개 <br> 신규 일반 적 <br> 신규 보스 1종 | 전투·성장·아트를 모두 갖춘 완성된 게임의 모습을 15분 안팎 분량으로 보여 줍니다. |

M6까지 2026년 안에 마치는 것을 목표로 합니다.
