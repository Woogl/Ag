# 마일스톤 2

마일스톤 2는 **던전**을 주제로 진행 중입니다. 이 문서는 정식 채택된 개발 범위와 일정, 담당 과제를 정의합니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 기간

시작일은 2026.10.25입니다.

| 단계 | 마감일 | 작업 내용 |
| - | - | - |
| 기획 | 2026.11.01 | 담당 과제의 Spec 문서와 레벨디자인 기획서 작성 |
| 구현 | 2026.11.08 | 확정된 기획에 따라 기능과 콘텐츠 구현 |

## 목표

일반 적과 보스를 배치한 선형 던전을 만들고, 동선과 전투 구성의 재미를 검증합니다. 전투 연습과 밸런싱·디버깅에 사용할 환경을 함께 마련합니다.

## 개발 범위

| 항목 | 범위 |
| - | - |
| 일반 적 | 근거리 일반 적 1종과 원거리 일반 적 1종을 추가하여 미니던전에 배치합니다. 컨셉과 패턴은 담당 기획자가 정합니다. |
| 네임플레이트 | 일반 적과 샌드백 머리 위에 체력바를 출력합니다. 세부 표시 규칙은 Spec에서 정합니다. |
| 미니던전 | 전투 콘텐츠 중심의 선형 던전 3종을 만듭니다. 각 던전은 최종 목적지의 보스를 처치하면 클리어됩니다. |
| 시뮬레이션 룸 | 샌드백이나 원하는 적들과 싸울 수 있는 전투 연습장을 만듭니다. 전투 밸런싱과 디버깅에 사용하며, 전투할 적의 선택과 배치 규칙은 Spec에서 정합니다. |
| 샌드백 | 전투 밸런싱과 디버깅용 샌드백을 만듭니다. 세부 동작은 Spec에서 정합니다. |
| 스테이지 선택 | 타이틀 화면에서 기존 보스전, 미니던전, 시뮬레이션 룸에 접속할 수 있도록 게임 흐름을 수정합니다. |
| 카메라 연출 개선 | 처형·패리 등의 상황에서 카메라 연출을 데이터로 조정할 수 있는 방법을 개발합니다. |

## 미니던전 제작 기준

- 그레이박싱과 적 배치만으로 동선을 설계하고 전투를 구성합니다. 실제 배치는 플레이 결과에 따라 조정합니다.
- 미니던전 제작을 위한 별도의 기술 지원이나 아트 에셋 지원은 없습니다. 컷신, 보상, 퀘스트 등은 이번 범위에서 제외합니다.
- 제작 중 필요한 신규 구현은 별도로 취합하여 다음 마일스톤에서 정식 기획합니다.
- 플레이 결과를 바탕으로 가장 재미있는 던전 하나를 선정하거나 반응이 좋았던 부분을 취합하여 후속 프로덕션에 활용합니다.

| - | - |

## 작업 방식

기능 개발은 [AI 워크플로우](<../AI 워크플로우.md>)의 SDD 절차를 따릅니다. 기능별 세부 규칙은 Spec에서 구체화하고, 구현·검증과 확인을 마친 뒤 해당 기획서와 구현 문서에 반영합니다.

미니던전은 신규 시스템 구현 없이 레벨을 구성하므로 별도 Spec 대신 레벨디자인 기획서를 작성합니다. 문서의 상세 수준은 [스테이지 - 보스 전장](<../Design/Level/스테이지 - 보스 전장.md>)을 참고합니다.

회의 자료는 [2026-10-25 회의 내용](<../Meeting/2026-10-25 회의 내용.md>)에서 확인합니다.
