# 마일스톤 4

마일스톤 4의 주제는 **보상**입니다. 이 문서는 개발 범위와 완료 기준을 정의합니다. 주간 담당 과제는 각 회의 문서에서 관리합니다.

## 목표

보물상자에서 얻은 장비로 린을 강하게 만들고, 사망하거나 게임을 다시 켜도 진행을 이어 가는 던전 플레이를 완성합니다.

## 보상의 완성 기준

완성본은 **보물상자와 체크포인트를 배치한 새 던전 레벨 1개**입니다. 아래 콘텐츠가 하나의 플레이 가능한 빌드에 들어 있어야 합니다.

| 콘텐츠 | 완성본에 들어갈 내용 |
| - | - |
| 던전 | 새로 만드는 던전 레벨입니다. 보물상자를 찾아 여는 탐험 동선과, 체크포인트로 나뉜 전투 구간을 갖춥니다. |
| 장비 아이템 | [아이템 시스템](<../Design/System/아이템 시스템.md>)의 소비·재화 아이템에 장비 아이템이 더해집니다. 장비는 린의 스탯만 올리고 외형은 바꾸지 않습니다. |
| 인벤토리 | 가진 아이템과 보유 수를 보고, 장비를 끼고 뺄 수 있는 화면입니다. |
| 보물상자 | 던전에 놓인 상자를 상호작용으로 열어 아이템을 얻습니다. |
| 사다리 | 던전에서 높이가 다른 곳을 사다리로 오르내립니다. |
| 체크포인트 | 체크포인트를 지난 뒤 사망하면 던전 처음이 아니라 마지막으로 지난 체크포인트에서 다시 시작합니다. |
| 세이브&로드 | 게임을 끄고 다시 켜도 보유 아이템, 장비, 연 보물상자, 지난 체크포인트가 이어집니다. |

## Spec에서 정할 것

| 기능 | 정할 것 |
| - | - |
| 장비 아이템 | 장비 목록, 장비마다 올리는 스탯과 수치 |
| 인벤토리 | 여는 키, 전투 중에도 열 수 있는지, 여는 동안 게임이 멈추는지 |
| 보물상자 | 상자마다 나오는 아이템(정해져 있는지, 무작위인지), 재화 아이템을 넣을지 |
| 사다리 | 타는 방식(닿기, 상호작용)과 내리는 방식, 오르내리는 속도, 타는 동안 할 수 있는 행동, 타는 동안 맞았을 때, 적이 사다리를 따라오는지 |
| 체크포인트 | 지나는 방식(닿기, 상호작용), 다시 시작할 때 HP·회복병·적의 상태 |
| 세이브&로드 | 저장하는 순간, 저장 슬롯 수, 타이틀 화면에서 이어 하기와 새로 하기, 스테이지 사이에 이어 가는 상태(보유 아이템, 장비)와 스테이지마다 따로 두는 상태(연 상자, 체크포인트) |

## 바뀌는 기존 기획

아래 기획서의 지금 규칙은 이번 기능과 맞지 않으므로, 해당 Spec에서 함께 정리합니다.

- [아이템 시스템](<../Design/System/아이템 시스템.md>) '공통'의 시작: 스테이지에 들어갈 때마다 시작 보유 수로 돌아갑니다.
- [게임 플로우](<../Design/System/게임 플로우.md>) '스테이지 공통': 다시 시작하면 레벨을 처음부터 로드하고 모든 상태를 초기화합니다. 'Front End'에는 저장을 불러오는 흐름이 없습니다.

## 진행 순서

1. 장비 아이템, 인벤토리, 보물상자, 사다리의 Spec을 정하고 구현합니다. 새 던전은 이와 함께 레벨 기획서를 쓰고 만들기 시작하며, 보물상자와 체크포인트, 사다리를 놓을 자리도 레벨 기획서에서 정합니다.
2. 체크포인트와 세이브&로드는 저장할 상태(보유 아이템, 장비, 연 보물상자)가 정해진 뒤에 Spec을 정하고 구현합니다.
3. 새 던전에 보물상자와 체크포인트를 배치하고, 시작부터 Stage Clear까지 사망과 게임 재시작을 거쳐도 진행이 이어지는지 통합 플레이로 확인합니다.
