# 마일스톤 3

마일스톤 3의 주제는 **전투 MVP 완성**입니다. 이 문서는 개발 범위와 완료 기준, 일정을 정의합니다. 주간 담당 과제는 각 회의 문서에서 관리합니다.

## 기간과 목표

기간은 **2026년 11월 9일 ~ 11월 22일**입니다. 개발팀 밖의 사람이 처음 플레이해도 재미를 느낄 수 있는 5분 이상 분량의 전투를 완성합니다.

## 전투 MVP의 완성 기준

완성본은 **일반 적과의 전투부터 마지막 보스전까지 이어지는, 5분 이상 분량의 던전 1개**입니다. 아래 콘텐츠가 하나의 플레이 가능한 빌드에 들어 있어야 합니다.

| 콘텐츠 | 완성본에 들어갈 내용 |
| - | - |
| 플레이어 전투 | 스킬 4종과 기본 공격을 연계하며, 샌드백을 때리는 것만으로도 타격과 콤보의 재미를 느낄 수 있습니다. |
| 던전 1개 | M2 미니던전에서 선정하거나, 일부 구간을 취합하거나, 새로 제작한 던전. 입구에서 일반 적 전투 구간을 거쳐 보스방까지 이동할 수 있는 지형과 동선, 적 배치가 갖춰져 있습니다. |
| 일반 적 전투 | 창영님과 민석님이 정한 적의 종류와 공격 패턴이 실제 던전에 적용되어 있습니다. 배치된 적과 공방을 주고받으며 진행할 수 있습니다. |
| 보스전 | 던전의 마지막에 보스와 싸우며, 보스를 처치하면 해당 던전이 클리어됩니다. |
| 보너스 대미지 | 그로기·백어택·에어리얼 상황에 보너스 대미지가 적용됩니다. 수치는 이후 밸런싱할 수 있습니다. |
| 회복병 | 전투 중 회복병을 사용하고 HUD에서 잔여 횟수를 확인할 수 있습니다. 던전에서 보스방으로 진행할 때 잔여 횟수가 이어집니다. |

이 빌드를 M3 마감까지 준비하고, 마감 직후 주변 친구들에게 플레이를 부탁해 전투가 재미있는지 피드백을 받습니다.

## 전투 작업 내용

**공방으로 적을 그로기에 빠뜨리고, 그 틈에 스킬 콤보로 큰 피해를 주는 방향**을 실제 플레이로 확인합니다.

### 스킬 확장과 콤보

스킬 4개와 궁극기 1개 구성으로 확장합니다. 이우성이 아래 내용을 바탕으로 스킬과 콤보를 구현합니다.

| 스킬 | 역할 | 구현할 내용 |
| - | - | - |
| 스킬 1 | 접근기 | 적의 뒤로 텔레포트해 대미지를 가하는 공격. 회피 용도로도 사용 가능 |
| 스킬 2 | 띄우기 | 지금의 올려베기 스킬을 바탕으로 한 공중 콤보 시동기 |
| 스킬 3 | 장풍 | 최대 3스택까지 재충전 가능한 원거리 투사체 공격 |
| 스킬 4 | 광역기 | 근처의 다수의 적에게 큰 대미지를 입히는 기술 |

각 스킬의 역할에 맞춰 기본 공격과 스킬 간 연계도 함께 구현하겠습니다.

### 전투 상황별 보너스 대미지

전투 상황에 따른 보너스 대미지도 이우성이 구현합니다.

| 상황 | 보너스 대미지 |
| - | - |
| 그로기 | +50% |
| 백어택 | +10% |
| 에어리얼 | +10% |

각 수치는 기획 데이터로 제공해 이후 밸런싱할 수 있도록 하겠습니다.

### 회복병

회복병 사용과 잔여 횟수, HUD를 구현했습니다. 규칙은 [플레이어 캐릭터 - 린](<../Design/Content/플레이어 캐릭터 - 린.md>)의 '회복병'을 따릅니다.

## MVP 던전 선정과 구성

M2에서 만든 미니던전 중 하나를 선정하거나, 일부 구간을 취합하거나, 새로 제작해 MVP 던전을 구성합니다.

- 첫 전투에서 조작과 적의 공격을 익힐 수 있는지 확인합니다.
- 이후 근거리·원거리 적을 조합해 전투에 변화를 줍니다.
- 길을 헤매거나 전투 없이 이동하는 시간이 길어지지 않도록 동선을 다듬습니다.
- 보스에게 도달했을 때 남는 체력과 회복병 횟수를 보며 전투 난도를 조정합니다.
- 보스 처치, 플레이어 사망, 재도전까지 한 흐름으로 확인합니다.

문·엘리베이터·사다리 같은 상호작용은 **선정한 던전에서 꼭 필요한 것부터** 범위를 정했으면 합니다. 레벨디자인에 필요한 위치와 목적을 먼저 정하고, 신규 구현이 필요하면 Spec으로 요청해주세요.

성장, 장비, 체크포인트, 2단 점프와 공중 대시는 이번 전투 MVP의 필수 범위에 넣지 않는 제안입니다. 현재 이동 능력으로 끝까지 진행할 수 있도록 구성합니다.

## M3 진행 일정

- **첫째 주 (11월 9일 ~ 15일)**: 스킬·콤보·보너스 대미지·회복병을 구현합니다. MVP에 사용할 던전을 선정하고, 적의 종류와 패턴을 결정해 전투 구간을 설계하고 임시 배치합니다.
- **둘째 주 (11월 16일 ~ 22일)**: 필요한 적·패턴을 구현하고, 통합 플레이를 통해 세부 동선과 세부 적 배치를 재미있게 조정해 확정 배치합니다. 난이도 조정과 전투 밸런싱을 진행해 전투 MVP 빌드를 완성합니다.
- **11월 23일**: 주변 친구들에게 플레이를 부탁하고 전투의 재미에 대한 피드백을 받습니다.

## 외부 플레이테스트에서 확인할 것

외부 플레이테스트는 **2026년 11월 23일, M3 마감 직후**에 진행합니다. 주변 친구들에게 플레이를 부탁하고 전투가 재미있는지 의견을 들어보려고 합니다. 이번 MVP에서는 이 피드백으로 전투 방향을 판단하는 것이 중요합니다.

- 조작법과 규칙이 직관적이었는지
- 어떤 부분이 재미있었는지
- 어떤 부분이 별로였는지
- 다시 플레이하고 싶은지
