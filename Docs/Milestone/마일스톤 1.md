# 마일스톤 1

마일스톤 1은 2026.10.24에 완료되었습니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 기간

| 단계 | 시작일 | 종료일 | 작업 내용 |
| - | - | - | - |
| 기획 | 2026.10.08 | 2026.10.10 | 마일스톤에 필요한 모든 기획서를 적확하게 작성 |
| 구현 | 2026.10.10 | 2026.10.20 | AI에게 기획서 전달하여 설계 문서화. 이후 AI에게 구현 위임 |
| 플레이 검증 | 2026.10.21 | 2026.10.24 | 의도한 대로 구현되었는지 직접 플레이하며 확인합니다. |

## 목표

### 1. 보스전 프로토타이핑 제작

타이틀부터 보스전, 결과 화면까지 게임 루프 한 바퀴를 완성하며, 보스전을 치르기 위해 필요한 최소 요소만 만듭니다.

- 플레이어 캐릭터 1종
- 보스 캐릭터 1종
- 보스전 스테이지 1종
- 전투 시스템
- 카메라
- HUD 및 UI

### 2. 핵심 전투 재미 검증

직접 플레이하며 기획한 전투 재미(조작 반응성, 공격·방어 타격감, 패턴 대응의 성취감)가 체감되는지 확인합니다.

## 아트 리소스

신규 아트 에셋을 추가하지 않고, 현재 있는 것을 활용합니다.

사용하는 리소스와 세부 표현은 [아트 표현 사양](<../Art/아트 표현 사양.md>)을 따릅니다.
