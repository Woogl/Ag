# 플레이어 사양

플레이어가 조작하는 캐릭터의 스탯과 행동 규칙을 정의합니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<전투 시스템.md>) 문서를 따릅니다.

키 배치와 입력 처리(허용 입력, 선입력, 모션 캔슬)는 [플레이어 입력](<플레이어 입력.md>) 문서를 따릅니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

행동명에 병기한 영문 식별자는 `Abilities.json`에 정의된 어빌리티 ID입니다.

## 개요

| 항목 | 내용 |
| - | - |
| 시점 | 3인칭 |
| 무기 | 카타나 |
| 핵심 플레이 | 보스의 공격을 패리와 회피로 받아 내고, 생긴 빈틈에 콤보와 스킬을 넣어 보스의 PP를 깎습니다. |
| 리소스 | [마일스톤1 계획](<마일스톤1 계획.md>)의 아트 리소스를 따릅니다. |

## 스탯

| 스탯 | 초기값 | 비고 |
| - | - | - |
| HP / MaxHP | 1000 / 1000 | |
| SP / MaxSP | 100 / 100 | |
| MP / MaxMP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| UP / MaxUP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| PP / MaxPP | 미사용 | 플레이어는 그로기 대상이 아닙니다. |
| ATK | 100 | |
| DEF | 50 | |
| MOV | 400 | 단위 cm/s. 기본 이동 속도 |

### 자원 회복

| 스탯 | 회복 규칙 |
| - | - |
| HP | 회복하지 않습니다. |
| SP | 마지막으로 SP를 소모하고 1초 뒤부터 초당 40 회복합니다. 가드 중에는 초당 20 회복합니다. SP가 0이 되면 리젠 대기 시간이 1.5초로 늘어납니다. |
| MP | 자연 회복하지 않습니다. 아래 'MP 충전' 표의 행동으로 충전합니다. |
| UP | 자연 회복하지 않습니다. 아래 'UP 충전' 표의 행동으로 충전합니다. |

### MP 충전

| 행동 | 충전량 |
| - | - |
| 평타 적중 (1타당) | +4 |
| 점프 공격 적중 | +4 |
| 회피 반격 적중 | +8 |
| 극한 회피 성공 | +10 |
| 패리 성공 | +15 |

- 스킬, 궁극기, 처형의 적중으로는 MP를 충전하지 않습니다.

### UP 충전

| 행동 | 충전량 |
| - | - |
| 스킬 적중 | +25 |
| 평타 5타(마지막 타) 적중 | +10 |
| 패리 성공 | +10 |
| 극한 회피 성공 | +10 |

- 그 밖의 행동(평타 1 ~ 4타, 회피 반격, 궁극기, 처형 등)으로는 UP를 충전하지 않습니다.

### SP 소모

| 행동 | 소모량 |
| - | - |
| 회피 | 20 |
| 달리기 | 초당 12 |
| 가드로 막은 공격 | 가드 경감 배율 적용 전 HP 감소량의 25% |

- 점프, 점프 공격, 평타, 스킬은 SP를 소모하지 않습니다.
- 회피는 SP가 위 표의 소모량 이상일 때만 사용할 수 있습니다.
- 달리기는 SP가 0보다 크면 사용할 수 있습니다.
- 가드로 공격을 막을 때 SP가 부족하면 가드 브레이크가 발생합니다. (가드 항목 참고)

## 이동

| 상태 | 속도 | 캐릭터 방향 |
| - | - | - |
| 기본 이동 | MOV | 락온하지 않았을 때는 이동 방향을 바라봅니다. 락온 중에는 대상을 바라보며 이동합니다. |
| 달리기 | MOV × 1.5 | 락온 여부와 관계없이 이동 방향을 바라봅니다. |
| 가드 중 | MOV × 0.65 | 락온 중에는 대상을, 아닐 때는 카메라 정면을 바라봅니다. |

### 달리기 (Sprint)

- 회피 후딜 중 Shift를 누르고 있고 이동 입력이 있으면 그 순간 회피 모션을 캔슬하고 달리기로 전환됩니다. 가드 키를 누르고 있을 때는 '가드'를 따릅니다.
- Shift를 떼거나, 이동 입력이 없어지거나, SP가 0이 되면 기본 이동으로 돌아갑니다.
- 다시 달리려면 Shift를 새로 눌러 회피부터 시작해야 합니다.

## 락온 (LockOn)

카메라 규칙은 [카메라](<카메라.md>) 문서를 따릅니다.

- 락온 타겟팅 범위: 플레이어로부터 20m 이내입니다.
- 락온 대상: 락온 타겟팅 범위 안에 있고 화면 안에 있는 생존한 보스입니다. 적은 보스 1명이므로 대상 전환 기능은 없습니다.
- 락온 해제 조건: 락온 키 재입력, 대상이 플레이어로부터 30m 밖으로 벗어남, 대상 사망.
- 락온 중 캐릭터의 방향은 '이동' 항목을, 카메라의 움직임은 [카메라](<카메라.md>)의 '락온 카메라'를 따릅니다.
- 락온 마커 표시는 [전투 HUD](<전투 HUD.md>) 문서를 따릅니다.

## 전투 행동

이 문서의 모션 그림은 모션을 실제 재생 속도로 보여 주는 움직이는 그림입니다.

- 그림 속 시간은 참고 값입니다.
- 타격 순간에는 타 이름과 테두리를, 무적·극한 회피 구간·패리 구간·시간 정지·후딜인 동안은 그 이름을 표시합니다. 패리는 공격을 쳐 내는 순간을, 점프 공격은 판정 구간 전체를 타격 순간으로 표시합니다.
- 왼쪽 아래에는 지금 재생 중인 모션의 에셋 이름을 표시합니다.
- 카메라가 플레이어를 따라가므로 이동한 거리는 나타나지 않습니다. 넉업과 점프 공격의 높이도 모션 밖에서 주므로 나타나지 않습니다.
- 입력 시점에 따라 모습이 달라지는 행동은 아래 경우를 보여 줍니다.
  - 평타: [Samurai 애니메이션 조사](<../Art/Samurai 애니메이션 조사.md>)의 연결 시점에서 다음 타를 이은 경우
  - 점프 공격: 점프 최고점에서 공격한 경우
  - 가드: 가드를 시작하고 이동할 수 있게 되자마자 앞으로 걷는 경우
  - 패리: 가드를 시작한 뒤 패리 구간에 공격을 받은 경우

### 공통 규칙

- 구간별 허용 입력은 [플레이어 입력](<플레이어 입력.md>)을 따르며, 무적 등 다른 규칙은 각 행동 항목을 따릅니다.

#### 공격 방향

평타, 점프 공격, 회피 반격, 스킬은 각 타를 시작할 때 아래 순서로 공격 방향을 정합니다.

| 순서 | 조건 | 공격 방향 |
| - | - | - |
| 1 | 보스가 타겟팅 범위 안에 있음 | 락온 여부와 관계없이 보스 방향 |
| 2 | 락온 중 | 락온 대상 방향 |
| 3 | 그 밖의 경우 | 캐릭터 정면 |

- 타겟팅 범위는 각 행동 항목에서 정하며, 평타는 타마다 정합니다.
- 1은 [전투 시스템](<전투 시스템.md>)의 '공격 중 위치·회전 보정'에 따라 보스를 향해 돕니다. 2도 같은 회전 규칙으로 락온 대상을 향해 돌고, 회전 정지 시점부터는 돌지 않습니다.

#### 공격 중 위치·회전 보정

평타, 점프 공격, 회피 반격, 스킬은 [전투 시스템](<전투 시스템.md>)의 '공격 중 위치·회전 보정'을 따르며, 플레이어의 값은 아래와 같습니다.

| 항목 | 값 |
| - | - |
| 대상과의 최소 간격 | 1m |
| 회전 정지 | 각 타의 준비 시작부터 추적하고, 현재 재생 속도에서 판정 시작 약 0.05초 전에 방향을 확정합니다. 짧은 선딜에도 적용합니다. |
| 접근 구간 | 평타·스킬·회피 반격의 준비 중 실제로 전진하는 부분에만 배치하고, 회전 정지와 함께 끝냅니다. 판정·후딜에는 모션 자체의 이동만 사용합니다. |
| 타겟팅 범위, 최대 워핑 거리 | 각 행동 항목. 평타는 타마다 정합니다. |

각 타의 시작에 대상을 한 번 선택하고 타 도중에는 교체하지 않습니다. 범위를 벗어나면 그 타의 보정을 중단하며, 다음 타 전에는 다시 추적하지 않습니다. 스킬은 내려베기 직전에 방향을 확정하고, 점프 공격은 내리꽂기 전 준비 구간의 회전만 보정합니다. 점프 공격에는 추가 접근을 적용하지 않으며, 낙하 중에는 추적하지 않습니다. 처형은 처형의 지정 대상·간격 규칙을 따릅니다.

- 선딜 중 대상이 물러나면(Backstep 등) 보정 구간 시작 위치에서 최대 워핑 거리 밖으로 목표를 늘리지 않으므로 그만큼 간격이 벌어집니다.

#### 쿨다운

- 행동을 시작한 순간부터 셉니다. 쿨다운 중에는 그 행동을 입력해도 발동하지 않습니다.
- 보스전이 시작될 때는 모든 쿨다운이 끝난 상태입니다.
- 쿨다운 값은 각 행동 항목을 따르며, 적혀 있지 않은 행동은 쿨다운이 없습니다.

### 평타 (BasicAttack)

평타 키를 연속으로 입력하면 최대 5타까지 이어지는 콤보입니다.

| 타 | 대미지 배율 | PP 배율 | 피격 반응 | 타겟팅 범위 | 최대 워핑 거리 | 후딜 시작 |
| - | - | - | - | - | - | - |
| 1 | 0.8 | 0.8 | 움찔 | 2.0m | 1.1m | 판정 구간 끝 |
| 2 | 0.8 | 0.8 | 움찔 | 2.5m | 1.6m | 판정 구간 끝 |
| 3 | 1.0 | 1.0 | 움찔 | 2.5m | 1.6m | 판정 구간 끝 |
| 4 | 1.0 | 1.0 | 움찔 | 2.6m | 1.7m | 판정 구간 끝 |
| 5 | 1.2 | 2.0 | 움찔 | 2.6m | 1.7m | 모션 끝 0.3초 전 |

![평타 모션](<Attachments/플레이어 모션 평타.gif>)

모션: `ARPG_Samurai_Anim_UE_Attack_Combo_B1` → `ARPG_Samurai_Anim_UE_Attack_Combo_B2` → `ARPG_Samurai_Anim_UE_Attack_Combo_B3` → `ARPG_Samurai_Anim_UE_Attack_Combo_B4` → `ARPG_Samurai_Anim_UE_Attack_Combo_B5`

- 후딜이 끝날 때까지 입력이 없으면 콤보가 초기화됩니다.
- 회피, 가드, 점프, 스킬, 궁극기, 처형으로 평타를 모션 캔슬하거나 넉업, 넉백에 맞으면 콤보가 초기화됩니다. 움찔은 콤보를 끊지 않습니다.

#### 평타 키의 처리 순서

평타 키를 누르면 아래 순서로 검사해 처음 맞는 행동 하나를 사용합니다.

| 순서 | 조건 | 사용하는 행동 |
| - | - | - |
| 1 | 공중에 있음 | 점프 공격 |
| 2 | 회피 반격 기회가 남아 있음 ('극한 회피' 참고) | 회피 반격 |
| 3 | 평타 후딜 중 | 다음 타 (5타 다음은 1타) |
| 4 | 그 밖의 경우 | 1타 |

### 점프 (Jump)

| 항목 | 값 |
| - | - |
| 점프 높이·체공 시간 | 최고 높이 약 0.9m, 체공 시간 약 0.86초 |
| 공중 이동 | 공중에서는 방향을 거의 바꿀 수 없습니다. |

- 점프에는 무적 구간이 없습니다.
- 공중에서 허용되는 입력은 [플레이어 입력](<플레이어 입력.md>)의 '상태별 허용 입력'을 따릅니다.
- 달리는 중에 점프하면 달리기 속도를 유지한 채 점프합니다. 공중에서도 달리기가 이어져 SP를 소모하며, 착지했을 때 Shift와 이동 입력이 그대로 있으면 계속 달립니다.

#### 점프 공격 (JumpAttack)

공중에서 평타 키로 사용하는 공격입니다. 칼을 내려벤 뒤 빠르게 내리꽂아, 착지하며 바닥을 찍습니다.

| 대미지 배율 | PP 배율 | 피격 반응 | 타겟팅 범위 | 최대 워핑 거리 |
| - | - | - | - | - |
| 1.5 | 1.5 | 움찔 | 3m | 0m |

| 단계 | 내용 |
| - | - |
| 내려베기 | 칼을 뒤로 젖혔다가 앞 아래로 내려벱니다. 이 동안은 점프하던 궤적을 따라 움직입니다. |
| 내리꽂기 | 내려베기가 끝나면 초속 10m로 떨어집니다. |
| 착지 | 착지하며 칼끝으로 앞쪽 바닥을 찍고, 칼을 뽑아 일어섭니다. 착지 후 0.35초부터 후딜입니다. |

![점프 공격 모션](<Attachments/플레이어 모션 점프 공격.gif>)

모션: `ARPG_Samurai_Anim_UE_Attack_Airborne_Start` → `ARPG_Samurai_Anim_UE_Attack_Airborne_Mid` (반복) → `ARPG_Samurai_Anim_UE_Attack_Airborne_End`

- 판정 구간은 내려베기에서 칼을 내리기 시작할 때부터 착지해 바닥을 찍을 때까지이며, 1타입니다.
- 내려베기가 끝나기 전에 착지하면 그 순간 착지 단계로 넘어갑니다.
- 방향과 다가가는 거리는 '공통 규칙'을 따릅니다. 위치 보정 없이 회전만 적용하므로 보스에게 더 다가가지 않습니다. 수평 이동은 점프할 때의 이동을 그대로 이어 갑니다.

### 회피 (Dodge)

| 항목 | 값 |
| - | - |
| 발동 | Shift를 누르는 순간 |
| 방향 | 락온 여부와 관계없이 이동 입력 방향(카메라 기준)으로 구릅니다. 입력이 없으면 캐릭터 기준 후방으로 뛰어 물러납니다. |
| 무적 구간 | 시작 후 0초 ~ 0.3초 |
| 극한 회피 구간 | 시작 후 0초 ~ 0.15초 |
| 후딜 시작 | 구를 때는 시작 후 0.6초, 뒤로 물러날 때는 시작 후 0.4초 |
| 쿨다운 | 0.4초 |

![구르기 모션](<Attachments/플레이어 모션 구르기.gif>)

![뒤로 물러나기 모션](<Attachments/플레이어 모션 뒤로 물러나기.gif>)

모션: 구르기 `ARPG_Samurai_Anim_UE_Evade_Forward` (8방향 `ARPG_Samurai_Anim_UE_Evade_*` 중 앞), 뒤로 물러나기 `ARPG_Samurai_Anim_UE_Dodge`

- 가드 불가 공격도 회피 무적으로 피할 수 있습니다.

#### 극한 회피

극한 회피 구간에 보스의 공격 판정(투사체 포함)이 닿으면 극한 회피가 발동합니다. 회피 한 번당 한 번만 발동하며, 추가로 공격을 피해도 보상과 회피 반격 기회를 다시 주지 않습니다.

- 회피에 소모한 SP를 돌려받고, MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 슬로우모션이 발동합니다. (슬로우모션 항목 참고)

##### 회피 반격 기회

| 항목 | 규칙 |
| - | - |
| 발생 시점 | 극한 회피가 발동한 순간 |
| 유효 시간 | 발생 시점부터 1초. 회피가 끝나도 남은 시간 동안 유지됩니다. |
| 사용 입력 | 평타 키. 입력 처리는 '평타 키의 처리 순서'를 따릅니다. |

다음 중 하나가 일어나면 기회가 사라집니다.

- 유효 시간이 끝남
- 회피 반격을 사용함
- 이동 외의 행동(회피, 가드, 점프, 스킬, 궁극기, 처형)을 함. 가드 키를 누르고 있어 가드가 저절로 시작된 경우도 포함합니다.
- 넉업, 넉백에 맞음

#### 회피 반격 (DodgeCounter)

| 대미지 배율 | PP 배율 | 피격 반응 | 타겟팅 범위 | 최대 워핑 거리 | 후딜 시작 |
| - | - | - | - | - | - |
| 2.5 | 5.0 | 움찔 | 8.5m | 7.5m | 판정 구간 끝 |

- 순식간에 다가가 베어 냅니다. 방향과 다가가는 거리는 '공통 규칙'을 따릅니다. 짧은 준비 중에도 회전과 접근을 보정하고 판정 직전에 방향을 확정합니다.
- 회전은 공통 회전 속도 제한을 적용하지 않고, 추적 구간이 끝날 때까지 선택한 대상 방향으로 완료합니다. 대상 선택과 타겟팅 범위 이탈 시 추적 중단은 공통 규칙을 따릅니다.
- 시작부터 판정 구간이 끝날 때까지 무적입니다.

### 가드 (Guard)

가드 키를 누르고 있는 동안 공격을 막는 행동입니다.

#### 가드 시작

| 입력 상황 | 처리 |
| - | - |
| 가드 입력이 허용된 상태에서 가드 키를 새로 누름 | 진행 중인 행동을 모션 캔슬하고 즉시 가드를 시작합니다. 허용 상태는 [플레이어 입력](<플레이어 입력.md>)을 따릅니다. |
| 가드 입력이 허용되지 않는 상태에서 가드 키를 누름 | [플레이어 입력](<플레이어 입력.md>)의 '선입력'을 따릅니다. 선입력이 버려진 뒤에도 계속 누르고 있으면 아래 규칙을 따릅니다. |

### 패리

#### 패리 구간

가드를 새로 시작한 순간부터 0.3초 동안을 '패리 구간'이라 합니다. 이 구간에 가드 가능한 공격을 받으면 패리에 성공합니다. 패리 구간 중에 가드 키를 떼면 패리 구간도 즉시 끝납니다.

가드가 시작될 때 패리 구간이 생기는지는 아래 표를 따릅니다.

| 가드가 시작되는 경우 | 패리 구간 |
| - | - |
| 가드 입력이 허용된 상태에서 가드 키를 새로 누르거나 선입력으로 가드를 시작함 (패리 모션의 후딜 포함) | 생김 |
| 가드 키를 누르고 있는 채로 가드 입력이 허용되는 상태가 되어 가드를 시작함 ('가드 시작' 참고) | 생김 |
| 가드 키를 누르고 있는 채로 패리 모션의 후딜이 시작되거나 가드 밀림이 끝나 가드로 돌아옴 | 생기지 않음 |

- 패리에 성공해 패리 모션을 시작하면 기존 패리 구간은 즉시 종료됩니다.
- 설계 의도: 패리 예고([보스 사양](<보스 사양.md>)의 '공격 예고')를 보고 공격이 닿기 전에 가드를 누르면 패리에 성공하도록, 패리 구간을 패리 예고 시간과 같은 길이로 둡니다. SwordWave는 패리 예고가 발사 순간에 끝나므로, 날아오는 검기를 보고 패리합니다.
- 가드 키 연타에 대한 제한은 두지 않습니다.

#### 성공 시 효과

- 패리 성공 시 HP·PP·SP 처리는 [전투 시스템](<전투 시스템.md>)의 '피격 처리 순서'를 따릅니다. PP 감소량은 아래와 같습니다.
- 공격자의 PP를 공격자 MaxPP의 8%만큼 감소시킵니다.
- MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 히트스톱을 적용하고([전투 시스템](<전투 시스템.md>)의 히트스톱을 따릅니다), 패리 전용 VFX를 재생합니다.

### 처형 (Execution)

그로기 상태의 보스에게 사용하는 마무리 공격입니다.

- 발동 조건: 아래를 모두 만족해야 합니다.
  1. 보스가 그로기 상태이고, 이번 그로기에서 아직 처형을 쓰지 않았습니다.
  2. 보스가 처형 타겟팅 범위 안에 있습니다. 이 범위는 플레이어와 보스의 캡슐 중심 사이 수평 거리 3m 이내입니다.
  3. 플레이어가 처형을 입력할 수 있는 상태입니다. ([플레이어 입력](<플레이어 입력.md>)에서 처형 입력이 허용됨)
- 발동 조건을 만족할 때 처형 키를 누르면 처형을 사용합니다. 조건을 만족하지 않으면 처형 키를 눌러도 아무 일도 일어나지 않습니다. 처형 안내 표시는 [전투 HUD](<전투 HUD.md>)를 따릅니다.
- 처형을 시작하면 보스가 플레이어를 바라보도록 돌립니다. 플레이어는 처형 모션을 재생하며 찌르기 전까지 보스 정면으로 다가가 붙습니다. 보스는 그로기 자세에서 처형 모션과 짝을 이루는 처형 피격 모션으로 넘어갑니다.
- 처형 모션은 칼로 보스를 찌른 채 버티다가, 발차기로 보스를 걷어차 칼을 뽑습니다.
- 처형 모션은 무게감이 느껴지도록 0.6배속으로 재생합니다. 보스의 처형 피격·처형 사망 모션도 같은 속도로 재생해 두 모션이 맞물립니다.

| 대미지 배율 | PP 배율 | 피격 반응 |
| - | - | - |
| 찌르기 1.5, 마지막 일격(발차기로 칼을 뽑음) 4.5 | 0 | 없음 |

![처형 모션](<Attachments/플레이어 모션 처형.gif>)

모션: `ARPG_Warrior_Anim_UE_Execute`

- 처형 대미지는 처형 모션의 찌르기와 마지막 일격에서 각각 적용합니다.
- 처형 중 플레이어는 무적입니다.
- 처형에는 후딜이 없어, 처형 모션이 끝날 때까지 모션 캔슬할 수 없습니다.
- 플레이어의 처형 종료와 관계없이, 보스의 그로기 종료는 [전투 시스템](<전투 시스템.md>)의 '그로기' 규칙을 따릅니다. 처형 대미지로 보스의 HP가 0 이하가 되면 보스 사망 연출로 이어집니다.

## 전투 연출

### 슬로우모션

극한 회피에 성공한 순간과 적이 궁극기 마무리에 맞는 순간을 강조하는 연출로, 게임 전체를 잠깐 느리게 합니다.

| 발동 | 속도 | 지속 시간 |
| - | - | - |
| 극한 회피 성공 | 0.3배 | 실제 시간 0.3초 |
| 궁극기 마무리 적중 | 0.3배 | 실제 시간 0.8초 |

- 대상은 게임 전체입니다. (카메라 셰이크 포함)
- 지속 시간이 끝나면 바로 원래 속도로 돌아갑니다. 쿨다운은 없습니다.
- 슬로우모션 중에 다시 발동하면 새로 발동한 슬로우모션의 속도와 지속 시간으로 처음부터 다시 셉니다.

## 피격과 사망

### 피격

- 무적이 적용되는 구간은 각 행동 항목(회피, 회피 반격, 궁극기, 처형)을 따릅니다.
- 피격 반응별 피격 모션은 [전투 시스템](<전투 시스템.md>)을 따릅니다.
- 넉업의 식별자는 `KnockUp`, 넉백의 식별자는 `KnockBack`입니다.

![넉업 모션](<Attachments/플레이어 모션 넉업.gif>)

![넉백 모션](<Attachments/플레이어 모션 넉백.gif>)

모션: 넉업 `ARPG_Samurai_Anim_UE_Hit_Air_Up` → `ARPG_Samurai_Anim_UE_Hit_Air_Down` → `ARPG_Samurai_Anim_UE_Hit_knockdown2` → `ARPG_Samurai_Anim_UE_Getup2_Idle1`, 넉백 `ARPG_Samurai_Anim_UE_Hit_knockdown`

### 사망 (Death)

- HP가 0 이하가 되면 [전투 시스템](<전투 시스템.md>)의 사망 처리를 따릅니다.
- 사망 연출은 3초입니다. 종료 후 결과 UI 처리는 [게임 플로우](<게임 플로우.md>)를 따릅니다.
- 이미 결과가 정해진 뒤에 사망한 경우는 [게임 플로우](<게임 플로우.md>)의 Boss Stage를 따릅니다.
