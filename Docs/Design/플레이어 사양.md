# 플레이어 사양

플레이어가 조작하는 캐릭터의 스탯, 조작, 행동 규칙을 정의합니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<전투 시스템.md>) 문서를 따릅니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

> 구현 우선순위: 🔴 S / 🟡 A / 🟢 B (기준은 [마일스톤1 계획](<마일스톤1 계획.md>) 참고)

## 개요

| 항목 | 내용 |
| - | - |
| 시점 | 3인칭 |
| 무기 | 카타나 |
| 핵심 플레이 | 보스의 공격을 패리와 회피로 받아 내고, 생긴 빈틈에 콤보와 스킬을 넣어 보스의 PP를 깎습니다. |
| 리소스 | [마일스톤1 계획](<마일스톤1 계획.md>)의 아트 리소스를 따릅니다. |

## 스탯

| 스탯 | 초기값 | 비고 |
| - | - | - |
| HP / MaxHP | 1000 / 1000 | |
| SP / MaxSP | 100 / 100 | |
| MP / MaxMP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| UP / MaxUP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| PP / MaxPP | 무한 | PP가 감소하지 않으므로 그로기에 빠지지 않습니다. |
| ATK | 100 | |
| DEF | 50 | |
| MOV | 400 | 단위 cm/s. 기본 이동 속도 |

### 자원 회복

| 스탯 | 회복 규칙 |
| - | - |
| HP | 회복하지 않습니다. |
| SP | 마지막으로 SP를 소모하고 1초 뒤부터 초당 40 회복합니다. 가드 중에는 초당 20 회복합니다. SP가 0이 되면 리젠 대기 시간이 1.5초로 늘어납니다. |
| MP | 자연 회복하지 않습니다. 아래 'MP 충전' 표의 행동으로 충전합니다. |
| UP | 자연 회복하지 않습니다. 아래 'UP 충전' 표의 행동으로 충전합니다. |

### MP 충전

| 행동 | 충전량 |
| - | - |
| 평타 적중 (1타당) | +4 |
| 회피 반격 적중 | +8 |
| 극한 회피 성공 | +10 |
| 패리 성공 | +15 |

- 스킬, 궁극기, 처형의 적중으로는 MP를 충전하지 않습니다.

### UP 충전

| 행동 | 충전량 |
| - | - |
| 스킬 적중 | +10 |
| 평타 4타(마지막 타) 적중 | +4 |
| 패리 성공 | +4 |
| 극한 회피 성공 | +6 |

- 그 밖의 행동(평타 1 ~ 3타, 회피 반격, 궁극기, 처형 등)으로는 UP를 충전하지 않습니다.

### SP 소모

| 행동 | 소모량 |
| - | - |
| 회피 | 20 |
| 달리기 | 초당 12 |
| 가드로 막은 공격 | 가드 경감 배율 적용 전 HP 감소량의 25% |

- 점프, 평타, 스킬은 SP를 소모하지 않습니다.
- 회피와 달리기는 SP가 0보다 크면 소모량보다 적어도 사용할 수 있습니다.
- 가드로 공격을 막을 때 SP가 부족하면 가드 브레이크가 발생합니다. (가드 항목 참고)

## 조작

지원하는 조작 장치는 [게임 개요](<게임 개요.md>)를 따릅니다. 아래는 키보드·마우스 기준의 키 배치입니다.

| 행동 | 키 | 설명 |
| - | - | - |
| 이동 | W, A, S, D | |
| 시야 | 마우스 이동 | |
| 평타 | 마우스 왼쪽 버튼 | 사용하는 행동은 '평타 키의 처리 순서'를 따릅니다. |
| 가드 / 패리 | 마우스 오른쪽 버튼 (누르고 있기) | 누른 직후 패리 구간 ('패리' 참고) |
| 회피 / 달리기 | Left Shift | 누르면 회피하고, 회피 후에도 계속 누르고 있으면 달리기 |
| 점프 | Space | |
| 스킬 | E | |
| 궁극기 | R | |
| 처형 | F | |
| 락온 / 락온 해제 | 마우스 휠 클릭 | |

- 각 행동의 구현 우선순위는 그 행동을 정의한 항목을 따릅니다. 시야는 [카메라](<카메라.md>)의 자유 시점을 따릅니다.

## 이동

| 상태 | 속도 | 캐릭터 방향 |
| - | - | - |
| 기본 이동 | MOV | 락온하지 않았을 때는 이동 방향을 바라봅니다. 락온 중에는 대상을 바라보며 이동합니다. |
| 달리기 | MOV × 1.5 | 락온 여부와 관계없이 이동 방향을 바라봅니다. |
| 가드 중 | 이동할 수 없습니다. | 락온 중에는 대상을, 아닐 때는 카메라 정면을 바라봅니다. |

### 달리기 (🟡 A)

- 회피 모션이 끝나는 순간 Shift를 누르고 있고 이동 입력이 있으면 달리기로 전환됩니다. 가드 키를 누르고 있을 때는 '가드'를 따릅니다.
- Shift를 떼거나, 이동 입력이 없어지거나, SP가 0이 되면 기본 이동으로 돌아갑니다.
- 다시 달리려면 Shift를 새로 눌러 회피부터 시작해야 합니다.

## 락온

카메라 규칙은 [카메라](<카메라.md>) 문서를 따릅니다.

- 락온 타겟팅 범위: 플레이어로부터 20m 이내입니다.
- 락온 대상: 락온 타겟팅 범위 안에 있고 화면 안에 있는 생존한 보스입니다. 적은 보스 1명이므로 대상 전환 기능은 없습니다.
- 락온 해제 조건: 락온 키 재입력, 대상이 플레이어로부터 30m 밖으로 벗어남, 대상 사망.
- 락온 중 캐릭터의 방향은 '이동' 항목을, 카메라의 움직임은 [카메라](<카메라.md>)의 '락온 카메라'를 따릅니다.
- 락온 마커 표시는 [전투 HUD](<전투 HUD.md>) 문서를 따릅니다.

## 전투 행동

이 문서의 모션 그림은 모션의 주요 프레임을 순서대로 보여 줍니다.

- 테두리가 있는 칸은 타격 순간입니다. 패리는 공격을 쳐 내는 순간입니다.
- 타격 칸의 선은 타격 직전에 칼끝이 지나간 길입니다.
- 그림 속 시간은 참고 값입니다. 여러 모션을 잇는 그림은 [Samurai 애니메이션 조사](<../Art/Samurai 애니메이션 조사.md>)의 연결 시점에서 이은 시간입니다.
- 카타나 위치는 [Samurai 애니메이션 조사](<../Art/Samurai 애니메이션 조사.md>)의 추정값입니다.
- 칸 아래쪽 글은 그 순간의 판정 정보입니다.

### 공통 규칙

- 구간별 허용 입력은 '입력과 모션 캔슬'을 따르며, 무적 등 다른 규칙은 각 행동 항목을 따릅니다.

#### 공격 방향

평타, 회피 반격, 스킬, 궁극기는 각 타를 시작할 때 아래 순서로 공격 방향을 정합니다.

| 순서 | 조건 | 공격 방향 |
| - | - | - |
| 1 | 보스가 타겟팅 범위 안에 있음 | 락온 여부와 관계없이 보스 방향 |
| 2 | 락온 중 | 락온 대상 방향 |
| 3 | 그 밖의 경우 | 캐릭터 정면 |

- 타겟팅 범위는 각 행동 항목에서 정하며, 평타는 타마다 정합니다.
- 공격 보정 대상이 있으면 이후의 방향 갱신과 고정 시점은 아래 '공격 중 이동'을 따릅니다.

#### 공격 중 이동

평타, 회피 반격, 스킬, 궁극기에 적용합니다. 아래에서 '대상과의 간격'은 플레이어와 보스의 캡슐 중심 사이 수평 거리입니다.

- 각 타를 시작할 때 타겟팅 범위 안에 있는 보스를 대상으로 정합니다. 대상과 1m 간격을 두는 위치를 접근 목표로 삼고, 모션이 정한 이동 거리와 관계없이 선딜 동안 그 지점까지 다가갑니다. 이미 이보다 가까우면 더 다가가지 않습니다.
- 선딜 동안 대상의 위치에 맞춰 캐릭터가 바라보는 방향과 접근 목표를 함께 갱신하고, 해당 타의 판정 구간이 시작되면 둘 다 고정합니다.
- 접근은 수평으로만 합니다. 선딜 중 대상이 해당 타의 타겟팅 범위를 벗어나면 그 타의 추적과 접근을 멈추고, 마지막 방향으로 공격을 계속합니다.
- 타겟팅 범위 안에 보스가 없으면 위 '공격 방향'으로 모션이 정한 거리만큼 이동합니다. 이동 중 보스와의 간격이 위 기준에 도달하면 멈춥니다.

#### 쿨다운

- 행동을 시작한 순간부터 셉니다. 쿨다운 중에는 그 행동을 입력해도 발동하지 않습니다.
- 보스전이 시작될 때는 모든 쿨다운이 끝난 상태입니다.
- 쿨다운 값은 각 행동 항목을 따르며, 적혀 있지 않은 행동은 쿨다운이 없습니다.

### 평타 (🔴 S)

평타 키를 연속으로 입력하면 최대 4타까지 이어지는 콤보입니다.

| 타 | 대미지 배율 | PP 배율 | 피격 반응 | 타겟팅 범위 |
| - | - | - | - | - |
| 1 | 1.0 | 1.0 | 움찔 | 4m |
| 2 | 1.0 | 1.0 | 움찔 | 4.5m |
| 3 | 1.2 | 1.2 | 움찔 | 5m |
| 4 | 1.6 | 2.4 | 움찔 | 5m |

![평타 모션](<Attachments/플레이어 모션 평타.jpg>)

모션: `ARPG_Samurai_Anim_UE_Attack_Combo1` → `ARPG_Samurai_Anim_UE_Attack_Combo2` → `ARPG_Samurai_Anim_UE_Attack_Combo3` → `ARPG_Samurai_Anim_UE_Attack_Combo4`

- 후딜이 끝날 때까지 입력이 없으면 콤보가 초기화됩니다.
- 회피, 가드, 점프, 스킬, 궁극기, 처형으로 평타를 모션 캔슬하거나 넉백, 다운에 맞으면 콤보가 초기화됩니다. 움찔은 콤보를 끊지 않습니다.

#### 평타 키의 처리 순서

평타 키를 누르면 아래 순서로 검사해 처음 맞는 행동 하나를 사용합니다.

| 순서 | 조건 | 사용하는 행동 |
| - | - | - |
| 1 | 회피 반격 기회가 남아 있음 ('극한 회피' 참고) | 회피 반격 |
| 2 | 평타 후딜 중 | 다음 타 (4타 다음은 1타) |
| 3 | 그 밖의 경우 | 1타 |

### 점프 (🟢 B)

| 항목 | 값 |
| - | - |
| 점프 높이·체공 시간 | 최고 높이 약 0.9m, 체공 시간 약 0.86초 |
| 공중 이동 | 공중에서는 방향을 거의 바꿀 수 없습니다. |

- 점프에는 무적 구간이 없습니다.
- 공중에서 허용되는 입력은 '입력과 모션 캔슬'의 '상태별 허용 입력'을 따릅니다.
- 달리는 중에 점프하면 달리기 속도를 유지한 채 점프합니다. 공중에서도 달리기가 이어져 SP를 소모하며, 착지했을 때 Shift와 이동 입력이 그대로 있으면 계속 달립니다.

### 회피 (🔴 S)

| 항목 | 값 |
| - | - |
| 발동 | Shift를 누르는 순간 |
| 방향 | 락온 여부와 관계없이 이동 입력 방향(카메라 기준)으로 구릅니다. 입력이 없으면 캐릭터 기준 후방으로 뛰어 물러납니다. |
| 무적 구간 | 시작 후 0초 ~ 0.3초 |
| 극한 회피 구간 | 시작 후 0초 ~ 0.15초 |
| 후딜 시작 | 구를 때는 시작 후 0.6초, 뒤로 물러날 때는 시작 후 0.4초 |
| 쿨다운 | 0.4초 |

![회피 모션](<Attachments/플레이어 모션 회피.jpg>)

모션: 구르기 `ARPG_Samurai_Anim_UE_Evade_Forward` (8방향 `ARPG_Samurai_Anim_UE_Evade_*` 중 앞), 뒤로 물러나기 `ARPG_Samurai_Anim_UE_Dodge`

- 가드 불가 공격도 회피 무적으로 피할 수 있습니다.

#### 극한 회피 (🔴 S)

극한 회피 구간에 보스의 공격 판정(투사체 포함)이 닿으면 극한 회피가 발동합니다. 회피 한 번당 한 번만 발동하며, 추가로 공격을 피해도 보상과 회피 반격 기회를 다시 주지 않습니다.

- 회피에 소모한 SP를 돌려받고, MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 슬로우모션이 발동합니다. (슬로우모션 항목 참고)

##### 회피 반격 기회

| 항목 | 규칙 |
| - | - |
| 발생 시점 | 극한 회피가 발동한 순간 |
| 유효 시간 | 발생 시점부터 1초. 회피가 끝나도 남은 시간 동안 유지됩니다. |
| 사용 입력 | 평타 키. 입력 처리는 '평타 키의 처리 순서'를 따릅니다. |

다음 중 하나가 일어나면 기회가 사라집니다.

- 유효 시간이 끝남
- 회피 반격을 사용함
- 이동 외의 행동(회피, 가드, 점프, 스킬, 궁극기, 처형)을 함. 가드 키를 누르고 있어 가드가 저절로 시작된 경우도 포함합니다.
- 넉백, 다운에 맞음

#### 회피 반격 (🟡 A)

| 대미지 배율 | PP 배율 | 피격 반응 | 타겟팅 범위 |
| - | - | - | - |
| 2.5 | 5.0 | 움찔 | 8m |

![회피 반격 모션](<Attachments/플레이어 모션 회피 반격.jpg>)

모션: `ARPG_Samurai_Anim_UE_Attack_Heavy1`

- 순식간에 다가가 베어 냅니다. 방향과 다가가는 거리는 '공통 규칙'을 따릅니다.
- 시작부터 판정 구간이 끝날 때까지 무적입니다.

### 가드 (🔴 S)

가드 키를 누르고 있는 동안 공격을 막는 행동입니다.

#### 가드 시작

| 입력 상황 | 처리 |
| - | - |
| 가드 입력이 허용된 상태에서 가드 키를 새로 누름 | 진행 중인 행동을 모션 캔슬하고 즉시 가드를 시작합니다. 허용 상태는 '입력과 모션 캔슬'을 따릅니다. |
| 가드 입력이 허용되지 않는 상태에서 가드 키를 누름 | 진행 중인 행동을 모션 캔슬하지 않습니다. 계속 누르고 있으면 아래 규칙을 따릅니다. |
| 가드 키를 누른 채 행동이나 피격 모션이 끝나 대기 또는 이동 상태가 됨 | 즉시 가드를 시작합니다. |

- 가드 키를 누르고 있는 도중 가드 입력이 허용되는 구간에 들어서더라도, 그것만으로 진행 중인 행동을 모션 캔슬하지 않습니다.
- 회피가 끝날 때 가드 키와 Shift를 함께 누르고 있으면 가드를 시작하며, 달리기로 이어지지 않습니다.
- 가드가 시작될 때 패리 구간이 생기는지는 '패리'의 표를 따릅니다.

#### 가드 유지와 해제

| 상황 | 처리 |
| - | - |
| 가드 키를 누르고 있음 | 가드를 유지합니다. |
| 가드 키를 뗌 | 가드를 해제합니다. 단, 가드 밀림 중에는 모션이 끝날 때까지 가드를 유지합니다. |
| 가드 중 다른 행동을 입력함 | '입력과 모션 캔슬'을 따릅니다. |

- 가드 중에는 이동할 수 없습니다. 캐릭터 방향은 '이동'을 따릅니다.
- 패리 모션 중과 종료 후의 가드 처리는 '패리'를 따릅니다.

#### 공격을 받았을 때

- 가드 불가 공격을 포함한 피격 판정과 HP·PP·SP 처리는 [전투 시스템](<전투 시스템.md>)의 '피격 처리 순서'를 따릅니다. 가드 SP 소모량은 'SP 소모'를 따릅니다.
- 가드 반응은 [전투 시스템](<전투 시스템.md>)의 '가드 반응'을 따릅니다.
- 가드 브레이크가 발생했을 때의 행동은 아래 '가드 브레이크'를 따릅니다.

![가드, 가드 밀림, 가드 브레이크 모션](<Attachments/플레이어 모션 가드.jpg>)

모션: 가드 `ARPG_Samurai_Anim_UE_Guard_Start` → `ARPG_Samurai_Anim_UE_Guard` (반복), 가드 밀림 `ARPG_Samurai_Anim_UE_Guard_Hit2`, 가드 브레이크 `ARPG_Samurai_Anim_UE_Guard_Break`

#### 가드 브레이크

발생 조건과 HP·PP·SP 처리는 [전투 시스템](<전투 시스템.md>)의 '피격 처리 순서'를 따릅니다.

- 가드가 강제로 해제되고 가드 브레이크 모션을 재생합니다.
- 모션 중의 입력 제한은 '입력과 모션 캔슬'을, 모션 종료 후 가드 키를 누르고 있을 때의 처리는 '가드 시작'을 따릅니다.

### 패리 (🔴 S)

#### 패리 구간

가드를 새로 시작한 순간부터 0.3초 동안을 '패리 구간'이라 합니다. 이 구간에 패리 가능한 공격을 받으면 패리에 성공합니다. 패리 구간 중에 가드 키를 떼면 패리 구간도 즉시 끝납니다.

가드가 시작될 때 패리 구간이 생기는지는 아래 표를 따릅니다.

| 가드가 시작되는 경우 | 패리 구간 |
| - | - |
| 가드 입력이 허용된 상태에서 가드 키를 새로 누름 (패리 모션의 후딜 포함) | 생김 |
| 가드 키를 누르고 있는 채로 행동이 끝나 가드를 시작함 ('가드' 참고) | 생김 |
| 가드 키를 누르고 있는 채로 패리 모션이나 가드 밀림이 끝나 가드로 돌아옴 | 생기지 않음 |

- 패리에 성공해 패리 모션을 시작하면 기존 패리 구간은 즉시 종료됩니다.
- 설계 의도: 예고 섬광([보스 사양](<보스 사양.md>)의 '공격 속성과 예고')을 보고 공격이 닿기 전에 가드를 누르면 패리에 성공하도록, 패리 구간을 예고 섬광 시간과 같은 길이로 둡니다.
- 가드 키 연타에 대한 제한은 두지 않습니다.

#### 성공 시 효과

- 패리 성공 시 HP·PP·SP 처리는 [전투 시스템](<전투 시스템.md>)의 '피격 처리 순서'를 따릅니다. PP 감소량은 아래와 같습니다.
- 공격자의 PP를 공격자 MaxPP의 8%만큼 감소시킵니다.
- MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 히트스톱을 적용하고([전투 시스템](<전투 시스템.md>)의 히트스톱을 따릅니다), 패리 전용 이펙트(🟢 B)를 재생합니다.
- 슬로우모션이 발동합니다. (슬로우모션 항목 참고)

#### 패리 모션 중·종료 후

| 상황 | 가드 키를 누르고 있음 | 가드 키를 떼었음 |
| - | - | - |
| 모션 중 공격을 받음 | '가드 → 공격을 받았을 때'를 따름 | 일반 피격 |
| 모션이 끝남 | 가드 상태로 돌아감 | 대기 상태로 돌아감 |

- 패리 모션 중의 입력은 '입력과 모션 캔슬'을 따릅니다.
- 패리 모션의 후딜은 공격을 쳐내는 동작을 마친 뒤 자세를 되돌리는 구간입니다.

### 처형 (🔴 S)

그로기 상태의 보스에게 사용하는 마무리 공격입니다.

- 발동 조건: 아래를 모두 만족해야 합니다.
  1. 보스가 그로기 상태이고, 이번 그로기에서 아직 처형을 쓰지 않았습니다.
  2. 보스가 처형 타겟팅 범위 안에 있습니다. 이 범위는 플레이어와 보스의 캡슐 중심 사이 수평 거리 3m 이내입니다.
  3. 플레이어가 처형을 입력할 수 있는 상태입니다. ('입력과 모션 캔슬'에서 처형 입력이 허용됨)
- 발동 조건을 만족할 때 처형 키를 누르면 처형을 사용합니다. 조건을 만족하지 않으면 처형 키를 눌러도 아무 일도 일어나지 않습니다. 처형 안내 표시는 [전투 HUD](<전투 HUD.md>)를 따릅니다.
- 처형을 시작하면 보스가 플레이어를 바라보도록 돌립니다. 플레이어는 처형 모션을 재생하며 보스 정면으로 다가가 붙고, 보스는 처형 피격 모션을 재생합니다.

| 대미지 배율 | PP 배율 | 피격 반응 |
| - | - | - |
| 15.0 | 0 | 없음 |

![처형 모션](<Attachments/플레이어 모션 처형.jpg>)

모션: `ARPG_Samurai_Anim_UE_Execute`

- 처형 대미지는 처형 모션의 마지막 일격에서 한 번 적용합니다.
- 처형 중 플레이어는 무적입니다.
- 처형의 후딜은 마지막 일격을 마친 뒤의 구간입니다. 모션 캔슬하면 플레이어의 처형과 처형 무적은 끝나지만, 보스의 처형 피격·사망 모션은 계속 재생합니다.
- 플레이어의 처형 종료나 모션 캔슬과 관계없이, 보스의 그로기 종료는 [전투 시스템](<전투 시스템.md>)의 '그로기' 규칙을 따릅니다. 처형 대미지로 보스의 HP가 0 이하가 되면 보스 사망 연출로 이어집니다.

### 슬로우모션 (🟡 A)

극한 회피나 패리에 성공한 순간을 강조하는 연출로, 게임 전체를 아주 잠깐 느리게 합니다.

| 항목 | 값 |

| 발동 | 극한 회피 성공, 패리 성공 |

| 속도 | 0.3배 |
| 지속 시간 | 실제 시간 0.3초. 끝나면 바로 원래 속도로 돌아갑니다. |
| 쿨다운 | 없음 |

- 패리로 발동하면 패리 히트스톱이 끝난 직후에 시작합니다.
- 슬로우모션 중에 다시 발동하면 지속 시간을 처음부터 다시 셉니다.

## 피격과 사망

### 피격

- 플레이어에게는 슈퍼아머가 없어 넉백, 다운을 모두 받습니다. 무적이 적용되는 구간은 각 행동 항목(회피, 회피 반격, 궁극기, 처형)을 따릅니다.
- 피격 반응별 피격 모션은 [전투 시스템](<전투 시스템.md>)을 따릅니다. 공중에서 넉백, 다운에 맞으면 해당 피격 모션을 재생하며 떨어집니다. 움찔은 점프를 끊지 않습니다.

![넉백과 다운 모션](<Attachments/플레이어 모션 피격.jpg>)

모션: 넉백 `ARPG_Samurai_Anim_UE_Hit3`, 다운 `ARPG_Samurai_Anim_UE_Death` → `ARPG_Samurai_Anim_UE_Getup2_Idle1`

### 사망

- HP가 0 이하가 되면 [전투 시스템](<전투 시스템.md>)의 사망 처리를 따릅니다.
- 사망 연출은 3초입니다. 종료 후 결과 UI 처리는 [게임 플로우](<게임 플로우.md>)를 따릅니다.
- 이미 결과가 정해진 뒤에 사망한 경우는 [게임 플로우](<게임 플로우.md>)의 Boss Stage를 따릅니다.

## 입력과 모션 캔슬

상태별로 사용할 수 있는 입력과, 진행 중인 모션을 다른 행동으로 캔슬할 수 있는 시점을 정합니다.

### 공통 입력 처리

- 표는 이동, 평타, 처형, 가드, 회피, 점프, 스킬, 궁극기 입력을 다룹니다. 이 중 '허용 입력'에 없는 입력은 무시합니다. '없음'이면 이 입력들을 모두 무시합니다.
- 락온 키는 이 표의 제한을 받지 않으며, 사망 전까지 언제든 입력할 수 있습니다.
- 허용된 입력은 해당 행동의 자원, 쿨다운, 발동 조건을 만족하면 즉시 실행합니다.
- 평타 입력으로 어떤 행동을 사용하는지는 '평타 키의 처리 순서'를, 처형 입력은 '처형'의 발동 조건을 따릅니다.
- 가드 키를 누르고 있거나 떼었을 때의 처리는 '가드'를 따릅니다.

### 상태별 허용 입력

피격과 사망으로 인한 행동 중단 및 입력 제한은 [전투 시스템](<전투 시스템.md>)을 따르며, 아래 표에도 함께 표시합니다.

| 현재 상태 | 구간·조건 | 허용 입력 |
| - | - | - |
| 대기, 이동, 달리기 | 전체 | 이동, 평타, 처형, 가드, 회피, 점프, 스킬, 궁극기 |
| 가드 | 전체 | 평타, 처형, 회피, 점프, 스킬, 궁극기 |
| 평타, 스킬, 궁극기, 회피 반격, 처형, 패리 모션, 회피 | 후딜 전 | 없음 |
| 평타, 스킬, 궁극기, 회피 반격, 처형, 패리 모션, 회피 | 후딜 | 평타, 처형, 가드, 회피, 점프, 스킬, 궁극기 |
| 공중 | 전체 | 이동 (공중 이동) |
| 넉백, 다운, 가드 밀림, 가드 브레이크 | 전체 | 없음 |
| 사망 | 전체 | 없음 |

### 모션 캔슬

평타, 스킬, 궁극기, 회피 반격, 처형, 패리 모션, 회피에 적용합니다.

- 후딜부터 허용된 행동을 입력해 진행 중인 모션을 캔슬할 수 있습니다. 후딜이 따로 정해지지 않은 행동은 모션이 끝난 뒤에만 다른 행동을 시작할 수 있습니다.
- 연속 공격의 후딜은 마지막 타의 판정 구간이 끝난 뒤입니다. 평타는 각 타를 별도 행동으로 보므로, 타마다 후딜에서 전환할 수 있습니다.
- 이동 입력은 모션 캔슬을 일으키지 않습니다. 위 행동 중에는 후딜에도 이동 키로 캐릭터를 움직일 수 없습니다. 모션이 끝났을 때 이동 키를 누르고 있으면 이동합니다.
