# 플레이어 사양

플레이어가 조작하는 캐릭터의 스탯, 조작, 행동 규칙을 정의합니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<전투 시스템.md>) 문서를 따릅니다.

용어는 [용어집](<용어집.md>)을 따릅니다.

> 구현 우선순위: 🔴 S / 🟡 A / 🟢 B (기준은 [마일스톤1 계획](<마일스톤1 계획.md>) 참고)

## 개요

| 항목 | 내용 |
| - | - |
| 시점 | 3인칭 |
| 무기 | 카타나 |
| 핵심 플레이 | 보스의 공격을 패리와 회피로 받아 내고, 생긴 빈틈에 콤보와 스킬을 넣어 보스의 PP를 깎습니다. |
| 리소스 | [마일스톤1 계획](<마일스톤1 계획.md>)의 아트 리소스를 따릅니다. |

## 스탯

| 스탯 | 초기값 | 비고 |
| - | - | - |
| HP / MaxHP | 1000 / 1000 | |
| SP / MaxSP | 100 / 100 | |
| MP / MaxMP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| UP / MaxUP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| PP / MaxPP | 무한 | PP가 감소하지 않으므로 그로기에 빠지지 않습니다. |
| ATK | 100 | |
| DEF | 50 | |
| MOV | 400 | 단위 cm/s. 기본 이동 속도 |

### 자원 회복

| 스탯 | 회복 규칙 |
| - | - |
| HP | 회복하지 않습니다. |
| SP | 마지막으로 SP를 소모하고 1초 뒤부터 초당 40 회복합니다. 가드 중에는 초당 20 회복합니다. SP가 0이 되면 리젠 대기 시간이 1.5초로 늘어납니다. |
| MP | 자연 회복하지 않습니다. 아래 'MP 충전' 표의 행동으로 충전합니다. |
| UP | 자연 회복하지 않습니다. 아래 'UP 충전' 표의 행동으로 충전합니다. |

### MP 충전

| 행동 | 충전량 |
| - | - |
| 평타 적중 (1타당) | +4 |
| 회피 반격 적중 | +8 |
| 극한 회피 성공 | +10 |
| 패리 성공 | +15 |

- 스킬, 궁극기, 처형의 적중으로는 MP를 충전하지 않습니다.

### UP 충전

| 행동 | 충전량 |
| - | - |
| 스킬 적중 | +10 |
| 평타 4타(마지막 타) 적중 | +4 |
| 패리 성공 | +4 |
| 극한 회피 성공 | +6 |

- 그 밖의 행동(평타 1 ~ 3타, 회피 반격, 궁극기, 처형 등)으로는 UP를 충전하지 않습니다.

### SP 소모

| 행동 | 소모량 |
| - | - |
| 회피 | 20 |
| 달리기 | 초당 12 |
| 가드로 막은 공격 | 가드 경감 배율 적용 전 HP 감소량의 25% |

- 점프, 평타, 스킬은 SP를 소모하지 않습니다.
- 회피와 달리기는 SP가 0보다 크면 소모량보다 적어도 사용할 수 있으며, SP는 0 미만으로 내려가지 않습니다.
- 가드로 공격을 막을 때 SP가 부족하면 가드 브레이크가 발생합니다. (가드 항목 참고)

## 조작

지원하는 조작 장치는 [게임 개요](<게임 개요.md>)를 따릅니다. 아래는 키보드·마우스 기준의 키 배치입니다.

| 행동 | 키 | 설명 |
| - | - | - |
| 이동 | W, A, S, D | |
| 시야 | 마우스 이동 | |
| 평타 | 마우스 왼쪽 버튼 | 연속으로 누르면 콤보로 이어집니다. 극한 회피 직후에는 회피 반격으로 바뀝니다. |
| 가드 / 패리 | 마우스 오른쪽 버튼 (누르고 있기) | 누른 직후 패리 구간 ('패리' 참고) |
| 회피 / 달리기 | Left Shift | 누르면 회피하고, 회피 후에도 계속 누르고 있으면 달리기 |
| 점프 | Space | |
| 스킬 | E | |
| 궁극기 | R | |
| 처형 | F | |
| 락온 / 락온 해제 | 마우스 휠 클릭 | |
| ~~숙이기~~ | ~~C (토글)~~ | |

- 각 행동의 구현 우선순위는 그 행동을 정의한 항목을 따릅니다. 시야는 [카메라](<카메라.md>)의 자유 시점을 따릅니다.
- 취소선을 그은 키는 마일스톤1에서 구현하지 않는 기능입니다. 이 키는 다른 행동에 할당하지 않고 비워 둡니다.

## 이동

| 상태 | 속도 | 캐릭터 방향 |
| - | - | - |
| 기본 이동 | MOV | 락온하지 않았을 때는 이동 방향을 바라봅니다. 락온 중에는 대상을 바라보며 이동합니다. |
| 달리기 | MOV × 1.15 | 락온 여부와 관계없이 이동 방향을 바라봅니다. |
| 가드 중 이동 | MOV × 0.65 | 락온 중에는 대상을, 아닐 때는 카메라 정면을 바라봅니다. |

### 달리기 (🟡 A)

- 회피가 끝나는 순간 Shift를 누르고 있고 이동 입력이 있으면 달리기로 전환됩니다. 회피의 캔슬 가능 시점 이후 이동 입력으로 회피가 캔슬된 경우도 회피가 끝난 것으로 봅니다. 가드 키를 누르고 있을 때는 '가드'를 따릅니다.
- Shift를 떼거나, 이동 입력이 없어지거나, SP가 0이 되면 기본 이동으로 돌아갑니다.
- 다시 달리려면 Shift를 새로 눌러 회피부터 시작해야 합니다.

## 락온

카메라 규칙은 [카메라](<카메라.md>) 문서를 따릅니다.

- 락온 대상: 화면 안에 있고, 플레이어로부터 20m 이내에 있는 생존한 보스입니다. 적은 보스 1명이므로 대상 전환 기능은 없습니다.
- 락온 해제 조건: 락온 키 재입력, 대상이 플레이어로부터 30m 밖으로 벗어남, 대상 사망.
- 락온 중 캐릭터의 방향은 '이동' 항목을, 카메라의 움직임은 [카메라](<카메라.md>)의 '락온 카메라'를 따릅니다.
- 락온 마커 표시는 [전투 HUD](<전투 HUD.md>) 문서를 따릅니다.

## 행동

이 문서의 모션 그림은 모션의 주요 프레임을 순서대로 보여 줍니다.

- 테두리가 있는 칸은 타격 순간입니다. 패리는 공격을 쳐 내는 순간입니다.
- 타격 칸의 선은 타격 직전에 칼끝이 지나간 길입니다.
- 그림 속 시간은 참고 값입니다. 여러 모션을 잇는 그림은 [Samurai 애니메이션 조사](<../Art/Samurai 애니메이션 조사.md>)의 연결 시점에서 이은 시간입니다.
- 카타나 위치는 [Samurai 애니메이션 조사](<../Art/Samurai 애니메이션 조사.md>)의 추정값입니다.
- 칸 아래쪽 글은 그 순간의 판정 정보입니다.
- 그림 아래에 그림에 쓴 애니메이션 에셋 이름을 적습니다.

### 공통 규칙

- 모든 공격 모션은 '선딜 → 판정 구간 → 후딜' 3구간으로 나뉩니다. 각 구간에서 가능한 행동은 '행동 가능 표'를 따릅니다.
- 공격 방향 보정: 평타, 회피 반격, 스킬, 궁극기는 시작할 때 아래 순서로 처음 맞는 방향을 향해 즉시 회전한 뒤 발동합니다. 공격 방향 보정 범위는 각 행동 항목에 정하며, 평타는 타마다 정합니다.
  1. 보스가 공격 방향 보정 범위 안에 있으면, 락온하지 않았더라도 보스 방향
  2. 락온 중이면 락온 대상 방향
  3. 그 밖에는 캐릭터 정면
- 평타의 각 타를 시작할 때 보스가 공격 방향 보정 범위 안에 있고 보스와의 캡슐 중심 사이 수평 거리가 1m보다 멀면, 선딜 동안 이 거리가 1m가 될 때까지 최대 2.5m 다가갑니다.
- 평타, 회피 반격, 스킬, 궁극기는 시작할 때 회전한 방향으로 모션이 정한 거리만큼 이동하며, 그 전에 보스와의 캡슐 중심 사이 수평 거리가 1m가 되면 멈춥니다. 단, 회피 반격은 보스가 공격 방향 보정 범위 안에 있으면 모션이 정한 거리와 관계없이 이 거리가 1m가 될 때까지 다가갑니다.
- 쿨다운은 행동을 시작한 순간부터 셉니다. 쿨다운 중에는 그 행동을 입력해도 발동하지 않습니다. 보스전이 시작될 때는 모든 쿨다운이 끝난 상태입니다. 쿨다운 값은 각 항목을 따르며, 적혀 있지 않은 행동은 쿨다운이 없습니다.

### 평타 (🔴 S)

평타 키를 연속으로 입력하면 최대 4타까지 이어지는 콤보입니다.

| 타 | 대미지 배율 | PP 배율 | 피격 반응 | 공격 방향 보정 범위 |
| - | - | - | - | - |
| 1 | 1.0 | 1.0 | 움찔 | 4m |
| 2 | 1.0 | 1.0 | 움찔 | 4.5m |
| 3 | 1.2 | 1.2 | 움찔 | 5m |
| 4 | 1.6 | 2.4 | 움찔 | 5m |

![평타 모션](<Attachments/플레이어 모션 평타.jpg>)

모션: `ARPG_Samurai_Anim_UE_Attack_Combo1` → `ARPG_Samurai_Anim_UE_Attack_Combo2` → `ARPG_Samurai_Anim_UE_Attack_Combo3` → `ARPG_Samurai_Anim_UE_Attack_Combo4`

- 후딜이 끝날 때까지 입력이 없으면 콤보가 초기화됩니다.
- 회피, 가드, 점프, 스킬, 궁극기, 처형을 사용하거나 넉백, 다운에 맞으면 콤보가 초기화됩니다. 움찔은 콤보를 끊지 않습니다.

#### 평타 키의 처리 순서

평타 키를 누르면 아래 순서로 검사해 처음 맞는 행동 하나를 사용합니다. 평타 키는 행동 가능 표에서 평타·처형이 O인 상태에서만 처리하며, X인 상태에서는 무시합니다.

| 순서 | 조건 | 사용하는 행동 |
| - | - | - |
| 1 | 회피 반격 기회가 남아 있음 ('극한 회피' 참고) | 회피 반격 |
| 2 | 평타 후딜 중 | 다음 타 (4타 다음은 1타) |
| 3 | 그 밖의 경우 | 1타 |

### 점프 (🟢 B)

| 항목 | 값 |
| - | - |
| 점프 높이·체공 시간 | 엔진 기본값을 씁니다. (참고: 최고 높이 약 0.9m, 체공 시간 약 0.86초) |
| 공중 이동 | 엔진 기본값을 씁니다. (참고: 공중에서는 방향을 거의 바꿀 수 없습니다.) |

- 점프에는 무적 구간이 없습니다.
- 공중에서는 이동 외의 행동을 할 수 없습니다.
- 달리는 중에 점프하면 달리기 속도를 유지한 채 점프합니다. 공중에서도 달리기가 이어져 SP를 소모하며, 착지했을 때 Shift와 이동 입력이 그대로 있으면 계속 달립니다.

### 회피 (🔴 S)

| 항목 | 값 |
| - | - |
| 발동 | Shift를 누르는 순간 |
| 방향 | 이동 입력 방향(카메라 기준)으로 구릅니다. 입력이 없으면 캐릭터 기준 후방으로 뛰어 물러납니다. |
| 무적 구간 | 시작 후 0초 ~ 0.3초 |
| 극한 회피 구간 | 시작 후 0초 ~ 0.15초 |
| 캔슬 가능 시점 | 구를 때는 시작 후 0.6초, 뒤로 물러날 때는 시작 후 0.4초 |
| 쿨다운 | 0.4초 |

![회피 모션](<Attachments/플레이어 모션 회피.jpg>)

모션: 구르기 `ARPG_Samurai_Anim_UE_Evade_Forward` (8방향 `ARPG_Samurai_Anim_UE_Evade_*` 중 앞), 뒤로 물러나기 `ARPG_Samurai_Anim_UE_Dodge`

- 가드 불가 공격도 회피 무적으로 피할 수 있습니다.
- 회피는 락온 여부와 관계없이 입력 방향으로 이동합니다.
- 캔슬 가능 시점 전에는 극한 회피 후의 회피 반격과 처형 말고는 다른 행동으로 캔슬할 수 없고, 이후에는 모든 행동으로 캔슬할 수 있습니다. 자세한 입력 처리는 '행동 가능 표'를 따릅니다.

#### 극한 회피 (🔴 S)

극한 회피 구간에 보스의 공격 판정(투사체 포함)이 닿으면 극한 회피가 발동합니다.

- 회피에 소모한 SP를 돌려받고, MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 화면 효과를 재생합니다. ([전투 HUD](<전투 HUD.md>) 참고)
- 슬로우모션이 발동합니다. (슬로우모션 항목 참고)
- 극한 회피가 발동한 순간부터 1초 동안 회피 반격 기회가 생기며, 이 동안 평타 키를 누르면 회피 반격을 사용합니다. ('평타 키의 처리 순서' 참고) 회피 반격 기회는 회피가 끝난 뒤에도 남아 있으며, 아래 중 하나가 일어나면 사라집니다.
  - 1초가 지남
  - 회피 반격을 사용함
  - 이동 외의 행동(회피, 가드, 점프, 스킬, 궁극기, 처형)을 함. 가드 키를 누르고 있어 가드가 저절로 시작된 경우도 포함합니다.
  - 넉백, 다운에 맞음

#### 회피 반격 (🟡 A)

| 대미지 배율 | PP 배율 | 피격 반응 | 공격 방향 보정 범위 |
| - | - | - | - |
| 2.5 | 5.0 | 움찔 | 8m |

![회피 반격 모션](<Attachments/플레이어 모션 회피 반격.jpg>)

모션: `ARPG_Samurai_Anim_UE_Attack_Heavy1`

- 순식간에 다가가 베어 냅니다. 방향과 다가가는 거리는 '공통 규칙'을 따릅니다.
- 시작부터 판정 구간이 끝날 때까지 무적입니다.

### 가드 (🔴 S)

- 가드 키를 누르고 있는 동안 가드를 유지합니다. 가드 키를 누르는 즉시 가드가 적용됩니다. 가드 밀림 중에는 가드 키를 떼어도 모션이 끝날 때까지 가드 자세를 유지합니다.
- 가드 키를 누르고 있는 채로 진행 중인 행동(평타, 회피, 스킬 등)이나 넉백, 다운, 가드 브레이크가 끝나 대기 또는 이동 상태가 되면(회피가 이동 입력으로 캔슬된 경우 포함) 즉시 가드를 시작합니다. 이때는 Shift를 누르고 있어도 달리기로 이어지지 않습니다. 행동이 끝나기 전에는 가드 키를 누르고 있어도 가드를 시작하지 않으므로, 도중에 가드로 바꾸려면 가드가 O인 상태에서 가드 키를 새로 누릅니다. 이때 패리 구간이 생기는지는 '패리'를 따릅니다.
- 가드로 공격을 막으면 HP 감소량에 가드 경감 배율을 적용하고([전투 시스템](<전투 시스템.md>) 참고), SP를 소모하며('SP 소모' 참고), 가드 반응이 적용됩니다.
- 가드 불가 공격은 [전투 시스템](<전투 시스템.md>)의 공격 판정 세부 규칙을 따릅니다.

![가드, 가드 밀림, 가드 브레이크 모션](<Attachments/플레이어 모션 가드.jpg>)

모션: 가드 `ARPG_Samurai_Anim_UE_Guard_Start` → `ARPG_Samurai_Anim_UE_Guard` (반복), 가드 밀림 `ARPG_Samurai_Anim_UE_Guard_Hit2`, 가드 브레이크 `ARPG_Samurai_Anim_UE_Guard_Break`

#### 가드 브레이크

가드로 공격을 막을 때 SP가 소모량보다 적으면 가드 브레이크가 발생합니다.

- SP가 0이 되고 가드가 강제로 해제됩니다.
- HP 감소량에는 가드 경감 배율을 적용합니다.
- 가드 반응 대신 가드 브레이크 모션을 재생하며, 모션이 끝날 때까지 회피를 포함한 모든 행동을 할 수 없습니다.

### 패리 (🔴 S)

가드를 새로 시작한 순간부터 0.2초 동안을 '패리 구간'이라 합니다. 이 구간에 패리 가능한 공격을 받으면 패리에 성공합니다. 패리 구간 중에 가드 키를 떼면 패리 구간도 즉시 끝납니다.

가드가 시작될 때 패리 구간이 생기는지는 아래 표를 따릅니다.

| 가드가 시작되는 경우 | 패리 구간 |
| - | - |
| 가드 키를 누름 (패리 모션 중 다시 누른 경우 포함) | 생김 |
| 가드 키를 누르고 있는 채로 행동이 끝나 가드를 시작함 ('가드' 참고) | 생김 |
| 가드 키를 누르고 있는 채로 패리 모션이나 가드 밀림이 끝나 가드로 돌아옴 | 생기지 않음 |

- 대미지와 SP 소모가 없습니다.
- 공격자의 PP를 공격자 MaxPP의 8%만큼 감소시킵니다.
- MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 0.12초 히트스톱을 적용하고(적용 대상은 [전투 시스템](<전투 시스템.md>)의 히트스톱을 따릅니다), 패리 전용 이펙트를 재생합니다.
- 슬로우모션이 발동합니다. (슬로우모션 항목 참고)
- 패리 모션을 재생한 뒤, 가드 키를 누르고 있으면 가드 상태로, 떼었으면 대기 상태로 돌아갑니다. 패리 모션 중의 입력은 '행동 가능 표'를 따릅니다.
- 패리 모션 중에 공격을 받으면, 가드 키를 누르고 있을 때는 가드로 막고, 떼었을 때는 일반 피격으로 처리합니다.
- 가드 키 연타에 대한 제한은 두지 않습니다.

![패리 모션](<Attachments/플레이어 모션 패리.jpg>)

모션: `ARPG_Samurai_Anim_UE_Parry`

### 슬로우모션 (🟡 A)

극한 회피나 패리에 성공한 순간을 강조하는 연출로, 게임 전체를 아주 잠깐 느리게 합니다.

| 항목 | 값 |
| - | - |
| 발동 | 극한 회피 성공, 패리 성공 |
| 대상 | 게임 전체 (카메라 셰이크, 화면 효과 포함) |
| 속도 | 0.3배 |
| 지속 시간 | 실제 시간 0.3초. 끝나면 바로 원래 속도로 돌아갑니다. |
| 쿨다운 | 없음 |

- 패리로 발동하면 패리 히트스톱이 끝난 직후에 시작합니다.
- 슬로우모션 중에 다시 발동하면 지속 시간을 처음부터 다시 셉니다.

### 스킬 (🔴 S)

E 키로 사용하는 MP 소모 공격입니다.

| 항목 | 돌진 베기 |
| - | - |
| MP 소모 | 30 |
| 쿨다운 | 5초 |
| 동작 | 돌진하며 벱니다. 방향은 '공통 규칙'의 공격 방향 보정을 따릅니다. |
| 대미지 배율 | 3.0 |
| PP 배율 | 6.0 |
| 피격 반응 | 넉백 |
| 공격 방향 보정 범위 | 3m |

![스킬 돌진 베기 모션](<Attachments/플레이어 모션 스킬.jpg>)

모션: `ARPG_Samurai_Anim_UE_Attack_Sprint`

- 후딜 구간에서는 회피로 캔슬할 수 있습니다.

### 궁극기 (🔴 S)

R 키로 사용하는, UP를 모두 소모하는 강력한 공격입니다.

| 항목 | 난무 |
| - | - |
| UP 소모 | 100 (UP가 MaxUP일 때만 사용 가능) |
| 동작 | 순식간에 다가간 뒤 5회 연속으로 베고, 강한 일격으로 마무리합니다. 방향은 '공통 규칙'의 공격 방향 보정을 따릅니다. |
| 대미지 배율 | 1~5타 각 1.2, 6타 4.0 |
| PP 배율 | 1~5타 각 1.8, 6타 6.0 |
| 피격 반응 | 1~5타 움찔, 6타 넉백 |
| 보호 | 시작부터 종료까지 무적 |
| 공격 방향 보정 범위 | 4m |

![궁극기 난무 모션](<Attachments/플레이어 모션 궁극기.jpg>)

모션: `ARPG_Samurai_Anim_UE_Attack_Dodge` → `ARPG_Samurai_Anim_UE_Attack_Combo_B1` ~ `ARPG_Samurai_Anim_UE_Attack_Combo_B5` → `ARPG_Samurai_Anim_UE_Attack_HeavyB`

- 궁극기는 캔슬할 수 없습니다.

### 스킬과 궁극기의 공통 규칙

- 스킬은 MP가 부족하거나 쿨다운 중이면, 궁극기는 UP가 부족하면 발동하지 않습니다.
- 그로기 상태의 보스에게도 사용할 수 있습니다. 처형 전에 스킬이나 궁극기로 추가 대미지를 넣을 수 있습니다.

### 처형 (🔴 S)

그로기 상태의 보스에게 사용하는 마무리 공격입니다.

- 발동 조건: 아래를 모두 만족해야 합니다.
  1. 보스가 그로기 상태이고, 이번 그로기에서 아직 처형을 쓰지 않았습니다.
  2. 플레이어와 보스의 캡슐 중심 사이 수평 거리가 3m 이내입니다.
  3. 플레이어가 처형을 입력할 수 있는 상태입니다. (행동 가능 표에서 평타·처형이 O)
- 발동 조건을 만족할 때 처형 키를 누르면 처형을 사용합니다. 조건을 만족하지 않으면 처형 키를 눌러도 아무 일도 일어나지 않습니다. 처형 안내 표시는 [전투 HUD](<전투 HUD.md>)를 따릅니다.
- 처형을 시작하면 보스가 플레이어를 바라보도록 돌립니다. 플레이어는 처형 모션을 재생하며 보스 정면으로 다가가 붙고, 보스는 처형 피격 모션을 재생합니다.

| 대미지 배율 | PP 배율 | 피격 반응 |
| - | - | - |
| 15.0 | 0 | 없음 |

![처형 모션](<Attachments/플레이어 모션 처형.jpg>)

모션: `ARPG_Samurai_Anim_UE_Execute`

- 처형 대미지는 처형 모션의 마지막 일격에서 한 번 적용합니다.
- 처형 중 플레이어는 무적입니다.
- 처형이 끝난 뒤 보스의 그로기는 [전투 시스템](<전투 시스템.md>)의 그로기를 따릅니다. 처형 대미지로 보스의 HP가 0 이하가 되면 보스 사망 연출로 이어집니다.

### 피격

- 플레이어에게는 슈퍼아머가 없어 넉백, 다운을 모두 받습니다. 무적이 적용되는 구간은 각 행동 항목(회피, 회피 반격, 궁극기, 처형)을 따릅니다.
- 피격 반응별 피격 모션은 [전투 시스템](<전투 시스템.md>)을 따릅니다. 공중에서 넉백, 다운에 맞으면 해당 피격 모션을 재생하며 떨어집니다. 움찔은 점프를 끊지 않습니다.
- 피격 시 피격 이펙트와 카메라 셰이크([카메라](<카메라.md>) 참고)를 재생합니다.

![넉백과 다운 모션](<Attachments/플레이어 모션 피격.jpg>)

모션: 넉백 `ARPG_Samurai_Anim_UE_Hit3`, 다운 `ARPG_Samurai_Anim_UE_Death` → `ARPG_Samurai_Anim_UE_Getup2_Idle1`

### 사망

- HP가 0 이하가 되면 [전투 시스템](<전투 시스템.md>)의 사망 처리를 따릅니다.
- 사망 연출은 3초입니다. 3초 후 사망 연출을 종료하고 Game Over UI를 출력합니다. ([게임 플로우](<게임 플로우.md>) 참고)
- 이미 결과가 정해진 뒤에 사망한 경우는 [게임 플로우](<게임 플로우.md>)의 Boss Stage를 따릅니다.

## 행동 가능 표

현재 상태에서 각 입력이 어떻게 처리되는지 정리한 표입니다.

- O: 즉시 실행. 진행 중인 행동은 캔슬합니다. 단, '(느리게)'와 '(공중 이동)'으로 적은 이동은 행동을 끊지 않습니다.
- X: 무시
- '-': 해당 없음 (이미 그 행동 중)

| 현재 상태 | 이동 | 평타·처형 | 가드 | 회피 | 점프 | 스킬·궁극기 |
| - | - | - | - | - | - | - |
| 대기, 이동, 달리기 | O | O | O | O | O | O |
| 평타 선딜 | X | X | X | O | X | X |
| 평타 판정 구간 | X | X | X | X | X | X |
| 평타 후딜 | X | O | O | O | O | O |
| 회피 (시작 ~ 캔슬 가능 시점, 극한 회피 발동 전) | X | X | X | X | X | X |
| 회피 (극한 회피 발동 ~ 캔슬 가능 시점) | X | O | X | X | X | X |
| 회피 (캔슬 가능 시점 ~ 종료) | O | O | O | O | O | O |
| 회피 반격 | X | X | X | X | X | X |
| 공중 | O (공중 이동) | X | X | X | X | X |
| 가드 | O (느리게) | O | - | O | O | O |
| 패리 모션 | X | O | O | O | O | O |
| 스킬 (시작 ~ 판정 구간 종료) | X | X | X | X | X | X |
| 스킬 후딜 | X | X | X | O | X | X |
| 궁극기 | X | X | X | X | X | X |
| 넉백, 다운, 가드 밀림, 가드 브레이크 | X | X | X | X | X | X |
| 처형, 사망 | X | X | X | X | X | X |

- 평타 후딜이 끝나면 대기 상태가 되어 모든 입력이 가능합니다.
- 평타·처형이 O일 때 평타 키로 어떤 행동을 사용하는지는 '평타 키의 처리 순서'를, 처형 키는 '처형'의 발동 조건을 따릅니다.
- 가드 키를 누르고 있는 채로 행동이 끝날 때의 처리는 '가드'를, 패리 구간이 생기는지는 '패리'를 따릅니다.
- 움찔과 가드 움찔은 행동을 끊지 않으므로, 맞기 전 상태의 규칙을 그대로 따릅니다.
- 락온 키는 사망 전까지 상태와 관계없이 언제든 입력할 수 있습니다.
