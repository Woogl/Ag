# 플레이어 사양

플레이어가 조작하는 캐릭터의 스탯과 행동 규칙을 정의합니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<전투 시스템.md>) 문서를 따릅니다.

키 배치와 입력 처리(허용 입력, 선입력, 모션 캔슬)는 [플레이어 입력](<플레이어 입력.md>) 문서를 따릅니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

행동명에 병기한 영문 식별자는 `Abilities.json`에 정의된 어빌리티 ID입니다.

## 개요

| 항목 | 내용 |
| - | - |
| 이름 | 린 |
| 시점 | 3인칭 |
| 무기 | 카타나 |
| 핵심 플레이 | 보스의 공격을 패리와 회피로 받아 내고, 생긴 빈틈에 콤보와 스킬을 넣어 보스의 PP를 깎습니다. |
| 리소스 | [아트 표현 사양](<아트 표현 사양.md>)을 따릅니다. |

## 스탯

| 스탯 | 초기값 | 비고 |
| - | - | - |
| HP / MaxHP | 1000 / 1000 | |
| SP / MaxSP | 100 / 100 | |
| MP / MaxMP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| UP / MaxUP | 0 / 100 | 0에서 시작하며 전투 중에 충전합니다. |
| PP / MaxPP | 미사용 | 플레이어는 그로기 대상이 아닙니다. |
| ATK | 100 | |
| DEF | 50 | |
| MOV | 350 | 단위 cm/s. 기본 이동 속도 |

### 자원 회복

| 스탯 | 회복 규칙 |
| - | - |
| HP | 자동 리젠되지 않습니다. |
| SP | 마지막으로 SP를 소모하고 1초 뒤부터 초당 40 회복합니다. 가드 중에는 초당 20 회복합니다. SP가 0이 되면 리젠 대기 시간이 2초로 늘어납니다. |
| MP | 자동 리젠되지 않습니다. 아래 'MP 충전' 표의 행동으로 충전합니다. |
| UP | 자동 리젠되지 않습니다. 아래 'UP 충전' 표의 행동으로 충전합니다. |

#### 적중에 의한 충전 횟수

- 공격 적중에 의한 MP·UP 충전은 공격의 각 타에서 최초 적중에만 1회 발생합니다. 적중하지 않으면 충전하지 않습니다.
- 한 타가 같은 적을 여러 번 맞히거나 여러 적을 맞혀도 추가로 충전하지 않습니다. 여러 적을 동시에 맞혀도 충전량은 같습니다.
- 평타는 콤보 전체가 아니라 각 타가 따로 충전합니다. 각 타의 최초 적중에서 해당 타의 MP·UP를 함께 충전하며, 다음 타에서는 다시 충전할 수 있습니다. 점프 공격, 회피 반격, 스킬은 한 번 발동에 타가 하나라 발동마다 한 번 충전합니다.
- 충전 대상 행동과 충전량은 아래 'MP 충전', 'UP 충전' 표를 따릅니다. 이 횟수 제한은 공격 적중에 의한 충전에 적용하며, SP 자동 리젠과 패리·극한 회피 성공 보상은 각 규칙을 따릅니다.

### MP 충전

| 행동 | 충전량 |
| - | - |
| 평타 적중 (1타당) | +4 |
| 점프 공격 적중 | +4 |
| 회피 반격 적중 | +8 |
| 극한 회피 성공 | +10 |
| 패리 성공 | +10 |

- 스킬, 궁극기, 처형의 적중으로는 MP를 충전하지 않습니다.

### UP 충전

| 행동 | 충전량 |
| - | - |
| 스킬 적중 | +15 |
| 평타 마지막 타 적중 | +15 |
| 패리 성공 | +10 |
| 극한 회피 성공 | +10 |

- 그 밖의 행동(평타 1 ~ 4타, 회피 반격, 궁극기, 처형 등)으로는 UP를 충전하지 않습니다.

### SP 소모

| 행동 | 소모량 |
| - | - |
| 회피 | 20 |
| 달리기 | 초당 12 |
| 가드로 막은 공격 | 가드 경감 배율 적용 전 HP 감소량의 25% |

- 점프, 점프 공격, 평타, 스킬은 SP를 소모하지 않습니다.
- 회피는 SP가 위 표의 소모량 이상일 때만 사용할 수 있습니다.
- 달리기는 SP가 0보다 크면 사용할 수 있습니다.
- 가드로 공격을 막을 때 SP가 부족하면 가드 브레이크가 발생합니다. (가드 항목 참고)

## 이동

플레이어의 Yaw 회전 속도는 초당 540°입니다. 공격 중 회전 보정에도 이 속도를 사용하며, 회피 반격의 예외는 해당 항목을 따릅니다.

| 상태 | 속도 | 캐릭터 방향 |
| - | - | - |
| 기본 이동 | MOV | 락온하지 않았을 때는 이동 방향을 바라봅니다. 락온 중에는 대상을 바라보며 이동합니다. |
| 달리기 | MOV × 1.5 | 락온 여부와 관계없이 이동 방향을 바라봅니다. |
| 가드 중 | MOV × 0.65 | 락온 중에는 대상을, 아닐 때는 카메라 정면을 바라봅니다. |

- 락온 중이나 가드 중에 서 있을 때도 바라볼 방향(위 표)을 늘 정면으로 바라봅니다. 작은 차이는 그 자리에서 회전 속도로 부드럽게 돌고, 크게 벌어지면 제자리 회전 모션으로 발을 옮기며 돌아섭니다.

모션: 제자리 회전 [ARPG_Warrior_Anim_UE_Turn_45L](<../Art/GIF/Warrior/ARPG_Warrior_Anim_UE_Turn_45L.gif>)·`R`, [ARPG_Warrior_Anim_UE_Turn_90L](<../Art/GIF/Warrior/ARPG_Warrior_Anim_UE_Turn_90L.gif>)·`R` (가드 중은 '가드')

### 달리기 (Sprint)

- 회피 후딜 중 Shift를 누르고 있고 이동 입력이 있으면 그 순간 회피 모션을 캔슬하고 달리기로 전환됩니다. 가드 키를 누르고 있을 때는 '가드'를 따릅니다.
- Shift를 떼거나 SP가 0이 되면 기본 이동으로 돌아갑니다. 이때 다시 달리려면 Shift를 새로 눌러 회피부터 시작해야 합니다.
- 달리기로 전환한 뒤 Shift를 누른 상태에서 이동 입력이 없으면 제자리에 멈추며, 이동 입력을 재개하면 다시 달립니다.
- SP는 이동 입력이 있어 실제로 달리는 동안에만 소모됩니다.

## 락온 (LockOn)

카메라 규칙은 [카메라](<카메라.md>) 문서를 따릅니다.

- 락온 타겟팅 범위: 플레이어 캡슐 중심에서 반경 20m 안에 적의 캡슐이 닿는 범위입니다.
- 락온 대상: 락온 타겟팅 범위 안에 있고 화면 안에 있는 생존한 적 가운데 가장 가까운 적입니다.
- 락온 해제 조건: 락온 키 재입력, 대상의 캡슐이 플레이어 캡슐 중심에서 반경 30m 밖으로 벗어남, 대상 사망.
- 락온 중 캐릭터의 방향은 '이동' 항목을, 카메라의 움직임은 [카메라](<카메라.md>)의 '락온 카메라'를 따릅니다.
- 락온 마커 표시는 [전투 HUD](<전투 HUD.md>) 문서를 따릅니다.

## 전투 행동

아래 모션 이름의 링크는 원본 시퀀스를 1배속으로 보여 줍니다. 행동별 조합 그림은 원본 GIF의 필요한 구간을 연결하고 배속·반복을 적용한 미리보기입니다. 캐릭터와 무기는 각 원본 GIF의 구성을 따르며, 판정·예고·연출 설명은 본문을 따릅니다.

모션 그림에서는 카메라가 플레이어를 따라가므로 이동한 거리는 나타나지 않습니다. 넉업과 점프 공격의 높이도 모션 밖에서 주므로 나타나지 않습니다. 입력 시점에 따라 모습이 달라지는 행동은 아래 경우를 보여 줍니다.

- 평타: [Samurai 애니메이션 조사](<../Art/Samurai 애니메이션 조사.md>)의 연결 시점에서 다음 타를 이은 경우
- 점프 공격: 점프 최고점에서 공격한 경우
- 가드: 가드를 시작한 뒤 앞으로 걷는 경우
- 패리: 가드를 시작한 뒤 패리 구간에 공격을 받은 경우

### 공통 규칙

- 구간별 허용 입력은 [플레이어 입력](<플레이어 입력.md>)을 따르며, 무적 등 다른 규칙은 각 행동 항목을 따릅니다.

#### 공격 방향

평타, 점프 공격, 회피 반격, 스킬은 각 타를 시작할 때 아래 순서로 공격 방향을 정합니다.

| 순서 | 조건 | 공격 방향 |
| - | - | - |
| 1 | 락온 중 | 락온 대상 방향 |
| 2 | 적이 타겟팅 범위 안에 있음 | 범위 안에서 가장 가까운 적 방향 |
| 3 | 그 밖의 경우 | 캐릭터 정면 |

- 타겟팅 범위는 각 행동 항목에서 정하며, 평타는 타마다 정합니다. 대상이 타겟팅 범위 안에 있다는 것은 플레이어 캡슐 중심에서 그 반경 안에 대상의 캡슐이 닿는 것입니다.
- 1은 락온 대상이 타겟팅 범위 밖이면 범위 안에 다른 적이 있어도 락온 대상을 향합니다. 보정은 [전투 시스템](<전투 시스템.md>)의 '공격 중 위치·회전 보정'을 따릅니다.
- 2는 '공격 중 위치·회전 보정'에 따라 그 적을 향해 돕니다.

#### 공격 중 위치·회전 보정

평타, 점프 공격, 회피 반격, 스킬은 [전투 시스템](<전투 시스템.md>)의 '공격 중 위치·회전 보정'을 따르며, 플레이어의 값은 아래와 같습니다.

| 항목 | 값 |
| - | - |
| 대상과의 최소 간격 | 1m |
| 회전 정지 | 각 타의 준비 시작부터 추적하고, 현재 재생 속도에서 판정 시작 약 0.1초 전에 방향을 확정합니다. 짧은 선딜에도 적용합니다. |
| 위치 보정 | 평타·스킬·회피 반격은 추적 구간에서 수평 이동도 보정합니다. 판정·후딜에는 모션 자체의 이동만 사용합니다. |
| 타겟팅 범위, 최대 워핑 거리 | 각 행동 항목. 평타는 타마다 정합니다. |

각 타의 시작에 대상을 한 번 선택하고 타 도중에는 교체하지 않습니다. 스킬은 올려베기 직전에 방향을 확정합니다. 점프 공격은 시작부터 내려베기의 판정 시작 전까지 위 표의 '회전 정지' 기준에 따라 회전만 보정하고, 이후 착지와 후딜이 끝날 때까지 공격 방향을 유지합니다. 점프 공격에는 추가 접근을 적용하지 않으며, 수평 이동은 '점프 공격'의 이동 규칙을 따릅니다. 처형은 처형의 지정 대상·간격 규칙을 따릅니다.

#### 쿨다운

- 행동을 시작한 순간부터 셉니다. 쿨다운 중에는 그 행동을 입력해도 발동하지 않습니다.
- 보스전이 시작될 때는 모든 쿨다운이 끝난 상태입니다.
- 쿨다운 값은 각 행동 항목을 따르며, 적혀 있지 않은 행동은 쿨다운이 없습니다.

#### 평타 키의 처리 순서

### 점프 (Jump)

| 항목 | 값 |
| - | - |
| 점프 높이·체공 시간 | 같은 높이에 착지할 때 최고 높이 약 0.73m, 체공 시간 약 0.58초 |
| 공중 이동 | 점프와 공중 이동 설정은 [전투 시스템](<전투 시스템.md>)의 '점프와 공중 이동'을 따릅니다. |

- 점프에는 무적 구간이 없습니다.
- 공중에서 허용되는 입력은 [플레이어 입력](<플레이어 입력.md>)의 '상태별 허용 입력'을 따릅니다.
- 달리는 중에 점프하면 달리기 속도를 유지한 채 점프합니다. 공중에서도 달리기가 이어져 SP를 소모하며, 착지했을 때 Shift와 이동 입력이 그대로 있으면 계속 달립니다.

#### 점프 공격 (JumpAttack)

공중에서 평타 키로 사용하는 공격입니다. 칼을 내려벤 뒤 빠르게 내리꽂아, 착지하며 바닥을 찍습니다.

| HP 배율 | PP 배율 | 피격 반응 | 타겟팅 범위 | 최대 워핑 거리 |
| - | - | - | - | - |
| 1.5 | 1.5 | 움찔 | 3m | 0m |

| 단계 | 내용 |
| - | - |
| 내려베기 | 칼을 뒤로 젖혔다가 앞 아래로 내려벱니다. 이 동안은 점프하던 궤적을 따라 움직입니다. |
| 내리꽂기 | 내려베기가 끝나면 초속 10m로 떨어집니다. |

#### 극한 회피

극한 회피 구간에 보스의 공격 판정(투사체 포함)이 닿으면 극한 회피가 발동합니다. 극한 회피 구간 동안에는 회피를 시작한 자리에 캐릭터의 캡슐이 남아 있는 것으로 보고, 그 캡슐에 닿은 공격 판정도 캐릭터에 닿은 것으로 처리합니다. 회피 한 번당 한 번만 발동하며, 추가로 공격을 피해도 보상과 회피 반격 기회를 다시 주지 않습니다.

- 회피에 소모한 SP를 돌려받고, MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 슬로우모션이 발동합니다. ([전투 시스템](<전투 시스템.md>)의 '슬로우모션' 참고)
- 화면 효과를 한 번 재생합니다. 전체 길이는 성공 시점의 극한 회피 슬로우모션 길이를 따르며, 시간 배율·히트스톱의 영향을 받지 않습니다. 궁극기 화면 효과와 함께 발생하면 둘 다 적용합니다. 외형은 [아트 표현 사양](<아트 표현 사양.md>)의 '극한 회피 화면 효과'를 따릅니다.

##### 회피 반격 기회

| 항목 | 규칙 |
| - | - |
| 발생 시점 | 극한 회피가 발동한 순간 |
| 유효 시간 | 발생 시점부터 1초. 회피가 끝나도 남은 시간 동안 유지됩니다. |
| 사용 입력 | 평타 키. 입력 처리는 '평타 키의 처리 순서'를 따릅니다. |

- 유효 시간이 끝남
- 회피 반격을 사용함
- 이동 외의 행동(회피, 가드, 점프, 스킬, 궁극기, 처형)을 함. 가드 키를 누르고 있어 가드가 저절로 시작된 경우도 포함합니다.
- 넉업, 넉백에 맞음

### 패리

#### 패리 구간

가드를 새로 시작한 순간부터 0.3초 동안을 '패리 구간'이라 합니다. 이 구간에 가드 가능한 공격을 받으면 패리에 성공합니다. 패리 구간 중에 가드 키를 떼면 패리 구간도 즉시 끝납니다.

가드가 시작될 때 패리 구간이 생기는지는 아래 표를 따릅니다.

| 가드가 시작되는 경우 | 패리 구간 |
| - | - |
| 가드 입력이 허용된 상태에서 가드 키를 새로 누르거나 선입력으로 가드를 시작함 (패리 모션의 후딜 포함) | 생김 |
| 가드 키를 누르고 있는 채로 가드 입력이 허용되는 상태가 되어 가드를 시작함 ('가드 시작' 참고) | 생김 |
| 가드 키를 누르고 있는 채로 패리 모션의 후딜이 시작되거나 가드 밀림이 끝나 가드로 돌아옴 | 생기지 않음 |

- 패리에 성공해 패리 모션을 시작하면 기존 패리 구간은 즉시 종료됩니다.
- 패리 입력은 공격이 플레이어에게 실제로 닿는 시점에 맞춥니다. 예고의 기준은 [보스 사양](<보스 사양.md>)의 '공격 예고'를 따릅니다. DashThrust는 돌진해 오는 보스를, SwordWave는 날아오는 검기를 보고 패리합니다.
- 가드 키 연타에 대한 제한은 두지 않습니다.

#### 성공 시 처리

- 패리 성공 시 HP·PP·SP 처리는 [전투 시스템](<전투 시스템.md>)의 '피격 처리 순서'를 따릅니다. PP 감소량은 아래와 같습니다.
- 투사체가 아닌 공격은 공격자의 PP를 공격자 MaxPP의 8%만큼 즉시 감소시킵니다. 투사체는 아래 '투사체 반사'를 따릅니다.
- MP와 UP를 충전합니다. ('MP 충전', 'UP 충전' 참고)
- 히트스톱을 적용하고([전투 시스템](<전투 시스템.md>)의 히트스톱을 따릅니다), 패리 전용 VFX를 재생합니다.

#### 투사체 반사

- 투사체를 패리하면 패리한 위치에서 원래 발사자의 현재 위치를 향하도록 투사체의 방향을 바꿉니다. 이후에는 직진하며, 발사자가 이동해도 추적하지 않습니다.
- 반사 순간 이동 거리를 초기화하여 반사 지점부터 원래 투사체의 최대 사거리를 새로 적용합니다. 속도는 유지합니다.
- 반사된 투사체도 같은 대상은 한 번만 판정하고 관통합니다. 벽에 닿거나 최대 사거리에 도달하거나 원래 발사자가 사망하면 소멸합니다.
- 패리 성공 순간에는 발사자의 HP와 PP를 감소시키지 않습니다. 반사된 투사체가 발사자에게 실제로 적중했을 때 대미지를 적용합니다.
- HP 감소량은 플레이어의 ATK와 원래 투사체의 HP 배율, 피격 대상의 DEF를 사용하여 [전투 시스템](<전투 시스템.md>)의 'HP 감소량 계산식'으로 계산합니다. 반사 전용 배율은 사용하지 않습니다.
- PP 감소량은 발사자 MaxPP의 8%이며, ATK와 DEF의 영향을 받지 않습니다. PP 감소 면역은 [전투 시스템](<전투 시스템.md>)의 'PP 감소량 계산식'을 따릅니다.
- 피격 반응은 원래 투사체의 속성을 유지합니다. 실제 피격 반응과 행동 중단은 대상의 상태에 따른 기존 피격 처리 규칙을 따릅니다.
- MP·UP는 패리 성공 시 충전하며, 반사된 투사체의 적중으로 추가 충전하지 않습니다.

| - | - | - |
| 모션 중 공격을 받음 | '가드 → 공격을 받았을 때'를 따름 | 일반 피격 |
| 후딜이 시작됨 | 모션을 캔슬하고 가드 상태로 돌아감 | 모션을 이어가고, 끝나면 대기 상태로 돌아감 |

- 패리 모션 중의 입력은 [플레이어 입력](<플레이어 입력.md>)을 따릅니다.
- 패리 모션의 후딜은 공격을 쳐내는 동작을 마친 뒤 자세를 되돌리는 구간입니다.

### 궁극기 (Ultimate)

궁극기 키로 사용하는 UP 소모 광역 공격입니다. 키 배치는 [플레이어 입력](<플레이어 입력.md>)을 따릅니다. 궁극기 컷신 뒤 멈춘 시간 속에 베기 선을 새기고, 칼을 칼집에 넣는 순간 범위 안의 적을 한꺼번에 벱니다.

| 항목 | 심판 |
| - | - |
| UP 소모 | 100 |
| 범위 | 플레이어 캡슐 중심에서 반경 10m 안에 캡슐이 닿는 적 |
| HP 배율 | 5.0 |
| PP 배율 | 5.0 |
| 피격 반응 | 넉업 |
| 보호 | 시작부터 끝까지 무적. 후딜에서 모션 캔슬하면 궁극기의 무적도 끝납니다. |

UP가 위 표의 소모량 이상일 때만 사용할 수 있으며, 최대 UP와 관계없이 정해진 양을 소모합니다.

| 단계 | 시간 | 내용 |
| - | - | - |
| 컷신 | 0 ~ 2.0초 | 궁극기 컷신을 재생합니다. 플레이어는 몸을 낮추고 칼을 뒤로 거둔 자세로 기다립니다. 카메라는 [카메라](<카메라.md>)의 '궁극기 컷신'을 따릅니다. |
| 베기 | 2.0 ~ 4.07초 | 게임 화면으로 돌아옵니다. 플레이어는 칼을 크게 휘두른 뒤 천천히 칼집에 넣고, 그동안 베기 선이 하나씩 나타납니다. |
| 마무리 | 4.07초 | 칼이 칼집에 들어가는 순간 베기 선이 모두 터지며 사라지고, 범위 안의 모든 적에게 1타가 적중합니다. 시간 정지가 끝나면 1타의 적중과 관계없이 슬로우모션이 발동합니다. ([전투 시스템](<전투 시스템.md>)의 '슬로우모션' 참고) |
| 칼 뽑기 | 4.07 ~ 4.89초 | 칼을 다시 뽑아 쥡니다. 이 구간이 후딜입니다. |

- 플레이어는 제자리에서 하며, 방향을 바꾸지 않습니다.
- 마무리의 1타는 범위 안의 적마다 [전투 시스템](<전투 시스템.md>)의 '피격 처리 순서'를 따릅니다. 범위 밖의 적은 맞지 않습니다.
- 베기 선이 터지는 VFX(궁극기 마무리 VFX)는 1타의 적중과 관계없이 재생합니다. 쓰는 에셋은 [아트 표현 사양](<아트 표현 사양.md>)을 따릅니다.

#### 궁극기 화면 효과

궁극기 시작부터 마무리까지 화면 전체에 궁극기 전용 후처리를 적용하며, 마무리 순간 원래 화면으로 돌아옵니다. 시간 정지 기능과 독립된 연출입니다. 외형은 [아트 표현 사양](<아트 표현 사양.md>)의 '궁극기 화면 효과'를 따릅니다.

#### 시간 정지

| 항목 | 값 |
| - | - |
| 대상 | 보스와 보스의 투사체(검기) |
| 기간 | 궁극기 시작부터 마무리까지 |
| 멈추는 것 | 모션, 이동, 패턴 진행이 그 자리에서 멈춥니다. 마무리 순간 멈췄던 상태에서 그대로 이어집니다. |

- 시간 정지 동안 멈추는 시간과 흐르는 시간은 [전투 시스템](<전투 시스템.md>)의 '시간 연출 중의 시간'을 따릅니다.
- 컷신이나 베기 중에 누른 선입력 대상인 입력은 마무리 뒤 후딜이 시작될 때 실행됩니다. 기억할 입력과 실행 조건은 [플레이어 입력](<플레이어 입력.md>)의 '선입력'을 따릅니다.

#### 베기 선

| 항목 | 값 |
| - | - |
| 개수 | 16개 |
| 나타나는 시점 | 베기 단계 동안 일정한 간격으로 하나씩 |
| 위치 | 플레이어 주변 모든 방향으로 수평 3 ~ 7m, 바닥에서 높이 0 ~ 3m 안의 무작위 위치. 각도도 무작위입니다. |
| 사라지는 시점 | 마무리 순간 모두 함께. 사라지는 자리마다 궁극기 마무리 VFX가 하나씩 터집니다. |

- 베기 선은 보이기만 하고 공격 판정이 없습니다. 위치·모양 등의 값은 아트 제작 기준입니다. 쓰는 에셋은 [아트 표현 사양](<아트 표현 사양.md>)을 따릅니다.

### 처형 (Execution)

그로기 상태의 보스에게 사용하는 마무리 공격입니다.

- 발동 조건: 아래를 모두 만족해야 합니다.
  1. 보스가 지상에서 그로기 상태입니다.
  2. 보스가 처형 타겟팅 범위 안에 있습니다. 이 범위는 플레이어 캡슐 중심에서 반경 3m 안에 보스의 캡슐이 닿는 범위입니다.
  3. 플레이어가 처형을 입력할 수 있는 상태입니다. ([플레이어 입력](<플레이어 입력.md>)에서 처형 입력이 허용됨)
- 발동 조건을 만족할 때 처형 키를 누르면 처형을 사용합니다. 조건을 만족하지 않으면 처형 키를 눌러도 아무 일도 일어나지 않습니다. [플레이어 입력](<플레이어 입력.md>)의 '선입력'에 따라 처형 입력은 기억하지 않습니다. 처형 안내 표시는 [전투 HUD](<전투 HUD.md>)를 따릅니다.
- 처형을 시작하면 보스가 플레이어를 바라보도록 돌립니다. 플레이어는 처형 모션을 재생하며 찌르기 전까지 보스 정면으로 다가가 붙습니다. 보스는 그로기 자세에서 처형 모션과 짝을 이루는 처형 피격 모션으로 넘어갑니다.
- 처형 모션은 칼로 보스를 찌른 채 버티다가, 발차기로 보스를 걷어차 칼을 뽑습니다.
- 처형 모션은 무게감이 느껴지도록 0.6배속으로 재생합니다. 보스의 처형 피격·처형 사망 모션도 같은 속도로 재생해 두 모션이 맞물립니다.

| HP 배율 | PP 배율 | 피격 반응 |
| - | - | - |
| 찌르기 1.5, 마지막 일격(발차기로 칼을 뽑음) 4.5 | 0 | 없음 |

![처형 모션](<Attachments/플레이어 모션 처형.gif>)

모션: [ARPG_Warrior_Anim_UE_Execute](<../Art/GIF/Warrior/ARPG_Warrior_Anim_UE_Execute.gif>)

- 처형 대미지는 처형 모션의 찌르기와 마지막 일격에서 각각 적용합니다.
- 처형 중 플레이어는 무적입니다.
- 처형에는 후딜이 없어, 처형 모션이 끝날 때까지 모션 캔슬할 수 없습니다.
- 보스의 그로기는 처형 시작 시 끝나며, 이후 처형 상태의 종료는 플레이어의 처형 종료와 관계없이 [전투 시스템](<전투 시스템.md>)의 '그로기' 규칙을 따릅니다. 처형 대미지로 보스의 HP가 0 이하가 되면 보스 사망 연출로 이어집니다.
