# 플레이어 입력

플레이어의 키 배치와, 상태에 따라 입력을 처리하는 규칙(허용 입력, 선입력, 모션 캔슬)을 정의합니다.

각 행동의 규칙은 [플레이어 사양](<플레이어 사양.md>) 문서를 따릅니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 키 배치

지원하는 조작 장치는 [게임 개요](<게임 개요.md>)를 따릅니다. 아래는 키보드·마우스 기준의 키 배치입니다.

| 행동 | 키 | 설명 |
| - | - | - |
| 이동 | W, A, S, D | |
| 시야 | 마우스 이동 | |
| 평타 | 마우스 왼쪽 버튼 | 사용하는 행동은 [플레이어 사양](<플레이어 사양.md>)의 '평타 키의 처리 순서'를 따릅니다. |
| 가드 / 패리 | 마우스 오른쪽 버튼 (누르고 있기) | 누른 직후 패리 구간 ([플레이어 사양](<플레이어 사양.md>)의 '패리' 참고) |
| 회피 / 달리기 | Left Shift | 누르면 회피하고, 회피 후에도 계속 누르고 있으면 달리기 |
| 점프 | Space | |
| 스킬 | E | |
| 궁극기 | R | |
| 처형 | F | |
| 락온 / 락온 해제 | 마우스 휠 클릭 | |

- 시야는 [카메라](<카메라.md>)의 자유 시점을 따릅니다.
- 화면 UI의 조작은 [게임 플로우](<게임 플로우.md>)의 'UI 조작'을 따릅니다.

## 공통 입력 처리

- 아래 '상태별 허용 입력' 표는 이동, 평타, 처형, 가드, 회피, 점프, 스킬, 궁극기 입력을 다룹니다. 이 중 '허용 입력'에 없는 입력('없음'이면 모든 입력)은 바로 실행하지 않습니다. 이동 입력은 무시하고, 나머지는 '선입력'을 따릅니다.
- 락온 키는 이 표의 제한을 받지 않으며, 사망 전까지 언제든 입력할 수 있습니다.
- 허용된 입력은 해당 행동의 자원, 쿨다운, 발동 조건을 만족하면 즉시 실행합니다.
- 평타 입력으로 어떤 행동을 사용하는지는 [플레이어 사양](<플레이어 사양.md>)의 '평타 키의 처리 순서'를, 처형 입력은 '처형'의 발동 조건을 따릅니다.
- 가드 키를 누르고 있거나 떼었을 때의 처리는 [플레이어 사양](<플레이어 사양.md>)의 '가드'를 따릅니다.

## 상태별 허용 입력

피격과 사망으로 인한 행동 중단 및 입력 제한은 [전투 시스템](<전투 시스템.md>)을 따르며, 아래 표에도 함께 표시합니다.

| 현재 상태 | 구간·조건 | 허용 입력 |
| - | - | - |
| 대기, 이동, 달리기 | 전체 | 이동, 평타, 처형, 가드, 회피, 점프, 스킬, 궁극기 |
| 가드 | 패리 구간이 생기는 가드 시작 후 0.5초 | 평타, 처형, 회피, 점프, 스킬, 궁극기 |
| 가드 | 그 밖 | 이동, 평타, 처형, 회피, 점프, 스킬, 궁극기 |
| 평타, 스킬, 궁극기, 회피 반격, 패리 모션, 회피 | 후딜 전 | 없음 |
| 평타, 스킬, 궁극기, 회피 반격, 패리 모션, 회피 | 후딜 | 평타, 처형, 가드, 회피, 점프, 스킬, 궁극기 |
| 처형 | 전체 | 없음 |
| 공중 | 전체 | 이동 (공중 이동) |
| 넉업, 넉백, 가드 밀림, 가드 브레이크 | 전체 | 없음 |
| 사망 | 전체 | 없음 |

## 선입력

허용되지 않는 상태에서 누른 입력을 잠시 기억했다가, 입력이 허용되는 순간 실행합니다.

- 대상은 평타, 처형, 가드, 회피, 점프, 스킬, 궁극기 입력입니다. 이동 입력은 기억하지 않습니다.
- 누른 순간부터 0.3초 동안 기억합니다. 그 안에 입력이 허용되면 그 순간 실행하고, 지나면 버립니다.
- 기억하는 입력은 하나입니다. 새로 누른 입력이 기억하던 입력을 대신합니다.
- 실행하는 순간의 상태로 처리합니다. 가드는 그때도 가드 키를 누르고 있을 때만 실행하고, 자원, 쿨다운, 발동 조건을 만족하지 않으면 버립니다.

## 모션 캔슬

평타, 스킬, 궁극기, 회피 반격, 패리 모션, 회피에 적용합니다.

- 후딜부터 허용된 행동을 입력해 진행 중인 모션을 캔슬할 수 있습니다. 후딜이 따로 정해지지 않은 행동은 모션이 끝난 뒤에만 다른 행동을 시작할 수 있습니다.
- 연속 공격의 후딜은 마지막 타의 판정 구간이 끝난 뒤입니다. 평타는 각 타를 별도 행동으로 보므로, 타마다 후딜에서 전환할 수 있습니다.
- 이동 입력은 모션 캔슬을 일으키지 않습니다. 위 행동 중에는 후딜에도 이동 키로 캐릭터를 움직일 수 없습니다. 모션이 끝났을 때 이동 키를 누르고 있으면 이동합니다.
