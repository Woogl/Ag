# 게임 개요

게임의 장르, 컨셉, 타겟 플랫폼, 조작 장치, 레퍼런스 게임을 정리합니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 기본 정보

| 항목 | 내용 |
| - | - |
| 제목 | AG (가제) |
| 장르 | 3인칭 액션 RPG |
| 플레이 인원 | 1인, 멀티플레이 미지원 |
| 개발 기반 | Unreal Engine 5.8 |

## 컨셉

적의 공격 전조를 보고 반응하며 공방을 주고받는 싱글플레이 액션 RPG입니다. 복잡한 커맨드 암기 대신 직관적인 조작과 명확한 액션 피드백에 집중합니다.

- **직관적인 조작과 공방 (액션성)**: 선입력과 모션 캔슬 기반의 반응성 높은 조작으로 기본 공격, 스킬, 패리, 회피를 유연하게 연계하며 전투를 주도합니다.
- **명확한 피드백 (타격감)**: 히트스톱, 카메라 셰이크, 슬로우모션을 통해 공격 적중과 방어 성공의 손맛을 직관적으로 전달합니다.
- **패턴 대응과 균형 붕괴 (성취감)**: 적의 전조 동작을 파악해 공격을 쳐내며 균형(PP)을 무너뜨리고, 그로기 상태에서 처형과 궁극기로 이어지는 공방의 재미를 제공합니다.

## 레퍼런스 게임

| 게임 | 참고하는 점 |
| - | - |
| 스텔라 블레이드 (Stellar Blade) | 패리와 회피를 중심으로 한 1:1 보스전 <br> 보스의 균형 수치를 깎아 그로기를 만들고 처형으로 마무리하는 흐름 <br> 가드할 수 없는 공격을 색으로 예고하는 방식 |
| 명조: 워더링 웨이브 (Wuthering Waves) | 빠른 템포의 공방 <br> 극한 회피 및 회피 반격의 민첩한 액션성 <br> 공격 타이밍과 궤적을 읽을 수 있는 직관적인 패턴 전조 |
| 젠레스 존 제로 (Zenless Zone Zero) | 과장되고 명확한 히트스톱과 카메라 셰이크를 통한 강렬한 타격감 <br> 패리·피격 시의 직관적인 시각·청각 피드백 <br> 빠른 템포의 연속 공격 연계와 경쾌한 모션 캔슬 조작감 |

- 레퍼런스는 방향을 잡기 위한 것입니다. 세부 규칙은 레퍼런스 게임이 아니라 각 기획서를 따릅니다.
