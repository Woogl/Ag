# 게임 개요

게임의 장르, 컨셉, 타겟 플랫폼, 조작 장치, 레퍼런스 게임을 정리합니다. 기획서를 처음 읽을 때 시작하는 문서이며, 세부 규칙은 각 기획서를 따릅니다.

용어는 [용어집](<용어집.md>)을 따릅니다.

## 기본 정보

| 항목 | 내용 |
| - | - |
| 제목 | AG (가제) |
| 장르 | 3인칭 액션 RPG |
| 플레이 인원 | 1인 (멀티플레이 미지원) |
| 개발 기반 | Unreal Engine 5.8 |

## 컨셉

강한 보스 한 명과 1:1로 겨루는 싱글플레이 액션 RPG입니다. 승패는 플레이어의 눈과 손에서 갈립니다.

### 핵심 재미

| 재미 | 무엇에서 오나 | 관련 시스템 |
| - | - | - |
| 액션성 | 원하는 대로 캐릭터를 컨트롤하며 전투 | 평타, 회피, 가드, 패리, 극한 회피, 회피 반격, 스킬, 궁극기, 처형, 캔슬, 공격 방향 보정 |
| 타격감 | 공격의 손맛과 타격 연출 | 히트스톱, 카메라 셰이크, 슬로우모션, 피격 반응, 피격 이펙트 |
| 성취감 | 쌓여 가는 실력 | 패턴 전조 동작, 붉은 섬광, 패턴 |

- 마일스톤1의 '핵심 전투 재미 검증' 목표는 위 재미가 실제로 느껴지는지 확인합니다. ([마일스톤1 계획](<마일스톤1 계획.md>) 참고)

## 타겟 플랫폼

| 항목 | 내용 |
| - | - |
| 플랫폼 | PC (Windows)만 지원합니다. |
| 기준 해상도 | [UI 스타일](<UI 스타일.md>)을 따릅니다. |

## 조작 장치

키보드·마우스를 지원합니다.

- 키 배치는 [플레이어 사양](<플레이어 사양.md>)의 조작을 따릅니다.

## 레퍼런스 게임

| 게임 | 참고하는 점 |
| - | - |
| 스텔라 블레이드 (Stellar Blade) | 패리와 회피를 중심으로 한 1:1 보스전 <br> 보스의 균형 수치(이 게임의 PP)를 깎아 그로기를 만들고 처형으로 마무리하는 흐름 <br> 가드할 수 없는 공격을 색으로 예고하는 방식 |

- 레퍼런스는 방향을 잡기 위한 것입니다. 세부 규칙은 레퍼런스 게임이 아니라 각 기획서를 따릅니다.
