# 보스 사양

LV_BossStage에 등장하는 보스의 스탯, 공격 패턴, AI 행동 규칙, 연출을 정의합니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<전투 시스템.md>) 문서를 따릅니다.

용어는 [용어집](<용어집.md>)을 따릅니다.

> 구현 우선순위: 🔴 S / 🟡 A / 🟢 B (기준은 [마일스톤1 계획](<마일스톤1 계획.md>) 참고)

## 공격 속성과 예고

패턴의 공격은 아래 2종류로 나뉩니다.

| 속성 | 가드 | 패리 | 예고 | 플레이어의 대응 |
| - | - | - | - | - |
| 일반 | 가능 | 가능 | 없음 | 패리, 가드, 회피 |
| 가드 불가 | 불가 | 불가 | 판정 구간 0.5초 전부터 판정 구간이 시작될 때까지 무기에 붉은 섬광 이펙트 | 회피 (극한 회피 시 회피 반격) |

- 공격 패턴은 선딜 동안 패턴 전조 동작을 크게 보여 주어, 플레이어가 공격 타이밍을 읽을 수 있어야 합니다.

## 패턴 공통 규칙

### 모션 재생 속도

- 공격 패턴(A1 ~ A6)의 모션은 원래 속도의 0.8배로 재생합니다.
- 기획서에 초나 속도로 적은 값(붉은 섬광, 회전 정지, A3 돌진, A4 체공)은 이 배율의 영향을 받지 않습니다.
- 2페이즈에서는 이보다 더 빠르게 재생합니다. 배율과 적용 대상은 아래 '2페이즈 변화'를 따릅니다.

### 회전

- 패턴 실행, 이동, 패턴 후딜레이 중에는 플레이어를 향해 초당 180°로 회전합니다.
- 단, 각 타의 판정 구간 시작 0.2초 전부터 판정 구간 종료까지는 회전하지 않습니다. 패턴별 예외는 해당 패턴의 정의를 따릅니다.

### 이동

아래에서 '대상과의 간격'은 보스와 플레이어의 캡슐 중심 사이 수평 거리입니다. 모션의 이동 거리는 보스가 이동하는 양이며, 최대 접근 거리는 접근 보정으로 이동할 수 있는 거리의 상한입니다.

| 적용 패턴 | 이동 규칙 |
| - | - |
| A1, A2, A5, A6 | 모션이 정한 거리만큼 앞으로 이동하되, 그 전에 대상과의 간격이 정지 간격(1.5m)이 되면 멈춥니다. |
| A1과 A5의 1타 | 선딜 동안 대상과의 간격이 정지 간격이 될 때까지 추가로 다가갑니다. 최대 접근 거리는 1m이며, 목표는 회전을 멈추는 순간의 플레이어 위치로 정합니다. |
| A3, A4 | 각 패턴의 이동 규칙을 따릅니다. |

- A1, A2, A5, A6은 이미 대상과의 간격이 위 정지 간격 이내라면 모션에 따른 전진과 추가 접근을 하지 않습니다.

## AI 행동 규칙

### 거리 구간

패턴을 선택할 때 보스와 플레이어의 캡슐 중심 사이 수평 거리로 구간을 판단합니다.

| 구간 | 거리 |
| - | - |
| 근거리 | 3m 이하 |
| 중거리 | 3m 초과 10m 이하 |
| 원거리 | 10m 초과 |

### 패턴 선택

1. 현재 거리 구간에서 사용할 수 있고, 쿨다운이 끝났으며, 현재 페이즈에서 사용 가능한 패턴을 후보로 모읍니다.
2. 후보 중 가중치('거리 구간별 가중치' 참고)에 따라 무작위로 하나를 선택합니다.
3. 후보가 없으면 플레이어에게 걸어서 다가가며, 0.5초마다 다시 선택을 시도합니다.

### 패턴 후딜레이

- 패턴이 끝나면 패턴 후딜레이 동안 플레이어를 바라보며 좌우로 걷습니다. (🟡 A)
- 패턴 후딜레이의 대기 시간은 AI 상태 트리의 '2-5. 패턴 후딜레이'를 따릅니다.

### 거리 구간별 가중치

보스는 현재 거리 구간에 적힌 패턴 중에서 다음 패턴을 고릅니다. 괄호 안의 숫자는 후보끼리 비교하는 비율이라 합이 100일 필요는 없으며, 뽑힐 확률은 '그 패턴의 가중치 ÷ 후보 가중치의 합'입니다. (예: 가중치가 40과 30인 후보 둘이면 각각 40/70, 30/70)

| 거리 구간 | 후보 패턴 (가중치) |
| - | - |
| 근거리 | A1 2연격 (40), A2 휩쓸기 (30), A5 3연격 (40) |
| 중거리 | A3 돌진 찌르기 (40), A4 도약 내려찍기 (40), A6 검기 발사 (20) |
| 원거리 | A3 돌진 찌르기 (60), A4 도약 내려찍기 (40), A6 검기 발사 (60) |

- 거리 구간의 범위는 '거리 구간'을, 후보에서 빠지는 조건(페이즈, 쿨다운)은 '패턴 선택'을 따릅니다. 예를 들어 1페이즈 근거리에서는 2페이즈 전용인 A5가 빠지므로 A1과 A2의 가중치만 비교합니다.

## 패턴 상세

각 패턴의 구현 우선순위는 '패턴 목록'을 따릅니다.

이 문서의 모션 그림은 모션의 주요 프레임을 순서대로 보여 줍니다.

- 테두리가 있는 칸은 타격 순간입니다. A6은 검기를 발사하는 순간입니다.
- 가드 불가 공격의 타격 칸은 테두리와 글자 색을 달리해 구분합니다.
- 그림 속 시간은 참고 값입니다. 공격 패턴(A1 ~ A6)은 1페이즈 재생 속도로 잰 시간입니다.
- A3 돌진과 A4 도약의 이동은 모션 밖에서 주므로 그림에 나타나지 않습니다.
- 할버드 위치는 [할버드 애니메이션 조사](<../Art/할버드 애니메이션 조사.md>)의 추정값입니다.
- 타격 칸의 선은 타격 직전에 창날 끝이 지나간 길입니다.
- 칸 아래쪽 글은 그 순간의 판정 정보입니다.
- 그림 아래에 그림에 쓴 애니메이션 에셋 이름을 적습니다.

#### 돌진과 모션

1. 찌르기 모션에서 몸을 앞으로 내던지는 순간 돌진을 시작합니다.
2. 창을 다 내지른 자세가 되면 돌진이 끝날 때까지 그 자세를 유지합니다.
3. 돌진이 끝나면 창을 거두는 나머지 모션을 이어서 재생합니다.

- 설계 의도: 옆으로 회피하면 가장 큰 반격 기회를 얻는 패턴입니다. 극한 회피 후 회피 반격을 노리게 합니다.

### A6. 검기 발사 (2페이즈)

멀리 있는 플레이어에게 검기를 날리는 원거리 공격입니다.

| 타 | 동작 | 대미지 배율 | 피격 반응 | 가드 | 패리 |
| - | - | - | - | - | - |
| 1 ~ 3 | 할버드를 휘둘러 검기 발사 | 1.2 | 움찔 | O | O |

![A6 검기 발사 모션](<Attachments/보스 모션 A6.jpg>)

모션: `ARPG_Halberd_Anim_UE_Attack_Combo2` → `ARPG_Halberd_Anim_UE_Attack_Combo3` → `ARPG_Halberd_Anim_UE_Attack_Combo4`

- 할버드를 세 번(내려찍기, 사선 베기, 휩쓸기) 휘둘러 휘두를 때마다 검기를 1발씩, 모두 3발 발사합니다.
- 검기는 각 타에서 회전을 멈춘 시점의 보스 정면으로 발사합니다. 회전과 정지 시점은 '패턴 공통 규칙'의 '회전'을 따릅니다.
- 보스 모션의 각 타는 검기를 발사하는 순간을 판정 구간으로 봅니다.

#### 검기

- 검기는 지면을 따라 날아가며, 폭은 2.0m, 높이는 지면부터 1.0m입니다.
- 속도는 1500cm/s, 최대 사거리는 20m입니다.
- 발사된 뒤 소멸할 때까지 공격 판정을 유지합니다.

다음 중 하나가 발생하면 검기가 소멸합니다.

- 플레이어에게 적중하거나 가드 또는 패리됨
- 벽에 닿음 (보이지 않는 벽 포함)
- 최대 사거리에 도달함
- 보스가 사망함. 사망 시 투사체 처리는 [전투 시스템](<전투 시스템.md>)의 '사망 처리'를 따릅니다.

발사된 검기는 보스의 그 밖의 상태 변화(그로기, 페이즈 전환 등)와 관계없이 계속 날아갑니다.

- 설계 의도: 거리를 벌린 플레이어를 압박하여 다시 근접전으로 끌어들입니다.

## AI 상태 트리

보스의 상태와 전환 규칙을 정리한 것입니다. 구현 구조는 구현 설계에서 정합니다.

- 상태는 위에서부터 순서대로 진입 조건을 검사하여, 조건을 통과한 첫 번째 상태를 선택합니다. 자식 상태가 있으면 자식 중에서 같은 방식으로 다시 선택합니다.
- '2-3. 패턴 실행'의 자식은 순서 대신 가중치 무작위로 선택합니다. (AI 행동 규칙의 '패턴 선택' 참고)
- 레벨이 시작되면 '2-5. 패턴 후딜레이'에서 시작합니다.
- '전환으로만 진입'인 상태는 순서대로 선택할 때 건너뛰며, 전환을 통해서만 들어갑니다.
- 'Root 전환'은 현재 어떤 상태에 있든 항상 검사합니다. 단, 끝 상태인 '1. 사망'과 '3. 비전투'에서는 검사하지 않습니다.
- 각 상태의 구현 우선순위는 그 상태가 실행하는 기능을 따릅니다. (패턴은 '패턴 목록' 참고)

```
Root
├── 1. 사망
├── 2. 전투
│   ├── 2-1. 페이즈 전환
│   ├── 2-2. 그로기
│   │   ├── 2-2-1. 그로기 유지
│   │   └── 2-2-2. 처형 피격
│   ├── 2-3. 패턴 실행
│   │   ├── A1. 2연격
│   │   ├── A2. 휩쓸기
│   │   ├── A3. 돌진 찌르기
│   │   ├── A4. 도약 내려찍기
│   │   ├── A5. 3연격
│   │   └── A6. 검기 발사
│   ├── 2-4. 이동
│   ├── 2-5. 패턴 후딜레이
│   └── 2-6. 백스텝 (B1)
└── 3. 비전투
```

### Root 전환

여러 조건을 동시에 만족하면 순서가 앞선(숫자가 작은) 전환을 따릅니다. 조건이 '~하는 순간'인 전환은 그 일이 일어날 때 한 번만 검사하고, 나머지는 조건을 만족하는 동안 계속 검사합니다.

| 순서 | 조건 | 대상 상태 | 비고 |
| - | - | - | - |
| 1 | HP가 0 이하가 되는 순간 | 1. 사망 | |
| 2 | 플레이어가 사망하는 순간 | 3. 비전투 | |
| 3 | PP가 0 이하가 되는 순간 | 2-2. 그로기 | |
| 4 | 플레이어가 처형을 시작하는 순간 | 2-2-2. 처형 피격 | 그로기 중에만 발생합니다. |
| 5 | 2페이즈 HP 구간에 들어선 뒤 아직 페이즈 전환을 시작하지 않았고, 패턴 실행이나 그로기(처형 피격 포함) 중이 아님 | 2-1. 페이즈 전환 | 패턴이나 그로기 중의 처리는 '페이즈 전환'을 따릅니다. |
