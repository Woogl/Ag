# 전투 HUD

전투 중 화면에 표시하는 정보(HUD)를 정의합니다. 타이틀 화면과 결과 UI 같은 화면 UI는 [게임 플로우](<게임 플로우.md>)에서 정의합니다.

화면 전환 규칙은 [게임 플로우](<게임 플로우.md>)를, 표시하는 수치와 상태는 [전투 시스템](<전투 시스템.md>), [플레이어 사양](<플레이어 사양.md>), [보스 사양](<보스 사양.md>)을 따릅니다.

기준 해상도, 화면 여백, 글자 크기, 입력 키 표시는 [UI 스타일](<UI 스타일.md>)을 따릅니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

> 구현 우선순위: 🔴 S / 🟡 A / 🟢 B (기준은 [마일스톤1 계획](<마일스톤1 계획.md>) 참고)

## HUD 요소

각 요소의 구현 우선순위는 '화면 구성'을 따릅니다.

### 1. 플레이어 상태

| 요소 | 크기 | 표시 규칙 |
| - | - | - |
| SP 바 | 300 × 8px | SP가 MaxSP보다 적을 때만 HP 바 바로 위에 표시합니다. |
| HP 바 | 400 × 16px | 항상 표시합니다. HP가 줄면 감소 잔상을 표시합니다. |
| HP 수치 | 글자 Medium | HP 바 오른쪽에 '현재값 / 최대값'으로 표시합니다. (🟡 A) |
| MP 바 | 300 × 10px | 항상 표시합니다. |
| MP 수치 | 글자 Medium | MP 바 오른쪽에 '현재값 / 최대값'으로 표시합니다. (🟡 A) |

- 위에서부터 SP, HP, MP 순서로 배치합니다.
- SP 바가 사라져도 HP 바와 MP 바의 위치는 바뀌지 않습니다.
- 플레이어 PP는 표시하지 않습니다.
- 감소 잔상 (🟢 B): HP가 줄면 줄어든 부분을 감소 잔상으로 남겨 두었다가, 0.5초 뒤 0.3초 동안 현재 HP까지 줄입니다. 잔상이 줄어드는 동안 HP가 다시 줄면 그 자리에서 다시 0.5초를 기다립니다.

### 2. 스킬·궁극기 슬롯

| 슬롯 | 위치 | 키 표시 | 슬롯 안 정보 |
| - | - | - | - |
| 스킬 | 화면 오른쪽 아래 | E | 스킬 아이콘, 스킬의 MP 코스트 |
| 궁극기 | 화면 오른쪽 아래, 스킬 슬롯 오른쪽 | R | 궁극기 아이콘. 슬롯 테두리에 UP 게이지를 표시합니다. |

- 슬롯 크기는 64 × 64px, 슬롯 사이 간격은 12px입니다. 키 표시는 슬롯 아래에 표시합니다.
- 아이콘 모양은 '화면 구성' 그림을 따릅니다. 마일스톤1에서 만드는 방법은 [마일스톤1 계획](<마일스톤1 계획.md>)의 아트 리소스를 따릅니다.
- 키 표시와 슬롯 안 숫자(MP 코스트)는 글자 Small로 표시합니다.
- UP 게이지는 궁극기 슬롯의 테두리가 UP 비율만큼 위쪽 가운데부터 시계 방향으로 채워지는 표시입니다. UP가 가득 차면 테두리 전체가 채워집니다.
- 사용할 수 없는 슬롯(MP 또는 UP 부족, 스킬 쿨다운 중)은 흐리게(반투명하게) 표시합니다. UP 게이지는 슬롯이 흐릴 때도 그대로 표시합니다.

### 3. 보스 상태

| 요소 | 크기 | 표시 규칙 |
| - | - | - |
| 보스 이름 | 글자 Large | HP 바 위 가운데에 보스 이름을 표시합니다. 이름은 [보스 사양](<보스 사양.md>)을 따릅니다. |
| HP 바 | 1000 × 14px | 수치와 페이즈 경계는 표시하지 않습니다. 플레이어가 페이즈가 바뀌는 시점을 미리 알 수 없게 합니다. 감소 잔상은 플레이어 HP 바와 같습니다. |
| PP 바 | 600 × 6px | HP 바 아래 가운데에 항상 표시합니다. |

- 그로기 중에는 PP 바를 평소와 다른 색으로 바꾸고, 빈 바를 그로기 지속 시간 동안 다시 채워 남은 시간을 보여 줍니다. 처형 때문에 그로기가 지속 시간보다 길어지면, 가득 찬 바를 그로기가 끝날 때까지 바뀐 색으로 유지합니다.

### 4. 락온 마커

- 락온 중일 때 보스의 락온 지점([카메라](<카메라.md>) 참고)에 지름 32px의 원형 마커를 표시합니다.

### 5. 처형 안내

- [플레이어 사양](<플레이어 사양.md>)의 처형 발동 조건 중 1번(그로기)과 2번(처형 타겟팅 범위)을 만족하는 동안 보스 머리 위에 '[F] 처형'을 표시합니다. (글자 Large) 평타나 회피 중이라 잠시 처형을 입력할 수 없을 때도 숨기지 않습니다.
- 조건을 벗어나거나 그로기가 끝나면 즉시 숨깁니다.

### 6. 화면 효과

| 효과 | 조건 | 표현 |
| - | - | - |
| 패리 성공 | 플레이어가 패리에 성공 | 화면 전체에 플래시 0.1초. 화면을 가리지 않을 만큼 옅게 표시합니다. |
| 극한 회피 | 플레이어가 극한 회피에 성공 | 화면 가장자리에 플래시 0.3초. 가장자리를 감싸는 모양이면 형태는 구현에 맡깁니다. |

### 7. 대미지 숫자

- 플레이어가 보스에게 준 HP 감소량을, 공격 판정이 보스에게 닿은 위치에 정수로 표시합니다. 처형은 보스의 캡슐 중심에 표시합니다.
- 대미지 숫자는 전용 글자입니다. 스킬·궁극기·처형은 Size 36, 그 밖에는 Size 24로 표시합니다.
- 0.8초 동안 일정한 속도로 0.5m 떠오르면서 점점 투명해져 사라집니다. 같은 자리에 연달아 나와 겹쳐도 따로 흩지 않습니다.
- 플레이어가 받은 대미지는 숫자로 표시하지 않습니다.

## 상황별 표시 규칙

| 상황 | 플레이어 상태, 슬롯 | 보스 상태 | 락온 마커, 처형 안내 |
| - | - | - | - |
| 전투 (페이즈 전환 연출 포함) | 표시 | 표시 | 조건에 따라 표시 |
| 처형 | 표시 | 표시 | 숨김 |
| 사망 연출 (플레이어·보스 모두, 연출이 시작되는 순간부터) | 숨김 | 숨김 | 숨김 |
| 결과 UI | 숨김 | 숨김 | 숨김 |

- 대미지 숫자와 화면 효과는 이 표와 관계없이, 나타난 것은 끝까지 재생합니다. 마지막 일격의 대미지 숫자도 표시합니다.
