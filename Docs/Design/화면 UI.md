# 화면 UI

타이틀 화면, 조작 안내 팝업, 결과 UI의 배치와 표시, 포커스와 조작 규칙을 정의합니다.

화면이 열리는 조건, 승패와 레벨 전환, Start·Try Again·Return to Title·Quit 버튼의 실행 결과는 [게임 플로우](<게임 플로우.md>)를 따릅니다. 전투 중 정보 표시는 [전투 HUD](<전투 HUD.md>)를 따릅니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

기준 해상도, 화면 여백, 글자 크기, 버튼 스타일은 [UI 스타일](<UI 스타일.md>)을 따릅니다.

## 타이틀 화면

LV_FrontEnd에 표시하는 화면입니다.

- 화면 위쪽 가운데에 게임 제목 'AG'를 크게 표시합니다. (전용 글자 Size 168)
- 제목 아래 가운데에 Start, Controls, Quit 버튼을 위에서부터 세로로 배치합니다. (글자 Large)
- 레벨이 열리면 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Start입니다.

### 조작 안내

보스전에 들어가기 전에 키 배치와 누르기·누르고 있기의 차이를 확인할 수 있도록 Controls 버튼으로 여는 팝업에 조작 안내를 표시합니다.

- 게임을 처음 실행했을 때와 결과 UI에서 타이틀로 돌아왔을 때 팝업은 닫힌 상태입니다. Controls 버튼을 실행하면 레벨 전환 없이 팝업을 엽니다.
- 팝업은 화면 가운데에 배치하고 화면 여백 안에 들어오게 합니다. 뒤의 타이틀 화면은 어둡게 표시합니다.
- 패널 위쪽에 제목 'Controls'을 Large로 표시합니다. 본문은 Medium으로 표시하며, 글자를 읽을 수 있는 어두운 배경과 안쪽 여백 24px을 둡니다.
- [플레이어 입력](<플레이어 입력.md>)의 '키 배치' 표에 있는 모든 행동을 표의 순서대로 표시합니다. 키 배치와 행동의 의미는 해당 문서를 따릅니다.
- 각 항목은 왼쪽에 키, 오른쪽에 행동 이름을 표시합니다. 모든 항목의 행동 이름은 같은 위치에서 시작하고, 키와 행동 이름 사이는 24px을 띄웁니다.
- 키 이름은 [UI 스타일](<UI 스타일.md>)의 '입력 키 표시'를 따릅니다. '누르고 있기'는 키 이름에 붙이지 않고 아래 설명에 표시합니다.
- 가드 / 패리와 회피 / 달리기는 해당 항목 바로 아래에 '키 배치' 표의 누르기·누르고 있기 설명을 Small로 표시합니다. 문서 링크나 참조 문구는 화면에 표시하지 않습니다.
- 안내의 모든 항목과 설명은 한 화면에서 읽을 수 있게 표시합니다. 설명이 길면 줄바꿈하며, 스크롤이나 페이지 전환은 사용하지 않습니다.
- 안내 본문은 읽기 전용입니다. 팝업 아래쪽 가운데에 'Confirm' 버튼을 Large로 표시하며, 팝업을 열면 이 버튼이 선택됩니다.
- 팝업이 열려 있는 동안 마우스 커서를 표시하고 팝업만 입력을 받습니다. 뒤의 타이틀 버튼은 선택하거나 실행할 수 없으며, 팝업 바깥을 클릭해도 닫히지 않습니다.
- Confirm 버튼을 실행하면 팝업을 닫고 타이틀의 Controls 버튼으로 선택을 되돌립니다. 닫는 입력으로 뒤의 버튼이 함께 실행되지는 않습니다. 다시 Controls 버튼을 실행하면 팝업을 다시 열 수 있습니다.
- 전투 HUD의 조작 안내는 [전투 HUD](<전투 HUD.md>)를 따릅니다.

## Stage Clear UI / Game Over UI

| 항목 | Stage Clear UI | Game Over UI |
| - | - | - |
| 제목 문구 | STAGE CLEAR | GAME OVER |
| 버튼 | Try Again, Return to Title, Quit (세로 배치) | Try Again, Return to Title, Quit (세로 배치) |

- 글자 크기는 제목 Size 84(전용 글자), 버튼 Large입니다.
- 사망 연출이 끝나면 0.5초 동안 화면을 서서히 어둡게 하면서 결과 UI를 서서히 표시합니다. 버튼 입력은 표시가 끝난 뒤부터 받습니다.
- 결과 UI가 떠 있는 동안 게임은 멈추지 않으며, 플레이어 입력은 UI만 받습니다. 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Try Again입니다.

## UI 조작

| 동작 | 키 |
| - | - |
| 버튼 선택 | 마우스 이동, 또는 ↑·↓ |
| 실행 | 좌클릭, 또는 Enter, Space |
| 조작 안내 팝업 닫기 | Confirm 버튼 실행 |

- 맨 위나 맨 아래 버튼에서 더 넘어가는 방향을 누르면 선택이 그대로 멈춥니다. 반대쪽 끝으로 돌아가지 않습니다.
- 마우스와 키보드를 섞어 쓰면 마지막으로 움직인 장치를 따릅니다. 마우스를 버튼 위로 움직이면 그 버튼이 선택되고, 키보드는 지금 선택된 버튼에서 이어서 움직입니다.
