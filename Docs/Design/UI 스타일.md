# UI 스타일

전투 HUD와 화면 UI에 함께 적용하는 화면 기준, 글자, 버튼의 스타일을 정의합니다. 각 화면 문서는 글자 크기를 이 문서의 단계 이름(예: Large)으로 적습니다.

화면별 사용처는 [전투 HUD](<전투 HUD.md>)와 [게임 플로우](<게임 플로우.md>)를 따릅니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 화면 기준

| 항목 | 내용 |
| - | - |
| 기준 해상도 | 1920 × 1080. 다른 해상도에서는 화면의 짧은 변 길이에 맞춰 UI 전체의 크기를 함께 조절하며, 요소 간 크기 비율과 각 화면에서 정한 배치 기준을 유지합니다. |
| 화면 여백 | 화면 가장자리에 붙는 요소는 가장자리에서 48px 안쪽에 배치합니다. |
| 크기 단위 | 바, 슬롯, 여백 등 글자가 아닌 크기는 px로 적습니다. px는 기준 해상도에서의 크기입니다. |
| 입력 키 표시 | 키보드·마우스 기준으로 표시합니다. (예: E, R, F) 지원하는 조작 장치는 [게임 개요](<게임 개요.md>)를 따릅니다. |

## 글자

| 항목 | 내용 |
| - | - |
| 언리얼 Size | 언리얼 엔진 폰트의 Size 값으로, 언리얼에 입력하는 값입니다. 기획서의 글자 크기는 이 값을 기준으로 합니다. 언리얼은 폰트 크기를 96 DPI 기준으로 처리하므로 px × 0.75입니다. |
| 최소 크기 | Small(Size 15, 20px)보다 작은 글자는 쓰지 않습니다. Xbox 접근성 가이드라인의 PC 최소 기준(1080p에서 글자 높이 18px)보다 조금 크게 잡았습니다. |
| 크기 간격 | 언리얼 Size는 3의 배수로 정해 px가 4의 배수(정수)가 되게 합니다. |
| 글꼴 | 마일스톤1에서는 엔진 기본 글꼴(Roboto)을 씁니다. 글꼴 에셋은 추가하지 않습니다. |

### 크기 단계

| 단계 | 언리얼 Size | px |
| - | - | - |
| Small | 15 | 20 |
| Medium | 18 | 24 |
| Large | 24 | 32 |

- px는 시안(SVG)과 비교하기 위한 참고 값입니다.
- 새 글자를 추가할 때는 가까운 단계를 먼저 씁니다. 여러 곳에서 반복해서 쓰는데 맞는 단계가 없을 때만 단계를 추가하고, 한 곳에서만 쓰는 글자는 전용 글자로 둡니다.

### 전용 글자

한 곳에서만 쓰고 크기, 색상, 굵기가 따로 정해진 글자는 크기 단계에 넣지 않습니다. 크기는 정의 문서에 언리얼 Size로 적습니다. (예: Size 168)

| 글자 | 정의 문서 |
| - | - |
| 게임 제목 | [게임 플로우](<게임 플로우.md>)의 타이틀 화면 |
| 결과 UI 제목 | [게임 플로우](<게임 플로우.md>)의 Stage Clear UI / Game Over UI |
| 대미지 숫자 | [전투 HUD](<전투 HUD.md>)의 대미지 숫자 |

## 버튼

화면 UI의 모든 버튼에 적용합니다.

- 선택된 버튼은 선택되지 않은 버튼보다 밝은 배경, 굵은 테두리, 굵은 글자로 구분합니다.
- 버튼의 크기와 모양은 각 화면의 그림을 따릅니다.
