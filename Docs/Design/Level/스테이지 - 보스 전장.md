# 스테이지 - 보스 전장

보스전이 진행되는 레벨인 LV_BossStage의 구성, 보스 아레나, 배치 요소를 정의합니다.

보스전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_BossStage |
| 환경 | 엔진 제공 샘플 레벨 Lvl_Combat의 지형, 조명, 하늘, 안개 |
| 등장 적 | 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 회복 수단 | 없음 |

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 샘플의 적 스포너, 훈련용 허수아비, 파괴 가능한 상자, 체크포인트 볼륨, 활성화 볼륨은 없습니다.

## 보스 아레나

보스전이 진행되는 구역입니다.

| 항목 | 조건 |
| - | - |
| 크기 | 장애물이 없는 평지, 최소 30m × 30m |
| 바닥 | 높이차, 경사, 구멍이 없어야 합니다. |
| 장애물 | 없음. 보스의 돌진과 도약 패턴, 카메라가 지형에 걸리지 않게 합니다. |
| 경계 | 방의 벽으로 막습니다. 플레이어와 보스 모두 통과할 수 없습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고) |
| 입구 | 방의 입구(폭 약 5m)는 보이지 않는 벽으로 막습니다. |

- 아레나는 Lvl_Combat의 원형 단상 방(내부 약 33m × 33m)이며, 방 전체 바닥이 단상 윗면 높이의 평지입니다. 샘플의 용암 바닥, 입구 쪽 통로 블록, 단상 가운데의 얇은 원판은 없습니다.

## 배치 요소

![보스 스테이지 배치](<../../Art/Attachments/보스 스테이지 배치.png>)

- LV_BossStage를 위에서 내려다본 캡처입니다. 오른쪽(+X)이 아레나 안쪽입니다.

| 기호 | 요소 | 위치와 설정 |
| - | - | - |
| P | 플레이어 시작 지점 | 아레나 중심(C). 보스를 바라보며, 보스의 시야 안이고 지형에 가려지지 않는 곳에 둡니다. |
| G | 아레나 입구 | 보이지 않는 벽으로 막습니다. |
| C | 아레나 중심 | 플레이어 시작 지점이자 보스 시작 위치(B)를 정하는 기준점입니다. |
| B | 보스 시작 위치 | 중심에서 입구 반대편으로 8m. 플레이어를 바라봅니다. |
