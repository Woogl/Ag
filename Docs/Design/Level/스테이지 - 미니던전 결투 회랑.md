# 스테이지 - 미니던전 결투 회랑

> 이 문서는 AI가 기획한 미니던전입니다. 던전 선정, 구간 구성, 적 배치, 수치를 AI가 정했고 담당 기획자가 검토했습니다.

미니던전 '결투 회랑'의 레벨인 LV_DuelCorridor의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 별도의 기능 구현 없이 그레이박스 지형, 동선, 적 배치만으로 재미를 만드는 것을 전제로 합니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)을 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 설계 의도

이 던전은 패리, 회피, 가드 같은 근접 전투의 손맛을 정면으로 즐기게 하는 것이 목적입니다. 한 번에 상대하는 적을 1~2명으로 묶어 두고, 방을 지날 때마다 상황을 하나씩 어렵게 만들어 마지막에 커스터와의 1:1로 이어지게 합니다.

적이 두 종류뿐이고 별도의 장치가 없으므로, 같은 적을 어떤 지형의 어떤 자리에서 만나게 하느냐로 교전마다 변화를 줍니다.

- **선제 기회:** 결투방 1의 적은 출구 쪽을 향해 등을 보이고 서 있습니다. 조용히 다가가면 먼저 때릴 수 있습니다.
- **지형:** 결투방 1은 빈 방, 결투방 2는 기둥, 결투방 3은 높은 단상으로 방마다 지형을 하나씩 바꿉니다.
- **흐름 깨기:** 방 → 통로 → 방의 리듬이 익숙해질 즈음 통로 2에서 매복으로 한 번 흐름을 깹니다.

7분 남짓의 짧은 던전이므로 중심은 결투입니다. 탐험은 결투 사이의 양념으로, 다음 방을 엿보는 난간 하나와 매복을 뒤집는 샛길 하나만 둡니다. 보상 아이템은 마일스톤 범위 밖이므로, 샛길의 보상은 '유리하게 시작하는 싸움'입니다.

- **결투장 아치:** 보스 아레나 안쪽 끝, 커스터의 등 뒤로 던전에서 가장 높은 아치가 솟아 있습니다. 천장이 없어 어느 방에서든 벽 너머로 아치가 보이며, 마지막 결투가 기다리는 곳을 처음부터 알려 줍니다. 대기 공간에서는 통로 너머로 커스터가 아치 아래에 서 있는 모습이 함께 보입니다.
- **엿보기 난간:** 통로 1의 벽 한 구간이 허리 높이 난간으로 트여 결투방 2를 들여다볼 수 있습니다. 들어가기 전에 적과 기둥의 위치를 보고 어느 쪽부터 상대할지 미리 계획하게 합니다.
- **매복 뒤집기:** 결투방 2를 끝내고 방을 둘러본 플레이어만 구석의 좁은 샛길을 발견합니다. 샛길은 통로 2의 매복한 적 등 뒤로 이어져, 기습당하는 쪽이 아니라 기습하는 쪽이 됩니다.
- **방 모양:** 결투방 1은 둥근 결투장, 결투방 2는 기둥이 선 정사각형 방, 결투방 3은 끝에 단상이 있는 길쭉한 방으로, 지형뿐 아니라 방의 모양도 서로 다르게 둡니다.

난이도는 결투방 1(근거리 1명) → 매복(근거리 1명) → 결투방 2(근거리 2명) → 결투방 3(근거리 1명 + 원거리 1명) → 커스터 순서로 올라갑니다.

'결투'가 깨지지 않으려면 한 방의 적만 전투에 들어와야 합니다. 이 던전에는 출입구를 막는 장치가 없으므로, 방과 방 사이의 통로를 두 번 꺾어 앞 방에서 다음 방의 적이 보이지 않게 하는 것으로 이를 지킵니다.

대기 공간에서는 통로 너머로 커스터가 서 있는 모습이 보입니다. 커스터의 시야 밖이라 전투는 시작되지 않으며, 들어가기 전에 마지막 상대를 미리 보여 줍니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 던전 전체의 바닥은 같은 높이의 평지입니다. 결투방 3의 단상과 경사로만 예외입니다.
- 벽은 높이 4m 이상으로 만들어 플레이어가 점프로 넘을 수 없게 합니다. 천장은 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 통로의 폭은 모두 약 5m입니다. 샛길만 약 1.5m입니다.
- 큰 길은 하나이며, 시작 지점에서 보스 아레나까지의 이동 거리는 약 135m입니다. 샛길은 하나뿐이고 통로 2에서 큰 길과 다시 합쳐집니다.

### 결투방 1

근거리 일반 적의 공격 패턴을 익히는 방입니다. 장애물이 없어 적에게만 집중할 수 있습니다.

적은 방 안쪽에서 출구를 바라보고 서 있어 입구에는 등을 보입니다. 들키지 않고 다가가 먼저 공격할 수도 있고, 정면으로 마주해 싸울 수도 있습니다.

| 항목 | 조건 |
| - | - |
| 모양과 크기 | 장애물이 없는 원형 평지, 지름 약 14m |
| 적 | 근거리 일반 적 1명. 입구에서 약 11m 안쪽, 입구와 출구를 잇는 가운데 줄 위에서 출구를 바라봅니다. |
| 입구와 출구 | 입구는 시작 통로 쪽, 출구는 맞은편에 둡니다. 둘 다 입구와 출구를 잇는 가운데 줄 위에 있습니다. |

### 통로 1

| 항목 | 조건 |

| 모양 | 두 번 꺾인 통로. 결투방 1의 출구와 결투방 2의 입구가 옆으로 약 10m 어긋납니다. |
| 길이 | 중심선 기준 약 20m |
| 엿보기 난간 | 두 번째 직선 구간의 결투방 2 쪽 벽. 결투방 2의 입구 아래쪽(-Y) 가장자리에서 1m 떨어진 곳부터 폭 약 4.5m 구간의 벽을 높이 약 1.2m의 난간으로 틉니다. 난간 앞은 통로가 방 쪽으로 약 2.5m 넓어져 설 자리가 있습니다. 난간은 플레이어만 막고(점프 최고 높이 약 0.73m로 넘을 수 없음) 시선은 막지 않습니다. 난간 너머로 결투방 2의 오른쪽 적과 두 기둥이 보이고, 두 기둥 사이로 왼쪽 기둥 뒤 적도 보여야 합니다. |
| 시야 | 결투방 1 안에서 결투방 2의 적 위치가 보이지 않아야 합니다. 적은 엿보기 난간 너머를 보지 못합니다. |
| 적 | 없음 |

### 결투방 2

두 적을 함께 상대하는 방입니다. 기둥 뒤로 돌아 한 명의 시야를 끊고 다른 한 명부터 상대하는 식으로, 지형을 써서 2:1을 1:1 두 번으로 나누게 합니다.

한 명은 오른쪽(-Y)에 서서 입구에서 바로 보이고, 다른 한 명은 왼쪽(+Y) 기둥 바로 뒤에 서 있어 입구에서는 기둥에 가려 보이지 않습니다. 플레이어가 입구 쪽에 머물며 오른쪽 적과 싸우는 동안은 기둥이 기둥 뒤 적의 시선을 막고, 가운데 길을 따라 기둥을 지나쳐 들어가면 기둥 뒤 적이 시야에 들어와 합류합니다. 기둥이 큰 만큼 기둥 뒤로 돌아 오른쪽 적을 먼저 상대하는 선택이 분명해집니다.

| 항목 | 조건 |
| - | - |
| 크기 | 평지, 약 16m × 16m |
| 기둥 | 약 3m × 3m, 벽과 같은 높이의 기둥 2개. 방 중심에서 입구 쪽으로 3m, 좌우로 각각 4m. 입구에서 출구로 가는 가운데 길(폭 약 5m)은 비워 둡니다. |
| 적 | 근거리 일반 적 2명. 오른쪽 적은 입구에서 약 11.7m 떨어져 입구에서 보입니다. 왼쪽 적은 입구에서 약 8.9m이지만 왼쪽 기둥 바로 뒤에 있어 입구에서는 기둥에 가려 보이지 않습니다. |
| 샛길 입구 | 출구 쪽 오른쪽(-Y) 모서리, 출구 쪽 벽에서 약 1.5m 떨어진 오른쪽 벽에 폭 약 1.5m의 좁은 틈. 입구에서는 오른쪽 기둥에 가려 잘 보이지 않습니다. |
| 입구와 출구 | 입구는 통로 1 쪽 벽의 가운데, 출구는 맞은편 벽의 가운데에 둡니다. |

### 통로 2

결투방 2와 결투방 3을 잇는 통로입니다. 모양과 길이는 통로 1과 같으며, 꺾이는 방향은 반대입니다.

| 항목 | 조건 |
| - | - |
| 매복 | 첫 번째 모퉁이를 돌면 약 7m 앞에 근거리 일반 적 1명이 플레이어 쪽을 바라보고 서 있습니다. |
| 시야 | 결투방 2 안과 통로 2의 첫 직선 구간에서는 매복한 적이 보이지 않아야 합니다. |

### 샛길

결투방 2의 샛길 입구에서 통로 2의 두 번째 모퉁이로 이어지는 좁은 길입니다. 고르지 않아도 되는 길이며, 고르면 매복한 적의 등 뒤로 나와 먼저 공격할 수 있습니다.

| 항목 | 조건 |
| - | - |
| 폭 | 약 1.5m. 양옆은 벽으로 막혀 있습니다. |
| 경로 | 샛길 입구에서 오른쪽(-Y)으로 약 7m → 왼쪽(+X)으로 꺾어 약 7m → 왼쪽(+Y)으로 꺾어 약 2m 뒤 통로 2의 두 번째 모퉁이 바깥 벽으로 나옵니다. |
| 나오는 곳 | 매복한 적의 약 5m 뒤. 매복한 적은 첫 번째 모퉁이를 바라보고 있어 등을 보입니다. |
| 적 | 없음 |

- 샛길 안에서는 매복한 적과 결투방 3의 적이 플레이어를 볼 수 없어야 합니다.

### 결투방 3

근거리 일반 적이 앞을 막는 동안 단상 위에 원거리 적이 서 있는 방입니다. 근거리 적을 먼저 처리할지, 경사로로 올라가 원거리 적을 먼저 끊을지 플레이어가 고르게 합니다.

| 항목 | 조건 |
| - | - |
| 모양과 크기 | 입구에서 출구 방향으로 길쭉한 직사각형, 약 22m × 14m |
| 단상 | 출구 쪽 왼쪽(+Y) 모서리에 약 6m × 6m, 높이 1.5m. 점프(최고 높이 약 0.73m)로는 오를 수 없습니다. |
| 경사로 | 단상에서 입구 방향으로 왼쪽 벽을 따라 길이 약 6m, 폭 약 2m |
| 적 | 근거리 일반 적 1명, 원거리 일반 적 1명 |
| 입구와 출구 | 입구는 통로 2 쪽 벽의 가운데, 출구는 맞은편 벽의 가운데에 둡니다. 단상이 출구를 가리지 않게 합니다. |

### 보스 아레나

커스터와 싸우는 구역입니다. 크기, 바닥, 장애물, 경계는 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)의 '보스 아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 33m (보스 전장의 원형 단상 방 내부와 같은 크기) |
| 입구 | 대기 공간 쪽 벽의 가운데, 폭 약 5m |
| 결투장 아치 | 입구 반대편 벽의 가운데에 선 아치, 폭 약 10m, 높이 약 15m. 아치 안쪽은 벽으로 막혀 있어 지나갈 수 없고, 커스터 시작 위치(B)는 아치에서 약 8.5m 앞입니다. 시작 통로와 각 결투방에서 벽 너머로 보이도록 높이를 정합니다. 올라갈 수 없습니다. |
| 커스터의 시야 | 입구에서 약 5m 들어오면 커스터의 시야(20m)에 들어갑니다. |

## 미확정 항목

일반 적의 기획이 나오기 전에 정한 값이 있어, 아래는 적이 확정되거나 플레이해 본 뒤 조정합니다.

- **결투방 크기:** 근거리 일반 적의 공격 사거리와 이동 속도를 보고 조정합니다. 회피로 거리를 벌릴 여유가 있으면서, 적과 멀어져 전투가 늘어지지 않는 크기를 찾습니다.
- **적의 시야:** 결투방의 적은 플레이어가 입구에 들어섰을 때 전투에 들어가는 것을 전제로 배치했습니다. 근거리 일반 적의 시야는 12m, 정면 각도는 120°입니다 ([근거리 일반 적 Spec](<../../../Specs/근거리 일반 적/1-spec.md>)). 결투방 2의 오른쪽 적은 입구에서 약 11.7m, 결투방 3의 근거리 적은 약 11m로 시야 안입니다. 결투방 2의 기둥 뒤 적은 약 8.9m로 거리상 시야 안이지만 기둥에 가려 보이지 않으므로, 이 적은 거리가 아니라 기둥의 가림에 기대고 있습니다. 시야 값이 줄면 오른쪽 적을 입구 쪽으로 옮깁니다. 원거리 일반 적은 단상에서 입구까지 약 20m를 볼 수 있어야 합니다.
- **기둥 뒤 적의 합류:** 오른쪽 적과 싸우는 동안 기둥 뒤 적이 그 소란에 반응해 합류하는지는 적 AI에 달렸습니다. 반응하지 않고 계속 서 있으면 플레이어가 지나쳐 들어가야만 만나게 되므로, 기둥 뒤 적의 위치를 기둥 가장자리 쪽으로 당겨 자연스럽게 시야에 들어오게 합니다. 반대로 소란에 곧바로 합류해 1:1이 깨지면 기둥을 더 키우거나 두 적의 간격을 벌립니다.
- **엿보기 난간과 기둥 뒤 적:** 난간에서 기둥 뒤 적이 보이는 각도는 왼쪽 기둥의 모서리를 약 0.4m 비켜 지나는 좁은 틈입니다. 서 있는 자리에 따라 가려지면 난간 폭을 넓히거나 기둥 뒤 적을 기둥 모서리에서 더 떨어뜨립니다. 반대로 입구에서도 보이면 기둥 뒤 적을 기둥 쪽으로 붙입니다.
- **엿보기 난간:** 적의 시야가 난간 너머로 새면 난간 너머의 적이 플레이어를 보고 통로로 몰려옵니다. 그레이박스에서 난간이 적의 시야를 막는지 확인합니다.
- **샛길의 발견:** 기둥에 가려 아무도 샛길을 못 찾으면, 틈 주변 바닥이나 벽의 색을 달리해 눈에 띄게 합니다.
- **결투방 1의 선제 기회:** 들키지 않고 다가갈 수 있는지는 근거리 일반 적의 시야와 걷는 속도에 달렸습니다. 시작 통로에서 적에게 들키면 시작 통로를 꺾습니다.
- **기둥과 카메라:** 결투방 2의 기둥에 락온 카메라가 자주 걸리면 기둥을 가늘게 하거나 벽 쪽으로 옮깁니다.
- **적이 줄어든 만큼의 밀도:** 적이 근거리 5명, 원거리 1명이라 방마다 한 번의 교전이 짧습니다. 플레이해 보고 너무 싱거우면 방의 모양과 기둥, 단상의 배치로 밀도를 올립니다.
- **잠긴 아레나가 없는 보스 아레나:** 출입구를 막는 장치가 없어 커스터의 돌진이 통로 4로 빠져나갈 수 있습니다. 플레이해 보고 문제가 되면 아레나 입구의 지형을 바꿉니다.
