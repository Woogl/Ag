# 스테이지 - 미니던전 콜로세움

미니던전 '콜로세움'의 레벨인 LV_Colosseum의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 그레이박스 지형, 동선, 적 배치로 재미를 만드는 것을 전제로 하며, 기능 구현이 필요한 요소는 성문 하나뿐입니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_Colosseum |
| 컨셉 | 지하 감방에서 출발해 관중석이 둘러싼 구덩이를 지나고, 관중석 맨 위에서 외곽 회랑과 출전 광장을 거쳐 원형 투기장에 들어갑니다. 높이가 다른 단을 오르내리며 싸우는 던전입니다. 플레이어는 관중석 단을 점프로 오르고 회랑에서 광장으로 뛰어내리지만, 적은 경사로와 계단으로 돌아와야 합니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 다른 스테이지 레벨과 같습니다. |
| 등장 적 | 근거리 일반 적 9명, 원거리 일반 적 4명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 약 7분 (이동 약 1분, 일반 교전 합계 약 3분, 커스터전 약 3분) |

| 체크포인트 | 없음 |
| 레벨에 배치하는 회복 수단 | 없음 |

레벨을 돌려 보며 높이를 확인하려면 [콜로세움 3D](<콜로세움 3D.html>)를 브라우저로 엽니다.

## 설계 의도

콜로세움은 높이가 다른 단을 오르내리며 싸우는 던전입니다. 플레이어는 점프와 낙하로 단을 곧장 오르내리지만 적은 경사로와 계단으로 돌아야 하므로, 높이를 쓰는 플레이어는 위에서 쏘는 사수에게 먼저 닿거나 쫓아오는 근거리 적을 떼어 놓을 수 있습니다.

재미 요소는 아래와 같습니다. 성문을 빼면 모두 지형과 적 배치만으로 만들어집니다.

- **감방 앞의 매복:** 지하 통로 양옆의 감방 벽이 시야를 가려, 감방 안의 근거리 적은 플레이어가 감방 바로 앞에 와서야 보고 뛰어나옵니다. 좁은 통로에서 옆에서 덮치는 적을 하나씩 상대합니다.
- **관중석 오르기:** 구덩이를 둘러싼 관중석 단은 한 단이 0.75m라 플레이어는 점프로 오르지만, 적은 대각선 네 곳의 통로 경사로로만 단을 오르내립니다. 맨 위 회랑 단의 사수 둘이 구덩이를 내려다보며 쏘고, 출구는 구덩이 맞은편 맨 위에 있습니다. 단을 곧장 뛰어올라 사수에게 가면 근거리 적은 경사로로 돌아오느라 늦습니다.
- **훈련 기둥:** 구덩이의 기둥 넷이 사수의 사격을 잠깐 끊습니다. 두 사수가 마주 보고 있어, 한쪽 사수를 가리면 다른 쪽 사수에게 겨눠지기 쉽습니다.
- **기둥 사이로 뛰어내리기:** 외곽 회랑은 4.5m 아래 출전 광장을 끼고 지나고, 광장의 사수가 회랑의 기둥 사이로 쏩니다. 기둥 사이로 뛰어내리면 회랑의 근거리 적을 떼어 놓고 사수에게 먼저 갈 수 있습니다. 끝까지 걸어 계단으로 내려가면 성문 앞 근거리 적과 바로 만납니다.
- **내 손으로 여는 성문:** 출전 광장의 성문을 직접 열고 커스터에게 갑니다.

린의 스킬 1은 이 던전에서 있으면 편한 보조 수단입니다. 어느 구간도 스킬 1 없이 걸어서 풀 수 있어야 합니다.

구간의 모양도 서로 다르게 둡니다. 지하 감방은 감방이 딸린 좁은 일자, 관중석은 원형 구덩이와 그 둘레를 오르는 단, 외곽 회랑은 한쪽이 트인 높은 길, 출전 광장은 네모, 보스 아레나는 원형입니다.

난이도는 지하 감방(근거리 3명, 따로따로) → 관중석(근거리 3명 + 원거리 2명) → 외곽 회랑(근거리 1명 + 광장 사수의 사격) → 출전 광장(근거리 2명 + 원거리 2명) → 커스터 순서로 이어집니다. 외곽 회랑은 관중석과 출전 광장 사이에서 사격을 받으며 지나가는 짧은 구간입니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 길을 막는 장치는 성문 하나뿐입니다. 성문 앞까지는 구간 사이에 문을 두지 않아, 플레이어는 적을 남겨 둔 채 다음 구간으로 지나갈 수 있습니다.
- 바닥 높이는 지하 감방이 -3m, 관중석 구덩이와 출전 광장, 통로, 보스 아레나가 0m입니다. 관중석 단은 0.75m에서 3.75m까지 0.75m씩 높아지고, 관중석 맨 위의 회랑 단과 외곽 회랑은 4.5m입니다. 구간 사이는 계단과 경사로로 잇습니다.
- 벽은 지하 감방이 바닥에서 6m, 관중석 바깥 벽이 회랑 단에서 4m, 외곽 회랑의 왼쪽 벽이 4m, 출전 광장이 8.5m, 통로와 보스 아레나가 6.5m이며, 점프로 넘을 수 없습니다. 천장은 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 관중석 단과 단 사이의 0.75m는 플레이어가 점프(최고 높이 약 1.2m)로 오르내립니다. 적은 이 높이를 오르내리지 못해 통로 경사로로만 다른 단에 갑니다.
- 떨어지는 높이는 회랑 단이나 외곽 회랑에서 뛰어내리는 4.5m가 가장 커서, 레벨 어디에서도 낙하 대미지를 받지 않습니다.
- 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 바닥 위에 서고, 뒤쪽 벽에서 3m 이상 떨어뜨려 둡니다. 린의 스킬 1은 대상의 등 뒤 3m에 나타나므로, 그 자리에 바닥이 있어야 합니다.
- 장애물은 훈련 기둥과 회랑 기둥 두 가지입니다. 둘 다 시선과 탄환을 가리며 점프로 넘을 수 없습니다.
- 큰 길은 하나이며, 시작 지점에서 보스 아레나 중심까지의 이동 거리는 약 176m입니다.

## 구간

### 지하 감방

검투사가 갇혀 있던 지하 통로입니다. 좁은 통로 양옆으로 감방이 번갈아 나 있고, 감방 안의 근거리 적이 통로를 지나는 플레이어에게 옆에서 덤벼듭니다.

| 항목 | 조건 |
| - | - |
| 크기 | 폭 5m, 길이 약 40m의 곧은 통로 (높이 -3m). 시작 지점은 통로의 막힌 끝에 있습니다. |
| 감방 | 5칸 (폭 3m, 깊이 3m). 시작 쪽 벽에서 약 10m(왼쪽), 16m(오른쪽), 22m(왼쪽), 28m(오른쪽), 34m(왼쪽)부터 나 있습니다. |
| 적 | 근거리 일반 적 3명 (오른쪽 첫 칸, 왼쪽 둘째 칸, 오른쪽 둘째 칸 안. 통로 쪽을 바라봅니다.) 왼쪽 첫 칸과 왼쪽 셋째 칸은 비어 있습니다. |
| 출구 | 통로 끝의 계단(폭 5m, 길이 약 4.5m, 한 단 20cm)으로 3m 올라 관중석의 입구 통로로 이어집니다. |

- 감방 안의 근거리 적은 감방 벽에 가려, 플레이어가 그 감방 입구 약 2m 앞에 와야(약 5.3m 거리) 플레이어를 봅니다.

### 관중석

이 던전의 첫 번째 큰 싸움입니다. 원형 구덩이를 관중석 단이 둘러싸고, 맨 위 회랑 단의 좌우에서 사수 둘이 구덩이를 내려다봅니다. 플레이어는 구덩이 바닥에서 들어와 맞은편 맨 위의 출구로 나갑니다.

입구 통로를 나서면 구덩이의 근거리 적이 다가오고, 좌우의 사수가 쏩니다. 플레이어는 구덩이에서 근거리 적을 상대하거나, 단을 곧장 뛰어올라 한쪽 사수에게 갈 수 있습니다. 근거리 적은 통로 경사로로 돌아 올라오므로 늦게 따라옵니다.

| 항목 | 조건 |
| - | - |
| 크기 | 지름 24m의 원형 구덩이(높이 0m)를 관중석 단 다섯 개(깊이 1.5m, 높이 0.75 ~ 3.75m)와 맨 위 회랑 단(깊이 4.5m, 높이 4.5m)이 둘러쌉니다. 바깥 벽 안쪽 지름은 48m입니다. |
| 입구 통로 | 관중석의 시작 쪽(-X)을 가르는 폭 5m, 길이 약 13m의 통로입니다. 지하 감방의 계단에서 구덩이 바닥으로 곧장 들어갑니다. |
| 통로 경사로 | 4개 (폭 2m, 기울기 약 27°). 구덩이에서 앞뒤 좌우의 대각선 네 방향으로 뻗어 회랑 단까지 오릅니다. 경사로는 단마다 그 단의 높이를 지나, 적은 경사로에서 어느 단으로든 드나듭니다. |
| 훈련 기둥 | 4개 (1.2m × 1.2m, 높이 2.5m). 구덩이 중심에서 대각선 네 방향으로 약 6.4m 떨어져 있습니다. |
| 근거리 적 | 3명. 둘은 구덩이 중심에서 입구 쪽으로 3m, 좌우로 2.5m씩. 하나는 중심에서 출구 쪽으로 6m. 모두 입구 쪽을 바라봅니다. |
| 원거리 적 | 2명. 회랑 단의 왼쪽과 오른쪽 가운데, 단 가장자리에서 1m. 구덩이 중심을 바라봅니다. 둘 사이는 약 41m입니다. |
| 출구 | 맞은편(+X) 회랑 단의 바깥 벽에 난 폭 5m의 문. 외곽 회랑으로 그대로 이어집니다. |

- 플레이어가 입구 통로 끝 약 3m 앞에 오면 구덩이의 근거리 적 둘(약 11.8m)과 사수 둘(약 25.8m)이 플레이어를 봅니다. 구덩이 안쪽의 근거리 적은 플레이어가 구덩이에 약 6m 들어오면 봅니다.
- 구덩이 바닥의 거의 모든 곳(약 97%)이 두 사수 가운데 적어도 하나에게 보입니다. 훈련 기둥 뒤에서는 한쪽 사수의 사격이 끊기고, 구덩이 중심에서 입구 쪽과 출구 쪽으로 약 5 ~ 6m, 기둥 두 개 너머의 좁은 자리는 두 사수 모두에게서 가려집니다.
- 적은 이웃한 단으로도 경사로를 거쳐 가야 합니다. 두 경사로의 가운데에서는 바로 위 단의 플레이어에게 가는 데 약 21m를 돌아갑니다.

### 외곽 회랑

관중석 바깥을 따라 지나는 높은 길입니다. 오른쪽 아래 4.5m에 출전 광장이 있고, 광장의 사수가 회랑의 기둥 사이로 쏩니다.

| 항목 | 조건 |
| - | - |
| 크기 | 폭 6m, 길이 약 28m의 곧은 길 (높이 4.5m). 관중석의 출구에서 그대로 이어집니다. |
| 왼쪽 | 높이 4m의 벽 |
| 오른쪽 | 처음 약 5m는 벽이고, 그 뒤로 기둥 4개(1.5m × 1.5m, 회랑 바닥에서 4m 높이)가 5m 간격으로 섭니다. 벽과 기둥 사이, 기둥과 기둥 사이 약 3.5m씩은 트여 있어 아래 출전 광장으로 뛰어내릴 수 있습니다. |
| 적 | 근거리 일반 적 1명 (회랑 가운데. 관중석 출구 쪽을 바라봅니다.) |
| 출구 | 회랑 끝에서 오른쪽으로 내려가는 계단(폭 5m, 길이 약 7.6m, 한 단 25cm)으로 출전 광장에 내려갑니다. |

- 플레이어가 처음 벽 구간을 지나 첫 트인 곳에 오면 회랑의 근거리 적(약 11.9m)과 광장의 사수 둘(약 24.5m, 약 29.8m)이 플레이어를 봅니다.
- 트인 곳에서는 광장의 사수에게 겨눠지고, 기둥 바로 뒤(회랑 오른쪽 가장자리)에서는 한쪽이나 두 사수의 사격이 끊깁니다. 처음 벽 구간 뒤에서는 두 사수 모두 쏘지 못합니다.
- 적은 회랑에서 광장으로 뛰어내리지 못하고, 회랑의 근거리 적은 계단 쪽으로 돌아갑니다(바로 아래 광장까지 약 37m). 플레이어가 회랑 벽 바로 아래에 있으면 회랑 가장자리에 가려 보이지 않으므로, 근거리 적은 계단에 닿기 전에 시야 상실 5초가 지나 비전투로 돌아가 처음 자리로 갑니다.

### 출전 광장

이 던전의 마지막 일반 교전입니다. 왼쪽 가장자리를 외곽 회랑이 4.5m 높이로 지나고, 안쪽 벽에 보스 아레나로 가는 성문이 있습니다. 사수 둘은 오른쪽 벽 앞에서 회랑을 바라보고, 근거리 적 둘은 성문 앞을 지킵니다.

회랑 끝의 계단으로 내려오면 계단 중간과 계단 끝에서 성문 앞 근거리 적 둘이 플레이어를 보고 다가옵니다. 회랑의 트인 곳으로 일찍 뛰어내리면 성문 앞 근거리 적의 시야(12m) 밖에 내려서므로, 근거리 적이 다가오기 전에 사수에게 먼저 갈 수 있습니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 30m × 22.5m의 평지 (높이 0m). 왼쪽 가장자리에 회랑의 기둥이 섭니다. |
| 입구 | 회랑 끝의 계단이 광장 안쪽(+X)의 왼쪽 구석에 내려옵니다. 회랑의 트인 곳으로 뛰어내려도 광장에 들어옵니다. |
| 근거리 적 | 2명. 성문 앞, 성문에서 약 8m. 회랑 쪽을 바라봅니다. |
| 원거리 적 | 2명. 오른쪽 벽에서 3.6m 앞, 서로 12m 떨어져 회랑 쪽을 바라봅니다. |
| 성문 | 안쪽(+X) 벽의 오른쪽 부분(성문 가운데가 오른쪽 벽에서 6m), 폭 5m. 처음에는 닫혀 있습니다. 아래 '성문'을 따릅니다. |

- 사수 둘은 계단 끝과 회랑에서 뛰어내리는 자리를 모두 봅니다.

#### 성문

출전 광장과 보스 아레나 사이를 막는 문입니다. 이 던전에서 플레이어가 상호작용하는 유일한 장치입니다. 처음 상태, 여는 조건, 안내, 상호작용 범위, 열리는 중과 열린 뒤, 재도전의 규칙은 [스테이지 - 미니던전 요새 돌파](<스테이지 - 미니던전 요새 돌파.md>)의 '성문'과 같습니다.

- 성문에서 가장 가까운 적(근거리 적)까지는 약 8m입니다.

### 보스 아레나

커스터와 싸우는 원형 투기장입니다. 성문을 지나 길이 8m, 폭 5m의 곧은 통로로 이어지며, 통로와 아레나는 출전 광장과 같은 높이(0m)입니다. 바닥, 장애물, 경계는 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 지름 약 36m의 원형 (벽 높이 6.5m) |
| 입구 | 통로 쪽 벽, 폭 5m |
| 시야 | 성문이 열리면 통로 너머로 아레나 안의 커스터가 보입니다. 성문에서 커스터까지 약 34m라 커스터의 시야(20m) 밖입니다. |
| 커스터의 시야 | 입구에서 약 6.5m 들어오면 커스터의 시야(20m)에 들어갑니다. |

- 따로 쉬어 가는 대기 공간은 두지 않습니다. 적을 정리한 출전 광장과, 성문을 열고 지나는 통로가 그 역할을 합니다.

## 높이 구성

-3m의 지하 감방에서 계단으로 3m 올라 관중석 구덩이(0m)에 들어가고, 관중석 단(0.75 ~ 3.75m)을 올라 맨 위 회랑 단(4.5m)에서 외곽 회랑으로 나갑니다. 외곽 회랑에서 계단으로 내려가거나 뛰어내려 출전 광장(0m)에 들어서며, 그 뒤로는 통로와 보스 아레나까지 같은 높이입니다.

## 미확정 항목

구간의 크기, 거리, 적의 수는 그레이박스를 만들기 전에 정한 값이라, 아래는 플레이해 본 뒤 조정합니다.

- **구간 크기와 거리:** 각 구간의 길이, 폭, 장애물의 자리와 간격, 적 사이의 거리는 플레이해 보고 조정합니다.
- **예상 플레이 시간:** 약 7분은 적의 수와 이동 거리로 어림한 값입니다. 플레이해 보고 고칩니다.
- **감방의 매복:** 감방의 근거리 적이 약 5m 거리에서야 플레이어를 보므로, 갑자기 덤벼드는 것이 반응할 틈 없이 느껴지지 않는지 확인합니다.
- **관중석 단 오르기:** 0.75m 단을 점프로 오르는 것이 편한지, 깊이 1.5m의 단 위에서 카메라와 싸움이 불편하지 않은지 확인합니다.
- **관중석의 두 사수:** 마주 보는 두 사수가 구덩이 거의 전부를 겨눠, 한쪽 사수에게 단을 오르는 동안 맞은편 사수에게 계속 맞는 것이 지나치게 어렵지 않은지 확인합니다. 어려우면 훈련 기둥을 늘리거나 사수를 하나로 줄입니다.
- **경사로를 오르는 근거리 적:** 근거리 적이 경사로로 단 위의 플레이어를 실제로 쫓아오는지, 단 가장자리에 붙은 플레이어를 아래 단에서 공격하는지 확인합니다.
- **회랑의 사격:** 광장의 사수 둘이 회랑을 쏘는 동안 회랑의 근거리 적과 싸우기가 지나치게 어렵지 않은지, 기둥 뒤에 숨는 것이 의미가 있는지 확인합니다.
- **뛰어내리기의 선택:** 회랑에서 광장으로 뛰어내리는 길과 계단으로 내려가는 길 가운데 한쪽만 고르게 되지 않는지 확인합니다. 회랑 벽 바로 아래로 뛰어내리면 회랑의 근거리 적이 플레이어를 놓치고 제자리로 돌아가, 그 적을 아예 따돌리게 됩니다. 이것이 지나치게 쉬운 길이 되는지 봅니다.
- **계단 위의 싸움:** 성문 앞 근거리 적이 계단 중간에서 플레이어를 보고 다가오므로 계단 위에서 싸우게 될 수 있습니다. 불편하면 근거리 적의 자리나 방향을 조정합니다.
- **구간을 지나치는 플레이:** 성문 앞까지는 길을 막는 장치가 없어 적을 무시하고 달려 지나갈 수 있습니다. 남겨 둔 적이 다음 구간까지 따라와 문제가 되면 구간 사이의 계단과 입구로 조정합니다.
- **보스 아레나에서 커스터의 이동:** 열린 성문은 다시 닫히지 않아 커스터의 돌진이 통로로 빠져나갈 수 있습니다. 플레이해 보고 정합니다.
