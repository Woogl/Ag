# 스테이지 - 시뮬레이션 룸

플레이어가 고른 적과 싸우는 전투 연습장 레벨인 LV_SimulationRoom의 구성과 적 배치 자리를 정의합니다.

적 선택과 배치, 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>)의 'Simulation Room'을 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_SimulationRoom |
| 환경과 아레나 | [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)의 '개요' 환경과 '보스 아레나' 조건을 그대로 따릅니다. |
| 레벨에 배치하는 적 | 없음. 적은 아래 '배치 자리'에 놓습니다. |
| 제한 시간, 체크포인트, 회복 수단 | 없음 |

## 배치 요소

![시뮬레이션 룸 배치](<../../Art/Attachments/시뮬레이션 룸 배치.png>)

- LV_SimulationRoom을 위에서 내려다본 캡처입니다. 오른쪽(+X)이 아레나 안쪽이고, 삼각형은 바라보는 방향입니다.

| 기호 | 요소 | 위치와 설정 |
| - | - | - |
| C | 아레나 중심 | 플레이어 시작 지점과 적 배치 자리를 정하는 기준점입니다. |
| P | 플레이어 시작 지점 | C에서 입구 쪽으로 5m. 입구 반대편(아레나 안쪽)을 바라봅니다. |
| 1 ~ 5 | 적 배치 자리 | 아래 '배치 자리' |

## 배치 자리

배치 자리는 아레나 중심(C)에서 캡슐 중심까지 수평 거리 8m이고, 플레이어 시작 방향을 0°로 한 각도는 아래와 같습니다.

| 배치 자리 | 1 | 2 | 3 | 4 | 5 |
| - | - | - | - | - | - |
| 각도 | 왼쪽 70° | 왼쪽 35° | 0° | 오른쪽 35° | 오른쪽 70° |
