# 스테이지 - 시뮬레이션 룸

플레이어가 고른 적과 싸우는 전투 연습장 레벨인 LV_SimulationRoom의 구성과 적 배치 자리를 정의합니다.

적 선택과 배치, 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>)의 'Simulation Room'을 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_SimulationRoom |
| 환경 | 엔진 제공 샘플 레벨 Lvl_Combat의 지형, 조명, 하늘, 안개 |
| 레벨에 배치하는 적 | 없음. 적은 아래 '배치 자리'에 놓습니다. |
| 제한 시간, 체크포인트, 레벨에 배치하는 회복 수단 | 없음 |

## 아레나

전투가 진행되는 구역입니다. 미니던전의 보스 아레나도 이 조건을 기준으로 합니다.

| 항목 | 조건 |
| - | - |
| 크기 | 장애물이 없는 평지, 최소 30m × 30m |
| 바닥 | 높이차, 경사, 구멍이 없어야 합니다. |
| 장애물 | 없음. 보스의 돌진과 도약 패턴, 카메라가 지형에 걸리지 않게 합니다. |
| 경계 | 방의 벽으로 막습니다. 플레이어와 적 모두 통과할 수 없습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고) |
| 입구 | 방의 입구(폭 약 5m)는 보이지 않는 벽으로 막습니다. |

- 아레나는 Lvl_Combat의 원형 단상 방(내부 약 33m × 33m)이며, 방 전체 바닥이 단상 윗면 높이의 평지입니다. 샘플의 용암 바닥, 입구 쪽 통로 블록, 단상 가운데의 얇은 원판은 없습니다.
- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 샘플의 적 스포너, 훈련용 허수아비, 파괴 가능한 상자, 체크포인트 볼륨, 활성화 볼륨은 없습니다.

## 배치 요소

![시뮬레이션 룸 배치](<../../Art/Attachments/시뮬레이션 룸 배치.png>)

- LV_SimulationRoom을 위에서 내려다본 캡처입니다. 오른쪽(+X)이 아레나 안쪽이고, 삼각형은 바라보는 방향입니다.

| 기호 | 요소 | 위치와 설정 |
| - | - | - |
| C | 아레나 중심 | 플레이어 시작 지점과 적 배치 자리를 정하는 기준점입니다. |
| P | 플레이어 시작 지점 | C에서 입구 쪽으로 5m. 입구 반대편(아레나 안쪽)을 바라봅니다. |
| 1 ~ 5 | 적 배치 자리 | 아래 '배치 자리' |

## 배치 자리

배치 자리는 아레나 중심(C)에서 캡슐 중심까지 수평 거리 8m이고, 플레이어 시작 방향을 0°로 한 각도는 아래와 같습니다.

| 배치 자리 | 1 | 2 | 3 | 4 | 5 |
| - | - | - | - | - | - |
| 각도 | 왼쪽 70° | 왼쪽 35° | 0° | 오른쪽 35° | 오른쪽 70° |
