# 스테이지 - 미니던전 요새 돌파

> 이 문서는 AI가 기획한 미니던전입니다. 던전 선정, 구간 구성, 적 배치, 수치를 AI가 정했고 담당 기획자가 검토했습니다.

미니던전 '요새 돌파'의 레벨인 LV_FortressBreach의 구성, 구간별 조건, 배치 요소를 정의합니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)을, 출입구 잠금과 2차 웨이브 규칙은 [스테이지 - 미니던전 결투 회랑](<스테이지 - 미니던전 결투 회랑.md>)의 '결투방 잠금'을 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_FortressBreach |
| 컨셉 | 원거리 적이 지키는 요새를 엄폐물과 투사체 반사로 뚫고 들어가, 성벽에서 안뜰로 뛰어내려 마지막 저항을 꺾은 뒤 커스터에게 도착합니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 LV_BossStage와 같습니다. |
| 등장 적 | 근거리 일반 적 4명, 원거리 일반 적 6명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 약 9분 (이동 약 45초, 일반 교전 합계 약 5분, 커스터전 약 3분) |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 회복 수단 | 없음 |

## 설계 의도

이 던전의 주인공은 원거리 일반 적입니다. 결투 회랑이 닫힌 방에서 근거리 적과 맞붙는 던전이라면, 요새 돌파는 탁 트인 공간에서 멀리서 쏘는 적에게 어떻게 다가갈지를 고민하는 던전입니다.

재미 요소는 아래와 같습니다.

- **반사 학습 곡선:** 전초에서 원거리 적 하나로 투사체 반사를 처음 익히고, 마당과 사격 통로를 거치며 점점 어려운 상황에서 반사를 쓰게 됩니다. 커스터의 검기(SwordWave)도 패리로 반사할 수 있어, 던전 전체가 커스터전의 예습이 됩니다.
- **올라갈까, 받아칠까:** 원거리 적은 모두 높은 곳에 있지만 경사로로 올라갈 수 있습니다. 경사로로 돌아 올라가 직접 베거나, 그 자리에서 투사체를 반사해 잡는 것 중 플레이어가 고릅니다.
- **교차 사격:** 마당에서는 원거리 적 둘이 양쪽 성벽에서 쏩니다. 엄폐물은 한쪽만 막아 주므로, 한쪽을 피하면 다른 쪽에 드러납니다. 멈춰 있지 말고 엄폐물 사이를 옮겨 다니게 합니다.
- **칸막이 사격 통로:** 좌우 벽에서 엇갈려 튀어나온 칸막이 사이를 지그재그로 지나갑니다. 칸막이 뒤에서는 안전하고 틈에서만 사수에게 보이므로, 숨었다 달리기를 되풀이하는 리듬이 생깁니다.
- **뛰어내리는 돌파:** 안뜰에는 문으로 들어가지 않고, 사격 통로 끝의 높은 단상에서 3m 아래로 뛰어내려 들어갑니다. 돌아갈 수 없는 한 걸음이라 '쳐들어간다'는 느낌을 줍니다.
- **남겨 둔 적의 대가:** 전초부터 사격 통로까지는 문이 잠기지 않아 적을 무시하고 달려 지나갈 수 있습니다. 다만 사격 통로의 사수를 살려 둔 채 뛰어내리면, 그 사수가 단상 위에서 안뜰 싸움 내내 쏩니다.
- **안뜰 2차 웨이브:** 안뜰 좌우 벽에는 처음부터 막힌 벽으로 이어지는 경사로가 보입니다. 1차 웨이브를 끝내면 그 벽이 열리며 좌우 발코니에 원거리 적이 나타나 마당의 교차 사격이 다시 시작되고, 정면 출구 옆에서는 근거리 적이 나옵니다.

난이도는 전초(원거리 1명) → 마당(근거리 1명 + 원거리 2명) → 사격 통로(원거리 1명) → 안뜰(근거리 2명, 이어서 원거리 2명 + 근거리 1명) → 커스터 순서로 올라갑니다. 사격 통로는 앞뒤의 큰 싸움 사이에서 짧고 날카롭게 긴장을 이어 주는 구간입니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것과 안뜰·보스 아레나의 잠금 장치만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 바닥의 기준 높이는 0m입니다. 망대(1.5m), 마당의 성벽 위 통로(3m), 사격 통로의 단상(3m), 안뜰의 발코니(1.5m)와 각 경사로만 높이가 다릅니다.
- 벽은 높이 4m 이상으로 만들어 플레이어가 점프로 넘을 수 없게 합니다. 천장은 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 1.5m 이상의 높이는 점프(최고 높이 약 0.73m)로 오를 수 없습니다. 높은 곳에는 경사로로만 올라갑니다.
- 원거리 적이 서는 높은 곳에는 모두 경사로를 둡니다. 플레이어가 반사를 못 하더라도 원거리 적에게 직접 다가가 처치할 수 있어야 합니다.
- 엄폐물과 칸막이는 투사체를 막습니다.
- 길은 하나뿐이며, 시작 지점에서 보스 아레나까지의 이동 거리는 약 160m입니다.

## 잠금 적용 범위

- 출입구 잠금과 2차 웨이브는 [스테이지 - 미니던전 결투 회랑](<스테이지 - 미니던전 결투 회랑.md>)의 '결투방 잠금'과 같은 규칙입니다. 이 던전에서는 안뜰과 보스 아레나에만 적용합니다.
- 전초, 마당, 사격 통로에는 잠금이 없습니다.
- 안뜰은 단상에서 뛰어내려 들어가므로 입구 문이 없습니다. 플레이어가 안뜰 바닥에 내려 단상 가장자리에서 약 2m 안으로 들어오면 출구가 닫힙니다.
- 잠금의 '그 방의 적'은 안뜰에 배치된 적만 셉니다. 단상 위에 남은 사격 통로의 사수는 세지 않습니다.

### 전초

원거리 적 하나만 있는 구간입니다. 투사체가 엄폐물에 막힌다는 것과, 패리로 투사체를 되돌려 보낼 수 있다는 것을 안전하게 익힙니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 20m × 16m |
| 망대 | 안쪽 한 모서리에 약 5m × 6m, 높이 1.5m |
| 경사로 | 망대에서 입구 방향으로 벽을 따라 길이 약 6m, 폭 약 2m |
| 엄폐물 | 약 3m × 1m, 높이 2m의 블록 3개. 입구에서 망대까지 지그재그로 놓아, 엄폐물에서 엄폐물로 옮겨 가며 다가갈 수 있게 합니다. |
| 적 | 원거리 일반 적 1명 (망대 위) |
| 입구와 출구 | 입구는 진입로 쪽 벽의 가운데, 출구는 맞은편 벽의 망대 반대쪽 끝에 폭 약 5m로 둡니다. |

### 마당

이 던전의 첫 번째 큰 싸움입니다. 양쪽 성벽 위의 원거리 적이 교차로 쏘는 동안 근거리 적이 엄폐물 사이로 달려듭니다.

플레이어는 한쪽 경사로로 성벽에 올라가 원거리 적 하나를 먼저 끊고 반대쪽을 반사로 상대하거나, 마당 한가운데서 근거리 적을 먼저 처리하는 등 순서를 직접 고릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 30m × 24m |
| 성벽 위 통로 | 좌우 벽을 따라 하나씩, 폭 약 3m, 높이 3m. 마당 안쪽(출구 쪽) 약 20m 구간에 둡니다. |
| 경사로 | 성벽 위 통로마다 입구 쪽 끝에 하나씩, 벽을 따라 길이 약 8m, 폭 약 3m |
| 엄폐물 | 약 3m × 1m, 높이 2m의 블록 4개. 긴 쪽이 입구와 출구를 잇는 방향으로 놓여 한쪽 성벽의 사격만 막습니다. 왼쪽을 막는 것과 오른쪽을 막는 것을 번갈아 둡니다. |
| 적 | 근거리 일반 적 1명, 원거리 일반 적 2명 (좌우 성벽 위에 하나씩) |
| 입구와 출구 | 입구는 전초의 출구와 길이 약 5m의 통로로 잇습니다. 출구는 맞은편 벽의 가운데에 폭 약 6m로 두고, 사격 통로로 바로 이어집니다. |

### 사격 통로

단상 위의 사수 하나가 통로 끝에서 쏘는 구간입니다. 칸막이 뒤에 숨었다가 틈을 달려 다음 칸막이로 옮기기를 되풀이하며 다가가, 경사로를 뛰어올라 사수를 처치합니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 30m, 폭 약 6m |
| 칸막이 | 벽과 같은 높이, 두께 약 1m, 벽에서 약 3m 튀어나온 칸막이 3개. 좌우 벽에서 번갈아 약 5m 간격으로 둡니다. |
| 경사로 | 칸막이 뒤에서 단상까지 통로 폭 전체로, 길이 약 8m |
| 단상 | 통로 끝에 길이 약 4m, 높이 3m. 단상의 끝은 안뜰 쪽으로 열린 가장자리입니다. |
| 적 | 원거리 일반 적 1명 (단상 위) |
| 시야 | 칸막이가 통로를 엇갈려 가려, 사수가 마당까지 볼 수 없어야 합니다. |

### 안뜰

이 던전의 마지막 일반 교전입니다. 단상에서 뛰어내려 들어오면 출구가 잠깁니다.

1차 웨이브는 근거리 적 둘입니다. 둘을 처치하면 좌우 경사로 끝의 벽이 열리며 발코니에 원거리 적이 하나씩 나타나고, 출구 옆 대기실에서 근거리 적이 나옵니다. 정면의 근거리 적과 싸우면서 좌우의 교차 사격을 다시 감당해야 하는, 지금까지 배운 것을 모두 쓰는 싸움입니다.

| 항목 | 조건 |
| - | - |
| 크기 | 평지, 약 24m × 24m |
| 진입 | 사격 통로의 단상(높이 3m)에서 뛰어내립니다. 안뜰에서 단상으로 다시 올라갈 수 없습니다. |
| 발코니 | 좌우 벽 너머에 하나씩, 약 4m × 3m, 높이 1.5m. 2차 웨이브의 대기실입니다. |
| 발코니 경사로 | 발코니마다 안뜰 바닥으로 내려오는 경사로. 벽을 따라 출구 쪽으로 길이 약 6m, 폭 약 2m. 처음부터 보이며, 끝이 막힌 벽이라 무언가 나올 곳임을 미리 알려 줍니다. |
| 출구 옆 대기실 | 출구가 있는 벽 너머, 출구 한쪽 옆에 약 3.5m × 4m |
| 1차 웨이브 | 근거리 일반 적 2명 |
| 2차 웨이브 | 원거리 일반 적 2명 (좌우 발코니에 하나씩), 근거리 일반 적 1명 (출구 옆 대기실) |
| 출구 | 단상 맞은편 벽의 가운데, 폭 약 6m |

### 대기 공간

보스 아레나에 들어가기 전에 숨을 돌리는 공간입니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 10m × 10m |
| 연결 | 안뜰과 보스 아레나 사이에 두고, 양쪽과 길이 약 6m의 곧은 통로로 잇습니다. |
| 시야 | 통로 너머로 아레나 안의 커스터가 보여야 합니다. 커스터까지 약 35m 떨어져 있어 커스터의 시야(20m) 밖입니다. |
| 적 | 없음 |

### 보스 아레나

커스터와 싸우는 구역입니다. 크기, 바닥, 장애물, 경계는 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)의 '보스 아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 33m (보스 전장의 원형 단상 방 내부와 같은 크기) |
| 입구 | 대기 공간 쪽 벽의 가운데, 폭 약 5m. 위 '잠금 적용 범위'를 따릅니다. |
| 전투 시작 | 입구에서 약 2m 들어오면 입구가 닫히고, 약 5m 들어오면 커스터의 시야(20m)에 들어가 전투가 시작됩니다. |

## 배치 요소

![요새 돌파 배치](<../../Art/Level/요새 돌파 배치.svg>)

- LV_FortressBreach를 위에서 내려다본 도식입니다. 오른쪽(+X)이 보스 아레나 방향입니다. 바닥의 밝기가 높이를 나타냅니다. 그레이박스를 만든 뒤 실제 캡처로 바꿉니다.
- 적은 모두 정찰 지점 없이 처음 배치된 자리에서 대기합니다.

| 기호 | 요소 | 위치와 설정 |
| - | - | - |
| P | 플레이어 시작 지점 | 진입로의 시작에서 2m. 요새 쪽을 바라봅니다. |
| 원 (전초) | 원거리 일반 적 | 망대 위 가운데. 전초 입구를 바라봅니다. |
| 근 (마당) | 근거리 일반 적 | 마당 중심에서 입구 쪽으로 약 1m. 입구를 바라봅니다. |
| 원 (마당) | 원거리 일반 적 2명 | 좌우 성벽 위 통로에 하나씩, 출구 쪽 끝에서 약 5m. 마당 입구 쪽을 바라봅니다. |
| 원 (사격 통로) | 원거리 일반 적 | 단상 위 가운데. 통로를 내려다봅니다. |
| 근 (안뜰) | 근거리 일반 적 2명 (1차) | 안뜰 중심에서 좌우로 각각 4m. 단상 쪽을 바라봅니다. |
| 원 (안뜰 발코니) | 원거리 일반 적 2명 (2차) | 좌우 발코니에 하나씩. 안뜰 안쪽을 바라봅니다. |
| 근 (안뜰 대기실) | 근거리 일반 적 (2차) | 출구 옆 대기실 가운데. 안뜰 안쪽을 바라봅니다. |
| G | 아레나 입구 | 잠금을 따릅니다. |
| C | 아레나 중심 | 보스 시작 위치(B)를 정하는 기준점입니다. |

## 미확정 항목

일반 적의 기획이 나오기 전에 정한 값이 있어, 아래는 적이 확정되거나 플레이해 본 뒤 조정합니다.

- **원거리 일반 적의 투사체:** 이 던전은 원거리 적의 투사체를 패리로 반사할 수 있고, 엄폐물로 막을 수 있으며, 피하거나 반사할 여유가 있는 속도라는 전제로 구성했습니다. 히트스캔(쏘는 즉시 맞는 공격)이거나 반사할 수 없으면 던전 구성을 다시 검토합니다.
- **원거리 일반 적의 시야:** 마당의 성벽 위 원거리 적은 마당 입구까지 약 29m를 볼 수 있다는 전제로 배치했습니다. 시야가 짧으면 원거리 적을 입구 쪽으로 옮기고, 너무 길어 앞 구간에서 다음 구간의 적이 플레이어를 보면 구간 사이 통로를 꺾습니다.
- **원거리 적의 수:** 원거리 적이 6명으로, 결투 회랑보다 피격이 잦을 수 있습니다. 마당이나 안뜰 2차 웨이브가 지나치게 어려우면 원거리 적을 하나씩 근거리 적으로 바꿉니다.
- **아래에 몰린 근거리 적:** 플레이어가 사격 통로의 단상에 있는 동안 안뜰의 근거리 적이 플레이어를 보고 단상 아래에 몰려 서 있을 수 있습니다. 뛰어내리자마자 둘러싸여 억울하면 근거리 적을 단상에서 보이지 않는 곳으로 옮깁니다.
- **엄폐물 높이:** 높은 곳에서 쏘는 투사체가 높이 2m 엄폐물을 넘어 플레이어에게 닿으면 엄폐물을 높이거나 원거리 적의 위치를 낮춥니다.
- **잠긴 아레나에서 커스터의 이동:** 닫힌 출입구는 적을 막지 않으므로 커스터의 돌진이 통로로 빠져나갈 수 있습니다. 결투 회랑과 같이 플레이해 보고 정합니다.
