# 스테이지 - 미니던전 요새 돌파

> 이 미니던전은 AI가 던전 선정과 첫 기획을 했고, 담당 기획자가 구간의 지형과 장애물, 적 배치를 직접 다시 설계했습니다.

미니던전 '요새 돌파'의 레벨인 LV_FortressBreach의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 그레이박스 지형, 동선, 적 배치로 재미를 만드는 것을 전제로 하며, 기능 구현이 필요한 요소는 성문 하나뿐입니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)을 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_FortressBreach |
| 컨셉 | 높은 시작 지점에서 멀리 성문까지 내려다본 뒤, 평지를 달려 원거리 적의 사격을 패리로 받아치며 다가가 직접 벱니다. 통로, 마당, 언덕길을 지나 성문 단 위에서 내려다보며 쏘는 사수들에게 올라가 베고, 성문을 열어 그 너머의 커스터에게 도착합니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 LV_BossStage와 같습니다. |
| 등장 적 | 근거리 일반 적 4명, 원거리 일반 적 8명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 약 7분 (이동 약 1분, 일반 교전 합계 약 3분, 커스터전 약 3분) |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 레벨에 배치하는 회복 수단 | 없음 |

## 설계 의도

이 던전의 주인공은 원거리 일반 적입니다. 요새 돌파는 평지를 달리는 액션의 기본기 위에서, 멀리서 쏘는 적에게 패리로 다가가 붙어서 베는 재미를 주는 던전입니다.

약 7분의 짧은 던전이므로 중심은 전투입니다. 탐험은 전투 사이의 양념으로, 미리 내려다보는 높은 시작 지점 하나와 선택할 수 있는 샛길 하나만 둡니다. 보상 아이템은 마일스톤 범위 밖이므로, 샛길의 보상은 '유리하게 시작하는 싸움'입니다.

지형은 높은 시작 지점과 평지, 완만한 언덕길, 그리고 성문 앞의 낮은 단으로 이루어집니다. 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 자리에 서 있습니다.

재미 요소는 아래와 같습니다. 성문을 빼면 모두 지형과 적 배치만으로 만들어집니다.

- **먼저 내려다보기:** 시작 지점은 요새 바깥의 높은 단(12m) 위입니다. 출발하자마자 마당과 그 뒤의 성문이 멀리 보이고, 두 번에 걸친 내리막을 따라 내려갑니다. 앞으로 지나갈 곳을 미리 본 플레이어는 나중에 '아까 본 그곳'에 도착합니다.
- **패리로 다가가기:** 사수의 탄환을 패리하면 쏜 사수에게 되돌아갑니다. 통로에는 가릴 것이 하나도 없어, 사수 하나를 상대로 패리하며 걸어 들어가거나 빠르게 달려들어 베는 법을 처음 익힙니다. 마당과 언덕길, 성문 앞을 거치며 점점 바쁜 상황에서 같은 일을 하게 됩니다.
- **붙으면 이긴다:** 사수는 가까이 붙으면 쉽게 쓰러집니다. 다가가는 동안의 긴장과 붙은 뒤의 시원함이 이 던전의 기본 박자입니다.
- **주변을 읽으면 유리해지는 지형:** 장애물은 숨어서 버티는 자리가 아니라 사수의 사격 각을 끊는 자리입니다. 통로, 언덕길, 성문 앞의 평지에는 장애물을 두지 않고, 마당과 성문 단 위에만 몇 개를 둡니다. 주변을 살핀 플레이어는 사수 하나의 사격이 닿지 않는 자리에서 싸우고, 살피지 않고 달려든 플레이어는 여러 사수에게 한꺼번에 겨눠집니다. 구간을 벽으로 갈라 길을 나누지는 않으며, 모든 구간은 트인 공간입니다.
- **근접전 속의 사격:** 마당에서는 근거리 적과 싸우는 동안 안쪽의 사수 둘이 쏩니다. 마당 가운데로 곧장 달려들면 두 사수가 모두 겨눕니다. 싸우는 동안 엄폐물과 사수의 자리를 파악하면, 사수 하나의 사격이 닿지 않는 자리에서 근거리 적을 상대할 수 있습니다.
- **붙어서 벤 사람만 찾는 샛길:** 통로 끝에서 큰 길은 왼쪽 앞으로 비스듬히 꺾여 한눈에 보이고, 샛길 문은 칸막이 뒤에 숨어 있습니다. 어디로 가야 하는지는 분명하게 보여 주되, 샛길은 통로 끝의 사수 자리까지 다가간 플레이어만 발견합니다. 샛길은 마당 바깥을 돌아 마당 오른쪽 사수의 등 뒤로 이어져, 다음 싸움의 선제공격을 보상으로 줍니다. 다만 샛길에서 나온 자리에서는 다른 사수가 기둥에 가려 보이지 않아, 오른쪽 사수를 베는 동안 그 사수에게 기습당할 수 있습니다.
- **언덕길 오르기:** 완만한 오르막 위에서 사수 둘이 내려다보며 쏩니다. 오르막에는 가릴 것이 없고, 달려 올라가다 보면 오른쪽 벽에 숨는 곳이 하나 보입니다. 그곳에 숨을지, 패리하며 그대로 올라가 사수를 상대할지를 플레이어가 고릅니다.
- **튀어나온 보루:** 성문은 평지보다 높은 단 위에 있고, 단의 가운데가 평지 쪽으로 튀어나와 보루를 이룹니다. 보루 끝의 사수가 평지를 내려다보며 쏩니다. 보루의 앞과 양옆은 해자가 ㄷ자로 둘러, 보루 아래로 다가가 붙을 수 없습니다. 평지에는 엄폐물이 없고, 좌우 경사로 앞은 근거리 적이 하나씩 지키며 그 뒤 단 위 안쪽에서 사수가 하나씩 쏘아 경사로로 들어서기 어렵게 합니다. 린의 스킬 1로 보루의 사수에게 올라서면 경사로를 거치지 않고 단 위로 바로 진입하며, 단 위의 엄폐물이 좌우 사수의 사격을 가려 싸움을 유리하게 시작합니다.
- **사수에서 사수로:** 단 위에 올라서면 보루의 사수를 베고, 좌우 안쪽의 사수에게 차례로 달려갑니다. 올라가는 동안의 긴장을 단 위에서 연달아 베며 돌려받습니다.
- **내 손으로 여는 성문:** 성문 앞의 방어선을 뚫고 성문에 다가가 직접 엽니다. 마지막 방어선을 뚫었다는 마침표이자, 커스터전에 들어가기 전의 한 호흡입니다.

린의 스킬 1은 이 던전에서 있으면 편한 보조 수단입니다. 어느 구간도 스킬 1 없이 걸어서 풀 수 있어야 합니다.

구간의 모양도 서로 다르게 둡니다. 통로는 가릴 것 없는 긴 일자, 마당은 벽에 둘러싸인 넓은 네모에 엄폐물 둘과 기둥 하나가 놓인 모양, 언덕길은 좁은 오르막 외길에 숨는 곳이 하나 딸린 모양, 성문 앞은 넓고 빈 평지 뒤로 높은 단이 가로지르고 오르는 길이 둘인 모양입니다.

난이도는 통로(원거리 1명) → 마당(근거리 2명 + 원거리 2명) → 언덕길(원거리 2명) → 성문 앞(근거리 2명 + 원거리 3명) → 커스터 순서로 이어집니다. 성문 앞은 적의 수가 마당보다 하나 많고, 어느 경사로를 고르든 근거리 적 하나를 상대하는 동안 단 위의 사수에게 겨눠집니다. 언덕길은 앞뒤의 큰 싸움 사이에서 짧게 긴장을 이어 주는 구간입니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 길을 막는 장치는 성문 하나뿐입니다. 성문 앞까지는 구간 사이에 문을 두지 않아, 플레이어는 적을 남겨 둔 채 다음 구간으로 지나갈 수 있습니다.
- 바닥의 기준 높이는 0m입니다. 시작 지점(12m)에서 중간 단(6m)을 거쳐 내려와 통로, 샛길, 마당은 0m이고, 언덕길로 4m까지 올라가 성문 앞의 평지와 보스 아레나는 4m입니다. 성문 앞 뒤쪽의 성문 단은 6m이고, 보루를 두르는 해자의 바닥은 2m입니다.
- 벽은 높이 4m 이상으로 만들어 플레이어가 점프로 넘을 수 없게 합니다. 천장은 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 바닥 위에 섭니다. 높은 자리에 둘 때는 언덕길이나 성문 단처럼 경사로로 걸어 올라갈 수 있게 합니다.
- 원거리 적의 앞에는 난간, 낮은 담, 흉벽을 두지 않습니다. 사수는 총구와 플레이어 사이가 가려지면 쏘지 않으므로([일반 적 - 경비 사수](<../Content/일반 적 - 경비 사수.md>)의 '조준'), 사수 자리에서 그 구간의 바닥이 보여야 합니다. 마당의 엄폐물 뒤와 성문 단의 엄폐물 뒤처럼 일부러 사격을 끊어 둔 자리는 예외입니다.
- 원거리 적은 뒤쪽 벽에서 3m 이상 떨어뜨려 둡니다. 린의 스킬 1은 대상의 등 뒤 3m에 나타나므로, 그 자리에 바닥이 있어야 합니다.
- 장애물은 작은 엄폐물과 기둥 두 가지입니다. 모두 속이 찬 구조물이며 시선과 탄환을 가립니다. 작은 엄폐물(약 3m × 0.5m, 높이 2m)은 마당에 2개, 성문 단 위에 2개를 두며, 점프 최고 높이(약 1.2m)보다 높아 넘을 수 없습니다. 기둥(약 2.3m × 1.5m, 높이 4m)은 마당에 1개를 둡니다. 통로, 언덕길, 성문 앞의 평지에는 장애물을 두지 않습니다. 구간 안을 가로질러 길을 나누는 긴 벽은 두지 않습니다.
- 구간 사이는 꺾인 통로로 이어, 다음 구간의 사수가 앞 구간의 플레이어를 보지 못하게 합니다. 통로와 마당 사이만은 비스듬히 꺾인 통로로 이어, 통로 끝에서 큰 길이 한눈에 보이게 합니다. 경비 사수의 시야 거리는 30m입니다.
- 큰 길은 하나이며, 시작 지점에서 보스 아레나까지의 이동 거리는 약 230m입니다. 샛길은 하나뿐이고 마당에서 큰 길과 다시 합쳐집니다.

## 구간

### 진입로

요새 바깥의 높은 시작 지점에서 출발해, 멀리 성문을 내려다보며 두 번에 걸쳐 내려가는 구간입니다.

| 항목 | 조건 |
| - | - |
| 시작 지점 | 높이 12m, 약 5m × 5m의 단. 요새 방향(+X)을 뺀 세 면은 높이 약 2m의 담으로 막습니다. 이곳에서 마당과 그 뒤의 성문이 보여야 합니다. |
| 첫째 내리막 | 시작 지점에서 요새 방향(+X)으로 곧게 길이 약 12m, 폭 약 5m. 12m에서 6m로 내려갑니다. 양옆에 난간을 둡니다. |
| 중간 단 | 높이 6m, 약 5m × 6m. 첫째 내리막이 끝나는 자리입니다. 가장자리에는 낮은 담을 둡니다. |
| 둘째 내리막 | 중간 단에서 오른쪽(-Y)으로 90도 꺾어 길이 약 12m, 폭 약 5m. 6m에서 0m로 내려갑니다. 바닥에 닿으면 왼쪽(+X)으로 꺾어 통로 입구에 닿습니다. |
| 적 | 없음 |

- 시작 지점은 통로의 사수에게서 30m보다 멀리 두어(약 48m), 내려오는 동안 전투가 시작되지 않게 합니다.

### 통로

원거리 적 하나만 있는 구간입니다. 가릴 것이 없는 긴 일자 통로 끝의 사수를 향해, 패리하며 걸어 들어가거나 빠르게 달려들어 베는 법을 익힙니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 30m, 폭 약 6m의 곧은 평지 |
| 장애물 | 없음. 입구에서 사수까지 약 26m를 가릴 것 없이 다가갑니다. |
| 적 | 원거리 일반 적 1명 (통로 끝) |
| 큰 길 출구 | 통로 끝의 왼쪽(+Y) 벽에 폭 약 7m. 왼쪽 앞으로 비스듬히 꺾인 폭 약 5.5m, 길이 약 14m의 통로로 마당 입구와 이어집니다. 통로 끝에 다가가면 꺾인 길의 안쪽이 보여 어디로 가야 하는지 알 수 있습니다. |
| 샛길 문 | 통로 끝의 오른쪽(-Y) 벽에 폭 약 1.5m의 좁은 문. 벽에서 튀어나온 칸막이가 입구 쪽 시선을 가려, 사수 자리 옆까지 와야 보입니다. 아래 '샛길'로 이어집니다. |

- 사수의 탄환은 거리와 관계없이 같은 박자로 닿으므로, 통로를 걸어 들어가는 동안 같은 리듬으로 패리를 되풀이하게 됩니다.

### 샛길

통로 끝에서 마당의 출구 쪽 모서리로 이어지는 좁은 길입니다. 고르지 않아도 되는 길이며, 고르면 마당의 오른쪽 원거리 적 등 뒤로 나와 먼저 공격할 수 있습니다. 샛길에서 나온 자리에서는 출구 앞의 원거리 적이 기둥에 가려 보이지 않습니다.

| 항목 | 조건 |
| - | - |
| 폭 | 약 2m. 양옆은 벽으로 막혀 있습니다. |
| 경로 | 통로의 샛길 문에서 오른쪽(-Y)으로 나간 뒤, 마당 오른쪽 벽의 바깥을 따라 출구 방향(+X)으로 가서, 마당의 출구 쪽 오른쪽 모서리로 들어옵니다. |
| 높이 | 0m. 높이 변화가 없습니다. |
| 적 | 없음 |

- 샛길 안에서는 마당의 적이 플레이어를 볼 수 없어야 합니다.
- 샛길을 따라가도 마당에 들어가며, 마당을 지나지 않고 다음 구간으로 갈 수는 없습니다.

### 마당

이 던전의 첫 번째 큰 싸움입니다. 넓은 마당에서 근거리 적과 싸우는 동안 안쪽의 원거리 적 둘이 쏩니다.

마당에는 작은 엄폐물 둘과 기둥 하나를 둡니다. 엄폐물은 숨어서 버티는 자리가 아니라 두 사수 중 하나의 사격을 끊는 자리입니다. 입구 왼쪽 안의 엄폐물 뒤는 출구 앞 사수에게, 오른쪽 엄폐물의 뒤는 오른쪽 사수에게 보이지 않습니다. 근거리 적과 싸우는 동안 엄폐물과 사수의 자리를 파악한 플레이어는 사수 하나에게 보이지 않는 자리로 싸움을 옮길 수 있습니다. 살피지 않고 마당 가운데로 달려들면 두 사수가 모두 겨눕니다.

입구에 들어서면 적 넷이 모두 보이고, 두 사수 모두 입구의 플레이어를 겨눌 수 있습니다. 근거리 적은 입구 쪽의 좌우에 하나씩 서 있습니다.

샛길로 온 플레이어는 오른쪽 사수의 등 뒤에서 싸움을 시작합니다. 샛길 출구에서는 출구 앞의 기둥이 출구 앞 사수를 가려, 플레이어는 그 사수가 어디 있는지 모른 채 오른쪽 사수에게 다가가게 됩니다. 오른쪽 사수에게 붙으면 출구 앞 사수의 시야에 들어가므로, 기습한 플레이어가 되레 기습당할 수 있습니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 30m × 24m의 평지 |
| 장애물 | 작은 엄폐물 2개, 기둥 1개. 엄폐물 하나는 입구에서 약 13m 들어온 가운데 왼편에 비스듬히 두어, 출구 앞 사수가 입구 왼쪽 안을 보지 못하게 가립니다. 다른 하나는 입구에서 약 12m 들어온 오른쪽(오른쪽 벽에서 약 5m)에, 오른쪽 사수 쪽을 가로막게 둡니다. 기둥은 출구 앞 오른편(출구 쪽 벽에서 약 4.5m)에 두어 샛길 출구와 출구 앞 사수 사이를 가립니다. |
| 적 | 근거리 일반 적 2명 (입구에서 약 13m 들어온 왼쪽 벽 쪽에 하나, 약 10m 들어온 오른쪽 벽 쪽에 하나), 원거리 일반 적 2명 (출구 앞 왼편에 하나, 마당 안쪽의 오른쪽 벽 쪽에 하나) |
| 입구와 출구 | 입구는 폭 약 3.5m로, 통로에서 온 비스듬한 통로와 잇습니다. 출구는 맞은편 벽의 가운데에 폭 약 6m로 두고, 꺾인 통로로 언덕길과 이어집니다. |
| 샛길 출구 | 출구 쪽 오른쪽(-Y) 모서리. 오른쪽 사수의 등 뒤로 나옵니다. |

### 언덕길

완만한 오르막 위에서 원거리 적 둘이 내려다보며 쏘는 구간입니다. 오르막에는 가릴 것이 없고, 올라가는 도중 오른쪽 벽에 숨는 곳이 하나 있습니다. 숨는 곳에 들어가 사격을 끊을지, 패리하며 그대로 올라가 사수를 처치할지를 플레이어가 고릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 30m, 폭 약 8m. 0m에서 4m까지 고르게 올라갑니다. |
| 장애물 | 없음 |
| 숨는 곳 | 오르막 시작에서 약 18m 지점의 오른쪽 벽에 폭 약 4m의 입구를 둡니다. 안쪽은 깊이 약 4m의 막힌 공간이며 두 사수 모두에게 보이지 않습니다. 오르막 아래에서는 보이지 않고, 약 15m 올라오면 입구가 보입니다. 입구에서 사수까지는 약 10m입니다. |
| 적 | 원거리 일반 적 2명 (오르막이 끝나는 자리의 좌우에 하나씩) |
| 사수 자리 | 경사가 끝나는 모서리에 붙여 세워, 오르막 전체가 사수에게 막힘 없이 보이게 합니다. |
| 출구 | 오르막 위에서 꺾인 통로로 성문 앞과 이어집니다. |

### 성문 앞

이 던전의 마지막 일반 교전입니다. 넓은 평지의 뒤쪽을 높은 단이 가로지르고, 성문은 그 단 위에 있습니다. 단의 가운데는 평지 쪽으로 튀어나와 보루를 이루고, 그 끝에 사수 하나가 서서 평지를 내려다보며 쏩니다. 평지에는 엄폐물을 두지 않습니다.

보루의 앞과 양옆은 깊이 2m의 해자가 ㄷ자로 둘러, 보루 아래로 걸어가 붙을 수 없습니다. 보루의 사수에게 가는 길은 경사로를 돌아 오르거나 린의 스킬 1로 해자를 건너 올라서는 것뿐입니다.

단으로 오르는 길은 좌우 벽을 따라 놓인 경사로 둘입니다. 경사로 앞은 근거리 적이 하나씩 지키고, 그 뒤 단 위 안쪽에서 사수가 하나씩 경사로를 내려다보며 쏩니다. 근거리 적을 상대하는 동안 그 뒤의 사수에게 겨눠지므로 경사로로 들어서기가 어렵습니다.

린의 스킬 1로 보루의 사수에게 올라서면 경사로를 거치지 않고 단 위로 바로 진입합니다. 보루 좌우의 단 가장자리에는 엄폐물을 하나씩 두어, 좌우 사수가 보루 쪽을 쏘지 못하게 가립니다. 보루 위에서 싸움을 시작한 플레이어는 좌우 사수의 사격을 받지 않고 보루의 사수를 벤 뒤, 좌우 사수에게 차례로 달려가고 성문을 엽니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 36m × 24m (평지 높이 4m). 입구에서 약 24m까지가 평지이고, 그 뒤 약 12m가 성문 단입니다. |
| 성문 단 | 평지보다 2m 높은 단(높이 6m). 구간의 폭 전체를 가로지릅니다. 평지 쪽 가장자리에는 난간을 두지 않습니다. 2m는 점프 최고 높이(약 1.2m)보다 높아 경사로로만 오를 수 있습니다. |
| 경사로 | 좌우 벽에 붙여 하나씩. 길이 약 8m, 폭 약 4m로 평지에서 단 위까지 오릅니다. 단의 앞쪽으로 뻗어 나와 있습니다. |
| 보루 | 단의 가운데가 평지 쪽으로 약 6m 튀어나온 부분. 폭 약 8m, 단과 같은 높이(6m)이며 난간을 두지 않습니다. 보루와 좌우 경사로 사이의 폭 약 4m는 해자가 됩니다. |
| 해자 | 보루의 앞(폭 약 3m)과 양옆(보루와 좌우 경사로 사이 약 4m)을 ㄷ자로 두르는 깊이 2m의 구덩이(바닥 높이 2m). 점프 최고 높이(약 1.2m)로는 올라올 수 없고, 빠져도 죽지 않습니다. 좌우 경사로 쪽 벽에 붙여 폭 약 1.5m의 오르막을 하나씩 두어 평지로 걸어 나옵니다. |
| 엄폐물 | 2개 (약 3m × 0.5m, 높이 2m). 성문 단 위, 평지 쪽 가장자리에서 약 1m 안쪽에 하나씩 둡니다. 좌우 사수의 약 3m 앞에서 보루 쪽을 가립니다. 평지에는 엄폐물을 두지 않습니다. |
| 근거리 적 | 2명. 좌우 경사로 앞에 하나씩 섭니다. |
| 원거리 적 | 3명. 하나는 보루 끝에서 약 1m 안쪽에(입구에서 약 19m), 둘은 좌우 경사로 꼭대기에서 약 4m 뒤의 단 위에 하나씩 섭니다(성문 쪽 벽에서 약 8m). |
| 성문 | 단 위, 입구 맞은편 벽의 가운데에 폭 약 5m. 처음에는 닫혀 있습니다. 아래 '성문'을 따릅니다. |

- 보루의 사수 등 뒤 3m는 보루 위입니다.

#### 성문

성문 앞과 보스 아레나 사이를 막는 문입니다. 이 던전에서 플레이어가 상호작용하는 유일한 장치입니다. 상호작용 대상을 고르는 순서, 입력, 안내는 [플레이어 시스템](<../System/플레이어 시스템.md>)의 '상호작용'과 [UI 시스템](<../System/UI 시스템.md>)의 '상호작용 안내'를 따릅니다.

| 항목 | 조건 |
| - | - |
| 위치와 크기 | 성문 단(높이 6m) 위, 성문 앞 구간 입구 맞은편 벽의 가운데. 폭 약 5m. |
| 처음 상태 | 닫혀 있습니다. 닫힌 성문은 플레이어와 적의 이동, 시선, 탄환을 모두 막습니다. |
| 여는 조건 | 없습니다. 성문 앞에 적이 남아 있어도 열 수 있습니다. |
| 안내에 적는 행동 | 성문 열기 |
| 상호작용 범위 | 성문의 폭 전체에서, 성문 면으로부터 앞뒤 1m까지입니다. |
| 안내 지점 | 성문 폭의 가운데, 바닥에서 2m 높이입니다. |
| 열리는 중 | 상호작용하면 성문이 약 2초 동안 위로 올라갑니다. 다 올라가기 전까지는 이동, 시선, 탄환을 계속 막습니다. 열리기 시작한 성문은 상호작용 후보에서 빠지므로 안내가 바로 사라지고, 다시 상호작용 키를 눌러도 성문에는 아무 일도 일어나지 않습니다. |
| 열린 뒤 | 끝까지 올라간 성문은 이동, 시선, 탄환을 막지 않고, 다시 닫히지 않습니다. |
| 재도전 | [게임 플로우](<../System/게임 플로우.md>)의 Restart나 타이틀을 통한 새 도전에서는 닫힌 상태로 다시 시작합니다. |

- 성문 가까이에는 적을 두지 않아 처형과 성문 열기가 겹치는 일이 드물게 합니다.
- 상호작용 범위 1m, 열리는 시간 2초, 안내 지점의 높이 2m는 플레이해 보고 조정합니다.

### 보스 아레나

커스터와 싸우는 구역입니다. 성문을 지나 길이 약 8m의 곧은 통로로 이어지며, 이 통로는 성문 단의 높이(6m)에서 아레나의 높이(4m)까지 완만하게 내려갑니다. 크기, 바닥, 장애물, 경계는 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)의 '보스 아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 33m (보스 전장의 원형 단상 방 내부와 같은 크기) |
| 입구 | 성문 쪽 벽의 가운데, 폭 약 5m |
| 시야 | 성문이 열리면 통로 너머로 아레나 안의 커스터가 보여야 합니다. 성문에서 커스터까지 약 32m 떨어져 있어 커스터의 시야(20m) 밖입니다. |
| 커스터의 시야 | 입구에서 약 5m 들어오면 커스터의 시야(20m)에 들어갑니다. |

- 따로 쉬어 가는 대기 공간은 두지 않습니다. 적을 정리한 성문 앞과, 성문을 열고 지나는 통로가 그 역할을 합니다.

## 높이 구성

![요새 돌파 높이](<../../Art/Level/요새 돌파 높이.svg>)

- 요새 돌파를 옆에서 본 그림입니다. 길을 곧게 펴서 그린 단면이라 구간 길이의 합이 '레벨 구성'의 이동 거리와 조금 다를 수 있고, 세로를 가로보다 약 3배 늘려 그렸습니다.
- 12m의 시작 지점에서 6m의 중간 단을 거쳐 내려와 통로와 마당은 0m로 이어지고, 언덕길로 4m까지 올라가 성문 앞의 평지에 닿고, 경사로로 성문 단(6m)에 오른 뒤 성문 뒤 통로를 따라 보스 아레나(4m)로 내려갑니다. 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 바닥 위에 섭니다.

## 미확정 항목

구간의 크기, 거리, 적의 수는 그레이박스를 만들기 전에 정한 값이라, 아래는 플레이해 본 뒤 조정합니다.

- **구간 크기와 거리:** 각 구간의 길이, 폭, 장애물의 자리와 간격, 적 사이의 거리는 플레이해 보고 조정합니다.
- **원거리 적의 수:** 원거리 적이 8명으로, 피격이 잦을 수 있습니다. 마당이나 성문 앞이 지나치게 어려우면 원거리 적을 하나씩 줄이거나 근거리 적으로 바꿉니다.
- **예상 플레이 시간:** 약 7분은 적의 수와 이동 거리로 어림한 값입니다. 플레이해 보고 고칩니다.
