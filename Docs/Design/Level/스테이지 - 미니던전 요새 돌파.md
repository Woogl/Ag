# 스테이지 - 미니던전 요새 돌파

> 이 문서는 AI가 기획한 미니던전입니다. 던전 선정, 구간 구성, 적 배치, 수치를 AI가 정했고 담당 기획자가 검토했습니다.

미니던전 '요새 돌파'의 레벨인 LV_FortressBreach의 구성, 구간별 조건, 배치 요소를 정의합니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)을, 출입구 잠금과 2차 웨이브 규칙은 [스테이지 - 미니던전 결투 회랑](<스테이지 - 미니던전 결투 회랑.md>)의 '결투방 잠금'을 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_FortressBreach |
| 컨셉 | 언덕 위에서 요새를 내려다본 뒤, 원거리 적이 지키는 요새를 엄폐물과 투사체 반사로 뚫고 들어가, 성벽에서 안뜰로 뛰어내려 마지막 저항을 꺾고 탑 너머의 커스터에게 도착합니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 LV_BossStage와 같습니다. |
| 등장 적 | 근거리 일반 적 4명, 원거리 일반 적 6명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 약 9분 (이동 약 50초, 일반 교전 합계 약 5분, 커스터전 약 3분) |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 회복 수단 | 없음 |
| 전제 | 원거리 일반 적이 플레이어의 높이를 겨냥해 반사 가능한 투사체를 쏩니다. 아래 '건의 사항'을 참고합니다. |

## 설계 의도

이 던전의 주인공은 원거리 일반 적입니다. 결투 회랑이 닫힌 방에서 근거리 적과 맞붙는 던전이라면, 요새 돌파는 탁 트인 공간에서 멀리서 쏘는 적에게 어떻게 다가갈지를 고민하는 던전입니다.

9분 남짓의 짧은 던전이므로 중심은 전투입니다. 탐험은 전투 사이의 양념으로, 미리 내려다보는 전망 지점 하나와 선택할 수 있는 샛길 하나만 둡니다. 보상 아이템은 마일스톤 범위 밖이므로, 샛길의 보상은 '유리하게 시작하는 싸움'입니다.

재미 요소는 아래와 같습니다.

- **먼저 내려다보기:** 시작 지점은 요새 바깥의 언덕 위입니다. 진입로가 꺾여 내려가는 동안 성벽 너머의 마당과 안뜰, 그 뒤의 탑이 보입니다. 앞으로 지나갈 곳을 미리 본 플레이어는 나중에 '아까 본 그곳'에 도착합니다.
- **탑이라는 목표:** 보스 아레나 앞에 요새에서 가장 높은 탑이 서 있습니다. 어느 구간에서든 성벽 위로 탑이 보여 가야 할 방향을 알려 주며, 마지막 대기 공간은 이 탑의 1층입니다.
- **반사 학습 곡선:** 전초에서 원거리 적 하나로 투사체 반사를 처음 익히고, 마당과 사격 통로를 거치며 점점 어려운 상황에서 반사를 쓰게 됩니다. 커스터의 검기(SwordWave)도 패리로 반사할 수 있어, 던전 전체가 커스터전의 예습이 됩니다.
- **올라갈까, 받아칠까:** 원거리 적은 모두 높은 곳에 있지만 경사로로 올라갈 수 있습니다. 경사로로 돌아 올라가 직접 베거나, 그 자리에서 투사체를 반사해 잡는 것 중 플레이어가 고릅니다.
- **올라간 사람만 찾는 샛길:** 전초의 망대에 직접 올라간 플레이어만 망대 뒤의 좁은 문을 발견합니다. 샛길은 성벽 바깥을 돌아 마당 성벽 위, 원거리 적의 등 뒤로 이어집니다. 반사 대신 올라가기를 고른 플레이어에게 다음 싸움의 선제공격을 보상으로 줍니다.
- **교차 사격:** 마당에서는 원거리 적 둘이 양쪽 성벽에서 쏩니다. 엄폐물은 한쪽만 막아 주므로, 한쪽을 피하면 다른 쪽에 드러납니다. 멈춰 있지 말고 엄폐물 사이를 옮겨 다니게 합니다.
- **칸막이 사격 통로:** 좌우 벽에서 엇갈려 튀어나온 칸막이 사이를 지그재그로 지나갑니다. 칸막이 뒤에서는 안전하고 틈에서만 사수에게 보이므로, 숨었다 달리기를 되풀이하는 리듬이 생깁니다.
- **뛰어내리는 돌파:** 안뜰에는 문으로 들어가지 않고, 사격 통로 끝의 높은 단상에서 3m 아래로 뛰어내려 들어갑니다. 돌아갈 수 없는 한 걸음이라 '쳐들어간다'는 느낌을 줍니다.
- **남겨 둔 적의 대가:** 전초부터 사격 통로까지는 문이 잠기지 않아 적을 무시하고 달려 지나갈 수 있습니다. 다만 사격 통로의 사수를 살려 둔 채 뛰어내리면, 그 사수가 단상 위에서 안뜰 싸움 내내 쏩니다.
- **원형 안뜰의 2차 웨이브:** 안뜰은 앞의 네모난 구간과 달리 둥근 광장입니다. 둥근 벽을 따라 내려오는 경사로 두 개가 처음부터 보이며, 그 끝은 막혀 있습니다. 1차 웨이브를 끝내면 막힌 곳이 열리며 좌우 발코니에 원거리 적이 나타나 교차 사격이 다시 시작되고, 출구 옆에서는 근거리 적이 나옵니다.

구간의 모양도 서로 다르게 둡니다. 전초는 출구 쪽으로 좁아지는 깔때기, 마당은 성벽에 둘러싸인 넓은 네모, 사격 통로는 긴 일자, 안뜰은 원형, 대기 공간은 탑의 1층입니다.

난이도는 전초(원거리 1명) → 마당(근거리 1명 + 원거리 2명) → 사격 통로(원거리 1명) → 안뜰(근거리 2명, 이어서 원거리 2명 + 근거리 1명) → 커스터 순서로 올라갑니다. 사격 통로는 앞뒤의 큰 싸움 사이에서 짧고 날카롭게 긴장을 이어 주는 구간입니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것과 안뜰·보스 아레나의 잠금 장치만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 바닥의 기준 높이는 0m입니다. 진입로의 언덕(6m), 망대(1.5m), 샛길(1.5m → 3m), 마당의 성벽 위 통로(3m), 사격 통로의 단상(3m), 안뜰의 발코니(1.5m)와 각 경사로만 높이가 다릅니다.
- 벽은 높이 4m 이상으로 만들어 플레이어가 점프로 넘을 수 없게 합니다. 천장은 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 1.5m 이상의 높이는 점프(최고 높이 약 0.73m)로 오를 수 없습니다. 높은 곳에는 경사로로만 올라갑니다.
- 원거리 적이 서는 높은 곳에는 모두 경사로를 둡니다. 플레이어가 반사를 못 하더라도 원거리 적에게 직접 다가가 처치할 수 있어야 합니다.
- 엄폐물과 칸막이는 투사체를 막습니다.
- 큰 길은 하나이며, 시작 지점에서 보스 아레나까지의 이동 거리는 약 170m입니다. 샛길은 하나뿐이고 마당에서 큰 길과 다시 합쳐집니다.

## 잠금 적용 범위

- 출입구 잠금과 2차 웨이브는 [스테이지 - 미니던전 결투 회랑](<스테이지 - 미니던전 결투 회랑.md>)의 '결투방 잠금'과 같은 규칙입니다. 이 던전에서는 안뜰과 보스 아레나에만 적용합니다.
- 전초, 샛길, 마당, 사격 통로에는 잠금이 없습니다.
- 안뜰은 단상에서 뛰어내려 들어가므로 입구 문이 없습니다. 플레이어가 안뜰 바닥에 내려 단상 가장자리에서 약 2m 안으로 들어오면 출구가 닫힙니다.
- 잠금의 '그 방의 적'은 안뜰에 배치된 적만 셉니다. 단상 위에 남은 사격 통로의 사수는 세지 않습니다.

## 구간

### 진입로

요새 바깥 언덕 위에서 출발해, 요새를 내려다보며 꺾어 내려가는 구간입니다.

| 항목 | 조건 |
| - | - |
| 언덕 길 | 높이 6m, 길이 약 18m, 폭 약 5m. 요새 방향(+X)으로 곧게 뻗습니다. 가장자리에는 높이 1m의 낮은 담을 둡니다. |
| 전망 지점 | 언덕 길의 끝. 낮은 담 너머로 전초, 마당, 안뜰의 일부와 탑이 내려다보여야 합니다. |
| 내리막 경사로 | 전망 지점에서 오른쪽(-Y)으로 90도 꺾어 길이 약 12m, 폭 약 5m로 내려갑니다. 바닥에 닿으면 왼쪽(+X)으로 꺾어 전초 입구에 닿습니다. |
| 적 | 없음 |

- 낮은 담(1m)은 점프 최고 높이(약 0.73m)보다 높아 넘을 수 없습니다.

### 전초

원거리 적 하나만 있는 구간입니다. 투사체가 엄폐물에 막힌다는 것과, 패리로 투사체를 되돌려 보낼 수 있다는 것을 안전하게 익힙니다.

| 항목 | 조건 |
| - | - |
| 모양과 크기 | 입구 쪽 폭 약 16m에서 출구 쪽 폭 약 12m로 좁아지는 깔때기 모양, 길이 약 18m. 왼쪽(+Y) 벽이 비스듬히 좁아집니다. |
| 망대 | 출구 쪽 오른쪽(-Y) 모서리에 약 5m × 6m, 높이 1.5m |
| 경사로 | 망대에서 입구 방향으로 오른쪽 벽을 따라 길이 약 6m, 폭 약 2m |
| 샛길 문 | 망대 위, 오른쪽 벽에 폭 약 1.5m의 좁은 문. 망대 위에서만 보이고, 바닥에서는 망대 난간에 가려 보이지 않습니다. 아래 '샛길'로 이어집니다. |
| 엄폐물 | 약 3m × 1m, 높이 2m의 블록 3개. 입구에서 망대까지 지그재그로 놓아, 엄폐물에서 엄폐물로 옮겨 가며 다가갈 수 있게 합니다. |
| 적 | 원거리 일반 적 1명 (망대 위) |
| 입구와 출구 | 입구는 진입로 쪽 벽의 가운데, 출구는 맞은편 벽의 망대 옆에 폭 약 5m로 둡니다. |

### 샛길

전초의 망대에서 마당 오른쪽 성벽 위 통로의 안쪽 끝으로 이어지는 좁은 길입니다. 고르지 않아도 되는 길이며, 고르면 마당의 오른쪽 원거리 적 등 뒤로 나와 먼저 공격할 수 있습니다.

| 항목 | 조건 |
| - | - |
| 폭 | 약 1.5m. 양옆은 벽으로 막혀 있습니다. |
| 경로 | 망대의 샛길 문에서 오른쪽(-Y)으로 약 6m → 왼쪽(+X)으로 꺾어 마당 바깥을 따라 약 37m → 왼쪽(+Y)으로 꺾어 약 2m 뒤 마당 오른쪽 성벽 위 통로의 안쪽(출구 쪽) 끝으로 나옵니다. |
| 높이 | 망대와 같은 1.5m에서 출발해, 두 번째 구간의 처음 약 6m를 경사로로 올라 3m가 됩니다. |
| 적 | 없음 |

- 샛길 안에서는 마당의 적이 플레이어를 볼 수 없어야 합니다.
- 샛길을 따라가도 마당에 들어가며, 마당을 지나지 않고 다음 구간으로 갈 수는 없습니다.

### 마당

이 던전의 첫 번째 큰 싸움입니다. 양쪽 성벽 위의 원거리 적이 교차로 쏘는 동안 근거리 적이 엄폐물 사이로 달려듭니다.

플레이어는 한쪽 경사로로 성벽에 올라가 원거리 적 하나를 먼저 끊고 반대쪽을 반사로 상대하거나, 마당 한가운데서 근거리 적을 먼저 처리하는 등 순서를 직접 고릅니다. 샛길로 온 플레이어는 오른쪽 원거리 적의 등 뒤에서 싸움을 시작합니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 30m × 24m |
| 성벽 위 통로 | 좌우 벽을 따라 하나씩, 폭 약 3m, 높이 3m. 마당 안쪽(출구 쪽) 약 20m 구간에 둡니다. 오른쪽 통로의 안쪽 끝은 샛길과 이어집니다. |
| 경사로 | 성벽 위 통로마다 입구 쪽 끝에 하나씩, 벽을 따라 길이 약 8m, 폭 약 3m |
| 엄폐물 | 약 3m × 1m, 높이 2m의 블록 4개. 긴 쪽이 입구와 출구를 잇는 방향으로 놓여 한쪽 성벽의 사격만 막습니다. 왼쪽을 막는 것과 오른쪽을 막는 것을 번갈아 둡니다. |
| 적 | 근거리 일반 적 1명, 원거리 일반 적 2명 (좌우 성벽 위에 하나씩) |
| 입구와 출구 | 입구는 전초의 출구와 길이 약 5m의 통로로 잇습니다. 출구는 맞은편 벽의 가운데에 폭 약 6m로 두고, 사격 통로로 바로 이어집니다. |

### 사격 통로

단상 위의 사수 하나가 통로 끝에서 쏘는 구간입니다. 칸막이 뒤에 숨었다가 틈을 달려 다음 칸막이로 옮기기를 되풀이하며 다가가, 경사로를 뛰어올라 사수를 처치합니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 30m, 폭 약 6m |
| 칸막이 | 벽과 같은 높이, 두께 약 1m, 벽에서 약 3m 튀어나온 칸막이 3개. 좌우 벽에서 번갈아 약 5m 간격으로 둡니다. |
| 경사로 | 칸막이 뒤에서 단상까지 통로 폭 전체로, 길이 약 8m |
| 단상 | 통로 끝에 길이 약 4m, 높이 3m. 단상의 끝은 안뜰 쪽으로 열린 가장자리입니다. |
| 적 | 원거리 일반 적 1명 (단상 위) |
| 시야 | 칸막이가 통로를 엇갈려 가려, 사수가 마당까지 볼 수 없어야 합니다. |

### 안뜰

이 던전의 마지막 일반 교전입니다. 단상에서 뛰어내려 들어오면 출구가 잠깁니다.

1차 웨이브는 근거리 적 둘입니다. 둘을 처치하면 좌우 경사로 끝의 막힌 곳이 열리며 발코니에 원거리 적이 하나씩 나타나고, 출구 옆 대기실에서 근거리 적이 나옵니다. 정면의 근거리 적과 싸우면서 좌우의 교차 사격을 다시 감당해야 하는, 지금까지 배운 것을 모두 쓰는 싸움입니다.

| 항목 | 조건 |
| - | - |
| 모양과 크기 | 지름 약 26m의 원형 평지 |
| 진입 | 사격 통로의 단상(높이 3m)에서 뛰어내립니다. 안뜰에서 단상으로 다시 올라갈 수 없습니다. |
| 발코니 | 원의 좌우(±Y) 꼭대기 벽 너머에 하나씩, 약 4m × 3m, 높이 1.5m. 2차 웨이브의 대기실입니다. |
| 발코니 경사로 | 발코니마다 둥근 벽을 따라 출구 쪽으로 안뜰 바닥까지 내려오는 경사로. 길이 약 6m, 폭 약 2m. 처음부터 보이며, 위쪽 끝이 막혀 있어 무언가 나올 곳임을 미리 알려 줍니다. |
| 출구 옆 대기실 | 출구 왼쪽(+Y) 옆의 둥근 벽 너머에 약 4m × 4m |
| 1차 웨이브 | 근거리 일반 적 2명 |
| 2차 웨이브 | 원거리 일반 적 2명 (좌우 발코니에 하나씩), 근거리 일반 적 1명 (출구 옆 대기실) |
| 출구 | 단상 맞은편 벽, 폭 약 6m |

### 대기 공간 (탑 1층)

보스 아레나에 들어가기 전에 숨을 돌리는 공간입니다. 던전 내내 보이던 탑의 1층이며, 탑을 통과하면 보스 아레나입니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 10m × 10m |
| 탑 | 대기 공간을 1층으로 하는 약 10m × 10m의 탑. 시작 지점의 언덕과 각 구간에서 성벽 위로 보이도록 높이 약 20m로 둡니다. 올라갈 수 없습니다. |
| 연결 | 안뜰과 보스 아레나 사이에 두고, 양쪽과 길이 약 6m의 곧은 통로로 잇습니다. |
| 시야 | 통로 너머로 아레나 안의 커스터가 보여야 합니다. 커스터까지 약 35m 떨어져 있어 커스터의 시야(20m) 밖입니다. |
| 적 | 없음 |

### 보스 아레나

커스터와 싸우는 구역입니다. 크기, 바닥, 장애물, 경계는 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)의 '보스 아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 33m (보스 전장의 원형 단상 방 내부와 같은 크기) |
| 입구 | 대기 공간 쪽 벽의 가운데, 폭 약 5m. 위 '잠금 적용 범위'를 따릅니다. |
| 전투 시작 | 입구에서 약 2m 들어오면 입구가 닫히고, 약 5m 들어오면 커스터의 시야(20m)에 들어가 전투가 시작됩니다. |

## 건의 사항

이 던전을 만들려면 다른 담당 과제의 협조가 필요합니다. 아래는 해당 담당자에게 건의할 내용이며, 받아들여지지 않으면 함께 적은 대안으로 던전을 고칩니다.

### 원거리 일반 적 Spec: 높이를 겨냥하는 투사체

- **건의:** 원거리 일반 적의 투사체는 발사 순간 플레이어의 캡슐 중심을 향해, 위아래 각도까지 맞춰 쏘게 해 주세요. 패리로 반사할 수 있고, 피하거나 반사할 여유가 있는 속도면 좋습니다.
- **이유:** 지금의 투사체는 발사자의 정면으로 수평으로만 날아갑니다 (커스터 검기와 같은 방식). 이 던전의 원거리 적은 1.5m ~ 3m 높이에 서 있어서, 수평으로 쏘면 바닥에 있는 플레이어의 머리 위로 지나가 맞지 않습니다. 교차 사격, 사격 통로, 반사 학습이 모두 성립하지 않습니다.
- **반사:** 반사된 투사체는 이미 원래 발사자의 위치를 향해 위아래 각도까지 맞춰 날아가므로 바꿀 것이 없습니다. ([플레이어 캐릭터 - 린](<../Content/플레이어 캐릭터 - 린.md>)의 '투사체 반사')
- **받아들여지지 않을 때의 대안:** 원거리 적을 모두 플레이어와 같은 높이로 옮깁니다. 망대, 성벽 위 통로, 발코니를 없애고 원거리 적을 바닥 높이의 같은 자리에 둡니다. 사격 통로는 마당 출구에서 경사로로 3m 올라간 뒤 통로 전체를 3m 높이로 두어 사수와 같은 높이에서 다가가게 합니다. 이때 '올라갈까, 받아칠까'는 '붙을까, 받아칠까'로, 샛길은 마당 오른쪽 원거리 적의 등 뒤 바닥으로 나오도록 바꾸며, '남겨 둔 적의 대가'는 성립하지 않으므로 뺍니다.

## 미확정 항목

일반 적의 기획이 나오기 전에 정한 값이 있어, 아래는 적이 확정되거나 플레이해 본 뒤 조정합니다.

- **원거리 일반 적의 투사체:** 위 '건의 사항'을 따릅니다. 히트스캔(쏘는 즉시 맞는 공격)이거나 반사할 수 없으면 던전 구성을 다시 검토합니다.
- **원거리 일반 적의 시야:** 마당의 성벽 위 원거리 적은 마당 입구까지 약 29m를 볼 수 있다는 전제로 배치했습니다. 시야가 짧으면 원거리 적을 입구 쪽으로 옮기고, 너무 길어 앞 구간에서 다음 구간의 적이 플레이어를 보면 구간 사이 통로를 꺾습니다.
- **전망 지점과 샛길의 노출:** 전망 지점(높이 6m)에서 전초의 원거리 적까지 약 28m입니다. 원거리 적의 시야가 이보다 길면 전투가 언덕 위에서 시작되므로, 전초의 진입로 쪽 벽을 높이거나 전망 지점을 뒤로 물립니다. 샛길에서 마당으로 나오는 순간 왼쪽 원거리 적이 플레이어를 정면 각도 안에 두면 선제공격의 의미가 약해지므로, 원거리 적의 정면 각도가 정해지면 출구 위치를 확인합니다.
- **원거리 적의 수:** 원거리 적이 6명으로, 결투 회랑보다 피격이 잦을 수 있습니다. 마당이나 안뜰 2차 웨이브가 지나치게 어려우면 원거리 적을 하나씩 근거리 적으로 바꿉니다.
- **아래에 몰린 근거리 적:** 근거리 일반 적의 시야는 12m입니다 ([근거리 일반 적 Spec](<../../../Specs/근거리 일반 적/1-spec.md>)). 안뜰의 1차 근거리 적은 단상 가장자리에서 약 13.6m 떨어져 있어, 플레이어가 단상 위에 있는 동안에는 보지 못합니다. 시야 값이 바뀌어 단상 아래로 몰려들면 근거리 적을 출구 쪽으로 옮깁니다.
- **엄폐물 높이:** 높은 곳에서 쏘는 투사체가 높이 2m 엄폐물을 넘어 플레이어에게 닿으면 엄폐물을 높이거나 원거리 적의 위치를 낮춥니다.
- **탑의 높이:** 시작 지점과 각 구간에서 성벽 위로 탑이 보이는지 그레이박스에서 확인하고 높이를 조정합니다.
- **잠긴 아레나에서 커스터의 이동:** 닫힌 출입구는 적을 막지 않으므로 커스터의 돌진이 통로로 빠져나갈 수 있습니다. 결투 회랑과 같이 플레이해 보고 정합니다.
