# 스테이지 - 미니던전 요새 돌파

미니던전 '요새 돌파'의 레벨인 LV_FortressBreach의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 그레이박스 지형, 동선, 적 배치로 재미를 만드는 것을 전제로 하며, 기능 구현이 필요한 요소는 성문 하나뿐입니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'를 따릅니다.

레벨의 모양은 [요새 돌파 3D](<요새 돌파 3D.html>)에서 돌려 볼 수 있습니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_FortressBreach |
| 컨셉 | 높은 시작 지점에서 멀리 보스 아레나까지 내려다본 뒤, 평지를 달려 원거리 적의 사격을 패리로 받아치며 다가가 직접 벱니다. 통로, 마당, 언덕길을 지나 성문 단 위에서 내려다보며 쏘는 사수들에게 올라가 베고, 성문을 열어 그 너머의 커스터에게 도착합니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 LV_SimulationRoom과 같습니다. |
| 등장 적 | 근거리 일반 적 6명, 원거리 일반 적 7명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 약 7분 (이동 약 1분, 일반 교전 합계 약 3분, 커스터전 약 3분) |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 레벨에 배치하는 회복 수단 | 없음 |

## 설계 의도

이 던전의 주인공은 원거리 일반 적입니다. 요새 돌파는 멀리서 쏘는 적에게 패리로 공격을 쳐내고 스킬과 이동으로 붙어서 베는 재미를 주는 던전입니다.

약 7분의 짧은 던전이므로 중심은 전투입니다. 탐험은 전투 사이의 양념으로, 미리 내려다보는 높은 시작 지점 하나만 둡니다.

지형은 높은 시작 지점과 평지, 완만한 언덕길, 그리고 성문 앞의 낮은 단으로 이루어집니다. 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 자리에 서 있습니다.

재미 요소는 아래와 같습니다. 성문을 빼면 모두 지형과 적 배치만으로 만들어집니다.

- **먼저 내려다보기:** 시작 지점은 요새 바깥의 높은 단(16.5m) 위입니다. 출발하자마자 마당과 성문 단이 내려다보이고, 그 뒤로 높이 솟은 보스 아레나의 벽이 최종 목적지를 알려 줍니다. 두 번에 걸친 내리막을 따라 내려가며, 앞으로 지나갈 곳을 미리 본 플레이어는 나중에 '아까 본 그곳'에 도착합니다.
- **패리로 다가가기:** 사수의 탄환을 패리하면 쏜 사수에게 되돌아갑니다. 통로에는 가릴 것이 하나도 없어, 사수 하나를 상대로 패리하며 걸어 들어가거나 빠르게 달려들어 베는 법을 처음 익힙니다. 마당과 언덕길, 성문 앞을 거치며 점점 바쁜 상황에서 같은 일을 하게 됩니다.
- **붙으면 이긴다:** 사수는 가까이 붙으면 쉽게 쓰러집니다. 다가가는 동안의 긴장과 붙은 뒤의 시원함이 이 던전의 기본 박자입니다.
- **근접전 속의 사격:** 마당에서는 근거리 적과 싸우는 동안 안쪽 단 위의 사수가 내려다보며 쏩니다. 사수에게 가려면 왼쪽 벽을 따라 놓인 경사로로 단에 올라야 합니다.
- **언덕길 오르기:** 완만한 오르막 위에서 사수가 내려다보며 쏩니다. 오르막에는 가릴 것이 없고, 올라가는 도중 왼쪽 벽의 움푹한 자리에 선 근거리 적이 옆에서 나옵니다. 오르막을 다 오르면 안쪽의 사수와 모퉁이 뒤의 근거리 적이 기다립니다.
- **튀어나온 보루:** 성문은 평지보다 높은 단 위에 있고, 단의 가운데가 평지 쪽으로 튀어나와 보루를 이룹니다. 보루 끝의 사수가 평지를 내려다보며 쏩니다. 보루의 앞과 양옆은 해자가 ㄷ자로 둘러, 해자에 내려가도 보루로는 올라설 수 없습니다. 단으로 오르는 좌우 경사로의 꼭대기는 근거리 적이 하나씩 지킵니다. 린의 스킬 1로 보루의 사수에게 올라서면 경사로를 거치지 않고 단 위로 바로 진입합니다.
- **사수에서 사수로:** 단 위에 올라서면 보루의 사수와 성문 앞의 사수 둘을 차례로 벱니다. 올라가는 동안의 긴장을 단 위에서 연달아 베며 돌려받습니다.
- **내 손으로 여는 성문:** 성문 앞의 방어선을 뚫고 성문에 다가가 직접 엽니다. 마지막 방어선을 뚫었다는 마침표이자, 커스터전에 들어가기 전의 한 호흡입니다.

린의 스킬 1은 이 던전에서 있으면 편한 보조 수단입니다. 어느 구간도 스킬 1 없이 걸어서 풀 수 있어야 합니다.

난이도는 진입로(근거리 1명) → 통로(원거리 1명) → 마당(근거리 1명 + 원거리 1명) → 언덕길(근거리 1명 + 원거리 1명) → 언덕 위(근거리 1명 + 원거리 1명) → 성문 앞(근거리 2명 + 원거리 3명) → 커스터 순서로 이어집니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 체크포인트와 활성화 볼륨은 없습니다.
- 길을 막는 장치는 성문 하나뿐입니다. 성문 앞까지는 구간 사이에 문을 두지 않아, 플레이어는 적을 남겨 둔 채 다음 구간으로 지나갈 수 있습니다.
- 바닥의 기준 높이는 0m입니다. 시작 지점(16.5m)에서 중간 단(6m)을 거쳐 내려와 통로와 마당은 0m이고, 언덕길로 4m까지 올라가 언덕 위, 성문 앞의 평지, 보스 아레나는 4m입니다. 성문 앞 뒤쪽의 성문 단과 보루는 6m이고, 보루를 두르는 해자의 바닥은 3m입니다. 마당 안쪽의 단은 약 1.5m입니다.
- 왼쪽과 오른쪽은 요새 방향(+X)을 바라본 기준으로 적고, 진행 방향이 다른 구간에서는 축을 함께 적습니다.
- 벽은 높이 4m 이상으로 만들어 플레이어가 점프로 넘을 수 없게 합니다. 천장은 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 보스 아레나와 그 앞 통로의 벽은 높이 약 20m로 세워, 시작 지점에서 최종 목적지가 보이게 합니다.
- 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 바닥 위에 섭니다. 높은 자리에 둘 때는 마당의 단이나 성문 단처럼 경사로로 걸어 올라갈 수 있게 합니다.
- 원거리 적의 앞에는 난간, 낮은 담, 흉벽을 두지 않습니다. 사수는 총구와 플레이어 사이가 가려지면 쏘지 않으므로([일반 적 - 경비 사수](<../Content/일반 적 - 경비 사수.md>)의 '조준'), 사수 자리에서 그 구간의 바닥이 보여야 합니다.
- 엄폐물과 기둥은 두지 않습니다. 구간 안을 가로질러 길을 나누는 긴 벽도 두지 않습니다.
- 큰 길은 하나이며, 시작 지점에서 보스 아레나 입구까지의 이동 거리는 약 240m입니다. 갈림길은 성문 앞의 좌우 경사로뿐입니다.

## 구간

### 진입로

요새 바깥의 높은 시작 지점에서 출발해, 멀리 보스 아레나를 내려다보며 두 번에 걸쳐 내려가는 구간입니다.

| 항목 | 조건 |
| - | - |
| 시작 지점 | 높이 16.5m, 약 8m × 6m의 단. 요새 방향(+X)을 뺀 세 면은 높이 약 3.6m의 담으로 막습니다. |
| 첫째 내리막 | 시작 지점에서 요새 방향(+X)으로 곧게 길이 약 14m, 폭 약 5m. 16.5m에서 6m로 내려갑니다. 양옆에 난간을 둡니다. |
| 중간 단 | 높이 6m, 약 12m × 12m. 첫째 내리막이 끝나는 자리입니다. 가장자리는 높이 약 3.9m의 담으로 두르고, 두 내리막이 닿는 곳만 틉니다. |
| 둘째 내리막 | 중간 단에서 왼쪽(-Y)으로 90도 꺾어 길이 약 12m, 폭 약 5m. 6m에서 0m로 내려갑니다. 양옆에 난간을 둡니다. 바닥에 닿으면 오른쪽(+X)으로 꺾어 통로 입구에 닿습니다. |
| 적 | 근거리 일반 적 1명 (중간 단) |

- 중간 단의 근거리 적은 첫째 내리막을 내려오는 플레이어를 약 11m 거리에서 발견합니다.

### 통로

원거리 적 하나만 있는 구간입니다. 가릴 것이 없는 긴 일자 통로 끝의 사수를 향해, 패리하며 걸어 들어가거나 빠르게 달려들어 베는 법을 익힙니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 27m, 폭 약 6m의 곧은 평지 |
| 장애물 | 없음 |
| 적 | 원거리 일반 적 1명 (통로 끝) |
| 출구 | 통로 끝의 오른쪽(+Y) 벽에 폭 약 7m. 오른쪽 앞으로 비스듬히 꺾인 길이 약 14m의 통로로 마당 입구와 이어집니다. 통로 끝에 다가가면 꺾인 길의 안쪽이 보여 어디로 가야 하는지 알 수 있습니다. |

- 통로의 사수는 둘째 내리막을 거의 다 내려온 플레이어를 약 21m 거리에서 발견합니다.

### 마당

이 던전의 첫 번째 섞인 싸움입니다. 넓은 마당에서 근거리 적과 싸우는 동안 안쪽 단 위의 원거리 적이 내려다보며 쏩니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 20m × 24m의 평지 |
| 단 | 출구 쪽 왼쪽(-Y) 모서리에 높이 약 1.5m, 약 8m × 9m. 입구 쪽에서 왼쪽 벽을 따라 놓인 폭 약 4.5m의 경사로로 오릅니다. 점프 최고 높이(약 1.2m)보다 높아 경사로로만 오를 수 있습니다. |
| 장애물 | 없음 |
| 적 | 근거리 일반 적 1명 (입구 쪽 벽에서 약 10m, 오른쪽 벽에서 약 8m), 원거리 일반 적 1명 (단 위). 둘은 한 그룹입니다. |
| 입구와 출구 | 입구는 폭 약 5m로, 통로에서 온 비스듬한 통로와 잇습니다. 출구는 맞은편 벽의 가운데에 폭 약 6m로 두고, 곧은 통로로 이어집니다. 그 통로 끝의 오른쪽(+Y)에서 언덕길이 시작됩니다. |

- 단 위의 사수는 비스듬한 통로의 끝에 이른 플레이어를 약 24m 거리에서 발견합니다.

### 언덕길

완만한 오르막 위에서 원거리 적이 내려다보며 쏘는 구간입니다. 오르막에는 가릴 것이 없고, 올라가는 도중 왼쪽 벽의 움푹한 자리에 근거리 적이 서 있습니다. 오르막은 오른쪽(+Y)을 향해 오르며, 이 구간의 왼쪽은 오르는 방향을 바라본 왼쪽(+X)입니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 30m, 폭 약 8m. 0m에서 4m까지 고르게 올라갑니다. |
| 장애물 | 없음 |
| 움푹한 자리 | 오르막 시작에서 약 7m 지점의 왼쪽 벽에 폭 약 4m의 입구를 둡니다. 안쪽은 깊이 약 7.5m의 막힌 공간이며, 바닥은 오르막과 같은 기울기입니다. |
| 적 | 원거리 일반 적 1명 (오르막이 끝난 자리에서 약 2m 뒤), 근거리 일반 적 1명 (움푹한 자리 안쪽) |

- 위의 사수는 오르막에 들어선 플레이어를 약 30m 거리에서 발견합니다.
- 움푹한 자리의 근거리 적은 오르막을 약 5m 올라온 플레이어를 입구 너머로 약 11m 거리에서 발견합니다.

### 언덕 위

언덕길과 성문 앞을 잇는 꺾인 구간입니다. 오르막이 끝난 평지 안쪽에 원거리 적이, 모퉁이를 돈 통로 안에 근거리 적이 있습니다.

| 항목 | 조건 |
| - | - |
| 크기 | 오르막이 끝난 자리에서 요새 방향(+X)으로 길이 약 16m, 폭 약 5 ~ 6m의 평지. 그 끝에서 폭 약 5m의 통로가 오른쪽(+Y)으로 약 9m 이어지고, 다시 요새 방향으로 꺾여 성문 앞 입구에 닿습니다. |
| 장애물 | 없음 |
| 적 | 원거리 일반 적 1명 (평지 안쪽, 오르막 쪽을 바라봄), 근거리 일반 적 1명 (모퉁이를 돈 통로 안, 평지 쪽을 바라봄) |

- 평지 안쪽의 사수는 오르막을 거의 다 올라온 플레이어를 약 10m 거리에서 발견합니다.
- 통로 안의 근거리 적은 평지 안쪽으로 들어온 플레이어를 약 4m 거리에서 발견합니다.

### 성문 앞

이 던전의 마지막 일반 교전입니다. 구간의 뒤쪽을 높은 단이 가로지르고, 성문은 그 단 위에 있습니다. 단의 가운데는 평지 쪽으로 튀어나와 보루를 이루고, 그 끝에 사수 하나가 서서 평지를 내려다보며 쏩니다. 평지에는 엄폐물을 두지 않습니다.

보루의 앞과 양옆은 깊이 1m의 해자가 ㄷ자로 두릅니다. 해자에는 입구 쪽의 오르막으로 걸어 드나들 수 있지만, 해자 바닥에서 보루 위까지는 3m라 올라설 수 없습니다. 보루의 사수에게 가는 길은 경사로를 돌아 오르거나 린의 스킬 1로 해자를 건너 올라서는 것뿐입니다.

단으로 오르는 길은 좌우 벽을 따라 놓인 경사로 둘입니다. 입구 앞의 평지에서 해자 옆의 좁은 길을 지나 경사로에 닿으며, 경사로 꼭대기의 단 위는 근거리 적이 하나씩 지킵니다. 성문 바로 앞에는 사수 둘이 나란히 서서 좌우 경사로 쪽을 바라봅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 24m (평지 높이 4m). 입구에서 약 21m까지가 평지와 해자이고, 그 뒤 약 12m가 성문 단입니다. |
| 평지 | 입구 앞에 깊이 약 5m. 좌우 벽을 따라 폭 약 4m의 길이 경사로까지 이어집니다. |
| 해자 | 평지 가운데의 약 16m × 16m, 깊이 1m의 구덩이(바닥 높이 3m). 보루의 앞(폭 약 8m)과 양옆(폭 약 4m)을 ㄷ자로 두릅니다. 입구 쪽 가장자리의 가운데에 폭 약 4.5m의 오르막을 두어 평지와 걸어서 오갑니다. |
| 울타리 | 좌우 길의 해자 쪽 가장자리에 높이 약 1m의 낮은 울타리를 길이 약 8m씩 둡니다. 경사로가 시작되는 곳에서 끝납니다. |
| 성문 단 | 평지보다 2m 높은 단(높이 6m). 구간의 폭 전체를 가로지릅니다. 평지 쪽 가장자리에는 난간을 두지 않습니다. 2m는 점프 최고 높이(약 1.2m)보다 높아 경사로로만 오를 수 있습니다. |
| 경사로 | 좌우 벽에 붙여 하나씩. 길이 약 8m, 폭 약 4m로 평지에서 단 위까지 오릅니다. 단의 앞쪽으로 뻗어 나와 있습니다. |
| 보루 | 단의 가운데가 평지 쪽으로 약 8m 튀어나온 부분. 폭 약 8m, 단과 같은 높이(6m)이며 난간을 두지 않습니다. |
| 근거리 적 | 2명. 좌우 경사로 꼭대기의 단 위에 하나씩 섭니다. |
| 원거리 적 | 3명. 하나는 보루 끝에서 약 1.5m 안쪽에, 둘은 성문에서 약 3.5m 앞에 좌우로 약 2m 떨어져 섭니다. |
| 그룹 | 보루의 사수와 근거리 적 둘이 한 그룹, 성문 앞의 사수 둘이 한 그룹입니다. |
| 성문 | 단 위, 입구 맞은편 벽의 가운데에 폭 약 5m. 처음에는 닫혀 있습니다. 아래 '성문'을 따릅니다. |

- 보루의 사수는 성문 앞에 들어서기 전, 언덕 위의 통로를 지나는 플레이어를 성문 앞 입구 너머로 약 23m 거리에서 발견합니다.
- 성문 앞의 사수 둘은 입구 앞의 평지에서 좌우 길로 들어서는 플레이어를 약 28m 거리에서 발견합니다.

#### 성문

성문 앞과 보스 아레나 사이를 막는 문입니다. 이 던전에서 플레이어가 상호작용하는 유일한 장치입니다. 상호작용 대상을 고르는 순서, 입력, 안내는 [플레이어 시스템](<../System/플레이어 시스템.md>)의 '상호작용'과 [UI 시스템](<../System/UI 시스템.md>)의 '상호작용 안내'를 따릅니다.

| 항목 | 조건 |
| - | - |
| 위치와 크기 | 성문 단(높이 6m) 위, 성문 앞 구간 입구 맞은편 벽의 가운데. 폭 약 5m. |
| 처음 상태 | 닫혀 있습니다. 닫힌 성문은 플레이어와 적의 이동, 시선, 탄환을 모두 막습니다. |
| 여는 조건 | 없습니다. 성문 앞에 적이 남아 있어도 열 수 있습니다. |
| 안내에 적는 행동 | 성문 열기 |
| 상호작용 범위 | 성문의 폭 전체에서, 성문 앞 구간 쪽(보스 아레나의 반대쪽) 면으로부터 1m, 바닥에서 2.5m 높이까지입니다. 보스 아레나 쪽에서는 상호작용할 수 없습니다. |
| 안내 지점 | 상호작용하는 쪽의 성문 면에서 폭의 가운데, 바닥에서 1.2m 높이입니다. |
| 열리는 중 | 상호작용하면 성문이 약 2초 동안 위로 올라갑니다. 올라가는 동안에는 올라간 만큼 문 아래가 열리고, 성문은 문이 있는 높이에서만 이동, 시선, 탄환을 막습니다. 문 아래가 약 1.6m 열리면(상호작용한 지 약 0.7초 뒤) 린이 문 아래로 지나갈 수 있습니다. 열리기 시작한 성문은 상호작용 후보에서 빠지므로 안내가 바로 사라지고, 다시 상호작용 키를 눌러도 성문에는 아무 일도 일어나지 않습니다. |
| 열린 뒤 | 끝까지 올라간 성문은 이동, 시선, 탄환을 막지 않고, 다시 닫히지 않습니다. |
| 재도전 | [게임 플로우](<../System/게임 플로우.md>)의 Restart나 타이틀을 통한 새 도전에서는 닫힌 상태로 다시 시작합니다. |

- 상호작용 범위 1m, 열리는 시간 2초, 안내 지점의 높이 1.2m는 플레이해 보고 조정합니다.

### 보스 아레나

커스터와 싸우는 구역입니다. 성문을 지나 길이 약 10m의 곧은 통로로 이어지며, 이 통로는 성문 단의 높이(6m)에서 아레나의 높이(4m)까지 완만하게 내려갑니다. 크기, 바닥, 장애물, 경계는 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 33m (시뮬레이션 룸의 원형 단상 방 내부와 같은 크기) |
| 입구 | 성문 쪽 벽의 가운데, 폭 약 5m |
| 시야 | 성문이 열리면 통로 너머로 아레나 안의 커스터가 보입니다. 커스터는 아레나 안으로 약 5m 들어온 플레이어를 발견합니다. |

- 따로 쉬어 가는 대기 공간은 두지 않습니다. 적을 정리한 성문 앞과, 성문을 열고 지나는 통로가 그 역할을 합니다.

## 미확정 항목

아래는 플레이해 본 뒤 조정합니다.

- **구간 크기와 거리:** 각 구간의 길이, 폭, 적 사이의 거리는 플레이해 보고 조정합니다.
- **원거리 적의 수:** 원거리 적이 7명으로, 피격이 잦을 수 있습니다. 성문 앞이 지나치게 어려우면 원거리 적을 하나씩 줄이거나 근거리 적으로 바꿉니다.
- **예상 플레이 시간:** 약 7분은 적의 수와 이동 거리로 어림한 값입니다. 플레이해 보고 고칩니다.
- **가릴 것 없는 통로:** 사수까지 약 21m를 달려서 다가갈 때 사수가 몇 발을 쏘는지, 패리와 달려들기 중 한쪽만 고르게 되지 않는지 플레이해 보고 통로 길이를 조정합니다.
- **마당 단 위 사수의 등 뒤:** 사수가 출구 쪽 벽에서 약 2m 떨어져 있어, 스킬 1로 등 뒤에 나타날 자리가 없습니다. 옆에 나타나는 일이 불편하면 사수를 벽에서 떼어 놓습니다.
- **언덕길 사수의 사격:** 오르막 위의 사수가 오르막 아래의 플레이어를 실제로 조준해 쏘는지 확인합니다. 쏘지 않으면 사수 자리를 경사면 쪽으로 옮기거나 경사를 낮춥니다.
- **뒤로 걷는 사수:** 경비 사수는 플레이어가 8m 안으로 들어오면 뒤로 걷습니다. 통로 끝에서 사수가 벽에 붙는지, 마당의 단과 보루 위에서 사수가 뒤로 물러나 아래를 보지 못하게 되는지 플레이해 보고 사수 자리를 조정합니다.
- **성문 단 사수의 사격:** 단 위의 사수가 평지의 플레이어를 실제로 조준해 쏘는지 플레이해서 확인합니다. 쏘지 않으면 사수를 가장자리 쪽으로 옮기거나 단을 낮춥니다.
- **스킬 1로 해자 건너기:** 플레이어가 해자를 보고 스킬 1로 보루의 사수에게 건너갈 생각을 하는지, MP가 모자랄 때 경사로 쪽 싸움이 지나치게 어렵지 않은지 플레이해서 확인합니다.
- **성문 단의 높이와 경사로:** 높이 2m, 경사로 길이 8m는 플레이해 보고 조정합니다. 근거리 적이 경사로를 오르내리며 따라오는지도 함께 확인합니다.
- **성문 앞의 두 경사로:** 한쪽 경사로만 고르게 되는지 플레이해 보고, 근거리 적의 수와 사수의 자리로 조정합니다.
- **성문 앞의 사수와 성문:** 사수 둘이 성문에서 약 3.5m 앞에 서 있어, 그로기에 빠진 사수의 처형과 성문 열기가 가까운 자리에서 겹칠 수 있습니다. 상호작용 대상이 뜻대로 골라지는지 플레이해서 확인합니다.
- **구간을 지나치는 플레이:** 성문 앞까지는 길을 막는 장치가 없어 적을 무시하고 달려 지나갈 수 있습니다. 남겨 둔 적이 다음 구간까지 따라와 문제가 되면 구간 사이 통로의 길이와 꺾임으로 조정합니다.
- **보스 아레나에서 커스터의 이동:** 열린 성문은 다시 닫히지 않아 커스터의 돌진이 통로로 빠져나갈 수 있습니다. 플레이해 보고 정합니다.
