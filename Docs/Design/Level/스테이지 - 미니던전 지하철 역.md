# 스테이지 - 미니던전 지하철 역

미니던전 '지하철 역'의 레벨인 LV_Subway의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 그레이박스 지형, 동선, 적 배치로 재미를 만드는 것을 전제로 하며, 기능 구현이 필요한 요소는 성문 하나뿐입니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_Subway |
| 컨셉 | 지상의 출입구에서 지하철역으로 내려가, 대합실과 승강장을 지나 선로를 따라 차량기지까지 걸어 들어갑니다. 지형이 적을 갈라 놓는 던전입니다. 플레이어는 개찰구를 뛰어넘고 선로로 내려설 수 있지만, 적은 틈과 계단으로 돌아와야 합니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 LV_SimulationRoom과 같습니다. |
| 등장 적 | 근거리 일반 적 7명, 원거리 일반 적 6명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 약 7분 (이동 약 1분, 일반 교전 합계 약 3분, 커스터전 약 3분) |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 레벨에 배치하는 회복 수단 | 없음 |

레벨을 돌려 보며 높이를 확인하려면 [지하철 역 3D](<지하철 역 3D.html>)를 브라우저로 엽니다.

## 설계 의도

지하철 역은 지형이 적을 갈라 놓는 던전입니다. 플레이어는 점프와 낙하로 지름길을 내지만 적은 걸어서 돌아와야 하므로, 지형을 읽은 플레이어는 여러 적을 한꺼번에 상대하지 않고 하나씩 떼어 내어 싸웁니다.

재미 요소는 아래와 같습니다. 성문을 빼면 모두 지형과 적 배치만으로 만들어집니다.

- **아래로 내려가기:** 지상(0m)에서 대합실(-6m), 승강장(-11m)을 거쳐 선로(-12.5m)까지 계단을 따라 내려갑니다. 구간마다 한 층씩 내려가며, 내려갈수록 길이 좁고 길어집니다.
- **개찰구 넘기:** 대합실을 가로지르는 개찰구는 높이 0.8m로, 플레이어는 점프로 넘지만 적은 양쪽 끝의 틈으로 돌아와야 합니다. 개찰구를 넘어 안쪽의 사수에게 곧장 달려들면, 근거리 적이 틈을 돌아오는 동안 사수를 먼저 벨 수 있습니다.
- **세 갈래 승강장:** 승강장 끝의 사수 둘에게 가는 길이 셋입니다. 가릴 것 없는 승강장을 걸어가거나, 멈춘 전동차 안으로 들어가 사격을 피하며 다가가거나, 1.5m 아래 선로로 내려가 근거리 적을 떼어 놓고 다가갑니다. 전동차 안에는 근거리 적이 하나 있어, 사격을 피하는 대신 좁은 곳에서 싸워야 합니다.
- **대피소에서 대피소로:** 선로 터널 끝의 사수가 긴 일자 터널을 내려다보며 쏩니다. 터널 벽의 대피소에 들어가면 사격이 끊기므로, 대피소 사이를 옮겨 가며 다가가거나 패리하며 곧장 걸어갑니다.
- **작업차 뒤에서 시작하는 마지막 싸움:** 차량기지 앞에 세워 둔 작업차 두 대가 입구 쪽을 가려, 터널에서 나온 플레이어는 사수에게 겨눠지지 않은 채 근거리 적과 싸움을 시작합니다. 작업차 옆으로 나서면 안쪽 구석의 사수 둘에게 겨눠집니다.
- **내 손으로 여는 성문:** 차량기지로 들어가는 성문을 직접 열고 커스터에게 갑니다.

린의 스킬 1은 이 던전에서 있으면 편한 보조 수단입니다. 어느 구간도 스킬 1 없이 걸어서 풀 수 있어야 합니다.

구간의 모양도 서로 다르게 둡니다. 대합실은 개찰구가 가로지르고 기둥 네 개가 선 넓은 네모, 승강장은 전동차와 승강장과 선로가 나란히 놓인 긴 세 줄, 선로 터널은 대피소가 딸린 좁은 일자, 차량기지 앞은 작업차 둘이 놓인 네모입니다.

난이도는 대합실(근거리 3명 + 원거리 1명) → 승강장(근거리 2명 + 원거리 2명) → 선로 터널(원거리 1명) → 차량기지 앞(근거리 2명 + 원거리 2명) → 커스터 순서로 이어집니다. 선로 터널은 앞뒤의 큰 싸움 사이에서 짧게 긴장을 이어 주는 구간입니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 길을 막는 장치는 성문 하나뿐입니다. 성문 앞까지는 구간 사이에 문을 두지 않아, 플레이어는 적을 남겨 둔 채 다음 구간으로 지나갈 수 있습니다.
- 바닥 높이는 출입구가 0m, 대합실이 -6m, 승강장이 -11m이고, 선로부터 보스 아레나까지는 모두 -12.5m입니다. 구간 사이는 모두 계단으로 잇습니다.
- 벽은 출입구가 바닥에서 4m, 대합실이 5m, 승강장부터는 6m 높이이며, 점프로 넘을 수 없습니다. 천장은 두지 않으며, 같은 까닭으로 전동차에도 지붕이 없습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 떨어지는 높이는 승강장에서 선로로 내려서는 1.5m가 가장 커서, 레벨 어디에서도 낙하 대미지를 받지 않습니다.
- 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 바닥 위에 서고, 뒤쪽 벽에서 3m 이상 떨어뜨려 둡니다. 린의 스킬 1은 대상의 등 뒤 3m에 나타나므로, 그 자리에 바닥이 있어야 합니다.
- 장애물은 개찰구, 기둥, 전동차, 작업차 네 가지입니다. 개찰구(높이 0.8m)는 시선과 탄환을 가리지 않고 점프로 넘을 수 있습니다. 기둥, 전동차의 벽(2.5m), 작업차(2.2m)는 시선과 탄환을 가리며 점프로 넘을 수 없습니다.
- 큰 길은 하나이며, 시작 지점에서 보스 아레나 중심까지의 이동 거리는 약 190m입니다. 승강장의 세 갈래 길은 승강장 끝에서 다시 합쳐집니다.

## 구간

### 출입구

지상의 출입구에서 대합실로 내려가는 구간입니다.

| 항목 | 조건 |
| - | - |
| 시작 지점 | 높이 0m, 약 5m × 5m의 단. 계단 쪽(+X)을 뺀 세 면은 높이 4m의 벽으로 막습니다. |
| 계단 | 폭 5m, 길이 약 9.3m. 0m에서 -6m까지 한 단 20cm로 곧게 내려가 대합실 입구 벽의 가운데로 들어갑니다. |
| 적 | 없음 |

- 계단을 3분의 2쯤 내려오면 대합실 안쪽의 사수가 약 30m 거리에서 플레이어를 보고 쏘기 시작합니다. 계단 끝에 닿을 즈음에는 대합실 앞쪽의 근거리 적도 플레이어를 봅니다.

### 대합실

이 던전의 첫 번째 큰 싸움입니다. 넓은 대합실을 개찰구가 가로질러 앞쪽과 안쪽으로 나눕니다.

입구로 들어서면 앞쪽의 근거리 적 하나가 다가오고, 개찰구 너머 안쪽의 사수가 쏩니다. 개찰구에 다가가면 안쪽의 근거리 적 둘도 플레이어를 보고 개찰구 양쪽 끝의 틈으로 돌아 나옵니다. 플레이어는 개찰구를 뛰어넘어 사수에게 곧장 갈 수 있고, 근거리 적은 틈까지 돌아오느라 늦게 따라옵니다. 기둥은 숨어서 버티는 자리가 아니라 사수의 사격을 잠깐 끊는 자리입니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 30m × 24m의 평지 (높이 -6m) |
| 개찰구 | 입구 벽에서 약 15m 들어온 자리에서 대합실을 가로지릅니다. 길이 20m, 두께 0.4m, 높이 0.8m입니다. 양쪽 옆벽과의 사이에 폭 2m의 틈이 하나씩 있어, 적은 이 틈으로만 지나갑니다. 플레이어는 점프(최고 높이 약 1.2m)로 넘습니다. |
| 기둥 | 4개 (약 1m × 1m, 벽 높이까지). 입구 벽에서 약 7.7m와 약 21.7m 들어온 자리에, 가운데 줄에서 좌우로 약 5.5m씩 떨어뜨려 둡니다. |
| 적 | 근거리 일반 적 3명 (개찰구 앞쪽에 하나, 안쪽에 둘), 원거리 일반 적 1명 (안쪽 벽 앞 가운데) |
| 입구와 출구 | 입구는 출입구 계단이 들어오는 앞쪽 벽의 가운데, 출구는 맞은편 벽의 가운데이며 둘 다 폭 5m입니다. 출구는 승강장으로 내려가는 계단입니다. |


### 승강장

이 던전의 두 번째 큰 싸움입니다. 대합실에서 내려온 계단이 승강장의 한쪽 끝에 닿고, 반대쪽 끝에 사수 둘이 서 있습니다. 승강장의 왼쪽(-Y)에는 전동차가 멈춰 있고, 오른쪽(+Y)은 1.5m 낮은 선로입니다.

사수에게 가는 길은 셋입니다.

- **승강장:** 가릴 것 없이 곧장 걸어갑니다. 가운데의 근거리 적과 싸우는 동안 끝의 사수 둘에게 겨눠집니다.
- **전동차:** 계단 바로 옆의 문으로 들어가 전동차 안을 걸어갑니다. 전동차의 벽이 사격을 가리지만, 둘째 칸에 근거리 적이 하나 있어 좁은 곳에서 싸워야 합니다. 둘째 칸의 마지막 문은 사수에게서 약 4m 떨어진 곳으로 나옵니다.
- **선로:** 계단 옆의 선로 계단으로 내려가거나 승강장 가장자리에서 뛰어내려 선로를 걸어갑니다. 1.5m는 점프로 오를 수 없어, 선로에서는 승강장 양쪽 끝의 선로 계단으로만 올라옵니다. 근거리 적도 선로 계단으로만 내려오므로, 선로로 내려서면 근거리 적을 떼어 놓을 수 있습니다. 승강장 끝의 선로 계단은 사수 바로 옆으로 올라옵니다.

선로는 승강장 끝에서 그대로 선로 터널로 이어집니다. 다음 구간으로 가려면 결국 선로로 내려가야 합니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 40m. 왼쪽부터 전동차(폭 3.2m), 승강장(폭 8m, 높이 -11m), 선로(폭 5m, 높이 -12.5m)가 나란히 놓입니다. |
| 전동차 | 승강장의 길이 전체에 걸친 두 칸. 벽 높이 2.5m, 지붕은 없고 안쪽 폭은 2.6m입니다. 승강장 쪽 벽에 문(폭 1.4m, 높이 2.1m)이 넷 있으며, 계단 끝에서 약 3m, 14m, 26m, 33m 지점입니다. 두 칸 사이에는 같은 크기의 통로문이 있습니다. 선로 쪽(바깥쪽)에는 문이 없습니다. |
| 선로 계단 | 2개. 승강장 가장자리에서 선로 쪽으로 내려가는 폭 2m, 한 단 15cm의 계단으로, 계단 끝에서 약 1~3m 지점과 약 32~34m 지점에 있습니다. 계단 옆의 선로 폭은 약 1.7m가 남습니다. |
| 적 | 근거리 일반 적 2명 (승강장 가운데에 하나, 전동차 둘째 칸 안에 하나), 원거리 일반 적 2명 (승강장 끝 벽에서 약 3.6m 앞에 나란히) |
| 입구와 출구 | 입구는 대합실에서 내려오는 계단(폭 5m)이 승강장 한쪽 끝의 가운데에 닿는 자리입니다. 출구는 선로가 이어지는 선로 터널입니다. |

- 끝의 사수 둘은 플레이어가 승강장이나 선로를 약 7m 걸어 들어오면 사격을 시작합니다.
- 선로는 승강장보다 1.5m 낮아, 승강장 가장자리에 붙어 걸으면 전동차 쪽 사수의 사격이 일부 가려집니다.

### 선로 터널

원거리 적 하나만 있는 구간입니다. 폭 5m의 긴 일자 터널 끝에서 사수가 쏘고, 터널 벽의 대피소에 들어가면 사격이 끊깁니다.

| 항목 | 조건 |
| - | - |
| 크기 | 길이 약 40m, 폭 5m의 곧은 평지 (높이 -12.5m) |
| 대피소 | 3개. 터널 벽을 폭 2m, 깊이 1.5m, 높이 2.5m로 판 홈이며, 터널 입구에서 약 7m(왼쪽 벽), 17m(오른쪽 벽), 27m(왼쪽 벽) 지점에 있습니다. 대피소 안은 터널 끝의 사수에게 보이지 않습니다. |
| 적 | 원거리 일반 적 1명 (터널 끝에서 약 3m 안쪽 가운데) |
| 출구 | 터널 끝이 그대로 차량기지 앞의 입구가 됩니다. |

- 사수는 플레이어가 첫 대피소에 닿을 즈음 사격을 시작합니다.

### 차량기지 앞

이 던전의 마지막 일반 교전입니다. 넓은 네모 공간의 안쪽 벽에 차량기지로 들어가는 성문이 있고, 성문 앞을 근거리 적 둘이 지키며, 안쪽 두 구석에서 사수 둘이 쏩니다.

입구 앞에는 작업차 두 대가 길 양옆에 서 있어, 입구에서 곧장 들어오는 가운데 길은 약 7m까지 두 사수 모두에게 보이지 않습니다. 플레이어는 이 자리에서 다가오는 근거리 적과 싸움을 시작하고, 작업차 옆으로 나서면 두 사수에게 겨눠집니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 24m × 24m의 평지 (높이 -12.5m) |
| 작업차 | 2대 (약 6m × 2.4m, 높이 2.2m). 입구 벽에서 약 7~13m 들어온 자리에, 가운데 줄의 좌우로 약 4~6.5m 떨어뜨려 길이 방향으로 세웁니다. |
| 근거리 적 | 2명. 입구 벽에서 약 17m, 가운데 줄의 좌우로 약 3m씩. 입구 쪽을 바라봅니다. |

#### 성문

차량기지 앞과 보스 아레나 사이를 막는 문입니다. 이 던전에서 플레이어가 상호작용하는 유일한 장치입니다. 처음 상태, 여는 조건, 안내, 상호작용 범위, 열리는 중과 열린 뒤, 재도전의 규칙은 [스테이지 - 미니던전 요새 돌파](<스테이지 - 미니던전 요새 돌파.md>)의 '성문'과 같습니다.

- 성문에서 가장 가까운 적(근거리 적)까지는 약 8m입니다.

### 보스 아레나

커스터와 싸우는 구역입니다. 성문을 지나 길이 8m, 폭 5m의 곧은 통로로 이어지며, 통로와 아레나는 차량기지 앞과 같은 높이(-12.5m)입니다. 크기, 바닥, 장애물, 경계는 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 33m (시뮬레이션 룸의 원형 단상 방 내부와 같은 크기) |
| 입구 | 통로 쪽 벽의 가운데, 폭 5m |
| 시야 | 성문이 열리면 통로 너머로 아레나 안의 커스터가 보여야 합니다. |

- 따로 쉬어 가는 대기 공간은 두지 않습니다. 적을 정리한 차량기지 앞과, 성문을 열고 지나는 통로가 그 역할을 합니다.

## 미확정 항목

구간의 크기, 거리, 적의 수는 그레이박스를 만들기 전에 정한 값이라, 아래는 플레이해 본 뒤 조정합니다.

- **구간 크기와 거리:** 각 구간의 길이, 폭, 장애물의 자리와 간격, 적 사이의 거리는 플레이해 보고 조정합니다.
- **예상 플레이 시간:** 약 7분은 적의 수와 이동 거리로 어림한 값입니다. 플레이해 보고 고칩니다.
- **계단 위의 사격:** 대합실 사수는 출입구 계단을 내려오는 플레이어를 약 30m 거리에서 쏘기 시작합니다. 계단 위에서 패리하기가 불편하지 않은지 확인합니다.
- **개찰구 넘기:** 플레이어가 개찰구를 넘어 사수에게 달려들 생각을 하는지, 근거리 적이 틈으로 돌아오는 동안 사수를 벨 여유가 있는지 플레이해 보고 개찰구의 길이와 틈의 자리를 조정합니다.
- **대합실 적 4명:** 입구에서 근거리 적 하나와 싸우는 동안 사수가 쏘고, 개찰구에 다가가면 근거리 적 둘이 더 옵니다. 지나치게 어려우면 안쪽의 근거리 적을 하나로 줄입니다.
- **전동차 안의 카메라:** 안쪽 폭 2.6m의 전동차 안에서 카메라가 벽에 걸려 싸우기 어렵지 않은지, 전동차 안의 근거리 적과 싸울 만한지 확인합니다.
- **전동차 안에서 쓰는 스킬 1:** 전동차 안의 근거리 적에게 스킬 1을 쓰면 등 뒤 3m가 전동차의 벽 너머일 수 있습니다. 어디에 나타나는지 확인합니다.
- **세 갈래 길의 선택:** 한 가지 길만 고르게 되지 않는지, 특히 선로로 곧장 내려가 승강장의 적을 모두 지나치는 플레이가 너무 쉽지 않은지 확인합니다.
- **선로 안의 사격:** 선로에 내려선 플레이어에게 승강장 끝의 사수가 얼마나 쏠 수 있는지, 승강장 가장자리에 붙어 걸으면 사격이 얼마나 가려지는지 확인합니다.
- **선로 계단 옆의 통로:** 선로 계단 옆은 선로 폭이 약 1.7m로 좁아집니다. 선로에서 싸우다 걸리지 않는지 확인합니다.
- **뒤로 걷는 사수:** 경비 사수는 플레이어가 8m 안으로 들어오면 뒤로 걷습니다. 승강장 끝의 사수가 벽에 붙어 스킬 1이 실패하는지 확인합니다.
- **대피소의 의미:** 대피소에 숨은 플레이어에게 사수가 다가와 숨는 의미가 사라지는지, 대피소 사이를 옮겨 가는 것이 패리하며 걷는 것보다 나은지 플레이해 보고 대피소의 수와 간격을 조정합니다.
- **터널 끝의 싸움:** 터널 끝의 사수와 싸우는 동안 차량기지 앞의 적이 플레이어를 발견하는지, 터널의 사수가 뒤로 걸어 차량기지 앞까지 물러나는지 확인합니다.
- **작업차가 가리는 범위:** 입구 앞에서 근거리 적과 싸우는 동안 사수가 작업차를 돌아 나와 쏘는지, 작업차 뒤가 지나치게 안전하지 않은지 확인합니다.
- **구간을 지나치는 플레이:** 성문 앞까지는 길을 막는 장치가 없어 적을 무시하고 달려 지나갈 수 있습니다. 남겨 둔 적이 다음 구간까지 따라와 문제가 되면 구간 사이의 계단과 입구로 조정합니다.
- **성문과 커스터의 거리:** 성문이 열린 순간 커스터가 플레이어를 발견하지 않는지 확인합니다.
- **보스 아레나에서 커스터의 이동:** 열린 성문은 다시 닫히지 않아 커스터의 돌진이 통로로 빠져나갈 수 있습니다. 플레이해 보고 정합니다.
