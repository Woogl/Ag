# 스테이지 - 미니던전 폐허 성곽길

> 이 문서는 AI가 기획한 미니던전입니다. 던전 선정, 구간 구성, 적 배치, 수치를 AI가 정했고 담당 기획자가 검토했습니다. 던전 이름은 가안입니다.

미니던전 '폐허 성곽길'의 레벨인 LV_TempDungeon03의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 별도의 기능 구현 없이 그레이박스 지형, 동선, 적 배치만으로 재미를 만드는 것을 전제로 합니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)을 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 설계 의도

이 던전의 재미는 '돌아서 다시 만나는 곳'에 있습니다. 시작하자마자 성곽 안의 마당을 낮은 담 너머로 엿보지만, 마당은 막혀 있어 들어갈 수 없습니다. 바깥 길을 따라 한 바퀴 돌아 올라가는 동안 그 마당이 점점 다른 각도로 다시 보이고, 마침내 성벽 위에서 마당 전체를 내려다보며 '아까 본 그곳'에 도착합니다. 결투 회랑이 닫힌 방의 1:1, 요새 돌파가 열린 공간의 원거리 대응이라면, 폐허 성곽길은 길과 시야와 높이의 변화로 긴장을 만드는 던전입니다.

문을 여는 장치나 체크포인트가 없으므로 지름길은 만들지 않습니다. 대신 '미리 본 곳에 다른 높이에서 도착하는 것'과 '모퉁이를 돌자마자 만나는 적'이 이 던전의 긴장을 만듭니다. 모두 지형과 적 배치만으로 만들어집니다.

- **담 너머의 마당:** 시작 지점 옆 바깥 길의 한 구간에서 허리 높이보다 낮은 담 너머로 마당 안이 보입니다. 마당 한가운데 서 있는 적과 출구 옆 단 위의 원거리 적이 미리 눈에 들어오지만, 담은 넘을 수 없어 지금은 갈 수 없습니다.
- **모퉁이의 적:** 외곽 길이 꺾이는 모퉁이 너머에 근거리 적 하나가 서 있고, 모퉁이 바깥쪽이 낮은 담으로 트여 있어 모퉁이를 돌기 전부터 멀리서 보입니다. 보이는 적에게 어떻게 다가갈지 미리 정하게 합니다.
- **올라가며 트이는 시야:** 비탈길은 마당 벽을 따라 올라갑니다. 처음에는 벽에 가려 마당이 보이지 않다가, 높이가 오를수록 벽 너머가 트입니다. 올라가는 동안 쉼터에서 숨을 돌린 뒤, 오르막 위쪽 끝에서 근거리 적 하나를 만나 위에서 내려오는 적을 아래에서 맞이하는 싸움을 합니다. 비탈길의 적은 줄이고, 본격적인 싸움은 성벽 위로 미룹니다.
- **성벽 위에서 다시 보기:** 성벽 위 통로는 마당의 한쪽 벽 위를 따라 걷는 길입니다. 안쪽 가장자리가 열려 있어 걸으면서 마당 전체를 내려다볼 수 있고, 처음 담 너머로 엿본 적과 단이 한눈에 들어옵니다.
- **성벽 위의 적:** 성벽 위 통로에 올라서면 북쪽 부분에 근거리 적 하나가 먼저 기다리고, 통로 끝에는 원거리 적이 하나만 있습니다. 위에서 마당을 내려다보는 풍경을 즐길 틈 없이 높은 곳에서 싸움이 시작됩니다.
- **내려갈지 걸을지:** 근거리 적을 처치한 뒤 통로를 끝까지 걸어 원거리 적을 직접 처치하거나, 통로 어디에서든 마당으로 뛰어내려 아래에서 싸운 뒤 경사로로 올라가 처치할 수 있습니다. 뛰어내리면 마당의 적들과 먼저 싸우게 되고, 성벽 위의 사수는 내려다보며 쏘는 위치를 유지합니다. 낙하 대미지는 없는 것으로 가정합니다.
- **출구를 지키는 사수:** 마당의 출구 바로 옆 단 위에도 원거리 적이 서 있습니다. 출구로 가는 길이 곧 이 사수 앞을 지나는 길입니다.
- **종탑이라는 목표:** 보스 아레나의 안쪽 끝, 커스터의 등 뒤로 성곽에서 가장 높은 종탑이 서 있습니다. 바깥 길, 비탈길, 성벽 위에서 종탑이 보여 가야 할 방향을 알려 주고, 출구 통로를 걷는 동안에는 종탑이 점점 커 보입니다.

구간의 모양도 서로 다르게 둡니다. 외곽 길은 곧고 좁은 일자, 비탈길은 오르막과 평평한 쉼터가 이어지는 긴 길, 성벽 위 통로는 한쪽이 열린 높은 길, 마당은 네모난 넓은 평지, 대기 공간은 벽으로 둘러싸인 작은 방입니다.

난이도는 외곽 길(근거리 1명) → 비탈길(근거리 1명) → 성벽 위 통로(근거리 1명 + 원거리 1명) → 마당(근거리 1명 + 원거리 1명) → 커스터 순서로 올라갑니다. 앞의 둘은 가볍게 몸을 풀고, 성벽 위 통로에서 처음으로 두 종류의 적을 함께 상대하며, 마당에서 지형을 읽는 싸움이 한 번 더 커집니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 바닥의 기준 높이는 0m입니다. 비탈길(0m → 3m), 성벽 위 통로(3m), 마당의 단(1.5m)과 각 경사로만 높이가 다릅니다.
- 점프(최고 높이 약 0.73m)로 오를 수 있는 높이는 두지 않습니다. 1.5m 이상의 높이는 경사로로만 올라갑니다. 점프로 건너야 하는 발판이나 틈은 없습니다.
- 마당 둘레의 서쪽·북쪽·남쪽 벽은 높이 4m, 동쪽 벽은 성벽 위 통로(높이 3m)입니다. 그 밖의 벽도 높이 4m 이상으로 만들어 넘을 수 없게 합니다. 천장은 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 성벽 위 통로에서 마당으로 뛰어내리는 높이는 3m입니다. 낙하 대미지는 없는 것으로 보며, 마당에서 성벽 위 통로로는 경사로로만 올라갈 수 있습니다.
- 원거리 적이 서는 높은 곳에는 모두 경사로를 둡니다. 플레이어가 원거리 적에게 직접 다가가 처치할 수 있어야 합니다.
- 큰 길은 하나이며, 시작 지점에서 보스 아레나까지의 이동 거리는 약 150m입니다. 마당으로 내려가는 방법은 두 가지(성벽 위 통로를 끝까지 걷기 / 통로 중간에서 뛰어내리기)이며, 두 방법 모두 마당을 거쳐야 다음 구간으로 갑니다.

## 구간

### 외곽 길

시작 지점에서 마당의 서쪽 벽 바깥을 따라 북쪽으로 올라가는 좁은 길입니다. 마당을 엿보고, 모퉁이에서 첫 번째 적을 만납니다.

| 항목 | 조건 |
| - | - |
| 크기 | 폭 약 5m, 길이 약 25m의 곧은 길. 높이 0m |
| 낮은 담 | 길 오른쪽(+X) 벽의 가운데 약 10m 구간(시작 지점에서 약 8m ~ 18m)이 높이 1m의 낮은 담입니다. 담 너머로 마당이 보입니다. 점프 최고 높이(약 0.73m)보다 높아 넘을 수 없습니다. |
| 모퉁이 | 길의 북쪽 끝에서 오른쪽(+X)으로 꺾입니다. 꺾이는 곳의 바깥쪽(북쪽) 벽은 높이 1m의 낮은 담이라, 길을 따라 올라오는 동안 모퉁이 너머 비탈길의 첫 부분이 보입니다. |
| 적 | 근거리 일반 적 1명 (모퉁이 너머 비탈길 시작 부분) |

- 시작 지점은 바깥 길의 남쪽 끝이며, 플레이어는 북쪽(+Y)을 바라보고 시작합니다.
- 낮은 담 너머의 적이 담 구간을 지나는 플레이어를 바로 보지 못해야 합니다. (마당의 근거리 적은 담에서 약 12m 이상 떨어져 있습니다.)

### 비탈길

마당의 북쪽 벽 바깥을 따라 동쪽으로 올라가는 긴 길입니다. 근거리 적 하나가 오르막 위쪽 끝에서 맞이하며, 쉼터까지는 적이 없고 오르는 풍경이 중심인 구간입니다.

| 항목 | 조건 |
| - | - |
| 크기 | 폭 약 4m, 길이 약 26m. 외곽 길의 모퉁이에서 동쪽(+X)으로 뻗습니다. |
| 오르막 | 처음 약 10m는 0m에서 1.5m로, 마지막 약 11m는 1.5m에서 3m로 올라갑니다. |
| 쉼터 | 두 오르막 사이 길이 약 4m의 평평한 구간(높이 1.5m) |
| 끝 | 높이 3m에 닿으면 폭 약 4m의 평평한 모서리를 지나 남쪽(-Y)으로 꺾여 성벽 위 통로로 이어집니다. |
| 시야 | 길 오른쪽의 마당 북쪽 벽(높이 4m)은 길이 높아지기 전에는 안이 보이지 않게 가립니다. 높이 3m 근처에서야 벽 너머로 마당이 내려다보입니다. |
| 적 | 근거리 일반 적 1명 (끝 모서리 가까이) |

### 성벽 위 통로

마당의 동쪽 벽 위를 따라 남쪽으로 걷는 길입니다. 안쪽(서쪽) 가장자리는 열려 있어 걸으면서 마당 전체가 내려다보입니다. 북쪽 부분에서 근거리 적이 기다리고, 끝에는 원거리 적이 하나만 있습니다.

| 항목 | 조건 |
| - | - |
| 크기 | 폭 약 4m, 길이 약 24m. 높이 3m |
| 가장자리 | 안쪽(서쪽)은 난간 없이 열려 있고, 바깥쪽(동쪽)은 벽으로 막혀 있습니다. 열린 가장자리 어디서든 마당으로 뛰어내릴 수 있습니다. |
| 경사로 | 마당 바닥에서 통로로 올라오는 경사로 하나. 통로의 북쪽 끝에서 남쪽으로 약 4m 떨어진 곳에서 시작해, 통로 안쪽 벽을 따라 마당 쪽으로 길이 약 8m, 폭 약 3m로 내려갑니다. |
| 적 | 근거리 일반 적 1명 (북쪽 부분), 원거리 일반 적 1명 (남쪽 끝) |

- 경사로를 올라온 플레이어는 원거리 적에게서 약 15m 떨어진 곳에 나옵니다. 사수가 통로의 북쪽을 바라보고 있어, 올라오는 동안 몸을 숨길 곳은 없습니다.
- 통로를 걸어 내려오는 동안 사수는 플레이어를 정면으로 봅니다. 일반 적의 시야 값이 정해지면, 걸어서 접근할지 마당으로 뛰어내릴지 선택하게 만든다는 의도를 확인합니다.

### 마당

이 던전의 마지막 일반 교전입니다. 바닥의 근거리 적과 출구 옆 단 위의 원거리 적을, 성벽 위 사수의 시선 아래에서 상대합니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 24m × 24m의 네모난 평지. 높이 0m |
| 엄폐물 | 약 3m × 1m, 높이 2m의 블록 3개. 마당 가운데 근거리 적을 둘러싸듯 흩어 놓아, 성벽 위 사수의 시선을 일부 가립니다. |
| 단 | 출구 바로 옆, 마당 남쪽 벽에 붙은 약 6m × 4m, 높이 1.5m의 열린 단. 출구에서 약 4m 떨어져 있습니다. |
| 단 경사로 | 단의 북쪽 변에서 마당 쪽으로 길이 약 6m, 폭 약 2m |
| 적 | 근거리 일반 적 1명, 원거리 일반 적 1명 (단 위) |
| 입구 | 성벽 위 통로의 경사로 아래, 또는 3m 높이에서 뛰어내리는 자리. 마당의 문은 없습니다. |
| 출구 | 남쪽 벽의 가운데보다 약간 서쪽, 폭 약 5m |

- 성벽 위 통로에서 걸어 내려오는 플레이어는 이미 성벽 위 사수를 처치한 채 마당에 들어옵니다. 뛰어내린 플레이어는 사수를 살려 둔 채 마당에 들어옵니다.
- 마당의 적을 무시하고 출구로 달려 지나갈 수 있습니다. 다만 출구 옆 단 위 사수가 그 길을 내려다봅니다.

### 출구 통로와 대기 공간

마당을 나와 보스 아레나에 들어가기 전에 숨을 돌리는 구간입니다. 출구 통로는 마당 남쪽으로 내려간 뒤 동쪽으로 길게 이어지며, 끝이 대기 공간입니다. 통로를 걷는 동안 정면에 던전 내내 보이던 종탑이 점점 커집니다.

| 항목 | 조건 |
| - | - |
| 출구 통로 | 폭 약 5m. 마당 출구에서 남쪽으로 약 8m 내려간 뒤 동쪽으로 약 40m 곧게 뻗습니다. 적은 없습니다. |
| 대기 공간 | 약 10m × 10m. 벽으로 둘러싸인 작은 방이며 적은 없습니다. |
| 연결 | 대기 공간과 보스 아레나 사이를 길이 약 6m의 곧은 통로로 잇습니다. |
| 시야 | 통로 너머로 아레나 안의 커스터와 그 뒤의 종탑이 보여야 합니다. 커스터까지 약 35m 떨어져 있어 커스터의 시야(20m) 밖입니다. |

### 보스 아레나

커스터와 싸우는 구역입니다. 크기, 바닥, 장애물, 경계는 [스테이지 - 보스 전장](<스테이지 - 보스 전장.md>)의 '보스 아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 약 33m × 33m (보스 전장의 원형 단상 방 내부와 같은 크기) |
| 입구 | 대기 공간 쪽 벽의 가운데, 폭 약 5m |
| 종탑 | 입구 반대편 벽 바깥에 선 약 10m × 10m의 탑. 높이 약 16m이며, 시작 지점과 각 구간에서 벽 너머로 보이도록 높이를 정합니다. 올라갈 수 없고, 아레나 안에서는 커스터의 등 뒤로 솟아 보입니다. 커스터 시작 위치(B)는 종탑에서 약 8.5m 앞입니다. |
| 커스터의 시야 | 입구에서 약 5m 들어오면 커스터의 시야(20m)에 들어갑니다. |

## 높이 구성

![미니던전 높이 비교](<../../Art/Level/미니던전 높이 비교.svg>)

- 세 미니던전을 같은 눈금으로 옆에서 본 그림입니다. 폐허 성곽길은 맨 아래 그림입니다. 길을 곧게 펴서 그린 단면이라 구간 길이의 합이 '레벨 구성'의 이동 거리와 조금 다를 수 있고, 세로를 가로보다 약 1.8배 늘려 그렸습니다.
- 외곽 길의 0m에서 비탈길을 따라 3m까지 올라가 성벽 위 통로를 걷고, 마당으로는 3m를 뛰어내리거나 경사로로 내려갑니다.

## 미확정 항목

일반 적의 기획이 나오기 전에 정한 값이 있어, 아래는 적이 확정되거나 플레이해 본 뒤 조정합니다.

- **낙하 대미지:** 성벽 위 통로에서 마당으로 뛰어내리는 3m에는 대미지가 없다고 가정했습니다. 낙하 대미지 규칙이 생기면 높이를 다시 정합니다.
- **낮은 담으로 보이는 적:** 낮은 담 구간에서 마당의 적이 플레이어를 보거나 쏠 수 있는지는 일반 적의 시야와 사거리가 정해져야 알 수 있습니다. 보인다면 담 구간을 줄이거나 마당 적의 위치를 옮깁니다.
- **성벽 위 사수의 시야:** 통로를 걸어 내려오는 동안 사수가 너무 먼 거리에서 플레이어를 보면 걷는 길이 일방적으로 불리해집니다. 원거리 적의 시야가 정해지면 통로 길이나 사수 위치를 조정합니다.
- **마당의 동시 교전:** 걸어서 접근한 플레이어는 마당에서 근거리 1명과 단 위 원거리 1명을, 뛰어내린 플레이어는 거기에 성벽 위 사수까지 상대합니다. 뛰어내리는 쪽이 지나치게 어려우면 마당의 근거리 적을 단 아래 근처로 옮깁니다.
- **마당을 지나치는 플레이:** 출입구를 막는 장치가 없어 마당의 적을 무시하고 출구로 달려 지나갈 수 있습니다. 플레이해 보고 문제가 되면 엄폐물 배치로 동선을 조정합니다.
- **종탑의 높이:** 시작 지점과 각 구간에서 벽 너머로 종탑이 보이는지 그레이박스에서 확인하고 높이를 조정합니다.
- **보스 아레나에서 커스터의 이동:** 출입구를 막는 장치가 없어 커스터의 돌진이 통로로 빠져나갈 수 있습니다. 결투 회랑과 같이 플레이해 보고 정합니다.
