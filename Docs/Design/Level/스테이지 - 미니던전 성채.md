# 스테이지 - 미니던전 성채

미니던전 '성채'의 레벨인 LV_Citadel의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 그레이박스 지형, 동선, 적 배치로 재미를 만드는 것을 전제로 하며, 기능 구현이 필요한 요소는 성문 넷뿐입니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_Citadel |
| 컨셉 | 절벽 위에 세 단으로 쌓인 성채를 올라 꼭대기 본성의 커스터에게 갑니다. 성문을 차례로 뚫는 정면 길 말고도 성벽 위, 지하, 다리 밑으로 도는 길이 서로 얽혀 있고, 길마다 만나는 적과 싸우는 자리가 다릅니다. 본성은 시작 지점 바로 위 절벽에 서 있어, 처음부터 목적지가 보이고 끝에서는 걸어온 길이 내려다보입니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 다른 스테이지 레벨과 같습니다. |
| 등장 적 | 근거리 일반 적 46명, 원거리 일반 적 11명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 정면 길만 따라가면 약 18분 (이동 약 3분, 일반 교전 합계 약 12분, 커스터전 약 3분). 모든 구간을 돌면 약 30분, 지름길을 알면 커스터까지 약 5분 |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 레벨에 배치하는 회복 수단 | 없음 |

레벨을 돌려 보며 높이와 길을 확인하려면 [성채 3D](<성채 3D.html>)를 브라우저로 엽니다. 길마다 켜고 끌 수 있고, 단면 높이를 내리면 지하와 건물 안이 보입니다.

이 문서의 동·서·남·북은 시작 지점에서 플레이어가 바라보는 쪽을 동쪽으로 둔 방향입니다. 그때 오른쪽이 남쪽입니다.

## 설계 의도

성채는 길을 고르는 던전입니다. 정면 길은 넓고 알기 쉽지만 위에서 쏘는 원거리 적 아래로 문과 계단을 밀고 올라가야 합니다. 돌아가는 길은 좁거나 숨어 있지만, 그 사수의 등 뒤로 나오거나 싸움을 통째로 지나칩니다. 체크포인트가 없어 죽으면 처음부터 다시 하므로, 한 번 찾은 지름길이 다음 도전의 길이 됩니다.

재미 요소는 아래와 같습니다. 성문을 빼면 모두 지형과 적 배치만으로 만들어집니다.

- **보이는 목적지:** 시작 지점의 왼쪽 절벽 위로 본성 성벽이 보입니다. 성채는 동쪽으로 뻗었다가 북쪽으로 돌아 서쪽으로 되돌아오므로, 윗마당의 난간에서는 처음 걸어온 절벽길과 아랫마당이 내려다보입니다.
- **위에서 쏘는 사수와 정면 싸움:** 외성문 지붕, 큰 계단 위, 윗문루 지붕, 본성 앞 단의 원거리 적이 그 아래의 길을 쏩니다. 엄폐물에서 엄폐물로 옮겨 가며 근거리 적을 상대합니다.
- **사수의 등 뒤로 도는 길:** 성벽 위 길은 외성문 지붕과 큰 계단 위 사수의 뒤로, 다리 밑 길은 윗문루 통로의 적 옆으로, 가운데 성벽 위 길은 예배당 발코니 사수의 뒤로 나옵니다.
- **층을 잇는 탑:** 탑 하나가 지하, 마당, 성벽 위를 계단으로 잇습니다. 층마다 문이 있어 어느 층에서든 다른 길로 갈아탑니다.
- **반대편에서 여는 문:** 저장고 문과 윗문루 옆문은 한쪽에서만 열립니다. 돌아가는 길로 그 뒤에 닿으면 열 수 있고, 열린 문은 그 도전 동안 두 길을 잇습니다.
- **뛰어내리는 길:** 우물, 예배당 바닥의 구멍, 성벽 위에서 마당으로, 본성 성벽 위에서 아레나로 뛰어내립니다. 내려가기만 하는 길이라, 뛰기 전에 돌아올 길을 생각해야 합니다.
- **아는 사람의 지름길:** 서북 탑 꼭대기에서 달려 뛰면 절벽의 턱을 지나 윗마당으로 바로 갑니다. 처음에는 눈에 띄지 않고, 윗마당에서 내려다보면 보입니다.
- **떨어지는 다리:** 큰 다리는 가운데가 무너져 폭이 3m이고 난간이 끊긴 곳이 있습니다. 떨어지면 사망하며, 적도 넉업으로 다리 밖에 띄울 수 있습니다.

린의 스킬 1은 이 던전에서 있으면 편한 보조 수단입니다. 어느 길도 스킬 1 없이 걸어서 풀 수 있어야 합니다.

난이도는 절벽길(근거리 2명 + 지붕 사수 2명의 사격) → 외성문 통로(근거리 2명) → 아랫마당(근거리 3명) → 큰 계단(근거리 3명 + 원거리 2명) → 가운데 마당(근거리 5명) → 다리목(근거리 2명) → 큰 다리(근거리 3명 + 원거리 2명) → 윗문루(근거리 2명) → 윗마당과 본성 계단(근거리 4명 + 원거리 2명) → 커스터 순서로 이어집니다. 돌아가는 길의 구간은 이 순서 밖에 있습니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 길을 막는 장치는 성문 넷입니다. 정면 길에는 가운데 성문과 본성 성문이 있고, 나머지 구간 사이에는 문을 두지 않아 플레이어는 적을 남겨 둔 채 지나갈 수 있습니다.
- 바닥 높이는 아래와 같습니다. 구간 사이는 계단으로 잇습니다. 계단은 한 단이 높이 0.25m, 깊이 0.5m이고, 절벽길의 계단만 깊이 1m입니다.

| 높이 | 구간 |
| - | - |
| 0m | 절벽길, 하수로 턱, 지하 저수조, 지하 저장고, 해자 바닥 |
| 4m | 외성문 앞마당, 외성문 통로 |
| 5m, 10m | 지하 감옥, 납골당 |
| 6m | 아랫마당 |
| 14m | 외벽 위 길, 외성문 지붕, 윗문루 아래층 |
| 16m | 가운데 마당, 가운데 성문 앞 단 |
| 20m | 다리목, 큰 다리, 윗문루 통로와 경비실 |
| 21m | 절벽 턱 |
| 24m | 가운데 성벽 위 길, 동남 탑 꼭대기 |
| 28m | 윗마당, 윗문루 지붕 |
| 34m | 본성 앞 단, 본성(보스 아레나) |
| 42m, 44m | 본성 성벽 위, 종탑 꼭대기 |

- 성채 바깥은 낭떠러지이며 40m 아래에 바닥이 있습니다. 바깥으로 떨어지면 사망합니다. 바깥쪽 가장자리는 아래 표의 두 곳을 빼고 모두 난간이나 벽으로 막혀 있습니다.
- 낙하 대미지([전투 시스템](<../System/전투 시스템.md>)의 '낙하 대미지')를 받는 곳은 아래와 같습니다. 그 밖에 뛰어내리는 곳은 모두 10m 이하라 HP를 잃지 않습니다.

| 떨어지는 곳 | 높이 | 결과 |
| - | - | - |
| 큰 다리의 무너진 곳과 끊긴 난간 → 해자 바닥 | 20m | 사망 |
| 윗문루 지붕의 다리 쪽 가장자리 → 해자 바닥 (다리 위로 떨어지면 8m) | 28m | 사망 |
| 하수로 턱의 남쪽, 동남 탑 꼭대기의 서쪽 틈 → 성채 바깥 | 40m 이상 | 사망 |
| 서북 탑 꼭대기와 절벽 턱 사이 → 아랫마당 | 16m | MaxHP의 60% |
| 가운데 성문 앞 단의 북쪽 끝 → 해자 바닥 | 16m | MaxHP의 60% |
| 종탑 꼭대기의 동쪽 틈 → 윗마당 | 16m | MaxHP의 60% |
| 절벽 계단 위 단, 해자 쪽 성벽 위 → 해자 바닥 | 14m | MaxHP의 40% |
| 종탑의 다리 → 윗마당 | 14m | MaxHP의 40% |

- 벽과 난간은 점프로 넘을 수 없습니다. 난간은 1.5m, 마당의 성벽은 8m입니다. 난간이 없는 곳은 외벽 위 길과 가운데 성벽 위 길의 안쪽, 원거리 적이 선 가장자리(외성문 지붕, 동남 탑과 종탑 꼭대기, 윗문루 지붕), 서북 탑 꼭대기의 북쪽, 가운데 성문 앞 단의 서쪽과 북쪽 끝, 큰 계단과 절벽 계단의 옆, 큰 다리의 무너진 곳과 끊긴 난간, 종탑의 다리, 본성 성벽 위의 안쪽입니다.
- 지붕이 덮인 곳은 외성문 통로(높이 6m), 지하 저수조와 저장고(5m), 지하 감옥(4.5m), 납골당(5m), 예배당(12m), 윗문루 통로(5m)와 경비실·아래층(4.5m ~ 5m), 저장고 집, 탑의 안입니다. 그 밖에는 천장을 두지 않습니다. (카메라는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 카메라 충돌 참고)
- 적은 낭떠러지와 단의 가장자리에서 뛰어내리지 못합니다([적 시스템](<../System/적 시스템.md>)의 '낭떠러지'). 플레이어가 뛰어내리면 따라오지 못하고 계단으로 돌아옵니다.
- 원거리 적은 모두 플레이어가 걸어서 닿을 수 있는 바닥 위에 서고, 등 뒤 3m 안은 바닥입니다. 린의 스킬 1은 단검에 맞은 대상의 등 뒤 3m에 나타나므로, 그 자리에 바닥이 있어야 합니다. 높은 곳의 원거리 적은 가장자리에서 1m 안쪽에 서서 아래를 봅니다.
- 정찰하는 적은 '배치 요소'의 정찰 경로를 돕니다([적 시스템](<../System/적 시스템.md>)의 '비전투와 정찰').
- 장애물은 3m 높이의 엄폐 벽과 상자 더미, 방책, 폐허 벽, 4m 석상, 건물(마구간, 병영), 기둥입니다. 모두 시선과 탄환을 가리며 점프로 넘을 수 없습니다. 병영의 지붕은 상자를 밟고 오릅니다.
- 정면 길은 시작 지점에서 보스 아레나 중심까지 약 545m입니다.

## 길

| 길 | 가는 순서 | 얻는 것과 치르는 것 |
| - | - | - |
| 정면 돌파 | 절벽길 → 외성문 → 아랫마당 → 큰 계단 → 가운데 성문 → 가운데 마당 → 다리목 → 큰 다리 → 윗문루 → 윗마당 → 본성 | 넓고 알기 쉽습니다. 근거리 26명, 원거리 8명을 만납니다. |
| 성벽 길 | 서북 탑 → 외벽 위 길 → 외성문 지붕 → 남쪽 성벽 → 동남 탑 → 가운데 성벽 위 길 → 예배당 발코니 | 외성문 지붕과 큰 계단 위의 사수를 뒤에서 잡고, 큰 계단과 가운데 성문을 건너뜁니다. 길이 폭 4m로 좁고 동남 탑의 사수가 내려다봅니다. |
| 지하 길 | 앞마당 난간의 틈 → 하수로 턱 → 저수조 → 저장고 → 감옥 → 납골당 → 예배당 | 외성문, 아랫마당, 큰 계단, 가운데 성문을 지나칩니다. 좁고 어두우며 근거리 9명이 숨어 있습니다. |
| 다리 밑 길 | 아랫마당의 쪽문이나 서북 탑 밑의 통로 → 해자 바닥 → 절벽 계단 → 윗문루 아래층 → 옆문 | 가운데 마당과 큰 다리를 지나쳐 윗문루 통로의 적 옆으로 나옵니다. 해자 바닥과 아래층의 근거리 6명을 만납니다. |
| 절벽 지름길 | 서북 탑 꼭대기 → 달려 뛰기 → 절벽 턱 → 돌계단 → 윗마당 | 아랫마당에서 윗마당으로 바로 갑니다. 적이 없습니다. 뛰지 못하면 MaxHP의 60%를 잃습니다. |
| 종탑에서 본성으로 | 종탑 → 다리 → 본성 성벽 위 → 아레나로 뛰어내림 | 본성 계단의 적을 지나치고 커스터의 옆이나 뒤에 내려섭니다. 본성 성문은 닫힌 채 싸웁니다. |

## 구간

### 절벽길

절벽을 깎은 길을 따라 동쪽으로 가서 계단을 오르면 외성문 앞마당입니다. 북쪽은 28m 절벽이고 그 위로 본성 성벽이 보이며, 남쪽은 낭떠러지입니다.

| 항목 | 조건 |
| - | - |
| 길 | 길이 60m, 폭 28m (0m). 북쪽 벽에 붙은 초소(6m × 6m, 높이 3m)가 하나 있습니다. |
| 계단 | 폭 28m, 16단. 0m에서 4m로 오릅니다. |
| 앞마당 | 24m × 30m (4m). 3m 엄폐 벽 2개 (폭 5m) |
| 근거리 적 | 2명. 하나는 시작 지점 앞 26m ~ 48m 사이의 길을 오가며 정찰하고, 하나는 앞마당의 외성문 통로 앞 6m에 서서 계단 쪽을 봅니다. |
| 난간의 틈 | 앞마당 남쪽 난간에 4m 틈이 있습니다. 틈 밖 4m 아래가 하수로 턱(0m, 폭 4m, 길이 32m)이고, 턱의 동쪽 끝이 지하 저수조의 하수로입니다. |
| 출구 | 외성문 통로 (앞마당의 동쪽) |

- 계단을 거의 다 오르면(끝에서 약 2m 앞) 외성문 지붕의 원거리 적 둘이 약 30m에서 플레이어를 봅니다. 외성문에 약 10m까지 다가가면 지붕 가장자리에 가려 사격이 끊깁니다.
- 앞마당에 약 6.5m 들어서면 앞마당의 근거리 적이 약 11.5m에서 봅니다.
- 하수로 턱으로 내려가면 앞마당으로 다시 오를 수 없습니다. 턱의 남쪽은 난간이 없는 낭떠러지입니다.

### 외성문

성채의 첫 문루입니다. 문루를 뚫은 통로로 아랫마당에 들어갑니다. 통로에는 문이 없습니다.

| 항목 | 조건 |
| - | - |
| 문루 | 20m × 30m, 지붕 14m |
| 통로 | 폭 8m, 높이 6m, 길이 20m (4m). 끝의 4m는 계단 8단이고 아랫마당(6m)으로 오릅니다. |
| 근거리 적 | 2명. 통로 입구에서 12m 안쪽에 좌우로 4m 떨어져 서서 입구를 봅니다. |

- 무너진 곳을 지나 윗문루 약 27m 앞에 이르면 지붕의 원거리 적 둘이 약 25m ~ 30m에서 봅니다. 윗문루 약 6.5m 앞부터는 지붕 가장자리에 가려 사격이 끊깁니다. 그 사이에 셋째와 넷째 방책이 있습니다.

## 성문

이 던전에서 플레이어가 상호작용하는 장치는 성문 넷입니다. 처음 상태, 여는 조건, 안내, 열리는 중과 열린 뒤, 재도전의 규칙은 [스테이지 - 미니던전 요새 돌파](<스테이지 - 미니던전 요새 돌파.md>)의 '성문'과 같습니다. 성문은 모두 폭 5m, 높이 5m이며, 아래 표의 '여는 쪽'에서만 열립니다. 여는 쪽의 성문 면에서 1m 안에 서면 안내가 뜨고, 반대쪽에서는 안내가 뜨지 않습니다.

| 성문 | 위치 | 여는 쪽 | 잇는 곳 |
| - | - | - | - |
| 가운데 성문 | 가운데 마당의 서쪽 성벽 가운데, 큰 계단의 정면 | 큰 계단 쪽 (서쪽) | 성문 앞 단 ↔ 가운데 마당 |
| 본성 성문 | 본성의 동쪽 벽 가운데 | 앞 단 쪽 (동쪽) | 본성 앞 단 ↔ 보스 아레나 |
| 저장고 문 | 아랫마당 저장고 집의 북쪽 면 | 집 안쪽 (남쪽) | 지하 저장고의 계단 ↔ 아랫마당 |
| 윗문루 옆문 | 윗문루 통로의 남쪽 벽 가운데 | 경비실 쪽 (남쪽) | 윗문루 경비실 ↔ 윗문루 통로 |

- 가운데 성문에서 가장 가까운 적(성문 앞 단의 원거리 적)까지는 약 8m, 본성 성문에서 가장 가까운 적(앞 단의 원거리 적)까지는 약 11.5m입니다.

## 미확정 항목

구간의 크기, 거리, 적의 수는 그레이박스를 만들기 전에 정한 값이라, 아래는 플레이해 본 뒤 조정합니다.

- **구간 크기와 거리:** 각 구간의 길이, 폭, 적 사이의 거리는 플레이해 보고 조정합니다.
- **예상 플레이 시간:** 적의 수와 이동 거리로 어림한 값입니다. 플레이해 보고 고칩니다.
- **적의 수:** 일반 적 57명은 다른 미니던전(9명 ~ 13명)의 서너 배이고, 정면 길에서만 34명을 만납니다. 회복병 3개로 끝까지 갈 수 있는지 플레이해 보고 줄입니다.
- **죽으면 처음부터:** 체크포인트가 없어 커스터에게 죽으면 성채를 처음부터 다시 오릅니다. 지름길을 아는 플레이어는 약 5분에 돌아가지만, 모르는 플레이어에게 지나치게 가혹하지 않은지 확인합니다.
- **지붕이 덮인 곳의 밝기:** 지하와 예배당은 어둡습니다. 벽, 기둥, 적은 구분되지만 공격 예고가 잘 보이는지 확인합니다.
- **탑 안의 카메라:** 탑의 계단은 폭이 3m라 카메라가 벽에 자주 닿습니다. 오르내리기 불편하지 않은지 확인합니다.
- **절벽 지름길의 점프:** 달려 뛰기 3.6m가 너무 쉽거나 어렵지 않은지, 실패의 대가(MaxHP의 60%)가 알맞은지 확인합니다.
- **병영 지붕의 점프:** 0.75m씩 오르는 상자와 1.5m 틈이 알맞은지 확인합니다.
- **큰 다리의 사격 범위:** 지붕의 원거리 적은 윗문루 앞 약 6.5m ~ 27m만 봅니다. 다리 전체가 사격을 받게 할지 정합니다.
- **스킬 1로 건너뛰기:** 아래에서 위의 원거리 적(외성문 지붕, 성문 위 성벽, 예배당 발코니, 윗문루 지붕, 본성 앞 단, 탑 꼭대기)에게 스킬 1의 단검을 맞히면 그 적의 등 뒤에 나타나 사이의 길을 건너뜁니다. 지름길로 둘지 봅니다.
- **닫힌 성문 너머의 적:** 한쪽에서만 열리는 문의 반대편에서 적과 싸우면, 적이 닫힌 문 쪽으로 다가오려다 막힐 수 있습니다.
- **저장고 문 앞의 골목:** 문 앞이 큰 계단 옆면과의 사이 2m 골목이라 좁습니다. 플레이해 보고 넓힐지 정합니다.
- **난간 없는 사수 자리:** 동남 탑 꼭대기의 서쪽 틈으로 떨어지면 성채 바깥이라 사망합니다. 사수를 치다 떨어지지 않는지 확인합니다.
- **밖으로 떨어지는 적:** 넉업으로 띄운 적은 다리, 성벽 위, 단의 가장자리 밖으로 떨어질 수 있습니다. 10m 넘게 떨어진 적은 낙하 대미지를 받습니다.
- **구간을 지나치는 플레이:** 성문 밖에는 길을 막는 장치가 없어 적을 무시하고 지나갈 수 있습니다. 남겨 둔 근거리 적은 계단으로 쫓아오고, 원거리 적은 계속 쏩니다.
- **보스 아레나에서 커스터의 이동:** 열린 본성 성문은 다시 닫히지 않아 커스터의 돌진이 앞 단으로 빠져나갈 수 있습니다. 플레이해 보고 정합니다.
