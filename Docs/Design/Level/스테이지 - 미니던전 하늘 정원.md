# 스테이지 - 미니던전 하늘 정원

미니던전 '하늘 정원'의 레벨인 LV_SkyGarden의 구성, 구간별 조건, 배치 요소를 정의합니다. 이 던전은 그레이박스 지형, 동선, 적 배치로 재미를 만드는 것을 전제로 하며, 기능 구현이 필요한 요소는 성문 하나뿐입니다.

미니던전의 시작과 결과, 레벨 간 전환 규칙은 [게임 플로우](<../System/게임 플로우.md>) 문서를 따릅니다. 보스 아레나의 기준 규격은 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 레벨 | LV_SkyGarden |
| 컨셉 | 계단처럼 층층이 솟은 정원을 점프로 올라 꼭대기의 보스 아레나에 닿습니다. 블록과 기둥을 뛰어오르고, 좁은 들보를 건너고, 달려서 넓은 틈을 넘고, 탑을 한 바퀴 도는 기둥을 올라 다리를 건넙니다. 출발 정원에서 멀리 꼭대기의 탑과 정상 광장 뒤의 벽이 보입니다. |
| 환경 | 지형은 그레이박스로 새로 만듭니다. 조명, 하늘, 안개는 다른 스테이지 레벨과 같습니다. |
| 등장 적 | 근거리 일반 적 6명, 원거리 일반 적 3명, 보스 1명 ([보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)) |
| 예상 플레이 시간 | 약 8분 (이동과 점프 약 2분, 일반 교전 합계 약 3분, 커스터전 약 3분) |
| 제한 시간 | 없음 |
| 체크포인트 | 없음 |
| 레벨에 배치하는 회복 수단 | 없음 |

레벨을 돌려 보며 높이와 점프 경로를 확인하려면 [하늘 정원 3D](<하늘 정원 3D.html>)를 브라우저로 엽니다.

## 설계 의도

하늘 정원은 점프로 길을 여는 던전입니다. 구간마다 점프 도전이 하나씩 있고, 떨어지면 그 도전을 시작한 아래층에 떨어져 다시 시도합니다. 낙하 대미지를 받을 만큼 높이 떨어지는 곳은 없어서, 실수의 대가는 HP가 아니라 다시 오르는 시간입니다. 적은 발판에서 내려가지 못하므로, 발판 위의 적과는 그 발판에서 떨어질 위험을 안고 싸우고, 원거리 적은 건너편에서 점프하는 플레이어를 쏩니다.

재미 요소는 아래와 같습니다. 성문을 빼면 모두 지형과 적 배치만으로 만들어집니다.

- **징검다리 오르기:** 0.75m씩 높아지는 블록 셋을 뛰어올라 분수 마당에 오릅니다. 아래는 출발 정원 바닥이라 떨어져도 바로 다시 합니다.
- **사격 속의 기둥 오르기:** 분수 마당에서 근거리 적과 싸우는 동안 기둥 숲 망루의 원거리 적이 쏩니다. 그 적을 치려면 기둥을 뛰어올라 망루로 가야 합니다.
- **좁은 들보:** 폭 0.8m 들보를 건너는 동안 건너편 원거리 적이 쏩니다. 가운데 섬의 근거리 적은 건너편을 보고 있어 먼저 칠 수 있지만, 섬 위의 싸움은 떨어질 위험이 있습니다.
- **달려 뛰기:** 걸어서 뛰면 닿지 않는 3.6m 틈을 회피 뒤 달리기로 넘습니다. 가운데 섬에서 멈추지 않고 이어서 뜁니다.
- **탑을 도는 기둥:** 다리 밑을 지나 탑 뒤의 가장 낮은 기둥부터 탑을 한 바퀴 돌며 오릅니다. 정상의 원거리 적이 내려다보며 쏘고, 탑 뒤로 돌면 사격이 끊깁니다.
- **내 손으로 여는 성문:** 정상 광장의 성문을 직접 열고 커스터에게 갑니다.

점프의 높이와 거리는 [플레이어 캐릭터 - 린](<../Content/플레이어 캐릭터 - 린.md>)의 '점프'와 [전투 시스템](<../System/전투 시스템.md>)의 '점프와 공중 이동'을 따릅니다. 오르는 점프는 모두 높이 차이 0.75m에 틈 1.6m 이하라 걸어서 뛰면 닿고, 달려 뛰기의 틈 3.6m는 달려서 뛰어야 닿습니다.

구간의 모양도 서로 다르게 둡니다. 징검다리는 네모난 블록, 기둥 숲은 원기둥, 들보 다리는 좁은 판, 달려 뛰기는 넓은 틈, 나선 탑은 탑을 도는 원기둥이고, 보스 아레나는 벽으로 둘러싼 네모입니다.

난이도는 분수 마당(근거리 2명 + 원거리 1명) → 기둥 숲(망루의 원거리 1명) → 들보 다리(근거리 1명 + 건너편 원거리 1명) → 사수 테라스(근거리 1명 + 원거리 1명) → 달려 뛰기 → 나선 탑(정상의 원거리 1명이 쏨) → 정상 광장(근거리 2명 + 원거리 1명) → 커스터 순서로 이어집니다.

## 레벨 구성

- 게임플레이 액터는 아래 '배치 요소'의 것만 둡니다. 적 스포너, 체크포인트 볼륨, 활성화 볼륨은 없습니다.
- 길을 막는 장치는 성문 하나뿐입니다. 성문 앞까지는 구간 사이에 문을 두지 않아, 플레이어는 적을 남겨 둔 채 다음 구간으로 지나갈 수 있습니다.
- 진행 방향으로 층이 높아집니다. 바닥 높이는 출발 정원이 0m, 분수 마당과 기둥 숲 바닥이 3m, 쉼터·사수 테라스·탑 바닥이 7.5m, 탑 꼭대기·다리·정상 광장·보스 아레나가 13.5m입니다. 들보 다리와 달려 뛰기 아래의 구덩이 바닥은 4.5m입니다.
- 각 점프 도전은 그 도전을 시작한 바닥 위에 놓여, 떨어지면 그 바닥에 떨어집니다. 징검다리는 출발 정원 바닥, 기둥 숲은 분수 마당 바닥, 나선 탑은 탑 바닥입니다. 들보 다리와 달려 뛰기는 구덩이에 떨어지고, 구덩이 옆의 경사로로 그 도전의 출발점(쉼터, 사수 테라스)에 돌아갑니다. 경사로는 출발점으로만 이어집니다.
- 떨어지는 높이는 기둥 숲이 최대 3.75m, 들보 다리와 달려 뛰기가 3m, 나선 탑이 최대 5.25m, 탑 꼭대기·다리·정상 광장 가장자리가 6m입니다. 모두 [전투 시스템](<../System/전투 시스템.md>)의 낙하 대미지 시작 높이(10m)보다 낮아 HP를 잃지 않습니다.
- 테라스와 구덩이의 옆은 1.5m 난간(구덩이 안에서는 벽)으로 막아 점프로 넘을 수 없습니다. 레벨 전체의 아래와 바깥은 0m 바닥이며 출발 정원과 이어지고, 그 둘레는 3m 벽으로 막습니다.
- 적은 발판과 테라스 가장자리에서 뛰어내리지 못합니다([적 시스템](<../System/적 시스템.md>)의 '낭떠러지'). 폭 0.8m 들보에는 적이 올라서지 못합니다.
- 원거리 적은 모두 플레이어가 점프로 닿을 수 있는 바닥 위에 서고, 등 뒤 3m 안은 바닥입니다. 린의 스킬 1은 대상의 등 뒤 3m에 나타나므로, 그 자리에 바닥이 있어야 합니다.
- 장애물은 분수 마당의 화단 하나입니다. 시선과 탄환을 가리며 점프로 넘을 수 없습니다.
- 큰 길은 하나입니다. 시작 지점에서 보스 아레나 중심까지의 이동 거리는 약 275m입니다. (발판 가운데와 탑을 도는 기둥을 따라 잰 거리)

## 구간

### 출발 정원과 징검다리

넓은 0m 바닥에서 출발해, 블록 셋을 뛰어올라 3m 높이의 분수 마당에 오릅니다.

| 항목 | 조건 |
| - | - |
| 출발 정원 | 0m 바닥. 시작 지점에서 첫 블록까지 약 12m입니다. |
| 블록 | 3개. 3m × 3m, 3m × 3m, 2.8m × 2.5m. 윗면 높이 0.75m → 1.5m → 2.25m. |
| 틈 | 첫 블록은 바닥에서 바로 뛰어오릅니다. 블록 사이는 1.2m, 1.5m이고, 셋째 블록에서 분수 마당까지 1.5m입니다. 모두 0.75m씩 오릅니다. |
| 적 | 없음 |
| 출구 | 분수 마당의 앞쪽 가장자리. 마당은 출발 정원보다 3m 높아 바닥에서 바로 오를 수 없습니다. |

### 분수 마당과 기둥 숲

첫 교전입니다. 마당에서 근거리 적과 싸우는 동안 기둥 숲 망루의 원거리 적이 쏘고, 마당 뒤의 기둥을 뛰어올라 망루를 지나 쉼터로 오릅니다.

| 항목 | 조건 |
| - | - |
| 분수 마당 | 18m × 19m 평지 (높이 3m). 양옆은 1.5m 난간입니다. |
| 장애물 | 가운데 화단 1개 (3m × 3m, 높이 1.5m) |
| 근거리 적 | 2명. 마당 앞쪽 가장자리에서 약 16m, 가운데에서 좌우로 4m씩. 마당 앞쪽을 바라봅니다. |
| 기둥 숲 | 마당 뒤 26m. 마당 바닥에서 원기둥 4개와 망루가 솟습니다. 기둥 지름은 3m, 3m, 2.5m, 3m입니다. |
| 망루 | 7m × 7m (높이 5.25m). 둘째 기둥과 셋째 기둥 사이에 있습니다. |
| 원거리 적 | 1명. 망루 가운데. 마당 쪽을 바라봅니다. |
| 오르는 순서 | 마당 바닥 → 첫 기둥 3.75m → 둘째 기둥 4.5m → 망루 5.25m → 셋째 기둥 6m → 넷째 기둥 6.75m → 쉼터 7.5m. 모두 0.75m씩 오르며, 틈은 1.3 ~ 1.5m입니다. |
| 출구 | 쉼터(12m × 19m, 높이 7.5m). 쉼터는 마당 바닥보다 4.5m 높아 넷째 기둥에서만 오릅니다. |

- 마당에 약 3m 들어서면 망루의 원거리 적이 약 29m에서 플레이어를 봅니다. 망루의 원거리 적은 마당 바닥의 약 77%를 보며, 화단 바로 뒤(망루 반대쪽)에서는 사격이 끊깁니다. 첫째·둘째 기둥 위도 보입니다.
- 근거리 적 하나는 마당에 약 4m, 다른 하나는 약 8m 들어서면 플레이어를 봅니다(둘 다 약 12m).
- 기둥 숲의 기둥에서 떨어지면 마당 바닥에 떨어집니다.

### 들보 다리

쉼터에서 18m 너비의 구덩이를 건넙니다. 구덩이 위에 폭 0.8m 들보 둘이 V자로 놓여 가운데 섬을 지나 사수 테라스로 이어집니다.

| 항목 | 조건 |
| - | - |
| 구덩이 | 길이 18m, 바닥 높이 4.5m (쉼터와 사수 테라스보다 3m 낮음) |
| 들보 | 2개. 폭 0.8m, 길이 약 8.5m, 높이 7.5m. 첫 들보는 쉼터 앞쪽 가장자리의 왼쪽에서 가운데 섬으로, 둘째 들보는 가운데 섬에서 사수 테라스 앞쪽 가장자리의 왼쪽으로 이어집니다. |
| 가운데 섬 | 6m × 6m (높이 7.5m) |
| 근거리 적 | 1명. 가운데 섬 가운데. 둘째 들보 쪽(사수 테라스 쪽)을 바라봅니다. |
| 돌아오는 길 | 구덩이 오른쪽 벽을 따라 쉼터로 오르는 경사로(폭 3m, 기울기 약 25°) |
| 출구 | 둘째 들보 끝이 사수 테라스에 닿습니다. |

- 첫 들보에 올라서면 사수 테라스의 원거리 적이 약 30m에서 플레이어를 봅니다. 첫 들보의 대부분(약 24 ~ 30m)과 가운데 섬, 둘째 들보(약 13 ~ 18m)는 모두 그 적에게 보입니다.
- 가운데 섬의 근거리 적은 둘째 들보 쪽을 보고 있어, 첫 들보를 건너 섬에 올라서도 플레이어를 보지 못합니다. 플레이어가 섬 가운데를 지나 둘째 들보 쪽으로 가면 봅니다.
- 들보나 가운데 섬에서 떨어지면 구덩이 바닥에 떨어지고, 경사로로 쉼터에 돌아가 첫 들보부터 다시 건넙니다.

### 사수 테라스와 달려 뛰기

들보를 건너 사수 테라스의 적을 치고, 테라스를 도움닫기 삼아 걸어서는 닿지 않는 틈 둘을 달려서 넘습니다.

| 항목 | 조건 |
| - | - |
| 사수 테라스 | 18m × 19m 평지 (높이 7.5m) |
| 근거리 적 | 1명. 테라스 앞쪽 가장자리에서 약 11m, 가운데에서 오른쪽으로 5m. 둘째 들보가 닿는 쪽을 바라봅니다. |
| 원거리 적 | 1명. 테라스 앞쪽 가장자리에서 12m, 가운데. 들보 다리 쪽을 바라봅니다. |
| 구덩이 | 길이 15.6m, 바닥 높이 4.5m |
| 가운데 섬 | 8.4m × 6m (높이 7.5m) |
| 틈 | 사수 테라스 → 가운데 섬 3.6m, 가운데 섬 → 탑 바닥 3.6m. 높이 차이는 없습니다. |
| 돌아오는 길 | 구덩이 오른쪽 벽을 따라 사수 테라스로 오르는 경사로(폭 3m, 기울기 약 25°) |
| 출구 | 탑 바닥(높이 7.5m)의 앞쪽 가장자리 |

- 둘째 들보에서 테라스에 약 4m 들어서면 근거리 적이 약 12m에서 플레이어를 봅니다.
- 틈 3.6m는 걸어서 뛰면 닿지 않고 구덩이에 떨어집니다. 회피 뒤 Shift를 누른 채 달려서 뛰면 닿습니다. 달리기는 착지한 뒤에도 이어지므로, 가운데 섬의 8.4m를 도움닫기 삼아 둘째 틈을 이어서 넘습니다.
- 구덩이에 떨어지면 경사로로 사수 테라스에 돌아가 첫 틈부터 다시 넘습니다.

### 나선 탑

탑 바닥 가운데에 지름 8m, 높이 6m의 탑이 서 있고, 탑 둘레를 원기둥 7개가 한 바퀴 돌며 탑 꼭대기까지 오릅니다. 탑 꼭대기에서 다리를 건너 정상 광장으로 갑니다.

| 항목 | 조건 |
| - | - |
| 탑 바닥 | 28m × 19m 평지 (높이 7.5m). 양옆은 1.5m 난간입니다. |
| 탑 | 지름 8m, 꼭대기 높이 13.5m |
| 기둥 | 7개. 탑 둘레에 45°씩 떨어져 섭니다. 첫 기둥은 다리 바로 밑(탑의 정상 광장 쪽)에 있고, 탑의 왼쪽, 탑 바닥 입구 쪽, 오른쪽을 차례로 돌며 높아집니다. 지름은 첫째 ~ 셋째가 3m, 넷째 ~ 일곱째가 2.8m입니다. |
| 오르는 순서 | 탑 바닥 → 첫 기둥 8.25m → … → 일곱째 기둥 12.75m → 탑 꼭대기 13.5m. 모두 0.75m씩 오르며, 기둥 사이 틈은 1.4m(첫째 ~ 셋째), 1.5m(셋째 → 넷째), 1.6m(넷째 ~ 일곱째)입니다. 일곱째 기둥과 탑 사이는 0.3m입니다. |
| 다리 | 탑 꼭대기에서 정상 광장까지 폭 4m, 길이 약 12m (높이 13.5m). 탑 바닥에서 6m 위를 지납니다. |
| 적 | 없음. 정상 광장의 원거리 적이 내려다보며 쏩니다. |
| 출구 | 다리 끝이 정상 광장의 앞쪽 가장자리에 닿습니다. 정상 광장은 탑 바닥보다 6m 높아 다리로만 갑니다. |

- 탑 바닥에 들어서면 정면에 다섯째 기둥이 보이고, 가장 낮은 첫 기둥은 다리 밑을 지나 탑 뒤쪽에 있습니다.
- 정상 광장의 원거리 적은 탑 바닥과 첫째 ~ 셋째 기둥 위의 플레이어를 보지 못합니다. 넷째·일곱째 기둥과 탑 꼭대기, 다리 위의 플레이어를 봅니다(약 13 ~ 26m). 다섯째·여섯째 기둥은 탑에 가려집니다.
- 기둥이나 탑 꼭대기, 다리에서 떨어지면 탑 바닥에 떨어지고, 첫 기둥부터 다시 오릅니다.

### 정상 광장

이 던전의 마지막 일반 교전입니다. 다리를 건너면 성문 앞을 근거리 적 둘이 지키고, 원거리 적이 광장의 탑 쪽 가장자리에서 쏩니다.

| 항목 | 조건 |
| - | - |
| 크기 | 19m × 19m 평지 (높이 13.5m). 양옆은 1.5m 난간이고, 탑 쪽 가장자리는 트여 있으며, 뒤쪽은 6m 벽입니다. |
| 근거리 적 | 2명. 다리 끝에서 약 14m, 가운데에서 좌우로 3.5m. 다리 쪽을 바라봅니다. |
| 원거리 적 | 1명. 다리 끝에서 약 6m, 가운데에서 왼쪽으로 6m. 탑 쪽을 바라봅니다. |
| 출구 | 뒤쪽 벽 가운데의 성문 통로(폭 5m, 길이 8m, 벽 6m). 통로 가운데에 성문이 있습니다. |
| 성문 | 통로 입구에서 약 4m, 폭 5m. 처음에는 닫혀 있습니다. 아래 '성문'을 따릅니다. |

- 다리를 건너 광장에 약 2.5m 들어서면 근거리 적 둘이 약 12m에서 플레이어를 봅니다.
- 근거리 적은 다리와 탑 꼭대기까지 걸어 나올 수 있습니다. 다리나 광장의 탑 쪽 가장자리에서 떨어지면 탑 바닥에 떨어집니다.

#### 성문

정상 광장과 보스 아레나 사이를 막는 문입니다. 이 던전에서 플레이어가 상호작용하는 유일한 장치입니다. 처음 상태, 여는 조건, 안내, 상호작용 범위, 열리는 중과 열린 뒤, 재도전의 규칙은 [스테이지 - 미니던전 요새 돌파](<스테이지 - 미니던전 요새 돌파.md>)의 '성문'과 같습니다.

- 성문에서 가장 가까운 적(성문 앞 근거리 적)까지는 약 10.6m입니다.

### 보스 아레나

커스터와 싸우는 네모난 방입니다. 성문을 지나 약 4m 뒤에 입구가 있으며, 성문 통로와 아레나는 정상 광장과 같은 높이(13.5m)입니다. 바닥, 장애물, 경계는 [스테이지 - 시뮬레이션 룸](<스테이지 - 시뮬레이션 룸.md>)의 '아레나'와 같으며, 아래만 다릅니다.

| 항목 | 조건 |
| - | - |
| 크기 | 31m × 31m의 사각 평지 (벽 높이 6.5m) |
| 입구 | 성문 쪽 벽 가운데, 폭 5m |
| 시야 | 성문이 열리면 통로 너머로 아레나 안의 커스터가 보입니다. 성문에서 커스터까지 약 28.5m라 커스터의 시야(20m) 밖입니다. |
| 커스터의 시야 | 입구에서 약 3.5m 들어오면 커스터의 시야(20m)에 들어갑니다. |

- 따로 쉬어 가는 대기 공간은 두지 않습니다. 적을 정리한 정상 광장과, 성문을 열고 지나는 통로가 그 역할을 합니다.

## 높이 구성

0m의 출발 정원에서 징검다리로 3m의 분수 마당에 오르고, 기둥 숲을 지나 7.5m의 쉼터에 오릅니다. 들보 다리, 사수 테라스, 달려 뛰기, 탑 바닥은 7.5m로 이어지며, 들보 다리와 달려 뛰기 아래의 구덩이는 4.5m입니다. 탑을 도는 기둥으로 13.5m의 탑 꼭대기에 오르고, 다리, 정상 광장, 성문 통로, 보스 아레나는 13.5m입니다. 높이가 오르는 곳은 모두 점프로만 오르며, 걸어서 오르는 곳은 구덩이에서 출발점으로 돌아가는 경사로 둘뿐입니다.

## 미확정 항목

구간의 크기, 거리, 적의 수는 그레이박스를 만들기 전에 정한 값이라, 아래는 플레이해 본 뒤 조정합니다.

- **구간 크기와 거리:** 각 구간의 길이, 폭, 발판의 크기와 틈, 적 사이의 거리는 플레이해 보고 조정합니다.
- **예상 플레이 시간:** 약 8분은 적의 수와 이동 거리로 어림한 값입니다. 플레이해 보고 고칩니다.
- **점프의 난이도:** 오르는 점프는 가장자리 약 0.6m 앞에서 뛰어도 닿고, 달려 뛰기도 0.6m 앞에서 뛰면 닿습니다. 처음 하는 플레이어에게 너무 빡빡하거나 너무 쉽지 않은지, 달려야 넘는 틈이라는 것을 알아채는지 확인합니다.
- **떨어진 뒤 다시 오르기:** 들보 다리, 달려 뛰기, 나선 탑은 떨어지면 그 도전을 처음부터 다시 합니다. 다시 오르는 시간이 지나치게 길지 않은지 확인합니다.
- **사격 속의 점프:** 원거리 적이 쏘는 가운데 들보를 건너고 기둥을 오르는 것이 지나치게 어렵지 않은지 확인합니다.
- **분수 마당의 첫 기둥:** 기둥 숲의 첫 기둥(마당 바닥에서 0.75m 위)에 서면 근거리 적이 올라오지 못합니다. 위에서 점프 공격만 하는 플레이가 되지 않는지 봅니다.
- **스킬 1로 건너뛰기:** 마당에서 망루의 원거리 적에게, 가운데 섬에서 사수 테라스의 원거리 적에게 스킬 1을 쓰면 그 사이의 기둥이나 들보를 건너뛰어 그 적 너머에 나타납니다. 지름길로 둘지 봅니다.
- **나선 탑의 난간:** 셋째·일곱째 기둥은 옆 난간에서 약 2.3m 떨어져 있어, 바깥으로 뛰면 난간 위나 난간 너머로 갈 수 있습니다. 난간 너머는 레벨 바깥의 0m 바닥이라 출발 정원으로 걸어 돌아가야 하고, 일곱째 기둥에서 떨어지면 약 13 ~ 14m를 떨어져 MaxHP의 약 30 ~ 40%를 잃습니다. 난간을 높일지 플레이해 보고 정합니다.
- **발판 밖으로 떨어지는 적:** 넉업으로 띄운 적은 가운데 섬이나 테라스 가장자리 밖으로 떨어질 수 있습니다. 떨어진 적은 구덩이나 아래층에 남습니다.
- **다리 위의 싸움:** 성문 앞의 근거리 적이 다리로 나오면 폭 4m 다리 위에서 싸우게 되고, 밀리면 탑 바닥으로 떨어져 기둥을 다시 오릅니다. 지나치게 가혹하지 않은지 확인합니다.
- **구간을 지나치는 플레이:** 성문 앞까지는 길을 막는 장치가 없어 적을 무시하고 지나갈 수 있습니다. 남겨 둔 적은 발판에서 내려가지 못해 따라오지 못하지만, 원거리 적은 건너편에서 계속 쏩니다.
- **보스 아레나에서 커스터의 이동:** 열린 성문은 다시 닫히지 않아 커스터의 돌진이 성문 통로로 빠져나갈 수 있습니다. 플레이해 보고 정합니다.
