# 용어집

기획서에서 사용하는 용어와 그 뜻을 정의합니다. 문서마다 같은 개념을 다르게 부르지 않도록, 모든 기획서는 이 문서의 용어를 따릅니다.

## 사용 규칙

- 기획서에는 이 문서의 '용어' 열에 있는 표현을 사용합니다. 대화나 메모에서 쓰인 표현도 문서에 옮길 때는 이 문서의 용어로 바꿉니다.
- 새로운 개념을 문서에 쓰기 전에 이 문서에 먼저 용어를 추가합니다.
- 이 문서는 뜻만 짧게 설명하며 수치는 적지 않습니다. 자세한 규칙과 수치는 각 항목의 정의 문서를 따릅니다.
- 일상적인 뜻 그대로 쓰는 말(예: 점프, 콤보, 사망)은 싣지 않습니다.
- 엔진이나 업계에서 널리 쓰는 표준 표현(예: State Tree, 애니메이션, 피벗, 셰이크)은 그대로 써도 되며, 이 프로젝트에서 따로 정한 뜻이 없으면 싣지 않습니다.
- 동의어는 나열하지 않습니다. 두 표현이 실제로 헷갈릴 때만 해당 분류 아래에 구분을 적습니다.
- '영문 표기'는 구현할 때 클래스, 변수, Gameplay Tag 등의 이름을 정하는 기준으로 삼습니다.
- 스탯은 [전투 시스템](<전투 시스템.md>)의 스탯 표를 따르며, 본문에서는 약어(HP, SP 등)로 씁니다.
- 구현 우선순위는 🔴 S, 🟡 A, 🟢 B로만 표기합니다. ([마일스톤1 계획](<마일스톤1 계획.md>) 참고) 필수, 권장, 선택, 범위 외, 제외, P0 ~ P2는 구현 우선순위 표기로 쓰지 않으며, 일반적인 뜻으로는 쓸 수 있습니다. (예: 패턴 선택)

## 전투 공통

정의 문서: [전투 시스템](<전투 시스템.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 대미지 | Damage | 공격이 적중했을 때 HP와 PP를 감소시키는 효과 |
| HP 감소량 | HPDamage | 대미지로 줄어드는 HP의 양 |
| PP 감소량 | PPDamage | 대미지로 줄어드는 PP의 양 |
| 대미지 배율 | DamageMultiplier | 공격마다 정해진 HP 감소량 배율. ATK에 곱합니다. |
| PP 배율 | PoiseMultiplier | 공격마다 정해진 PP 감소 배율. ATK에 곱합니다. |
| 가드 경감 배율 | GuardReduction | 가드로 막았을 때 HP 감소량에 곱하는 경감 배율 |
| 공격 데이터 | Attack Data | 공격 판정 1타가 가지는 값의 묶음 |
| 타 | Hit | 공격 판정 하나를 세는 단위 (1타, 2타) |
| 공격 판정 | Attack Hitbox | 공격이 대상에게 닿았는지 검사하는 단위 하나. 1타가 공격 판정 하나입니다. |
| 선딜 / 판정 구간 / 후딜 | Startup / Active / Recovery | 공격 모션의 세 구간. 판정 구간 전의 준비, 공격 판정이 켜져 있는 구간, 판정 구간 후의 회복 |
| 리젠 대기 시간 | Regen Delay | 자원이 줄어든 뒤 자동 회복이 시작되기까지의 시간 |
| 무적 | Invincible | 공격 판정이 닿아도 아무 일도 일어나지 않는 상태 |
| 가드 | Guard | 공격을 막아 대미지를 경감하는 행동 |
| 가드 불가 | Unblockable | 가드와 패리로 막을 수 없는 공격 속성 |
| 피격 반응 | Hit Reaction | 공격에 맞았을 때 재생하는 반응의 종류. 없음, 움찔, 넉백, 다운 |
| 움찔 | Flinch | 하던 행동을 끊지 않고 모션만 덧입혀 재생하는 피격 반응 |
| 넉백 | KnockBack | 뒤로 크게 밀려나는 피격 반응 |
| 다운 | KnockDown | 쓰러졌다가 일어나는 피격 반응 |
| 가드 반응 | Guard React | 가드로 공격을 막았을 때의 반응. 가드 움찔과 가드 밀림이 있습니다. |
| 가드 움찔 | Guard Flinch | 피격 반응이 움찔인 공격을 막았을 때의 반응. 행동 제한이 없습니다. |
| 가드 밀림 | Guard Pushback | 피격 반응이 넉백, 다운인 공격을 막았을 때의 반응. 모션이 끝날 때까지 다른 행동을 할 수 없습니다. |
| 슈퍼아머 | SuperArmor | 넉백, 다운을 무시하고 하던 행동을 계속하는 상태 |
| 그로기 | Groggy | PP가 0 이하가 되어 일정 시간 아무 행동도 할 수 없는 상태 |
| 상태 우선순위 | - | 상태끼리 서로 중단시킬 수 있는지 정하는 순서 |

- 공격에 관한 '판정'은 무엇을 가리키는지 구분해 씁니다. 공격 하나는 '공격 판정', 공격 모션의 구간은 '판정 구간', 패리가 가능한 구간은 '패리 구간'입니다.
- '경직'은 쓰지 않습니다. 가드로 막았을 때의 반응은 '가드 반응', PP에 관한 값과 규칙은 'PP'로 씁니다.

## 플레이어 행동

정의 문서: [플레이어 사양](<플레이어 사양.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 평타 | Basic Attack | 평타 키로 사용하는 연속 공격 |
| 회피 | Dodge | 입력 방향으로 빠르게 이동하며 잠깐 무적이 되는 행동 |
| 극한 회피 | Perfect Dodge | 극한 회피 구간에 공격을 피해 내는 것 |
| 극한 회피 구간 | Perfect Dodge Window | 회피를 시작한 직후 극한 회피가 가능한 짧은 구간 |
| 회피 반격 | Dodge Counter | 극한 회피 직후 평타를 입력해 사용하는 반격 |
| 가드 브레이크 | Guard Break | 가드 중 SP가 부족해 가드가 강제로 풀리는 것 |
| 패리 | Parry | 패리 구간에 공격을 받아 내는 것 |
| 패리 구간 | Parry Window | 가드를 새로 시작한 직후 패리가 가능한 짧은 구간 |
| 슬로우모션 | Slow Motion | 극한 회피나 패리에 성공한 순간 게임 전체가 아주 잠깐 느려지는 연출 |
| 실제 시간 | Real Time | 슬로우모션 등 속도 변화의 영향을 받지 않는 현실의 시간 |
| 달리기 | Sprint | 회피 후 회피 키를 계속 누르고 있으면 이어지는 빠른 이동 |
| 스킬 | Skill | MP를 소모하는 공격 |
| 궁극기 | Ultimate | UP를 모두 소모하는 강력한 공격 |
| 처형 | Execution | 그로기 상태의 보스에게 사용하는 마무리 공격 |
| 락온 | Lock-On | 보스를 대상으로 고정해 캐릭터와 카메라의 방향을 맞추는 기능 |
| 공격 방향 보정 | Attack Assist | 공격을 시작할 때 보스 쪽으로 회전하고 거리를 좁혀 주는 보정 |
| 캔슬 | Cancel | 플레이어가 다른 행동을 입력해 진행 중인 행동을 끊는 것 |
| 행동 가능 표 | - | 현재 상태에서 각 입력이 어떻게 처리되는지 정리한 표 |

- '공격'은 일반적인 뜻(보스의 공격, 공격 판정 등)으로만 씁니다. 플레이어가 평타 키로 쓰는 연속 공격은 '평타'로 씁니다.
- '대시'는 회피와 달리기 중 무엇인지 모호하므로 쓰지 않습니다.

## 보스·AI

정의 문서: [보스 사양](<보스 사양.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 커스터 | Custer | LV_BossStage의 보스 |
| 페이즈 전환 | Phase Transition | 다음 페이즈로 넘어갈 때 재생하는 전환 연출 |
| 패턴 | Pattern | 보스의 행동 단위. 공격 패턴과 보조 행동이 있습니다. |
| 거리 구간 | Range Band | 패턴을 고르는 기준이 되는 거리 구분. 근거리, 중거리, 원거리 |
| 패턴 후딜레이 | Pattern Recovery | 패턴, 그로기, 페이즈 전환 등이 끝난 뒤 다음 패턴을 고르기 전까지 기다리는 시간 |
| 패턴 전조 동작 | Wind-up | 공격 타이밍을 읽을 수 있도록 패턴의 선딜 동안 보여 주는 큰 준비 동작 |
| 붉은 섬광 | Unblockable Telegraph | 가드 불가 공격 직전에 무기에 표시하는 예고 이펙트 |
| 처형 피격 | Executed | 보스가 처형당하고 있는 상태 |
| AI 상태 트리 | AI State Tree | 보스의 상태와 상태 사이의 전환 규칙을 트리로 정리한 것 |
| Root 전환 | Root Transition | 개별 상태가 아니라 트리 전체에 걸어 두고 검사하는 전환 |

- 보스의 행동은 '패턴'으로 씁니다. '스킬'은 플레이어의 스킬에만 씁니다.
