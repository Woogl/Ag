# 아트 표현 사양

캐릭터의 외형과 사용 리소스, 전투 VFX·화면 효과·효과음, HUD 아이콘의 표현을 정의합니다. 제작 범위는 [마일스톤1 계획](<마일스톤1 계획.md>)의 아트 리소스를 따릅니다.

발동 조건과 판정 시점은 [전투 시스템](<전투 시스템.md>), [플레이어 사양](<플레이어 사양.md>), [보스 사양](<보스 사양.md>)을 따릅니다. 카메라 연출은 [카메라](<카메라.md>), UI의 배치와 표시는 [전투 HUD](<전투 HUD.md>), [화면 UI](<화면 UI.md>), [UI 스타일](<UI 스타일.md>)을 따릅니다.

기존 리소스의 조사 근거는 [에셋 조사 개요](<../Art/에셋 조사 개요.md>), 실제 설정 위치와 에셋 경로는 [데이터 위치표](<../Program/데이터 위치표.md>)와 [에셋 목록](<../Program/에셋 목록.md>)에서 찾습니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 효과와 UI 리소스

| 용도 | 쓰는 에셋 | 표현 |
| - | - | - |
| 가드 불가 예고 | 직접 제작한 `NS_Telegraph` | 젠레스 존 제로의 공격 전 섬광처럼, 무기에서 교차하는 가는 가로·세로 빛줄기입니다. 세로 줄기는 화면 위아래 끝까지 이어지고, 가로 줄기는 화면 너비의 약 4/5 길이로 끝으로 갈수록 가늘어집니다. 예고가 켜진 동안 젠레스 존 제로와 같은 순서로 바뀝니다. 켜질 때 교차점까지 굵게 번쩍이고, 굵은 빛이 교차점에서 바깥으로 물러나며 가늘어집니다. 이어서 가로 줄기의 바깥 끝이 줄어들며 흐려지고, 세로 줄기가 가로 줄기보다 먼저 흐려집니다. 교차점은 끝나기 직전(시간의 97%)에야 비고, 사라질수록 주황빛이 짙어집니다. 빨간색입니다. 위치와 시작·종료 시점은 [보스 사양](<보스 사양.md>)의 '공격 예고'를 따르고, 예고가 끝나면 남은 빛도 바로 사라집니다. |
| 패리 예고 | 직접 제작한 `NS_Telegraph` | 가드 불가 예고와 같은 VFX를 금색으로, 예고가 켜진 동안 같은 순서로 변화하도록 재생합니다. 시작·종료 시점은 [보스 사양](<보스 사양.md>)의 '공격 예고'를 따릅니다. |
| 극한 회피 화면 효과 | 직접 제작한 극한 회피용 후처리 에셋 | 스텔라 블레이드의 Perfect Dodge를 참고합니다. 성공 순간 가장자리의 짧은 왜곡과 색 분리, 붉은 기운으로 회피 성공을 강조하고, 중앙의 적과 플레이어는 식별할 수 있게 유지합니다. 궁극기처럼 화면 전체를 지속해서 흑백으로 만들지 않습니다. 페이드는 아트에서 조정합니다. 재생 조건과 길이는 [플레이어 사양](<플레이어 사양.md>)의 '극한 회피'를 따릅니다. |
| 궁극기 화면 효과 | 직접 제작한 궁극기용 후처리 에셋 | 데빌 메이 크라이의 Judgement Cut End를 참고해 채도를 낮춘 차가운 색감, 어두운 배경과 선명한 명암으로 참격을 강조합니다. 극한 회피 화면 효과와 별도로 제작·조정합니다. 공간을 가르는 참격과 파편은 화면의 색·왜곡을 담당하는 후처리와 구분하는 시각 효과입니다. 재생 구간은 [플레이어 사양](<플레이어 사양.md>)의 '궁극기 화면 효과'를 따릅니다. |
| 카메라 셰이크 | 직접 제작한 소·중·대 셰이크 에셋 | 단계와 상황별 선택은 [카메라](<카메라.md>)를 따릅니다. |
