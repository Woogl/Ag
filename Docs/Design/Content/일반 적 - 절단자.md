# 일반 적 - 절단자

단발 베기·짧은 연타·가드 불가 공격으로 패리와 회피 뒤 반격하는 기본 공방을 만드는 근거리 일반 적입니다. 강인도는 중형으로, 기본 공격의 움찔에는 공격을 계속하고 넉업·넉다운 공격에는 행동이 중단됩니다.

공격 예고·시야·정찰·패턴 선택은 [적 시스템](<../System/적 시스템.md>), 대미지·강인도·피격·그로기·사망은 [전투 시스템](<../System/전투 시스템.md>)을 따릅니다. 외형과 모션은 [일반 적 아트 구성](<../../Art/일반 적 아트 구성.md>)을 따릅니다.

## 개요

| 항목 | 내용 |
| - | - |
| 이름 | 절단자 |
| 분류 | 근거리 일반 적 |
| 무기 | 검 1자루 |
| 강인도 | 중형 |
| 크기 | 무기를 제외한 직립 신장 기준 플레이어와 같은 크기 |
| 목표 전투 시간 | 패턴을 숙지한 플레이어의 1:1 전투 기준 8~12초 |

목표 전투 시간은 평지에서 적의 HP·PP가 최대이고 린은 기본 스탯, HP 최대, MP·UP 0으로 시작하는 조건입니다. 기본 공격·패리·가드·회피·스킬·처형을 사용하고 궁극기는 사용하지 않습니다. 전투 진입부터 적 HP가 0이 될 때까지의 실제 시간으로, 5회 교전의 중앙값을 기준으로 합니다.

## 스탯

| 스탯 | 값 |
| - | - |
| HP / MaxHP | 600 / 600 |
| MP / MaxMP | 0 / 0 |
| UP / MaxUP | 0 / 0 |
| PP / MaxPP | 400 / 400 |
| ATK | 120 |
| DEF | 0 |
| MOV | 250cm/s |

- MP·UP는 사용하지 않습니다. 패턴은 쿨다운으로 제어합니다.
- HP는 자동 회복하지 않습니다.
- PP는 초당 25 회복합니다. 리젠 대기 시간은 전투 시스템을 따릅니다.

## 시야와 이동

| 항목 | 값 |
| - | - |
| 시야 거리 | 12m |
| 정면 각도 | 120° — 좌우 60°씩 |
| 회전 속도 | 초당 360° |

- 발견·피격에 의한 전투 진입, 지형 가림, 시야 상실과 복귀는 적 시스템을 따릅니다. 보스의 전투 유지 예외는 적용하지 않습니다.
- 패턴을 고르지 못하는 동안의 움직임은 [적 시스템](<../System/적 시스템.md>)의 '공격하지 않는 동안의 움직임'을 따릅니다. 접근·물러나기·정찰·복귀·좌우 걷기는 MOV 속도를 사용합니다.
- 전투 중 일반 이동·대기에서는 플레이어를 바라봅니다. 피격으로 행동이 중단된 동안, 그로기, 처형 피격 중에는 일반 목표 방향 회전을 하지 않습니다.
- 여러 적과 함께 싸울 때 공격할 차례는 [적 시스템](<../System/적 시스템.md>)의 '동시 공격 수'를 따릅니다. 배치와 클리어 조건은 해당 레벨 기획서와 [게임 플로우](<../System/게임 플로우.md>)를 따릅니다.

## 패턴 공통 규칙

### 추적과 방향 확정

- 각 타의 준비 동작 중에만 플레이어를 향해 회전하며, 단발 베기는 판정 시작 0.05초 전, 2연 베기와 내려찍기는 0.15초 전에 방향을 확정합니다. 이후 다음 추적 구간 전까지 플레이어의 이동을 따라가지 않습니다.
- 2연 베기는 첫 타 판정이 끝난 뒤 두 번째 준비 동작에서 다시 방향을 보정합니다.
- 공격 중 위치·회전 보정은 전투 시스템을 따릅니다. 타겟팅 범위는 반경 12m 안에 플레이어의 캡슐이 닿는 범위입니다.
- 대상과의 최소 간격은 캡슐 중심 사이 수평 거리로 단발 베기 1.0m, 2연 베기와 내려찍기 1.2m입니다. 위치 보정 목표는 각 추적 구간 시작에 한 번 정하며 이후 대상 이동에 맞춰 갱신하지 않습니다.
- 추적 구간 뒤의 내딛기는 제자리에서 하며, 다음 추적 구간 전까지 추가 접근하지 않습니다. 발동 거리 상한에서 정면의 정지한 대상에게 접근하는 양은 단발 베기 최대 1.0m, 2연 베기 각 타 최대 0.8m, 내려찍기 1.1m입니다.
- 이동 중 벽과 캐릭터의 충돌을 유지합니다. 발동 가능 거리와 실제 검의 공격 궤적은 별개입니다.

### 패턴 후딜레이

- 패턴 후딜레이는 걸 때마다 0.6~1.0초 중 무작위로 정합니다. 거는 때는 [적 시스템](<../System/적 시스템.md>)의 '패턴 후딜레이'를 따릅니다.
- 적정 거리는 2~4m이고, 그 안에서 기다리는 동안 플레이어를 바라보며 좌우로 걷습니다. 다수전에서 기다리는 절단자가 플레이어 바로 앞에 몰리지 않고 둘러싸도록 띄운 거리이며, 공격할 차례가 되면 패턴이 닿는 거리(0~2.3m)까지 다가갑니다.

### 페이즈와 선택

HP 구간 전체에서 1페이즈만 사용하며, HP 감소에 따른 패턴 변화와 페이즈 전환 연출은 없습니다.

| 패턴 | 발동 가능 거리 | 가중치 | 가드 가능 | 쿨다운 |
| - | - | - | - | - |
| 단발 베기 | 0~2.0m | 6 | 가능 | 없음 |
| 2연 베기 | 0~2.0m | 3 | 두 타 모두 가능 | 4초 |
| 내려찍기 | 0~2.3m | 1 | 불가 | 8초 |

- 발동 가능 거리는 캡슐 중심 사이 수평 거리이며 양 끝값을 포함합니다.
- 거리·쿨다운 조건을 만족한 후보 중 가중치로 선택합니다. 쿨다운은 패턴 시작부터 계산하고 중단되어도 유지합니다.
- 공격의 PP 배율은 모두 0입니다. 플레이어는 그로기 면역입니다.
- 공격 판정은 검이 실제로 베는 구간에만 있으며, 준비·회수 동작에는 피해가 없습니다. 각 타는 같은 대상에게 한 번만 적중합니다.

## 패턴 상세

### 단발 베기

몸을 옆으로 비틀고 검을 뒤로 당겼다가 정면을 가로지르며 한 번 벱니다. 패리하거나 피한 뒤 검을 회수하는 틈에 반격할 수 있습니다.

| 타 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - |
| 1 | 1.0 | 움찔 | 가능 |

- 패리 예고를 적용합니다.
- 빗나가도 정해진 회수 동작과 후딜을 수행합니다.

### 2연 베기

검을 세워 들어 내려벤 뒤, 대기 자세로 돌아가지 않고 검을 다시 들어 사선으로 내려벱니다. 후속타까지 확인한 뒤 마지막 타의 후딜에 반격할 수 있습니다.

| 타 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - |
| 1 | 0.8 | 움찔 | 가능 |
| 2 | 0.8 | 움찔 | 가능 |

- 각 타에 패리 예고를 적용합니다.
- 첫 타가 빗나가거나 패리되어도 두 번째 타를 수행합니다. 사망·그로기·행동을 중단시키는 피격 반응과 플레이어 사망에 따른 전환은 공통 규칙대로 우선 적용합니다.

### 내려찍기

검을 머리 위로 크게 넘겨 준비한 뒤 정면 아래로 내려찍습니다. 회피 후 긴 후딜에 반격하거나 넉업·넉다운 공격으로 준비 동작을 중단할 수 있습니다.

| 타 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - |
| 1 | 1.5 | 넉다운 | 불가 |

- 붉은 가드 불가 예고를 적용합니다.
- 판정은 검이 내려오는 전방 궤적에만 있으며 별도의 충격파는 없습니다.
- 내려찍은 뒤 검을 낮게 둔 회복 동작을 보여 줍니다.

### 공격 타이밍

아래는 모션 진행 기준의 시간이며 소수 둘째 자리로 반올림한 값입니다. 히트스톱과 슬로우모션 등은 [시간 규칙](<../System/시간 규칙.md>)을 따릅니다. 패턴 후딜레이는 별도로 적용합니다.

| 패턴 | 판정 시작 (패턴 시작 기준) | 판정 길이 | 마지막 판정 뒤 후딜 |
| - | - | - | - |
| 단발 베기 | 0.66초 | 0.12초 | 0.45초 |
| 2연 베기 | 0.77초, 1.44초 | 각각 0.10초 | 0.66초 |
| 내려찍기 | 1.10초 | 0.09초 | 0.87초 |

## 피격·그로기·처형·사망

- 강인도 중형의 피격 규칙을 적용합니다. 움찔 공격에는 맞은 부위가 흔들리며 행동을 유지하고, 넉업·넉다운 공격에는 움찔로 패턴이 중단됩니다. 중단된 패턴의 남은 타격은 발생하지 않습니다.
- 슈퍼아머와 자체 무적 구간은 없습니다.
- PP 소진 시 공격을 중단하고 무방비한 그로기 자세가 됩니다. 지속 시간·피격·종료 시 PP 회복은 전투 시스템을 따릅니다.
- 그로기 상태에서 [린의 처형 조건](<플레이어 캐릭터 - 린.md#처형-execution>)을 만족하면 처형 대상이 됩니다. 린의 찌르기와 마지막 일격에 맞춰 처형 피격 동작을 재생합니다.
- 그로기 또는 처형 피격이 끝난 뒤 살아 있고 행동할 수 있으면 패턴 후딜레이를 거칩니다.
- HP가 0 이하가 되면 공통 사망 처리를 적용합니다. 처형으로 사망하면 처형 사망 동작으로 이어집니다. 사망한 개체는 공격하거나 이동을 막지 않습니다.
- 일반 적 처치에는 보스 처치 슬로우모션을 적용하지 않습니다.
- 락온은 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>), 상호작용 안내는 [UI 시스템](<../System/UI 시스템.md>), 대미지 숫자는 전투 시스템의 공통 규칙을 따릅니다.
