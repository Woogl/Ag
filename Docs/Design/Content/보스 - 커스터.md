# 보스 - 커스터

LV_BossStage에 등장하는 보스의 스탯, 공격 패턴, 연출을 정의합니다.

공격 예고, 시야, AI 행동과 페이즈 규칙은 [적 시스템](<../System/적 시스템.md>)을, 보스의 전투 유지 예외는 [보스 시스템](<../System/보스 시스템.md>)을 따릅니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<../System/전투 시스템.md>) 문서를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 패턴 공통 규칙

### 모션 템포

- 공격 패턴은 플레이어가 전조 동작을 보고 패리와 회피로 대응할 수 있도록 자연스럽고 적절한 템포로 조절합니다.

### 회전

보스의 Yaw 회전 속도는 초당 360°입니다.

- 보스의 목표 방향은 플레이어이며, 이동 중이거나 서 있을 때 [전투 시스템](<../System/전투 시스템.md>)의 '목표 방향 회전'에 따라 플레이어를 정면으로 바라봅니다. 단, 공격 패턴, Backstep, 피격 반응(넉업/넉다운), 그로기, 처형 피격, 페이즈 전환 중에는 이 회전을 하지 않습니다.
- 공격 패턴의 각 타는 준비 동작 동안 플레이어를 향해 돌고, 판정 직전에 방향을 확정해(회전 정지) 이후 플레이어의 이동을 따라가지 않습니다. 패턴마다 다른 점은 각 패턴 항목을 따릅니다.

모션: 제자리 회전 [ARPG_Warrior_Anim_UE_Turn_45L](<../../Art/GIF/Warrior/ARPG_Warrior_Anim_UE_Turn_45L.gif>)·`R`, [ARPG_Warrior_Anim_UE_Turn_90L](<../../Art/GIF/Warrior/ARPG_Warrior_Anim_UE_Turn_90L.gif>)·`R`

### 이동

공격 패턴은 [전투 시스템](<../System/전투 시스템.md>)의 '공격 중 위치·회전 보정'을 따릅니다. 보스는 캡슐 중심에서 반경 50m 안에 캡슐이 닿는 플레이어를 대상으로 합니다. 대상이 이 범위를 벗어나면 락온을 해제합니다. 범위 안에 다시 들어오면 대상을 다시 찾습니다. 대상과의 최소 간격은 1.5m, 회전 정지는 위 '회전'을 따릅니다. 위치 보정을 하는 추적 구간은 아래와 같습니다.

| 패턴 | 위치 보정을 하는 추적 구간 |
| - | - |
| DoubleStrike의 1타 | 준비 동작부터 판정 직전까지 |
| JumpCleave | 도약부터 공중의 정점까지, 정점부터 내려찍기 직전까지 (정점에서 보정 목표를 다시 정함) |
| 그 밖의 타 (DoubleStrike의 2타, Sweep, QuintupleStrike, SwordWave) | 없음 |

- DashThrust와 GroundSlam은 각 패턴의 이동 규칙을 따릅니다.

### 패턴 후딜레이

- 대기 시간은 0.5 ~ 1.2초 중 무작위입니다. 패턴 후딜레이 동안의 행동은 [적 시스템](<../System/적 시스템.md>)의 '패턴 후딜레이'를 따릅니다.

## 페이즈

| 페이즈 | HP 구간 | 특징 |
| - | - | - |
| 1페이즈 | 100% ~ 50% 초과 | 기본 패턴 4종 (DoubleStrike, Sweep, DashThrust, JumpCleave) |
| 2페이즈 | 50% 이하 | 신규 패턴 3종 추가 (GroundSlam, QuintupleStrike, SwordWave) |

- 페이즈 규칙은 [적 시스템](<../System/적 시스템.md>)의 '페이즈'를 따르며, 다음 페이즈로 넘어갈 때의 연출은 '연출'의 페이즈 전환을 따릅니다.

## 패턴 목록

| ID | 설명 | 페이즈 | 허용 거리 | 가중치 | 가드 가능 | 쿨다운 |
| - | - | - | - | - | - | - |
| DoubleStrike | 찌른 뒤 내려찍기 | 1, 2 | 0 ~ 3m | 4 | 가능 | 없음 |
| Sweep | 달려들며 크게 휩쓸기 | 1, 2 | 0 ~ 3m | 3 | 가능 | 5초 |
| DashThrust | 먼 거리를 돌진하며 찌르기 | 1, 2 | 3 ~ 50m | 4 | 가능 | 10초 |
| JumpCleave | 뛰어올라 내려찍기 | 1, 2 | 0 ~ 10m | 3 | 가능 | 6초 |
| GroundSlam | 높이 도약해 플레이어 위치에 내려찍기 | 2 | 3 ~ 50m | 8 | 불가 | 12초 |
| QuintupleStrike | 4연타 후 휩쓸기로 마무리 | 2 | 0 ~ 3m | 8 | 1 ~ 4타 가능, 5타 불가 | 8초 |
| SwordWave | 세 번 휘둘러 검기 날리기 | 2 | 3 ~ 50m | 8 | 가능 | 10초 |
| Backstep | 뒤로 크게 물러나기 | 1, 2 | 0 ~ 4m | - | - | 4초 |

- 허용 거리는 양 끝 거리를 포함합니다.
- 가중치는 후보끼리 비교하는 비율이라 합이 정해진 값일 필요는 없으며, 뽑힐 확률은 '해당 패턴 가중치 ÷ 후보 가중치 총합'입니다. 예를 들어 1페이즈 거리 2m 상황에서는 DoubleStrike(4), Sweep(3), JumpCleave(3)가 후보가 되며, 각각 4/10, 3/10, 3/10의 확률로 선택됩니다.
- Backstep은 가중치로 고르지 않고, 발동 조건을 만족하면 사용합니다. ('Backstep' 참고)
- 쿨다운 규칙은 [전투 시스템](<../System/전투 시스템.md>)의 '쿨다운'을 따릅니다.
- 플레이어는 그로기 대상이 아니므로 보스 공격에는 PP 배율을 정의하지 않습니다.

## 패턴 상세

아래 모션 이름의 링크는 원본 시퀀스를 1배속으로 보여 줍니다. 행동별 조합 그림은 원본 GIF의 필요한 구간을 연결하고 배속·반복을 적용한 미리보기입니다. 캐릭터와 무기는 각 원본 GIF의 구성을 따르며, 판정·예고·연출 설명은 본문을 따릅니다.

모션 그림에서는 카메라가 보스를 따라가므로 이동한 거리는 나타나지 않습니다. DashThrust의 돌진과 GroundSlam의 도약도 모션 밖에서 주므로 나타나지 않으며, DashThrust는 10m를 돌진하는 경우입니다.

할버드로 찌른 뒤 내려찍는 기본 연속 공격입니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 낮은 자세에서 앞으로 찌르기 | 1.0 | 움찔 | 가능 |
| 2 | 머리 위로 들어 올렸다가 정면 바닥까지 내려찍기 | 1.4 | 넉다운 | 가능 |

![DoubleStrike 모션](<../../Art/Attachments/보스 모션 2연격.gif>)

모션: [ARPG_Halberd_Anim_UE_Attack_Combo1](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo1.gif>) → [ARPG_Halberd_Anim_UE_Attack_Combo2](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo2.gif>)

- 패턴 전조 동작: 찌르기 전에 낮은 자세로 창을 끌어당기고, 내려찍기 전에 창을 머리 위로 들어 올려 공격 타이밍을 읽을 수 있게 합니다.
- 설계 의도: 패리 연습용 기본 패턴입니다. 패턴 전조 동작을 보고 1타를 패리할 수 있게 합니다. 2타 후의 후딜이 반격 기회입니다.

### Sweep

앞으로 달려들며 할버드를 크게 휩쓰는 공격입니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 오른쪽 뒤에서 정면을 지나 왼쪽 아래까지, 가슴에서 무릎 높이로 비스듬히 휩쓸기 | 1.5 | 넉업 | 가능 |

![Sweep 모션](<../../Art/Attachments/보스 모션 휩쓸기.gif>)

모션: [ARPG_Halberd_Anim_UE_Attack_Sprint](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Sprint.gif>)

- 패턴 전조 동작: 앞으로 달려들며 할버드를 세워 들었다가 몸 오른쪽 뒤로 끌어당겨 공격 타이밍을 읽을 수 있게 합니다.
- 휩쓸기 뒤 할버드를 반대로 한 번 더 휘두르며 마무리합니다. 이 동작에는 공격 판정이 없습니다.
- 설계 의도: 옆으로 피하기 어려운 공격입니다. 후방 회피나 패리로 대응하게 합니다.

### DashThrust

먼 거리를 한 번에 좁히며 찌르는 공격입니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 플레이어 쪽으로 제한적으로 유도되며 돌진 찌르기 | 2.0 | 넉업 | 가능 |

![DashThrust 모션](<../../Art/Attachments/보스 모션 돌진 찌르기.gif>)

모션: [ARPG_Halberd_Anim_UE_Attack_Heavy1_Start](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Heavy1_Start.gif>) → [ARPG_Halberd_Anim_UE_Attack_Heavy1](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Heavy1.gif>)

- 패턴 전조 동작: 자세를 낮추며 할버드를 뒤로 당겨 모읍니다.

#### 돌진 규칙

| 항목 | 규칙 |
| - | - |
| 방향 | 준비 동작에서 바라보던 방향으로 출발하고, 돌진 중에는 플레이어를 향해 제한된 속도로 방향을 바꿉니다. 몸과 이동 방향은 함께 바뀝니다. |
| 유도 회전 속도 | 최대 초당 90°. 0이면 출발 방향으로 직선 돌진합니다. |
| 속도 | 초당 20m |
| 이동 거리 | 출발 시 보스와 플레이어의 캡슐 중심 사이 수평 거리에 2m를 더합니다. 휘어진 경로를 따라 실제 이동한 수평 거리로 잽니다. |
| 최대 이동 거리 | 20m |
| 막힘 | 벽에 부딪히거나, 플레이어가 가드(가드 브레이크 포함)나 패리로 막으면 그 자리에서 멈춥니다. |
| 캐릭터 간 충돌 | 돌진하는 동안 해제하여 플레이어를 통과합니다. |
| 판정 구간 | 돌진하는 동안 |

#### 돌진과 모션

1. 찌르기 모션에서 몸을 앞으로 내던지는 순간 돌진을 시작합니다.
2. 창을 다 내지른 자세가 되면 돌진이 끝날 때까지 그 자세를 유지합니다.
3. 돌진이 끝나면 창을 거두는 나머지 모션을 이어서 재생합니다.

- 설계 의도: 먼 거리에서 한 번에 다가오는 공격입니다. 패리 예고를 보고 가드나 패리로 막거나, 옆으로 회피해 반격 기회를 노리게 합니다.

### GroundSlam

높이 뛰어올라 플레이어가 있는 곳을 내려찍는 가드 불가 공격입니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 착지하며 내려찍기 (착지한 보스의 캡슐 중심에서 반경 50m 안에 캡슐이 닿는, 땅에 있는 대상) | 2.0 | 넉업 | 불가 |

![GroundSlam 모션](<../../Art/Attachments/보스 모션 도약 내려찍기.gif>)

모션: [ARPG_Halberd_Anim_UE_Attack_Airborne_Start](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Airborne_Start.gif>) → [ARPG_Halberd_Anim_UE_Attack_Airborne_Mid](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Airborne_Mid.gif>) (반복) → [ARPG_Halberd_Anim_UE_Attack_Airborne_End](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Airborne_End.gif>)

- 동작: 도약해 창끝을 아래로 향한 채 내려오고, 착지하며 창끝을 바닥에 꽂습니다. 착지와 동시에 판정 구간을 시작합니다. 착지하는 순간 공중에 있는 대상은 맞지 않으므로 점프로 피할 수 있습니다.
- 방향 보정은 '패턴 공통 규칙'의 '회전'을 따릅니다. 착지 목표는 아래 '착지 목표'를 따릅니다.

| 항목 | 규칙 |
| - | - |
| 체공 시간 | 도약부터 착지까지 1.2초 |
| 궤적 | 포물선을 그리며 도약하고 착지합니다. 최고 높이는 약 2.2m입니다. |
| 착지 목표 | 도약을 시작하는 순간의 플레이어 위치에서 보스 쪽으로 대상과의 최소 간격('패턴 공통 규칙'의 '이동')만큼 떨어진 지점으로 확정합니다. 도약 중 플레이어가 이동해도 착지 목표와 그 목표로 향하는 궤적을 바꾸지 않습니다. |
| 최대 도약 거리 | 도약한 위치에서 수평으로 최대 12m. 착지 목표가 이보다 멀면 최대 도약 거리 지점에 착지합니다. |
| 가드 불가 예고 | 떠오르는 모션에서 창을 들어 올리기 시작할 때부터 떠오르는 모션이 끝날 때까지 |

- 설계 의도: 가드 불가 공격입니다. 도약할 때 가드 불가 예고로 가드 불가임을 알리고, 착지에 맞춰 점프로 뛰어넘거나 회피 무적 타이밍으로 피하게 합니다.

### QuintupleStrike

뛰어들며 베고, 찌르고, 내려찍고, 창을 들어 올리며 올려친 뒤 가드 불가 휩쓸기로 마무리하는 연속 공격입니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 | 앞으로 뛰어들며 머리 위에서 사선 아래로 베기 | 0.7 | 움찔 | 가능 |
| 2 | 이어서 앞으로 찌르기 | 0.7 | 움찔 | 가능 |
| 3 | 머리 위로 들어 올렸다가 정면 바닥까지 내려찍기 | 0.7 | 움찔 | 가능 |
| 4 | 바닥에 내려찍은 창을 앞에서 머리 위로 들어 올리며 올려치기 | 0.7 | 움찔 | 가능 |
| 5 | 앞으로 뛰어들며 약 270° 휩쓸기 (가드 불가 예고) | 2.0 | 넉업 | 불가 |

- 리듬: 1 ~ 4타는 고른 박자로 이어져 연속 패리를 유도하고, 5타는 직전 박자보다 살짝 길어져 회피 타이밍을 재게 합니다.

### SwordWave

멀리 있는 플레이어에게 검기를 날리는 원거리 공격입니다.

| 타 | 동작 | HP 배율 | 피격 반응 | 가드 가능 |
| - | - | - | - | - |
| 1 ~ 3 | 할버드를 휘둘러 검기 발사 | 1.2 | 움찔 | 가능 |

![SwordWave 모션](<../../Art/Attachments/보스 모션 검기 발사.gif>)

모션: [ARPG_Halberd_Anim_UE_Attack_Combo2](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo2.gif>) → [ARPG_Halberd_Anim_UE_Attack_Combo3](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo3.gif>) → [ARPG_Halberd_Anim_UE_Attack_Combo4](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo4.gif>)

- 할버드를 세 번(내려찍기, 사선 베기, 휩쓸기) 휘둘러 휘두를 때마다 검기를 1발씩, 모두 3발 발사합니다.
- 검기는 각 타에서 회전을 멈춘 시점의 보스 정면으로 발사합니다. 회전과 정지 시점은 '패턴 공통 규칙'의 '회전'을 따릅니다.
- 보스 모션의 각 타는 검기를 발사하는 순간을 판정 구간으로 봅니다.

#### 검기

- 검기는 보스의 캡슐 중심 높이에서 수평으로 곧게 날아가며, 폭은 2.0m, 높이는 1.0m입니다.
- 속도는 1500cm/s, 최대 사거리는 20m입니다.
- 발사된 뒤 소멸할 때까지 공격 판정을 유지합니다.
- 플레이어에게 적중하거나 가드되어도 사라지지 않고 플레이어를 뚫고 지나갑니다. 검기 하나는 플레이어를 한 번만 판정합니다.
- 패리되면 [캐릭터 - 린](<캐릭터 - 린.md>)의 '투사체 반사'를 따릅니다.

다음 중 하나가 발생하면 검기가 소멸합니다.

- 벽에 닿음 (보이지 않는 벽 포함)
- 최대 사거리에 도달함

발사된 검기는 보스의 상태 변화(사망, 그로기, 페이즈 전환 등)와 관계없이 계속 날아갑니다.

- 설계 의도: 거리를 벌린 플레이어를 압박하여 다시 근접전으로 끌어들입니다.

- 패턴 전조 동작: 몸을 웅크렸다가 뛰어오르며 할버드를 머리 위로 치켜들어 공격 타이밍을 읽을 수 있게 합니다.

## 연출

### 페이즈 전환

현재 페이즈보다 뒤 페이즈의 HP 구간('페이즈' 참고)에 들어서면 전환 연출을 시작합니다. 시작 조건은 [적 시스템](<../System/적 시스템.md>)의 '전투 시작과 상태 전환'을 따릅니다.

1. 무적 상태가 되고 포효 모션을 재생합니다.
2. 포효 모션이 끝나면 무적을 해제하고 PP를 MaxPP로 회복합니다. 이때부터 새 페이즈의 특징을 적용합니다.
3. '패턴 공통 규칙'의 '패턴 후딜레이' 대기 시간만큼 기다린 뒤 다음 패턴을 선택합니다. 이 대기 중에는 일반적인 피격과 그로기 규칙을 적용합니다.

![페이즈 전환 포효 모션](<../../Art/Attachments/보스 모션 페이즈 전환.gif>)

모션: [ARPG_Samurai_Anim_UE_Buff](<../../Art/GIF/Samurai/ARPG_Samurai_Anim_UE_Buff.gif>)

### 사망

- HP가 0 이하가 되면 [전투 시스템](<../System/전투 시스템.md>)의 사망 처리를 따릅니다.
- 처형으로 사망하면 처형 피격 모션을 끊지 않고 처형 사망 모션으로 이어서 재생합니다. 처형 사망 모션은 일어나지 않고 쓰러진 채로 끝납니다.
- 이미 결과가 정해진 뒤에 사망한 경우는 [게임 플로우](<../System/게임 플로우.md>)의 Boss Stage를 따릅니다.
- 락온 해제는 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 '락온'을, HUD 표시는 [UI 시스템](<../System/UI 시스템.md>)의 '상황별 표시 규칙'을 따릅니다.
