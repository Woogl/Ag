# 일반 적 - 경비 사수

멀리서 단발 사격으로 압박하고, 사격을 피하며 접근한 플레이어가 쉽게 제압할 수 있는 원거리 일반 적입니다. '조준을 확인한다 → 한 발을 피하거나 막는다 → 긴 빈틈에 접근해 처치한다'는 흐름을 만듭니다.

공격 예고·시야·정찰·패턴 선택은 [적 시스템](<../System/적 시스템.md>), 대미지·강인도·피격·그로기·사망은 [전투 시스템](<../System/전투 시스템.md>)을 따릅니다. 외형과 모션은 [일반 적 아트 구성](<../../Art/일반 적 아트 구성.md>)을 따릅니다.

## 개요와 스탯

| 항목 | 값 |
| - | - |
| 이름 | 경비 사수 |
| 분류·무기 | 인간형 원거리 일반 적, 권총 1자루 |
| 크기 | 무기를 제외한 직립 신장 기준 플레이어와 같은 크기 |
| 강인도 | 소형 |
| HP / MaxHP | 300 / 300 |
| MP / MaxMP, UP / MaxUP | 각각 0 / 0. 사용하지 않음 |
| PP / MaxPP | 200 / 200 |
| ATK | 90 |
| DEF | 0 |
| MOV | 200cm/s |
| HP 회복 | 자동 회복 없음 |
| PP 리젠 | 초당 15. 회복 시작 시점은 전투 시스템을 따름 |
| 회전 속도 | 초당 360° |

- 접근 후 기본 공격으로 쉽게 제압할 수 있습니다. 슈퍼아머·자체 무적·가드·회피 행동이 없습니다.
- HP 구간 전체에서 1페이즈만 사용하며, HP에 따른 패턴 변경과 페이즈 전환 연출은 없습니다.
- 단발 사격만 사용합니다. 연사·강공격·가드 불가 공격·근접 공격·회피 공격은 없습니다.
- 탄창 수·잔탄·빈 총 발사·탄약 보급은 관리하지 않습니다. 재장전은 단발 사격 패턴의 후딜 동작입니다.

## 시야와 이동

| 항목 | 값 |
| - | - |
| 시야 거리 | 30m |
| 정면 각도 | 180° — 좌우 90°씩 |
| 적정 거리 | 8~30m. 그 안에서 기다리는 동안 제자리에 섬 |

- 발견·피격에 의한 전투 진입, 지형 가림, 시야 상실과 복귀는 적 시스템을 따릅니다. 보스의 전투 유지 예외는 적용하지 않습니다.
- 접근·정찰·복귀·뒤로 걷기는 MOV 속도를 사용합니다. 사격하지 않는 동안의 움직임은 적 시스템의 '공격하지 않는 동안의 움직임'을 따릅니다. 기다리는 동안 8m 안이면 뒤로 걷고, 8~30m면 서 있고, 30m 밖이면 다가갑니다. 쏠 차례인데 30m 밖이거나 안 보이면 다가갑니다. 적정 거리의 가까운 쪽은 뒤로 걷는 거리, 먼 쪽은 사거리입니다.
- 8m 안에서 뒤로 걷는 것 말고는 도망가지 않습니다. 사격 조건이 맞으면 거리와 관계없이 같은 기본 사격을 사용하며, 근접 전용 공격이나 빠른 발사는 없습니다.
- 발사부터 반동 종료까지, 피격 반응·그로기·처형 중에는 일반 목표 방향 회전을 하지 않습니다. 조준하는 동안(발사 순간까지)과 재장전, 일반 대기에서는 플레이어를 바라봅니다.
- 여러 사수는 대기 시간을 독립적으로 뽑습니다. 여러 적과 함께 싸울 때 쏠 차례는 [적 시스템](<../System/적 시스템.md>)의 '동시 공격 수'를 따릅니다. 배치와 클리어 조건은 해당 레벨 기획서와 [게임 플로우](<../System/게임 플로우.md>)를 따릅니다.

## 기본 사격

| 패턴 | 발동 가능 거리 | 가중치 | 가드 가능 | 쿨다운 |
| - | - | - | - | - |
| 기본 사격 | 캡슐 중심 사이 수평 거리 0~30m | 1 | 가능 | 패턴 시작부터 게임 시간 6초 |

발동 거리뿐 아니라 시야와 총구의 가림 조건도 만족해야 합니다. 시야 거리는 고저차를 포함한 캡슐 중심 사이 거리로 판단하며, 카메라 방향과 관계없습니다.

### 진행과 공격 간격

| 구간 | 길이 | 동작과 판정 |
| - | - | - |
| 조준 | 1.2초 | 제자리에서 권총을 겨누며 플레이어를 바라봄 |
| 발사·반동 | 0.8초 | 구간 시작에 탄환 1발 발사. 추가 타격 없음 |
| 재장전 | 2.0초 | 공격하거나 이동하지 않고 재장전 |
| 패턴 후딜레이 | 2.0~4.0초 중 무작위 | 플레이어를 바라보며 '시야와 이동'의 적정 거리를 지킴. 끝난 뒤 다음 사격 조건 확인 |

- 조준·반동·재장전은 모션 진행 기준이고, 패턴 후딜레이와 쿨다운은 게임 시간 기준입니다. [시간 규칙](<../System/시간 규칙.md>)을 따릅니다.
- 중단이나 시간 연출 없이 사격 조건이 계속 맞으면 발사부터 다음 발사까지 6~8초입니다. 패턴과 후딜레이를 합한 값이며, 쿨다운을 다시 더하지 않습니다.
- 전투 진입에도 먼저 패턴 후딜레이를 거쳐, 조건이 계속 맞는 첫 발은 발견 후 3.2~5.2초에 나옵니다.
- 대기는 시작할 때 한 번 뽑습니다. 쿨다운이나 사격 조건 때문에 더 기다리더라도 지난 발사 기회를 모아 연속으로 쏘지 않고 조준부터 시작합니다.

### 조준

- 조준 시작 시 플레이어가 살아 있고 사격 거리와 시야 안에 있어야 하며, 총구에서 플레이어의 캡슐 중심까지 벽·지형이 가리지 않아야 합니다.
- 조준을 시작하면 플레이어가 시야를 벗어나거나 벽 뒤에 숨어도 취소하지 않고 발사합니다.
- 탄환은 발사 순간 총구에서 예측 지점을 향해 직진합니다. 예측 지점은 적 시스템의 '투사체 조준'을 따릅니다. 예측 지점이 벽 뒤에 있어도 쏘며, 탄환은 벽에 닿아 사라집니다.
- 패리 예고는 공통 길이·색·효과음으로 발사 시점을 알립니다. 탄환 도착 시점과는 다르며, 실제 도착에 맞춰 가드·패리·회피합니다.

## 탄환

| 항목 | 값 |
| - | - |
| 발사 수 | 패턴당 1발 |
| HP 배율 | 1.0 |
| PP 배율 | 0 |
| 피격 반응 | 움찔 |
| 가드·패리 | 모두 가능 |
| 이동 | 초당 30m로 직진. 중력·유도·폭발 없음 |
| 판정 크기 | 반지름 7.5cm, 전체 길이 45cm의 캡슐. 진행 방향으로 눕힘 |
| 최대 이동 거리 | 발사점부터 100m |
| 소멸 | 벽·지형 충돌, 최대 이동 거리 도달, 캐릭터에게 적중하거나 가드된 순간 |

- 발사와 동시에 원거리 대상에게 피해를 주지 않습니다. 정상 속도로 10m를 비행하는 데 약 0.33초가 걸립니다.
- 적중하거나 가드되면 그 자리에서 사라져, 뒤에 있는 다른 대상은 맞지 않습니다. 극한 회피·무적처럼 피격 처리가 없으면 그대로 지나갑니다. 팀·무적·극한 회피는 전투 시스템을 따릅니다.
- 패리하면 [린의 투사체 반사 규칙](<플레이어 캐릭터 - 린.md#투사체-반사>)을 적용합니다. 발사자의 현재 위치로 방향을 바꾼 뒤 직진하고, 반사 시 이동 거리를 다시 셉니다. 반사된 탄환도 처음으로 적중하거나 가드된 대상에서 사라집니다. 반사된 탄환의 대미지도 같은 규칙을 따릅니다.
- 사수의 피격·그로기·처형·사망으로 이미 발사된 탄환을 제거하지 않습니다.

## 피격·그로기·처형·사망

- 강인도 소형을 적용하므로 일반 움찔 공격에도 조준·반동·재장전이 중단됩니다. 발사 전에 중단되면 탄환이 나오지 않습니다.
- 피격 반응 종료 후 행동 전환은 적 시스템을 따릅니다. 움찔만 끝나면 패턴 후딜레이를 새로 걸지 않고(걸려 있던 후딜레이는 남음), 넉업·넉다운이 끝나면 패턴 후딜레이를 겁니다.
- 중단해도 시작한 쿨다운은 유지합니다. 남은 쿨다운과 사격 조건을 만족해야 다음 조준을 시작하며, 재장전을 중단해도 탄약 부족 상태가 되지 않습니다.
- 그로기 지속 시간·피격·PP 회복은 전투 시스템을 따릅니다. 그로기 또는 처형 피격 종료 후 살아 있고 행동할 수 있으면 패턴 후딜레이를 거칩니다. 대기를 중복해서 더하지 않습니다.
- 린의 처형 조건을 만족하면 처형 대상이 되며, 처형 피격·사망 동작은 린의 처형에 맞춰 재생합니다.
- HP가 0 이하가 되면 공통 사망 처리를 적용합니다. 일반 적 처치에는 보스 처치 슬로우모션을 적용하지 않습니다.
- 락온은 [카메라와 타겟팅](<../System/카메라와 타겟팅.md>), 처형 안내는 [UI 시스템](<../System/UI 시스템.md>), 대미지 숫자는 전투 시스템의 공통 규칙을 따릅니다.
