# 샌드백

전투 연습과 밸런싱·디버깅에 쓰는 샌드백 2종의 규칙과 수치를 정의합니다. 샌드백은 사망하지 않아 대미지를 계속 넣을 수 있고, 피격 반응·그로기·처형을 공통 규칙대로 받아 콤보와 처형을 시험할 수 있습니다. 공격 샌드백은 제자리에서 같은 공격을 되풀이해 패리·가드·회피를 연습하게 합니다.

대미지, 공격 판정, PP, 피격 반응, 그로기 등 공통 규칙은 [전투 시스템](<../System/전투 시스템.md>) 문서를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 종류

| 이름 | 행동 | 무기 |
| - | - | - |
| 샌드백 | 놓인 자리에서 놓인 방향을 보고 서 있기만 합니다. | 없음 |
| 공격 샌드백 | 놓인 자리에서 플레이어를 바라보며, 플레이어가 가까이 오면 공격합니다. ('공격 샌드백의 공격') | 할버드 |

## 개요

| 항목 | 내용 |
| - | - |
| 진영 | 중립. 적중 규칙은 [전투 시스템](<../System/전투 시스템.md>)의 '공격 판정 세부 규칙'을, 적이 노리지 않는 규칙은 [적 시스템](<../System/적 시스템.md>)의 '공격 대상과 시야'를 따릅니다. |
| 강인도 | 소형. 공통 규칙은 [전투 시스템](<../System/전투 시스템.md#강인도>)을 따릅니다. |
| 크기 | 플레이어와 같음 |
| 외형 | 보스·일반 적과 한눈에 구분되어야 합니다. 리소스는 [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다. |

## 스탯

두 샌드백의 스탯은 같습니다.

| 스탯 | 값 | 비고 |
| - | - | - |
| HP / MaxHP | 10000 / 10000 | 아래 'HP' 참고 |
| SP / MaxSP | 0 / 0 | 사용하지 않음 |
| MP / MaxMP | 0 / 0 | 사용하지 않음 |
| UP / MaxUP | 0 / 0 | 사용하지 않음 |
| PP / MaxPP | 1000 / 1000 | |
| ATK | 100 | 공격 샌드백의 공격에만 씁니다. |
| DEF | 0 | HP·PP 감소량이 공격자의 ATK × 배율 그대로 나옵니다. |
| MOV | 0 | 걷지 않습니다. |

| 항목 | 값 |
| - | - |
| PP 리젠 | 초당 100 회복. 리젠 대기 시간은 [전투 시스템](<../System/전투 시스템.md>)을 따릅니다. |

## 위치와 회전

- 샌드백은 스스로 이동하지 않습니다. 피격 반응으로 밀려나면 밀려난 자리에 그대로 서 있으며, 놓인 자리로 돌아가지 않습니다.
- 샌드백은 스스로 돌지 않습니다. 넉업·넉다운 등 [전투 시스템](<../System/전투 시스템.md>)의 '피격 반응'에 따라 돌아선 방향을 그대로 유지합니다.
- 공격 샌드백의 목표 방향은 플레이어이며, [전투 시스템](<../System/전투 시스템.md>)의 '목표 방향 회전'에 따라 플레이어를 정면으로 바라봅니다. 회전 속도와 제자리 회전 모션은 [보스 캐릭터 - 커스터](<보스 캐릭터 - 커스터.md>)의 '회전'과 같습니다. 공격, 피격 반응(움찔·넉업·넉다운), 그로기, 처형 피격 중에는 이 회전을 하지 않습니다.

## 공격 샌드백의 공격

| 동작 | HP 배율 | 피격 반응 | 가드 가능 | 예고 |
| - | - | - | - | - |
| 머리 위로 들어 올렸다가 정면 바닥까지 내려찍기 | 1.0 | 움찔 | 가능 | 패리 예고 |

- 공격은 내려찍기 1타 하나이며, 공격할 때마다 같은 내려찍기를 되풀이합니다.
- 공격 예고는 [적 시스템](<../System/적 시스템.md>)의 '공격 예고'와 같습니다.
- 공격 조건: 샌드백과 플레이어의 캡슐 중심 사이 수평 거리가 1.5m 이하이고, 공격 대기 시간이 끝났고, 공격·피격 반응·그로기·처형 피격 중이 아닐 때 공격을 시작합니다. 플레이어가 1.5m보다 멀면 플레이어를 바라보며 서 있습니다.
- 공격 대기 시간: 배치된 순간, 그리고 공격·움찔·넉업·넉다운·그로기·처형 피격이 끝난 순간부터 2초입니다. 이 동안에는 공격하지 않습니다.
- 공격 대상은 플레이어뿐입니다. 공격 판정에 들어온 적에게도 맞습니다. ([전투 시스템](<../System/전투 시스템.md>)의 '공격 판정 세부 규칙')
- 놓인 자리에서 공격하며, 공격 모션에 들어 있는 이동도 하지 않습니다.
- 내려찍기는 준비 동작 동안 플레이어를 향해 돌고, 판정 직전에 방향을 확정해(회전 정지) 이후 플레이어의 이동을 따라가지 않습니다. 타겟팅 범위는 샌드백 캡슐 중심에서 반경 3m 안에 플레이어의 캡슐이 닿는 범위이며, 그 밖의 보정은 [전투 시스템](<../System/전투 시스템.md>)의 '공격 중 위치·회전 보정'을 따릅니다.
- 공격이 닿은 극한 회피 구간은 극한 회피를 발동합니다. 패리·가드·가드 브레이크·극한 회피와 그 보상은 [플레이어 캐릭터 - 린](<플레이어 캐릭터 - 린.md>)을 따릅니다. 패리로 줄어든 샌드백의 PP가 0 이하가 되면 그로기에 빠집니다.
- 플레이어가 사망하면 진행 중인 공격을 즉시 중단하고 그 자리에서 대기 모션을 유지하며, 더 공격하지 않습니다.

모션: 내려찍기 [ARPG_Halberd_Anim_UE_Attack_Combo2](<../../Art/GIF/Halberd/ARPG_Halberd_Anim_UE_Attack_Combo2.gif>)

- 커스터의 DoubleStrike 2타와 같은 모션을 혼자 시작합니다. 판정 구간과 패리 구간은 모션을 따릅니다.

## HP

- 샌드백은 사망하지 않습니다. HP 감소로 HP가 0 이하가 되면 사망 처리 없이 즉시 MaxHP로 회복합니다. 회복은 그 타격의 피격 반응과 그로기 판정을 바꾸지 않습니다.
- 처형 피격 중에 HP가 0 이하가 되어도 위와 같이 회복하며, 처형 사망 모션을 재생하지 않고 처형 피격 모션을 끝까지 재생합니다. 처형 피격이 끝난 뒤의 PP 회복은 [전투 시스템](<../System/전투 시스템.md>)의 '그로기'를 따릅니다.
- 그 밖에 HP는 자동으로 회복하지 않습니다.
- 사망하지 않으므로 스테이지 결과(Stage Clear)와 관계가 없습니다.

## 피격과 그로기

- 피격 반응, 저글, 그로기, 처형은 [전투 시스템](<../System/전투 시스템.md>)의 공통 규칙을 그대로 따릅니다.
- 피격·그로기·처형 피격 모션은 [보스 캐릭터 - 커스터](<보스 캐릭터 - 커스터.md>)의 '피격과 그로기'와 같습니다.
- 플레이어에게는 아래 항목에서 샌드백을 적과 같게 다룹니다.

| 항목 | 내용 |
| - | - |
| 락온 | 락온 대상 후보에 들어갑니다. ([카메라와 타겟팅](<../System/카메라와 타겟팅.md>)의 '락온') |
| 공격 방향 | 공격 방향을 정하는 '적'에 들어갑니다. ([플레이어 캐릭터 - 린](<플레이어 캐릭터 - 린.md>)의 '공격 방향') |
| MP·UP 충전 | 샌드백에게 공격이 적중하면 적과 같이 충전합니다. |
| 처형 | 그로기 상태의 샌드백도 처형할 수 있고, 처형 안내를 표시합니다. ([플레이어 캐릭터 - 린](<플레이어 캐릭터 - 린.md>)의 '처형') |
| 대미지 숫자 | 플레이어의 공격이 샌드백에게 적중하면 보스와 같은 규칙으로 HP 감소량을 표시합니다. ([전투 시스템](<../System/전투 시스템.md>)의 '대미지 숫자') |

- 적의 공격에 맞은 샌드백도 그 공격의 HP·PP 배율에 따라 HP·PP가 줄고 피격 반응을 받지만, 대미지 숫자는 표시하지 않습니다.
