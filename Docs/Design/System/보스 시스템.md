# 보스 시스템

보스에게만 더하거나 바꾸는 규칙을 정의합니다. 보스는 적이므로 이 문서에 적지 않은 규칙은 [적 시스템](<적 시스템.md>)을 따릅니다. 보스별 스탯, 공격 패턴, 연출은 [보스 - 커스터](<../Content/보스 - 커스터.md>)를 따릅니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<전투 시스템.md>) 문서를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 전투 유지

- 보스도 [적 시스템](<적 시스템.md>)의 시야와 피격 규칙으로 전투에 들어갑니다.
- 전투에 들어간 보스는 시야에서 플레이어를 놓쳐도 비전투로 돌아가지 않습니다. 플레이어 사망 시 대기는 적 공통 규칙을 따릅니다.
- 보스 상태 표시는 [UI 시스템](<UI 시스템.md>)의 '보스 상태'를 따릅니다.
