# UI 시스템

전투 HUD와 메뉴 UI의 스타일, 레이어, 화면별 배치와 조작을 정의합니다.

화면이 열리는 조건과 레벨 전환, Play·Start·Resume·Restart·Return to Title·Quit 버튼의 실행 결과는 [게임 플로우](<게임 플로우.md>)를 따릅니다. 표시하는 수치와 상태는 [전투 시스템](<전투 시스템.md>), [플레이어 캐릭터 - 린](<../Content/플레이어 캐릭터 - 린.md>), [보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## UI 스타일

전투 HUD와 메뉴 UI에 함께 적용하는 화면 기준, 글자, 버튼, 메뉴 화면, 게이지 바의 스타일입니다. 각 화면은 글자 크기를 이 절의 단계 이름(예: Large)으로 적습니다.

### 화면 기준

| 항목 | 내용 |
| - | - |
| 기준 해상도 | 1920 × 1080. 다른 해상도에서는 화면의 짧은 변 길이에 맞춰 UI 전체의 크기를 함께 조절하며, 요소 간 크기 비율과 각 화면에서 정한 배치 기준을 유지합니다. |
| 화면 여백 | 화면 가장자리에 붙는 요소는 가장자리에서 48px 안쪽에 배치합니다. |
| 크기 단위 | 바, 슬롯, 여백 등 글자가 아닌 크기는 px로 적습니다. px는 기준 해상도에서의 크기입니다. |
| 입력 키 표시 | 키보드·마우스 기준으로, 지금 키 배치의 키를 키 아이콘으로 표시합니다. 키보드 키는 키 이름을 적은 키캡입니다. 마우스 입력은 마우스 그림으로, 좌클릭·우클릭은 누르는 버튼을, 휠 클릭은 휠을 강조하고, 마우스 이동은 마우스 둘레에 네 방향 화살표를 둡니다. 아이콘 크기는 아이콘을 담는 정사각형 칸의 한 변이며, 키캡과 마우스 그림은 칸 안에 여백을 두고 그립니다. 모양은 [아트 표현 사양](<../../Art/아트 표현 사양.md>)의 '입력 키 아이콘'을, 지원하는 조작 장치는 [게임 개요](<../게임 개요.md>)를 따릅니다. |

### 글자

| 항목 | 내용 |
| - | - |
| 언리얼 Size | 언리얼 엔진 폰트의 Size 값으로, 언리얼에 입력하는 값입니다. 기획서의 글자 크기는 이 값을 기준으로 합니다. 언리얼은 폰트 크기를 96 DPI 기준으로 처리하므로 px × 0.75입니다. |
| 최소 크기 | Small보다 작은 글자는 쓰지 않습니다. Xbox 접근성 가이드라인의 PC 최소 기준(1080p에서 글자 높이 18px)보다 조금 크게 잡았습니다. |
| 글꼴 | [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다. |

#### 크기 단계

| 단계 | 언리얼 Size | px |
| - | - | - |
| Small | 14 | 18.7 |
| Medium | 18 | 24 |
| Large | 24 | 32 |

- px는 시안(SVG)과 비교하기 위한 참고 값입니다.
- 새 글자를 추가할 때는 가까운 단계를 먼저 씁니다. 여러 곳에서 반복해서 쓰는데 맞는 단계가 없을 때만 단계를 추가하고, 한 곳에서만 쓰는 글자는 전용 글자로 둡니다.

#### 전용 글자

한 곳에서만 쓰고 크기, 색상, 굵기가 따로 정해진 글자는 크기 단계에 넣지 않습니다. 크기는 정의 문서에 언리얼 Size로 적습니다. (예: Size 168)

| 글자 | 정의 문서 |
| - | - |
| 게임 제목 | '메뉴 UI'의 타이틀 화면 |
| 전투 결과 UI 제목 | '메뉴 UI'의 Stage Clear UI / Game Over UI |
| 적 카드의 빈 자리 '+' | '메뉴 UI'의 적 선택 화면 |
| 대미지 숫자 | [전투 시스템](<전투 시스템.md>)의 대미지 숫자 |
| 쿨다운 숫자 | '전투 HUD'의 스킬·궁극기 슬롯 |

### 버튼

메뉴 UI의 모든 버튼에 적용합니다.

- 글자는 굵은 글자로 표시합니다. 선택된 버튼은 선택되지 않은 버튼보다 밝은 배경, 굵은 테두리, 밝은 글자로 구분합니다.
- 마우스를 버튼 위로 올릴 때와 버튼을 실행할 때 효과음을 재생합니다. 쓰는 사운드는 [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다.
- 버튼에 실행 키를 안내할 때는 글자 왼쪽에 그 키의 키 아이콘을 36px로 글자와 8px 띄워 두고, 키 아이콘과 글자를 함께 버튼 가운데에 놓습니다. 그 키를 누르면 버튼을 실행합니다. 키 아이콘은 UI 스타일의 '입력 키 표시'를 따릅니다. 키를 안내하는 버튼과 그 키는 각 화면에 적으며, 적지 않은 버튼은 키 아이콘을 표시하지 않습니다.

### 메뉴 화면

스테이지 선택 화면, Settings 화면, 적 선택 화면, 일시정지 메뉴에 함께 적용하는 화면 양식입니다. 타이틀 화면과 전투 결과 UI는 각 화면의 규칙을 따릅니다.

- 화면 전체를 불투명한 검은 배경으로 덮어, 뒤의 레벨과 게임 화면은 보이지 않습니다.
- 화면 위쪽 가운데에 제목을 표시합니다. 제목의 위쪽은 화면 여백에 맞춥니다. 제목은 Large 흰색 굵은 글자이고, 제목 아래 8px에 제목 너비만큼 두께 4px의 흰 밑줄을 긋습니다. 일시정지 메뉴는 이 자리에 탭 바를 두며, 고른 탭의 이름이 제목과 같은 모양입니다.
- 화면의 내용은 화면 가운데에 놓고, 위쪽을 제목 아래 72px에 맞춥니다.

### 게이지 바

HP, MP, PP처럼 현재값의 비율을 보여 주는 모든 바에 적용합니다. 바마다 다른 것은 크기와 채움 색뿐입니다. 채움 색은 자원마다 정하며, 플레이어와 적의 바를 구분하지 않습니다. 크기와 감소 잔상·수치 표시 여부는 각 바를 정의한 화면을 따릅니다.

![게이지 바 스타일](<../../Art/Attachments/게이지 바 스타일.svg>)

- 모서리가 각진 사각형이고 테두리는 없습니다.
- 바 전체에 반투명한 검은 배경을 깔고, 현재 비율만큼 왼쪽부터 채움 색으로 채웁니다. 줄어들 때는 오른쪽 끝부터 줄입니다.
- 감소 잔상은 채움 바로 오른쪽에 반투명한 흰색으로 표시합니다.
- 수치를 표시하는 바는 바 오른쪽에 12px 띄우고 Medium 글자로 '현재값 / 최대값'을 표시합니다. 세로 맞춤은 각 바를 정의한 화면을 따릅니다.

| 자원 | 채움 색 |
| - | - |
| HP | 빨간색 |
| MP | 파란색 |
| PP | 흰색 |


## UI 레이어

여러 화면이 함께 떠 있을 때 어느 화면을 위에 표시하고, 어느 화면이 입력을 받는지 정의합니다.

### 레이어 구성

모든 화면은 아래 두 레이어 가운데 하나에 표시합니다. 표는 아래 레이어부터 적었으며, 위 레이어의 화면이 아래 레이어의 화면을 덮습니다.

| 레이어 | 화면 | 성격 |
| - | - | - |
| HUD | 전투 HUD | 플레이하는 동안 계속 보는 정보 |
| Menu | 타이틀 화면, 스테이지 선택 화면, Settings 화면, 적 선택 화면, 일시정지 메뉴, Stage Clear UI, Game Over UI | 버튼으로 다음 진행을 고르는 화면 |

- 전투 HUD의 락온 마커, 상호작용 안내, 적 네임플레이트와 [전투 시스템](<전투 시스템.md>)의 대미지 숫자는 대상과 맞은 위치를 따라 움직이므로 레이어에 넣지 않고, 모든 레이어보다 아래에 표시합니다.

![UI 레이어 구성](<../../Art/Attachments/UI 레이어 구성.svg>)

### 표시

- 한 레이어에 화면을 여러 개 열면 마지막에 연 화면만 표시하고, 먼저 연 화면은 숨깁니다. 마지막에 연 화면을 닫으면 그 전에 연 화면을 다시 표시합니다.
- 위 레이어에 화면이 열려도 아래 레이어의 화면은 숨기지 않고 그대로 표시합니다. 아래 화면을 어둡게 하거나 숨기는 것은 각 화면의 규칙(UI 스타일의 '메뉴 화면', 전투 결과 UI, 전투 HUD의 '상황별 표시 규칙')을 따릅니다.
- 레벨이 바뀌면 모든 레이어의 화면을 닫습니다.

### 입력

- 입력은 표시 중인 화면 가운데 가장 위 레이어에서 마지막에 연 화면 하나만 받습니다. 마우스 커서 표시와 게임 입력을 받을지는 이 화면의 규칙('메뉴 UI', 전투 HUD는 [게임 플로우](<게임 플로우.md>)의 '스테이지 공통')을 따릅니다.
- 입력을 받지 않는 화면의 버튼은 선택하거나 실행할 수 없고, 마우스 클릭도 그 화면에 전달되지 않습니다.
- 입력을 받던 화면이 닫히면 남은 화면 가운데 위 규칙에 맞는 화면이 입력을 받고, 그 화면에서 마지막으로 선택되어 있던 버튼을 다시 선택합니다. 화면을 닫은 입력은 다음 화면에 전달되지 않습니다.


## 전투 HUD

전투 중 화면에 표시하는 정보(HUD)를 정의합니다.

### 화면 구성

![전투 HUD 화면 구성](<../../Art/Attachments/전투 HUD 화면 구성.svg>)

- 기준 해상도에서의 배치입니다.
- 상호작용 안내와 적 네임플레이트는 조건부 요소지만, 위치를 보여 주기 위해 함께 그렸습니다.

| 번호 | 요소 | 위치 |
| - | - | - |
| 1 | 플레이어 상태 | 화면 왼쪽 아래 |
| 2 | 스킬·궁극기 슬롯 | 화면 오른쪽 아래 |
| 3 | 보스 상태 | 화면 위쪽 가운데 |
| 4 | 락온 마커 | 락온 대상 몸의 락온 지점 |
| 5 | 상호작용 안내 | 상호작용 대상의 안내 지점 오른쪽 (적은 락온 지점) |
| 6 | 적 네임플레이트 | 일반 적·샌드백 머리 위 |

- 적중한 위치에 뜨는 대미지 숫자는 [전투 시스템](<전투 시스템.md>)의 '대미지 숫자'를 따릅니다.

### HUD 요소

#### 1. 플레이어 상태

| 요소 | 크기 | 표시 규칙 |
| - | - | - |
| HP 바 | 400 × 15px | 항상 표시합니다. HP가 줄면 감소 잔상을 표시합니다. |
| HP 수치 | 글자 Medium | 글자의 아래 끝을 HP 바의 아래 끝에 맞춥니다. |
| MP 바 | 400 × 10px | HP 바 바로 아래에 항상 표시합니다. |
| MP 수치 | 글자 Medium | 글자의 위 끝을 MP 바의 위 끝에 맞춰, HP 수치와 위아래로 나뉘어 겹치지 않게 합니다. |
| 회복병 칸 | 지름 80px | 항상 표시합니다. HP 바 12px 위에 왼쪽을 맞춰 놓습니다. 모양과 아이콘 크기는 스킬 슬롯과 같습니다. 회복병이 0개이면 MP가 부족한 슬롯처럼 흐리게 표시합니다. |
| 회복병 키 | 36px | 칸 중심에서 아래로 36px인 곳에 회복병 키의 키 아이콘을 표시합니다. 키 아이콘은 UI 스타일의 '입력 키 표시'를 따릅니다. |
| 회복병 보유 수 | 글자 Medium | 칸 오른쪽에 8px 띄우고 칸과 세로 가운데를 맞춰 '보유 수/최대 보유 수'로 표시합니다. (예: 2/3) |

- 플레이어 PP는 표시하지 않습니다.
- 감소 잔상: HP가 줄면 줄어든 부분을 감소 잔상으로 남겨 두었다가, 0.5초 뒤 0.3초 동안 현재 HP까지 줄입니다. 잔상이 줄어드는 동안 HP가 다시 줄면 그 자리에서 다시 0.5초를 기다립니다.
- 감소 잔상의 시간 기준은 [시간 규칙](<시간 규칙.md>)의 '시간 연출의 영향'을 따릅니다.

#### 2. 스킬·궁극기 슬롯

| 슬롯 | 위치 | 슬롯 안 정보 |
| - | - | - |
| 스킬 1 ~ 4 | 화면 오른쪽 아래에 십자로 놓습니다. 스킬 1 왼쪽, 스킬 2 위, 스킬 3 오른쪽, 스킬 4 아래입니다. | 그 스킬의 아이콘, MP 코스트, 쿨다운 표시(쿨다운이 흐르는 동안), 남은 충전 횟수(최대 충전 2회 이상) |
| 궁극기 | 스킬 십자의 오른쪽 위 | 궁극기 아이콘. 슬롯 테두리에 UP 게이지를 표시합니다. |

- 슬롯은 모두 지름 80px의 원형이며, 반투명한 어두운 바탕에 얇고 옅은 흰 테두리를 둡니다. 아이콘은 슬롯 가운데에 54 × 54px로 표시합니다.
- 십자 가운데에서 각 스킬 슬롯의 중심까지는 75px입니다. 십자 가운데에는 아무것도 표시하지 않습니다.
- 궁극기 슬롯은 십자 가운데에서 오른쪽으로 96px, 위로 96px인 곳에 중심을 둡니다.
- 궁극기 슬롯의 오른쪽 끝과 아래 슬롯(스킬 4)의 아래쪽 끝을 화면 여백(48px)에 맞춥니다.
- 아이콘의 에셋과 표현은 [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다.
- 키 표시: 각 스킬 슬롯의 십자 가운데 쪽 테두리에 걸치도록 십자 가운데에서 30px 떨어진 곳에 그 슬롯의 키 아이콘을 36px로 표시합니다. 키 아이콘은 UI 스타일의 '입력 키 표시'를 따릅니다.
- 궁극기 키 표시: 궁극기 슬롯 중심에서 아래로 36px인 곳에 궁극기 키의 키 아이콘을 36px로 표시합니다.
- MP 코스트는 슬롯 중심에서 오른쪽으로 29px, 아래로 29px인 곳에 글자 Small로 표시합니다. 슬롯 테두리에 걸치므로 글자에 어두운 외곽선을 둘러 배경 위에서도 읽히게 합니다. 궁극기 슬롯에는 코스트를 표시하지 않습니다.
- 남은 충전 횟수: 최대 충전 횟수가 2회 이상인 스킬(스킬 3)은 남은 충전 횟수(0 ~ 최대)를 늘 표시합니다. 슬롯 중심에서 오른쪽으로 29px, 위로 29px인 곳에 MP 코스트와 같은 글자(Small, 어두운 외곽선)로 표시합니다. 충전과 쿨다운의 규칙은 [전투 시스템](<전투 시스템.md>)의 '쿨다운'을 따릅니다.
- UP 게이지는 궁극기 슬롯의 원형 테두리가 UP 비율만큼 위쪽 가운데부터 시계 방향으로 채워지는 표시입니다.
- 쿨다운 표시: 스킬의 쿨다운이 흐르는 동안 그 스킬의 슬롯에 아래 표시를 겹칩니다. 스킬마다 따로 표시합니다.
  - 원형 표시: 쿨다운이 흐르는 동안(충전이 있는 스킬은 충전이 최대보다 적은 동안) 슬롯 안쪽을 남은 쿨다운 비율만큼 밝은 반투명으로 덮습니다. 덮개의 경계는 위쪽 가운데에서 시작해 시계 방향으로 돌고, 지나간 부분부터 덮개가 걷힙니다.
  - 숫자: 쿨다운 중(충전이 있는 스킬은 충전이 0회인 동안)에만 남은 쿨다운을 슬롯 가운데에 표시합니다. 1초 이상은 초 단위 정수, 1초 미만은 소수 한 자리로 표시하며, 둘 다 올림합니다. 쿨다운 숫자는 전용 글자이며 Size 24입니다.
- MP 또는 UP가 부족한 슬롯은 흐리게(반투명하게) 표시합니다. 쿨다운 중이라는 이유로는 흐리게 하지 않습니다. UP 게이지와 쿨다운 표시는 슬롯이 흐릴 때도 그대로 표시합니다.

#### 3. 보스 상태

- 보스가 전투에 들어간 뒤부터 사망하기 전까지 이름·HP 바·PP 바를 표시하고, 그 밖에는 숨깁니다. 다른 적이 남아 전투가 이어지는 시뮬레이션 룸에서도 보스가 사망하면 숨깁니다. 컷신과 스테이지 결과 연출 중 표시는 아래 '상황별 표시 규칙'을 따릅니다.

| 요소 | 크기 | 표시 규칙 |
| - | - | - |
| 보스 이름 | 글자 Large | HP 바 위 가운데에 보스 이름을 표시합니다. 이름은 [보스 캐릭터 - 커스터](<../Content/보스 캐릭터 - 커스터.md>)를 따릅니다. |
| HP 바 | 1000 × 15px | 수치와 페이즈 경계는 표시하지 않습니다. 플레이어가 페이즈가 바뀌는 시점을 미리 알 수 없게 합니다. 감소 잔상은 플레이어 HP 바와 같습니다. |
| PP 바 | 1000 × 10px | HP 바 바로 아래에 항상 표시합니다. 감소 잔상은 플레이어 HP 바와 같습니다. |

- 그로기가 시작되면 PP 바를 가득 채운 뒤 그로기 지속 시간 동안 줄여 남은 시간을 보여 줍니다. 줄어드는 동안에는 감소 잔상을 표시하지 않습니다. 공중에서도 같은 방식으로 표시합니다. 그로기 중의 PP 바는 노란색으로 맥동하고, 그로기가 시작되는 순간 하얗게 번쩍이며 파편이 튀어 그로기 중임을 알립니다. 이 연출의 시간은 그로기 지속 시간과 같은 시간 기준을 따르며, 모양은 [아트 표현 사양](<../../Art/아트 표현 사양.md>)의 '그로기 PP 바'를 따릅니다. 처형으로 전환되면 PP 바와 감소 잔상을 처형 직전의 표시 위치에 원래 색으로 멈춰 둡니다. 처형 피격이 끝나거나 중단되면 실제 PP 표시로 돌아가며, 살아 있으면 최대로 채워집니다. 처형 없이 그로기가 종료되어도 실제 PP 표시로 돌아갑니다. 종료와 PP 회복 시점, 사망 시 회복하지 않는 규칙은 [전투 시스템](<전투 시스템.md>)의 '그로기'를 따릅니다.

#### 4. 락온 마커

- 락온 중일 때 락온 대상의 락온 지점([카메라와 타겟팅](<카메라와 타겟팅.md>) 참고)에 지름 20px의 원형 마커를 표시합니다.

#### 5. 상호작용 안내

[플레이어 시스템](<플레이어 시스템.md>)의 '상호작용'에서 고른 상호작용 대상이 있는 동안, 그 대상 위에 안내를 하나 표시합니다.

| 항목 | 규칙 |
| - | - |
| 구성 | 왼쪽부터 키 아이콘, 행동 이름 순서입니다. (예: F 키 아이콘, 행동 이름 '처형') |
| 키 아이콘 | 상호작용 키의 키 아이콘을 48px로 표시합니다. 키 아이콘은 UI 스타일의 '입력 키 표시'를 따릅니다. |
| 행동 이름 | 키 아이콘 오른쪽에 8px 띄우고 세로 가운데를 맞춰 글자 Large로 적습니다. 밝은 배경 위에서도 읽히도록 글자에 어두운 외곽선을 두릅니다. |
| 위치 | 대상의 안내 지점 오른쪽에 둡니다. 키 아이콘의 왼쪽 끝을 안내 지점에서 오른쪽으로 22px 띄우고, 세로 가운데를 안내 지점에 맞춥니다. 대상이 움직이면 따라가고, 카메라 거리와 관계없이 화면상 크기를 유지합니다. |
| 안내 지점 | 적은 락온 지점입니다. 장치는 장치마다 정한 지점입니다. |

- 안내는 상호작용 대상 하나에만 표시합니다. 대상이 바뀌면 즉시 새 대상으로 옮기고, 대상이 없어지면 즉시 숨깁니다.
- 기본 공격이나 회피 중이라 잠시 상호작용을 입력할 수 없을 때도 숨기지 않습니다.
- 안내 지점이 화면 밖에 있으면 안내는 보이지 않습니다. 화면 가장자리에 붙이지 않으며, 이때도 상호작용 키는 동작합니다.

#### 6. 적 네임플레이트

일반 적과 샌드백의 머리 위에 HP·PP를 표시합니다. 보스는 '보스 상태'로 표시하며 머리 위에는 표시하지 않습니다.

| 요소 | 크기 | 표시 규칙 |
| - | - | - |
| HP 바 | 118 × 9px | 수치와 이름은 표시하지 않습니다. 감소 잔상은 플레이어 HP 바와 같습니다. |
| PP 바 | 118 × 6px | HP 바 바로 아래에 왼쪽을 맞춰 붙입니다. 감소 잔상은 플레이어 HP 바와 같습니다. 최대 PP가 0인 대상은 PP 바 없이 HP 바만 표시합니다. |

- 위치: 현재 자세의 머리 위에 가로 가운데로 두며, 머리와의 화면상 여백은 16px입니다. 점프·넉업·넉다운 중에도 머리를 따라가고, 카메라 거리와 관계없이 화면상 크기를 유지합니다.
- HP·PP가 회복되면 바로 반영하고, 회복된 값보다 낮은 감소 잔상은 없앱니다. 그로기·처형 피격 중의 PP 바는 '보스 상태'의 PP 바와 같습니다.
- 대상이 살아 있고, 머리 위가 화면 안에 있으며, 카메라에서 대상의 몸 중심까지 벽·지형에 막히지 않을 때만 표시합니다. 다른 캐릭터가 앞을 지나가는 것으로는 숨기지 않습니다.
- 위 조건에서 **플레이어와 전투 중**, **락온 대상**, **최근 3초 안에 HP 또는 PP가 줄어듦** 가운데 하나를 만족하면 표시합니다. 3초는 마지막으로 줄어든 순간부터 다시 세며, 회복으로는 다시 세지 않습니다. 그로기·처형 피격 중이라는 이유만으로 표시를 유지하지는 않습니다.
- 거리 제한 없이 조건을 만족하는 모든 대상에 각각 표시합니다. 표시가 겹치면 락온 대상이 가장 앞에, 나머지는 카메라와 가까운 대상이 앞에 보입니다.
- 조건을 잃으면 페이드 없이 즉시 숨기며, 화면 밖 대상을 화면 가장자리에 붙이거나 화살표로 대신 표시하지 않습니다. 다시 표시할 때는 숨겨진 동안의 감소 잔상을 재생하지 않고 현재 HP·PP로 시작합니다.
- 최근 감소 시간과 감소 잔상의 시간 기준은 [시간 규칙](<시간 규칙.md>)의 '시간 연출의 영향'을 따릅니다.

| - | - | - | - |
| 전투 (페이즈 전환 연출, 처형 포함) | 표시 | 표시 | 조건에 따라 표시 |

| 전투 결과 UI | 숨김 | 숨김 | 숨김 |

- 일시정지 메뉴가 열려 있는 동안에는 메뉴의 배경이 위 표시를 모두 가립니다. 감소 잔상과 쿨다운 표시는 멈췄다가 메뉴를 닫으면 이어집니다.


## 메뉴 UI

메뉴 UI(타이틀 화면, 스테이지 선택 화면, Settings 화면, 적 선택 화면, 일시정지 메뉴, 전투 결과 UI)의 배치와 표시, 포커스와 조작 규칙을 정의합니다.

### 타이틀 화면

LV_FrontEnd에 표시하는 화면입니다.

- 화면 위쪽 가운데에 게임 제목 'AG'를 크게 표시합니다. (전용 글자 Size 168)
- 제목 아래 가운데에 Play, Settings, Quit 버튼을 위에서부터 세로로 배치합니다. (글자 Large)
- 배경은 뒤의 LV_FrontEnd 레벨이 보입니다.
- 레벨이 열리면 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Play입니다.

![타이틀 화면](<../../Art/Attachments/FrontEnd 화면 구성.svg>)

### 스테이지 선택 화면

LV_FrontEnd에서 타이틀 화면의 Play 버튼으로 여는 화면입니다. 목록의 스테이지와 버튼의 실행 결과는 [게임 플로우](<게임 플로우.md>)의 '스테이지 선택'을 따릅니다.

- UI 스타일의 '메뉴 화면'을 따르며, 제목은 'Stage Select'입니다.
- 제목 아래 가운데에 스테이지 드롭다운을 놓고, 그 아래 가운데에 Start, Back 버튼을 가로로 놓습니다. 버튼과 드롭다운의 글자는 Large입니다.
- 페이드 없이 바로 표시하고, 표시하는 즉시 입력을 받습니다.
- 마우스 커서를 표시합니다.
- 처음 선택된 것은 스테이지 드롭다운입니다.
- 스테이지 드롭다운은 닫혀 있을 때 고른 스테이지의 이름을 표시합니다. 화면을 열 때마다 목록의 첫 스테이지가 골라져 있습니다.
- 드롭다운을 실행하면 목록을 열고 스테이지를 순서대로 한 줄에 하나씩 표시합니다. 목록의 항목을 실행하면 그 스테이지를 고르고 목록을 닫습니다.

![스테이지 선택 화면](<../../Art/Attachments/스테이지 선택 화면.svg>)

### Settings 화면

LV_FrontEnd에서 타이틀 화면의 Settings 버튼으로 여는 화면입니다. 스테이지 선택 화면과 같이 타이틀 화면 대신 표시하며, 일시정지 메뉴의 Settings 탭과 같은 Settings 내용을 보여 줍니다.

- UI 스타일의 '메뉴 화면'을 따르며, 제목은 'Settings'이고 내용은 아래 'Settings 내용'입니다.
- 내용 칸 아래 32px 가운데에 Back 버튼을 Large로 표시합니다.
- 페이드 없이 바로 표시하고, 표시하는 즉시 입력을 받습니다. 마우스 커서를 표시합니다.
- 화면을 열 때마다 Controls 분류가 선택됩니다.
- Back 버튼을 실행하거나 Esc를 누르면 화면을 닫고 타이틀 화면으로 돌아갑니다. 타이틀 화면에서는 Settings 버튼이 선택됩니다.

![Settings 화면 - Display](<../../Art/Attachments/Settings 화면 - Display.svg>)

#### Settings 내용

Settings 화면과 일시정지 메뉴의 Settings 탭이 같은 내용을 씁니다. 분류 목록은 화면 왼쪽에 놓고 왼쪽 끝을 화면 여백에 맞춥니다. 고른 분류의 내용 칸은 화면 가운데에 놓습니다. 둘의 위쪽은 UI 스타일 '메뉴 화면'의 내용 위치에 맞춥니다.

**분류 목록**

- 분류 이름을 위에서부터 Controls, Display, Language 순서로 세로로 놓습니다. 글자는 Large이고, 분류 이름 사이는 24px입니다.
- 고른 분류의 이름은 흰색 굵은 글자이고, 이름 왼쪽 16px에 이름 높이만큼 두께 4px의 흰 세로 막대를 긋습니다. 고르지 않은 분류의 이름은 흐린 회색 글자이고 막대가 없으며, 마우스를 올리면 글자가 밝아집니다.
- 분류 이름을 좌클릭하거나, 분류 목록에서 ↑·↓로 선택을 옮기면 그 분류를 고릅니다. 마우스를 올리기만 해서는 고르지 않습니다.
- W를 누르면 위 분류로, S를 누르면 아래 분류로 바꿉니다. 첫 분류에서 W, 마지막 분류에서 S를 누르면 분류가 그대로입니다. 선택이 분류 목록과 내용 어디에 있어도 바꾸며, 바꾼 뒤에는 고른 분류의 이름이 선택됩니다.
- 분류를 고르면 내용이 페이드 없이 바로 바뀝니다.
- 분류 이름에 마우스를 올릴 때와 좌클릭이나 W·S로 분류를 고를 때 UI 스타일 '버튼'의 효과음을 재생합니다.
- 분류 목록에서 →를 누르면 고른 분류 내용의 첫 드롭다운으로 선택을 옮기고, 내용에서 ←를 누르면 고른 분류의 이름으로 돌아옵니다. Controls에는 고를 것이 없어 →로 옮기지 않습니다.

**내용 칸**

- 분류를 바꿔도 내용 칸의 크기는 바뀌지 않습니다. 크기는 세 분류 가운데 가장 큰 내용에 맞추고, 내용은 칸의 왼쪽 위에 붙입니다.
- Display와 Language의 줄은 왼쪽에 항목 이름, 오른쪽에 드롭다운을 둡니다. 글자는 둘 다 Large이고, 이름은 드롭다운과 세로 가운데를 맞춥니다. 드롭다운은 그 분류의 모든 줄에서 같은 위치, 가장 긴 항목 이름의 오른쪽 48px에서 시작합니다. 줄 사이는 16px입니다.
- 드롭다운의 모양과 목록을 여닫는 조작은 스테이지 선택 화면의 스테이지 드롭다운과 같습니다.

**Controls**

- [플레이어 시스템](<플레이어 시스템.md>)의 '키 배치' 표에 있는 모든 조작을 표의 순서대로 한 줄에 하나씩 표시합니다. 읽기 전용입니다.
- 각 줄은 왼쪽에 키 아이콘, 오른쪽에 조작 이름을 표시합니다. 조작 이름은 모든 줄에서 같은 위치에서 시작합니다.
- 키 아이콘은 36px이며 UI 스타일의 '입력 키 표시'를 따릅니다. 한 줄에 키가 여럿이면 키 배치 표의 순서대로 4px 간격으로 나란히 놓습니다. 키 칸의 '(누르고 있기)'와 '설명' 열은 표시하지 않습니다.
- 조작 이름은 '조작' 열을 그대로 씁니다. (예: 가드 / 패리)
- 조작 이름은 글자 Medium이며, 그 줄의 키 아이콘과 세로 가운데를 맞춥니다.
- 줄 사이는 6px입니다.
- 반투명한 어두운 배경 위에 표시합니다. 배경 안쪽 여백은 24px, 키 아이콘 열과 조작 이름 사이는 48px입니다.

**Display**

| 줄 | 항목 이름 | 목록 |
| - | - | - |
| 1 | Window Mode | Fullscreen, Windowed |
| 2 | Resolution | 지금 창 모드에서 고를 수 있는 해상도를 큰 것부터 '가로 × 세로'로 적습니다. (예: 1920 × 1080) |

- Fullscreen은 모니터를 고른 해상도로 바꿔 화면 전체를 씁니다. Windowed는 고른 해상도 크기의 창이며, 창 테두리를 끌거나 최대화해서 크기를 바꿀 수 없습니다.
- 고를 수 있는 해상도는 아래 표의 해상도 가운데, Fullscreen은 모니터가 지원하는 것, Windowed는 모니터보다 가로와 세로가 모두 작은 것입니다.
  - Fullscreen 목록에는 표에 없더라도 모니터 해상도를 늘 넣습니다.
  - Windowed에서 고를 수 있는 해상도가 하나도 없으면 모니터 해상도 하나입니다.

| 화면 비율 | 해상도 |
| - | - |
| 16:9 | 1280 × 720, 1366 × 768, 1600 × 900, 1920 × 1080, 2560 × 1440, 3840 × 2160 |
| 16:10 | 1280 × 800, 1440 × 900, 1680 × 1050, 1920 × 1200, 2560 × 1600 |
| 21:9 | 2560 × 1080, 3440 × 1440 |

- 창 모드를 바꿀 때 지금 해상도가 새 창 모드의 목록에 없으면 그 목록의 가장 큰 해상도로 바꿉니다.
- 목록의 항목을 실행하면 바로 적용하고 저장합니다. 저장한 창 모드와 해상도는 다음 실행에도 그대로입니다.
- 창 모드나 해상도를 고른 적이 없으면 Fullscreen, 모니터 해상도로 시작합니다.
- 드롭다운은 닫혀 있을 때 지금 창 모드와 지금 해상도를 표시합니다.

**Language**

지원 언어와 시작 언어는 [게임 개요](<../게임 개요.md>)의 '지원 언어'를 따릅니다.

- 'Language' 줄 하나입니다.
- 목록은 위에서부터 '한국어', 'English'입니다. 언어 이름은 지금 언어와 관계없이 그 언어로 적습니다.
- 닫혀 있을 때는 지금 언어의 이름을 표시합니다.
- 목록의 항목을 실행하면 그 언어로 바꾸고 저장한 뒤 목록을 닫습니다. 바꾼 언어는 바로 적용되어, 그 뒤에 보이는 문구는 모두 그 언어로 표시합니다. 일시정지 메뉴에서 바꿔도 같습니다.

### 적 선택 화면

LV_SimulationRoom에서 배치 자리마다 싸울 적을 고르는 화면입니다. 여는 때와 버튼의 실행 결과는 [게임 플로우](<게임 플로우.md>)의 'Simulation Room'을 따릅니다.

- UI 스타일의 '메뉴 화면'을 따르며, 제목은 'Enemy Select'입니다.
- 제목 아래 가운데에 배치 자리 1 ~ 5의 적 카드를 왼쪽부터 자리 번호 순서로 가로로 나란히 놓습니다. 카드는 300 × 450px, 카드 사이 간격은 24px입니다. 이 순서는 플레이어 시작 지점에서 본 배치 자리의 왼쪽부터 오른쪽 순서와 같습니다. ([스테이지 - 시뮬레이션 룸](<../Level/스테이지 - 시뮬레이션 룸.md>)의 '배치 자리')
- 카드 아래 가운데에 Start, Return to Title 버튼을 가로로 놓습니다. 버튼과 목록 항목의 글자는 Large입니다.
- 화면이 떠 있는 동안 게임은 멈춥니다. 일시정지 메뉴와 같이 페이드 없이 바로 표시합니다.
- 마우스 커서를 표시하고, 플레이어 입력은 UI만 받습니다.
- 처음 선택된 것은 배치 자리 1의 카드입니다.
- 모든 자리가 Empty이면 Start 버튼을 흐리게 표시합니다.

![적 선택 화면](<../../Art/Attachments/적 선택 화면.svg>)

**적 카드**

적 카드는 그 자리의 적 드롭다운이 닫혀 있을 때의 모양입니다.

- 카드의 바탕은 검은색입니다. 카드 아래쪽 60px은 이름 칸이고, 그 위가 모델 칸입니다.
- 고른 적이 있으면 모델 칸에 그 적의 모델을, 이름 칸 가운데에 그 적의 이름을 Large로 표시합니다.
- 고른 적이 없으면 모델 칸 가운데에 '+'를 전용 글자 Size 96으로, 이름 칸 가운데에 'Empty'를 Large로 표시합니다. 화면을 열 때는 모든 카드가 이 모양입니다.
- 자리의 적을 바꾸면 그 카드의 모델과 이름이 바로 바뀝니다.
- 실행하면 목록을 열고 'Empty'와 게임에 있는 보스, 일반 적, 샌드백을 이 순서로 한 줄에 하나씩 표시합니다. 이름은 각 캐릭터 문서를 따릅니다. (예: 커스터)
- 목록의 항목을 실행하면 그 자리에 그 적을 고르고 목록을 닫습니다. Empty를 실행하면 그 자리를 비웁니다. 같은 적을 여러 자리에 고를 수 있습니다.
- 보스는 한 자리에만 고릅니다. 다른 자리에 보스가 있으면 이 자리의 목록에는 보스를 표시하지 않습니다. (전투 HUD의 보스 상태가 하나뿐입니다.)

**모델**

- 모델은 게임에서와 같은 모습으로, 들고 있는 무기도 함께 보입니다.
- 모델은 카메라를 정면으로 바라보고 서 있으며, 머리부터 발끝까지 전신이 모델 칸 안에 들어옵니다. 적마다 키가 달라도 전신이 모델 칸의 높이를 거의 채우도록 크기를 맞춥니다.
- 모델은 그 적이 서 있을 때의 대기 모션을 반복합니다. 화면이 떠 있어 게임이 멈춰 있는 동안에도 움직입니다.
- 모델은 레벨의 조명과 관계없이 늘 같은 밝기로, 앞쪽에서 비추는 빛을 받아 형태와 무기가 또렷이 보입니다. 모델 뒤는 카드 바탕 그대로 검은색입니다.
- 카드에 보이는 모델은 아레나에 나타나지 않고, 전투에 끼어들지 않습니다.

### 일시정지 메뉴

스테이지 레벨(미니던전, LV_SimulationRoom)에서 Esc로 여는 화면입니다. 위쪽의 탭으로 Inventory 탭, System 탭, Settings 탭을 바꿔 봅니다. 여는 조건과 게임을 멈추는 규칙은 [게임 플로우](<게임 플로우.md>)의 '일시정지'를 따릅니다.

- UI 스타일의 '메뉴 화면'을 따르며, 제목 자리에 탭 바를 둡니다. 페이드 없이 바로 표시하고, 표시하는 즉시 입력을 받습니다.
- 메뉴가 떠 있는 동안 마우스 커서를 표시하고, 플레이어 입력은 UI만 받습니다.
- 메뉴를 열 때마다 System 탭을 표시합니다.
- 어느 탭에서든 Esc를 누르면 메뉴를 닫습니다. System 탭의 Resume 버튼을 실행해도 같습니다.

**탭 바**

- 탭 이름을 왼쪽부터 Inventory, System, Settings 순서로 가로로 놓습니다. 글자는 Large이고, 탭 이름 사이는 64px입니다.
- 고른 탭의 이름은 흰색 굵은 글자이고, 이름 아래 8px에 이름 너비만큼 두께 4px의 흰 밑줄을 긋습니다. 고르지 않은 탭의 이름은 흐린 회색 글자이고 밑줄이 없으며, 마우스를 올리면 글자가 밝아집니다.
- 탭 바 왼쪽 끝에 Q, 오른쪽 끝에 E 키 아이콘을 탭 이름과 32px 띄워 놓습니다. 키 아이콘은 36px이며 UI 스타일의 '입력 키 표시'를 따릅니다.
- 탭 바 아래에 고른 탭의 내용을 표시합니다. 탭을 바꾸면 내용이 페이드 없이 바로 바뀝니다.
- Q를 누르면 왼쪽 탭으로, E를 누르면 오른쪽 탭으로 바꿉니다. 첫 탭에서 Q를 누르면 마지막 탭으로, 마지막 탭에서 E를 누르면 첫 탭으로 바꿉니다. 고르지 않은 탭의 이름을 좌클릭해도 그 탭으로 바꿉니다.
- 탭 이름에 마우스를 올릴 때와 탭을 바꿀 때 UI 스타일 '버튼'의 효과음을 재생합니다.
- 탭을 바꾸면 그 탭에서 처음 선택된 것을 선택합니다.

![일시정지 메뉴 - System 탭](<../../Art/Attachments/일시정지 메뉴 - System 탭.svg>)

#### System 탭

- 화면 가운데에 Resume, Restart, Return to Title, Quit 버튼을 위에서부터 세로로 배치합니다. (글자 Large)
- 처음 선택된 버튼은 Resume입니다.
- 버튼의 실행 결과는 [게임 플로우](<게임 플로우.md>)의 '일시정지'를 따릅니다.

#### Inventory 탭

린이 가진 아이템을 보여 줍니다. 왼쪽에 아이템 칸을 격자로 늘어놓은 그리드를, 오른쪽에 고른 아이템의 상세 패널을 둡니다. 그리드와 상세 패널은 48px 띄워 한 묶음으로 화면 가운데에 놓고, 둘의 위쪽은 탭 바 아래 72px에 맞춥니다.

![일시정지 메뉴 - Inventory 탭](<../../Art/Attachments/일시정지 메뉴 - Inventory 탭.svg>)

**그리드**

- 칸은 128 × 160px이고, 칸 사이는 가로세로 모두 16px입니다. 그리드는 한 줄에 7칸, 4줄이 보이는 크기입니다.
- 보유 수가 1 이상인 아이템을 칸 하나에 하나씩, 왼쪽 위 칸부터 오른쪽으로 채우고 줄이 차면 다음 줄로 넘어갑니다. 순서는 소비 아이템, 재화 아이템 순서이고, 같은 카테고리 안에서는 [아이템 시스템](<아이템 시스템.md>)의 '아이템 목록' 순서입니다.
- 아이템이 들어가지 않은 자리는 빈 칸으로 채웁니다. 보이는 7칸 × 4줄은 언제나 칸으로 차 있고, 아이템이 4줄을 넘으면 마지막 줄의 끝까지 빈 칸을 둡니다.
- 칸의 바탕은 검은 배경 위에서 칸이 구분되는 옅은 밝은 색입니다. 칸 위쪽 가운데, 칸 위에서 12px에 아이템 아이콘을 96px로 놓고, 칸 아래쪽 32px은 바탕보다 밝은 띠로 두어 가운데에 보유 수를 숫자만 Medium으로 표시합니다. (예: 3)
- 빈 칸은 바탕만 표시합니다. 빈 칸은 고를 수 없고, 마우스를 올려도 반응하지 않으며, 방향키로 옮길 때도 건너뜁니다.
- 고른 칸은 굵은 흰 테두리와 밝은 바탕으로, 마우스를 올린 칸은 옅은 테두리로 구분합니다.
- 칸이 4줄을 넘으면 그리드 안에서 세로로 스크롤합니다. 마우스 휠로 스크롤하고, 방향키로 보이지 않는 칸을 고르면 그 칸이 보이도록 스크롤합니다.
- 보유한 아이템이 없으면 그리드를 빈 칸으로만 채우고 상세 패널은 표시하지 않습니다.

**칸 고르기**

- Inventory 탭을 표시할 때마다 첫 칸이 골라져 있습니다.
- 칸을 좌클릭하거나 방향키로 옮기면 그 칸을 고릅니다. 마우스를 올리기만 해서는 고르지 않습니다.
- 칸에 마우스를 올릴 때와 좌클릭으로 칸을 고를 때 UI 스타일 '버튼'의 효과음을 재생합니다.
- 이 탭에서 아이템을 쓰거나 버리는 조작은 없습니다. 고른 칸을 다시 좌클릭하거나 Enter를 눌러도 아무 일도 하지 않습니다.

**상세 패널**

고른 아이템을 너비 560px의 패널에 보여 줍니다. 패널의 바탕은 반투명한 어두운 색입니다.

- 패널 위쪽의 높이 72px 띠는 바탕보다 밝은 색이고, 왼쪽에서 24px 안쪽에 아이템 이름을 Large 굵은 글자로 표시합니다.
- 이름 띠 아래 높이 224px 칸의 오른쪽에 아이템 아이콘을 192px로 놓습니다. 왼쪽에는 위에서부터 카테고리 이름('소비 아이템' 또는 '재화 아이템', Medium, 흐린 회색), '보유'(Small, 흐린 회색), '보유 수 / 최대 보유 수'(Large)를 표시합니다. (예: 3 / 3)
- 그 아래에 아이템 설명을 Medium으로 표시합니다. 안쪽 여백은 24px이고, 패널 너비를 넘는 글은 다음 줄로 넘깁니다. 패널의 높이는 설명이 끝나는 곳까지입니다.
- 이름과 설명은 [아이템 시스템](<아이템 시스템.md>)의 '이름과 설명'을 따릅니다.

#### Settings 탭

- 'Settings 화면'의 'Settings 내용'을 표시합니다.
- 메뉴를 열 때마다 Controls 분류가 선택돼 있습니다. 메뉴를 닫기 전까지는 다른 탭에 갔다가 돌아와도 마지막에 고른 분류가 그대로입니다.

- 스테이지 결과 연출이 끝나면 0.5초 동안 화면을 서서히 어둡게 하면서 전투 결과 UI를 서서히 표시합니다. 버튼 입력은 표시가 끝난 뒤부터 받습니다.
- 페이드의 시간 기준은 [시간 규칙](<시간 규칙.md>)의 '시간 연출의 영향'을 따릅니다.
- 전투 결과 UI가 떠 있는 동안 게임은 멈추지 않으며, 플레이어 입력은 UI만 받습니다. 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Restart입니다.

**전투 통계 표**

LV_SimulationRoom의 Stage Clear UI와 Game Over UI에는 그 결과로 끝난 전투의 통계([게임 플로우](<게임 플로우.md>)의 '전투 통계')를 표로 보여 줍니다. 다른 스테이지의 전투 결과 UI에는 표시하지 않습니다.

- 제목, 통계 표, 버튼을 위에서부터 차례로 화면 가운데에 놓습니다. 표가 없으면 제목과 버튼의 위치는 위 그림과 같고, 표가 있으면 표만큼 제목과 버튼이 위아래로 벌어집니다.
- 한 줄에 항목 이름과 값을 하나씩, 위에서부터 아래 순서로 표시합니다. 글자는 Medium입니다.

| 항목 이름 | 값 |
| - | - |
| 전투 시간 | '분:초.밀리초', 초는 두 자리, 밀리초는 세 자리 (예: 0:48.312, 12:05.040) |
| 상대한 적 | 적의 이름을 처음 전투에 들어간 순서로 쉼표로 이어 적습니다. 같은 이름이 둘 이상이면 처음 나온 자리에 '× 수'를 붙여 한 번만 적습니다. (예: 커스터, 절단자 × 2). 이름은 각 캐릭터 문서를 따릅니다. |
| 패리 성공 | 숫자 |
| 회피 성공 | 숫자 |
| 피격 횟수 | 숫자 |

- 표는 전투 결과 UI와 함께 서서히 나타납니다.
- 스테이지 결과가 정해질 때 기록 중인 전투가 없었으면 표를 표시하지 않습니다.

### UI 조작

| 동작 | 키 |
| - | - |
| 버튼·드롭다운 선택 | 마우스 이동, 또는 방향키(↑·↓·←·→) |
| 실행 | 좌클릭, 또는 Enter |
| 열린 드롭다운 목록의 항목 선택 | 마우스 이동, 또는 ↑·↓ |
| 열린 드롭다운 목록의 항목 실행 | 좌클릭, 또는 Enter |
| 드롭다운 목록 닫기 | 항목 실행, 또는 Esc |
| Settings 화면 닫기 | Back 버튼 실행, 또는 Esc |
| Settings의 분류 고르기 | 분류 이름 좌클릭, 분류 목록에서 ↑·↓, 또는 W·S |
| 일시정지 메뉴 닫기 | Resume 버튼 실행, 또는 Esc |
| 일시정지 메뉴의 탭 바꾸기 | Q·E, 또는 탭 이름 좌클릭 |
| Inventory 탭의 칸 고르기 | 좌클릭, 또는 방향키(↑·↓·←·→) |

- 방향키는 그 방향에서 가장 가까운 버튼이나 드롭다운으로 선택을 옮깁니다. 드롭다운 목록이 열려 있으면 방향키는 목록 안에서만 움직입니다.
- Esc는 'UI 레이어'의 입력 규칙에 따라 입력을 받는 화면 하나에만 들어갑니다. 드롭다운 목록이 열려 있으면 목록만 닫습니다. 스테이지 선택 화면과 Settings 화면에서는 Back 버튼과 같습니다. 타이틀 화면, 적 선택 화면, 전투 결과 UI에서는 Esc가 아무 일도 하지 않습니다. 전투 HUD에서 Esc를 누르면 일시정지 메뉴를 엽니다([게임 플로우](<게임 플로우.md>)의 '일시정지').
- 그 방향의 끝에 있는 버튼이나 드롭다운에서 더 넘어가는 방향을 누르면 선택이 그대로 멈춥니다. 반대쪽 끝으로 돌아가지 않습니다.
- 마우스와 키보드를 섞어 쓰면 마지막으로 움직인 장치를 따릅니다. 마우스를 버튼 위로 움직이면 그 버튼이 선택되고, 마우스가 버튼을 벗어나면 선택 표시가 꺼집니다. 키보드는 마지막으로 선택된 버튼에서 이어서 움직입니다.
- Q·E는 일시정지 메뉴가 입력을 받을 때만 탭을 바꿉니다. 전투 HUD에서 Q는 궁극기입니다. W·S도 Settings 내용이 입력을 받을 때만 분류를 바꾸고, 전투 HUD에서는 이동입니다.
- 일시정지 메뉴에서 방향키는 지금 탭의 내용 안에서만 선택을 옮기고, 탭 바로는 옮기지 않습니다.
- Inventory 탭의 방향키는 그 방향의 바로 옆 칸이나 위아래 칸으로 옮깁니다. 줄의 끝에서 ←·→는 다음 줄이나 이전 줄로 넘어가지 않고 멈춥니다. 칸은 마우스를 올리기만 해서는 고르지 않습니다('Inventory 탭'의 '칸 고르기').
