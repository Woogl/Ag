# UI 시스템

전투 HUD와 메뉴·모달 UI의 스타일, 레이어, 화면별 배치와 조작을 정의합니다.

화면이 열리는 조건과 레벨 전환, Start·Resume·Restart·Return to Title·Quit 버튼의 실행 결과는 [게임 플로우](<게임 플로우.md>)를 따릅니다. 표시하는 수치와 상태는 [전투 시스템](<전투 시스템.md>), [캐릭터 - 린](<../Content/캐릭터 - 린.md>), [보스 - 커스터](<../Content/보스 - 커스터.md>)를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## UI 스타일

전투 HUD와 메뉴·모달 UI에 함께 적용하는 화면 기준, 글자, 버튼의 스타일입니다. 각 화면은 글자 크기를 이 절의 단계 이름(예: Large)으로 적습니다.

### 화면 기준

| 항목 | 내용 |
| - | - |
| 기준 해상도 | 1920 × 1080. 다른 해상도에서는 화면의 짧은 변 길이에 맞춰 UI 전체의 크기를 함께 조절하며, 요소 간 크기 비율과 각 화면에서 정한 배치 기준을 유지합니다. |
| 화면 여백 | 화면 가장자리에 붙는 요소는 가장자리에서 48px 안쪽에 배치합니다. |
| 크기 단위 | 바, 슬롯, 여백 등 글자가 아닌 크기는 px로 적습니다. px는 기준 해상도에서의 크기입니다. |
| 입력 키 표시 | 키보드·마우스 기준으로 표시합니다. 키보드 키는 키 이름으로(예: E, Left Shift), 마우스 입력은 마우스 이동, 좌클릭, 우클릭, 휠 클릭으로 표시합니다. 지원하는 조작 장치는 [게임 개요](<../게임 개요.md>)를 따릅니다. |

### 글자

| 항목 | 내용 |
| - | - |
| 언리얼 Size | 언리얼 엔진 폰트의 Size 값으로, 언리얼에 입력하는 값입니다. 기획서의 글자 크기는 이 값을 기준으로 합니다. 언리얼은 폰트 크기를 96 DPI 기준으로 처리하므로 px × 0.75입니다. |
| 최소 크기 | Small(Size 15, 20px)보다 작은 글자는 쓰지 않습니다. Xbox 접근성 가이드라인의 PC 최소 기준(1080p에서 글자 높이 18px)보다 조금 크게 잡았습니다. |
| 크기 간격 | 언리얼 Size는 3의 배수로 정해 px가 4의 배수(정수)가 되게 합니다. |
| 글꼴 | [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다. |

#### 크기 단계

| 단계 | 언리얼 Size | px |
| - | - | - |
| Small | 15 | 20 |
| Medium | 18 | 24 |
| Large | 24 | 32 |

- px는 시안(SVG)과 비교하기 위한 참고 값입니다.
- 새 글자를 추가할 때는 가까운 단계를 먼저 씁니다. 여러 곳에서 반복해서 쓰는데 맞는 단계가 없을 때만 단계를 추가하고, 한 곳에서만 쓰는 글자는 전용 글자로 둡니다.

#### 전용 글자

한 곳에서만 쓰고 크기, 색상, 굵기가 따로 정해진 글자는 크기 단계에 넣지 않습니다. 크기는 정의 문서에 언리얼 Size로 적습니다. (예: Size 168)

| 글자 | 정의 문서 |
| - | - |
| 게임 제목 | '메뉴 UI'의 타이틀 화면 |
| 전투 결과 UI 제목 | '메뉴 UI'의 Stage Clear UI / Game Over UI |
| 대미지 숫자 | [전투 시스템](<전투 시스템.md>)의 대미지 숫자 |
| 쿨다운 숫자 | '전투 HUD'의 스킬·궁극기 슬롯 |

### 버튼

메뉴 UI와 모달 UI의 모든 버튼에 적용합니다.

- 글자는 굵은 글자로 표시합니다. 선택된 버튼은 선택되지 않은 버튼보다 밝은 배경, 굵은 테두리, 밝은 글자로 구분합니다.
- 마우스를 버튼 위로 올릴 때와 버튼을 실행할 때 효과음을 재생합니다. 쓰는 사운드는 [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다.


## UI 레이어

여러 화면이 함께 떠 있을 때 어느 화면을 위에 표시하고, 어느 화면이 입력을 받는지 정의합니다.

### 레이어 구성

모든 화면은 아래 세 레이어 가운데 하나에 표시합니다. 표는 아래 레이어부터 적었으며, 위 레이어의 화면이 아래 레이어의 화면을 덮습니다.

| 레이어 | 화면 | 성격 |
| - | - | - |
| HUD | 전투 HUD | 플레이하는 동안 계속 보는 정보 |
| Menu | 타이틀 화면, 일시정지 메뉴, Stage Clear UI, Game Over UI | 버튼으로 다음 진행을 고르는 화면 |
| Modal | 조작 안내 팝업 | 다른 화면 위에 띄워, 닫을 때까지 뒤의 화면을 조작할 수 없게 하는 창 |

- 전투 HUD의 락온 마커와 처형 안내, [전투 시스템](<전투 시스템.md>)의 대미지 숫자는 보스와 맞은 위치를 따라 움직이므로 레이어에 넣지 않고, 모든 레이어보다 아래에 표시합니다.

![UI 레이어 구성](<../../Art/Attachments/UI 레이어 구성.svg>)

### 표시

- 한 레이어에 화면을 여러 개 열면 마지막에 연 화면만 표시하고, 먼저 연 화면은 숨깁니다. 마지막에 연 화면을 닫으면 그 전에 연 화면을 다시 표시합니다.
- 위 레이어에 화면이 열려도 아래 레이어의 화면은 숨기지 않고 그대로 표시합니다. 아래 화면을 어둡게 하거나 숨기는 것은 각 화면의 규칙(조작 안내 팝업, 일시정지 메뉴, 전투 결과 UI, 전투 HUD의 '상황별 표시 규칙')을 따릅니다.
- 레벨이 바뀌면 모든 레이어의 화면을 닫습니다.

### 입력

- 입력은 표시 중인 화면 가운데 가장 위 레이어에서 마지막에 연 화면 하나만 받습니다. 마우스 커서 표시와 게임 입력을 받을지는 이 화면의 규칙('메뉴 UI', 전투 HUD는 [게임 플로우](<게임 플로우.md>)의 'Boss Stage')을 따릅니다.
- 입력을 받지 않는 화면의 버튼은 선택하거나 실행할 수 없고, 마우스 클릭도 그 화면에 전달되지 않습니다.
- 입력을 받던 화면이 닫히면 남은 화면 가운데 위 규칙에 맞는 화면이 입력을 받고, 그 화면에서 마지막으로 선택되어 있던 버튼을 다시 선택합니다. 화면을 닫은 입력은 다음 화면에 전달되지 않습니다.


## 전투 HUD

전투 중 화면에 표시하는 정보(HUD)를 정의합니다.

### 화면 구성

![전투 HUD 화면 구성](<../../Art/Attachments/전투 HUD 화면 구성.svg>)

- 기준 해상도에서의 배치입니다.
- 처형 안내는 조건부 요소지만, 위치를 보여 주기 위해 함께 그렸습니다.

| 번호 | 요소 | 위치 |
| - | - | - |
| 1 | 플레이어 상태 | 화면 왼쪽 아래 |
| 2 | 스킬·궁극기 슬롯 | 화면 오른쪽 아래 |
| 3 | 보스 상태 | 화면 위쪽 가운데 |
| 4 | 락온 마커 | 보스 몸의 락온 지점 |
| 5 | 처형 안내 | 보스 머리 위 |
| 6 | 조작 안내 | 화면 오른쪽 가운데 |

- 적중한 위치에 뜨는 대미지 숫자는 [전투 시스템](<전투 시스템.md>)의 '대미지 숫자'를 따릅니다.

### HUD 요소

#### 1. 플레이어 상태

| 요소 | 크기 | 표시 규칙 |
| - | - | - |
| SP 바 | 400 × 8px | 항상 HP 바 바로 위에 표시합니다. 가드로 공격을 막아 SP가 줄면 감소 잔상을 표시합니다. |
| HP 바 | 400 × 16px | 항상 표시합니다. HP가 줄면 감소 잔상을 표시합니다. |
| HP 수치 | 글자 Medium | HP 바 오른쪽에 '현재값 / 최대값'으로 표시합니다. |
| MP 바 | 400 × 10px | 항상 표시합니다. |
| MP 수치 | 글자 Medium | MP 바 오른쪽에 '현재값 / 최대값'으로 표시합니다. |

- 위에서부터 SP, HP, MP 순서로 배치합니다.
- 플레이어 PP는 표시하지 않습니다.
- 감소 잔상: HP가 줄면 줄어든 부분을 감소 잔상으로 남겨 두었다가, 0.5초 뒤 0.3초 동안 현재 HP까지 줄입니다. 잔상이 줄어드는 동안 HP가 다시 줄면 그 자리에서 다시 0.5초를 기다립니다.
- SP 바의 감소 잔상은 HP 바와 같고, 가드와 가드 브레이크로 줄어든 SP에만 표시합니다. 회피와 달리기로 소모한 SP는 잔상 없이 바로 줄입니다.

#### 2. 스킬·궁극기 슬롯

| 슬롯 | 위치 | 슬롯 안 정보 |
| - | - | - |
| 스킬 | 화면 오른쪽 아래 | 스킬 아이콘, 스킬의 MP 코스트, 쿨다운 표시(쿨다운 중) |
| 궁극기 | 화면 오른쪽 아래, 스킬 슬롯 오른쪽 | 궁극기 아이콘. 슬롯 테두리에 UP 게이지를 표시합니다. |

- 슬롯 크기는 96 × 96px, 슬롯 사이 간격은 12px입니다. 아이콘은 슬롯 가운데에 72 × 72px로 표시합니다.
- 아이콘의 에셋과 표현은 [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다.
- 슬롯 안 숫자(MP 코스트)는 글자 Small로 표시합니다.
- UP 게이지는 궁극기 슬롯의 테두리가 UP 비율만큼 위쪽 가운데부터 시계 방향으로 채워지는 표시입니다. UP가 가득 차면 테두리 전체가 채워집니다.
- 쿨다운 표시: 스킬 쿨다운 중에는 슬롯에 아래 두 가지를 겹칩니다.
  - 원형 표시: 슬롯 안쪽을 남은 쿨다운 비율만큼 밝은 반투명으로 덮습니다. 덮개의 경계는 위쪽 가운데에서 시작해 시계 방향으로 돌고, 지나간 부분부터 덮개가 걷힙니다.
  - 숫자: 남은 쿨다운을 슬롯 가운데에 표시합니다. 1초 이상은 초 단위 정수, 1초 미만은 소수 한 자리로 표시하며, 둘 다 올림합니다. 쿨다운 숫자는 전용 글자이며 Size 24입니다.
- MP 또는 UP가 부족한 슬롯은 흐리게(반투명하게) 표시합니다. 쿨다운 중이라는 이유로는 흐리게 하지 않습니다. UP 게이지와 쿨다운 표시는 슬롯이 흐릴 때도 그대로 표시합니다.

#### 3. 보스 상태

- 보스가 전투에 들어간 뒤부터 이름·HP 바·PP 바를 표시합니다. 그 전에는 숨깁니다. 컷신과 사망 이후 표시는 아래 '상황별 표시 규칙'을 따릅니다.

| 요소 | 크기 | 표시 규칙 |
| - | - | - |
| 보스 이름 | 글자 Large | HP 바 위 가운데에 보스 이름을 표시합니다. 이름은 [보스 - 커스터](<../Content/보스 - 커스터.md>)를 따릅니다. |
| HP 바 | 1000 × 14px | 수치와 페이즈 경계는 표시하지 않습니다. 플레이어가 페이즈가 바뀌는 시점을 미리 알 수 없게 합니다. 감소 잔상은 플레이어 HP 바와 같습니다. |
| PP 바 | 1000 × 6px | HP 바 바로 아래에 항상 표시합니다. 감소 잔상은 플레이어 HP 바와 같습니다. |

- 그로기 중에는 빈 PP 바를 그로기 지속 시간 동안 다시 채워 남은 시간을 보여 줍니다. 공중에서도 같은 방식으로 표시합니다. 처형으로 전환되면 PP 바와 감소 잔상을 처형 직전의 표시 위치에 멈춰 둡니다. 처형 피격이 끝나거나 중단되면 실제 PP 표시로 돌아가며, 살아 있으면 최대로 채워집니다. 처형 없이 그로기가 종료되어도 실제 PP 표시로 돌아갑니다. 종료와 PP 회복 시점, 사망 시 회복하지 않는 규칙은 [전투 시스템](<전투 시스템.md>)의 '그로기'를 따릅니다.

#### 4. 락온 마커

- 락온 중일 때 보스의 락온 지점([카메라와 타겟팅](<카메라와 타겟팅.md>) 참고)에 지름 32px의 원형 마커를 표시합니다.

#### 5. 처형 안내

- [캐릭터 - 린](<../Content/캐릭터 - 린.md>)의 처형 발동 조건 중 1번(지상 그로기)과 2번(처형 타겟팅 범위)을 만족하는 동안 보스 머리 위에 '[F] 처형'을 표시합니다. (글자 Large) 기본 공격이나 회피 중이라 잠시 처형을 입력할 수 없을 때도 숨기지 않습니다.
- 조건을 벗어나거나 그로기가 끝나면 즉시 숨깁니다.

#### 6. 조작 안내

플레이어의 키 배치를 보여 주는 안내입니다.

- [플레이어 시스템](<플레이어 시스템.md>)의 '키 배치' 표에 있는 모든 조작을 표의 순서대로 한 줄에 하나씩 표시합니다.
- 각 줄은 왼쪽에 키, 오른쪽에 조작 이름을 표시합니다. 조작 이름은 모든 줄에서 같은 위치에서 시작합니다.
  - 키는 UI 스타일의 '입력 키 표시'를 따릅니다. 키 칸의 '(누르고 있기)'와 '설명' 열은 표시하지 않습니다.
  - 조작 이름은 '조작' 열을 그대로 씁니다. (예: 가드 / 패리)
- 글자는 키와 조작 이름 모두 Small입니다.
- 반투명한 어두운 배경 위에 표시합니다. 배경 안쪽 여백은 16px, 키와 조작 이름 사이는 24px입니다.
- 화면 오른쪽 가장자리에 붙이고, 세로로 화면 가운데에 둡니다.

### 상황별 표시 규칙

| 상황 | 플레이어 상태, 슬롯, 조작 안내 | 보스 상태 | 락온 마커, 처형 안내 |
| - | - | - | - |
| 전투 (페이즈 전환 연출 포함) | 표시 | 표시 | 조건에 따라 표시 |
| 처형 | 표시 | 표시 | 숨김 |
| 궁극기 컷신 | 숨김 | 숨김 | 숨김 |
| 스테이지 결과 연출 (플레이어·보스 사망으로 연출이 시작되는 순간부터) | 숨김 | 숨김 | 숨김 |
| 전투 결과 UI | 숨김 | 숨김 | 숨김 |

- 일시정지 메뉴가 열려 있는 동안에는 메뉴를 열기 직전의 표시를 그대로 둡니다. 감소 잔상과 쿨다운 표시도 멈췄다가 메뉴를 닫으면 이어집니다.


## 메뉴 UI

메뉴 UI(타이틀 화면, 일시정지 메뉴, 전투 결과 UI)와 모달 UI(조작 안내 팝업)의 배치와 표시, 포커스와 조작 규칙을 정의합니다.

### 타이틀 화면

LV_FrontEnd에 표시하는 화면입니다.

- 화면 위쪽 가운데에 게임 제목 'AG'를 크게 표시합니다. (전용 글자 Size 168)
- 제목 아래 가운데에 Start, Controls, Quit 버튼을 위에서부터 세로로 배치합니다. (글자 Large)
- 레벨이 열리면 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Start입니다.

![타이틀 화면](<../../Art/Attachments/FrontEnd 화면 구성.svg>)

#### 조작 안내 팝업

보스전에 들어가기 전에 키 배치를 확인할 수 있도록 Controls 버튼으로 여는 팝업에 조작 안내를 표시합니다.

- 게임을 처음 실행했을 때와 타이틀로 돌아왔을 때 팝업은 닫힌 상태입니다. Controls 버튼을 실행하면 레벨 전환 없이 팝업을 엽니다.
- 팝업은 화면 가운데에 배치하고 화면 여백 안에 들어오게 합니다. 뒤의 타이틀 화면은 어둡게 표시합니다.
- 패널 위쪽에 제목 'Controls'을 Large로 표시합니다. 패널에는 어두운 배경과 안쪽 여백 24px을 둡니다.
- 제목 아래 가운데에 전투 HUD의 '조작 안내'를 같은 모양 그대로 표시합니다. 표시 위치만 다릅니다.
- 안내 본문은 읽기 전용입니다. 팝업 아래쪽 가운데에 'Confirm' 버튼을 Large로 표시하며, 팝업을 열면 이 버튼이 선택됩니다.
- 팝업이 열려 있는 동안 마우스 커서를 표시합니다. 팝업 바깥을 클릭해도 닫히지 않습니다.
- Confirm 버튼을 실행하거나 Esc를 누르면 팝업을 닫습니다. 다시 Controls 버튼을 실행하면 팝업을 다시 열 수 있습니다.

![조작 안내 팝업](<../../Art/Attachments/조작 안내 팝업.svg>)

### 일시정지 메뉴

LV_BossStage에서 Esc로 여는 화면입니다.

- 화면 가운데에 Resume, Restart, Return to Title, Quit 버튼을 위에서부터 세로로 배치합니다. (글자 Large) 제목은 표시하지 않습니다.
- 뒤의 게임 화면은 어둡게 표시합니다. 페이드 없이 바로 표시하고, 표시하는 즉시 버튼 입력을 받습니다.
- 메뉴가 떠 있는 동안 마우스 커서를 표시하고, 플레이어 입력은 UI만 받습니다.
- 처음 선택된 버튼은 Resume입니다.

![일시정지 메뉴](<../../Art/Attachments/일시정지 메뉴 화면 구성.svg>)

### Stage Clear UI / Game Over UI

| 항목 | Stage Clear UI | Game Over UI |
| - | - | - |
| 제목 문구 | STAGE CLEAR | GAME OVER |
| 버튼 | Restart, Return to Title, Quit (세로 배치) | Restart, Return to Title, Quit (세로 배치) |

- 글자 크기는 제목 Size 84(전용 글자), 버튼 Large입니다.
- 스테이지 결과 연출이 끝나면 0.5초 동안 화면을 서서히 어둡게 하면서 전투 결과 UI를 서서히 표시합니다. 버튼 입력은 표시가 끝난 뒤부터 받습니다.
- 전투 결과 UI가 떠 있는 동안 게임은 멈추지 않으며, 플레이어 입력은 UI만 받습니다. 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Restart입니다.

### UI 조작

| 동작 | 키 |
| - | - |
| 버튼 선택 | 마우스 이동, 또는 ↑·↓ |
| 실행 | 좌클릭, 또는 Enter |
| 조작 안내 팝업 닫기 | Confirm 버튼 실행, 또는 Esc |
| 일시정지 메뉴 닫기 | Resume 버튼 실행, 또는 Esc |

- Esc는 'UI 레이어'의 입력 규칙에 따라 입력을 받는 화면 하나에만 들어갑니다. 조작 안내 팝업과 일시정지 메뉴는 Esc로 닫히고, 타이틀 화면과 전투 결과 UI에서는 Esc가 아무 일도 하지 않습니다. 전투 HUD에서 Esc를 누르면 일시정지 메뉴를 엽니다([게임 플로우](<게임 플로우.md>)의 '일시정지').
- 맨 위나 맨 아래 버튼에서 더 넘어가는 방향을 누르면 선택이 그대로 멈춥니다. 반대쪽 끝으로 돌아가지 않습니다.
- 마우스와 키보드를 섞어 쓰면 마지막으로 움직인 장치를 따릅니다. 마우스를 버튼 위로 움직이면 그 버튼이 선택되고, 마우스가 버튼을 벗어나면 선택 표시가 꺼집니다. 키보드는 마지막으로 선택된 버튼에서 이어서 움직입니다.
