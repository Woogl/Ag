# 적 시스템

적의 공격 예고와 AI 행동 규칙을 정의합니다. 이 문서의 규칙은 보스를 포함한 모든 적에게 적용하며, 보스에게만 더하거나 바꾸는 규칙은 [보스 시스템](<보스 시스템.md>)을 따릅니다. 적별 스탯, 공격 패턴, 연출은 각 적 문서([보스 - 커스터](<../Content/보스 - 커스터.md>))를 따릅니다.

대미지, 공격 판정, PP, 피격 반응, 그로기, 사망 등 공통 규칙은 [전투 시스템](<전투 시스템.md>) 문서를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 공격 예고

예고는 공격 판정이 시작될 시점을 알립니다. 가드 가능 여부에 따라 예고가 다르며, 판정 시작부터 플레이어에게 실제로 닿기까지는 거리와 공격의 이동에 따라 시간차가 있을 수 있습니다.

| 가드 가능 | 예고 | 플레이어의 대응 |
| - | - | - |
| 가능 | 패리 예고: 판정 구간이 시작되기 전 패리 구간 길이만큼 무기에 VFX (가드 불가 예고와 다른 색) | 패리, 가드, 회피 |
| 불가 (가드 불가) | 가드 불가 예고: 판정 구간 0.5초 전부터 판정 구간이 시작될 때까지 무기에 붉은 VFX | 회피 (극한 회피 시 회피 반격) |

- 공격 패턴은 선딜 동안 패턴 전조 동작을 크게 보여 주어, 플레이어가 공격 타이밍을 읽을 수 있어야 합니다.
- 패리 예고 시간은 패리 구간과 같은 길이로 맞춥니다. ([캐릭터 - 린](<../Content/캐릭터 - 린.md>)의 '패리 구간')
- 착지처럼 판정 구간의 시작을 모션으로 정할 수 없는 공격은 각 적 문서의 패턴 항목에 적은 구간에 예고를 켭니다.
- 예고가 켜질 때 효과음을 한 번 재생합니다. 가드 불가 예고와 패리 예고는 색처럼 효과음도 서로 다릅니다. 쓰는 사운드는 [아트 표현 사양](<../../Art/아트 표현 사양.md>)을 따릅니다.

## AI 행동 규칙

### 전투 시작과 상태 전환

- 레벨이 시작되면 '패턴 후딜레이'의 대기 시간만큼 기다린 뒤 패턴 선택을 시작합니다.
- 공격 패턴, 넉업, 넉다운, 그로기 유지 또는 처형 피격이 끝나면 패턴 후딜레이를 거쳐 다음 패턴을 선택합니다. 회피 패턴이 끝난 뒤의 처리는 각 적 문서의 패턴 항목을 따릅니다.
- 아래 전환은 진행 중인 패턴이나 상태와 관계없이 적용합니다. 여러 조건을 동시에 만족하면 순서가 앞선 전환을 따릅니다. 보스는 [보스 시스템](<보스 시스템.md>)의 '상태 전환'에 적은 전환을 이 표 뒤에 더합니다.
- 조건이 '~하는 순간'인 전환은 그 일이 일어날 때 한 번 적용하고, 나머지는 조건을 만족하는 동안 적용 여부를 판단합니다.
- 사망한 뒤에는 아래 전환을 더 적용하지 않습니다. 비전투로 전환한 뒤에는 사망만 적용합니다.

| 순서 | 조건 | 처리 |
| - | - | - |
| 1 | HP가 0 이하가 되는 순간 | 각 적 문서의 '사망'을 따릅니다. |
| 2 | 플레이어가 사망하는 순간 | 진행 중인 패턴을 즉시 중단하고 그 자리에서 대기 모션을 유지합니다. (비전투) |
| 3 | PP가 0 이하가 되는 순간 | 각 적 문서의 '그로기'를 따릅니다. |
| 4 | 플레이어가 처형을 시작하는 순간 | 각 적 문서의 '처형 피격'을 따릅니다. |

### 패턴 선택

1. 적과 플레이어의 캡슐 중심 사이 수평 거리가 허용 거리 안이고, 쿨다운이 끝났으며, 지금 사용할 수 있는 패턴을 후보로 모읍니다.
2. 후보 중 가중치(각 적 문서의 '패턴 목록' 참고)에 따라 무작위로 하나를 선택합니다.
3. 후보가 없으면 플레이어에게 걸어서 다가가며 다시 선택을 시도합니다.

### 패턴 후딜레이

- 패턴이 끝나면 패턴 후딜레이 동안 플레이어를 바라보며 좌우로 걷습니다.
- 대기 시간은 각 적 문서의 '패턴 후딜레이'를 따릅니다.
