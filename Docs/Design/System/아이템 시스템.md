# 아이템 시스템

린이 가지는 아이템의 카테고리와, 아이템을 가지고 쓰는 규칙을 정의합니다. 아이템을 쓰는 행동의 규칙은 그 행동의 기획서를 따릅니다.

용어는 [용어집](<../../용어집.md>)을 따릅니다.

## 공통

| 항목 | 규칙 |
| - | - |
| 카테고리 | 아이템마다 소비 아이템, 재화 아이템 중 하나입니다. |
| 이름과 설명 | 아이템마다 이름과 설명이 있습니다. 이름은 '아이템 목록'의 '아이템' 열이고, 문구는 문구 표에 둡니다. |
| 보유 수 | 린은 아이템마다 0개부터 그 아이템의 최대 보유 수까지 가집니다. |
| 얻기 | 보유 수는 최대 보유 수까지만 늘고, 넘는 만큼은 버려집니다. |
| 쓰기 | 쓰거나 내는 수가 보유 수보다 많으면 쓰지 않고, 보유 수도 그대로입니다. |
| 시작 | 새 게임은 '아이템 목록'의 시작 보유 수로 시작합니다. 시작 보유 수가 없는 아이템은 0개로 시작합니다. |
| 저장 | 보유 수는 저장 슬롯에 저장되어([게임 플로우](<게임 플로우.md>)의 '저장') 스테이지 사이에서도, 게임을 다시 켠 뒤에도 이어집니다. |
| 채우기 | 레벨을 열 때마다(스테이지에 들어갈 때, 다시 시작할 때) 휴식으로 채우는 아이템을 최대 보유 수까지 채웁니다. 체크포인트의 휴식도 같은 아이템을 채웁니다([게임 플로우](<게임 플로우.md>)의 '체크포인트'). |

## 소비 아이템

- 소비 아이템은 그 아이템을 쓰는 행동으로 씁니다. 행동이 아이템을 쓰는 순간에 보유 수가 1 줄고, 그 전에 행동이 끊기면 줄지 않습니다.
- 그 아이템이 0개이면 그 행동을 시작할 수 없습니다.

## 재화 아이템

- 재화 아이템은 보유 수가 곧 가진 양입니다.
