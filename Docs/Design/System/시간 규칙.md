# 시간 규칙

히트스톱, 슬로우모션, 궁극기 시간 정지와 각 기능의 시간이 흐르는 기준을 정의합니다. 개별 행동의 길이와 쿨다운, 그로기·스테이지 결과 연출의 지속 시간은 해당 기획서를 따릅니다.

## 시간 기준

| 기준 | 의미 |
| - | - |
| 실제 시간 | [용어집](<../../용어집.md>)의 '실제 시간'을 따릅니다. 슬로우모션의 지속 시간과 아래에 명시한 포스트프로세스는 이 기준으로 셉니다. |
| 게임 시간 | 게임의 진행에 따라 흐르는 시간입니다. 슬로우모션에서는 느려지고, 궁극기 시간 정지에서는 멈춥니다. 히트스톱만으로는 멈추지 않습니다. |
| 모션 진행 | 선딜·판정·후딜 등 모션 안의 구간은 모션의 진행을 따릅니다. 해당 캐릭터의 모션이 멈추면 구간도 진행하지 않습니다. 궁극기 시간 정지 중에도 플레이어의 모션은 진행합니다. |

같은 초 단위라도 기준에 따라 실제로 기다리는 길이가 달라집니다. 아래 영향표에서 기능별 기준을 확인합니다.

### 정지의 허용 오차

이 문서의 '멈춤'은 플레이 중 정지해 보이는 것을 기준으로 하며, 히트스톱과 궁극기 시간 정지 중의 미세한 모션·이동·시간 진행은 허용합니다. 궁극기 시간 정지 동안 수 밀리초 정도의 게임 시간이 진행해, 종료 직전의 그로기·쿨다운이 끝나거나 자원 회복 주기가 도래하는 것도 허용합니다. 아래 영향표의 정지와 해제 후 재개 규칙에도 이 기준을 적용합니다.

## 히트스톱

공격이 적중하면 타격감을 위해 공격자와 피격자의 모션과 이동을 게임 시간으로 0.12초 동안 멈춥니다. 게임 전체가 아닌 두 캐릭터에만 적용합니다.

- 가드로 막거나 패리한 경우에도 같은 히트스톱을 적용합니다.
- 처형에는 히트스톱을 적용하지 않습니다.
- 투사체가 적중하거나 가드 또는 패리되면, 투사체를 쏜 캐릭터는 멈추지 않고 맞거나 막거나 패리한 캐릭터에게만 적용합니다.
- 보스 GroundSlam 착지 충격파가 적중하면 보스는 멈추지 않고 맞은 캐릭터에게만 적용합니다.
- 무적 대상에게 닿은 공격의 처리는 [전투 시스템](<전투 시스템.md>)의 '피격 처리 순서'를 따릅니다.

## 슬로우모션

극한 회피에 성공한 순간과 궁극기 마무리 순간을 강조하는 연출로, 게임 전체를 잠깐 느리게 합니다. 카메라 셰이크도 느려지며, 실제 시간으로 흐르는 항목은 아래 영향표를 따릅니다.

| 발동 | 속도 | 지속 시간 |
| - | - | - |
| 극한 회피 성공 | 0.3배 | 실제 시간 0.5초 |
| 궁극기 마무리 (적중과 관계없음) | 0.3배 | 실제 시간 0.8초 |

- 지속 시간이 끝나면 바로 원래 속도로 돌아갑니다. 쿨다운은 없습니다.
- 슬로우모션 자체의 지속 시간은 실제 시간으로 셉니다. 자기 배율 때문에 더 길어지지 않습니다.
- 재발동과 다른 시간 연출의 중첩은 아래 '중첩과 전환'을 따릅니다.

## 궁극기 시간 정지

궁극기 시작부터 마무리까지 보스와 보스의 투사체(검기)의 모션·이동·패턴 진행이 그 자리에서 멈춥니다. 마무리 순간 멈췄던 상태에서 그대로 이어집니다. 궁극기의 단계와 공격은 [플레이어 캐릭터 - 린](<../Content/플레이어 캐릭터 - 린.md>)의 '궁극기'를 따릅니다.

플레이어의 모션과 이동은 계속 진행하지만, 플레이어를 포함한 게임 시간 기준의 쿨다운·선입력 유지 시간·자원 회복 등은 멈춥니다. 캐릭터가 움직일 수 있는지와 각 기능의 시간이 흐르는지는 아래 영향표로 구분합니다.

## 시간 연출의 영향

| 항목 | 히트스톱 중 | 슬로우모션 중 | 궁극기 시간 정지 중 |
| - | - | - | - |
| 모션과 이동, 무기 궤적, 모션을 따르는 선딜·판정·후딜·무적 구간·패턴 안의 모든 시간 | 멈춘 캐릭터의 것은 멈춤 | 느려짐 | 플레이어를 제외한 모든 대상은 멈춤. 플레이어는 진행 |
| 쿨다운, 선입력을 기억하는 시간, 그로기 지속 시간, 리젠 대기 시간과 자원 회복, 패턴 후딜레이 대기 시간 | 흐름 | 느려짐 | 플레이어를 포함한 모든 대상의 타이머 멈춤. 해제 후 남은 시간부터 이어짐 |
| 패리 구간(그동안 이동 제한), 극한 회피 구간, 회피 반격 기회 | 흐름 | 느려짐 | 궁극기 중에는 발생하지 않음 |
| 히트스톱의 남은 시간 | 흐름 | 느려짐 | 게임 시간이 멈춘 동안 진행하지 않음 |
| 슬로우모션의 남은 시간 | 실제 시간으로 흐름 | 실제 시간으로 흐름 | 아래 '중첩과 전환'을 따름 |
| 스테이지 결과 연출의 경과 시간 | 흐름 | 느려짐 | 게임 시간이 멈춘 동안 진행하지 않음 |
| 극한 회피 포스트프로세스의 재생 시간 | 실제 시간으로 흐름 | 실제 시간으로 흐름 | 실제 시간으로 흐름 |
| 대미지 숫자의 이동·페이드, 전투 결과 UI의 페이드 | 실제 시간으로 흐름 | 실제 시간으로 흐름 | 실제 시간으로 흐름 |
| HP·SP·PP 바 감소 잔상의 대기·감소 시간 | 흐름 | 느려짐 | 멈춤. 해제 후 남은 시간부터 이어짐 |

대미지 숫자와 감소 잔상은 일시정지 메뉴가 열려 있는 동안 멈춥니다. 전투 결과 UI가 표시되기 시작한 뒤에는 일시정지 메뉴를 열 수 없습니다. 일시정지 규칙은 [게임 플로우](<게임 플로우.md>)를 따릅니다.

극한 회피 포스트프로세스는 성공 시점의 극한 회피 슬로우모션 지속 시간을 전체 재생 길이로 사용합니다. 이후 슬로우모션의 재발동이나 종료로 그 길이를 바꾸지 않습니다. 궁극기 포스트프로세스의 시작·종료 시점은 [플레이어 캐릭터 - 린](<../Content/플레이어 캐릭터 - 린.md>)의 '궁극기 포스트프로세스'를 따릅니다.

## 중첩과 전환

- 슬로우모션 중에 다시 발동하면 새로 발동한 슬로우모션의 속도와 지속 시간으로 처음부터 다시 셉니다. 배율을 곱하거나 남은 시간에 더하지 않습니다.
- 히트스톱의 남은 시간도 슬로우모션의 영향을 받으므로, 실제 시간으로는 더 길게 멈춥니다. 히트스톱이 끝나도 슬로우모션이 남아 있으면 느린 속도로 모션과 이동을 이어갑니다.
- 궁극기 시간 정지가 시작되면 진행 중인 슬로우모션은 끝납니다. 시간 정지가 끝난 뒤 이전 슬로우모션의 남은 시간을 이어가지 않습니다.
- 궁극기 시간 정지가 시작되면 플레이어에게 남아 있는 히트스톱은 즉시 끝납니다. 보스에게 남아 있는 히트스톱은 유지하며, 시간 정지가 끝난 뒤 남은 시간부터 이어집니다.
- 궁극기 마무리의 슬로우모션은 시간 정지가 끝난 뒤 시작하며, 적중 여부와 관계없이 발동합니다.
- 궁극기 마무리의 적중으로 히트스톱이 발생하면, 시간 정지가 풀린 뒤 슬로우모션의 영향을 받으며 히트스톱 시간을 셉니다.
