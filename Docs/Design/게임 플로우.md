# 게임 플로우

게임 시작부터 보스전의 끝까지 레벨 전환 규칙, 보스전의 시작과 결과, 각 화면의 UI를 정의합니다.

용어는 [용어집](<../용어집.md>)을 따릅니다.

## 1. Front End

LV_FrontEnd는 게임을 실행하면 처음 열리는 레벨입니다.

Start 버튼을 누르면 보스전 스테이지(LV_BossStage)로 이동합니다.

Controls 버튼을 누르면 타이틀 화면 위에 조작 안내 팝업을 엽니다.

Quit 버튼을 누르면 게임을 종료합니다.

![타이틀 화면](<Attachments/FrontEnd 화면 구성.svg>)

## 2. Boss Stage

LV_BossStage는 보스전이 진행되는 레벨입니다. 구성은 [보스 스테이지](<보스 스테이지.md>)를 따릅니다.

레벨이 열리면 바로 보스전이 시작되며, 플레이어는 시작 지점에서 바로 조작할 수 있습니다. 보스가 전투를 시작하는 방식은 [보스 사양](<보스 사양.md>)의 '전투 시작과 행동 전환'을 따릅니다.

레벨이 열리면 마우스 커서를 숨기고, 입력은 게임만 받습니다.

보스전의 결과는 먼저 처리된 사망으로 정해집니다. 결과가 정해진 뒤 상대가 사망하면 사망 연출은 재생하지만, 결과와 결과 UI는 바뀌지 않습니다.

LV_BossStage를 다시 시작하면 레벨을 처음부터 다시 로드하며, 플레이어와 보스의 모든 상태(스탯, 페이즈 등)를 초기화합니다.

## 3. Stage Clear

보스의 HP가 0 이하가 되면, 보스의 사망 연출이 재생되고 Stage Clear UI 창이 출력됩니다. 이미 결과가 정해진 뒤에 사망한 경우는 'Boss Stage'를 따릅니다.

Try Again 버튼을 누르면 LV_BossStage를 다시 시작합니다.

Return to Title 버튼을 누르면 LV_FrontEnd 레벨로 돌아갑니다.

Quit 버튼을 누르면 게임을 종료합니다.

![Stage Clear UI](<Attachments/Stage Clear 화면 구성.svg>)

## 4. Game Over

플레이어 캐릭터의 HP가 0 이하가 되면, 플레이어 캐릭터의 사망 연출이 재생되고 Game Over UI 창이 출력됩니다. 이미 결과가 정해진 뒤에 사망한 경우는 'Boss Stage'를 따릅니다.

Try Again 버튼을 누르면 LV_BossStage를 다시 시작합니다.

Return to Title 버튼을 누르면 LV_FrontEnd 레벨로 돌아갑니다.

Quit 버튼을 누르면 게임을 종료합니다.

![Game Over UI](<Attachments/Game Over 화면 구성.svg>)

## 화면 UI

기준 해상도, 화면 여백, 글자 크기, 버튼 스타일은 [UI 스타일](<UI 스타일.md>)을 따릅니다.

### 타이틀 화면

LV_FrontEnd에 표시하는 화면입니다.

- 화면 위쪽 가운데에 게임 제목 'AG'를 크게 표시합니다. (전용 글자 Size 168)
- 제목 아래 가운데에 Start, Controls, Quit 버튼을 위에서부터 세로로 배치합니다. (글자 Large)
- 레벨이 열리면 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Start입니다.

#### 조작 안내

보스전에 들어가기 전에 키 배치와 누르기·누르고 있기의 차이를 확인할 수 있도록 Controls 버튼으로 여는 팝업에 조작 안내를 표시합니다.

- 게임을 처음 실행했을 때와 결과 UI에서 타이틀로 돌아왔을 때 팝업은 닫힌 상태입니다. Controls 버튼을 실행하면 레벨 전환 없이 팝업을 엽니다.
- 팝업은 화면 가운데에 배치하고 화면 여백 안에 들어오게 합니다. 뒤의 타이틀 화면은 어둡게 표시합니다.
- 패널 위쪽에 제목 'Controls'을 Large로 표시합니다. 본문은 Medium으로 표시하며, 글자를 읽을 수 있는 어두운 배경과 안쪽 여백 24px을 둡니다.
- [플레이어 입력](<플레이어 입력.md>)의 '키 배치' 표에 있는 모든 행동을 표의 순서대로 표시합니다. 키 배치와 행동의 의미는 해당 문서를 따릅니다.
- 각 항목은 왼쪽에 키, 오른쪽에 행동 이름을 표시합니다. 모든 항목의 행동 이름은 같은 위치에서 시작하고, 키와 행동 이름 사이는 24px을 띄웁니다.
- 키 이름은 [UI 스타일](<UI 스타일.md>)의 '입력 키 표시'를 따릅니다. '누르고 있기'는 키 이름에 붙이지 않고 아래 설명에 표시합니다.
- 가드 / 패리와 회피 / 달리기는 해당 항목 바로 아래에 '키 배치' 표의 누르기·누르고 있기 설명을 Small로 표시합니다. 문서 링크나 참조 문구는 화면에 표시하지 않습니다.
- 안내의 모든 항목과 설명은 한 화면에서 읽을 수 있게 표시합니다. 설명이 길면 줄바꿈하며, 스크롤이나 페이지 전환은 사용하지 않습니다.
- 안내 본문은 읽기 전용입니다. 팝업 아래쪽 가운데에 'Confirm' 버튼을 Large로 표시하며, 팝업을 열면 이 버튼이 선택됩니다.
- 팝업이 열려 있는 동안 마우스 커서를 표시하고 팝업만 입력을 받습니다. 뒤의 타이틀 버튼은 선택하거나 실행할 수 없으며, 팝업 바깥을 클릭해도 닫히지 않습니다.
- Confirm 버튼을 실행하면 팝업을 닫고 타이틀의 Controls 버튼으로 선택을 되돌립니다. 닫는 입력으로 뒤의 버튼이 함께 실행되지는 않습니다. 다시 Controls 버튼을 실행하면 팝업을 다시 열 수 있습니다.
- 전투 HUD의 조작 안내는 [전투 HUD](<전투 HUD.md>)를 따릅니다.

![조작 안내 팝업](<Attachments/조작 안내 팝업.svg>)

### Stage Clear UI / Game Over UI

| 항목 | Stage Clear UI | Game Over UI |
| - | - | - |
| 제목 문구 | STAGE CLEAR | GAME OVER |
| 버튼 | Try Again, Return to Title, Quit (세로 배치) | Try Again, Return to Title, Quit (세로 배치) |

- 글자 크기는 제목 Size 84(전용 글자), 버튼 Large입니다.
- 사망 연출이 끝나면 0.5초 동안 화면을 서서히 어둡게 하면서 결과 UI를 서서히 표시합니다. 버튼 입력은 표시가 끝난 뒤부터 받습니다.
- 결과 UI가 떠 있는 동안 게임은 멈추지 않으며, 플레이어 입력은 UI만 받습니다. 마우스 커서를 표시합니다.
- 처음 선택된 버튼은 Try Again입니다.

### UI 조작

| 동작 | 키 |
| - | - |
| 버튼 선택 | 마우스 이동, 또는 ↑·↓ |
| 실행 | 좌클릭, 또는 Enter, Space |
| 조작 안내 팝업 닫기 | Confirm 버튼 실행 |

- 맨 위나 맨 아래 버튼에서 더 넘어가는 방향을 누르면 선택이 그대로 멈춥니다. 반대쪽 끝으로 돌아가지 않습니다.
- 마우스와 키보드를 섞어 쓰면 마지막으로 움직인 장치를 따릅니다. 마우스를 버튼 위로 움직이면 그 버튼이 선택되고, 키보드는 지금 선택된 버튼에서 이어서 움직입니다.

## 플로우 차트

```mermaid
flowchart TD
    start([게임 시작]) -->|실행| title

    subgraph FE["LV_FrontEnd"]
        title["게임 제목 AG 출력"]
        startBtn[Start 버튼]
        controlsBtn[Controls 버튼]
        controlsPopup[조작 안내 팝업]
        quitBtn[Quit 버튼]
        title --> startBtn
        title --> controlsBtn
        title --> quitBtn
        controlsBtn -->|실행| controlsPopup
        controlsPopup -->|Confirm| controlsBtn
    end

    quitBtn -->|클릭| exitGame([게임 종료])
    startBtn -->|클릭| combat

    subgraph BOSS["LV_BossStage"]
        combat["보스 1명과 전투"]
        bossDeath[보스 사망 연출]
        playerDeath[플레이어 사망 연출]
        clearUI[Stage Clear UI]
        overUI[Game Over UI]
        clearRetry[Try Again]
        clearHome[Return to Title]
        clearQuit[Quit]
        overRetry[Try Again]
        overHome[Return to Title]
        overQuit[Quit]

        combat -->|보스 HP ≤ 0| bossDeath
        combat -->|플레이어 HP ≤ 0| playerDeath
        bossDeath -->|사망 연출 종료| clearUI
        playerDeath -->|사망 연출 종료| overUI
        clearUI --> clearRetry
        clearUI --> clearHome
        clearUI --> clearQuit
        overUI --> overRetry
        overUI --> overHome
        overUI --> overQuit
    end

    clearRetry -->|클릭| combat
    overRetry -->|클릭| combat
    clearHome -->|클릭| title
    overHome -->|클릭| title
    clearQuit -->|클릭| exitGame
    overQuit -->|클릭| exitGame
```
