# 용어집

기획과 구현에서 함께 사용하는 용어집입니다. 여러 문서에서 같은 뜻으로 써야 하거나 서로 구분해야 하는 용어를 정리합니다.

## 사용 규칙

1. 뜻이 헷갈리거나, 문서마다 다르게 쓰기 쉬운 용어만 등록합니다.
2. 문서에서는 등록된 용어의 뜻과 이름을 통일합니다.
3. 뜻은 짧게 설명하고, 수치와 세부 규칙은 해당 기획서에 적습니다.
4. 일상적인 말, 널리 쓰이는 표준 용어, 캐릭터·레벨·화면 이름은 별도 설명이 필요할 때만 등록합니다.
5. 쉽게 풀어 쓸 수 있는 내용에 새 용어를 만들지 않습니다.
6. 영문 표기는 이해를 돕기 위한 참고용입니다. 구현에서 이름을 정하면 용어집의 영문 표기도 그에 맞춰 갱신합니다.

## 전투 공통

정의 문서: [전투 시스템](<Design/System/전투 시스템.md>), [시간 규칙](<Design/System/시간 규칙.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 자원 | Resource | 전투 중 변화하는 캐릭터의 핵심 수치. HP(체력), SP(스태미나), MP(마나), UP(궁극기 포인트), PP(균형) |
| 효과 | Effect | 대미지, 자원 회복, 무적처럼 대상의 수치나 상태를 바꾸는 것. 구현의 GameplayEffect |
| 대미지 | Damage | 공격이 적중했을 때 HP와 PP를 감소시키는 효과 |
| 공격 판정 | Attack Check | 공격이 대상에게 닿았는지 검사하는 단위 하나 |
| 공격 방향 | Attack Direction | 기본 공격, 점프 공격, 회피 반격, 스킬의 각 타를 시작할 때 정하는 공격의 방향 |
| 피격 방향 | Hit Direction | 공격자에서 피격자를 향하는, 공격이 들어온 방향 |
| 추적 구간 | Tracking Window | 공격 중 대상을 향해 몸을 돌려 공격 방향을 보정하는 구간 |
| 무기 궤적 | Weapon Trail | 무기로 벨 때 날이 지나간 자리에 잠깐 남는 VFX |
| 선딜 / 판정 구간 / 후딜 | Startup / Attack Window / Recovery | 공격의 준비를 선딜, 공격 판정이 활성화된 구간을 판정 구간, 타격을 마친 뒤의 회복을 후딜이라 합니다. |
| 가드 불가 | Unblockable | 가드와 패리로 막을 수 없는 공격 |
| 피격 반응 | Hit Reaction | 공격에 맞았을 때 재생하는 반응의 종류. 없음, 움찔, 넉업, 넉다운 |
| 강인도 | Toughness | 일반 피격 반응에 의한 행동 중단 여부를 정하는 캐릭터 등급. 소형, 중형, 대형 |
| 슈퍼아머 | Super Armor | 일반 피격의 행동 중단과 가드 밀림·브레이크를 막는 버프 |
| 움찔 | Flinch | 짧은 피격 반응. 강인도와 슈퍼아머에 따라 행동을 중단하는 피격 모션이나 부위 흔들림으로 나타남 |
| 넉업 | KnockUp | 공중으로 떠올랐다가 떨어지는 피격 반응 (에어본, Airborne) |
| 넉다운 | KnockDown | 뒤로 크게 밀려나며 쓰러졌다가 일어나는 피격 반응 |
| 저글 | Juggle | 넉업으로 떠 있는 동안 움찔 공격에 맞아 그 높이에서 다시 떠오르는 것. 공중의 적을 계속 맞혀 띄워 둘 수 있습니다. |
| 가드 반응 | Guard Reaction | 가드로 공격을 막았을 때의 반응. 가드 움찔, 가드 밀림, 가드 브레이크가 있습니다. |
| 가드 움찔 | Guard Flinch | 가드 자세를 유지하면서 모션을 덧입히는 가드 반응 |
| 가드 밀림 | Guard Pushback | 피격 반응이 넉업·넉다운인 공격을 막았을 때 뒤로 밀려나는 반응 |
| 가드 브레이크 | Guard Break | 가드로 공격을 막을 때 SP가 부족해 가드가 풀리며 무방비가 되는 반응 |
| 그로기 | Groggy | PP가 0 이하가 되어 일정 시간 아무 행동도 할 수 없는 상태 |
| 히트스톱 | Hit Stop | 공격 적중이나 가드·패리 시 타격감을 위해 공격자와 피격자의 모션과 이동을 잠깐 멈추는 연출 |
| 게임 시간 / 실제 시간 | Game Time / Real Time | 게임 진행 속도(슬로우모션·시간 정지)의 영향을 받는 시간은 게임 시간, 현실의 흐름을 따르는 시간은 실제 시간이라 합니다. |

- 명사 '판정'은 대상을 명확히 붙여 씁니다. 공격 타격 단위는 '공격 판정', 공격이 활성화된 시간 구간은 '판정 구간'으로 쓰며, 방어와 피격 관련 상태는 '가드 판정', '패리 판정'(패리 가능 구간은 '패리 구간'), '무적 판정' 등으로 명시합니다.
- '경직'은 쓰지 않습니다. 공격 적중 시의 역경직(히트스톱)과 피격자의 피격 반응 사이에 용어 혼선이 생기기 쉽기 때문입니다. 공격 적중 시 멈추는 연출은 '히트스톱', 피격자의 동작 제한은 '피격 반응', 가드로 막았을 때의 반응은 '가드 반응', 균형 수치와 규칙은 'PP'로 구분해 씁니다.
- 플레이어가 공격하는 방향은 '공격 방향', 공격이 피격자에게 들어온 방향은 '피격 방향'으로 구분합니다.
- 시각 효과는 '효과'가 아니라 'VFX'로 씁니다. 코드와 데이터의 Effect는 GameplayEffect를 뜻합니다.

## 플레이어 액션

정의 문서: [플레이어 시스템](<Design/System/플레이어 시스템.md>), [플레이어 캐릭터 - 린](<Design/Content/플레이어 캐릭터 - 린.md>), [카메라와 타겟팅](<Design/System/카메라와 타겟팅.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 액션 | Action | 일반 이동(걷기·달리기)을 제외한 기본 공격, 점프, 회피, 가드, 스킬, 궁극기, 처형 등 버튼 입력으로 발동하는 개별 동작 단위 |
| 기본 공격 | Basic Attack | 플레이어가 기본 공격 키로 사용하는 연속 공격 |
| 극한 회피 | Perfect Dodge | 극한 회피 구간에 공격 판정이 닿아 공격을 피해 내는 것 |
| 극한 회피 구간 | Perfect Dodge Window | 회피를 시작한 직후 극한 회피가 가능한 짧은 구간 |
| 회피 반격 | Dodge Counter | 극한 회피로 얻은 반격 기회가 남아 있을 때 기본 공격 키로 사용하는 공격 |
| 패리 | Parry | 적의 공격 타이밍에 맞춰 가드를 올려 공격을 막아내고 공격자의 PP를 깎는 액션 |
| 패리 구간 | Parry Window | 가드를 새로 시작한 직후 패리가 가능한 짧은 구간 |
| 처형 | Execution | 그로기 상태의 적에게 접근해 큰 대미지를 주는 전용 공격 액션 |
| 타겟팅 | Targeting | 공격·처형 등 액션의 대상이나 공격 중 위치·회전 보정 대상을 조건에 따라 찾는 것 |
| 락온 | Lock-On | 특정 상대를 계속 대상으로 붙잡아 두는 것. 플레이어는 조작으로 락온하며 카메라와 조준을 그 적에게 고정합니다. 락온 중에는 타겟팅 범위 안의 다른 상대보다 락온 대상을 우선합니다. |

- '공격'은 일반적인 뜻(보스의 공격, 공격 판정 등)으로만 씁니다. 플레이어의 연속 공격은 '평타'나 '일반 공격' 대신 '기본 공격'으로 씁니다.
- 조작과 입력 규칙에서 '이동'만 쓰면 방향키 조작에 의한 일반 이동(걷기·달리기)을 가리킵니다.
- 피격 시 발생하는 물리적 충격 반응(움찔·넉업·넉다운)은 '피격 반응'으로, 그로기·처형 피격처럼 일정 시간 조작 권한이나 캐릭터 성질이 제약되는 모드는 '상태'로 구분해 씁니다.
- 기획서에서 조작 제한이나 캔슬을 서술할 때는 모호한 '행동' 대신 '모든 조작 불가(이동 및 액션 불가)', '액션 불가(이동만 가능)', '액션으로만 캔슬 가능'처럼 대상을 명확히 밝힙니다.
- '대시'는 회피와 달리기 중 무엇인지 모호하므로 쓰지 않습니다.
- '타겟팅'은 각 액션 시점에 대상을 찾는 일시적인 처리이고, '락온'은 특정 상대를 계속 붙잡아 두는 것입니다. 플레이어의 락온은 시점과 조준을 유지하는 독립된 조작입니다.

- 다른 액션의 입력으로 전환하는 것은 '모션 캔슬', 피격·사망으로 액션이 끊기는 것은 '중단'으로 구분합니다.

| 가드 불가 예고 | Unblockable Telegraph | 가드 불가 공격 직전에 무기에 표시하는 예고 VFX와 효과음 |
| 패리 예고 | Parry Telegraph | 가드 가능한 적 공격 직전에 무기에 표시하는 예고 VFX와 효과음. 가드 불가 예고와 색과 효과음으로 구분합니다. |
| 처형 피격 | Executed | 적이 처형당하고 있는 상태 |

- 적의 행동은 '패턴'으로 씁니다. '스킬'은 플레이어의 스킬에만 씁니다.
