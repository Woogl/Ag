# 용어집

기획과 구현에서 함께 사용하는 용어집입니다. 여러 문서에서 같은 뜻으로 써야 하거나 서로 구분해야 하는 용어를 정리합니다.

## 사용 규칙

1. 뜻이 헷갈리거나, 문서마다 다르게 쓰기 쉬운 용어만 등록합니다.
2. 문서에서는 등록된 용어의 뜻과 이름을 통일합니다.
3. 뜻은 짧게 설명하고, 수치와 세부 규칙은 해당 기획서에 적습니다.
4. 일상적인 말, 널리 쓰이는 표준 용어, 캐릭터·레벨·화면 이름은 별도 설명이 필요할 때만 등록합니다.
5. 쉽게 풀어 쓸 수 있는 내용에 새 용어를 만들지 않습니다.
6. 영문 표기는 이해를 돕기 위한 참고용입니다. 구현에서 이름을 정하면 용어집의 영문 표기도 그에 맞춰 갱신합니다.

스탯 표기는 [전투 시스템](<Design/전투 시스템.md>)의 '스탯'을, 구현 우선순위 표기는 [마일스톤1 계획](<Design/마일스톤1 계획.md>)의 '구현 우선순위'를 따릅니다.

## 전투 공통

정의 문서: [전투 시스템](<Design/전투 시스템.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 대미지 | Damage | 공격이 적중했을 때 HP와 PP를 감소시키는 효과 |
| HP 감소량 | HPDamage | 대미지로 줄어드는 HP의 양 |
| PP 감소량 | PPDamage | 대미지로 줄어드는 PP의 양 |
| 대미지 배율 | DamageMultiplier | 공격마다 정하는 HP 감소량 배율 |
| PP 배율 | PoiseMultiplier | 공격마다 정하는 PP 감소량 배율 |
| 가드 경감 배율 | GuardReduction | 가드로 막았을 때 HP 감소량에 곱하는 경감 배율 |
| 타 | Hit | 공격 판정 하나를 세는 단위 (1타, 2타) |
| 공격 판정 | Attack Check | 공격이 대상에게 닿았는지 검사하는 단위 하나 |
| 선딜 / 판정 구간 / 후딜 | Startup / Active / Recovery | 공격의 준비를 선딜, 공격 판정이 활성화된 구간을 판정 구간, 타격을 마친 뒤의 회복을 후딜이라 합니다. |
| 리젠 대기 시간 | Regen Delay | 자원이 줄어든 뒤 자동 회복이 시작되기까지의 시간 |
| 무적 | Invincible | 공격에 맞아도 대미지와 피격 반응을 받지 않는 상태 |
| 가드 | Guard | 공격을 막아 대미지를 경감하는 행동 |
| 가드 불가 | Unblockable | 가드와 패리로 막을 수 없는 공격 속성 |
| 피격 반응 | Hit Reaction | 공격에 맞았을 때 재생하는 반응의 종류. 없음, 움찔, 넉백, 다운 |
| 움찔 | Flinch | 하던 행동을 끊지 않고 모션만 덧입혀 재생하는 피격 반응 |
| 넉백 | KnockBack | 뒤로 크게 밀려나는 피격 반응 |
| 다운 | KnockDown | 쓰러졌다가 일어나는 피격 반응 |
| 가드 반응 | Guard React | 가드로 공격을 막았을 때의 반응. 가드 움찔과 가드 밀림이 있습니다. |
| 가드 움찔 | Guard Flinch | 피격 반응이 움찔인 공격을 막았을 때의 반응 |
| 가드 밀림 | Guard Pushback | 공격을 가드로 막았을 때 뒤로 밀려나는 반응 |
| 슈퍼아머 | SuperArmor | 넉백, 다운을 무시하고 하던 행동을 계속하는 상태 |
| 그로기 | Groggy | PP가 0 이하가 되어 일정 시간 아무 행동도 할 수 없는 상태 |

- 공격에 관한 '판정'은 무엇을 가리키는지 구분해 씁니다. 공격 하나는 '공격 판정', 공격 모션의 구간은 '판정 구간', 패리가 가능한 구간은 '패리 구간'입니다.
- '경직'은 쓰지 않습니다. 가드로 막았을 때의 반응은 '가드 반응', PP에 관한 값과 규칙은 'PP'로 씁니다.

## 플레이어 행동

정의 문서: [플레이어 사양](<Design/플레이어 사양.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 평타 | Basic Attack | 평타 키로 사용하는 연속 공격 |
| 회피 | Dodge | 공격을 피하기 위해 빠르게 이동하며 잠깐 무적이 되는 행동 |
| 극한 회피 | Perfect Dodge | 극한 회피 구간에 공격을 피해 내는 것 |
| 극한 회피 구간 | Perfect Dodge Window | 회피를 시작한 직후 극한 회피가 가능한 짧은 구간 |
| 회피 반격 | Dodge Counter | 극한 회피로 얻은 반격 기회가 남아 있을 때 평타 키로 사용하는 공격 |
| 가드 브레이크 | Guard Break | 가드 중 SP가 부족해 가드가 강제로 풀리는 것 |
| 패리 | Parry | 패리 구간에 공격을 받아 내는 것 |
| 패리 구간 | Parry Window | 가드를 새로 시작한 직후 패리가 가능한 짧은 구간 |
| 실제 시간 | Real Time | 슬로우모션 등 속도 변화의 영향을 받지 않는 현실의 시간 |
| 스킬 | Skill | MP를 소모하는 공격 |
| 궁극기 | Ultimate | UP를 모두 소모하는 강력한 공격 |
| 처형 | Execution | 그로기 상태의 보스에게 사용하는 마무리 공격 |
| 락온 | Lock-On | 보스를 대상으로 고정해 캐릭터와 카메라의 방향을 맞추는 기능 |
| 공격 보정 | SnapToTarget | 공격할 때 대상 쪽으로 방향을 맞추고, 필요하면 대상에게 다가가도록 돕는 기능 |
| 타겟팅 범위 | Targeting Range | 공격 보정, 락온, 처형의 대상을 찾거나 선택하는 범위 |
| 모션 캔슬 | Motion Cancel | 플레이어가 다른 행동을 입력해, 진행 중인 행동의 모션을 끝내고 새 행동으로 전환하는 것 |

- '공격'은 일반적인 뜻(보스의 공격, 공격 판정 등)으로만 씁니다. 플레이어가 평타 키로 쓰는 연속 공격은 '평타'로 씁니다.
- '대시'는 회피와 달리기 중 무엇인지 모호하므로 쓰지 않습니다.
- 다른 행동의 입력으로 전환하는 것은 '모션 캔슬', 피격·사망으로 행동이 끊기는 것은 '중단'으로 구분합니다.

## 보스·AI

정의 문서: [보스 사양](<Design/보스 사양.md>)

| 용어 | 영문 표기 | 뜻 |
| - | - | - |
| 페이즈 전환 | Phase Transition | 다음 페이즈로 넘어갈 때 재생하는 전환 연출 |
| 패턴 | Pattern | 보스의 행동 단위. 공격 패턴과 보조 행동이 있습니다. |
| 거리 구간 | Range Band | 패턴을 고르는 기준이 되는 거리 구분. 근거리, 중거리, 원거리 |
| 패턴 후딜레이 | Pattern Recovery | 패턴, 그로기, 페이즈 전환 등이 끝난 뒤 다음 패턴을 고르기 전까지 기다리는 시간 |
| 패턴 전조 동작 | Wind-up | 공격 타이밍을 읽을 수 있도록 패턴의 선딜 동안 보여 주는 큰 준비 동작 |
| 붉은 섬광 | Unblockable Telegraph | 가드 불가 공격 직전에 무기에 표시하는 예고 이펙트 |
| 처형 피격 | Executed | 보스가 처형당하고 있는 상태 |

- 보스의 행동은 '패턴'으로 씁니다. '스킬'은 플레이어의 스킬에만 씁니다.
