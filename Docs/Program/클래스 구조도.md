# 클래스 구조도

게임 코드(`Source/Ag`)의 클래스마다 부모와 역할을 표로 적고, 클래스가 서로 어떻게 이어지는지 그림으로 보여 줍니다. 그렇게 만든 이유는 같은 폴더의 주제별 구현 계획서를 따릅니다.

클래스를 더하거나 빼거나, 클래스의 역할이나 클래스 사이의 관계를 바꾸면 이 문서도 함께 고칩니다.

## 그림 읽는 법

- 클래스 그림의 선은 아래 뜻입니다. 선 위의 글은 필드 이름이나 함수 이름입니다.
  - 속이 빈 삼각형: 상속. 삼각형 쪽이 부모입니다. 점선이면 인터페이스 구현입니다.
  - 검은 마름모: 소유. 마름모 쪽이 컴포넌트나 구조체를 가지고 있습니다.
  - 실선 화살표: 참조. 화살표 쪽 클래스나 에셋을 필드로 가리킵니다.
  - 점선 화살표: 사용. 필드 없이 함수를 부르거나, 게임플레이 이벤트를 보내거나, 액터를 생성합니다.
- 클래스 상자 안의 줄은 엔진 클래스를 가리키는 주요 필드(타입, 이름)입니다.
- 클래스 이름 위 « » 안의 글은 그 클래스로 만든 에셋이나, 그 클래스가 맡는 기획서 항목입니다. «interface», «struct», «enum»은 C++ 종류입니다.
- `BP_`, `WBP_`, `ABP_`, `GC_`로 시작하는 이름은 블루프린트이고, `DA_`로 시작하는 이름은 데이터 에셋입니다. `.json`으로 끝나는 이름은 프로젝트 `Data` 폴더의 데이터 파일입니다.
- 이름에 `Ag`가 없는 클래스는 엔진과 플러그인 클래스입니다.
- 게임플레이 태그(`AgGameplayTags`)는 거의 모든 클래스가 쓰므로 그리지 않습니다. 에디터에서만 쓰는 코드는 게임에 들어가지 않아 그리지 않습니다.

## 캐릭터

플레이어·보스 캐릭터와 컴포넌트, 보스를 움직이는 AI 컨트롤러입니다.

| 클래스 | 부모 | 역할 |
| - | - | - |
| `AAgCharacterBase` | `ACharacter`, `IAbilitySystemInterface` | 플레이어·보스 공통. ASC, 어트리뷰트, 무기와 공격 판정(무기 스윕), 정지 간격(루트 모션 자르기), 회전과 바라보는 방향이 고정되는 때, 공격 중 이동의 대상(`FindAttackTarget`)과 범위 밖 타의 회전 대상(`GetFallbackFacingTarget`), 움찔, 히트스톱 중의 시간 배율, 사망 처리 |
| `AAgPlayerCharacter` | `AAgCharacterBase` | 카메라, 락온, 대상 찾기, 입력 매핑, 입력을 어빌리티로 연결 |
| `AAgBossCharacter` | `AAgCharacterBase` | 페이즈 같은 보스 상태, 회전 대상(AI 대상)과 회전하지 않는 상태. 보스에 표시하는 월드 위치 HUD(락온 마커, 처형 안내) |

## 보스 AI

보스 AI의 흐름(상태와 전환)은 StateTree 에셋 `ST_Boss`에 있어 에디터에서 그림으로 봅니다. 아래는 그 에셋을 실행하는 코드입니다. 태스크와 조건은 모두 `Controller`(Context 속성)로 `AAgBossAIController`를 받아 보스, 보스 데이터, 현재 대상(`GetTarget`)을 읽으며, 그 선은 그리지 않습니다.

| 클래스 | 부모 | 역할 |
| - | - | - |
| `AAgBossAIController` | `AAIController` | 보스 AI. 현재 대상을 정하고, StateTree AI 컴포넌트로 `ST_Boss`를 실행하고, 이 보스가 대상인 플레이어의 평타 시작을 StateTree 이벤트로 넘깁니다. |
| 보스 AI 태스크 | `FStateTreeAITaskBase` | 패턴 후딜레이 대기, 다가가기, 패턴 실행(선택 포함), 페이즈 전환, 피격 반응 대기, 비전투 |
| 보스 AI 조건 | `FStateTreeAIConditionBase` | 보스 사망, 플레이어 사망, 피격 반응 중, 페이즈 전환 시작 조건, 백스텝 발동 조건 |

## 어빌리티

모든 어빌리티는 `UGameplayAbility`를 상속한 `UAgGameplayAbility`를 바로 상속하고, 여러 어빌리티가 함께 쓰는 동작은 어빌리티 태스크로 씁니다([캐릭터와 GAS](<캐릭터와 GAS.md>) '어빌리티 구조'). 플레이어 행동, 상태, 보스 패턴으로 나눠 그립니다.

| 클래스 | 부모 | 역할 |
| - | - | - |
| `UAgGameplayAbility` | `UGameplayAbility` | 모든 어빌리티의 부모([캐릭터와 GAS](<캐릭터와 GAS.md>) '어빌리티 구조'). 캐릭터 데이터 읽기, 쿨다운과 비용(보스 패턴은 패턴별), 플레이어 행동·피격 반응·보스 패턴의 태그(상태별 허용 입력, 모션 캔슬, 상태 우선순위) |
| `UAgAbilityTask_WaitMontagePosition` | `UAbilityTask` | 몽타주 재생 위치가 정한 시간에 닿을 때까지 기다립니다(기획서에 초로 적힌 구간). |
| `UAgAbilityTask_HoldTag` | `UAbilityTask` | 도는 동안 상태 태그 하나를 붙여 둡니다(행동 중, 무적·극한 회피 구간, 가드 중, 패리 모션, 보스의 회전 정지). 어빌리티가 끝내거나 어빌리티가 끝나면 뗍니다. |
| `UAgAbilityTask_Dash` | `UAbilityTask` | 일정 속도로 직선 이동하고, 거리를 다 가거나 벽에 막히거나 어빌리티가 멈추면 끝납니다(돌진 찌르기의 돌진). |
| `UAgAbilityTask_LockOn` | `UAbilityTask` | 락온 중 매 프레임 카메라를 대상의 락온 지점 쪽으로 돌리고, 해제 조건이 되면 끝납니다. |
| `UAgAbilityTask_AttackMovement` | `UAbilityTask` | 공격 중 이동. 타를 시작할 때마다 대상을 다시 정해 정지 간격과 회전 대상(범위 밖이면 캐릭터가 정한 대체 대상)을 걸고, 매 프레임 워프 목표를 대상 앞 간격 지점에 두다가 바라보는 방향이 고정되면 함께 고정합니다. 끝나면 모두 지웁니다([애니메이션과 이동](<애니메이션과 이동.md>) '공격 중 이동'). |
| `UAgAbilityTask_Attack` | `UAbilityTask` | 판정 구간이 있는 공격 하나(평타 한 타, 점프 공격, 회피 반격, 스킬, 보스 공용 패턴). 공격 데이터를 판정 구간에 걸고 몽타주를 재생하며 공격 중 이동 태스크를 시작합니다. 마지막 판정 구간의 끝(후딜 시작), 모션의 끝, 끊김을 어빌리티에 알립니다([전투 규칙](<전투 규칙.md>) '공격 진행'). |
| `UAgAbilityTask_PlayReaction` | `UAbilityTask` | 피격 반응 모션. 반응 몽타주와 이어지는 몽타주(넉업의 기상)를 재생하고, 마지막 모션의 끝과 끊김을 어빌리티에 알립니다. 바닥에 쓰러진 순간부터 끝날 때까지 무적입니다. |
| `UAgAbilityTask_IgnoreRootMotion` | `UAbilityTask` | 도는 동안 몽타주의 루트 모션을 무시합니다. 루트 모션 소스로 옮기는 동안 씁니다(돌진 찌르기의 돌진, 넉업). |
| `UAgAbilityTask_IgnoreCollision` | `UAbilityTask` | 도는 동안 주인의 루트 충돌 컴포넌트(캐릭터는 캡슐)가 인자로 받은 충돌 채널을 무시합니다(돌진 찌르기의 돌진과 처형 피격은 Pawn 채널을 무시해 플레이어를 막지 않음). 끝나면 원래 응답으로 되돌리고, 그사이 죽었으면 사망 처리가 정한 대로 둡니다. |
| `UAgAbilityTask_PlayCutscene` | `UAbilityTask` | 컷신(레벨 시퀀스) 하나를 기준 액터의 위치·방향으로, 시네마틱 모드로 재생합니다. 시간 정지 중에는 정상 속도로 재생하고, 끝나면 알립니다. |
| `UAgAbilityTask_TimeStop` | `UAbilityTask` | 도는 동안 주인만 빼고 시간을 멈춥니다(궁극기, [전투 규칙](<전투 규칙.md>) '시간 정지'). 끝나면 시간 정지를 끕니다. |

### 플레이어 행동

판정 구간이 있는 공격 행동(평타, 점프 공격, 회피 반격, 스킬)은 공격 태스크로 공격 데이터, 몽타주, 공격 중 이동을 처리합니다. 보스 공용 패턴도 같은 태스크를 씁니다.

| 클래스 | 부모 | 역할 |
| - | - | - |
| 플레이어 행동 어빌리티 | `UAgGameplayAbility` | 평타, 회피, 회피 반격, 가드·패리, 스킬, 궁극기, 처형, 달리기, 점프, 점프 공격 |
| `UAgAbility_LockOn` | `UAgGameplayAbility` | 락온. 락온 키로 시작하고 끝나며, 실행 중에는 락온 태스크를 돌립니다. 행동이 아니라서 행동 상태의 제한과 취소를 받지 않습니다. |

### GameplayEffect

GameplayEffect는 모두 C++ 클래스입니다. 대미지 GameplayEffect는 공격하는 쪽(무기 스윕, 검기, 도약 내려찍기의 착지, 처형, 궁극기 마무리)이 적용하고, 피격 처리는 그 안에서 끝납니다. 계산 클래스가 피격 결과를 정해 스펙 태그로 남기고, 어트리뷰트 세트가 사망·그로기를 판정하며, 결과 처리 컴포넌트가 반응과 적중 후 처리를 합니다. 행동 비용은 어빌리티의 비용 GameplayEffect로 엔진이 치르고, 자원 얻기, PP 회복, 패리로 잃는 PP는 그 일을 하는 어빌리티나 결과 처리 컴포넌트가 적용합니다. 시간 태그 GameplayEffect는 그 클래스의 함수(`Apply`)로 적용하고, 리젠 GameplayEffect는 캐릭터가 시작할 때 캐릭터 데이터의 목록(`RegenEffects`)대로 겁니다. 리젠의 회복량은 크기 계산 클래스가 주기마다 캐릭터 데이터에서 읽습니다.

| 클래스 | 부모 | 역할 |
| - | - | - |
| `UAgEffect_Damage` | `UGameplayEffect` | 공격 하나의 적중. 적용하면 피격 처리가 그 안에서 끝납니다(죽은 대상 제외, 계산 클래스, 결과 처리 컴포넌트). 공격 데이터 1타를 스펙에 담는 함수가 있습니다. |
| `UAgDamageExecution` | `UGameplayEffectExecutionCalculation` | 피격 처리 순서와 대미지 계산식. 대상의 상태 태그로 결과를 정해 HP·PP·SP를 바꾸고, 결과를 스펙 태그로 남깁니다. |
| `UAgHitResultGameplayEffectComponent` | `UGameplayEffectComponent` | 대미지 GameplayEffect의 결과 처리. 피격 반응, 막힘 알림, 적중 후 처리(이펙트와 효과음, 셰이크, 대미지 숫자, 히트스톱, MP·UP 충전) |

## 주요 흐름

클래스 그림만으로는 보이지 않는 실행 순서입니다.

### 입력에서 행동까지

이동은 캐릭터 무브먼트로 갑니다. 락온 키는 선입력과 행동 제한을 거치지 않고 바로 `RunInput`으로 가서 락온 어빌리티를 시작하거나 끝냅니다. 나머지 행동 키는 아래처럼 어빌리티로 갑니다.

```mermaid
sequenceDiagram
    participant In as Enhanced Input
    participant P as AAgPlayerCharacter
    participant ASC as 플레이어 ASC
    participant GA as 행동 어빌리티
    In->>P: 행동 키
    P->>P: HandleInputPressed<br>막혀 있으면 선입력으로 기억
    P->>P: RunInput
    alt 이 키를 받는 어빌리티가 실행 중
        P->>ASC: 입력 태그의 게임플레이 이벤트
        ASC->>GA: 이벤트 전달<br>(평타 다음 타, 패리 모션 중 가드)
    else 그 밖
        P->>ASC: TryActivateAbilitiesByTag
        ASC->>GA: 막는 태그가 없으면 시작
    end
    Note over P: 행동이 다시 허용되면<br>기억한 입력을 RunInput으로 다시 처리
```

### 공격 판정과 피격 처리

```mermaid
sequenceDiagram
    participant GA as 공격 어빌리티<br>(플레이어 공격과 보스 공용 패턴은 공격 태스크)
    participant A as 공격자
    participant N as 판정 구간 노티파이
    participant G as 대미지 GameplayEffect
    participant T as 맞은 캐릭터
    GA->>A: SetActiveAttack
    GA->>A: 몽타주 재생
    N->>A: BeginAttackWindow
    loop 판정 구간 동안 매 프레임
        A->>A: 무기 날 스윕
        opt 상대 메시에 처음 닿음
            A->>G: ApplyAttack
            G->>T: 피격 결과, HP·PP·SP 변화(계산 클래스)
            Note over T: HP·PP가 0 이하면 사망·그로기 이벤트<br>(어트리뷰트 세트)
            G->>T: 상태 어빌리티 이벤트<br>또는 PlayFlinch(결과 처리 컴포넌트)
            G->>T: GameplayCue<br>(이펙트와 효과음, 셰이크, 대미지 숫자)
            G->>A: 히트스톱 태그 GameplayEffect
            G->>T: 히트스톱 태그 GameplayEffect
        end
    end
    N->>A: EndAttackWindow
    N-->>GA: Event.AttackWindowEnded
```

검기는 `AAgSwordWave`가, 도약 내려찍기의 착지는 `UAgBossPattern_Leap`이 같은 함수(`ApplyAttack`)로 대미지 GameplayEffect를 적용합니다. 처형의 타격은 `UAgAbility_Execution`이 스펙을 만들어 공격을 담고(`SetAttack`) 적용하며, 엔진이 스펙에 넣는 처형 어빌리티 태그로 처형의 셰이크와 히트스톱 없음이 정해집니다.

### 보스 패턴 실행

```mermaid
sequenceDiagram
    participant T as 패턴 실행 태스크<br>FAgBossAITask_RunPattern
    participant B as AAgBossCharacter
    participant ASC as 보스 ASC
    participant GA as 패턴 어빌리티
    T->>T: GatherCandidates, PickWeighted
    T->>B: FindPatternSpec (패턴 ID)
    T->>ASC: TryActivateAbility
    ASC->>GA: 시작
    GA->>B: FindPattern (스펙의 패턴 ID)
    GA->>GA: 공격 태스크<br>(공격 데이터, 몽타주, 공격 중 이동)
    GA-->>ASC: 모션이 끝나면 끝남
    T->>ASC: 매 프레임 스펙이 실행 중인지 확인
    Note over T: 끝났으면 성공 →<br>ST_Boss가 패턴 뒤 대기로 넘어감
```

백스텝은 컨트롤러가 대상(플레이어) ASC의 `Event.BasicAttackStarted` (평타의 각 타와 점프 공격의 시작) 가운데 그 공격의 대상이 자기 보스인 것을 StateTree 이벤트로 넘기면 패턴 후딜레이 상태의 전환이 백스텝 상태로 보내 시작하고, 페이즈 전환은 페이즈 전환 태스크가 보스에게 `Event.PhaseTransition`을 보내 시작합니다.

### 사망에서 결과 UI까지

```mermaid
sequenceDiagram
    participant C as 죽는 캐릭터
    participant D as UAgAbility_Death
    participant GM as AAgBossStageGameMode
    participant PC as AAgPlayerController
    participant R as UAgResultScreen
    Note over C: Event.Death를 받음
    C->>D: 이벤트로 시작
    D->>C: Die
    C-->>GM: OnDied
    GM->>PC: HideHUD
    Note over GM: 사망 연출 시간 뒤
    GM->>PC: ShowResult
    PC->>R: PushScreen, SetResult
    R->>GM: 버튼에 따라<br>RestartStage 등
```

`Event.Death`는 GameplayEffect가 HP를 0 이하로 만들 때 어트리뷰트 세트(`PostGameplayEffectExecute`)가 보냅니다. 대미지 GameplayEffect와, `Kill`(Kill Z 낙하, 테스트용 콘솔 명령)이 적용하는 HP를 0으로 만드는 GameplayEffect가 모두 이 판정을 거칩니다. 보스와 플레이어의 사망은 StateTree의 전환 조건이 매 프레임 확인해, 보스 AI가 각각 사망 상태와 비전투 상태로 넘어갑니다.
