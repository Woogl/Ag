# 애니메이션 GIF 촬영

## 구현

시퀀스 미리보기의 출력 조건은 [GIF 안내](<../Art/GIF/README.md>)를 따릅니다. 실행 방법은 [촬영 도구](<../../Scripts/AnimationGifs/README.md>)를 따릅니다.

- 외부 실행기가 시퀀스 목록과 게임 BP의 무기 기본값을 조회하고, 목록과 출력 경로를 실행별 작업 파일에 기록해 에디터에 한 번 전달합니다. 에디터 파이썬의 틱 콜백이 목록을 순서대로 처리합니다. 프레임별 MCP 호출과 Base64 전송은 사용하지 않습니다.
- 임시 스켈레탈 메시와 SceneCapture2D, Render Target을 재사용합니다. 윤곽의 계단 현상을 줄이기 위해 이미지 영역의 가로·세로 2배로 렌더링하고 외부에서 Lanczos 축소·제목 띠 합성을 합니다. 처음·끝 멈춤은 GIF 표시 시간으로 처리합니다. 전체 에디터 뷰포트는 촬영하지 않습니다. 기존 촬영의 카메라 방향·거리와 크롭 비율을 시야각으로 환산합니다.
- 자세를 지정한 뒤 에디터가 뼈와 부착물을 갱신할 틱을 거쳐 촬영합니다. 시퀀스의 루트 잠금은 원본 에셋을 바꾸지 않고 임시 컴포넌트의 변환으로 보정합니다. 노티파이는 실행하지 않습니다.
- 에디터는 PNG 프레임과 시퀀스 완료 표식을 출력합니다. 별도 프로세스가 완료 표식을 받아 배경 정리·라벨 합성·팔레트 변환·GIF 저장을 수행합니다. GIF는 임시 파일로 완성한 뒤 교체합니다.
- 같은 자세·카메라로 색상과 불투명도 마스크를 각각 캡처합니다. 마스크는 SceneColor HDR의 역불투명도 알파를 사용합니다. 몸통의 검은 부분을 배경으로 지우는 색상 키잉은 사용하지 않습니다. 마스크로 배경을 합성한 뒤 축소하며, 팔레트는 시퀀스 전체 구간에서 뽑은 256색을 공유해 프레임 간 색 변화도 줄입니다.
- 첫 프레임 전에 같은 자세로 준비 렌더링을 해 노출·반사를 안정화합니다. SceneCapture는 고정 수동 노출을 사용하고 시간 누적 안티앨리어싱과 모션 블러를 끕니다. 원래 뷰포트와 조명·윤곽이 픽셀 단위로 같지는 않습니다. 구도는 [GIF 안내](<../Art/GIF/README.md>)의 '캡처 조건'을 따릅니다.
- 실행별 작업 폴더와 에디터 내 중복 실행 방지로 작업 충돌을 막습니다. 취소·실패 시 콜백과 임시 액터를 제거하고 백그라운드 CPU 제한을 복원합니다. 사용자 에셋과 레벨은 저장하지 않습니다.
- 완료된 GIF만 건너뛰며, 재생성은 명시적인 옵션으로 요청합니다. 중간 프레임은 실행 폴더에 남겨 실패한 변환을 다시 실행할 수 있습니다.

이는 에디터용 제작 도구이며 게임 로직, PIE, 게임 창을 사용하지 않습니다.

## 사양 문서의 조합 GIF

`Scripts/MotionImages/assemble.py`는 촬영된 시퀀스 GIF를 읽어 기존 `sheets`의 구간·배속·자세 유지·반복 순서대로 조립합니다. 에디터 연결이나 재촬영은 필요하지 않습니다. 원본의 시작·끝 감상용 멈춤을 제거하고 조합 전체에만 기존 멈춤을 적용합니다. 원본의 상단 제목 띠를 그대로 포함하며, 설명 문구·주요 프레임 테두리를 추가하지 않습니다. 설명은 사양 문서 본문에 둡니다.

원본 GIF의 캐릭터·무기·구도를 그대로 사용하므로, 다른 팩의 모션을 조합하면 해당 팩의 미리보기 캐릭터와 무기가 표시됩니다. 20fps 원본에서 가장 가까운 자세를 선택하며, 기존 640×574 원본과 새 480×431 원본을 모두 읽습니다. 원본 파일은 유지하고 큰 원본만 정보 띠 포함 480×431로 Lanczos 축소하며, 같은 크기의 원본은 축소하지 않습니다. 축소 후 각 원본 프레임의 팔레트로 색을 매핑해 최종 GIF를 한 번 저장합니다. 파일마다 팔레트를 하나로 다시 줄이지 않습니다. 실행 방법은 [모션 그림 도구](<../../Scripts/MotionImages/README.md>)를 따릅니다.
