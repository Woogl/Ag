# 입력 처리

실행 구조와 기능별 고정 Params는 [AbilityTask 기반 어빌리티 설계안](<AbilityTask 기반 어빌리티 설계안.md>)을 따릅니다.

플레이어 입력(키 배치, 상태별 허용 입력, 선입력, 모션 캔슬)을 어떻게 구현할지 정합니다.

## 기술 결정

| 항목 | 결정 | 이유 |
| - | - | - |
| 입력 | Enhanced Input 입력 에셋 10개(이동, 시야, 평타, 가드, 회피·달리기, 점프, 스킬, 궁극기, 처형, 락온)를 둡니다. 행동 키는 입력 바인딩이 입력 태그를 함께 넘겨 함수 하나가 처리합니다(바인딩하는 때는 [캐릭터 초기화](<캐릭터 초기화.md>) '입력 연결'). 평타 키 처리 순서, 가드 키를 누른 채 후딜이 시작되거나('행동 중' 태그가 풀림) 행동이 끝났을 때의 자동 가드, 행동 모션 실행 기록과 패리 구간에 따른 이동 입력 제한는 플레이어 캐릭터의 C++ 입력 처리에서 합니다. 가드 밀림 뒤의 자동 가드는 게임플레이 이벤트(`Event.Guard.Resume`)로 가드 어빌리티를 시작하고, 가드 어빌리티는 이 이벤트로 시작했을 때 패리 구간을 열지 않습니다. | 패리 구간을 열지 말지가 시작하는 방법에 실려 와서, 캐릭터에 일회용 상태를 두지 않습니다. |
| 모션 캔슬 | 행동 Ability는 후딜 전까지 `State.Busy`를 유지하고, 이동을 제한하는 행동 모션은 실제 재생 기록으로 조회합니다. 새 행동은 Busy가 없을 때 발동해 진행 중인 행동을 취소합니다. 회피 후딜의 재입력은 회피를 다시 시작합니다. 이동 제한은 해당 모션의 블렌드 아웃을 포함한 종료까지 유지하며, 일반 점프·착지·가드 유지·Sprint에는 이 기록으로 새 제한을 걸지 않습니다. 가드 시작의 이동 제한은 `State.ParryWindow`와 같습니다. 후딜 알림과 모션 연결은 [애니메이션과 이동](<애니메이션과 이동.md>)을 따릅니다. | Busy와 실제 모션의 수명은 다릅니다. 별도 모션 태그를 복제하지 않고, 모션의 완료·중단 시점에 기록을 정리합니다. 피격 반응·그로기·페이즈 전환도 자연 완료까지 유지하며 넉업의 기상은 앞 모션의 블렌드 아웃에서 잇습니다. |
| 선입력 | 플레이어 캐릭터가 입력을 받을 때 '행동 중'이나 피격 반응 태그가 있으면, 그 입력 하나와 누른 시각(월드 시간)을 기억합니다. 점프 중의 평타 키는 점프 공격으로 허용되므로 기억하지 않습니다([애니메이션과 이동](<애니메이션과 이동.md>) '점프 공격'). 입력은 그때도 그대로 처리하므로 허용되지 않은 행동은 시작하지 않고, 진행 중인 어빌리티가 받는 입력(패리 모션 중의 가드)은 그대로 받습니다. 두 태그가 풀리면 다음 프레임에 기억한 입력을 다시 처리하고, 기억하는 시간이 지났거나 가드 키를 뗐으면 버립니다. 가드 키를 누른 채 후딜이 시작되거나 행동이 끝나 가드를 시작할 때도 기억한 입력을 먼저 처리합니다. | 입력이 한 함수로 모이고 허용되는 순간이 태그 두 개로 드러나, 행동 어빌리티를 고치지 않아도 됩니다. 다음 프레임에 처리해야 같은 프레임에 이어지는 상태(평타의 후딜 표시, 행동을 끊은 피격 반응)가 반영됩니다. 월드 시간은 히트스톱 중에도 흐릅니다. |

## 클래스 구조

### 입력에서 행동까지

이동은 캐릭터 무브먼트로 갑니다. 락온 키는 선입력과 행동 제한을 거치지 않고 바로 `RunInput`으로 가서 락온 어빌리티를 시작하거나 끝냅니다. 나머지 행동 키는 아래처럼 어빌리티로 갑니다.

```mermaid
sequenceDiagram
    participant In as Enhanced Input
    participant P as AAgPlayerCharacter
    participant ASC as 플레이어 ASC
    participant GA as 행동 어빌리티
    In->>P: 행동 키
    P->>P: HandleInputPressed<br>막혀 있으면 선입력으로 기억
    P->>P: RunInput
    alt 이 키를 받는 어빌리티가 실행 중
        P->>ASC: 입력 태그의 게임플레이 이벤트
        ASC->>GA: 이벤트 전달<br>(평타 다음 타, 패리 모션 중 가드)
    else 그 밖
        P->>ASC: TryActivateAbilitiesByTag
        ASC->>GA: 막는 태그가 없으면 시작
    end
    Note over P: 행동이 다시 허용되면<br>기억한 입력을 RunInput으로 다시 처리
```
