# 몽타주 시간표

몽타주 안에서 Task를 실행하는 시각(판정·보호·이동·전환·추적 구간과 지점)과 그 값을 어떻게 관리하고 실행하는지 정합니다. Task의 종류와 재생 Task는 [어빌리티와 AbilityTask](<어빌리티와 AbilityTask.md>)를 따릅니다.

## 기술 결정

| 항목 | 결정 | 이유 |
| - | - | - |
| 원본 | 몽타주 안에서 실행하는 Task의 시각과 값은 `Data/MontageTimelines.json`의 몽타주 시간표가 유일한 원본입니다. 항목은 값을 직접 가지며 행동 JSON의 설정을 가리키지 않습니다. 기획서가 정한 연출인 카메라 셰이크(GroundSlam 착지, 궁극기 마무리)도 시간표 지점에 둡니다. | 시각과 값을 에디터 없이 텍스트로 고치고 diff로 리뷰합니다. 새 기능은 Task 하나만 더하면 됩니다. |
| 몽타주에 남는 노티파이 | 연출(공격 예고·궁극기 화면 효과의 엔진 `AnimNotify_GameplayCueState`, 궁극기 베기 선의 엔진 `AnimNotify_GameplayCue`와 `AnimNotify_GameplayCueState`)만 몽타주에 둡니다. 게임 규칙을 실행하는 프로젝트 노티파이와 엔진 워핑 노티파이는 두지 않고, 루트 모션 소스가 움직이는 동안 몽타주 루트 모션을 끄는 일은 Dash와 Launch가 맡습니다([어빌리티와 AbilityTask](<어빌리티와 AbilityTask.md>) '몽타주와 섹션'). | 연출은 기획 데이터가 아니라 모션의 제작 정보입니다. 같은 일을 노티파이와 시간표가 함께 하면 두 번 일어납니다. |
| 판정 | 몽타주를 재생하는 Task(PlayMontage)가 자기 재생의 위치로 판정합니다([기본 방침](<기본 방침.md>) '구조 선택'의 예외). 판정한 뒤에는 Task와 엔진 Motion Warping을 씁니다. Task가 각자 자기 시각을 판정하지 않고, 판정기를 재생과 떼어 두지 않습니다. | 재생 위치는 히트스톱, 재생 배율, 반복 섹션, 섹션 이동, 몽타주 멈춤을 그대로 반영합니다. 판정하는 곳이 하나여야 한 프레임에 지난 항목들의 실행 순서와, 몽타주가 진행된 뒤·공격 판정 전이라는 판정 시점을 지킵니다. Task마다 판정하면 결과가 Task의 틱 순서에 달립니다. 판정기만 재생과 떼면 코드는 그대로 옮겨지고 재생과의 연결(재생 바뀜, 섹션 이동 알림)만 늘어나므로, 재생과 판정을 한 Task에 둡니다. 그래서 어빌리티는 몽타주·섹션·시간표를 모릅니다. |
| 같은 몽타주를 쓰는 행동 | 같은 값을 씁니다. 값이 달라야 하는 행동이 생기면 몽타주를 따로 둡니다. | 시간표는 몽타주 단위입니다. 함께 쓰는 넉업 몽타주에는 행동마다 달라지는 값이 없습니다. |
| 흐름 | 시작 섹션 고르기, 기다림, 다음 동작은 섹션과 Transition으로 적습니다. 시작 섹션은 PlayMontage의 Section과 조건으로 고릅니다([어빌리티와 AbilityTask](<어빌리티와 AbilityTask.md>) '몽타주와 섹션'). 기다림은 반복 섹션과 그 섹션을 덮는 Transition 구간(Event·Tag)입니다. 섹션을 바꾸는 항목은 Transition뿐입니다. | 몽타주의 흐름이 데이터에 드러나고, 재생 Task는 Transition이 요청한 전환만 합니다. |
| 다시 읽기 | 로딩 실패 처리와 재생별 반영 시점은 [JSON 로딩의 기술 결정](<JSON 데이터.md#기술-결정>) 중 '오류 검사'와 [재로딩 반영 시점](<JSON 데이터.md#재로딩-반영-시점>)을 따릅니다. | 진행 중인 구간의 값이 중간에 바뀌지 않습니다. |

## 형식

`Data/MontageTimelines.json`은 몽타주 에셋 경로를 키로 하고, 몽타주마다 섹션 이름을 키로 한 항목 배열을 둡니다(`{"몽타주 경로": {"섹션": [항목, ...]}}`). 경로는 캐릭터 데이터(`Characters.json`) `Montages`의 값과 같습니다. 섹션이 하나인 몽타주는 엔진 기본 섹션 이름(`Default`)을 씁니다. Task가 없는 섹션은 적지 않습니다.

| 항목 | 필드 |
| - | - |
| 구간 | `{"Task": 이름, "Start": 초, "End": 초(선택), "EndSection": 섹션(선택), Params 필드...}` |
| 지점 | `{"Task": 이름, "Time": 초, Params 필드...}` |

- Task 이름과 Params 필드는 [Task 목록](<어빌리티와 AbilityTask.md#task-목록>)을 따르고, 둘 수 있는 곳(구간·지점)도 그 표를 따릅니다. 추적 구간은 `Direction`이 Target(기본값)인 RootMotion 구간입니다.
- 기본값의 명시와 선택 필드의 생략은 [기본값 작성](<JSON 데이터.md#기본값-작성>)을 따릅니다.
- Start·Time은 그 섹션의 시작 기준 초이며, 몽타주 Rate Scale을 적용하기 전의 값입니다. Rate Scale이 아니라 몽타주에 넣은 모션의 재생 속도를 바꾸면 그 시각도 함께 고칩니다. Start가 있으면 구간, 없으면 지점이므로 Start·Time은 0이어도 적습니다. 섹션의 배열 안에서는 항목을 Start·Time 순서로 적습니다.
- 구간이 끝나는 섹션은 `EndSection`이고 생략하면 자기 섹션입니다. End는 그 섹션의 시작 기준 초이고, 생략하면 그 섹션 끝까지입니다. 구간은 몽타주 타임라인에서 Start부터 End까지라, 그 사이의 반복이나 섹션 이동도 구간 안이면 한 실행으로 이어집니다.

실제 몽타주별 시각과 값은 [MontageTimelines.json](<../../Data/MontageTimelines.json>)에서 확인합니다.

## 판정 규칙

| 규칙 | 내용 |
| - | - |
| 기준 | 몽타주 재생 인스턴스의 재생 위치. 히트스톱이나 몽타주 멈춤으로 위치가 그대로면 아무 일도 일어나지 않습니다. |
| 구간 | Start ≤ 위치 < End인 동안 켜집니다. 재생을 시작한 위치에 걸친 구간은 시작과 함께 켜집니다. 한 번의 판정에서 구간 전체를 지나면 열고 바로 닫습니다. |
| 지점 | 앞 판정 위치 < Time ≤ 지금 위치일 때 한 번 실행합니다. 재생 시작과 섹션 이동 직후에는 그 위치의 지점도 실행합니다. |
| 순서 | 시각 순서로만 실행합니다. 같은 시각의 항목 사이에는 순서가 없습니다([어빌리티와 AbilityTask](<어빌리티와 AbilityTask.md>) '결정과 목표'). |
| 반복 섹션 | 위치가 뒤로 가면 그 사이의 지점을 실행하지 않습니다. 반복 섹션 안에는 지점과 추적 구간을 두지 않습니다. |
| RootMotion 구간 | 서로 겹치지 않게 둡니다. 겹치면 워핑이 두 번 걸립니다. 보정 목표는 구간을 시작할 때 정하므로, 한 동작 안에서 목표를 다시 정하려면 구간을 나눕니다(JumpCleave의 정점). |
| 전환 | 판정 중에 항목이 위치를 바꾸면 그 판정의 남은 항목은 실행하지 않습니다(옮긴 위치로 다시 판정). 같은 시각의 순서가 없으므로 전환 지점과 같은 시각에 시작하는 항목은 실행될지 정해지지 않아 두지 않습니다. 전환 지점은 섹션 끝보다 앞에 둡니다. 섹션 끝의 지점은 이어지는 섹션의 시작과 같은 시각이라, 그 섹션으로 다시 재생하면 또 실행되기 때문입니다. 섹션을 옮기면 건너뛴 지점은 실행하지 않습니다. 재생이 끝나며 닫히는 구간이 요청한 전환은 받지 않습니다. |
| 재생 바뀜 | 다시 재생하면 이전 재생의 구간을 끝냅니다. 지점 Task는 재생이 바뀌어도 남고, 재생 Task가 끝날 때 끝납니다. |
| 재생 끝 | 완료, 다른 몽타주에 끊김, 인스턴스가 사라짐, 행동 종료에서 켜진 구간을 모두 끕니다. 완료면 재생 Task가 지점 Task도 끝내고 끝나며, 끊김이면 행동을 취소합니다. |

## 클래스 구조

| 클래스 | 부모 | 역할 |
| - | - | - |
| `UAgMontageTimelineData` | `UObject` | `MontageTimelines.json`의 값. 키는 몽타주(JSON에는 경로)입니다. `UAgAssetManager`가 읽고 다시 읽습니다. |
| `FAgMontageTimeline`, `FAgTimelineSection` | | 몽타주 하나의 시간표(섹션 이름별), 섹션 하나의 항목(Task Params) 배열. 항목의 시각은 Params의 공통 부모(`FAgTaskParams`)에 있습니다. |
| `UAgAbilityTask_PlayMontage` | `UAbilityTask` | 재생마다 시간표를 복사해 판정하고, 구간·지점 Task를 시작·종료합니다. 추적 구간도 다른 구간처럼 Task(RootMotion)로 실행합니다([애니메이션과 이동](<애니메이션과 이동.md>) '추적 구간'). |

```mermaid
classDiagram
    direction TB
    UAgAssetManager --> UAgMontageTimelineData : MontageTimelines.json
    UAgMontageTimelineData *-- FAgMontageTimeline : 몽타주 경로별
    FAgMontageTimeline *-- FAgTimelineSection : 섹션별
    FAgTimelineSection *-- FAgTaskParams : 항목 배열
    UAgAbilityTask_PlayMontage ..> FAgMontageTimeline : 재생 시작 때 복사
    UAgAbilityTask_PlayMontage ..> UAbilityTask : 구간 시작·끝, 지점
```
