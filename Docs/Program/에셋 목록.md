# 에셋 목록

새로 만든 에셋입니다. 두는 폴더는 [기본 방침](<기본 방침.md>) '새 에셋 위치'를 따릅니다.

| 폴더 | 에셋 |
| - | - |
| `Characters` | `BP_AgPlayer`, `BP_AgBoss` (데이터만 설정). 템플릿 마네킹(`Characters/Mannequins`)과 같은 폴더입니다. |
| `GameModes` | 게임 모드 블루프린트 2개 (데이터만 설정) |
| `AI` | `ST_Boss`(보스 AI StateTree) |
| `Input` | 입력 에셋 10개, 입력 매핑 컨텍스트 1개 |
| `Animations` | `ABP_Ag`(공통 그래프), `ABP_AgPlayer`·`ABP_AgBoss`(모션 기본값), 블렌드 스페이스 2개(플레이어 가드, 보스 이동. 플레이어 이동은 템플릿 것), 덧입힘 모션 2개, 몽타주([애니메이션과 이동](<애니메이션과 이동.md>) '몽타주') |
| `Projectiles` | 검기 투사체 블루프린트(데이터만 설정), 검기 머티리얼 인스턴스(궁극기 베기 선도 씀) |
| `GameplayCues` | GameplayCue 블루프린트 8개(엔진 클래스를 직접 상속하며 Cosmetic 그래프 허용)와 예고 공통 함수 라이브러리 `BFL_GameplayCueCosmetics`: 피격, 가드, 패리, 궁극기 마무리, 궁극기 베기 선, 대미지 숫자, 가드 불가 예고, 패리 예고 |
| `Audio` | 피격·가드·패리 효과음 3개. 엔진 플러그인 NetworkPredictionExtras의 사운드를 원본 WAV로 가져온 것으로, 그 플러그인은 켜지 않습니다. |
| `Cinematics` | `LS_UltimateCutscene`(궁극기 컷신, 카메라만) |
| `UI` | `WBP_HUD`, `WBP_Title`, `WBP_Result`, `WBP_AgButton`, 월드 위치 위젯 3개(`WBP_LockOnMarker`, `WBP_ExecutionPrompt`, `WBP_DamageFloater`), UP 게이지 머티리얼(`M_UPGauge`), 쿨다운 원형 표시 머티리얼(`M_CooldownSweep`), CommonUI 글자 스타일(크기 단계 3개, 버튼 상태 2개, 대미지 숫자 1개, 쿨다운 숫자 1개), 버튼 스타일, 스킬·궁극기 아이콘(`Icons`의 텍스처 2개) |
| `Maps` | `LV_FrontEnd`(빈 레벨), `LV_BossStage`(Lvl_Combat 복사본을 보스 스테이지 기획서대로 고친 레벨) |

고치는 기존 에셋과 설정입니다.
