# 에셋 목록

새로 만든 에셋입니다. 두는 폴더는 [기본 방침](<기본 방침.md>) '새 에셋 위치'를 따릅니다.

| 폴더 | 에셋 |
| - | - |
| `Characters` | `BP_Player`, `BP_Boss` (데이터만 설정). 템플릿 마네킹(`Characters/Mannequins`)과 같은 폴더입니다. |
| `GameModes` | 게임 모드 블루프린트 2개, `BP_PlayerController` (데이터만 설정) |
| `AI` | `ST_Boss`(보스 AI StateTree) |
| `Input` | 입력 에셋 10개, 입력 매핑 컨텍스트 1개 |
| `Animations` | 하위 폴더 없이 둡니다. `ABP_Character`(공통 그래프), `ABP_Player`·`ABP_Boss`(모션 기본값), 블렌드 스페이스 `BS_PlayerGuardMove`·`BS_BossMove`(플레이어 이동은 템플릿 것), 덧입힘 모션 `A_GuardFlinch_Additive`·`AM_GuardFlinch`, 행동 몽타주 `AM_<캐릭터>_<행동>`·공통 `AM_KnockUp`([캐릭터 이동과 모션 제어](<캐릭터 이동과 모션 제어.md>) '몽타주') |
| `Projectiles` | 검기 투사체 블루프린트(데이터만 설정), 검기 머티리얼 인스턴스(궁극기 베기 선도 씀) |
| `GameplayCues` | GameplayCue 블루프린트(데이터만 둠). 부모는 [전투 연출과 시간 제어](<전투 연출과 시간 제어.md>) 'GameplayCue': 피격, 가드, 패리, 궁극기 베기 선, 대미지 숫자, 가드 불가 예고, 패리 예고, 무기 궤적. 부모는 [카메라와 화면 효과](<카메라와 화면 효과.md>) '카메라 셰이크'·'화면 후처리': 궁극기 화면(`GC_UltimateScreen`), 극한 회피 화면(`GC_PerfectDodgeScreen`), 단계별 카메라 셰이크(`GC_CameraShake_Small/Medium/Large`) |
| `Camera` | 단계별 카메라 셰이크 `CS_Small`·`CS_Medium`·`CS_Large`([카메라와 화면 효과](<카메라와 화면 효과.md>) '카메라 셰이크') |
| `VFX` | 공격 예고 섬광 `NS_Telegraph`(경량 나이아가라)와 그 머티리얼 `M_Telegraph`(텍스처 없음), 무기 궤적 리본 `NS_WeaponTrail`과 그 굴절 머티리얼 `M_WeaponTrail`(텍스처 없음) |
| `VFX/PostProcess` | 궁극기 후처리 `M_UltimateScreen`·`MI_UltimateScreen`, 극한 회피 후처리 `M_PerfectDodgeScreen`·`MI_PerfectDodgeScreen`. 두 효과의 부모 머티리얼은 독립적입니다. 연결과 편집은 [카메라와 화면 효과](<카메라와 화면 효과.md>)의 '화면 후처리'를 따릅니다. |
| `Audio` | 피격·가드·패리 효과음 3개. 출처와 가져온 방법은 [VFX·사운드 리소스 조사](<../Art/VFX·사운드 리소스 조사.md>) 'NetworkPredictionExtras 사운드'를 따릅니다. |
| `Cinematics` | `LS_UltimateCutscene`(궁극기 컷신의 카메라와 플레이어 자세) |
| `UI` | `WBP_UILayout`, `WBP_HUD`, `WBP_Title`, `WBP_ControlsPopup`, `WBP_PauseMenu`, `WBP_ControlsGuide`, `WBP_Result`, `WBP_Button`, 월드 위치 위젯 3개(`WBP_LockOnMarker`, `WBP_ExecutionPrompt`, `WBP_DamageFloater`), UP 게이지 머티리얼(`M_UPGauge`), 쿨다운 원형 표시 머티리얼(`M_CooldownSweep`), CommonUI 글자 스타일(크기 단계 3개, 버튼 상태 2개, 대미지 숫자 1개, 쿨다운 숫자 1개), 버튼 스타일, 글꼴(`Fonts/NanumGothic`, 엔진에 포함된 TTF를 가져온 `NanumGothicRegular`·`NanumGothicBold`), 스킬·궁극기 아이콘(`Icons/T_Skill_DashSlash`, `Icons/T_Ultimate_Judgment`) |
| `Maps` | `LV_FrontEnd`(빈 레벨), `LV_BossStage`(보스 스테이지. 구성은 보스 스테이지 기획서) |

고치는 기존 에셋과 설정입니다.

| 대상 | 변경 |
| - | - |
| `SK_Mannequin` | `hand_r`에 카타나·할버드 소켓 추가 |
| 무기 메시 `katana`, `Halberd_weapon` | 무기 궤적의 날 시작·끝 소켓(`TrailStart`, `TrailEnd`) 추가 |
| Fab 시퀀스(쓰는 것) | 루트 모션 설정([기본 방침](<기본 방침.md>) 'Fab 모션') |
| 프로젝트 설정 | 시작 맵과 기본 게임 모드, 쿡할 맵, CommonGameViewportClient, CommonUI 버튼 실행 키 처리(`CommonButtonAcceptKeyHandling`), 에셋 매니저 클래스(`UAgAssetManager`), 공격 판정용 충돌 채널, GameplayCue 경로와 그 폴더의 항상 쿡하기, 마우스 스무딩 끄기(카메라 '자유 시점'의 회전 반응), 파이썬 원격 실행 |
