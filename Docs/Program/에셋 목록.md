# 에셋 목록

새로 만드는 에셋은 `/Game` 바로 아래 종류별 폴더에 둡니다.

| 폴더 | 에셋 |
| - | - |
| `Characters` | `BP_AgPlayer`, `BP_AgBoss` (데이터만 설정). 템플릿 마네킹(`Characters/Mannequins`)과 같은 폴더입니다. |
| `GameModes` | 게임 모드 블루프린트 2개 (데이터만 설정) |
| `Data` | `DA_Player`, `DA_Boss`(에셋 참조만), `TP_Enemy`(대상 찾기 프리셋) |
| `AI` | `ST_Boss`(보스 AI StateTree) |
| `Input` | 입력 에셋 10개, 입력 매핑 컨텍스트 1개 |
| `Animations` | `ABP_Ag`, 블렌드 스페이스 2개(플레이어 가드, 보스 이동. 플레이어 이동은 템플릿 것), 덧입힘 모션 2개, 몽타주(행동마다 하나, 약 40개) |
| `GameplayCues` | 피격, 가드, 패리, 궁극기 마무리, 궁극기 베기 선, 대미지 숫자, 가드 불가 예고, 패리 예고, 셰이크 3단계와 각 단계가 재생하는 카메라 셰이크 3개 |
| `Projectiles` | 검기 투사체 블루프린트(데이터만 설정), 검기 머티리얼 인스턴스(궁극기 베기 선도 씀) |
| `Audio` | 피격·가드·패리 효과음 3개. 엔진 플러그인 NetworkPredictionExtras의 사운드를 원본 WAV로 가져온 것으로, 그 플러그인은 켜지 않습니다. |
| `Cinematics` | `LS_UltimateCutscene`(궁극기 컷신, 카메라만) |
| `UI` | `WBP_HUD`, `WBP_Title`, `WBP_Result`, `WBP_AgButton`, 월드 위치 위젯 3개(`WBP_LockOnMarker`, `WBP_ExecutionPrompt`, `WBP_DamageFloater`), UP 게이지 머티리얼(`M_UPGauge`), 쿨다운 원형 표시 머티리얼(`M_CooldownSweep`), CommonUI 글자 스타일(크기 단계 3개, 버튼 상태 2개, 대미지 숫자 1개, 쿨다운 숫자 1개), 버튼 스타일 |
| `Maps` | `LV_FrontEnd`(빈 레벨), `LV_BossStage`(Lvl_Combat 복사본을 보스 스테이지 기획서대로 고친 레벨) |

고치는 기존 에셋과 설정입니다.

| 대상 | 변경 |
| - | - |
| `SK_Mannequin` | `hand_r`에 카타나·할버드 소켓 추가 |
| Fab 시퀀스(쓰는 것) | 루트 모션 켜기 |
| 프로젝트 설정 | 시작 맵과 기본 게임 모드, CommonGameViewportClient, 에셋 매니저 클래스(`UAgAssetManager`), 공격 판정용 충돌 채널, 카메라 채널 응답, GameplayCue 경로, 마우스 스무딩 끄기(카메라 '자유 시점'의 회전 반응). DPI 크기 조절은 엔진 기본값(짧은 변 기준, 1080에서 1배)이 UI 스타일의 화면 기준과 같아 그대로 둡니다. |
