# 구현 위치표

기획서의 각 항목을 어디에서 구현하는지 정리합니다. 기획서와 다르게 만들어진 곳을 찾을 때 이 표에서 시작합니다.

| 기획서 | 항목 | 구현 위치 |

| 전투 시스템 | 공격 중 이동 | `UAgAbilityTask_AttackMovement`(대상, 정지 간격, 추가 접근), `AAgCharacterBase`(회전, 회전 정지, 루트 모션 자르기), 공격 몽타주의 Motion Warping 구간 |
| 전투 시스템 | 피격 처리 순서, 대미지 | 대미지 GameplayEffect, `UAgDamageExecution`(피격 처리 순서, 대미지 계산식) |

| 플레이어 사양 | 이동, 달리기 | `AAgPlayerCharacter`, 달리기 어빌리티 |
| 플레이어 사양 | 락온 | `UAgAbility_LockOn`, `UAgLockOnComponent` |
| 플레이어 사양 | 공통 규칙(공격 방향, 공격 중 이동, 쿨다운) | `UAgAbilityTask_AttackMovement`(공격 방향, 공격 중 이동), `AAgPlayerCharacter`(범위 밖의 공격 방향), `UAgGameplayAbility`(쿨다운) |
