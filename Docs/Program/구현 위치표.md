# 구현 위치표

기획서의 각 항목을 어디에서 구현하는지 정리합니다. 기획서와 다르게 만들어진 곳을 찾을 때 이 표에서 시작합니다.

| 기획서 | 항목 | 구현 위치 |
| - | - | - |
| 전투 시스템 | 스탯 | `UAgAttributeSet`, 캐릭터 데이터 |
| 전투 시스템 | 공격 판정, 공격 데이터 | 몽타주 시간표(`UAgMontageTimelineComponent`), `UAgAbilityTask_Attack`(무기 스윕), 시간표와 캐릭터 데이터의 공격 데이터 |
| 전투 시스템 | 공격 중 위치·회전 보정 | `UAgGameplayAbility`(재생별 대상·이동 제약과 구간 존재 조회), `UAgRootMotionModifier_MotionWarping`(워프 목표), `AAgCharacterBase`(전달된 이동·회전 제약 적용), 공격 몽타주의 Motion Warping 구간 |
| 전투 시스템 | 피격 처리 순서, 대미지 | `Effects.json`의 `Damage` 효과, `UAgDamageExecution`(피격 처리 순서, 대미지 계산식) |
| 전투 시스템 | PP 리젠 | `Effects.json`의 `PPRegen`(회복)·`PPRegenDelay`(리젠 대기) 효과, `AAgCharacterBase`(PP가 줄 때 리젠 대기를 다시 검) |
| 전투 시스템 | 피격 반응, 가드 반응 | `UAgHitResultGameplayEffectComponent`(반응 판정), 상태 어빌리티, `UAbilityTask_PlayMontageAndWait`(반응 모션), `ABP_Ag`의 덧입힘 슬롯 |
| 전투 시스템 | 히트스톱 | `Effects.json`의 `Hitstop` 효과(시간, 태그), `UAgHitResultGameplayEffectComponent`(적용), `AAgCharacterBase`(시간 배율) |
| 전투 시스템 | 그로기, 사망 | `UAgAttributeSet`(사망·그로기 판정), 상태 어빌리티 |
| 전투 시스템 | 상태 우선순위 | `AgGameplayTags`, 어빌리티의 취소·차단 태그 |
| 플레이어 사양 | 스탯, 자원 회복, MP·UP 충전, SP 소모 | `Characters.json`의 `Player`, `Effects.json`의 리젠·자원 효과(행동의 SP·MP·UP 소모는 `Resource`), `UAgHitResultGameplayEffectComponent`(적중 충전), 회피·가드 어빌리티(극한 회피·패리 보상) |
| 플레이어 사양 | 이동, 달리기 | `AAgPlayerCharacter`, 달리기 어빌리티 |
| 플레이어 사양 | 락온 | `UAgGameplayAbility`, `UAgAbilityTask_LockOn`, `AAgPlayerCharacter::GetLockOnTarget` |
| 플레이어 사양 | 공통 규칙(공격 방향, 공격 중 위치·회전 보정, 쿨다운) | `UAgRootMotionModifier_MotionWarping`(공격 방향, 공격 중 위치·회전 보정), `AAgPlayerCharacter`(범위 밖의 공격 방향), `UAgGameplayAbility`(쿨다운) |
| 플레이어 사양 | 평타 ~ 처형 | 플레이어 행동 어빌리티 |
| 플레이어 사양 | 궁극기(궁극기 컷신, 시간 정지, 베기 선) | `UAgGameplayAbility`, `UAgAbilityTask_PlayCutscene`·`LS_UltimateCutscene`(궁극기 컷신), `UAgAbilityTask_TimeStop`·`UAgTimeSubsystem`(시간 정지), `AAgPlayerCharacter`(화면 흑백), `GC_UltimateSlashes`(베기 선) |
| 플레이어 사양 | 슬로우모션 | `UAgTimeSubsystem` |
| 플레이어 사양 | 피격과 사망 | 상태 어빌리티 |
| 플레이어 입력 | 키 배치, 공통 입력 처리, 상태별 허용 입력, 선입력, 모션 캔슬 | 입력 에셋, `AAgPlayerCharacter`, 어빌리티의 '행동 중' 태그 |
| 보스 사양 | 스탯 | `Characters.json`의 `Boss` |
| 보스 사양 | 공격 예고 | 공격 데이터, 보스 패턴 몽타주의 예고 노티파이, 예고 큐 블루프린트(`GC_UnblockableTelegraph`, `GC_ParryTelegraph`)와 `BFL_GameplayCueCosmetics` |
| 보스 사양 | 패턴 공통 규칙, 패턴 상세 | `UAgGameplayAbility`(패턴 사건 연결·쿨다운), `UAbilityTask_PlayMontageAndWait`(몽타주), `UAgMontageTimelineComponent`·`UAgAbilityTask_Attack`(판정), `UAgRootMotionModifier_MotionWarping`(이동), `AAgCharacterBase`·`AAgBossCharacter`(회전), `UAgAbilityTask_SpawnProjectile`·`AAgProjectile`(SwordWave의 검기) |
| 보스 사양 | 페이즈, AI 행동 규칙, 패턴 목록, 전투 시작과 행동 전환 | `ST_Boss`, 보스 AI 태스크·조건, `Characters.json`의 `Boss`, `Abilities.json`(패턴 정의) |
| 보스 사양 | 피격과 그로기, 연출 | 상태 어빌리티 |
| 카메라 | 자유 시점, 카메라 충돌 | `AAgPlayerCharacter`·`BP_AgPlayer`(스프링 암과 카메라) |
| 카메라 | 락온 카메라 | `UAgAbilityTask_LockOn`, `Camera.json` |
| 카메라 | 카메라 셰이크 | `AAgPlayerController::PlayCameraShake`, `UAgCameraShake`, `UAgCameraData`, `Camera.json` |
| 전투 HUD | HUD 요소, 상황별 표시 규칙 | `UAgHUDWidget`, UP 게이지 머티리얼, `AAgBossCharacter`(락온 마커, 처형 안내), `GC_DamageNumber`와 `AAgDamageFloater`(대미지 숫자) |
| 게임 플로우 | Front End, Boss Stage, Stage Clear, Game Over | `AAgFrontEndGameMode`, `AAgBossStageGameMode` |
| 게임 플로우 | 화면 UI, UI 조작 | `UAgTitleScreen`, `UAgResultScreen`, `UAgButton`, CommonUI 설정 |
| UI 스타일 | 화면 기준, 글자, 버튼 | 프로젝트 설정(DPI), CommonUI 글자·버튼 스타일 |
| 보스 스테이지 | 레벨 구성, 보스 아레나, 배치 요소 | `LV_BossStage` |
| 마일스톤1 계획 | 아트 리소스 | 캐릭터 블루프린트, GameplayCue 블루프린트, 검기 투사체 블루프린트 |
