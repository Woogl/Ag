# 데이터 위치표

기획서의 데이터가 어느 파일(JSON, 에셋)의 어느 필드에 있는지 정리합니다. 데이터를 어디에 두는지는 [JSON과 DataAsset](<JSON과 DataAsset.md>)을 따릅니다.

값은 기획서에만 적고 이 표에는 적지 않습니다. 데이터를 옮기거나 이름을 바꾸면 이 표도 함께 고칩니다.
