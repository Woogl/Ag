# 데이터 위치표

기획서의 데이터가 어느 파일(JSON, 에셋)의 어느 필드에 있는지 정리합니다. 데이터를 어디에 두는지는 [JSON 데이터](<JSON 데이터.md>)을 따릅니다.

값은 기획서에만 적고 이 표에는 적지 않습니다. 데이터를 옮기거나 이름을 바꾸면 이 표도 함께 고칩니다.

실행 구조와 Task별 Params는 [어빌리티와 AbilityTask](<어빌리티와 AbilityTask.md>)를, 행동 정의의 형식은 [JSON 데이터](<JSON 데이터.md>) '행동'을 따릅니다. 몽타주 안의 구간·지점의 시각과 값은 `MontageTimelines.json`에 몽타주 경로·섹션별로 있고, 시각은 섹션 시작 기준입니다([몽타주 시간표](<몽타주 시간표.md>)).
